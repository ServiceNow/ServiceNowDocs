# Requirements and limitations

Learn about requirements and limitations for this unified journey.

## Requirements

-   Application dependencies: Task Mining, Automation Center, AI Agent Studio, and AI Desktop Actions.
-   Windows requirement: Task Mining agent recording and AI Desktop Actions agent execution require Windows 11+. Automation Center configuration and agent creation can be performed on any supported operating system.
-   Instance requirements: starting with the Australia patch 4 release.
-   Plugin dependencies: Both Automation Center and AI Desktop Actions must be installed on the target instance before you can create an AI agent. ServiceNow Otto for Automation Center must be installed to use this feature.
-   AI skill dependencies: User task step summarization skill must be activated. For more information, see [Activate a skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/activate-skill.md).

## Limitations

-   Supported scenario: This feature currently supports only Excel-to-browser interactions, where data is copied from a Microsoft Excel file and it is entered into a form in a browser.
-   AI-generated output variability: Decomposed automations and agent instructions are generated by AI. Each run may produce different results. Review all AI-generated output before creating or activating an agent.
-   Anchor adjustment: On-screen task desktop actions require anchors that identify the UI element to interact with. Anchors captured from Task Mining recordings may not match the format AI Desktop Actions expects and may require manual correction in the AI Desktop Actions design workspace.
-   No cross-product notification: Automation Center users don't receive a notification when a Task Mining user submits an automation request. The business analyst and the technical user must coordinate directly.
