# Launcher screen headers

Launcher screen headers enable you to define how the heading of a launcher screen appears. You can either have text with an optional variable added, a logo, or leave the area blank.

|Launcher screen with logo header|Launcher screen with text header|
|--------------------------------|--------------------------------|
|\[Omitted image "launcher-screen-logo.png"\] Alt text: Launcher screen header with logo|\[Omitted image "launcher-screen-text.png"\] Alt text: Launcher screen header with text|

**Note:** The configuration of the launcher screen header with text is performed in the Mobile App Builder. Whereas configuration of the logo is performed in the ServiceNow AI Platform.
