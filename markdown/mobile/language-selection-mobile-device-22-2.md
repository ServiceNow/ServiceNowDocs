# Selecting languages on your mobile device \(ServiceNow mobile client version 22.2 and later\)

There are two areas where you can define the language for your ServiceNow mobile apps: the instance language setup and the mobile app language setup.

## Things to consider

-   For the optimum user experience, the same language should be used for the instance and the ServiceNow mobile app language.

    For a list of supported languages, see [Localization on mobile devices](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/mobile/localization-mobile-device.md).

-   The setup in this topic only applies if you're using ServiceNow mobile client version 22.2 and later.
-   When using Android version 12.0 or 13.0, the setup may differ depending on how your admin has configured the app.

**Note:** For the optimum user experience, the same language should be used for the instance and the ServiceNow mobile app language.

For a list of supported languages, see [Localization on mobile devices](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/mobile/localization-mobile-device.md).

## Defining the ServiceNow instance language from mobile app login screen

You can change the instance language by selecting the relevant language from the drop-down field in the mobile app login screen. If this field isn't displayed, this means that your instance has been preconfigured for a specific language and can't be changed.

\[Omitted image "mobile-app-login-language.png"\] Alt text: ServiceNow mobile instance login screen with language selection.

## Defining the mobile app language

You can change the mobile app language in the ServiceNow mobile app itself. The selected language incorporates both the Preferred language and the Instance language.

**Note:** In device ServiceNow mobile client version 22.1 and earlier, the Preferred language and Instance language is selected separately.
