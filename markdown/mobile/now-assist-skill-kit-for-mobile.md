# AI Skill Kit for mobile

The ServiceNow® AI Skill Kit plugin lets you create and activate custom prompts and skills for Otto on your mobile device.

If the default Otto skills aren't sufficient, you can use the AI Skill Kit to build custom skills and leverage more personalized generative AI features.

For more information on what skill kit can do, as well as how to configure Otto skills, see [Configuring AI Skill Kit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/configuring-now-assist-skill-kit.md).
