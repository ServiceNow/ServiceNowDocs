# Enable multiple users to work on a shared device

Enable multiple users to log in to a ServiceNow mobile account from a single mobile device. This is beneficial in environments where devices are shared, as it offers secure and personalized access. The configuration varies when working at an app level compared to working at a device level.

## App level and device level configuration

Refer to the following links for configuration at the app level and device level:

-   [Configure shared device mode at app level](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/mobile/shared-device-app-level.md)
-   [Configure shared device mode at device level](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/mobile/shared-device-device-level.md)

At the device level, Microsoft Entra shared device mode, managed through Microsoft Intune, gives users access across every Microsoft Entra-enabled app on the device. The device-level configuration differs between iOS and Android.

-   [Configure shared device mode at the device level for Android devices](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/mobile/shared-device-android-device.md)
-   [Configure shared device mode at the device level for iOS devices](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/mobile/shared-device-ios-device.md)

-   **Related links**

    [Overview of shared device mode - Microsoft Entra ID feature](https://learn.microsoft.com/en-us/entra/identity-platform/msal-shared-devices)
