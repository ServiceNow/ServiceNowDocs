# Configure L1 IT Service Desk AI Specialist profile settings

Modify the profile of the L1 IT Service Desk AI Specialist to set its assignment groups, roles, and language proficiencies.

## Before you begin

Role required: sn\_itsm\_common.sn\_service\_desk\_manager or admin

## Procedure

1.  Navigate to **All** &gt; **Service Operations Workspace**.

2.  On the Homepage, in the **L1 Service Desk AI Specialist** card, select **View details**.

    The L1 IT Service Desk AI Specialist setup page displays the following sections that you can select to review and configure the details:

    -   Profile
    -   Tasks
    -   Test
3.  On the L1 IT Service Desk AI Specialist setup page, select **Profile** and review or configure the following L1 IT Service Desk AI Specialist profile details.

    To modify the details in the profile section, select the **Edit** icon, make the changes and then select **Save**.
