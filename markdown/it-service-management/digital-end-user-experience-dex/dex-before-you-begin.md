# Before you begin

Review system requirements and use guided setup to activate required plugins before configuring DEX.

## Configuration overview and roadmap

The configuration overview describes the end-to-end setup process for DEX and presents a roadmap of the tasks you complete, in the order you complete them.

## Required plugins

Review the plugins required to run DEX, including their plugin IDs and activation instructions.

## System requirements

Before installing DEX, confirm that your environment meets the minimum platform version, supported Agent Client Collector versions, browser extension requirements, and compatible operating systems.

## Guided setup

Use DEX guided setup to install and configure the required plugins, enable the browser extension, and activate the Desktop Assistant.
