# Operating IT services in your organization

You can use a few Service Operations Workspace integrations to start operating IT services in your organization and set a path for your organization's performance and process improvements.

## Agent journey when starting IT service operations

-   Start the day by reviewing the outages, service announcements, and assignments in Service Operations Workspace to prioritize work based on service level agreements \(SLAs\), priority level, and urgency​.
-   Review the incoming interactions and resolve them through existing help resources.
-   If more help is required, the agent can create an incident from the interaction based on the issue reported. Because the agent has access to related incidents and recent interactions, the agent can provide better and faster support. The agent also has access to all related information from the incident record page.
