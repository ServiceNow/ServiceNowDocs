# Configure the verification methods for service desk process in Service Operations Workspace

Create and edit verification methods, map each to a service desk process, and integrate them with UXF routes for an end-to-end password reset flow.

-   **[Create verification settings](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/service-operations-workspace/create-verification-settings-pr-sow.md)**  
Create a verification type in the base system to authenticate the user credentials while resetting the password.
-   **[Map the password reset process](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/service-operations-workspace/map-password-reset-process-pr-sow.md)**  
Map the password reset process to verify the identity of the user requesting a password reset.
-   **[Map the UXF routes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/service-operations-workspace/map-uxf-routes-pr-sow.md)**  
Create a route for the verification method to map the verification process.
