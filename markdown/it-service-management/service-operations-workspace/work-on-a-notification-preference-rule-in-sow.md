# Manage delivery channel

Add, edit, and delete delivery channels for notification preference rules in Service Operations Workspace.

## Before you begin

Role required: rota\_manager, rota\_admin

## Procedure

1.  Navigate to **Workspaces** &gt; **Service Operations Workspace**.

2.  Select the **Schedules** icon.

3.  On the **Schedules** page, select **On-call Notification preferences** and then select **Edit** to add, edit, or delete delivery channels.

4.  Select **Add New** to add a new channel and enter the name and email address.

5.  Select the **Phone numbers** tab to add and edit phone numbers.

6.  To delete a delivery channel, select the channel from the list and select the **Delete** icon.

    **Important:**

    Deleting a delivery channel removes it from all notification preference rules that reference it. Verify that no active rules depend on the channel before deleting it.

7.  Select **Save** to apply your changes.
