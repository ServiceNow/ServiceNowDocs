# Join an active conference call from an incident

Join an active conference call from an incident to discuss its resolution.

## Before you begin

Role required: itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  On the **My work** tab, tap **See All**.

    \[Omitted image "my-work-itsm-mobile.png"\] Alt text: My work tab in the ITSM Mobile Agent app.

3.  Open the incident where the conference call originated.

4.  Tap **Collaborate**.

    \[Omitted image "incident-collaborate-itsm-mobile.png"\] Alt text: Collaborate option on an incident.

5.  Tap the active conference call.

    \[Omitted image "active-call-inc-itsm-mobile.png"\] Alt text: Active conference call listed for an incident.

6.  Tap the conference call.

7.  Tap **Join call**.

    \[Omitted image "join-call-inc-itsm-mobile2.png"\] Alt text: Join call option for an active conference call.
