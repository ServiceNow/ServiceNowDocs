# Create an incident from the app landing page

Create an incident directly from your ITSM Mobile Agent app landing page with a single tap.

## Before you begin

Role required: itil, sn\_incident\_write, or admin

## Procedure

1.  On your agent mobile app landing page, tap the add icon \[Omitted image "add-icon.png"\] Alt text: to create an incident directly from the landing screen.

2.  Fill in the fields.
