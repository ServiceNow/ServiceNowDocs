# View participants in an incident task conference call

View the active and inactive participants in an incident task conference call in the ITSM Mobile Agent app.

## Before you begin

Role required: itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  On the **My work** tab, tap **See All**.

    \[Omitted image "my-work-itsm-mobile.png"\] Alt text: My work tab with the See All option

3.  Tap the incident record.

4.  Tap **Related** &gt; **Incident tasks**.

    \[Omitted image "inc-task-itsm-mobile-1.png"\] Alt text: Incident task record

5.  Tap the incident task record.

6.  Tap **Collaborate** &gt; **Conference calls** &gt; **Active**.

7.  Tap the conference call.

8.  Do one of the following:

    |Option|Action|
    |------|------|
    |**Active**|Tap **Active** to view the active participants.|
    |**Inactive**|Tap **Inactive** to view the inactive participants.|

    \[Omitted image "participants-inc-call-itsm-mobile.png"\] Alt text: Participant status in a conference call
