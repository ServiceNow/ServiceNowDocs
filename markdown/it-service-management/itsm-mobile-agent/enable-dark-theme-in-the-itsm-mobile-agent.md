# Enable dark theme in ITSM Mobile Agent

Enable the dark theme in ITSM Mobile Agent to display light text on a dark background.

## Before you begin

Role required: itil, rota\_manager, or sn\_incident\_write

## Procedure

1.  Open the ITSM Mobile Agent and tap **More**.

2.  Tap **Settings** &gt; **Preferences** &gt; **Theme**.

3.  Tap **Dark**.
