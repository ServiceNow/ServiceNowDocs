# Collaboration with incidents

Agents can start and manage collaboration on incident records from the ITSM Mobile Agent app.

-   **[Initiate a chat with the caller from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/initiate-chat-incident-itsm-mobile.md)**  
Initiate a chat with the caller from an incident to discuss the resolution of an incident.
-   **[Initiate a chat with the assignment group from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/initiate-chat-assignment-group-itsm-mobile.md)**  
Initiate a chat with the assignment group members from an incident to discuss the resolution of an incident.
-   **[Initiate a conference call with the caller from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/initiate-conf-call-inc-itsm-mobile.md)**  
Initiate a conference call from an incident to discuss the resolution of an incident.
-   **[Add participants to a conference call from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/add-participants-inc-call-itsm-mobile.md)**  
Add participants to an active conference call from an incident to discuss the resolution of an incident.
-   **[Join an active conference call from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/join-call-inc-itsm-mobile.md)**  
Join an active conference call from an incident to discuss its resolution.
-   **[View active collaborations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/active-collaborations-inc-itsm-mobile.md)**  
As an incident manager, you can view all the active collaborations for the incidents.
-   **[View participants in an incident conference call](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/view-participants-inc-call-itsm-mobile.md)**  
View the active and inactive participants in an incident conference call in the ITSM Mobile Agent app.
-   **[End a conference call from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/end-inc-call-itsm-mobile.md)**  
End an active conference call from an incident record in ITSM Mobile Agent. The call host or a user with the incident manager role can end the call.
