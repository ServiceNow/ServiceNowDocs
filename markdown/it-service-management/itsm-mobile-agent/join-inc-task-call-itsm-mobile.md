# Join an active conference call from an incident task

Join an active conference call from an incident task record to discuss how to resolve the incident.

## Before you begin

Role required: itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  On the **My work** tab, tap **See All**.

    \[Omitted image "my-work-itsm-mobile.png"\] Alt text: My work.

3.  Tap the incident record you want to work on.

4.  Tap **Related** &gt; **Incident tasks**.

    \[Omitted image "inc-task-itsm-mobile-1.png"\] Alt text: Incident task record

5.  Tap the incident task record.

6.  Tap **Collaborate** &gt; **Conference calls** &gt; **Active**.

7.  Tap the conference call.

8.  Tap **Join call**.

    \[Omitted image "join-call-inc-itsm-mobile.png"\] Alt text: Join call option for an active conference call on an incident task.
