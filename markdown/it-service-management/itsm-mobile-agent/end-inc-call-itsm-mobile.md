# End a conference call from an incident

End an active conference call from an incident record in ITSM Mobile Agent. The call host or a user with the incident manager role can end the call.

## Before you begin

Role required: itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  On the **My work** tab, tap **See All**.

    \[Omitted image "my-work-itsm-mobile.png"\] Alt text: My work.

3.  Open the incident from which the conference call originated.

4.  Tap **Collaborate**.

    \[Omitted image "incident-collaborate-itsm-mobile.png"\] Alt text: Collaborate option in an incident record

5.  Tap the active conference call.

    \[Omitted image "participants-inc-call-itsm-mobile.png"\] Alt text: Participant status in a conference call

6.  Tap the more options icon \[Omitted image "more-options-itsm-mobile-agent.png"\] Alt text:.

7.  Tap **End call**.
