# View participants in an incident conference call

View the active and inactive participants in an incident conference call in the ITSM Mobile Agent app.

## Before you begin

Role required: itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  On the **My work** tab, tap **See All**.

    \[Omitted image "my-work-itsm-mobile.png"\] Alt text: My work tab with the See All option

3.  Open the incident from which the conference call originated.

4.  Tap **Collaborate**.

    \[Omitted image "incident-collaborate-itsm-mobile.png"\] Alt text: Incident record with the Collaborate option

5.  Tap the active conference call.

    \[Omitted image "participants-inc-call-itsm-mobile.png"\] Alt text: Participant status in a conference call

6.  Do one of the following:

    |Option|Action|
    |------|------|
    |**Active**|Tap **Active** to view the active participants.|
    |**Inactive**|Tap **Inactive** to view the inactive participants.|
