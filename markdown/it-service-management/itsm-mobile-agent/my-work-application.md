# Managing incidents and tasks using the My Work applet

Use the My Work applet in the ITSM Mobile Agent app to access and update your incidents, change tasks, and catalog tasks from your mobile device.

As an agent, you can:

-   Access incidents, change tasks, and catalog tasks.
-   Take quick actions and provide timely updates.
-   Add work notes or comments, update incident details, and assign incidents to other agents.
-   Access change requests and request approvals.

From the main screen of the ITSM Mobile Agent app, you can directly [create an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/create-incident-mobile.md).
