# Applications used with ITSM Mobile Agent

Plugins for related applications extend ITSM Mobile Agent with capabilities such as event management, on-call scheduling, major incident management, and performance analytics.

The following plugins are commonly used with ITSM Mobile Agent:

-   Event management \(com.glideapp.itom.snac\)
-   Hardware asset management \(com.sn\_hamp\)
-   Shift Planning \(com.sn\_shift\_planning\)
-   Slack spoke-store \(com.sn.slack.ahv2\)
-   Incident communications management \(com.snc.iam\)
-   Major incident management \(com.snc.incident.mim\)
-   Notify \(com.snc.notify\)
-   On-call Scheduling \(com.snc.on\_call\_rotation\)
-   Performance Analytics - Major Incident Management \(com.snc.pa.incident.mim\)
-   Performance Analytics - ITSM Dashboards \(com.snc.pa.itsm\_dashboards\)
-   Collaboration services - store \(com.snc.tcm\_collab\_hook\)
