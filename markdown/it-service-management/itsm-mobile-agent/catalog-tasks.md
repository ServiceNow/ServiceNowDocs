# Catalog tasks

Catalog tasks help fulfill service catalog requests. View the catalog tasks assigned to you and add comments to them.

A catalog task is a task that is associated with a service catalog item. Catalog tasks are used to source items and fulfill requests.

Tap the card to access all the catalog tasks assigned to you.

1.  [Filter](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/filter-records-agent-mobile.md) the list according to your set criteria.
2.  Swipe left to add comments or close the task.
3.  On the **Catalog tasks** screen, tap any task to view the details or activity of the catalog task. From this screen, you can add comments only.
