# Initiate a chat with the assignment group from an incident

Initiate a chat with the assignment group members from an incident to discuss the resolution of an incident.

## Before you begin

Role required: itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  On the **My work** tab, tap **See All**.

    \[Omitted image "my-work-itsm-mobile.png"\] Alt text: My work.

3.  Tap the incident record you want to work on.

4.  Tap **Assignment group**.

    \[Omitted image "assignment-group-itsm-mobile-2.png"\] Alt text: Assignment group in ITSM Mobile Agent

5.  Do one of the following:

    |Option|Action|
    |------|------|
    |Initiate chat in Slack|Tap the Slack assignment group.|
    |Initiate chat in Microsoft Teams|Tap the Microsoft Teams assignment group.|

    \[Omitted image "assignment-group-major-inc-itsm-mobile.png"\] Alt text: Assignment group in ITSM Mobile Agent

    You can also interact with a user from the assignment group. Tap the assignment group, tap a user, and then select either Slack or Microsoft Teams to initiate a conversation.

    **Note:** The Slack and Microsoft Teams assignment group contacts appear only if the assignment group has valid Slack and Microsoft Teams accounts.
