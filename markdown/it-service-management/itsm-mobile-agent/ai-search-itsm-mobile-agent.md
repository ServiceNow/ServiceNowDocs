# AI Search in ITSM Mobile Agent

AI Search helps agents find incidents, tasks, users, and knowledge articles in ITSM Mobile Agent with features such as auto-complete, typo correction, and Genius results.

With AI Search, agents can find the following records:

-   Incidents, including breached, at-risk, and major incident management \(MIM\) incidents
-   Change tasks
-   Catalog tasks
-   Changes
-   System users
-   Knowledge base articles

You can also switch between Zing search and AI Search.

AI Search in ITSM Mobile Agent offers the following features:

-   Navigation tab filters: Filters help users narrow down results on a site.
-   Auto-complete: As the user enters text, AI Search displays suggested queries.
-   Auto-correct typos: Typos are auto-corrected based on indexed content. 
-   Synonym handling: The search engine also searches for synonyms of the search term.
-   Genius cards: Genius result cards display the most relevant answers.
