# My team dashboard

As a group manager, you can use the My team dashboard to gain insights into data such as incidents at risk, breached incidents, and overdue changes.

Tap a section to process or perform an action on the incidents.

\[Omitted image "itsm-ma-my-team-dashboard.png"\] Alt text: My team dashboard on a mobile device showing incidents at risk, breached incidents, and overdue changes

**Note:**

-   The data visualization changes for My team dashboard are available in the base system for both new and upgrade customers. You can also view mobile analytics in Platform analytics workspace to configure or create new data visualizations. For more information, see [Create a mobile analytics preview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/mobile/sg-mobile-dashboard-preview.md).
-   For upgrade customers who have already customized the analytics sections, the data visualization changes aren't available by default. You can enable the new analytics section records from the Mobile Agent section of the Mobile App Builder to view the changes.
