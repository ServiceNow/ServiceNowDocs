# Collaboration with major incidents

Agents can start and manage collaboration on major incident records from the ITSM Mobile Agent app.

Add deep linking support for ITSM Mobile Agent in the Mobile studio. For information about adding deep linking support, see [Add deep linking support to ITSM Mobile Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/deep-link-itsm-mobile-agent.md).
