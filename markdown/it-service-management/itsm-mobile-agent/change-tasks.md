# Change tasks

ITSM Mobile Agent lists the change tasks assigned to you so you can view and work on them. A single tap shows the details, activities, and related change tasks.

Tap the card to access all the change tasks assigned to you.

1.  [Filter](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/filter-records-agent-mobile.md) the list according to your set criteria.
2.  Swipe left to add comments to the task or close the task.
3.  On the **Change Tasks** screen, tap any task to view the details, activity, and related change tasks. You can add comments or close a task from this screen.

    **Note:**

    Each change task card shows the risk value of the task, for example, Very High or Moderate.
