# Log in to ITSM Mobile Agent

Access ITSM Mobile Agent on your mobile device to manage incidents and to view and update on-call schedules.

## Before you begin

Ensure that ITSM Mobile Agent is installed from ServiceNow Store onto your instance. For more information, see [Install ITSM Mobile Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/install-itsm-mobile-agent.md).

The ServiceNow Agent app must be installed on your mobile device from the Apple App Store or Google Play Store. For more information about this app, see [Mobile Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/mobile/mobile-experience.md).

Role required: none

## Procedure

1.  Tap the mobile app icon on your device, and then tap the plus button to log in to an instance.

2.  In the instance address field, enter the instance address in one of two ways.

    If you have multiple instances added to the device, nicknames can help you quickly locate a ServiceNow AI Platform instance.

4.  Tap **Save and Login**.

    The ITSM Mobile Agent landing screen opens. You can search for incidents, change tasks, and other records using the search bar at the top of the landing screen.
