# Configuring ITSM Mobile Agent

Administrators can configure preferences, notifications, and application behavior in Mobile Agent for agents and managers.

As an administrator, you can configure preferences and application behavior and create tools for agents and managers. These are some of the tasks you can perform as an administrator:

-   Migrate to the latest supported version of ITSM Mobile Agent.
-   Create and configure actionable notifications for ITSM Mobile Agent.
-   Enable push notification categories.
