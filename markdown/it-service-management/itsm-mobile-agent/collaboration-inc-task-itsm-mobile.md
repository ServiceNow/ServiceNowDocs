# Collaboration with incident tasks

Agents can start and manage collaboration on incident task records from the ITSM Mobile Agent app.

-   **[Initiate a conference call from an incident task](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/initiate-call-inc-task-itsm-mobile.md)**  
Initiate a conference call from an incident task record to discuss the resolution of an incident.
-   **[Add participants to a conference call from an incident task](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/add-participants-inc-task-itsm-mobile.md)**  
Add participants to an active conference call with the caller from an incident task to discuss the resolution of a task.
-   **[Join an active conference call from an incident task](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/join-inc-task-call-itsm-mobile.md)**  
Join an active conference call from an incident task record to discuss how to resolve the incident.
-   **[View participants in an incident task conference call](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/view-participants-inc-task-call-itsm-mobile.md)**  
View the active and inactive participants in an incident task conference call in the ITSM Mobile Agent app.
-   **[End a conference call from an incident task](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-mobile-agent/end-inc-task-call-itsm-mobile.md)**  
End an active conference call from an incident task record in ITSM Mobile Agent. The call host or a user with the incident manager role can end the call.
