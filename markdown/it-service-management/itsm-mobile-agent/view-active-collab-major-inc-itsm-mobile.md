# View active collaborations for major incidents

View the active call and chat collaborations for major incidents in the ITSM Mobile Agent app.

## Before you begin

Role required: major\_incident\_manager, itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  Tap the **Major incidents** tab.

3.  Tap **Active collaborations**.

    \[Omitted image "major-inc-active-collab.png"\] Alt text: Major incidents tab with the Active collaborations option

4.  Do one of the following:

    |Option|Action|
    |------|------|
    |**Calls**|Tap **Calls** to view the active call collaborations.|
    |**Chats**|Tap **Chats** to view the active chat collaborations.|

    \[Omitted image "chat-major-inc-active-collab-itsm-mobile.png"\] Alt text: Active chat collaborations for a major incident

5.  Swipe and tap **View** to view the conversation in the respective application.

    \[Omitted image "chat-major-inc-active-collab-itsm-mobile.png"\] Alt text: Active chat collaboration with the View option

    Each collaboration displays:

    -   Application: Slack / Microsoft Teams
    -   Collaboration title
    -   Incident created date and timestamp
    -   Channel name: A channel marked with “\#” is public, and any user can view the conversation. A channel without “\#” is private, and only the collaborators can view the conversation.
