# End a conference call from a major incident

End an active conference call from a major incident in ITSM Mobile Agent. The call host or a user with the major incident manager role can end the call.

## Before you begin

Role required: major\_incident\_manager, itil, itil\_admin, or admin

## Procedure

1.  Open the ITSM Mobile Agent app.

2.  Tap the **Major incidents** tab.

3.  Tap **Active collaborations**.

    \[Omitted image "major-inc-active-collab.png"\] Alt text: Active collaborations in major incident tab.

4.  Tap the more options icon \[Omitted image "more-options-itsm-mobile-agent.png"\] Alt text:.

    \[Omitted image "more-options-maj-inc.png"\] Alt text: More options.

5.  Tap **End call**.

    Tap **Cancel** to resume the conference call.

    \[Omitted image "end-conf-call-maj-inc.png"\] Alt text: End call confirmation with End call and Cancel options
