# ITSM Mobile Agent settings

The Settings screen of the ITSM Mobile Agent app shows instance and version details and provides options for security, analytics, legal information, and logging out.

You can adjust the settings of the ITSM Mobile Agent app. The following information is available in the Settings screen of your app.

|Setting|Description|
|-------|-----------|
|Instance|Name of the app version|
|Version|Version of the app|
|Security|Field for entering secure credentials if the administrator has set authentication requirements|
|Analytics|Option to turn on analytics for app usage|
|Legal|Privacy policies, open source license information, and end user license agreement|
|Logout|Option to log out of the instance|
