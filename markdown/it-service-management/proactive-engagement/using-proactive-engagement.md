# Using Proactive Engagement

Proactive Engagement proactively detects digital experience issues on end-user devices and provides self-help resolutions that employees can run through Virtual Agent. When self-help doesn't resolve the issue, an incident is created as a fallback so that a service desk agent can take over.

## Overview of Proactive Engagement

When a DEX metric rule with a Proactive Engagement resolution is triggered on an end-user device, Proactive Engagement creates an experience issue record and starts an engagement with the employee. If the employee consents, Virtual Agent guides them through the resolution. If the resolution succeeds, Proactive Engagement requests feedback. If the resolution fails or the employee reports the issue as unresolved, Proactive Engagement falls back to a configured option \(typically creating an incident with the interaction summary attached, so a service desk agent can take over\).
