# Close multiple incidents from a list

Close multiple incidents that share a resolution code at once from the incident list.

## Before you begin

Role required: itil, list\_updater, sn\_incident\_write, or admin

## Procedure

1.  Select the check box beside each incident to close.

2.  Select and hold \(or right-click\) any list column header and select **Update Selected**.

    \[Omitted image "close-inci-from-list.png"\] Alt text: Update selected UI action

3.  Set the value of **State** to **Closed**.

4.  In the Resolution Information section, select a code in the **Resolution code** field and enter notes in the **Resolution notes** field.

5.  Select **Update**.

    The changes apply to all the selected records.
