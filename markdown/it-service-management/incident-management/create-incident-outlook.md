# Configuring Microsoft Outlook to create incidents and VTB tasks

To create incidents and VTB tasks, or to chat with a virtual agent from within your Outlook email, activate and deploy the ServiceNow Add-in for Microsoft Outlook.

The ServiceNow Add-in for Microsoft Outlook lets you engage with IT directly from an email. IT users can also create an incident from an email and assign it to the correct team, or create a Visual Task Board \(VTB\) task.

-   **[Activate the ServiceNow Add-in for Microsoft Office](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/activate-outlook-add-in.md)**  
You can install the ServiceNow Add-in for Microsoft Office plugin \(com.sn\_outlook\_addin\) if you have the admin role.
-   **[Deploy the ServiceNow Add-in for Microsoft Outlook](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/deploy-outlook-add-in.md)**  
Deploy the ServiceNow add-in for Microsoft Outlook so that users can chat with a virtual agent and create incidents and Visual Task Board \(VTB\) tasks from within Outlook.
