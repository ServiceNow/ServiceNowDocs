# Create a record producer using a template

Use a predefined incident template with a record producer to fill in standard information for the incidents that the record producer creates.

## Before you begin

Role required: catalog\_admin or admin

## Procedure

1.  Navigate to **All** &gt; **Service Catalog** &gt; **Catalog Definitions** &gt; **Record Producers**.

2.  Select **New** and complete the steps in [Create a record producer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/t_DefRecProdInSCat.md).

3.  Select the **Generated Record Data** tab and select the incident template to populate fields when the record producer is submitted.

4.  Select the Additional Action icon \[Omitted image "additional-actions.png"\] Alt text: and then select **Save**.
