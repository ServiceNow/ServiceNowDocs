# Resolve, reopen, or close incident associated with universal request

As a requester, resolve, reopen, or close an incident from the Incident Actions widget on a universal request record. The widget is available only when an incident is the primary task of the universal request.

## Before you begin

An incident must be associated with the universal request.

Role required: none

## Procedure

1.  Navigate to your portal page.

2.  Select **Requests**.

3.  Open the universal request that is associated with the incident.

4.  From the Incident Actions widget, select one of the following options.

    |Option|Description|
    |------|-----------|
    |**Resolve**|Resolves the incident and updates the state of the universal request record.|
    |**Reopen**|Reopens a closed incident and updates the state of the universal request record.|
    |**Close**|Closes an incident and updates the state of the universal request record.|

    **Note:** The state of the universal request record is updated based on the configuration in the State Mapping \[universal\_request\_state\_mapping\] table.
