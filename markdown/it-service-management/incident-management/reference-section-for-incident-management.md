# Incident Management reference

Reference sections provide additional information about components installed with Incident Management.

For information about incident routing and feedback, see [Exploring Incident Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/incident-management-process.md).

To track the knowledge articles used to resolve incidents, use the Knowledge related list on the Incident form. For more information, see [Create a knowledge article from an incident with a template](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/create-a-knowledge-article.md).

-   **[Domain separation and Incident Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/domain-separation-incident-management.md)**  
Domain separation is supported in Incident Management. Domain separation enables you to separate data, processes, and administrative tasks into logical groupings called domains. You can control several aspects of this separation, including which users can see and access data.
-   **[Incident Management data model](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/incident-mangmt-data-model.md)**  
The Incident Management data model diagram shows the relationships between the tables within the application and provides an overall picture of how the Incident Management application operates.
-   **[Incident Management plugins](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/incident-mgmt-plugins.md)**  
Many of the Incident Management plugins are activated in the base system. You can activate the others when you're ready to use them. Some plugins include demo data.
-   **[Enhanced security model features for incident tables](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/comp-instal-itsm-enhanced-sec-features.md)**  
Help prevent unauthorized access to incident-related tables using Deny-Unless access control lists \(ACLs\). A Deny-Unless authentication ACL restricts access for a non-authenticated user.
-   **[Incident Management integrations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-management/inci-mgmt-integrations.md)**  
Incident Management integrations connect your incident response process with other tools so you can automate incident handling and address specific challenges directly.
-   **[Incident Management glossary]()**  
Definitions of the terms and concepts used in Incident Management, grouped alphabetically.
