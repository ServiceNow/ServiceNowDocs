# Configuring Task Intelligence for ITSM

Configure Task Intelligence for ITSM so agents can use the application to get the field level predictions and similar records on incidents as actionable recommendations in Service Operations Workspace.

## Configuration overview

After you install Task Intelligence for ITSM from ServiceNow® Store, you set up, train, and deploy the prediction model, and configure the recommendation to use the trained and deployed model. This allows agents to see the prediction in Service Operations Workspace.

Complete the following tasks to configure Task Intelligence for ITSM:

-   Install the application. For more information, see [Install Task Intelligence for ITSM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-service-management/task-intelligence-for-itsm/install-ti-itsm.md).
-   Review the components installed with the application. For more information, see [Components installed with Task Intelligence for ITSM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-service-management/task-intelligence-for-itsm/components-installed-ti-itsm.md).
-   Set up, train, and deploy a prediction model. For more information, see [Managing Task Intelligence for ITSM models](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-service-management/task-intelligence-for-itsm/using-task-intelligence-itsm.md).

-   **[Install Task Intelligence for ITSM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-service-management/task-intelligence-for-itsm/install-ti-itsm.md)**  
You can install the Task Intelligence for ITSM application \(com.snc.itsm\_ml\_task\) if you have the admin role. The application installs related ServiceNow® Store applications and plugins if they aren't already installed.
