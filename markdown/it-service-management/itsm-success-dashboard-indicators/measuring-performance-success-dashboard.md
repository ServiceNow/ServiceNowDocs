# Maximizing the benefits of using the ITSM Success Dashboard indicators

Use the ITSM Success Dashboard indicators to measure the performance of your ITSM implementation using the key performance indicators \(KPIs\) defined.

-   **[Monitoring the KPIs of your ITSM implementation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-success-dashboard-indicators/monitor-kpi-for-itsm-imlementation.md)**  
Monitor ITSM Success Dashboard indicators to measure the performance of your ITSM implementation against KPIs.
-   **[Share the Success Dashboard indicators](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-success-dashboard-indicators/share-itsm-success-dashboard.md)**  
Share the Success Dashboard indicators with your ITSM or HR leadership teams so they can measure implementation performance.
-   **[Benchmarks for Success Dashboard indicators](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-success-dashboard-indicators/success-dashboard-benchmark.md)**  
View the global benchmark score for Success Dashboard KPIs and trends to compare them with other Success Dashboard customers.
-   **[Estimated cost savings for Success Dashboard indicators](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-success-dashboard-indicators/estimated-cost-savings-sd.md)**  
Use Estimated Cost Savings to measure the total amount agents save through Virtual Agent, Knowledge, and Service Catalog.
-   **[View metrics for selected period in ITSM Success Dashboard indicators](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-success-dashboard-indicators/view-metrics-selected-period.md)**  
View the Key Performance Indicators \(KPIs\) metrics on the ITSM Success Dashboard for a selected period to analyze the performance.
-   **[Create a target for the KPI in the Success Dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/itsm-success-dashboard-indicators/create-target-kpi-sd.md)**  
Create a target for a KPI to be on par with the benchmark score or the organizational targets.
