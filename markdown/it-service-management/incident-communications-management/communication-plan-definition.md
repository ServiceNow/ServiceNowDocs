# Communication plan definitions

An incident communication plan helps you streamline communication for an incident. It defines the stakeholders who should be informed, what information should be shared, when the information should be delivered, and the methods of communication.

For instructions on creating a communication plan definition, see [Create communication plan definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/create-comm-plan-definition.md).

**Note:** If the UI16 module link redirection feature is enabled in Service Operations Workspace \(SOW\) and the UI16 module supports the redirect configuration, navigating through UI16 paths such as **My Communication Plans**, automatically redirects you to the equivalent list or record pages in SOW instead of displaying the UI16 forms or lists. For more information, see [Redirect UI16 module links to Service Operations Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/service-operations-workspace/redirect-ui16-module-links-sow.md).

**Important:** When you create a communication plan definition, verify that the table is Incident \[incident\]. If you upgraded to London or a later release and use communication plans to streamline the communication process, deactivate the Major Incident Response and Resolution flow.
