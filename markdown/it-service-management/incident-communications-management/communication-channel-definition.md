# Communication channel definitions

You can define a communication channel for each communication task. The communication channel determines which mode of communication to use for the task when a plan is attached to an incident. The modes of communication available are email, SMS, conference, and Slack.

For instructions on creating a communication channel definition, see [Create communication channel definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/create-comm-channel-definition.md).
