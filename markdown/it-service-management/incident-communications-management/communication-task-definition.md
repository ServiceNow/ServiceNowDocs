# Communication task definition

The communication plan involves a series of communication tasks. A communication task definition enables you to specify the mode of communication \(channel\) such as email or SMS and the frequency of communication.

Communication task enables you to track the progress of the communication plan. You can define specific service level agreement \(SLA\) for each task. For instructions on creating a communication task definition, see [Create communication task definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/create-comm-task-definition.md).
