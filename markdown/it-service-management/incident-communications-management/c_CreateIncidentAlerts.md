# Creating ad hoc incident communication plans

Create an ad hoc incident communication plan to manage and track communications around a high-priority incident or other issues.

You can create an ad hoc incident communication plan in the following ways:

-   [Create ad hoc incident communication plan from Incident Communications Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-communications-management/t_CreateAnAlertDirectly.md).
-   [Create ad hoc incident communication plan from an incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-communications-management/t_CreateAnAlertFromAnIncident.md).

-   **[Create an ad hoc incident communication plan from Incident Communications Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-communications-management/t_CreateAnAlertDirectly.md)**  
Create an incident communication plan from Incident Communications Management for an issue that isn't covered by an existing plan and requires collaboration.
-   **[Create ad hoc incident communication plan from incident](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-service-management/incident-communications-management/t_CreateAnAlertFromAnIncident.md)**  
Create an ad hoc incident communication plan from an incident to collaborate on an issue that isn't covered by an existing plan. Information from the incident automatically populates the ad hoc communication plan.
