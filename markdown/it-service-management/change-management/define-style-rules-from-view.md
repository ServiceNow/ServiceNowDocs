# Define style rules from the change schedules view

Create style rules from the change schedules view to apply them to the specific change schedule where they're defined.

## Before you begin

Role required: sn\_chg\_soc.change\_soc\_admin, sn\_change\_role, sn\_change\_write, or admin

## Procedure

1.  Navigate to **All** &gt; **Change** &gt; **Schedule** &gt; **Change Schedules**.

2.  Select a tile to view the Change Schedule page.

3.  Select the style icon \[Omitted image "change-schedule-style-icon.png"\] Alt text:.

4.  Do any one of the following actions.

    |Option|Description|
    |------|-----------|
    |**Create a span style**|Select **Add Span Style**.|
    |**Edit the name of an existing span style**|Select the name of the span style that you want to edit.|
    |**Edit all details of the span style**|Select the arrow icon \[Omitted image "change-schedule-span-arrow.png"\] Alt text: to the right of the span style name, and edit the style rule name, span color, and filtering as required.|

5.  Select **Save**.
