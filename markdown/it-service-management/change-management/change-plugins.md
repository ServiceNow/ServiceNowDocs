# Change Management plugins

You can activate one or more of the Change Management plugins if they are not already active. Some plugins include demo data.

Many of the Change Management plugins are activated in the base system. You can activate others when you're ready to use them. The following table lists the Change Management plugins that are inactive in the base system. Each entry links to topics that explain how to activate, configure, and use the plugin.
