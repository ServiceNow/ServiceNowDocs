# Create approval definitions

Use approval definitions to define a set of criteria that are evaluated automatically before the policy is marked as approved.

## Before you begin

In the approval definitions, you can define to determine

-   If the approval is user or group based.
-   If it should automatically approve or reject on behalf of a user.
-   If a response to the approval is required.

Role required: change\_manager or admin

**Note:** Approval definitions can be applied only once if multiple applied decisions have the same approval definitions associated with them.

## Procedure

1.  Navigate to **All** &gt; **Change** &gt; **Change Policy** &gt; **Approval Definitions**.

2.  Select **New**.

3.  On the form, fill in the fields.

**Wait for**

</td><td>

Determines the approval timing.-   **First response**: waits for the first response from the group.

-   **Percentage of users**: Set a percentage of users required for approval in the Percentage field. The possible values are:
    -   Empty: The first response satisfies the approval decision.
    -   Less than or equal to 0%: The first response satisfies the approval decision.
    -   Greater than or equal to 100%: All responses are required.
    -   Between 0 and 100%: The specified percentage of responses is required.
 **Note:**

The script can't update the change request record.
-   Set the `approvers` variable to a sys\_id, a comma-separated list of sys\_ids, or an array of sys\_ids.
-   For the **Add a group approval** action, return group sys\_ids from the Group \[sys\_user\_group\] table. For all other approval actions, return user sys\_ids from the User \[sys\_user\] table. Invalid sys\_ids are ignored.
-   The script returns up to 100 approvers. To change this limit, set the `com.snc.change_management.approval.max_script_approvers` system property.
-   If the script is empty, fails, or runs longer than 10 seconds, no approvals are generated. The `com.snc.change_management.approval.script_eval_timeout_ms` system property sets the timeout in milliseconds. Script issues are logged with the sys\_id of the approval definition.
