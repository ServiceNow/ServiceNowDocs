# Test the L1 IT Service Desk AI Specialist

Test your L1 IT Service Desk AI Specialist on a single record to preview how it works, and verify that it matches your intentions.

## Before you begin

Role required: sn\_itsm\_common.sn\_service\_desk\_manager or admin

## About this task

You can test an execution of the L1 IT Service Desk AI Specialist on a single record.

**Note:** Testing a L1 IT Service Desk AI Specialist, depending on the tasks configured, can make changes to the record. Tests are not simulations.

## Procedure

1.  Navigate to **All** &gt; **Service Operations Workspace**.

2.  On the Homepage, in the **L1 Service Desk AI Specialist** card, select **View details**.

    The L1 IT Service Desk AI Specialist setup page displays the following sections that you can select to review and configure the details:

    -   Profile
    -   Tasks
    -   Test
3.  On the L1 IT Service Desk AI Specialist setup page, select **Test** to view recommended records to test.

    Recommended records are selected based on their relevance to the tasks available to the L1 IT Service Desk AI Specialist.

4.  **Choose a record** to run a test on to see how the L1 IT Service Desk AI Specialist resolves an open incident record.

    This enables the L1 IT Service Desk AI Specialist to work on an open incident.

    Once a record is chosen, you can select the open link button to open the record in a new browser tab to check the details.

    **Note:** Choose records that you can safely make changes to. The work is actually being done on the record during the test.

5.  Select **Run** to begin the test.

    The test begins on the record. You can watch what fields it updates and any comments or work notes it generates.

    When the test is complete, you can review all the changes made. Verify the L1 IT Service Desk AI Specialist meets your expectations.
