# ServiceNow Otto skills

Review the generative AI skills available for Telecommunications Network Inventory, what each one does, and where to use it.

The following skill is available for Telecommunications Network Inventory. Skills are generated on the record page and, where activated, in the ServiceNow Otto panel.

|Skill|What it does|
|-----|------------|
|Remote Hands Request Summarization|Provides a contextual overview of a Remote Hands case, combining current case data with insights from similar historical cases. See [ServiceNow Otto in Remote Hands Request Management application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/telecom-network-inventory/telecommunications-network-inventory/servicenow-otto-in-remote-hands-request-management-application.md).|
