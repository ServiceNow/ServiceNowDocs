# AI in Telecommunication Network Inventory

Use ServiceNow Otto to automate rack allocation and summarize Remote Hands cases in Telecommunications Network Inventory. AI agents find racks that fit the capacity requirements of a change request, and summarize Remote Hands cases using similar past cases.

ServiceNow Otto brings generative AI skills and agentic workflows to Telecommunications Network Inventory. Users can spend less time on manual rack searches and case reviews, and more time on exceptions that need human judgment.

Within Telecommunications Network Inventory, ServiceNow Otto capabilities fall into two categories:

-   **Agentic workflows:** Multi-step, autonomous processes that act on request data with minimal user intervention, such as finding racks that can accommodate the capacity requirements of a change request.
-   **Skills:** Individual generative AI capabilities that act on a record, such as summarizing a Remote Hands case.

Most skills and workflows are available directly on the relevant record page, and can also be started conversationally from the ServiceNow Otto panel. For more information about the panel, see [ServiceNow Otto panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-panel-overview.md). To activate the panel, see [Activate the ServiceNow Otto panel standard chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/activate-now-assist-panel.md).

Most skills are inactive by default. To activate a skill in the AI Admin Hub, follow the general procedure in [Activate an AI skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/configure-a-now-assist-skill.md), selecting the TMT workflow group. To customize a skill's prompt directly in AI Skill Kit, see [Clone and edit a ServiceNow skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/clone-and-edit-servicenow-skill.md).
