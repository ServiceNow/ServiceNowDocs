# ServiceNow Otto agentic workflows

Telecommunications Network Inventory agentic workflows find racks that can accommodate the capacity requirements of a data center infrastructure allocation change request.

The following agentic workflow is available for Telecommunications Network Inventory.

-   **Rack allocation**

    Finds racks that can accommodate the capacity requirement of a change request, based on physical and logical constraints and your placement policies, and creates Affected CI records. See [Data center infra allocation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/telecom-network-inventory/telecommunications-network-inventory/data-center-rack-allocation.md).
