# Configure ServiceNow Otto for TNI

If you have the admin role, you can configure ServiceNow Otto in Telecommunications Network Inventory so that your agents can use the generative AI skills and agentic workflows.

Install the ServiceNow Otto plugin before you use the Remote Hands skill or the rack allocation agentic workflow. For more information, see [Install ServiceNow Otto for TMT](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-network-inventory/telecommunications-network-inventory/install-servicenow-otto-for-tmt.md).

-   **[Install ServiceNow Otto for TMT](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-network-inventory/telecommunications-network-inventory/install-servicenow-otto-for-tmt.md)**  
Install the ServiceNow Otto for TMT `sn_tmt_gen_ai` plugin to configure and use agentic workflows and skills in Telecommunications Network Inventory.
