# Filter the information in individual columns in a list

Agents can use filters at the top of each column in a list to filter the information that is displayed in CSM Configurable Workspace.

## Before you begin

Role required: sn\_customerservice\_agent, sn\_customerservice.consumer\_agent

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace**.

2.  Select the List icon and then select a list such as My Cases.

3.  Select a value from the **Operator** list below the column header.

4.  Enter a value in the **Filter** field and then press **Enter**.

    The list updates to show the filtered information.
