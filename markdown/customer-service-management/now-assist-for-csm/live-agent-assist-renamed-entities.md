# Renamed entities in Live Agent Assist

Starting with version 7.0 of Customer Service Management AI agent collection, several configuration records that support the Live Agent Assist capability were renamed to align with its new label, Live interaction recommendations AI agent.

The following table shows the labels used before v7.0 of Customer Service Management AI agent collection and the labels used starting with v70.

|Entity type|Before 7.0|Starting with v7.0|
|-----------|----------|------------------|
|AI Search Profile|Live Agent Assist Search Profile|Live interaction recommendations AI agent Search Profile|
|Skill|Live Agent Assist Graph Query Generator|Live Interaction Graph Query Generator|
|Skill|Live Agent Assist Query Enhancer|Live Interaction Query Enhancer|
|Skill|Live Agent Assist Transcript Analyser|Live Interaction Transcript Analyser|
|Skill|Live Agent Assist Response Generator|Live Interaction Response Generator|
|AI Agent|Live Agent Assist|Live interaction recommendations AI agent|
|AI Agent Trigger|Live Agent Assist - Interaction|Live interaction recommendations AI agent - Interaction|
|Tag|Live Agent Assist Tag|CSM Live interaction recommendations AI agent Tag|
