# Configure the form layout

Configure the layout of a record form as needed. For example, add or remove fields that appear on the form, determine field visibility, or add new sections to the form.

## Before you begin

Role required: workspace\_admin, ui\_builder\_admin, admin

## About this task

You can configure the form layout from within CRM Workspace.

## Procedure

1.  Select your profile picture in the workspace header.

2.  Select **Configure Page** &gt; **Form Layout** from the drop-down menu.

    You can choose to edit the form using Form Builder or within the Core UI.

3.  Ensure that the view name is set correctly before editing the form.

4.  Make the desired changes to the form and select **Save**.
