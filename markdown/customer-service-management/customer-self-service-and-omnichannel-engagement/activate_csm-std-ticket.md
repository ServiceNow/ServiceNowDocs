# Activate the standard ticket page for upgrade customers

If you have upgraded your instance, redirect the ticket page to the standard\_ticket page in the Service Portal and view requests on the standard ticket page.

## Before you begin

Role required: sp\_admin

## About this task

For new customers, the standard ticket page is enabled by default. For upgrade customers, you must enable it.

## Procedure

1.  Navigate to **All** &gt; **Service Portal** &gt; **Page Route Maps**.

2.  Search for CSM Standard Ticket.

3.  Set the value to **true** in the **Active** column.

4.  Select the name of the page route map.

5.  Select **here** to edit the record.

6.  Select the **Active** check-box.

7.  Select **Update**.
