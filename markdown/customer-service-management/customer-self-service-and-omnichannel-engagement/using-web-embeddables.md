# Configure Web Embeddables

Web Embeddables enables you to embed the ServiceNow components into external websites outside of the ServiceNow environment. Use the default components or create custom components to interact with the ServiceNow platform. Dedicated APIs support real-time data exchange without requiring users to access the ServiceNow instance directly.

The Web Embeddables homepage displays modules, components, and provides an overview on how to configure and embed components. It also shows Frequently Asked Questions that provide insights into the most common queries asked by users.

## Web Embeddables overview

\[Omitted video\] Description: Web Embeddables overview video

You can configure and embed the following ServiceNow components on third-party websites.

|Component|Description|
|---------|-----------|
|[Case list component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/case-list-component.md)|A list of cases with key details such as number, short description, and status.|
|[Case view component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/case-view-web-component.md)|The details of one case, with activity, attachments, and a process tab that displays relevant playbooks.|
|[Case create component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/case-create-component.md)|A form to submit a case for issues related to products and services.|
|[Catalog item component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/catalog-item-web-component.md)|A form to request an item or service.|
|[Knowledge article view component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/we-know-article-view-comp-overview.md)|A knowledge article with its title, author, view count, and read time. Users can rate the article and switch the display language.|
|[Data visualization component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/we-data-viz-comp-overview.md)|Data from any table as a score, pie, donut, or semi-donut chart.|
|[Playbook intake component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/we-playbook-intake-comp-overview.md)|A guided experience for submitting a case, with the stages and activities involved in resolving it.|
|[Catalog browse component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/we-catalog-browse-comp.md)|Catalog items that you can browse by catalog or category, or search by keyword.|
|[Object list component](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/we-object-list-comp.md)|Records from any table in a list, with bulk and inline actions.|
