# Case list component

Use the Case list component to show customers their cases and let them open a case to see its details.

Each case in the case list can include details such as the case number, the customer's name, short description, status, and opened. You can also add other columns using component properties.

**Note:** The Case list component can show the records from any extended table of case or task table.
