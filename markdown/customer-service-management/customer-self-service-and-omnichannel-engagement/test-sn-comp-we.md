# Test the ServiceNow components in a sandbox environment

Enables you to test the ServiceNow components on your sandbox instance without setting up a custom URL and authentication. It isn’t recommended to use this method for production or non-production instance.

Sandbox testing lets you see a component on a test page before you set up a custom URL and authentication.

**Warning:** Use these methods only for testing. Don't use them on a production instance.

## Next steps

When you finish testing, set up a custom URL and authentication for your production site. See [Set up a custom URL as the instance URL](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/set-up-custom-url.md), [Authenticate the ServiceNow components using OIDC](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/authenticate-sn-webcomponents-oidc.md), and [Non OIDC authentication for ServiceNow components](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/customer-self-service-and-omnichannel-engagement/auth-sn-webcomponents-non-oidc.md).
