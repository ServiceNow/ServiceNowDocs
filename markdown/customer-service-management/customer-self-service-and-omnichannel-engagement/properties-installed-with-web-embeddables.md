# Properties installed with Web Embeddables

Configure the properties available with Web Embeddables. Properties are added with the activation of the Web Embeddables plugin.

All system properties are located in the System Properties \[sys\_properties\] table. To access table, navigate to **All** &gt; **System properties** or enter `sys_properties.list` in the navigation filter.

|Property|Description|Default|
|--------|-----------|-------|
|\[glide.uxf.lib.embeddables.enabled\]|Enables the rendering of web components and assets in an embeddables context. You must enable this sys property to allow Web Embeddables to function on third-party website. If you set it to false, Web Embeddables doesn’t function on third-party websites.|true|
|\[sn\_cb\_experiences.uib.enable.cb\]|Enables the component builder experience in UI Builder.|true|
