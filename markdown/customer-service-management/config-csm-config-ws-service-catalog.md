# Configure service catalogs

Service catalogs enable agents to submit requests on behalf of customers directly from within CRM Workspace.

## Before you begin

Role required: workspace\_admin, ui\_builder\_admin, admin

## About this task

Using service catalogs, agents can quickly initiate service requests during customer interactions without leaving the workspace.

## Procedure

1.  Navigate to **All** &gt; **Service Portal** &gt; **Portals**.

2.  Select **Service Workspace Portal**.

3.  Select the Catalogs related list and then select **Edit**.

    **Note:** If you are unable to select the Catalogs related list, make sure you are in the Service Catalog - Service Workspace application.

4.  Select and add the desired catalogs to the Catalogs list.

    For example, add Customer Service.

5.  Select **Save**.


## Result

The system displays the catalog items belonging to the configured service catalogs in CRM Workspace.
