# Track outages and install base service health on BOSP

Enable your business organization staff to view outage information affecting their install base items directly on the Business Organization Support Portal \(BOSP\).

## Before you begin

Role required: sn\_customerservice.svc\_location\_manager\_contributor, sn\_bus\_loc.business\_org\_consumer\_contributor, or sn\_bus\_loc.business\_org\_account\_contributor

## Procedure

1.  Log in to the Business Organization Support Portal \(BOSP\).

2.  If an outage affects an install base item belonging to your business organization, an outage banner is displayed on the home page, indicating that there is an outage for that install base item.

3.  In the outage banner, select:

    -   the install base item number to view the install base item details. The outage banner is also displayed on the install base item's details page. Scroll to the bottom to view the health status of an install base item.
    -   Select the related case id in the banner to view the case details.
4.  Navigate to **Your Information** &gt; **Install Base** and open an install base item from the list.

    The outage banner is also displayed on the install base item's details page.


## Result

You can view outage details and the related case for your business organization's affected install base items, giving you visibility into service disruptions before you need to report them.
