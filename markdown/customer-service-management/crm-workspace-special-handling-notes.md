# CRM Workspace special handling notes

Special handling notes bring important information about individual records to the agent's attention.

Special handling notes can be displayed in the following ways:

-   In a pop-up window when the record is opened in the workspace.
-   In an embedded list or a related list on the record form.

The notes are ordered by priority in the pop-up window and in the lists.

Agents can see the priority, short description, and message for each note. A note can be assigned one of the following priorities, which also have associated colors.

-   Priority 1 — red
-   Priority 2 — orange
-   Priority 3 — purple
-   Priority 4 — gray

\[Omitted image "csm-config-workspace-special-handling-note.png"\] Alt text: Window displaying special handling information for records requiring attention, based on priority. For the text description, refer to the preceding text in the Special handling notes section.

Agents can dismiss individual notes from the pop-up window. When all notes are dismissed, the pop-up window closes. Agents can also close the window.

Users with the sn\_shn.admin role can configure special handling notes and specify properties. For more information, see [Configure special handling notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/customer-service-management/configure-special-handling-notes.md).

Users with the sn\_shn.admin or sn\_customerservice\_manager roles can create special handling notes. For more information, see [Create a special handling note](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/customer-service-management/t_CreateAnOnScreenAlert.md).
