# Use quick actions on individual records in a list

Agents can use quick actions to update records in a list in CSM Configurable Workspace.

## Before you begin

Role required: sn\_customerservice\_agent, sn\_customerservice.consumer\_agent

## About this task

Icons that appear next to the records in a list enable agents to perform quick actions on individual records. The default action is **Edit form**, which opens an editable form for the record on a side panel.

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace**.

2.  Select the List icon and then select a list such as My Cases.

3.  Select the pencil icon next to the desired record to open the form in the side panel.

4.  Select the Details tab to edit record information and then select **Update**.

5.  Select the Activity tab to add comments or work notes to the activity stream and then select the **Post Comments** or **Post Work notes** icon.
