# Configure tabs in the contextual side panel

The contextual side panel in CRM Workspace includes different tools that agents can use to research and resolve customer issues. You can add, rearrange, or hide tabs as well as set default values.

## Before you begin

Role required: workspace\_admin, ui\_builder\_admin, admin

## About this task

The panel can be configured to ensure your agents have access to the necessary information for efficient case resolution.

## Procedure

1.  Navigate to **All** &gt; **Now Experience Framework** &gt; **UI Builder**.

2.  Select the CRM Workspace experience.

3.  Select the desired record page to open the page in the editor view.

4.  Select **Tab sidebar** in the Content pane.

    You can also select the component within the editor.

5.  To add a tab, select **+Add** in the Tab sidebar component.

6.  Select the option for building a tab.

    -       -   Use a repeater
    -   Display lists for a related record
    -   Add a page collection
    This procedure uses the **Start from an empty container** option.

7.  Fill out the Tab Settings modal and select **Create**.

    The tab appears at the bottom of the list of tabs.

8.  If desired, drag and drop the tab to the desired location in the list.

9.  Select **Save** to save the changes to the record page.
