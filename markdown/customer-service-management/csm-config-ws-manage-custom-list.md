# Manage customized record lists

Agents can manage the customized lists of records that they create in CRM Workspace. This includes saving a copy of a list, renaming a list, sharing or deleting a list, and opening a list in a new tab.

## Before you begin

Role required: sn\_customerservice\_agent, sn\_customerservice.consumer\_agent

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace**.

2.  Select the List icon and then select the My Lists tab.

3.  Select the Menu item actions icon next to a list.

4.  Select one of the following actions.

    |Action|Description|
    |------|-----------|
    |**Save a copy**|Saves a copy of the table with the name you provide in the **Title** field.|
    |**Rename**|Renames the table with the name you provide in the **Title** field.|
    |**Share**|Shares the list with the selected **Users** and **Groups**.|
    |**Delete**|Deletes the list after you confirm the action in the Delete modal.|
    |**Open in new tab**|Opens the list in a new tab.|
