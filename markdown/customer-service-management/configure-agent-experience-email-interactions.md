# Configure the agent experience for email interactions

Set up the tools and display options that agents use while they handle email interactions.

Agents handle email interactions in CSM Configurable Workspace. You can include earlier emails in agent replies, surface Recommended Actions based on the context of an email, change how the activity stream displays email conversations, and give agents wrap-up codes to categorize interactions when they close them.
