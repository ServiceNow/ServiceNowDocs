# Configure email addresses and properties for email to case

Set up which incoming emails create cases and which product each email address is tied to.

Customers submit cases by emailing the addresses you create in the [Email Accounts application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/c_EmailAccounts.md). You decide which incoming address creates a case automatically and link addresses to products so cases reach the right teams. You also set the subject line prefix that triggers case creation and choose whether to create cases for senders who aren't in the system yet.
