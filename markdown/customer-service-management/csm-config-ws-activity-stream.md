# Activity stream

The activity stream displays a running history of updates and communications within a record like field changes, comments, work notes, and emails.

\[Omitted image "csm-default-record-page-activity-stream.png"\] Alt text: The activity stream in the CRM Workspace is central to the record page and shows the record activity, including the user, action, and time

## Using the activity stream

Agents can use the activity stream component to view the activities occurring on a case or interaction record. These activities can include comments, work notes, emails sent or received, attachments, field changes, and chat discussions.

The activity stream component displays a list of changes made to a record. Different configurations of the activity stream component are included on each of the [record pages](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/customer-service-management/csm-config-workspace-record-pages.md) available with CRM Workspace.

Users with the administrator role can configure and customize the activity stream component in UI Builder. For more information, see [Activity Stream](https://horizon.servicenow.com/workspace/components/now-activity-stream-connected?release=brazil).
