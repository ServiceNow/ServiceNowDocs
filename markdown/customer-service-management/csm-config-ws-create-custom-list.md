# Create a customized list of records

Agents can create a customized list of records in CRM Workspace.

## Before you begin

Role required: sn\_customerservice\_agent, sn\_customerservice.consumer\_agent

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace**.

2.  Select the List icon and then select the My Lists tab.

3.  Select **Create new list** to display the New List modal.

4.  To create a list from an existing list:

    1.  Select **Start from existing**.

    2.  In the **Select a list** field, select an existing list to use as a starting point.

    3.  In the **Name the new list** field, enter a name for the list.

    4.  In the **Select columns** field, remove the columns that you don't want to include in the list.

    5.  In the **Add filters** section, select conditions and values to filter the records included in the list.

    6.  In the **Sort by** section, select the field on which to sort the list and select ascending or descending.

    7.  Select **Create**.

        The new list appears in the My Lists tab.

5.  To create a new list:

    1.  Select **Create your own**.

    2.  In the **Name the new list** field, enter a name for the list.

    3.  In the **Select a source** field, select a table.

    4.  In the **Select columns** field, remove the columns that you don't want to include in the list.

    5.  In the **Add filters** section, select conditions and values to filter the records included in the list.

    6.  In the **Sort by** section, select the field on which to sort the list and select ascending or descending.

    7.  Select **Create**.

        The new list appears in the My Lists tab.
