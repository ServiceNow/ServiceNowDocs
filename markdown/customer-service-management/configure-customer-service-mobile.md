# Configure the Customer Service mobile application

Configure the Customer Service mobile application and customize it for agents who use the application instance on their mobile devices.

## Before you begin

Role required: admin

## About this task

The Customer Service Mobile plugin \(com.sn\_csm\_mobile\) enables the Customer Service mobile application.

## Procedure

1.  Navigate to **All** &gt; **System Applications** &gt; **** &gt; **ServiceNow Studio**.

2.  In the **Select Application** pop-up window, select **Customer Service Mobile**.

    The Customer Service mobile application opens in the Studio, which is a guided app creator. For more information about using the Studio, [ServiceNow Studio](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-studio-landing.md).

3.  Customize the application to display the desired applets and data and configure agent actions and notifications.
