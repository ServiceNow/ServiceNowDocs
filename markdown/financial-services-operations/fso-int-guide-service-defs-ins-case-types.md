# Insurance service definition and case type relationships

Diagrams showing the relationships between FSO insurance applications, service definitions, and case types.

Cycle through the tabs in the embedded object to view each relationship diagram. To view a full list of all diagrams, select **Page List** in the bottom left hand corner of the object.

For full screen view, hover over the embedded object, and select the icon in the top left corner.

In each diagram:

-   The leftmost elements show the FSO application scope.
-   The centered elements are related service definitions.
-   The right most elements are the case types. Case type related to the service definitions are shown in green, and case types with no configured service definition are shown in purple.
