# Add an OT group with ServiceNow Otto for Setup

Add an Operational Technology \(OT\) group so you can organize users and assign roles per group.

## Before you begin

Role required: admin

## Procedure

1.  Access the Admin Home by logging in to your instance or navigating to **All** &gt; **Admin Center** &gt; **Admin Home**.

2.  Locate and select the **Operational Technology** card.

3.  In the **Configure your product** section, select **Configure** to open the configuration console.

4.  In the **Operational Data** section, select **Groups**.

5.  Edit an existing group's information by selecting the record in the list and updating the record.

6.  To add a group, complete the following steps.

    Alternatively, you can upload a Microsoft Excel spreadsheet with group information by selecting the **Add a group - More actions** \[Omitted image "more-actions-arrow.png"\] Alt text: icon, selecting **Upload groups**, and following the procedure on the **Import external data into Group** page.

    1.  Select **Add a group**.

    2.  On the form, fill in the fields as needed.

        For more information about the group form, see [Create a user group](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/t_CreateAGroup.md).

    3.  Select **Save**, or **Save &amp; add more** to repeat the process for additional groups.

7.  To assign one or more roles to a group, complete the following steps.

    1.  Select the check box next to the group or groups to assign a role to.

    2.  Select **Assign roles**.

    3.  Search for and select one or more roles as needed.

    4.  Select **Update**.

8.  After creating groups and assigning roles as needed, select **Mark as configured**.
