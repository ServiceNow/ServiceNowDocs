# Editing the Query Driver on the Metadata tab

The **Metadata** tab includes settings for several features related to metadata that enhance analysis and reporting in the Discovery Console for OT. The **Query Driver** section enables you to import or download query drivers as well as control the speed of Auto Queries.

## Before you begin

Role required: admin

## About this task

The **Query Driver** settings control your Sensors’ performance and resource usage. These settings manage how quickly Auto Queries are executed and how much load is placed on your network devices. They also regulate how many queries a Sensor can execute simultaneously. The **Delay** setting specifies the interval between consecutive queries. For example, setting the delay to 50% effectively halves the time between queries and operates the query at a faster pace.

## Procedure

1.  Navigate to the **Settings &gt; Metadata** tab.

2.  In the **Query Driver** section, you can import or download the Query Driver.

3.  To edit the Query Driver, select the **Edit Settings** button.

    The **Query Driver Settings** window opens.

4.  In the **Sensor Load** section of the window, use the sliding scale to change settings for the **Query Load** and the **Discovery Load**.

5.  In the **Delay** section of the window, use the sliding scale to change the **Query Delay** settings.

    \[Omitted image "settings-metadata-edit-query-driver.png"\] Alt text: Edit Query Driver

6.  Select the **Save Settings** button to save or **Cancel** to discard your changes.
