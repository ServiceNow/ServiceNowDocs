# ServiceNow Otto for Setup in Operational Technology

For Operational Technology \(OT\), ServiceNow Otto for Setup consolidates the setup processes for OT onto a single page, giving administrators a unified view of their configuration state.

## Admin use case for ServiceNow Otto for Setup

Configuring users, groups, and roles for your organization traditionally meant navigating between multiple pages to complete your administrative tasks. With ServiceNow Otto for Setup, administrators can create users, create user groups, and assign roles in a consolidated configuration console.

By opening the **Operational Technology** card on the Admin Home, administrators can access the Operational Technology Product Hub and Configuration Console to:

-   Install the necessary OT applications
-   Configure users, groups, and role assignments for OT

</table>## OT workflow

The OT workflow for ServiceNow Otto for Setup moves through organized configuration items to complete.

1.  Add OT users to your system, edit existing users, and assign multiple users to an OT group.
2.  Add an OT group to organize users and assign roles per group.
3.  Assign OT roles to a user or group.
4.  Assign OT admin roles to admin users that manage configuration and operational control.
