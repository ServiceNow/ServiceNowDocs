# Operational Technology Setup configuration items

The Configuration Console contains Operational Technology \(OT\) Setup configuration items, grouped by category, that administrators can complete.

Administrators can access and complete configuration items for user creation, group creation, and user and group role assignments. The following section describes the configuration items included in the Configuration Console under **Operational Data**.

**Note:** You can also use the ServiceNow Otto panel to help you complete configuration items.

## Operational Data

The Operational Data section contains configuration items that organize setup tasks by category.
