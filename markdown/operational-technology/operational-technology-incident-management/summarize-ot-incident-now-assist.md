# Summarize an Operational Technology incident by using ServiceNow Otto for Operational Technology \(OT\) Service Management

Understand the Operational Technology \(OT\) incident context and respond to user questions by using the OT incident summarization skill in the ServiceNow Otto for Operational Technology \(OT\) Service Management application.

## Before you begin

Role required: sn\_ot\_incident\_write

## About this task

An OT incident summary provides you with a concise summary of an incident. The summary is based on the OT incident state and is generated from the following information:

-   Short description
-   Description
-   Work notes
-   Additional comments
-   Priority
-   Site
-   Equipment model entity
-   OT device
-   OT incident task

## Procedure

1.  Navigate to **All** &gt; **Industrial Workspace**.

2.  Open the Industrial Workspace list view.

3.  On the OT Incidents module, select one of the available lists.

4.  Open the OT incident record to summarize.

5.  In the OT incident record, select the **Summarize** button.

6.  Manage the OT incident summary using the available options.
