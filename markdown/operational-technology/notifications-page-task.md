# Notifications page

The Notifications page shows the notifications available for your Discovery Sensor for Operational Technology \(OT\).

## About this task

You can add a filter to sort and find Notifications related to the following categories.

-   End Date
-   Rule
-   Rule Type
-   Severity
-   Status

## Before you begin

Role required: admin

## Procedure

1.  Navigate to the Notifications page.

2.  To filter the notifications, do the following.

    1.  Select the plus icon \[Omitted image "filter-plus-icon.png"\] Alt text:.

        The **Select Filter Type** field opens.

    2.  Select a filter from the drop-down menu.

    \[Omitted image "notifications-page-filter.png"\] Alt text: Notification filters


## Result

The Notifications are automatically sorted by the selected filter and displayed on the page.
