# Use Operational Technology Setup

Complete the configuration items for Operational Technology \(OT\) to help set up your OT environment.

-   **[Operational Technology Setup configuration items](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/ot-modules-in-sn-otto-setup.md)**  
The Configuration Console contains Operational Technology \(OT\) Setup configuration items, grouped by category, that administrators can complete.
-   **[Add OT users with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/add-users-sn-otto-setup-ot.md)**  
Add Operational Technology \(OT\) users to your system, edit existing users, and assign multiple users to a group.
-   **[Add an OT group with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/add-users-assignment-group-sn-otto-setup-ot.md)**  
Add an Operational Technology \(OT\) group so you can organize users and assign roles per group.
-   **[Assign OT roles to a user or group with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/assign-roles-sn-otto-setup-ot.md)**  
Assign Operational Technology \(OT\) roles to a user or group as needed so that group members can access the data required for their work.
-   **[Assign OT admin roles with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/assign-ot-admin-roles-sn-otto-setup-ot.md)**  
Create users and assign the necessary Operational Technology \(OT\) admin roles to users managing configuration and operational control.
