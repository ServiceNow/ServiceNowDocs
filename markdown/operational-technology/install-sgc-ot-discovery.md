# Install the Service Graph Connector for ServiceNow OT Discovery

Install the Service Graph Connector for ServiceNow OT Discovery from the ServiceNow Store.

## Before you begin

Role required: admin

## Procedure

1.  In the ServiceNow Store, select **Get** on the Service Graph Connector for OT Discovery store page to entitle the integration to one or more ServiceNow instances.

2.  Once entitled, log into your instance.

3.  Navigate to **System Applications** &gt; **All Available Applications** &gt; **All**.

4.  Locate the Service Graph Connector for ServiceNow OT Discovery and select **Install**.


## Result

After the installation is complete, you can refresh your browser and type `OT Discovery` in the filter navigator to see the OT Discovery modules under the Service Graph Connectors application menu.
