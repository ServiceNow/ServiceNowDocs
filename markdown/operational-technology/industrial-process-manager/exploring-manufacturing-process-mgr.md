# Explore Industrial Process Manager

Learn more about the common terminology, acronyms, and ISA-95 Equipment Model industry standard used in the Industrial Process Manager.

-   **[Industrial Process Manager common terminology](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/operational-technology/industrial-process-manager/common-manufacturing-process-manager-terminology.md)**  
Before getting started with the Industrial Process Manager, here are some common terminology and acronyms.
-   **[ISA-95 equipment model](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/operational-technology/industrial-process-manager/isa-95-equipment-model.md)**  
The ISA-95 equipment model is an industry standard for organizing industrial facilities and their production equipment. Use it to define hierarchical equipment structures with distinct levels and type options at each level.
-   **[Equipment model templates](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/operational-technology/industrial-process-manager/equipment-model-templates.md)**  
Create equipment model templates to characterize equipment models or organize data by grouping similar entities.
