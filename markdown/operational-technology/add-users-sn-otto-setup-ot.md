# Add OT users with ServiceNow Otto for Setup

Add Operational Technology \(OT\) users to your system, edit existing users, and assign multiple users to a group.

## Before you begin

Role required: admin

## Procedure

1.  Access the Admin Home by logging in to your instance or navigating to **All** &gt; **Admin Center** &gt; **Admin Home**.

2.  Locate and select the **Operational Technology** card.

3.  In the **Configure your product** section, select **Configure** to open the configuration console.

4.  In the **Operational Data** section, select **Users**.

5.  Edit an existing user's information by selecting the record in the list and updating the user record.

6.  To add a user, complete the following steps.

    1.  Select **Add a user**.

    2.  On the form, fill in the fields as needed.

        For more information about the user form, see [Create a user](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/t_CreateAUser.md).

    3.  Select **Save**, or **Save &amp; add more** to repeat the process and add additional users.

    Alternatively, you can upload a Microsoft Excel spreadsheet with user information by selecting the **Add a user - More actions** \[Omitted image "more-actions-arrow.png"\] Alt text: icon, selecting **Upload users**, and following the procedure on the **Import external data into User** page.

7.  To add users to a group, complete the following steps.

    1.  Select the check box next to the user or users to add to a group.

    2.  Select **Assign groups**.

    3.  Search for and select one or more groups as needed.

    4.  Select **Update**.

8.  After creating, editing, and adding users to groups as needed, select **Mark as configured**.
