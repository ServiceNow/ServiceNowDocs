# Use the Discovery Console for OT pages

Get started with the Discovery Console for OT application after it is installed and configured.

\[Omitted image "homepage1.png"\] Alt text: Console Home page

## Navigating the Console pages

The Discovery Console for OT is organized into multiple pages navigated by the side navigation panel. Each page displays specific tasks you can accomplish. Every page contains information and step-by-step procedures for using the Discovery Console for OT to query and inventory in your OT environment.

The next sections describe the Discovery Console for OT pages and how to use the Console's features.

-   **[Home page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/home-page.md)**  
The Home page on the Discovery Console for OT provides a dashboard overview of the assets and sites on your current system.
-   **[Assets page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/assets-page-console.md)**  
The Assets page shows a list of all available assets for the Discovery Console for OT.
-   **[Images page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/images-page-console.md)**  
The Images page contains the images related to your Discovery Console for OT assets.
-   **[Auto Query page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/auto-query-console.md)**  
The Auto Query page contains the automatic asset queries for the Discovery Console for OT.
-   **[Variables](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/variables.md)**  
The Variables page provides a list of currently available variable sets.
-   **[Results page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/results-page-console.md)**  
The Results page provides the results from your queries in the Discovery Console for OT.
-   **[Appliances page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/appliances-page.md)**  
The Appliances page displays active appliances in the Discovery Console for OT.
-   **[Sites page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/sites-page.md)**  
A Site represents a physical location in your organization, such as a DATACENTER, office, or IoT site. Each Site includes location details, time zone settings, and network range configurations that determine which IP addresses the Console for scans during discovery.
-   **[Updates page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/updates-page.md)**  
The Updates page shows available updates for your Sensor firmware.
-   **[Network Zones page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/network-zones-page.md)**  
The Network Zones page in the Appliances section includes a list of all Network Zones on the Console. Network zones group assets by IP address to help distinguish one or more assets that share an IP address but are in different local area networks.
-   **[Notifications page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/notifications-page-task.md)**  
The Notifications page shows the notifications available for your Discovery Sensor for Operational Technology \(OT\).
-   **[Notification Rules page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/notification-rules-page.md)**  
The Notification Rules page shows the notification rules that were setup for the Console. Notifications are displayed on the Notification page.
-   **[Certificates page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/certificates-page.md)**  
The Certificates page lets you access data regarding your CA certificates, Sensor credentials, and Collector credentials. You can also renew your certifications from this page.
-   **[Activity page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/activity-page.md)**  
The Activity page lists only the Appliance activity on your system.
-   **[Users page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/users-page.md)**  
The Users page shows the lists of both active and inactive users in your Discovery Console for OT system. You can access the Discovery Console for OT through user accounts available in the system.
-   **[Settings page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/settings-page-console.md)**  
The **Settings** page lets you view and modify system-wide settings for the Discovery Console for OT, Discovery Sensor for OT, and the OT Discovery Collector.
