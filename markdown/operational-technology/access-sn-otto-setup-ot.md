# Access ServiceNow Otto for Setup \(OT\)

Use the Admin Home to access the Operational Technology \(OT\) card, and start setting up your organization's OT environment.

## Before you begin

Role required: admin

## Procedure

1.  Access the Admin Home by logging in to your instance or navigating to **All** &gt; **Admin Center** &gt; **Admin Home**.

2.  Locate and select the **Operational Technology** card.

    \[Omitted image "admin-home-ot.png"\] Alt text: Operational Technology card available on the Admin Home page

3.  In the Operational Technology Product Hub under the **Apps and plugins** section, install the required OT applications.

4.  After the application installation is complete, select **Configure** in the **Configure your product** section to open the Configuration Console.

    \[Omitted image "ot-configure-sn-otto-setup.png"\] Alt text: Configure UI action for OT applications

5.  Complete the configuration items listed under **Operational Data**.

    For more information about the OT configuration items, see [Operational Technology Setup configuration items](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/operational-technology/ot-modules-in-sn-otto-setup.md).
