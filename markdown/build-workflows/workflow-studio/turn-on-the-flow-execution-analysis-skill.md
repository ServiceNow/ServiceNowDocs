# Turn on the Flow execution analysis skill

Turn on the flow execution analysis skill to summarize flow execution details and generate recommendations for flow in an error state.

## Before you begin

-   Install the ServiceNow Otto for Creator application. See [Install ServiceNow Otto for Creator](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/install-now-assist-for-creator.md).
-   Role required: flow\_designer or admin

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Skills**.

2.  In the workflow list, select **Creator**.

    \[Omitted image "na-creator-skill-cards.png"\] Alt text: List of cards displayed when selecting AI skills for Creator

3.  From the list of skills, select **Available**.

4.  In the Flow execution analysis card, select **Turn on**.

5.  In the Flow execution analysis card, verify that the skill is active.

    \[Omitted image "na-flow-execution-analysis-skill-active.png"\] Alt text: Flow execution analysis skill listed as active skill
