# Turn on AI skills for Playbooks

Turn on the ServiceNow Otto for Creator skills for using generative AI for creating and managing Playbooks.

## Before you begin

-   Install the ServiceNow Otto for Creator application. For more information, see .
-   Role required: admin

## About this task

You can use AI to generate a playbook, a summary of a playbook, or recommendations for placeholder activities. To enable these features, activate the corresponding AI skill in AI Admin Hub.

## Procedure

1.  Navigate to **Admin** &gt; **AI Admin Hub** &gt; **AI Skills**.

2.  In the workflow list, select **Creator**.

3.  In the search box, search for `Playbook` skills.

4.  On the skill tile, select **Turn on**.

    If a skill is already turned on, you see the option to deactivate the skill.

    \[Omitted image "ai-skills-playbook.png"\] Alt text: Activate or deactivate generative AI skills for Playbooks.


## Result

Generative AI skills for Playbooks are active on your instance.
