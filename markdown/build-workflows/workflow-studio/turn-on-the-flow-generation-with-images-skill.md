# Turn on the flow generation with images skill

Turn on the flow generation with images skill to use generative AI to create flows and subflows from an image.

## Before you begin

-   Install the ServiceNow Otto for Creator application
-   Role required: admin

## About this task

**Important:** This skill requires a separate subscription to ServiceNow Otto for Creator.

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Features**.

2.  In the workflow list, select **Creator**.

3.  In the Flow card, select **View details**.

4.  Select **All available Flow skills** &gt; **Flow Generation with Images** &gt; **Turn on**.

5.  In the Flow card, verify that the **Flow Generation with Images** skill is activated under **Active skills**.

    \[Omitted image "flowgen-image-skill.jpg"\] Alt text: Confirmation page with all skills active.


## What to do next

Grant the now.assist.creator and flow\_designer roles to each user who will use the flow generation with images skill.
