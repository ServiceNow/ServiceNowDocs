# Open a full list in a playbook

Open a full list from a playbook card to view and update all of its list items.

## Before you begin

Role required: agent

## About this task

A playbook card shows a limited set of list items. Opening the full list gives you every item in a separate tab, where you can review and update them.

## Procedure

1.  Open a playbook in workspace.

2.  On the playbook card, select **Open List**.

    \[Omitted image "playbook-open-list-card.png"\] Alt text: Playbook card displaying the Open List button.


## Result

The full list opens in a new tab.
