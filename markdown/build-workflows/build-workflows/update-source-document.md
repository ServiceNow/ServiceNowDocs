# Update source document

Update an existing intelligent approval by uploading a new source document. Regenerate the intelligent approval using the uploaded source document.

## Before you begin

Role required: sn\_iap.policy\_manager or sn\_iap.policy\_admin

## Procedure

1.  Navigate to **All** &gt; **Intelligent Approvals** &gt; **Intelligent Approvals Home**.

2.  Select the intelligent approval to update.

    \[Omitted image "intelligent-approval-update-01.png"\] Alt text: Intelligent approvals homepage with sample policies and executions

3.  From the three-dot menu, select **Upload new source document**.

    \[Omitted image "intelligent-approval-update-02.png"\] Alt text: Upload new source document option

4.  From the Warning dialog box, select **Proceed**.

    \[Omitted image "intelligent-approval-update-03.png"\] Alt text:

5.  From the Create intelligent approval dialog, select **Click to upload or drag and drop** to find your updated policy document.

6.  Verify the policy document name, and select **Create intelligent approval**.

    \[Omitted image "intelligent-approval-update-04.png"\] Alt text:

7.  From the Create intelligent approval dialog, verify the document name, and then select **Create intelligent approval**.


## Result

The system regenerates the intelligent approval using the policy document that you uploaded.

\[Omitted image "intelligent-approval-update-05.png"\] Alt text: Sample updated intelligent approval

## What to do next

Review the intelligent approval overview and suggested improvements.
