# Publish an intelligent approval

Set an intelligent approval to active and use it to make approval decisions.

## Before you begin

Role required: sn\_iap.policy\_manager or sn\_iap.policy\_admin

## Procedure

1.  Navigate to **All** &gt; **Intelligent Approvals** &gt; **Intelligent Approvals Home**.

2.  Select the draft or inactive intelligent approval you want to publish.

    \[Omitted image "intelligent-approval-publish-01.png"\] Alt text: Overview tab of draft intelligent approval

3.  Select **Publish**.

    \[Omitted image "intelligent-approval-publish-02.png"\] Alt text: Successfully Published banner message


## Result

The system sets the intelligent approval to active and uses it to make automated approval decisions when the approval matches the intelligent approval's start conditions.
