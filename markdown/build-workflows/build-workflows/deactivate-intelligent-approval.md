# Deactivate intelligent approval

Stop using an intelligent approval to make approval decisions and set its state to inactive.

## Before you begin

Role required: sn\_iap.policy\_manager or sn\_iap.policy\_admin

## Procedure

1.  Navigate to **All** &gt; **Intelligent Approvals** &gt; **Intelligent Approvals Home**.

2.  Select the intelligent approval to update.

    \[Omitted image "intelligent-approval-update-01.png"\] Alt text: Intelligent approvals homepage with sample policies and executions

3.  From the three-dot menu, select **Deactivate**.

    \[Omitted image "intelligent-approval-deactivate-01.png"\] Alt text: Three dot menu showing the Deactivate option

    \[Omitted image "intelligent-approval-deactivate-02.png"\] Alt text: Successfully Deactivated banner message


## Result

The system sets the intelligent approval to inactive and no longer uses it to make approval decisions. Any existing approval decisions remain unchanged.
