# Create a file

Add a file to a folder in your project directly from the Project Explorer tree. The file appears in the folder you choose, ready to open in the Code Editor.

## Before you begin

Role required: admin

## Procedure

1.  Hover over the folder in the tree where you want the file, to reveal the action icons.

2.  Select the **New File** icon.

    Alternatively, right-click the folder and select **New File**.

3.  Enter the file name.

4.  Press Enter to confirm.
