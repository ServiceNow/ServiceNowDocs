# Plans in Autonomous Engineer

Access all Autonomous Engineer plans from the **Plans** view in the Build Agent panel. The **Plans** view shows the plans you created and all plans available on the instance.

## Access the Plans view

To open the **Plans** view, select the Conversations icon \[Omitted image "ba-sns-otto-nav-icon.png"\] Alt text: in the Navigator panel, and then select the Plans icon in the Build Agent panel that appears.

\[Omitted image "ae-plans-panel.png"\] Alt text: Plans panel with the Plans view highlighted in the navigation.

The **Plans** view lists all Autonomous Engineer plans in the current application scope, and has two tabs.

-   **Created by me**

    Plans that you created in the current application scope.

-   **All plans**

    All plans available in the current application scope, including plans created by other users.


## Start a plan

To create a plan, select **Create a new plan** from the **Plans** view. This opens a new conversation in the chat panel where you can provide your requirements. To create and manage plans using Autonomous Engineer, see [Use Autonomous Engineer to implement an application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/use-autonomous-engineer.md).

## Manage plans

From the **Plans** view, you can take the following actions on an existing plan:

-   **Open a plan**

    Select a plan from the list to open the plan dashboard and review work item status, artifacts, and execution progress.


## Application scope and plans

Plans are scoped to the application scope active when the plan was created. The current scope is shown in the breadcrumb at the top of the **Plans** view. To view plans from a different scope, change the application scope in the Build Agent panel before opening the **Plans** view.
