# Guided tours in ERP Customization Mining

Learn about ERP Customization Mining guided tours, including how to access and take them to build your knowledge of ERP Customization Mining.

## What guided tours are

Guided tours are part of the default ServiceNow platform. There are guided tours available to take and you can use the Guided Tours application to create custom tours yourself in your own instances.

Tours contain interactive steps to help train and teach users. Some tours show various features in the user interface, such as an overview of a home page. Other tours help complete a task, such as configuring a connection or working with candidate details. For more information about what guided tours are and how to create them, see [Exploring Guided Tours](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/platform-user-interface/exploring-guided-tours.md).

## How to access and use ERP Customization Mining guided tours

To start a tour, select the **Show help** icon \[Omitted image "Banner\_HelpIcon.png"\] and then select **Take a Tour**.

\[Omitted image "erpcm-guided-tour-start.png"\] Alt text: ERP Customization Mining home page dashboard with show help option and take a tour button highlighted.

You're led through a series of steps. Read the text for each step and perform the required action or select **Next** to continue the tour.

\[Omitted image "erpcm-guided-tour-first-callout.png"\] Alt text: ERP Customization Mining home page dashboard with first step of guided tour displayed.

To stop a tour at any time, select the **X** on any tour step.

For more information, select the **View detailed documentation** link on any tour step.

\[Omitted image "erpcm-guided-tour-docs-link.png"\] Alt text: ERP Customization home page dashboard with guided tour step displayed and view documentation link highlighted.

At the end of the guided tour, select **Complete**.
