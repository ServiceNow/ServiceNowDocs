# Duplicate a schedule in Arc

Copy an existing schedule as a starting point for a new one, so you don't enter the same details again.

## Before you begin

You have at least one schedule. For more information, see [Create and manage scheduled tasks in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/create-scheduled-tasks.md).

Role required: sn\_app\_arc.user

## About this task

The original schedule stays as it is. The copy is a separate schedule that you can change before you save it.

## Procedure

1.  In Arc, select **Schedules** in the sidebar.

    Each schedule appears as a card that shows its name, instruction, how often it runs, and its next and last run.

2.  On the schedule's card, select the duplicate icon.

3.  Change the **Name**, **Message**, or the settings under **What time?** as needed.

4.  Select **Schedule it**.


## Result

The new schedule appears as its own card in the **Schedules** list.
