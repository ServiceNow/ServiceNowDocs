# Open a project folder

Open an existing project folder from disk so that its files load into the Project Explorer. Opening a folder makes that project the one you browse, edit, and run in Lux Lab.

## Before you begin

Role required: admin

## Procedure

1.  Select the project name in the title bar.

2.  Select **Open Folder…**.

3.  Navigate to and select your project root directory.


## Result

The folder loads into the Project Explorer.
