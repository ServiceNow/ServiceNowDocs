# Requesting workstation user data

Requesting workstation user data enables you to collect and store data for future analysis.

The process to request workstation user data is as follows:

1.  A Task Mining analyst submits a data request in the Employee Center. For more information, see [Submit a data request](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/request-workstation-user-logs.md).

    **Note:**

    Create a data request for manager's approval with the new dates to extend the dates you want to collect data past the dates in an approved data request.

2.  A workstation user's manager approves data requests from Task Mining analysts to enable workstation user data collection.

    For more information, see [Approve workspace user data collection](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/approve-workspace-user-log-requests.md).

3.  A Task Mining power user monitors data requests to confirm approvals are completed before Task Mining projects begin.

    For more information, see [Follow data request progress](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/manage-data-log-requests.md).


-   **[Submit a data request](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/request-workstation-user-logs.md)**  
Enable data collection for workstation users for a specific time range by completing a data request from the Employee Center.
-   **[Approve workspace user data collection](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/approve-workspace-user-log-requests.md)**  
Approve data requests from Task Mining analysts to enable workstation user data collection.
-   **[Follow data request progress](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/manage-data-log-requests.md)**  
Monitor data requests to confirm approvals are completed before Task Mining projects begin.
