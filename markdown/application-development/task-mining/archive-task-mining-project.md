# Archive or reopen a Task Mining project

Prepare to delete an unused project according to your data retention policy.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **Workspaces** &gt; **Task Mining Workspace**.

2.  Navigate to the project you want to archive.

3.  Select the More actions icon \[Omitted image "more-actions-menu-icon.png"\] Alt text: More Actions icon.

    \[Omitted image "tm-archive.png"\] Alt text: The More actions menu and the Archive option highlighted.

4.  Select **Archive** and confirm.

    \[Omitted image "tm-archive-confirm.png"\] Alt text: The Archive confirmation panel.

    Your project is scheduled to close after the end of your Project retention period. For more information, see [Modify the Task Mining data retention period](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/define-data-retention.md).

5.  Navigate to the project you archived that you want to reopen.

6.  Select the More actions icon \[Omitted image "more-actions-menu-icon.png"\] Alt text: More Actions icon.

    \[Omitted image "tm-reopen.png"\] Alt text: The More actions menu and the Reopen option highlighted.

7.  Select **Reopen** and confirm.

    \[Omitted image "tm-reopen-confirm.png"\] Alt text: The Reopen confirmation panel.
