# Split the editor

Split the Code Editor into editor groups to work with multiple files side by side. Each group keeps its own tabs, so you can compare or edit related files without switching back and forth.

## Before you begin

Role required: admin

## Procedure

1.  Select and hold \(or right-click\) any tab.

2.  Select **Split Editor Right** or **Split Editor Down**.

    Alternatively, press Cmd+\\ \(macOS\) or Ctrl+\\ \(Windows/Linux\).

3.  Open the file you want in the new group.


## Result

The new editor group appears beside or below the original. Each group maintains its own tab list and scroll position, and there's no limit on the number of splits.
