# Using ServiceNow Arc

Use ServiceNow Arc to get started with tasks, connect systems, and extend what Arc can do.

-   **[Start a ServiceNow Arc chat session](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/get-started-with-cowork.md)**  
Send your first request to ServiceNow Arc, from a simple question to a complex multi-step task, and track its progress.
-   **[Select AI model and workspace folders](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/select-model-folders.md)**  
Select the AI model the agent uses, confirm its connection, and set the folders it works in. These settings control the quality of the agent's responses and limits file access to the selected folders.
-   **[Respond to approval requests in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/respond-approval-requests.md)**  
Before Arc takes a sensitive action, such as changing a record or deleting a file, it pauses and asks for your permission. Responding to these requests keeps you in control of what the agent does on your behalf.
-   **[Use auto mode in an Arc chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/use-auto-mode-chat.md)**  
Switch a chat to auto mode so a safety check approves lower risk actions for you, and set the mode that new chats start in.
-   **[Assign tasks to ServiceNow Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/assign-tasks-cowork.md)**  
Use ServiceNow Arc to complete multi-step work, such as investigating incidents, creating reports, or coordinating updates across platforms. Combine skills, sub-agents, and connectors in a single request so Arc can complete the whole piece of work from start to finish.
-   **[Preview files in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/preview-files-arc.md)**  
View Word, Excel, PowerPoint, PDF, and PNG files in Arc without opening another app, and download them or open them in their native app.
-   **[App development in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/app-development-arc.md)**  
Arc builds ServiceNow apps for you with the Now SDK, from planning the app to installing it on your instance, through a conversation in a chat.
-   **[Create and manage scheduled tasks in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/create-scheduled-tasks.md)**  
Schedule Arc to run an instruction once or on a repeating schedule, and run, edit, copy, pause, or delete any schedule from one list.
-   **[Track tasks in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/track-respond-tasks.md)**  
Check and track the progress of the tasks you have delegated and respond when Arc needs your input. Tracking tasks lets you keep working while Arc completes them, and responding quickly keeps paused tasks from stalling.
-   **[Notifications in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/notifications-arc.md)**  
Arc lets you know when an action is waiting for your approval or response, or when a schedule is due, even when you're working in another chat or another app.
-   **[Connectors in ServiceNow Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/connectors-in-cowork.md)**  
Connectors link ServiceNow Arc to the platforms you work in, so Arc can read and update your real data, not only answer questions.
-   **[Extend ServiceNow Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/extending-cowork.md)**  
Extend Arc with skills, scheduled tasks, Model Context Protocol \(MCP\) servers, and sub-agents so the agent can handle more of your work. Each option adds new instructions, tools, or specialized agents, and you control what the agent can access.
-   **[Review and revoke standing approvals](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/review-revoke-approvals.md)**  
Review the actions you have allowed Arc to take without asking, and revoke any you no longer require.
-   **[Set up TOTP authorization for sensitive actions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/setup-totp-security.md)**  
Set up TOTP authorization to add another layer of security check before performing any sensitive action, such as changing records, deleting files, or sending messages on your behalf.
-   **[Set agent limits and safeguards](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/set-agent-limits-safeguards.md)**  
Set limits on how long the agent runs and when it checks in with you, so it doesn't use more time or resources than a task needs and you stay in control of long runs.
-   **[Update ServiceNow Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/update-cowork.md)**  
ServiceNow Arc checks for updates automatically and verifies each update before it installs. You can also check for updates yourself at any time.
