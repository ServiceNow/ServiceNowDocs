# ServiceNow SDK

The `now-sdk` command-line interface manages changes between a local application and its version on an instance. ServiceNow Fluent defines that application's metadata as TypeScript source code.

For the most up-to-date reference information, see the [ServiceNow SDK reference](https://servicenow.github.io/sdk/).
