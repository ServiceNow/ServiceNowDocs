## Task Mining

Collect workstation activity through a Task Mining desktop agent to reveal how work actually gets done. Organizations can use this analysis to spot repetitive, manual, or inefficient activity and target it for improvement or automation.

As a companion to Process Mining, Task Mining adds the view of individual desktop work that process logs don’t capture.

For more information, see [Task Mining](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/task-mining/task-mining.md).
