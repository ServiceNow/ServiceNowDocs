# Configure Autonomous Engineer

Configure Autonomous Engineer by installing it from the ServiceNow Store and enabling the features required for planning and parallel execution on your instance.

Autonomous Engineer is a separate application available in the ServiceNow Store. Installing Autonomous Engineer also installs Build Agent as a dependency. Configuring Autonomous Engineer involves installing the application, confirming the required roles and permissions, and optionally installing agent packs to extend Autonomous Engineer with product-specific domain knowledge.

## Prerequisites

Before configuring Autonomous Engineer, verify the following:

-   Autonomous Engineer is installed on your instance. For installation instructions, see [Install Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/install-autonomous-engineer.md).
-   You have the admin role.

## Installation

For installation steps, see [Install Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/install-autonomous-engineer.md).

## Agent packs

Autonomous Engineer uses agent packs with product-specific domain knowledge to run implementations. For more information, see [Agent packs for Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown).
