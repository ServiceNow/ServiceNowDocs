# Configure web search

Enable the web search tool so that Build Agent can search the public web and retrieve relevant information when responding to queries.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **App Development** &gt; **ServiceNow Studio** or **All** &gt; **App Development** &gt; **ServiceNow IDE**.

2.  Select the Settings icon \[Omitted image "ba-settings-icon.png"\] Alt text: in the Build Agent chat panel.

    \[Omitted image "ba-settings-panel-1.png"\] Alt text: Build Agent panel showing the greeting message and Settings button

3.  In the **General** tab, turn on **Enable web search**.
