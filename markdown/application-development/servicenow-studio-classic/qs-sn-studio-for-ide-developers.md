# ServiceNow Studio for ServiceNow IDE developers

Use ServiceNow IDE capabilities within ServiceNow Studio to build apps in source code. All IDE features have been consolidated in the Explorer tab in ServiceNow Studio.

To create apps in ServiceNow Studio, you use ServiceNow Fluent, a domain-specific programming language, to define the metadata that makes up applications. ServiceNow Fluent includes APIs for defining the different types of metadata. For more information, see [ServiceNow Fluent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-fluent.md).

## Workspaces

The concept of workspaces is a bit different in ServiceNow Studio than in ServiceNow IDE. In the ServiceNow IDE, you can add any applications that you're working on to a workspace to navigate through them all from one place. You can create multiple workspaces to group different sets of applications. Workspaces are specific to a user, and applications can be added or removed from a workspace at any time.

In ServiceNow Studio, the **Explorer** tab acts as a single, persistent workspace, where you can add any application that has been converted to Fluent. For that reason, workspaces don't need to be created in ServiceNow Studio to create or group applications.

## Fluent source control

ServiceNow Fluent source control is available in ServiceNow Studio to track work done on apps built in source code and converted to Fluent.

**Important:** Only admins can work on Fluent apps. Don't convert the app if you want delegated developers to continue working on the application.

For more information, see [Building apps in source code in ServiceNow Studio](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-studio-classic/building-apps-in-source-code-sn-studio.md) and [Fluent source control in ServiceNow Studio](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-studio-classic/fluent-source-control-sn-studio.md).
