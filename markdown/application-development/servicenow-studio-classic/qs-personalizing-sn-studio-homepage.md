# Personalizing the ServiceNow Studio homepage

Personalize your instance of ServiceNow Studio to match your preferences for development style and theme.

## How do you reorder the activity bar?

Drag tabs up or down to reorder them. For example, to place the **Recent** tab at the top, drag it to a new location.

\[Omitted image "sn-studio-drag-tab.png"\] Alt text: Drag a tab from its default location.

## How do you change Build Agent and theme preferences?

On the General tab, Build Agent is active by default. Turn it off to continue using ServiceNow Otto for app generation.

\[Omitted image "sn-studio-use-ba.png"\] Alt text: Select whether you want to use Build Agent or not.

On the Appearance tab, select Dark mode or Light mode for development.\[Omitted image "sn-studio-preferences-bs1.png"\] Alt text: Choose if you want to develop in Light mode or Dark mode.

## How do you choose a development mode?

Choose a development mode to control which tabs appear in the Activity bar. In the bottom left corner of the screen, select **Preferences**, and then select **Customize activity bar**.

For minimal tabs, choose **Vibe \(Minimal features\)**, which includes the Apps and Changes tabs. Select **Pro \(Full features\)** to access all tabs in ServiceNow Studio, or toggle the switch on any feature for a **Custom** view.

\[Omitted image "sn-studio-customize-activity-bar.png"\] Alt text: Choose which features you want to see in the Activity bar.
