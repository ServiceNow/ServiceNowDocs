# Personalizing the ServiceNow Studio homepage

Personalize your instance of ServiceNow Studio to match your preferences for development style and theme.

## Activity bar

Drag tabs up and down to reorder them to your preference. For example, if you want the **Recent** tab at the top for easy access, drag it to a new location.

\[Omitted image "sn-studio-drag-tab.png"\] Alt text: Drag a tab from its default location.

## Build Agent and theme preferences

On the General tab, using Build Agent is active by default, but you can turn it off to continue using ServiceNow Otto for app generation.

\[Omitted image "sn-studio-use-ba.png"\] Alt text: Select whether you want to use Build Agent or not.

On the Appearance tab, select whether you want to develop in Dark mode or Light mode.\[Omitted image "sn-studio-preferences-bs1.png"\] Alt text: Choose if you want to develop in Light mode or Dark mode.

## Development mode

Select the tabs you want to see in the Activity bar by choosing a development mode. Access your preferences in the bottom left corner of the screen, select **Preferences**, and select **Customize activity bar**.

If you want minimal tabs showing to keep things simple, choose **Vibe \(Minimal features\)**, which includes the Apps and Changes tabs. Select **Pro \(Full features\)** to access all tabs in ServiceNow Studio, or toggle the switch on any feature for a **Custom** view.

\[Omitted image "sn-studio-customize-activity-bar.png"\] Alt text: Choose which features you want to see in the Activity bar.
