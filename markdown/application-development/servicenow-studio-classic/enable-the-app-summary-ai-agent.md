# Enable the App Summary AI agent

Enable the App Summary AI agent to generate application summaries in ServiceNow Studio.

## Before you begin

The App Summary plugin must be installed.

Role required: admin

## About this task

After the App Summary plugin is installed, the App Summary AI agent is disabled by default. This default helps avoid unexpected charges, since using the agent is associated with a charge. Enable the agent to make app summary available to end users.

## Procedure

1.  Navigate to AI Agent Studio.

2.  Select the **AI Agents** tab.

3.  Select **App Summary AI Agent**.

4.  Select the **Select channels and status** tab.

5.  In the **Activation status** section, enable the **Active** toggle.

6.  Select **Save and test**.


## What to do next

Open an application in ServiceNow Studio to generate an app summary.
