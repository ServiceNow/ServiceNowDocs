# Bookmark apps, files, and lists in ServiceNow Studio

Bookmark apps, metadata files, and lists in ServiceNow Studio so you can access them quickly from the Bookmarks section of the Collections tab in the Navigator panel.

## Before you begin

Role required: admin or delegated\_developer

## About this task

**Note:** Bookmarks and favorites are distinct ServiceNow capabilities. Bookmarks exist only within ServiceNow Studio, while favorites are accessible throughout your instance. Bookmarks do not automatically become favorites, and favorites do not automatically become bookmarks.

## Procedure

1.  Navigate to **All** &gt; **App Engine** &gt; **ServiceNow Studio**.

2.  Select the Add to collections icon \[Omitted image "sn-studio-bookmark-icon.png"\] Alt text: from one of the following locations.

    -   To bookmark an open app, select the Add to collections icon next to the app name.

        \[Omitted image "sn-studio-bookmark-app-bs1.png"\] Alt text: Bookmark an app that's open in the canvas.

    -   To bookmark an app or file in the Navigator panel, hover over it and select the Add to collections icon.

        \[Omitted image "sn-studio-add-to-collection.png"\] Alt text: Hover over the file you want to bookmark, and select Add to collections.

    -   To bookmark a list, select **Bookmark list** or select the more options icon \[Omitted image "sn-studio-more-options-icon.png"\] Alt text:, then select **Add list to collections**. For example, open the list of all decision tables from the Automation file category and bookmark the list.

        \[Omitted image "sn-studio-bookmark-lists.png"\] Alt text: Bookmark a list by adding it to the Bookmark collection.

3.  Select the **Bookmarks** collection.

    \[Omitted image "sn-studio-bookmark-list-dec-tables.png"\] Alt text: Add the list to the Bookmarks collection.

4.  Add the app, list, or file to another collection for easy access.

5.  Select **Save**.

6.  Refresh the Navigator panel to view your new bookmark in the **Bookmarks** collection.

7.  To rename the bookmark, select the rename bookmark icon, enter a new name, and select **Save**.
