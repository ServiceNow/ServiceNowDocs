# Create a collection of files in ServiceNow Studio

Create a collection in ServiceNow Studio to group multiple files and apps in one folder for personal organization.

## Before you begin

Role required: admin or delegated\_developer

## About this task

Collections extend bookmark functionality in ServiceNow Studio by grouping multiple files and apps in the same folder. Bookmarks remain available as a subcategory within the collections tab in the Navigator panel.

## Procedure

1.  Navigate to **All** &gt; **App Engine** &gt; **ServiceNow Studio**.

2.  In the File Navigator, hover over a file and select the add to collections icon \[Omitted image "sn-studio-collections-icon.png"\] Alt text:.

    \[Omitted image "sn-studio-add-to-collection.png"\] Alt text: Add a file to a collection.

3.  Select **New Collection**.

4.  Enter a name for the collection, and select **Save**.

5.  Add files and applications of any scope to the collection.

6.  Select **Save**.


## Result

The new collection appears in the Navigator panel and is available for use. For more information, see [Add files to a collection in ServiceNow Studio](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/servicenow-studio-classic/qs-add-files-to-a-collection.md).
