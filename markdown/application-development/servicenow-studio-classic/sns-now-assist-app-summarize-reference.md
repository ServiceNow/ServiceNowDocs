# ServiceNow Otto for app summary generation reference

The following roles are required for use with the ServiceNow Otto for Creator app summary generation skill.

## Roles

Grant the admin and now.assist.creator roles, or the sn\_g\_app\_creator.app\_creator and now.assist.creator roles, to each user that you want to summarize apps.
