# Getting started with Build Agent in ServiceNow Studio

Begin developing on the ServiceNow AI Platform quickly with Build Agent, which enables developers to build, manage, and deploy custom, base system, or global applications and global metadata records.

Build Agent is integrated directly into ServiceNow Studio, giving developers access to AI-assisted development without leaving their authoring environment. Open Build Agent from the ServiceNow Studio interface to perform any development task. For example, use Build Agent when writing scripts, generating code, and working through implementation tasks as you build applications and features.

To get started, open ServiceNow Studio and enter a prompt into the main Build Agent chat panel. Build Agent generates code, explains platform concepts, and helps you troubleshoot issues in the context of your current work. You can accept, modify, or discard suggestions as you go. For more information, see [Exploring Build Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/exploring-build-agent.md).

**Note:** This topic provides a short overview of Build Agent. For more information and full documentation, see [Exploring Build Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/exploring-build-agent.md).

## How do I access Build Agent?

Access Build Agent from several places.

-   The home page of ServiceNow Studio contains the main chat panel for Build Agent.
-   The ServiceNow Otto icon \[Omitted image "sn-studio-conversations-icon.png"\] Alt text: in the activity bar opens the list of all current and past conversations with Build Agent.

## What can I do in Build Agent?

Build Agent is an AI tool designed for developers within ServiceNow Studio and the ServiceNow IDE. Build Agent acts as an autonomous AI agent capable of independently generating a custom, base system, or global application and global metadata records. For example, a global scope app that uses tables such as incident, problem, and change.

Key Build Agent benefits include:

-   Built-in governance to develop securely
-   Faster enhancement of existing applications, such as adding new features
-   Reduced development backlogs and streamlined deployment of new applications
-   Better documentation of existing applications through automated documentation
-   Increased developer productivity across skill levels
-   Reduction in overall development cost
-   Automated testing with Automated Test Framework \(ATF\) test suite generation and execution

Key capabilities of Build Agent include:

-   Creating and updating applications in source code or metadata records.
-   Conversational interface.
-   Support for file uploads.
-   Code-related tasks such as rewriting tables, explaining code, validating and enhancing existing applications, and fixing application errors.
