# ServiceNow Studio settings

Personalize your settings and preferences in ServiceNow Studio to get the most out of your application development experience.

The User profile menu in ServiceNow Studio provides access to the Command palette, a list of keyboard shortcuts, preferences for theme and development style, and to elevate your role. Select the **Settings** icon \[Omitted image "sn-studio-settings-icon.png"\] Alt text: in the activity bar to open this menu.

For more information about updating your preferences, see [Personalizing the ServiceNow Studio homepage](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-studio-classic/qs-personalizing-sn-studio-homepage.md).

\[Omitted image "sn-studio-settings-menu.png"\] Alt text: Access the settings menu from the activity bar.

## Command palette

Open the command palette from the Settings menu or by using the following keyboard shortcuts:

-   Windows: Ctrl-Shift-P
-   Mac: Cmd-Shift-P

Start typing the command you want, or scroll to find and select it. Select **Add** to create a keyboard shortcut.\[Omitted image "sn-studio-command-palette.png"\] Alt text: Open the command palette and select a command.

## Keyboard shortcuts

Keyboard shortcuts enable you to work more quickly and efficiently in ServiceNow Studio. Select **Keyboard Shortcuts** on the Settings menu to open the list.

Search or scroll through the list to see available shortcuts. Update existing shortcuts with new key commands by using the change keybinding icon \[Omitted image "sn-studio-change-keybinding-icon.png"\] Alt text:. Record new keyboard shortcuts by using the record keys icon \[Omitted image "sn-studio-record-keys-icon.png"\] Alt text:.

\[Omitted image "sn-studio-keyboard-shortcuts.png"\] Alt text: The list of keyboard shortcuts opens in a new tab, where you can edit shortcuts or record keys for a new shortcut.

## Elevate your role

Elevate your role to security\_admin to configure roles and access control lists \(ACLs\). For more information, see [Elevate your role in ServiceNow Studio](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-studio-classic/elevate-your-role-in-servicenow-studio.md).
