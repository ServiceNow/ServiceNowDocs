# Build a ServiceNow app with Arc

Describe the app you need, approve the plan, and let Arc build the app, save its source to your computer, and install it on your instance.

## Before you begin

Arc is connected to your ServiceNow instance.

Role required: sn\_app\_arc.user

## About this task

**Note:** App development isn't supported on Windows.

## Procedure

1.  In a chat, describe the app you want to build.

    For example: Build an app to track equipment loans, with a table for loans, a catalog item to request equipment, and a notification when a loan is overdue.

2.  Review the build plan that Arc shows, and approve it or ask for changes.

3.  When Arc asks, name the folder on your computer where it should save the app's source.

    If you don't name a folder, Arc saves the source to a default location and tells you where.

4.  Wait while Arc creates the project and builds the app.

    Arc saves the source as a .tar.gz archive in the folder you named and reports its location.

5.  When Arc asks to install the app on your instance, approve the request.
