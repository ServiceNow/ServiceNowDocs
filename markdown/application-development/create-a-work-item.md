# Create a work item

Have an agent plan a task in plan mode, and then save that plan as a work item in your project. You agree on an explicit plan before the agent makes any code changes.

## Before you begin

Role required: admin

The Agent Chat Harness panel is open. For ways to open it, see [Agent chat harness](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/agent-chat-harness.md).

## Procedure

1.  Switch the chat panel to plan mode by toggling the plan mode option in the input toolbar.

2.  Enter a description of what you want to build or fix.

3.  Press Enter.

    The agent processes the task and produces a structured plan of action.

4.  When Lux Lab prompts you to create a work item from the plan, select **Create Work Item**.

5.  To have the agent begin executing the plan, select **Start Implementation** on the new work item.


## Result

Lux Lab saves the plan as a work item file in your project.
