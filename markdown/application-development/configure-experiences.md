# Configure experiences

Configure experiences by setting the properties that drive each instance and using the inline and admin editing surfaces to manage those values. You can arrange widgets into layout regions and apply themes to control appearance without touching code.

Topics in this section cover the configuration model, the configurable property types, the inline configuration modes, and the in-page editor that administrators use. Topics also cover how to edit and save page layouts, and how to apply themes to an app—from brand configuration to individual design tokens.
