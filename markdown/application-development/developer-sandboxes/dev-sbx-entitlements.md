# Developer Sandboxes entitlements

Your company's entitlements determine whether you have access to Developer Sandboxes.

A free pack of four sandboxes is automatically available to all organizations. The free pack can be assigned to one non-production instance and can't be split across instances. You can use the four free sandboxes on the same instance as purchased sandboxes, for a maximum of 34 sandboxes on an instance.

In addition to the free sandboxes, Developer Sandboxes entitlements include the following parameters:

-   Developer Sandboxes is a standalone product and isn't included with any other product.
-   Developer Sandboxes are packaged in increments of ten. One license is 10 sandboxes.
-   Developer Sandboxes packs are purchased at the organization level. After purchase, a sandbox license admin can distribute packs across non-production instances using the self-serve license assignment UI in App Engine Management Center \(AEMC\). Each instance must receive at least one full pack. For more information, see [License assignment](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/developer-sandboxes/dsb-license-allocation-about.md).
-   Entitlements can be stacked, supporting up to 30 sandboxes per instance. For more information on suggested number of entitlements per instance, see [General guidelines and use cases for Developer Sandboxes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/developer-sandboxes/dev-sbx-general-guidelines.md).

For details on how to check your entitlements, see [Viewing instance-level entitlements in Subscription Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/viewing-instance-level-entitlements.md).
