# Developer Sandboxes entitlements

Your company's entitlements determine whether you have access to Developer Sandboxes.

In addition to the free sandboxes, Developer Sandboxes entitlements include the following parameters:

-   Developer Sandboxes is a standalone product and isn't included with any other product.
-   Developer Sandboxes are packaged in increments of ten. One license is 10 sandboxes.
-   Entitlements can be stacked, supporting up to 30 sandboxes per instance. For more information on suggested number of entitlements per instance, see [General guidelines and use cases for Developer Sandboxes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/developer-sandboxes/dev-sbx-general-guidelines.md).

For details on how to check your entitlements, see [Viewing instance-level entitlements in Subscription Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/viewing-instance-level-entitlements.md).
