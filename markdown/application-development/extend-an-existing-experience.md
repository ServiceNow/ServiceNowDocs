# Extend an existing experience

Create an extension project in Lux Lab to add pages and widgets to an experience that already exists on the ServiceNow AI Platform. Lux Lab scaffolds the project from its Extension template.

## Before you begin

-   Role required: admin
-   Your machine meets the minimum system requirements in [Configuring Lux Lab](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/configuring-lux-lab.md).
-   Lux Lab is connected to an instance. For instructions, see [Connect Lux Lab to an instance](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/connecting-lux-lab-to-an-instance.md).

## Procedure

1.  Select the project name in the title bar.

2.  Select **New Project**.

3.  In the **Create New Project** dialog, on the **Create New** tab, select the **Extension template**.

4.  Enter a **Project Name**.

5.  Select a **Project Location** on your local drive.

6.  Confirm or edit the **Scope**.

7.  Select **Create Project**.


## Result

Lux Lab scaffolds your extension project and opens it in the app automatically.
