# Autonomous Engineer

Autonomous Engineer is an agentic worker that augments product development capacity across the software development lifecycle \(SDLC\). It accepts requirements, generates a plan with structured work items, and builds all work items in parallel using background agents.

Autonomous Engineer reduces time to value by taking your specifications as input and driving the full implementation lifecycle end-to-end. It helps to ensure quality by applying ServiceNow AI Platform best practices during planning and implementation, and automatically generating and running Automated Test Framework \(ATF\) tests for each work item.

Autonomous Engineer is available in ServiceNow Studio and supports custom applications as well as agent pack implementations.
