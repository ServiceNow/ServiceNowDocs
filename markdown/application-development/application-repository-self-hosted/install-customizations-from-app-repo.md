# Install customizations from an application repository

Install a customization of a store application from the Application Repository to your instance.

## Before you begin

Role required: admin

[Publish a customization of a store application to the application repository](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/application-repository-self-hosted/publish-customizations-app-repo.md). Check the entitlement type of the application to verify that your instance is entitled to the application.

## Procedure

1.  Navigate to **System Applications** &gt; **All Available Applications** &gt; **All**.

2.  Find and select the application.

3.  Select **Proceed to update**.

4.  Select a customization version to install.

    **Note:** For scoped applications installed via plugins, the base system version is the ServiceNow release version that you're currently using \(for example, Brazil\).

5.  Select **Install**.
