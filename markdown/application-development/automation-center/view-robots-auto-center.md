# View the available robots

View a list of available robots in Automation Center for reference purpose.

## Before you begin

Role required: sn\_ac.automation\_business\_user, sn\_ac.automation\_technical\_user, or sn\_ac.automation\_admin

In addition to the Automation Center roles, you will also need the Robotic Process Automation \(RPA\) roles. For more information on RPA roles, see .

## About this task

A robot is a software agent that runs a bot process.

You can't create a robot.

## Procedure

1.  2.  3.  On the **Lists** tab, under **Monitor**, select **All Robots**.

4.  Open the robot that you want to view.

5.  Review the information on the robot page.
