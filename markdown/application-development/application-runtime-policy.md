# Application Runtime Policy \(ARP\)

Application Runtime Policy \(ARP\) is an opt-in, Zero Trust security framework for app creation and runtime that enforces fine-grained controls over accessing network, scripting, record, and platform resources. ARP provides automatic policy creation for applications in development, which helps simplify policy creation and the ServiceNow Store certification process.
