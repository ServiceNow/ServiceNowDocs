# Create a schedule from a chat in Arc

Ask Arc in a chat to run a task or remind you at a set time, without opening the scheduling window.

## Before you begin

Role required: sn\_app\_arc.user

## About this task

When your request says what to do and when, Arc creates the schedule for you. Schedules you create in a chat appear in the **Schedules** list with the ones you create there.

## Procedure

1.  In Arc, open a chat, and then in the message box describe the task and when it should run.

    `Remind me every day at 9:00 AM to check my emails`

2.  Select the send icon.

    Arc sets up the schedule and confirms when it runs and when the first run happens.

3.  To check the new schedule, select **Schedules** in the sidebar.


## Result

The schedule runs at the time you asked for. Each run appears in the chat list, which you can filter to **Scheduled**.

## What to do next

To change, copy, pause, run, or delete the schedule, see [Create and manage scheduled tasks in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/create-scheduled-tasks.md).
