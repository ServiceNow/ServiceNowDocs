# Create a widget

You can create a widget three ways — describe it in chat, build it by hand, or clone an existing widget. Each way produces a new widget ready to edit in the Editor.

## Before you begin

Role required: admin

## Procedure

-   Create with AI chat

    1.  From the Widgets catalog, select **Create widget**.

        The Editor opens with a new, unsaved widget.

    2.  In the chat panel, type a description of the widget you want, for example, "a card that lists open incidents assigned to me" and send it.

    3.  Chat shows a thinking indicator while the widget is generated, followed by streamed progress text.

    4.  When generation finishes, Widget Builder builds and deploys the widget automatically.

        The URL updates to the new widget's ID, and the **Preview** tab shows the result.

    5.  Chat then prompts for further changes, describe a change, or move on to editing manually.

    Every AI response in chat carries the disclaimer "Some answers generated by AI. Be sure to check for accuracy." Review the generated code and behavior before publishing.

    Chat history is kept for the current browser tab \(it survives a reload but doesn't follow you to another tab or device\).

    \[Omitted image "aiux-builder-chat-create.png"\] Alt text: Chat panel generating a widget, with streamed thinking text

-   Accept or decline a chat-driven change

    After chat applies a change, it shows **Accept changes** and **Decline changes**.

    -   **Accept changes** keeps the update.
    -   **Decline changes** reverts the widget to how it was before the change and reloads the editor with the prior code.
-   Create manually

    1.  From the Widgets catalog, select **Create widget**.

    2.  Skip the chat panel and edit the **Component** and **Script** tabs directly in the widget editor.

    3.  Select **Save** to build the widget without deploying it — the preview updates immediately from the build output.

    4.  When you're ready to make it available on the instance, select **Publish** to build and deploy it.

-   Clone an existing widget

    Cloning gives you your own independent copy of a widget, seeded with its current source.

    1.  From the Widgets catalog, select a widget's action menu and choose **Clone** \(or clone from the create dialog when creating a widget\).

    2.  Review and edit the pre-filled name, ID, and description.

    3.  **Confirm**.

        Widget Builder opens the new widget in the Editor, already published and unrelated to the original. Editing or deleting the clone never affects the widget you cloned it from.

    The clone is created in whichever application scope is currently active.
