# Autonomous Engineer limitations

Limitations that apply to Build Agent also apply to Autonomous Engineer.

Autonomous Engineer depends on Build Agent as its execution layer. Limitations that apply to Build Agent, including constraints on regulated environments, deployment capabilities, and performance, also apply when Autonomous Engineer runs. For full limitations information, see [Build Agent limitations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/build-agent-limitations.md).
