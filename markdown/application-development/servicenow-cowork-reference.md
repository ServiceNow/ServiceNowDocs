# ServiceNow Arc reference

Reference information for ServiceNow Arc, including environment and capability controls, sandbox file protection, local MCP server management, and policy change testing.

-   **[Turn off local MCP servers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/turn-off-local-mcp-servers.md)**  
Turn off local MCP servers for users or user groups so that Arc can't run MCP server actions directly on user devices.
-   **[Prevent changes to sandbox files](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/prevent-changes-sandbox.md)**  
Add a filesystem deny rule to your sandbox policy so that agent actions can't modify files in the sandbox runtime directory on user devices.
-   **[Environment and capability controls](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/environment-capability-controls.md)**  
Environment and capability controls limit what ServiceNow Arc can access while an action runs, keeping the agent within the boundaries you set.
-   **[Test a ServiceNow Arc policy change](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/test-cowork-policy-change.md)**  
Verify that a policy change works as intended before you apply it to all users.
-   **[Troubleshoot Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/troubleshoot-arc.md)**  
Resolve common Arc issues, such as a token page that keeps appearing, sign in errors, AI connection errors, and sandbox failures.
