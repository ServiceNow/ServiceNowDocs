# Run a schedule now in Arc

Run a schedule right away, outside its regular time, for example to test a new schedule or get a result early.

## Before you begin

You have at least one schedule. For more information, see [Create and manage scheduled tasks in Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/create-scheduled-tasks.md).

Role required: sn\_app\_arc.user

## About this task

Running a schedule now doesn't change its regular time. The schedule still runs at its next scheduled time.

## Procedure

1.  In Arc, select **Schedules** in the sidebar.

    Each schedule appears as a card that shows its name, instruction, how often it runs, and its next and last run.

2.  On the schedule's card, select the run icon.
