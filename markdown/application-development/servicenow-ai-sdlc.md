# AI-led software development life cycle \(SDLC\) on the ServiceNow AI Platform

Build, test, source-control, and release ServiceNow applications end to end using the recommended ServiceNow stack.

The advent of agentic software development has changed the software development life cycle across industries and organizations. To keep pace with these rapidly-evolving technologies and enhanced ServiceNow tooling, ServiceNow has developed a new approach to the software development life cycle \(SDLC\). This new, AI-led SDLC covers all stages of development for both net new apps and customizations or extensions to existing ServiceNow applications. To learn more about the ServiceNow AI-led SDLC, see [SDLC on ServiceNow](https://servicenow.github.io/sdk/guides/sdlc-guide).

The recommended ServiceNow stack includes:

-   [Build Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/build-agent.md)
-   [ServiceNow Studio](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-studio-classic/servicenow-studio-landing.md)
-   [ServiceNow SDK](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/servicenow-sdk/servicenow-sdk-landing.md)
-   [Developer Sandboxes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/developer-sandboxes/sandboxes-landing.md)
-   [Automated Test Framework \(ATF\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/automated-test-framework-atf/atf-landing-page.md)
-   [ReleaseOps](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/releaseops/releaseops-landing.md)

Together, these components carry an application through the stages of the SDLC:

-   **Planning**

    Define build-ready requirements with entities, roles, and Given-When-Then criteria.

-   **Building**

    Author ServiceNow Fluent metadata and logic, with or without AI assistance.

-   **Testing**

    Generate and run ATF coverage alongside development.

-   **Managing**

    Branch, review, and merge changes in GitHub, then publish to the Application Repository.

-   **Releasing**

    Assess and promote the deployment through ReleaseOps.


For the full walkthrough of this model, see the [SDLC on ServiceNow](https://servicenow.github.io/sdk/guides/sdlc-guide).
