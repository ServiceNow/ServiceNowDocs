# Autonomous Engineer in Build Agent

Autonomous Engineer is an agentic worker that augments product development capacity across the SDLC. It intakes requirements, applies platform best practices through agent packs, and generates an implementation plan before building work items in parallel through Build Agent.

Implementing applications on the ServiceNow AI Platform can require significant manual effort between defining requirements and delivering value to users. Autonomous Engineer reduces that time to value by taking your specifications as input and driving the full implementation lifecycle end to end.

**Note:** You must install the Autonomous Engineer app from the ServiceNow Store. Check your entitlements to see whether you can use Autonomous Engineer.

Autonomous Engineer uses agent packs to give background agents product-specific domain knowledge for application and product implementation. For more information, see [Agent packs for Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown).

Autonomous Engineer is available in ServiceNow Studio and covers custom applications.

For full documentation on Autonomous Engineer, including how it works, how to configure it, and step-by-step instructions for starting and managing a plan, see [Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/autonomous-engineer.md).

To start using Autonomous Engineer in Build Agent, see [Using Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/ae-using-autonomous-engineer.md).
