# Lux Reference

The Lux reference topics provide the exact names, keys, options, and values that the other chapters explain, from the `now-sdk` command-line interface to the design tokens.

Topics in this chapter cover the `now-sdk` command-line interface and the configuration schemas behind project files, configuration decorators, and configuration tables. They also cover the design tokens, grouped by family, and the `theme.js` file where an application declares its brand.
