# Deployment requests in ReleaseOps

Deployment requests contain one or more update sets. Deployment requests are attached to either a release or directly to a pipeline and source environment.

Deployment requests are the building blocks of moving code into production. They capture the content that a developer wants to be moved, including update sets. Deployment requests describe how and when the developer would like that code to go into production.

A deployment request must be attached to either a release or a pipeline, if the release hasn't been created yet. With either the release or pipeline defined, the deployment request can proceed to the assessment stage.
