# Deployment requests in ReleaseOps

Deployment requests contain one or more update sets. They are attached to a release, which runs through a pipeline to a destination environment.

Deployment requests are the building blocks of moving code into production. They capture the content that a developer intends to move, including update sets. Deployment requests also describe how and when that code should go into production.

When creating a deployment request, you can attach it to either a release or a pipeline, if the release hasn't been created yet, which enables the request to move to the assessment stage. However, for the deployment request to move to production, a release must be defined.
