# Using Application Runtime Policy

Application Runtime Policy \(ARP\) generates policies to control what external resources and cross-scope privileges an application can access at runtime. After opting in, manage policy records, configure resource quotas, and monitor access attempts during development.

## Overview of using Application Runtime Policy

After you opt an application in to Application Runtime Policy \(ARP\), you can manage generated policy records, define resource limits, and monitor access attempts as you continue development.

-   **[Review network policies](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/review-network-policy-arp.md)**  
Review automatically created network policy records and change their status as needed based on intended application behavior.
-   **[Create a segment policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/create-segment-policy-arp.md)**  
Create a segment policy to enable broad access to one or more policy categories without requiring individual policy records for each access attempt.
-   **[Review cross-scope privilege policies](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/review-cross-scope-policy-arp.md)**  
Review automatically created cross-scope privilege policy records and change their status as needed based on intended application behavior.
