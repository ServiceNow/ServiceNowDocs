# Exploring ServiceNow Otto for Creator

Explore the AI capabilities, users, benefits, and workflow for using ServiceNow Otto for Creator.

## ServiceNow Otto for Creator overview

ServiceNow Otto for Creator includes generative and agentic AI features that make developing on the ServiceNow AI Platform more efficient. The ServiceNow Otto for Creator AI capabilities are embedded across platform tools—including ServiceNow Studio, Workflow Studio, UI Builder, and the ServiceNow IDE—so developers can generate apps, flows, code, and UI components without leaving the tools they use every day. ServiceNow Otto for Creator also includes Build Agent, an autonomous AI agent that can develop full-stack applications through natural language conversations in the ServiceNow IDE.
