# Exploring ServiceNow AI Experience Lab for VS Code extension

The ServiceNow® AI Experience Lab for VS Code extension provides framework intelligence and quick commands to help you create and extend ServiceNow experiences with pages and widgets tailored to fit your needs.

## ServiceNow® AI Experience Lab for VS Code extension overview

\[Omitted video\] Description: ServiceNow Lux Lab for VS Code extension

The ServiceNow® AI Experience Lab for VS Code extension enables you to create and extend ServiceNow experiences. With built-in framework intelligence, you can run quick commands, preview entire applications, and see which files are relevant for your work from inside the explorer. Create experiences, pages, and widgets that support tailored functionality in your ServiceNow applications.

\[Omitted image "servicenow-lux-lab-vs-code-welcome.png"\] Alt text: ServiceNow AI Experience Lab for VS Code welcome screen.

## ServiceNow® AI Experience Lab for VS Code users

|User|Description|
|----|-----------|
|Developer|Build new experiences, pages, and widgets. Or extend base system ServiceNow applications with tailored experiences, pages, and widgets.|

## ServiceNow® AI Experience Lab for VS Code workflow

1.  Create a new experience or extend an existing experience.
2.  Create or extend pages and widgets manually or using agentic development tools.
3.  Preview your changes from within Visual Studio Code.
4.  Deploy your changes.

## ServiceNow® AI Experience Lab for VS Code benefits

|Benefit|Feature|Users|
|-------|-------|-----|
|Run commands via the ServiceNow® AI Experience Lab for VS Code extension interface rather than using the terminal.|Script Runner|Developer|
|Preview your application in real time without leaving Visual Studio Code.|Preview|Developer|
|Access relevant experiences, pages, and widgets from your instance.|Explorer|Developer|
|Develop tailored experiences with AI tools.|Claude Code in Visual Studio Code|Developer|
