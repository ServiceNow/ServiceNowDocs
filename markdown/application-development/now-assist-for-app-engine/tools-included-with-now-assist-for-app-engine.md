# Tools included with ServiceNow Otto for App Engine

Learn about the tools and applications included with ServiceNow Otto for App Engine.

ServiceNow Otto for App Engine enables users to use the generative and agentic AI capabilities of the ServiceNow AI Platform. With ServiceNow Otto for App Engine, you can create and activate custom skills using AI Skill Kit, build custom AI agents using AI Agent Studio, generate synthetic data for testing skills and AI agents using AI Data Kit, and more.

The following table highlights some of the ServiceNow AI Platform tools and applications that you can use to enhance custom applications with ServiceNow Otto for App Engine.

**Note:** Check your entitlements to determine whether you have access to the following tools and applications.

|Tool|Description|Resources for additional information|
|----|-----------|------------------------------------|
|AI Agent Studio|Create flexible, adaptive AI agents for App Engine use cases.|[AI Agent Studio overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/ai-agent-studio.md)|
|AI Control Tower|Govern AI assets.|[AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aict-landing.md)|
|AI Skill Kit|Develop custom skills that can be used in App Engine applications.|[AI Skill Kit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-skill-kit-landing.md)|
|AI Data Kit|Build and maintain datasets to evaluate your custom skills.|[AI Data Kit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-data-kit-landing.md)|
|Document Intelligence|Incorporate generative AI capabilities into your flows and playbooks.|[Now Assist in Document Intelligence \(Legacy\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/docintel-nowassist-landing.md)|
|Virtual Agent|Create generative AI-powered chatbots.|[ServiceNow Otto for Virtual Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/conversational-interfaces/now-assist-in-va-landing.md)|

For a complete list of the tools and skills in ServiceNow Otto for App Engine, see the product listing in the [ServiceNow Store](https://store.servicenow.com/store/app/5d27eef41bd92a50396216db234bcb45).
