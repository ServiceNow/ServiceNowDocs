# AI-native app development

Learn about the suite of AI tools available on the ServiceNow AI Platform and how you can use them to build applications more efficiently.

When developing applications on the ServiceNow AI Platform, you can use AI to help speed up the development process. ServiceNow has a suite of AI assets and products that can enable you to develop applications and app metadata more efficiently. Whether you're looking to expedite individual development tasks, or build entire applications with agentic development, ServiceNow has the AI tools that you need to supercharge your development.

-   **[Contextual assistance](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/dev-get-start-contextual-assistance.md)**  
ServiceNow Otto for Creator contains AI assets that provide contextual assistance for handling development tasks more efficiently.
-   **[Agentic development](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/dev-get-start-vibe-coding.md)**  
Agentic development is an AI-driven approach to app development in which you build applications through conversations with AI. On the ServiceNow AI Platform, developers can use Build Agent to build entire applications through agentic development.
-   **[General guidelines for agentic development](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/dev-get-start-ai-development-best-practices.md)**  
When using agentic development tools to build applications and app components on the ServiceNow AI Platform, the quality of the output depends on the quality of your instructions. Use these guidelines to write effective instructions and improve the products of your conversations with AI tools.
-   **[Choosing your build approach](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/dev-get-start-choosing-your-build-approach.md)**  
Understand when to use AI-assisted tools like the app generation skill with ServiceNow Otto for Creator and Build Agent versus when to build an application manually on the ServiceNow AI Platform.
-   **[Adding AI to your apps](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/dev-get-start-adding-ai-to-your-apps.md)**  
Learn about how you can add AI assets, such as skills, AI agents, and agentic workflows, to your custom apps using ServiceNow Otto for App Engine.
