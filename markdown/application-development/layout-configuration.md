# Layout configuration

A config admin can restructure a page's layout directly on the rendered page, without modifying code, by editing and persisting the regions a page exposes. This section covers the region and wrapper contract that makes a layout editable, what editing and persisting a layout costs, and how widgets get placed into regions.
