# Track tasks in Arc

Check and track the progress of the tasks you have delegated and respond when Arc needs your input. Tracking tasks lets you keep working while Arc completes them, and responding quickly keeps paused tasks from stalling.

## Before you begin

Role required: sn\_app\_arc.user

## Procedure

1.  Select **Kanban** in the ServiceNow Arc application.

2.  Review the status of each task.

    |Column|Description|
    |------|-----------|
    |**Queued**|The task is waiting to start.|
    |**Running**|Arc is working on the task.|
    |**Awaiting Input**|The task needs a response from you before it continues.|
    |**Completed**|The task is done.|
    |**Failed / Stopped**|The task ended before it completed.|

3.  If a task is in **Awaiting Input**, select it.

4.  Respond to the request in the chat.


## Result

Arc continues the task after you respond, and the task moves to **Completed** when it's done.
