# Using ServiceNow® AI Experience Lab for VS Code extension

Use the ServiceNow® AI Experience Lab for VS Code extension to create or extend experiences with pages and widgets tailored to fit your needs.

## Overview of using ServiceNow® AI Experience Lab for VS Code

With the ServiceNow® AI Experience Lab for VS Code extension, you can harness framework intelligence, AI tools, and easy-to-use commands to create tailored experiences on the ServiceNow AI Platform®. Start by creating a new experience or extending an existing one. Build or extend pages and widgets on your own or with the help of your preferred AI tools. Discover relevant tables and files and preview changes in real-time as you work. When you're ready, deploy changes to your instance with one click.

-   [Create a new experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/create-a-new-experience-servicenow-ai-experience-lab-for-vs-code.md)

    Build new experiences for the ServiceNow AI Platform®.

-   [Extend an existing experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/extending-existing-experience-servicenow-ai-experience-lab-for-vs-code.md)

    Add tailor-made pages and widgets to existing ServiceNow applications.

-   [Create pages for new experiences](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/create-page-servicenow-ai-experience-lab-for-vs-code.md) or [existing ones](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/create-page-existing-servicenow-ai-experience-lab-for-vs-code.md), or [extend existing pages](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/extend-existing-page-servicenow-ai-experience-lab-for-vs-code.md)
-   Depending on your project type, create or extend pages manually or using your preferred AI tools.
-   [Preview a page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/preview-page-servicenow-ai-experience-lab-for-vs-code.md)

    Test that your pages appear and function as intended from within Visual Studio Code.

-   [Add a page to the navigation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/add-page-to-navigation-servicenow-ai-experience-lab-for-vs-code.md)

    Make your pages accessible from ServiceNow application sidebars or within other pages.

-   [Deploy changes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/deploy-changes-servicenow-ai-experience-lab-for-vs-code.md)

    When you're ready, deploy your changes to a target instance.
