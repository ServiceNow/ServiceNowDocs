# Deploy changes

Deploy your changes to an instance to preview and publish experiences, pages, and widgets.

## About this task

The following procedure describes how to complete this task manually. You can also complete the task using agentic development tools, such as Claude Code.

## Before you begin

Role required: none

1.  Expand the **AI Experience Lab: Script Runner** panel.

2.  Select **Deploy**.

    The ServiceNow® AI Experience Lab for VS Code extension attempts to deploy your changes. If successful, a banner appears confirming that the deployment to your target instance was successful.


## What to do next

Preview and test your changes on your instance.
