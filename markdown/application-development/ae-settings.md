# Configuring Autonomous Engineer settings in Build Agent

Autonomous Engineer and Build Agent share the same configuration settings. Settings you configure for Build Agent also apply when Autonomous Engineer runs.

Because Autonomous Engineer is powered by Build Agent as its execution layer, both products use the same settings. For information on configuring these settings, see [Build Agent configuration](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/configure-build-agent.md).
