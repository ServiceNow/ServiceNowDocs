# Configuring ServiceNow Arc

Activate the ServiceNow Arc plugin, and then download, install, and set up Arc.

-   **[Activate the ServiceNow Arc plugin](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/activate-servicenow-cowork-plugin.md)**  
You can activate the ServiceNow Arc plugin \(sn\_app\_cowork\) for ServiceNow Arc if you have the admin role. The application includes demo data and installs related ServiceNow® Store applications and plugins if they aren't already installed.
-   **[Download and install ServiceNow Arc for macOS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/install-cowork.md)**  
Install ServiceNow Arc on a Mac with an M-series processor to use the AI desktop agent on your computer.
-   **[Download and install Arc on Windows](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/install-arc-windows.md)**  
Install ServiceNow Arc on your Windows computer.
-   **[Set up ServiceNow Arc](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/set-up-cowork.md)**  
Connect Arc to your ServiceNow instance and prepare your workspace and secure sandbox.
-   **[Create a ServiceNow Arc agent policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/create-cowork-agent-policy.md)**  
Create a policy to define what ServiceNow Arc can do, which actions need human approval, and which actions are blocked.
-   **[Configure a ServiceNow Arc agent policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/configure-cowork-agent-policy.md)**  
Add tool gates, approval patterns, network rules, sandbox rules, capability overrides, connector scopes, and file type rules to a policy to control what Arc can do for the users the policy applies to.
-   **[Manage Arc agent policies in AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/manage-arc-policies-aict.md)**  
Create and manage Arc agent policies and their rules in AI Control Tower, so you govern Arc in the same place as the rest of your AI systems.
-   **[Make auto mode available to Arc users](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/make-auto-mode-available.md)**  
Turn on auto mode for the users a policy covers and choose which tools can use it, so users can let an AI model reviewer approve lower risk actions instead of answering every prompt.
-   **[Add an MCP server for Arc users](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/add-mcp-server-arc.md)**  
Make a remote MCP server available to Arc users, so they can connect to it in one step without entering its details themselves.
-   **[Trace evaluation for Arc in AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/cowork-trace-evaluation.md)**  
AI Control Tower scores the traces that Arc sends for quality and safety. Review the scores to understand usage patterns and identify where responses fall short.
