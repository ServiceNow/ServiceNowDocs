# Agentic app development

Learn about the agentic app development approach, which tools you should use, and the AI-led software development life cycle on the ServiceNow AI Platform.

Agentic development, or vibe coding, is an AI-driven approach to application development. You describe your goals in natural language to an AI agent such as Build Agent or an AI-powered tool. From these descriptions, the AI agent or tool generates full-stack applications, workflows, and integrations with built-in ServiceNow AI Platform table extensibility, rules, governance, and more.

To learn more about agentic development, see the following resources:

-   [Agentic development guide](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/vibe-coding-landing.md)

## Agentic app development tools

There are a range of agentic development tools on the ServiceNow AI Platform. Some agentic development tools are autonomous AI agents, such as Build Agent and Autonomous Engineer, which are integrated into ServiceNow Studio and the ServiceNow IDE. These autonomous AI agents can generate full-stack applications and workflows and execute implementation plans independently. Other agentic development tools provide specific, contextual assistance and are embedded within existing products, such as the flow and playbook generation skills in Workflow Studio.

Many agentic development tools share the same underlying AI capabilities, so you can move between tools as your work changes, without needing a new file type, approach, or entitlement. The following table lists the agentic app development tools on the ServiceNow AI Platform.

|Application|Description|
|-----------|-----------|
|[AI Workflow Factory Prime](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/ai-workflow-factory-prime.md)|Grouping of applications, capabilities, and tools that spans the full life cycle and ecosystem of building on the ServiceNow AI Platform.|
|[Autonomous Engineer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/autonomous-engineer.md)|An autonomous AI agent that augments product development capacity across the software development life cycle \(SDLC\). The agent accepts requirements, generates a plan with structured work items, and builds all work items in parallel using background agents.|
|[Build Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/build-agent.md)|An autonomous AI agent capable of independently generating a complete ServiceNow scoped or global application. For example, a global scope app that uses tables such as incident, problem, and change.|
|[ServiceNow Otto for App Engine](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/now-assist-for-app-engine/add-ai-to-custom-apps-with-now-assist-for-app-engine-enterprise.md)|Tool that enables the creation and management of AI capabilities \(such as AI agents, skills, and agentic workflows\) in custom apps at runtime.|
|[ServiceNow Otto for Creator](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/now-assist-for-creator/now-assist-for-creator-landing.md)|Grouping of AI capabilities, including AI agents such as Build Agent and other chat-based AI skills that enable you to generate apps, UI components, workflows, tests, and other metadata.|
|[Test Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/test-agent-landing-page.md)|An autonomous AI agent that manages testing from end‑to‑end, including test authoring, execution, and troubleshooting from a single prompt.|

## AI-led software development life cycle \(SDLC\)

Agentic development tools have reshaped the software development life cycle \(SDLC\)—from the ways that apps are built and the tools used, to the timelines for deployment and adoption. This evolution calls for a broader approach to the SDLC that accounts for these new tools and stages in the life cycle. To learn more, see [AI-led software development life cycle \(SDLC\) on the ServiceNow AI Platform](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/servicenow-ai-sdlc.md).
