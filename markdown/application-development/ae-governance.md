# Autonomous Engineer governance

Governance controls for Autonomous Engineer are managed through Build Agent.

Autonomous Engineer uses Build Agent as its execution layer. Governance controls that apply to Build Agent also apply when Autonomous Engineer runs. For full governance information, including AI Control Tower integration, cross-scope privileges, background script containment, and custom skills and rules, see [Build Agent governance](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/build-agent-governance.md).
