# Search list selector

How to address dot-walked child fields that don't display following a search action. List selector search filters both list panes. Dot-walked reference may not appear when searching.

## Before you begin

Role required: workspace\_user

## About this task

**Note:** The list selector search simultaneously filters both the field categories and the available fields in the middle pane. If a search term doesn't match the dot-walked child field names, they're filtered out of view even if you expand the parent reference field.

## Procedure

1.  After running a search, select the reference field to expand it and reveal its dot-walked child fields.

2.  In the field picker, clear the search text.

    Any hidden child fields now display.

3.  Select the ones you want.
