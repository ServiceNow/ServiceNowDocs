# UIB Setup Information

UIB setup documentation provides configuration and property information for UIB components.

Each component has its own properties, such as text, color, and size, and its own events, such as a button click. Data flows down into components through properties, and components send signals back up through events, which you connect to actions with event handlers. Some components also fire life cycle events, such as `macroponent_ready` and `macroponent_property_changed`. Component presets can set properties and event handlers automatically.
