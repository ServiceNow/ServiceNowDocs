# UI Generation use cases

Learn how UI Generation capabilities in ServiceNow Otto for Creator support developers in creating and configuring UI Builder experiences using natural language.

UI generation is a set of AI-assisted features available in ServiceNow Otto for Creator. These features reduce the manual effort involved in building and maintaining ServiceNow UI experiences by enabling developers describe what they need in natural language and having ServiceNow Otto generate ready-to-use output.

-   **[Use case: Create an AI-generated experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/ui-builder/use-case-experience-generation.md)**  
Learn how to generate a multi-page UI experience from a natural language description.
-   **[Use case: Using UI Builder Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/ui-builder/use-case-ui-builder-agent.md)**  
Learn UI Builder features and accelerate page configuration using conversational AI.
-   **[Use case: Summarize a client script using ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/ui-builder/use-case-client-script-summarization.md)**  
Understand and edit client scripts.
-   **[Use case: Generate a data binding and formula](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/ui-builder/use-case-data-binding-generation.md)**  
Automate data binding configuration without memorizing formula syntax.
-   **[Use case: Configure an event handler with ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/ui-builder/use-case-event-handler-generation.md)**  
Automate event handler configuration without writing manual binding expressions.
-   **[Use case: Generate modules using ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-development/ui-builder/use-case-module-generation.md)**  
Create and configure application menu modules using natural language
