# Lux Lab

Lux Lab is the desktop app for building Lux applications on the ServiceNow AI Platform. It provides Lux aware tooling for scaffolding experiences, pages, and widgets.

## Get started

The Lux Lab documentation is organized into the following sections.

|Section|What it covers|
|-------|--------------|
|[Exploring Lux Lab](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/exploring-lux-lab.md)|Learn about Lux Lab.|
|[Configuring Lux Lab](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/configuring-lux-lab.md)|Install Lux Lab and connect it to your instance.|
|[Using Lux Lab](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/using-lux-lab.md)|Create and extend application experiences, pages, and widgets.|

## Panels and workflows

Lux Lab includes the following panels and workflows for building a Lux application:

-   Project file tree
-   Instance connection
-   Code editor
-   AI agent chat harness
-   Source control
-   Terminal and build output
-   One-click deployment to a ServiceNow instance
