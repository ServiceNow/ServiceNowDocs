# Create a folder

Add a subfolder inside any folder of your project, directly from the Project Explorer tree. Use subfolders to group related files in your project.

## Before you begin

Role required: admin

## Procedure

1.  Select and hold \(or right-click\) the folder in the tree where you want the subfolder.

2.  Select **New Folder**.

3.  Enter the folder name.

4.  Press Enter.
