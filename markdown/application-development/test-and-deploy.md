# Test and deploy a Lux app

A Lux app moves from your local machine to a ServiceNow instance through preview, testing, debugging, validation, and deployment.

Topics in this section start with the ways to preview an experience and with testing an app locally with Vitest. They then cover debugging a running page with Lux DevTools and diagnosing slow pages. They close with the validation checks that run between a local build and a deployed instance, and with the deployment pipeline.
