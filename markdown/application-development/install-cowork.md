# Download and install ServiceNow Arc for macOS

Install ServiceNow Arc on a Mac with an M-series processor to use the AI desktop agent on your computer.

## Before you begin

Role required: sn\_app\_arc.admin or sn\_app\_arc.user

## About this task

To install Arc on Windows, see [Download and install Arc on Windows](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/install-arc-windows.md).

## Procedure

1.  Navigate to **All** &gt; **ServiceNow Arc** &gt; **Downloads**.

2.  Download the Mac installer.

3.  Go to your **Downloads** folder and select ServiceNow Arc installer package.

4.  Open the ServiceNow Arc installer package.

5.  On the Introduction screen, select **Continue**.

6.  On the Installation Type screen, select **Install** to perform a standard installation in your home folder.

7.  Select **Change Install Location** to select a destination.

8.  On the Destination Select screen, select how you want to install the software.

    -   Install for all users of this computer: Installs Arc for every user account on the computer.
    -   Install for me only: Installs Arc in your home folder. Only you can use the software.
    -   Install on a specific disk: Installs Arc on a disk that you choose.
9.  Select **Continue**.

10. After the installation completes, select **Close**.


## What to do next

After you install Arc, it keeps itself up to date. It checks for updates at startup, and when you check for updates from **Settings**.
