# Preview files in Arc

View Word, Excel, PowerPoint, PDF, and PNG files in Arc without opening another app, and download them or open them in their native app.

## Before you begin

Role required: sn\_app\_arc.user

## Procedure

1.  In Arc, select a file in a chat.

    The file opens in a preview.

2.  Use the preview controls as needed.

    -   Download the file.
    -   Open the file in its native app.
    -   Show the file in Finder.
    -   View the file full screen.
    -   Zoom in or out.
    -   Rotate a PNG image.
