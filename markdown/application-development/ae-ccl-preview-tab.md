# View changes in the change log

When Autonomous Engineer completes a turn, it updates the change log.

To review what a background agent worker did during execution, open the work item and select the **Log** tab. The **Log** tab shows the chat history of the background agent, including the messages it sent and received during the work item build.

For information on how the Build Agent change log works, see [Checkpoints and conversation change log](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-development/ba-conversational-change-log.md).
