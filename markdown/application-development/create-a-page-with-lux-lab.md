# Create a page with Lux Lab

Create a page in a new experience so that you can add elements to it, preview it, and deploy it to an instance. You can create the page from a context menu, by hand, or with an AI agent.

## Before you begin

-   Role required: admin
-   Your machine meets the minimum system requirements in [Configuring Lux Lab](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/configuring-lux-lab.md).
-   You have an experience to add the page to. For instructions, see [Create an experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/application-development/create-a-new-experience.md).

## About this task

## Procedure

-   In your experience, create a page using one of the following methods.
-   Create a page from the Explorer panel context menu

    1.  Right-click the `/pages` folder, or a file or folder within your project.

    2.  Select **Add Page…**.

    This Lux-specific action scaffolds a new Lux page directly into your project.

-   Create a page manually

    1.  Select the `/pages` folder.

    2.  With the `/pages` folder highlighted, select the create folder icon.

        Alternatively, right-click and select **New Folder**.

    3.  Enter a name for the new folder and press Enter.

    4.  In the new folder, select the create file icon.

        Alternatively, select and hold \(or right-click\) in the folder and select **New File**.

-   Create a page with an AI agent

    1.  Open the Agent Chat panel.

    2.  Use the **Create a page** quick-start action, or enter a prompt describing the page to create.


## Result

Your new page is created. You can add elements to the page and preview it as needed.
