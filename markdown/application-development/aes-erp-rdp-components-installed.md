# Components installed with App Engine for ERP rapid deployment pack

When you purchase App Engine Prime \(which contains App Engine for ERP\) and then download the rapid deployment packs, components such as tables and properties are installed.

## Plugins required to activate App Engine for ERP rapid deployment packs

Only organizations with an App Engine Prime license can download the App Engine for ERP rapid deployment packs from the ServiceNow Store.

For instructions, see [Install a ServiceNow Store application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/t_InstallApplications.md).

## Components installed with App Engine for ERP rapid deployment packs

Find the components installed App Engine for ERP rapid deployment packs in the system metadata table.

1.  In the navigation filter, enter `sys_metadata.list` to open the list of system metadata.
2.  Filter the list with this condition: **\[Package\] \[is\] \[ERP Rapid Deployment Packs\]**.

For more information, see [Find components installed with an application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/find-components.md).

## Properties installed with App Engine for ERP rapid deployment packs

Find the properties that are installed with App Engine for ERP rapid deployment packs in the system properties table.

1.  In the navigation filter, enter `sys_properties.list` to open the list of system properties.
2.  Filter the list with this condition: **\[Application\] \[is\] \[ERP Rapid Deployment Packs\]**.

## Tables installed with App Engine for ERP rapid deployment packs

Find the tables that are installed with App Engine for ERP rapid deployment packs.

1.  Navigate to **All** &gt; **System Definition** &gt; **Tables**.
2.  Filter the list with this condition: **\[Application\] \[is\] \[ERP Rapid Deployment Packs\]**.

## Roles used in App Engine for ERP rapid deployment packs

Find the roles that define the access and permissions for users of App Engine for ERP rapid deployment packs.

1.  Navigate to **All** &gt; **User Administration** &gt; **Roles**.
2.  Filter the list with this condition: **\[Application\] \[is\] \[ERP Rapid Deployment Packs\]**.

For more information, see [Managing roles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ua-creating-roles.md).
