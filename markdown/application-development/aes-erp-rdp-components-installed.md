# Components installed with App Engine ERP Rapid Deployment Packs

When you purchase App Engine Prime \(which contains App Engine ERP\) and then download the rapid deployment packs, you install components such as tables and properties.

## Plugins required to activate App Engine ERP Rapid Deployment Packs

Only organizations with an App Engine Prime license can download the App Engine ERP Rapid Deployment Packs from the ServiceNow Store.

For instructions, see [Install a ServiceNow Store application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/t_InstallApplications.md).

## Installed components

Find the components installed with App Engine ERP Rapid Deployment Packs in the system metadata table.

1.  In the navigation filter, enter `sys_metadata.list` to open the list of system metadata.
2.  Filter the list with this condition: \[**Package**\] \[**is**\] \[**ERP Rapid Deployment Packs**\].

For more information, see [Find components installed with an application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/find-components.md).

## Properties installed with App Engine ERP Rapid Deployment Packs

Find the properties that are installed with App Engine ERP Rapid Deployment Packs in the system properties table.

1.  In the navigation filter, enter `sys_properties.list` to open the list of system properties.
2.  Filter the list with this condition: \[**Application**\] \[**is**\] \[**ERP Rapid Deployment Packs**\].

## Tables installed with App Engine ERP Rapid Deployment Packs

Find the tables that are installed with App Engine ERP Rapid Deployment Packs.

1.  Navigate to **All** &gt; **System Definition** &gt; **Tables**.
2.  Filter the list with this condition: \[**Application**\] \[**is**\] \[**ERP Rapid Deployment Packs**\].

## Roles used in App Engine ERP Rapid Deployment Packs

Find the roles that define the access and permissions for users of App Engine ERP Rapid Deployment Packs.

1.  Navigate to **All** &gt; **User Administration** &gt; **Roles**.
2.  Filter the list with this condition: \[**Application**\] \[**is**\] \[**ERP Rapid Deployment Packs**\].

For more information, see [Managing roles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ua-creating-roles.md).
