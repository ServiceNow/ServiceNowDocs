# View TRM technical debts for a business application

View Technology Reference Model \(TRM\) associated to a business application in the Enterprise Architecture Workspace.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Portfolio List view by selecting the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text: Portfolio icon\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text: Expand Row icon\) next to **Application Portfolio**.

4.  Select **Business Applications**.

5.  Select the business application that you want to view the TRM technical debts for.

6.  Select **TRM Technical Debts**.

    \[Omitted image "eaw-trm-tech-debt-for-ba.png"\] Alt text: TRM Technical Debts associated with a business application


## Result

A list of TRM technical debts associated with the business application is displayed.
