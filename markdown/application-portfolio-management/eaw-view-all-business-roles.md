# View all business roles

View all available business roles to understand organizational structure and role relationships in Enterprise Architecture Workspace.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Select the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text:\) to open the Portfolio List view.

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text:\) next to **Business Architecture**.

4.  Select **Business Roles**.


## Result

The business roles list displays with columns for name, description, department, parent role, group, and required skills. You can select any role to view details or edit its properties.
