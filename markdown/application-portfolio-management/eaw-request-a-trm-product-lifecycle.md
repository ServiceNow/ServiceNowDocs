# Request a TRM product lifecycle in Enterprise Architecture Workspace

Submit a request to add one or more lifecycle records to an existing TRM product.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspace** &gt; **Enterprise Architecture Workspace**.

2.  Open the Technology Portfolio page by selecting the Technology Portfolio icon \[Omitted image "technology-portfolio-icon.png"\] Alt text: Technology portfolio icon.

3.  Select the more actions icon \[Omitted image "trm-more-actions-icon.png"\] Alt text: TRM more actions icon next to **Request TRM product**, then select **Request TRM product lifecycles**.

4.  In the **TRM product** field, select the existing product to add lifecycles to.

5.  Select **Create**.
