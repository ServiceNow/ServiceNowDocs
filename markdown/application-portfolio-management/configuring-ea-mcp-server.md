# Configure MCP for Enterprise Architecture

The EA MCP server connects your ServiceNow instance to an MCP-compatible AI assistant, enabling natural language access to EA data. To set up the connection, install the application and configure the server.

## Configuration overview

1.  [Install MCP for Enterprise Architecture](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-portfolio-management/install-mcp-for-ea.md)
2.  [Connect the EA MCP server to an AI assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-portfolio-management/connect-ea-mcp-server-to-ai-assistant.md)

-   **[Install MCP for Enterprise Architecture](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-portfolio-management/install-mcp-for-ea.md)**  
You can install the MCP for Enterprise Architecture application \(sn\_ea\_mcp\_server\) if you have the admin role.
-   **[Connect the EA MCP server to an AI assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-portfolio-management/connect-ea-mcp-server-to-ai-assistant.md)**  
After configuring the EA MCP server, connect it to an AI assistant so the assistant can query business applications, capabilities, and architectural insights directly from your ServiceNow instance.
