# Remove a business process from a goal

Remove business processes associated with a goal in the Enterprise Architecture Workspace.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Portfolio List view by selecting the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text:\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text:\) next to **Business Architecture**.

4.  Select **Goals**.

5.  Select the goal that you want to remove a business process from.

6.  Select the **Business processes** tab.

7.  Select the checkbox next to the business process that you want to remove, and select **Remove**.

    A confirmation message appears.

8.  Select **Remove**.
