# Remove a value stream from a stakeholder

Remove value streams associated with a stakeholder in the Enterprise Architecture Workspace.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Portfolio List view by selecting the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text:\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text:\) next to **Business Architecture**.

4.  Select **Stakeholders**.

5.  Select the stakeholder that you want to remove a value stream from.

6.  Select the **Value streams** tab.

7.  Select the check box next to the value stream that you want to remove, and select **Remove**.

    A confirmation message appears.

8.  Select **Remove**.
