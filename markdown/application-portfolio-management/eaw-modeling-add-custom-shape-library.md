# Add a custom shape library

Create a shape library to add custom shapes that are unique to your organization.

## Before you begin

Role required: sn\_apm.apm\_admin

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Setup page by selecting the Setup icon \(\[Omitted image "eaw-icon-setup.png"\] Alt text: setup icon.\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text: expand row icon.\) next to **Enterprise Modeling and Visualization**.

4.  Select **Shape Libraries**.

5.  Select **New**.

6.  On the Shape Library form, fill in the fields.

    For field information, see [Shape library form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/application-portfolio-management/eaw-shape-library-form.md).

7.  Select **Save**.
