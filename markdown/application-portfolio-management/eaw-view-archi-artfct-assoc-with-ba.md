# View architectural artifacts for a business application

You can view the list of architectural artifacts associated with business applications, in the Enterprise Architecture Workspace.

## Before you begin

Architectural artifacts are created to describe a system, solution, or state of an enterprise. For more information on architectural artifacts, see [Manage architectural artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/application-portfolio-management/eaw-managing-architectural-artifacts.md).

Role required: sn\_apm.apm\_read

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Portfolio List view by selecting the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text: Portfolio icon\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text: Expand Row icon\) next to **Application Portfolio**.

4.  Select **Business Applications**.

5.  Select the business application that you want to view the architectural artifacts for.

6.  Select **Architectural Artifacts**.\[Omitted image "archi-artfct-related-list-ba.png"\] Alt text: Architectural artifacts tab available as a related entity for a business application.

    If the **Architectural Artifacts** tab isn’t visible in the related list, select **More** and then select **Architectural Artifacts**.

    A list of artifacts associated with the business application is displayed.
