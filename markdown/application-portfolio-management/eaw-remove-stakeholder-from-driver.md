# Remove a stakeholder from a driver

Remove stakeholders associated with a driver in the Enterprise Architecture Workspace.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Portfolio List view by selecting the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text: Portfolio icon\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text:\) next to **Business Architecture**.

4.  Select **Drivers**.

5.  Select the driver that you want to remove a stakeholder from.

6.  Select the **Stakeholders** tab.

7.  Select the checkbox next to the stakeholder that you want to remove, and select **Remove**.

    A confirmation message appears.

8.  Select **Remove**.
