# Modify BPMN diagram details

Edit the properties of a BPMN \(Business Process Model and Notation\) diagram element directly from the diagram page. It enables quick updates without leaving the modeling interface.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Modeling page by selecting the Modeling icon \(\[Omitted image "icon-modeling-logo.png"\] Alt text: Modeling\).

3.  Open an existing BPMN diagram.

4.  Select the **Modify business process details** icon on the diagram page.

    \[Omitted image "modeling-modify-bpmn.png"\] Alt text: Modify business process details icon on the bpmn diagram page

    **Note:**

    To access the **Modify business process details** icon using a keyboard, navigate to the diagram using the **Tab** key. Canvas controls are accessible without a mouse.

5.  Modify the details such as name, description, and other details.

    \[Omitted image "modeling-modify-bpmn-details.png"\] Alt text: Modifying the details of a business process

6.  Select **Update**.
