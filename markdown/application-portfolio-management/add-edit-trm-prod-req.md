# Request a TRM product from the service catalog

Submit a request from the service catalog to add a software or hardware product to the TRM library. Optionally, include one or more lifecycle records with the request.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **All** &gt; **Service Portal Home** &gt; **Request Something** &gt; **Technology Reference Model Management**.

2.  Select **Request TRM Product**.

3.  Fill in the fields on the form.

    For field information, see [Request TRM Product form the Service Catalog form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-portfolio-management/trm-prod-req-catalog-form.md).

4.  In the **TRM product lifecycles** section, select **Add** to include lifecycle records with the request.

    1.  In the **Add Row** dialog, fill in the lifecycle fields.

        For field information, see [Request TRM Product Lifecycle form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/application-portfolio-management/trm-product-lifecycle-request-form.md).

    2.  Select **Add** to save the lifecycle row.

5.  Select **Submit**.


## Result

A confirmation message appears with the request number, for example: `Request for TRM product is created successfully: TRMPREQ0000000`. Select the request number to view the request details and the associated lifecycle records.
