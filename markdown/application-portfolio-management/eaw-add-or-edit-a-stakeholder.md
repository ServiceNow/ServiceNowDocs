# Add or edit a stakeholder

Add or edit a stakeholder to track who has an interest in the outcome of your enterprise architecture.

## Before you begin

Role required: sn\_apm.apm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Portfolio List view by selecting the Portfolio icon \(\[Omitted image "portfolio-icon.png"\] Alt text:\).

3.  Select the expand row icon \(\[Omitted image "ExpandIcon.png"\] Alt text:\) next to **Business Architecture**.

4.  Select **Stakeholders**.

5.  Add or edit a stakeholder.

    -   To add a stakeholder, select **New**.
    -   To edit an existing stakeholder, select the stakeholder.
6.  Fill in the fields.

    For field descriptions, see [Create a stakeholder form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/application-portfolio-management/eaw-create-a-stakeholder-form.md).

7.  Select **Save**.
