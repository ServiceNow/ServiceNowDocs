# Configure AI Data Explorer and Query Generation skills

You can configure the AI Data Explorer and Query Generation skills to provide AI-assisted data exploration features and generate insights in Enterprise Architecture Workspace.

## Before you begin

Role required:

-   now\_assist\_explorer\_admin or higher \(to configure AI Data Explorer\)
-   admin \(to configure Query Generation\)

## About this task

Configuring AI Data Explorer and Query Generation skills enables you to use a conversational interface to query and analyze data from Enterprise Architecture Workspace dashboards instead of manually reviewing dashboard visualizations.

## Procedure

1.  AI Data Explorer skills.

    For information on how to activate AI Data Explorer skills, see [Activate AI Data Explorer skills](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/now-intelligence/activate-aide-explorer.md).

    **Note:**

    Activate the following skills for Enterprise Architecture Workspace dashboard insights:

    -   **Analytics exploration**
    -   **Exploration summarization**
    -   **Refine text in exploration**
    -   **Data visualization generation**
2.  Activate Query Generation skills.

    For information on how to Activate Query Generation skills, see [Query Generation skills](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/now-intelligence/enable-query-generation.md).

    **Note:** Activate the following skills for Enterprise Architecture Workspace dashboard insights:

    -   **Analytics query generation**
    -   **Analytics hidden insights generation**
3.  Configure AI Search.

    For information on how to configure AI Search, see [Configuring AI Search](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/platform-administration/configuring-ais.md)
