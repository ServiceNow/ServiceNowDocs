# Create a driver form

The create new driver form contains fields for documenting internal or external conditions that motivate your organization to define goals and implement changes.

<table id="table_driver_form"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Name

</td><td>

Unique name of the driver.

</td></tr><tr><td>

Source

</td><td>

Origin of the driver: **External** or **Internal**.

</td></tr><tr><td>

Driver type

</td><td>

Category of the driver. Available options depend on the **Source** value. -   When **Source** is **External**: Competitor, Customer, Environment, Partner, Government, Legal, Economic, Social, or Technological.
-   When **Source** is **Internal**: Assumption, Corporate, Infrastructure, Resource, or Other.

</td></tr><tr><td>

Urgency

</td><td>

Rating of how quickly the organization must respond to the driver.

</td></tr><tr><td>

Description

</td><td>

Explanation of the condition, its origin, and what it motivates.

</td></tr></tbody>
