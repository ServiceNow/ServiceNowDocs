# Compare Enterprise Modeling and Visualization diagrams

Compare different versions of Enterprise Modeling and Visualization diagrams and learn the details of the differences from the summary that is generated by ServiceNow Otto® in the Enterprise Architecture Workspace.

## About this task

Enterprise Modeling and Visualization diagrams often have complex architecture layers like business capabilities, application hierarchy, and process flows. Manual comparison can be time-consuming or error-prone. Using the diagram change analysis ServiceNow Otto skill, you can quickly generate a change summary.

You can compare any two diagram versions, not just adjacent versions. For example, you can compare version 3.0 with version 1.0, or version 4 with version 2.

The change summary generated by ServiceNow Otto® includes an executive summary of changes between the primary version and the comparison version. The summary also includes details of shapes or entities that have been added, modified, or removed.

When you compare two diagram versions, the comparison screen highlights the differences on the canvas:

-   New shapes added in the primary version are highlighted in green.
-   New relationship lines added in the primary version are highlighted in green.
-   Modified shapes are highlighted in yellow.
-   Modified relationship lines are highlighted in yellow.

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Modeling page by selecting the Enterprise Modeling and Visualization icon \(\[Omitted image "icon-modeling-logo.png"\] Alt text: Enterprise Modeling and Visualization icon.\).

3.  Select the diagram that you want to compare versions for.

4.  Select **Compare versions**.

    The **Compare versions** button isn’t available when you open a diagram that has only one version.

    \[Omitted image "compare-diag-butn.png"\] Alt text: Enterprise Modeling and Visualization page with the Compare versions button highlighted.

    The **Compare versions** pop-up window appears.

    \[Omitted image "compare-diag-modal.png"\] Alt text: Screenshot displaying the Compare versions pop-up window.

5.  In the **Compare versions** pop-up window select the versions that you want to compare:

    1.  Select the primary version of the diagram from the **Primary version** drop-down list.
    2.  Select another version of the diagram from the **Version to compare** drop-down list.
    **Note:** You can compare any two versions, not just consecutive versions. For example, you can compare version 3.0 directly with version 1.0.

6.  Select **Compare**.

    The **Compare versions** tab appears and a change summary is generated in the ServiceNow Otto side panel. The ServiceNow Otto side panel displays the following sections:

    -   **Executive summary**: A ServiceNow Otto generated summary of the key changes between the selected versions.
    -   **Diagram changes**: Changes to shapes, entities, or relationships that have been added, modified, or deleted.

        \[Omitted image "compare-diag-summry.png"\] Alt text: Screenshot displaying the version change summary generated by ServiceNow Otto

        **Note:**

        -   Select the edit icon \(\[Omitted image "edit-icon.png"\] Alt text: Edit icon.\) to change the existing diagram versions and generate a fresh diagram comparison summary.
        -   Select the refresh icon \(\[Omitted image "refresh-icon.png"\] Alt text: Refresh icon.\) if you have changed the primary version of the diagram and want to generate a fresh diagram comparison summary.
        -   Select the helpful icon \(\[Omitted image "like-button-icon.png"\] Alt text: Helpful icon.\) or not helpful icon \(\[Omitted image "dislike-button-icon.png"\] Alt text: Not helpful icon.\) to provide feedback on the change summary generated by ServiceNow Otto. This feedback helps ServiceNow Otto to generate better change summaries.
        -   Select the copy summary icon \(\[Omitted image "copy-summary.png"\] Alt text: Copy summary icon.\) to copy the diagram change summary created by ServiceNow Otto.
        -   Select the ServiceNow Otto icon \(\[Omitted image "now-assist-side-pane-icon.png"\] Alt text: ServiceNow Otto icon.\) to close the side panel.
