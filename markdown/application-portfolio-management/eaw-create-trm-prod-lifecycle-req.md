# Create TRM product lifecycles in Enterprise Architecture Workspace

As an Enterprise Architect, you can add one or more lifecycle records to an existing TRM product.

## Before you begin

You must be part of the Enterprise Architect Group.

Role required: sn\_apm.apm\_analyst

## Procedure

1.  Navigate to **Workspace** &gt; **Enterprise Architecture Workspace**.

2.  Open the Technology Portfolio page by selecting the Technology Portfolio icon \[Omitted image "technology-portfolio-icon.png"\] Alt text: Technology portfolio icon.

3.  Select the more actions icon \[Omitted image "trm-more-actions-icon.png"\] Alt text: TRM more actions icon next to **Request TRM product**, then select **Create TRM product lifecycles**.

4.  In the **TRM product** field, select the product to add lifecycles to.

5.  In the **TRM product lifecycles** section, add lifecycle records.

    **Note:**

    -   For software products: You can add up to 5 version and edition combinations, with a maximum of 10 phases per combination.
    -   For hardware products: You can add up to 5 hardware models, with a maximum of 10 phases per hardware model.
    1.  For a software product, enter the **Version** and **Edition**, then fill in the **TRM phase**, **Phase start date**, and optionally the **Phase end date** for the first phase row.

    2.  For a hardware product, select the **Hardware model**, then fill in the **TRM phase**, **Phase start date**, and optionally the **Phase end date**.

    3.  To add more phases to the same version or hardware model, select the Plus icon.

    4.  To add another version and edition group or hardware model group, select **Add version and edition**.

    See [Create TRM product lifecycle form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/application-portfolio-management/eaw-create-trm-prod-lifecycle-form.md)

6.  Select **Create**.


## Result

A confirmation message appears with the request number. The new lifecycle records are visible under the product in the Technology reference model catalog.
