# Enterprise Architecture administration - Legacy

With the sn\_apm.apm\_admin role, you can classify the applications used in the business enterprise. You can also provide privileges to users to do specific tasks. Set up indicators to assess application usability and create bubble charts to help define strategies to maintain applications.

With administrative privileges, you can set up application classification attributes to group applications. You can configure users and roles to provide levels of access and assign tasks. You can set up application assessment indicators to assess applications and bubble charts to recommend an application strategy. This setup helps you classify applications and maintain an inventory. You can provide privileges to users for specific tasks and assess application usability. You can also recommend a strategy to plan and execute organization goals.
