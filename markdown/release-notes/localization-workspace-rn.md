# Localization Workspace release notes

The ServiceNow® Localization Workspace application is a targeted translation management experience for content owners and translation requesters. See the following sections for release notes by version.

## About Localization Workspace

-   Manage and deliver multilingual content at scale.
-   Streamline and automate task creation and translation workflows.
-   Create and store glossaries of terms in the Language Asset Management area.
-   Enhance language governance, quality, and consistency across the platform.

See [Localization Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/localization-workspace.md) for more information.

## Activation and other requirements

-   **Activation information**

    Install Localization Workspace by requesting it from the ServiceNow Store. Visit the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) to view all the available apps, and for information about submitting requests to the store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).

## Brazil Early Availability

With Brazil Early Availability, Localization Workspace offers an AI skill: generate glossary.

### What's new

-   **[Globalization Terminology Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/lw-terminology-agent.md)**

    Use the generate glossary skill with Globalization Terminology Agent to create a glossary of English-language terms. Review and approve the terms and their definitions that the skill extracts from Knowledge Base articles. Store and edit the glossary in Language Asset Management.
