# Process Mining for ITSM release notes

The ServiceNow® Process Mining for ITSM application helps analysts and process owners quickly analyze and optimize their business processes. See the following sections for release notes by version.

## About Process Mining for ITSM

-   See your real processes, not assumptions — automated discovery maps actual workflow paths from audit logs.
-   Find where work breaks down — bottleneck and root-cause analysis pinpoint stalled approvals and rework.

See [Process Mining](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/process-mining.md) for more information.

## Activation and other requirements

-   **Activation information**

    Process Mining is available by default. See [Access Process Mining](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/activate-po-plugin.md) for more information.

## Brazil Early Availability

### Plugin information

-   **Deprecated plugins**

    ITSM Process Mining Content Pack \(sn\_itsm\_process\_opt\_cp\): This plugin is deprecated and replaced by the core Process Mining Content Pack application. Starting with the Brazil release this plugin will be migrated to Process Mining Content Pack store application. Upgrade your instance to Brazil or higher releases.
