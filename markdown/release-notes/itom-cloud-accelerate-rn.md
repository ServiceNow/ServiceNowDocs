# ITOM Cloud Accelerate release notes

The ServiceNow® ITOM Cloud Accelerate applications streamline cloud automation across the cloud adoption journey, using self-service catalogs and controlled workflows to expedite application migration, resource governance, and remediation. See the release notes of each individual ITOM Cloud Accelerate application.

## About ITOM Cloud Accelerate

-   Create, govern, and administer cloud subscription accounts, catalogs, and policies through workflows with Cloud Account Management and Cloud Provisioning and Governance.
-   Achieve end-to-end, workflow-driven cloud operations with policy governance using the Cloud Services Catalog.
-   Plan, organize, and track the migration of enterprise IT resources and workloads to cloud platforms with Cloud Migration Assessment.
-   Scan for violations of best-practice norms and remediate configuration drift with Cloud Configuration Governance.
-   Drive hyperautomation for the cloud using the ready-to-use actions and subflows in the Cloud Action Library.

See [ITOM Cloud Accelerate](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-operations-management/itom-cloud-accelerate-landing-page.md) for more information.

## Activation and other requirements

-   **Activation information**

    ITOM Cloud Accelerate features are available as separate apps on the ServiceNow Store. Visit the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) to view all the available apps, and for information about submitting requests to the store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).

## Cloud Services Catalog

The ServiceNow® Cloud Services Catalog application provides a simplified interface to access cloud resources. You can publish cloud offerings to a catalog and manage the usage and life cycle of those resources. This application is no longer supported starting with the Brazil release.

### Plugin information

-   **Plugins planned for deprecation**

    Cloud Services Catalog \(sn\_itom\_csc\): Planned for deprecation in D release. There is no replacement for this application.


## CSC Content Pack

The ServiceNow® CSC Content Pack application provides dashboards and reports for the Cloud Services Catalog application. This application is no longer supported starting with the Brazil release.

### Plugin information

-   **Plugins planned for deprecation**

    CSC Content Pack \(sn\_itom\_csc\_cp\): Planned for deprecation in D release. There is no replacement for this application.


## Cloud Services Catalog Terraform Connector

The ServiceNow® Cloud Services Catalog Terraform Connector application integrates Terraform with the Cloud Services Catalog application for cloud resource provisioning. This application is no longer supported starting with the Brazil release.
