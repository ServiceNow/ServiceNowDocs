# Legal Virtual Agent Conversations release notes

The ServiceNow® Legal Virtual Agent Conversations application uses machine-learning algorithms for the predicting Subcategory and Assignment group for legal requests. This application is currently supported for the Australia release, but it will be deprecated in a future release.

## About Legal Virtual Agent Conversations

**Important:** For Now LLM Service model updates for each release, see [Model provider updates](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-llm-model-updates.md).

## Activation and other requirements

**Important:** Legal Virtual Agent Conversations is available in the ServiceNow Store. For details, see the "Activation information" section of these release notes.

-   **Activation information**

    Install Legal Virtual Agent Conversations by requesting it from the ServiceNow Store. Visit the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) to view all the available apps, and for information about submitting requests to the store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).

## Australia

The ServiceNow® Legal Virtual Agent Conversations application uses machine-learning algorithms for the predicting Subcategory and Assignment group for legal requests. This application is currently supported for the Australia release, but it will be deprecated in a future release.

### Plugin information

    The following plugins are planned for deprecation in a future release:
