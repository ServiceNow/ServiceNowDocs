# Mobile Platform release notes

Mobile Platform product enhancements and updates in the Brazil release.

Mobile Platform brings the power of the ServiceNow AI Platform to mobile devices, enabling users to access and manage work from anywhere. With Mobile Platform, you can improve productivity for field workers, enable hands-free data capture, and provide secure access to critical workflows on iOS and Android devices.
