# Healthcare and Life Sciences release notes

Healthcare and Life Sciences has new and updated features in the Brazil release.

-   **[EMR Provider Directory Sync release notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/hco-fhir-release-notes.md)**  
The ServiceNow® EMR Provider Directory Sync application keeps Healthcare Operations organization, location, practitioner, and care-team data in sync with a FHIR R4 server on a schedule. EMR Provider Directory Sync is a new application.
-   **[Care Team Work Management release notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/hco-ctwm-rn.md)**  
The ServiceNow® Care Team Work Management application enables clinicians to create and track ad-hoc and recurring tasks for their care team. It supports orchestration and care team cases and tasks.
