# Content Understanding

Now Assist in Document Intelligence is now Content Understanding. The ServiceNow® Content Understanding application brings multimodal generative AI to document and image processing. It extracts key data, answers natural-language questions, and generates summaries from unstructured text, tables, and images. Content Understanding is enhanced and updated in the Brazil release.

## Content Understanding highlights for the Brazil release

-   Capture structured data from documents, review extracted values, and integrate the results into downstream processes.
-   Extract information, answer questions, and summarize documents and images to accelerate agentic workflows.
-   Use a multimodal tool to process documents and images within custom skills.
-   Enable document chat in Virtual Agent.
-   Summarize attached files linked to records on a large scale to facilitate comprehension and decision-making.

See [Content Understanding](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/content-understanding-landing.md) for more information.

**Important:** Content Understanding is available in the ServiceNow Store. For details, see the "Activation information" section of these release notes.

## Content Understanding features

-   ****

    Capture structured data from documents, validate extracted values in an intuitive review interface, and integrate the results into downstream processes.

-   ****

    Extract information, answer questions, and summarize documents and images to accelerate agentic workflows.

-   ****

    Read and summarize the content of uploaded documents, extract key information in near real-time, and significantly reduce manual triage time for agents.
