# Learn about the Brazil release

The Brazil release includes new features and improvements built on the ServiceNow AI Platform®.

## Release dates

-   Early availability: September 24, 2026
-   General availability: Q4 2026

## Release notes for upgrades

Before you upgrade, review release notes from your current version to the Brazil release. The release notes offer valuable information about new functionality, notable changes, and available fixes. They help you determine whether the upgrade contains functionality you need and fixes that resolve any issues affecting your instance. The release notes can also help you determine whether items you previously customized are being upgraded.
