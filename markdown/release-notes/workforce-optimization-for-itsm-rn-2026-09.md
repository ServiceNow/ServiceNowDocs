# Workforce Optimization for ITSM release notes

The ServiceNow® Workforce Optimization for ITSM application helps IT managers automate the management, monitoring, and mentoring of their teams. This application is currently supported for the Brazil release, but it will be deprecated in a future release.

## Plugin information

-   **Plugins planned for deprecation**

    Workforce Optimization for ITSM \(com.snc.wfo\_itsm\): Planned for deprecation in a future release. There is no replacement for this plugin.

    This plugin includes the following:

    -   Workforce Optimization for ITSM Configurable Workspace \(com.snc.sn\_wfo\_cfg\_itsm\): Planned for deprecation in a future release. There is no replacement for this plugin.

    -   User Surveys in Workforce Optimization for ITSM \(com.snc.sn\_wfo\_usersurveys\): Planned for deprecation in a future release. There is no replacement for this plugin.

    -   Skills Review in Workforce Optimization for ITSM \(com.snc.sn\_wfo\_skill\_review\): Planned for deprecation in a future release. There is no replacement for this plugin.

    -   Work Scheduler in Workforce Optimization for ITSM \(com.snc.sn\_wfo\_work\_sched\): Planned for deprecation in a future release. There is no replacement for this plugin.

    For more details on deprecation, see the [Deprecation Process \[KB0867184\]](https://support.servicenow.com/kb_view.do?sysparm_article=KB0867184) article in the Now Support Knowledge Base.
