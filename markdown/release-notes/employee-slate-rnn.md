# EmployeeWorks release notes

The ServiceNow® EmployeeWorks is ServiceNow's AI-powered employee experience platform that brings IT, HR, Finance, and enterprise services into a single, personalized destination.

## About EmployeeWorks

-   Get instant answers and complete tasks faster by using conversational AI to automate workflows and answer employee questions.
-   Stay informed and connected by accessing news, announcements, events, and curated content through departmental microsites and topic pages.
-   Find the right people and information by searching across profiles, org charts, and enterprise content all in one unified portal.
-   Manage your work seamlessly by consolidating to-dos, approvals, requests, and insights into a personalized workspace with configurable widgets.
-   Work whenever, wherever by accessing EmployeeWorks across web, mobile, and all your favorite devices with a mobile-first experience.

See  for more information.

## Activation and other requirements

-   **Activation information**

    Install EmployeeWorks by requesting it from the ServiceNow Store. Visit the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) to view all the available apps, and for information about submitting requests to the store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).

    For more information, see [EmployeeWorks Web App setup flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/emp-slate-setup-flow.md).

-   **Upgrade information**

    EmployeeWorks requires Zurich Patch 9 or later and an AI assistant \(Moveworks or ServiceNow Otto\).


## Accessibility

-   **Accessibility information**
    -   The AI widget builder in EmployeeWorks includes built-in design components that support accessibility standards. When custom widgets are created through the prompt-driven interface, the design components are structured to help developers address accessibility requirements.
