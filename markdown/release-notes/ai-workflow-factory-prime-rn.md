# AI Workflow Factory Prime release notes

The ServiceNow® AI Workflow Factory Prime application contains products that enable you to discover, build, run, and extend on the ServiceNow AI Platform. See the following sections for release notes by version.

## About AI Workflow Factory Prime

-   Discover how processes work in your ServiceNow ecosystem using process and task mining, AI-driven process insights, and Automation Center.
-   Build and edit applications with agentic AI development tools such as Build Agent, Autonomous Engineer, and Developer Sandboxes.
-   Deploy, run, and govern custom applications at-scale with unlimited table capacity, embedded AI agents, centralized management for developers and apps, and faster query performance.
-   Extend your platform's automation to the desktop, so that AI agents and actions can carry work across applications, browsers, email, and systems on behalf of employees.

See  for more information.

## Activation and other requirements

-   **Activation information**

    Install AI Workflow Factory Prime by requesting it from the ServiceNow Store. Visit the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) to view all the available apps, and for information about submitting requests to the store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).

-   **Additional requirements**

    Some AI Workflow Factory Prime capabilities aren't yet available in regulated markets. Check your entitlements to determine whether you have access to AI Workflow Factory Prime capabilities.

## October 2026

AI Workflow Factory Prime was enhanced in October 2026 for the release of the Credit Dashboard.

### What's new

-   ****

    Explore your credit usage and trends with the AI Workflow Factory Prime Credit Dashboard. The Credit Dashboard is a standalone application available with AI Workflow Factory Prime entitlements that must be installed from the ServiceNow Store.


### What's changed

-   ****

    The AI Workflow Factory Prime Credit Dashboard doesn't populate capability data on initial install. Use the troubleshooting guide to resolve the issue.


### Plugin information

-   **New plugins**

    AI Workflow Factory Prime Credit Dashboard \(sn\_aiwf\_credit\): This plugin contains the Credit Dashboard, including credit, capability, and usage data.
