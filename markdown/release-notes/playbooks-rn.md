# Playbooks release notes

The ServiceNow® Playbook helps you automate complex business processes. See the following sections for release notes by version.

## About Playbook

-   Playbooks are structured, guided workflows that lead users, agents, or technicians through the steps required to complete a business process, such as case resolution or work order fulfillment.
-   Playbooks consist of sequential stages, each containing activities that can be manual tasks, automated actions, or guided decisions, ensuring consistency and conformance across records.
-   Benefits include eliminating the need to memorize processes, providing real‑time guidance, automating routine steps, and enabling administrators to update processes centrally, which applies to all users.
-   Playbooks support use cases across multiple domains.

See [Workflow Studio playbooks](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/build-workflows/workflow-studio-playbooks-landing.md) for more information.

## Activation and other requirements

-   **Activation information**

    The Playbook application comes with the Workflow Studio ServiceNow® Store app. Workflow Studio is part of the ServiceNow AI Platform® and is available by default. Get the latest Workflow Studio features by downloading the latest Workflow Studio app in the ServiceNow® Store, as well as related applications like Process Automation Content and Process Automation Experience Demo. The Playbook application can be downloaded for patch fixes.

    To use playbook generation features in Workflow Studio, download the ServiceNow Otto for Creator application.

-   **Upgrade information**

    After you upgrade to Brazil, update the Workflow Studio application in the ServiceNow® Store.

## Brazil Early Availability

This release introduces the ability to view conditional activities and the preferred execution path of playbooks.

### What's new

-   **[Ideal path for a playbookIdeal path for a playbook](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/build-workflows/ideal-path-for-playbook.md)**

    Use ideal path to identify the intended execution path or view upcoming work hidden behind conditions. Ideal Path enables playbook authors to define and visualize the preferred process route. The end users of a playbook gets runtime visibility into the expected workflow path, improving process clarity, usability, and observability.
