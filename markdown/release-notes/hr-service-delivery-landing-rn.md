# Case and Knowledge Management release notes

Standardize how you document, interact with, and fulfill employee inquiries and requests using ServiceNow Case and Knowledge Management.

## About Case and Knowledge Management

-   Create, manage, and resolve HR cases efficiently — Create, manage, and resolve HR cases from a centralized platform for benefits, payroll, and talent acquisition.
-   Standardize documentation and service delivery — Build a searchable knowledge base to standardize HR processes and ensure consistent service delivery.
-   Optimize agent productivity — Equip HR agents with tools to prioritize cases, access knowledge articles, and resolve inquiries faster.
-   Route and track requests in real time — Route employee requests to the right agents based on skills and track case status in real time.
-   Leverage AI to improve efficiency — Use ServiceNow Otto AI to help HR agents and managers handle routine inquiries, suggest knowledge articles, and close cases faster.

-   **[Brazil Early Availability](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/hr-service-delivery-rn-2026-09.md)**  
The Brazil release introduces enhanced protections for read‑only fields across the ServiceNow AI Platform®. These changes include a new “read\_only\_option” field with granular control levels, including “strict\_read\_only” and “client\_script\_modifiable". The changes occur in the back end and maintain backward‑compatible behavior. This update helps strengthen your instance security while preserving the flexibility you need. Refer to [KB2718122](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB2718122) for additional technical details on how to identify affected fields and adjust their settings. For more information about granular read-only security options, see [Configuring read-only security options](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/read-only-option.md).
