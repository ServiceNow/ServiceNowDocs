# App Engine for ERP release notes

The ServiceNow® App Engine for ERP application contains rapid deployment packs that provide templates for specific business processes in enterprise ERP workflows that you can use as a starting point.App Engine for ERP is a new application in the Australia release.

## App Engine for ERP highlights for the Australia release

-   Manage the full life cycle of master data records across business domains through the MDM Orchestrator.
-   Review and act on transactions, master data records, and month-end journal entries from a single location through the Centralized Approvals Hub.
-   Validate and authorize manual journal entries before they post to the general ledger through the Journal Entry Approval Portal.
-   Automate data verification, duplicate detection, and risk profiling with the AI Agents Framework built on Now Assist.

See  for more information.

**Important:** App Engine for ERP is available in the ServiceNow Store. For details, see the "Activation information" section of these release notes.

## App Engine for ERP features

-   **MDM Orchestrator**

    Manage the full life cycle of master data management requests across six business domains — Customer, Business Partner, Material, Location, Cost center, and BOM — by using the MDM Orchestrator. Submit create, update, activate or deactivate, and bulk-upload requests, monitor request metrics on a dashboard, and review past submissions from the My Requests page.

-   **Centralized Approvals Hub**

    Oversee and act on ERP-bound data requests from a single command center by using the Centralized Approvals Hub. Monitor synchronization volume and daily trends on the executive dashboard, view full request details, and approve or reject individual records.

-   **Journal Entry Approval Portal**

    Validate, audit, and authorize manual journal entries before they post to the general ledger by using the Journal Entry Approval Portal. Track processing counters and approval scores by journal type, and manage entries through Pending and History queues with type-based filtering.

-   **AI Agents Framework**

    Automate verification and oversight across financial and master data domains by using the AI Agents Framework. The framework includes agents for autonomous domain inquiry, fuzzy duplicate detection, Knowledge Graph policy auto-approval, Excel ledger structural validation, and historical risk assessment.
