# Content Understanding release notes

The ServiceNow® Content Understanding application replaces Now Assist in Document Intelligence. It brings multimodal generative AI to document and image processing, extracting key data, answering natural-language questions, and generating summaries from unstructured text, tables, and images.

## Content Understanding highlights for the Australia release

-   Capture structured data from documents, review extracted values, and integrate the results into downstream processes.
-   Extract information, answer questions, and summarize documents and images to accelerate agentic workflows.
-   Use a multimodal tool to process documents and images within custom skills.
-   Enable document chat in Virtual Agent.
-   Summarize attached files linked to records on a large scale to facilitate comprehension and decision-making.

See [Content Understanding](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/content-understanding-landing.md) for more information.

**Important:** Content Understanding is available in the ServiceNow Store.

## Content Understanding features

-   **[Extract information from documents](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cu-extract-information-from-document.md)**

    Capture structured data from documents, validate extracted values in an intuitive review interface, and integrate the results into downstream processes.

-   **[Content insights AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cu-content-insights-ai-agent.md)**

    Extract information, answer questions, and summarize documents and images to accelerate agentic workflows.

-   **[Attachment Summarization](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/attachment-summarization.md)**

    Read and summarize the content of uploaded documents, extract key information in near real-time, and significantly reduce manual triage time for agents.
