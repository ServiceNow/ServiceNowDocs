# Advanced Approval Management AI release notes

The ServiceNow® Advanced Approval Management AI application enables advanced approval users to manage quote approvals using natural language requests in Model Context Protocol \(MCP\)-compatible clients, without opening a ServiceNow instance. Advanced Approval Management AI is a new application in the Australia release.

## About Advanced Approval Management AI

-   Enable approval requesters and approvers to access quote approval information and perform approval actions directly from MCP-compatible clients.
-   Use natural language in an MCP client to get details on quote approval status and perform tasks such as submitting approval requests or approving or rejecting approval requests.

See [Advanced Approval Management AI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/explore-advanced-approval-mgmt-ai.md) for more information.

## Activation and other requirements

**Important:** Advanced Approval Management AI is available in the ServiceNow Store. For details, see the "Activation information" section of these release notes.

## Australia

The ServiceNow® Advanced Approval Management AI application enables advanced approval users to manage quote approvals using natural language requests in Model Context Protocol \(MCP\)-compatible clients, without opening a ServiceNow instance. Advanced Approval Management AI is a new application in the Australia release.

### What's new

-   **Using MCP tools as a requester**

    As a requester, you can use the MCP client to:

    -   Get quote details
    -   Track approval status by viewing approval history for a quote
    -   Preview approval routing for a quote
    -   Add an ad-hoc approver
    -   Submit a quote for approval
    -   Recall an approval request for a quote
-   **Using MCP tools as an approver**

    As an approver, you can use the MCP client to:

    -   Get quote details
    -   Track approval status by viewing approval history for a quote
    -   View pending approval requests
    -   Add an ad-hoc approver
    -   Approve or reject an approval request

### Plugin information

-   **New plugins**

    The following plugin is new in Australia:

    Advanced Approval Management AI \(com.sn\_adv\_apr\_mgmt\_ai\): MCP server tools for managing advanced approval requests by using natural language in the conversational interface of an MCP client.
