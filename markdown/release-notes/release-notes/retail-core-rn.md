# Retail Core release notes

The ServiceNow® Retail Core application empowers frontline managers and associates to seamlessly manage day-to-day store operations by automating tasks, resolving issues quickly with self-service, and freeing up time to better serve customers. Retail Core was enhanced and updated in the Yokohama release.

## About Retail Core

Use the Retail Portal for an optimized and streamlined portal experience within your retail organization.

See [Retail](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/retail-industry/rahi-retail-operations-overview.md) for more information.

## Activation and other requirements

**Important:** Retail Core is available in the ServiceNow Store. For details, see the "Activation information" section of these release notes.

-   **Activation information**

    Install Retail Core by requesting it from the ServiceNow Store. Visit the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website to view all the available apps and for information about submitting requests to the store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).
