# Ethoca Spoke

The Ethoca Spoke connects ServiceNow® to Ethoca APIs, enabling customers to handle dispute management and fraud prevention more efficiently and securely, reducing the need for chargebacks. Ethoca Spoke was enhanced and updated in the Yokohama release.

## About Ethoca Spoke

Leveraging Ethoca Spoke actions enable issuers to:

-   Resolve disputes efficiently at a faster pace, reducing chargeback costs
-   Enhance collaboration between stakeholders, thus improving the customer experience

See [Ethoca spoke](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/integrate-applications/ethoca-spoke.md) for more information.

## Activation and other requirements

**Important:** Ethoca Spoke is available in the ServiceNow Store. For details, see the "Activation information" section of these release notes.

-   **Activation information**

    Install Ethoca Spoke by requesting it from the ServiceNow Store. For cumulative release notes information for all released apps, see the [ServiceNow Store version history release notes](https://www.servicenow.com/docs/r/store-release-notes/sn-store-release-notes.html).

## Yokohama

The Ethoca Spoke connects ServiceNow® to Ethoca APIs, enabling customers to handle dispute management and fraud prevention more efficiently and securely, reducing the need for chargebacks. Ethoca Spoke was enhanced and updated in the Yokohama release.

### What's changed

-   **[Ethoca spoke actions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/integrate-applications/ethoca-spoke.md)**

    The following Ethoca Spoke actions were built for Ethoca Alerts API in version 3.0.0:

    -   Create Transaction Alert
    -   Look up Transaction Alert Status by Batch
    -   Look up Alert Status
    -   Look up Alert Outcome by Batch Stream

        **Note:** To enable the Look up Alert Outcome by Batch Stream action, install the ServiceNow IntegrationHub Action Template - Data Stream \(com.glide.hub.action\_type.datastream\) plugin.
