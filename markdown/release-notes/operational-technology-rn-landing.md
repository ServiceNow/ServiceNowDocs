# Operational Technology release notes

Operational Technology has new and updated features in the Brazil release.

-   **[Operational Technology Discovery release notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/ot-discovery-rn.md)**  
The ServiceNow® Operational Technology Discovery product increases the visibility of OT devices in your system. See the following sections for release notes by version. This product is currently supported for the Brazil release, but it will be deprecated in a future release.
-   **[Operational Technology Setup release notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/operational-technology-setup-rn.md)**  
The ServiceNow® Operational Technology \(OT\) Setup application to help configure your OT applications. See the following sections for release notes by version.
-   **[Service Graph Connector Integration for Claroty CTD release notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/service-graph-connector-for-claroty-ctd-rn.md)**  
The ServiceNow® Service Graph Connector Integration for Claroty CTD application integrates Claroty Continuous Threat Detection \(CTD\) with the ServiceNow Operational Technology Manager. This application is currently supported for the Brazil release, but it will be deprecated in a future release. See the following sections for release notes by version.
-   **[Vulnerability Response Integration with Claroty CTD release notes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/release-notes/vulnerability-response-integration-with-claroty-ctd-rn.md)**  
The ServiceNow® Vulnerability Response Integration with Claroty CTD application uses vulnerability data imported from Claroty CTD to enable risk-based action within the production process. This application is currently supported for the Brazil release, but it will be deprecated in a future release. See the following sections for release notes by version.
