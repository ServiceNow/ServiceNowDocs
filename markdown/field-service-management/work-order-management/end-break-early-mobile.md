# End a break early in the mobile agent app

End a break before its scheduled end time in the ServiceNow Agent application.

## Before you begin

Role required: wm\_agent

## About this task

If your organization's Auto-status breaks setting is off and end-break-early is enabled, you can end an in-progress break before its scheduled end time.

## Procedure

1.  Open the ServiceNow Agent application and tap the break that's in progress.

2.  Tap **End break**.

3.  Tap **Confirm**.
