# Extend a break in the mobile agent app

Extend a break that's in progress in the ServiceNow Agent application, up to your organization's configured limit.

## Before you begin

Role required: wm\_agent

## About this task

While a break is in progress, you can extend it if you need more time.

## Procedure

1.  Open the ServiceNow Agent application and tap the break that's in progress.

2.  Tap **Extend break**.

3.  Enter the number of additional minutes.

4.  Tap **Submit**.
