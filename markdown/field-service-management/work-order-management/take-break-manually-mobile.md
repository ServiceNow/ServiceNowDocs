# Take a break manually in the mobile agent app

Manually record a break in the ServiceNow Agent application when your organization's Auto-status breaks setting is off.

## Before you begin

Role required: wm\_agent

## About this task

If your organization's Auto-status breaks setting is off, breaks don't start or end automatically. You must manually record when you took a break.

## Procedure

1.  Open the ServiceNow Agent application and tap **My schedule**.

2.  Tap the break that you want to take.

3.  Tap **Take Break**.

4.  Enter the actual start time you took the break.

    If a break window is set, the time must fall within the break window. If no break window is set, the time must fall within your shift.

5.  Tap **Confirm**.
