# Configure event colors

Change the border and background color of an event so it matches your company's colors or stands out on the team calendar.

## Before you begin

Role required: wm\_admin, maint

## About this task

An event indicator on the team calendar has 2 parts:

-   Border color: the outline that surrounds the event indicator.
-   Background color: the fill that shows inside the border of the event indicator.

## Procedure

1.  Select the **All** menu, type `sn_shift_planning_event.list`, and press **Enter**.

2.  Find the event that you want to change the color for.

3.  Update the fields:

    -   **Background color** — select the eyeglass icon next to **Background color** and choose a color.
    -   **Border color** — select the eyeglass icon next to **Border color** and choose a color.
4.  Select **Update**.
