# Add a break to a shift

Add a break to a shift to give technicians scheduled rest time within their shift, without leaving the schedule view.

## Before you begin

Role required: wm\_manager.

## Procedure

1.  Navigate to **Workspaces** &gt; **Manager Workspace**.

2.  Select **Schedule**.

3.  Select the shift that you want to add a break to.

4.  Select the **Edit** \[Omitted image "edit-schedule.png"\] Alt text: Edit icon, then choose an option.

5.  Select **Add break**.

6.  On the form, fill in the fields.

7.  Select **Save**.
