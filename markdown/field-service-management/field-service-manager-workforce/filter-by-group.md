# Filter the team calendar by assignment group

Filter which agents appear on the team calendar by assignment group.

## Before you begin

Role required: wm\_agent, wm\_basic, or wm\_manager

## About this task

Whenever you open the team calendar, agents in the assignment groups saved as your default are displayed. Select **Restore default** to return the filter to the assignment groups saved in Settings. Select **Clear all** to remove the current selection. To limit the filter to one assignment group at a time, in Settings, turn on **Single select assignment group**. With this setting on, selecting a different group replaces your previous selection. If no default assignment group is saved in Settings, the calendar displays all assignment groups.

## Procedure

1.  Navigate to **Workforce**.

    -   Managers, navigate to **All** &gt; **Field Service** &gt; **Manager** &gt; **Workforce**.
    -   Agents, navigate to **All** &gt; **Field Service** &gt; **Agent** &gt; **Workforce**.
    -   If Workforce Optimization is installed and activated, managers can navigate to **Workspaces** &gt; **Manager Workspace** &gt; **Workforce**.
2.  Select the assignment group filter above the calendar.

3.  Select one or more assignment groups from the list.

4.  Select **Apply**.

    The calendar updates to show agents in the selected assignment groups.
