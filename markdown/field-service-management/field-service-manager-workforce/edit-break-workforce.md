# Edit or delete a break

Edit or delete a break to keep a shift's schedule accurate as break needs change, without recreating the shift.

## Before you begin

Role required: wm\_manager.

## Procedure

1.  Navigate to **Workspaces** &gt; **Manager Workspace**.

2.  Select **Schedule**.

3.  Select the shift that you want to edit.

4.  Select the **Edit** \[Omitted image "image.edit-schedule"\] Alt text: edit icon, then choose an option.

## What to do next

Updating or deleting a break that affects a scheduled task recalculates the task's estimated end time and updates the related work order, whether the break is being embedded or removed. This works the same whether you make the update from Manager Workforce, Manager Workspace Teams calendar, Manager mobile, or the AI agent. Lunch breaks are indicated on the calendar with a fork and knife icon, with a fraction showing breaks taken versus scheduled when more than one occurs during a task, and an X if a technician misses a scheduled break.
