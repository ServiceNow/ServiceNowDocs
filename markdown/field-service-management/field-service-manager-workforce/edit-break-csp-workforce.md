# Edit or delete a break from the CSP in Workforce

Edit or delete a break from the contextual side panel in Workforce so you don't have to navigate out of the calendar.

## Before you begin

Role required: wm\_manager.

## Procedure

1.  Navigate to **Workspaces** &gt; **Manager Workspace**.

2.  Select **Workforce**.

3.  Select the break that you want to edit.

4.  Select the **Overflow actions** icon in the CSP.

5.  Choose from the following.
