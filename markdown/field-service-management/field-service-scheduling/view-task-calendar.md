# Viewing tasks or events on the calendar

Dispatchers can view any task on the calendar to navigate to the scheduled time and date of the task they chose.

When you select **View on calendar**, the calendar displays the agent assigned to the task in the **Added resources** section at the top. You can view up to 10 tasks simultaneously.

You can view events assigned to a single person only. **View on calendar** is unavailable for events with multiple attendees.

For repeating events, such as scheduled lunch breaks, the calendar displays the specific occurrence you selected. For example, if you select a lunch event scheduled for November 21 from a daily recurring series, the calendar shows the November 21 occurrence.

If you have the calendar sorted in a non-default way, when you select View on calendar the sort changes to default.

Dispatchers can view tasks on the calendar in any of the following states:

-   Assigned
-   Accepted
-   Scheduled
-   Work in Progress
-   Closed complete

Scheduling a work order task over an agent's planned break automatically adjusts the task to accommodate the break. The break embeds into the task when it starts at or after the task start time and falls within the task duration. A break that has already started is not embedded. Lunch breaks are indicated on the calendar with a fork and knife icon. If more than one break is scheduled during a task, a fraction on the break indicator shows the number of breaks taken vs. scheduled \(for example, 1/2\). Technicians must mark their breaks as taken; if a technician misses a scheduled break, an X shows on the break indicator.

Only managers can create and manage breaks. For more information see, [Add schedule breaks to a shift](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/field-service-management/field-service-manager-workforce/add-break-shift-wfo-fsm.md).
