# Create an operational note

Create an operational note for a user, crew, equipment, or work order task so that other dispatchers can see it in Dispatcher Workspace.

## Before you begin

Role required: wm\_dispatcher

## Procedure

1.  Navigate to **All** &gt; **Field Service** &gt; **Dispatching** &gt; **Dispatcher Workspace**.

2.  Select **Dispatcher Workspace**.

3.  Open the note form from one of these places:

    -   The overflow menu on a resource card, select **Open operational note**.
    -   The overflow menu on a work order task card, select **Open operational note**.
    -   Right-click a calendar event, select **Open operational note**.
4.  Enter a description.

    The description is required. It is plain text and can be up to 4,000 characters.

5.  Select the effective start and end dates.

    The start date defaults to today, and the end date defaults to the start date. A note covers whole calendar days. An end date earlier than the start date isn't allowed.

6.  Select the reference type, then select the record.

7.  Select **Submit**.

    If the dates overlap another note for the same record, the note isn't saved, and a message tells you that a note already exists on that date.
