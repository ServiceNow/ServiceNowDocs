# Apply a quick task filter

Filter the tasks in the task panel using criteria such as skill, parts, and SLA breach.

## Before you begin

Role required: wm\_dispatcher

## About this task

A quick task filter narrows the task panel list to only the tasks that match your criteria. Tasks that don't match are removed from the list until the filter is cleared.

## Procedure

1.  Navigate to **All** &gt; **Field Service** &gt; **Dispatching** &gt; **Dispatcher Workspace**.

2.  Select **Dispatcher Workspace**.

3.  Open the quick task filter using one of the following:

    -   Select the filter icon next to the task search field.
    -   In the task search field drop-down, select **Quick Filters**.
4.  Select a criterion, an operator, and a value.

5.  Choose from the following.

    |Option|Description|
    |------|-----------|
    |**Add a condition**|Select **+ Add Filter** to add another condition, and select **AND** or **OR** to determine how the conditions combine.|
    |**Save as default**|Select **Save as default** to apply this filter automatically each time you open Dispatcher Workspace.|

6.  Select **Filter task panel**.

    To apply the same filter to the calendar as well, select the drop-down arrow next to **Filter task panel** and select **Filter task panel and calendar** instead.


## Result

The task panel list updates to show only tasks that match the filter.
