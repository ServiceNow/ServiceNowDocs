# Manage operational notes

Edit or delete an operational note.

## Before you begin

Role required: wm\_dispatcher

## About this task

Any dispatcher can edit or delete any operational note, including notes that another dispatcher created.

If auto-refresh is on, created and deleted notes appear in the workspace without a page refresh. Changes to an existing note appear after you refresh the page or reopen the note.

## Procedure

1.  Navigate to **All** &gt; **Field Service** &gt; **Dispatching** &gt; **Dispatcher Workspace**.

2.  Select **Dispatcher Workspace**.

3.  Open the note.

4.  Edit the description or the dates.

5.  Select **Save &amp; close**.

6.  To delete the note, select **Delete**.

    The note is deleted immediately. No confirmation appears, and a deleted note can't be recovered.
