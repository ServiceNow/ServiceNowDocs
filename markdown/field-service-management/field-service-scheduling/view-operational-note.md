# View an operational note

View the operational note for a technician, crew, equipment, or work order task on the day you're viewing.

## Before you begin

Role required: wm\_dispatcher

## Procedure

1.  Navigate to **All** &gt; **Field Service** &gt; **Dispatching** &gt; **Dispatcher Workspace**.

2.  Select **Dispatcher Workspace**.

3.  Select the note \[Omitted image "note-icon-calendar.png"\] Alt text: icon on a resource or task row.

4.  To view the note for another day, change the calendar date.

    Only one note appears at a time, for the selected day.
