# Apply a quick calendar filter

Filter the tasks shown on the calendar using criteria such as skill, parts, and SLA breach.

## Before you begin

Role required: wm\_dispatcher

## About this task

A quick calendar filter grays out the tasks on the calendar that don't match your criteria. Matching tasks are unaffected. The quick calendar filter is only active in day and workday calendar views.

## Procedure

1.  Navigate to **All** &gt; **Field Service** &gt; **Dispatching** &gt; **Dispatcher Workspace**.

2.  Select **Dispatcher Workspace**.

3.  Select **Calendar filter** before the calendar.

4.  Select a criterion, an operator, and a value.

5.  Choose from the following.

    |Option|Description|
    |------|-----------|
    |**Add a condition**|Select **+ Add Filter** to add another condition, and select **AND** or **OR** to determine how the conditions combine.|
    |**Save as default**|Select **Save as default** to apply this filter automatically each time you open Dispatcher Workspace.|

6.  Select **Filter calendar**.


## Result

Tasks on the calendar that don't match the filter are grayed out.
