# Manage operational notes from the list

View all operational notes together in a list, and manage them from there.

## Before you begin

Role required: wm\_dispatcher

## About this task

The operational notes list shows notes for all records in the system, including users, crews, equipment, and work order tasks. Dispatcher Workspace can't show all notes together, so use this list to see them all.

## Procedure

1.  Navigate to **All** &gt; **CRM Workspace**.

2.  Select the **List**.

3.  Select **Dispatching** &gt; **Operational Notes**.

4.  Use the list to search, filter, and change dates on notes.

5.  To edit a note, open its record and edit it there.
