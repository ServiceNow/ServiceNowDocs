# Check a break in Dispatcher Workspace

Check whether a break on a work order task has been taken or is still planned, without leaving Dispatcher Workspace.

## Before you begin

Role required: wm\_dispatcher

## Procedure

1.  Navigate to **All** &gt; **Field Service** &gt; **Dispatching** &gt; **Dispatcher Workspace**.

2.  Select **Dispatcher Workspace**.

3.  Select the work order task that shows the break icon.

4.  In the contextual side panel, view the break's status.

    |Status|Description|
    |------|-----------|
    |**Planned**|The break hasn't been taken yet.|
    |**Taken**|The break has already been taken.|
