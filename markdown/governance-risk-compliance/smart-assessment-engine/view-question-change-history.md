# View question change history

View the logged history of response, justification, and flag state changes for a question in an assessment.

## Before you begin

Role required: sn\_smart\_asmt.actor, sn\_smart\_asmt.assessment\_reader, or sn\_smart\_asmt.assessment\_admin

## Procedure

1.  Navigate to your workspace and then to your list of assessments.

    Here’s an example of how to navigate to this list in the Compliance Workspace.

    1.  Navigate to **All** &gt; **Policy and Compliance** &gt; **Compliance Workspace**.
    2.  Select the tasks icon \[Omitted image "list-icon.png"\] Alt text:.
    3.  Select the **Control attestations** &gt; **Smart Assessments** on the left panel.
    4.  The smart assessments list is displayed.
2.  Select the assessment that contains the question you want to review.

3.  Open the question whose change history you want to view.

4.  Select the change history icon \[Omitted image "change-history-icon.png"\] Alt text: of the question card.

    The **Change history** panel opens, showing the logged changes for the response, justification, and flag state of the selected question, with the most recent change at the top.

5.  If a change is made to the question while the panel is open, select the refresh icon in the panel header to load the latest entries.

    The panel doesn't update automatically. It shows the latest changes only when you first open it and when you move to a different question.

6.  Select the close icon to close the panel.


## Result

The change history for the selected question is displayed, and you can review each logged change to its response, justification, and flag state.
