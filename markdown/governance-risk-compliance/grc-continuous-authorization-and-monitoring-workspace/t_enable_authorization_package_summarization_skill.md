# Reactivate Authorization package summarization skill

Activate or deactivate the authorization package summarization skill from the AI Admin Panel to control whether users can generate summaries.

## Before you begin

Role required: CAM GenAI User

Before you begin:

-   You must have the admin role to access the Now Assist Admin Panel.
-   The GRC Shared Gen AI must be installed on your instance.

## About this task

The authorization package summarization skill comes pre-activated when the plugin is installed. Use this procedure to reactivate it if it was previously disabled.

## Procedure

1.  Navigate to **All** &gt; **Admin Center** &gt; **AI Admin Hub**.

2.  On the **AI Skills** tab, navigate to **Technology** &gt; **Risk &amp; Sustainability**.

    The skills applicable to **Risk &amp; Sustainability** are displayed.

3.  Search for or locate **Authorization package summarization** in the skills list.

4.  To deactivate the skill, select the **Deactivate skill** button on the skill card.

5.  To reactivate the skill, select the **Activate skill** button on the skill card.

    The skill follows the standard activation process used for all AI skills.

6.  Review the skill configuration details on each tab, and select **Save and continue**.

7.  On the **Review and activate** tab, verify the full configuration and select **Activate**.

8.  Select **Return to Risk &amp; Sustainability** or close the dialog.

9.  Select **Done**.

    You’re redirected to the **AI Skills** home page.
