# Use ServiceNow Otto to analyze linked documents

Use ServiceNow Otto to summarize documents, ask questions, and generate audio summaries without manually reviewing every page.

## Before you begin

Role required:

-   sn\_irm\_cont\_auth.system\_owner
-   sn\_irm\_cont\_auth.info\_system\_sec\_officer
-   sn\_irm\_cont\_auth.authorization\_official
-   sn\_irm\_cont\_auth.info\_system\_sec\_manager
-   sn\_irm\_cont\_auth.admin
-   sn\_irm\_cont\_auth.information\_owner
-   sn\_irm\_cont\_auth.sec\_control\_assessor
-   sn\_irm\_cont\_auth.system\_user

In general, any role with write access to the record can add, edit, or modify the docs.

**Note:** You can add documents only when the record is in an active state. Inactive records don't allow changes to linked documents.

-   You have opened a linked document \(PDF or Word format\) in an authorization package or engagement
-   SN Otto for Document Management and SN Otto for Document Voice are installed.
-   Smart Docs and Voice Assist for Docs skills are activated in your instance by an administrator.

## About this task

ServiceNow Otto helps you quickly understand linked documents without reading every page:

-   **Document summarization:** Automatically summarize the entire document or specific sections
-   **Text questions:** Ask specific questions about the document and receive AI-generated answers based on the content
-   **Audio summaries:** Generate spoken audio summaries
-   **Voice questions:** Ask questions using voice input and receive answers

## Procedure

1.  In the authorization package or engagement, open the **Documents** side panel.

2.  Select a document to open it in the document viewer.

    The document opens in a preview pane. At the top of the document viewer, you will see an **Ask Otto** option.

3.  Select the **Ask Otto** from the menu on the top to open the ServiceNow Otto panel.

    ServiceNow Otto panel appears on the right of the screen. Wait for it to analyze the document.

4.  After the document analysis is complete, choose an action from the panel:

    1.  Select the **Summarise the document** option to generate an AI summary of the entire document.

        The summary appears in the panel, highlighting the main points and key information.

    2.  Select the **Generate Frequently Asked Questions** option to automatically generate common questions that readers typically ask about this type of document, along with answers drawn from the content.

    3.  Select the **Answer questions about the document** option to ask a specific question in the text field and press Enter.

    4.  Alternatively, you can type or paste a specific question.

    5.  To close the panel, select the X button.

5.  Select **Show Voice Assist** from the menu on the top to enable voice-based interactions.

    Voice-Assist panel appears on the right.

    1.  Select **Generate audio summary** to generate an audio summary of the document, and play it when it is ready.

    2.  Select **Start Voice Q&amp;A** to ask your question.

        Voice-Assist transcribes your voice input and provides an answer.

        To close Voice-Assist, select **Hide Voice Assist** from the top bar.


## Result

Review the summaries and voice summaries in the ServiceNow Otto panel. Some answers generated by AI might not be accurate. Always verify important information against the original document.
