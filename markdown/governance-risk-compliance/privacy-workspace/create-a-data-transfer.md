# Create a data transfer

Record a data transfer directly on a processing activity if it wasn't captured as part of a hierarchy relationship.

## Before you begin

Role required: sn\_privacy.analyst

## Procedure

1.  Navigate to **Workspaces** &gt; **Privacy Workspace**.

2.  Select the List icon \[Omitted image "ListsIcon.jpg"\] Alt text:.

3.  In the **Lists** tab, navigate to **Processing activities** &gt; **All processing activities**.

4.  Open the processing activity.

5.  Navigate to **Regulatory details** &gt; **Data transfers**.

6.  Select **Add**.

7.  In the Add data transfer form, fill in the fields.

    |Field|Description|
    |-----|-----------|
    |From location|Location from where the data is being transferred.|
    |To location|Location to where the data is being transferred.|
    |Transfer mechanism|Legal safeguard that permits the cross-border data transfer. For example, `Binding Corporate Rules (BCRs)`, `Standard Contractual Clauses (SCCs)`.|
    |Description|Description of the data transfer.|

8.  Select **Save**.


## Result

The data transfer record appears in the **Regulatory details** &gt; **Data transfers** tab of the processing activity.
