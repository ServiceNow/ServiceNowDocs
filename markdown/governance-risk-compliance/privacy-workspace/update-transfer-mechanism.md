# Manage transfer mechanisms in the Privacy Workspace

Add or update the existing transfer mechanisms in your Privacy Management application, so that privacy analysts can add them to data transfer records.

## Before you begin

Role required: sn\_privacy.manager

## Procedure

1.  Navigate to **Workspaces** &gt; **Privacy Workspace**.

2.  Select the List icon \[Omitted image "ListsIcon.jpg"\] Alt text:.

3.  In the **Lists** tab, navigate to **Privacy elements** &gt; **Transfer mechanisms**.

    1.  To add a new transfer mechanism, select **New**.

    2.  To update an existing transfer mechanism, select the record, and edit the details.

4.  Select **Save**.
