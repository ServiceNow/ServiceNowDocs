# Add a transfer mechanism to a data transfer record

Assign a transfer mechanism to a data transfer record to document the legal safeguard that permits the transfer of personal data.

## Before you begin

Role required: sn\_privacy.analyst

## About this task

A data transfer record generated from a hierarchy relationship does not have a transfer mechanism assigned by default. Review each data transfer record and assign the mechanism that provides the legal basis or safeguard for the transfer.

**Note:** If a transfer mechanism is not available for selection, a privacy manager with the sn\_privacy.manager role has to add it in the Privacy Workspace. For steps, see [Manage transfer mechanisms in the Privacy Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/governance-risk-compliance/privacy-workspace/update-transfer-mechanism.md).

## Procedure

1.  Navigate to **Workspaces** &gt; **Privacy Workspace**.

2.  Select the List icon \[Omitted image "ListsIcon.jpg"\] Alt text:.

3.  In the **Lists** tab, navigate to **Processing activities** &gt; **All processing activities**.

4.  Open the processing activity.

5.  Navigate to **Regulatory details** &gt; **Data transfers**.

6.  In the **Transfer mechanism** column, double-click the respective cell to select the applicable transfer mechanism for that data transfer record.

    For a list of transfer mechanisms in Privacy Management, see [Transfer mechanisms](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/governance-risk-compliance/privacy-workspace/transfer-mechanisms.md).

7.  Select **Save**.
