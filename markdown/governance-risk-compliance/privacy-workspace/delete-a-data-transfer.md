# Delete a data transfer

Delete a data transfer record from a processing activity.

## Before you begin

Role required: sn\_privacy.analyst

## About this task

Deleting a data transfer record from the processing activity does not delete the hierarchy relationship that generated it, if any.

## Procedure

1.  Navigate to **Workspaces** &gt; **Privacy Workspace**.

2.  Select the List icon \[Omitted image "ListsIcon.jpg"\] Alt text:.

3.  In the **Lists** tab, navigate to **Processing activities** &gt; **All processing activities**.

4.  Open the processing activity.

5.  Navigate to **Regulatory details** &gt; **Data transfers**.

6.  Select the data transfer records you want to delete, then select **Remove**.

7.  Select **Remove** in the confirmation dialog box.
