# Add a third-party element record to an engagement

Link a third-party element to an engagement by using the Third-party Risk Management application. After linking the element to an engagement, the third-party risk manager and internal stakeholders can assess it as part of the due diligence process.

## Before you begin

Role required: sn\_vdr\_risk\_asmt.vendor\_assessor or sn\_vdr\_risk\_asmt.vendor\_risk\_manager

## About this task

An element created from an engagement's **Elements** tab is linked to that engagement automatically. An element created from the third-party record isn't linked to any engagement by default and must be linked before it can be assessed.

When you assess an element or assign work on it, the system considers the primary contacts from all linked engagements, not just the engagement you're viewing. An element can be linked to multiple engagements.

For more information, see [Monitoring third-party elements](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/third-party-risk-management/tprm-monitor-tp-elements.md), [Create a third-party element](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/third-party-risk-management/tprm-tp-element-create.md), [Manage elements in the grid](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/third-party-risk-management/tprm-elements-grid-manage.md), and [Third-party portal contact roles and permissions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/third-party-risk-management/tprm-portal-contact-roles.md).

## Procedure

1.  Navigate to **Workspaces** &gt; **Vendor Management Workspace**.

2.  Select the list icon \[Omitted image "ws-list-icon.png"\] Alt text: and then navigate to **Third parties** &gt; **All engagements**.

3.  Select the engagement that you want.

4.  Navigate to the **Elements** tab of the engagement.

5.  Select **Add** to link the third-party element to the engagement.

    The third-party element is active and available for assessment.
