# Complete an element collection task

Element collection tasks let internal users add AI use case elements and let third-party or engagement contacts add elements on behalf of the third party in the Third-party Risk Management application.

## Before you begin

You must be assigned as the respondent on an internal collection task, or as the contact on an external collection task. The internal task respondent receives the internal task responder role.

## About this task

The due diligence process can create a task for an internal user or a third-party or engagement contact to add third-party elements. The configuration of your organization's due diligence process determines when element collection tasks are created. The following two scenarios use this process:

-   An internal task assigned to the due diligence requester to add AI use case elements, created when the requester selects **AI assets involved** on the due diligence request.
-   An external task assigned to a third-party or engagement contact to add more elements, created when the due diligence request owner selects **Start collection**.

The **Manage elements** button appears only on tasks that are collection-type tasks.

## Procedure

1.  Open the task.

    -   If you're completing an internal task, navigate to GRC tasks in the Employee Center and select the task.
    -   If you're completing an external task, log in to the third-party portal and select the task.
2.  Select **Manage elements**.

    The Elements grid opens, embedded in the task.

3.  Add or edit elements as needed.

    For more information on adding and editing elements, and linking AI models to AI use case elements, see [Manage elements in the grid](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/third-party-risk-management/tprm-elements-grid-manage.md).

4.  Select **Resolve Task**.

    The task moves to the Review state so the due diligence request owner or assessor can review the added elements.


## What to do next

For AI use case internal tasks, the due diligence request owner can proceed only after both this task and the Inherent Risk Questionnaire \(IRQ\) internal assessment are complete.

For more information, see [Monitoring third-party elements](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/third-party-risk-management/tprm-monitor-tp-elements.md).

After the task is resolved and transitions to Review state, the assessor or due diligence request owner can review the elements that were added or edited during the collection phase. The task remains in Review state until the assessor closes it. If revisions are needed, the task can be reopened and reassigned to the respondent.
