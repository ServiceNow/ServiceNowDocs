# Compare document versions

Track changes across document revisions collected during third-party assessments in the Document Management System. Use version comparison to review edits, deletions, and formatting changes between two Word document versions.

## Before you begin

Role required: sn\_vdr\_risk\_asmt.vendor\_assessor

The document must have at least two versions. Both versions must be Microsoft Word documents in the same format \(DOCX to DOCX or DOC to DOC\).

## Procedure

1.  Navigate to **Workspaces** &gt; **Vendor Management Workspace**, select the list icon \[Omitted image "ws-list-icon.png"\] Alt text: and then navigate to **All Documents**.

2.  Select the document record that you want and then the **Versions** tab.

3.  Select **Compare**.

4.  Select the **Source version** and the **Target version** you want to compare, and then select **Compare**.

    A new **Compare** tab opens, showing the comparison summary: Total changes, Edited, Deleted, and Format changes.

5.  Review the changes.

    To hide the redlines, select **Hide redlines**.

6.  Select **Download redlined document** to download the document with tracked changes.
