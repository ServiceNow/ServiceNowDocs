# Issue modules in Business Continuity Workspace

Browse and create issues from dedicated modules in the List view of the Business Continuity Workspace without opening a specific plan, event, or exercise.

The List view in the Business Continuity Workspace includes an **Issues** module, an **Issue remediation tasks** module, and an **Issue triage** module, alongside the modules for BIAs, plans, exercises, and crisis events. Use these modules to see the issues, remediation tasks, and triage records associated with your continuity plans and events in one place. You can view all records without opening each plan or event individually.

The following example shows the Issues and Issue remediation tasks modules in Business Continuity Workspace list view.

\[Omitted image "issue-list-groups-in-workspace.png"\] Alt text: Lists panel in the Business Continuity Workspace showing the Issues and Issue remediation tasks modules, each broken out by state.

## Issues module

The **Issues** module lists issues associated with your plan and event records, filtered by the **New**, **In progress**, and **Closed** states. Select one of these states to see the matching issues, or select **New** in the list toolbar to create an issue directly from this module.

## Issue remediation tasks module

The **Issue remediation tasks** module lists the remediation tasks created against those issues, filtered by the **Open** and **Closed** states.

## Issue triage module

The **Issue triage** module lists issue triage records that are classified as BCM, filtered by **Unassigned** and **All**. This module requires installation of the GRC: Advanced Core application.
