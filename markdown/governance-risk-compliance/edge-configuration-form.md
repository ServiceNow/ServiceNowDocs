# Connector configuration form

Use the Connector configuration form to view and configure the label, tooltip, and default Connector type for the connector between the selected nodes.

## Connector configuration record form

|Field|Description|
|-----|-----------|
|Nexus map configuration|Nexus map configuration record for which the connector is being configured. For example, OpRes resilience map UI \(Bottom to Top\).|
|Node relationship configuration|Node relationship configuration for which the connector is being configured. For example, Entity ← Entity.|
|Source table|Source table for which the connector is being configured. For example, Entity \[sn\_grc\_profile\].|
|Target table|Target table for which the connector is being configured. For example, Entity \[sn\_grc\_profile\].|
|Relationship table|Relationship table for the source and target tables. For example, Entity hierarchy \[sn\_grc\_m2m\_profile\_profile\]|
|Active|Option to mark the Connector configuration as active.|
|Label|Label to be displayed for the Connector configuration once the conditions are satisfied, for example, Class.|
|Tooltip|Tooltip to be used for the Connector configuration, for example, Domain created by.|
|Default Connector type|Default Connector type for the Connector configuration, for example, Solid.|
