# Cancel an approval

Cancel a pending approval request on an issue or remediation task.

## Before you begin

An approval request must be pending.

Role required: sn\_grc\_appr.approver

## Procedure

1.  Open the issue or remediation task.

2.  Open the pending approval request.

3.  Select **Cancel**.

4.  Confirm the cancellation.


## Result

The approval request is cancelled. If the request was for a state change, the record remains at its current state until a new approval request is submitted and approved.
