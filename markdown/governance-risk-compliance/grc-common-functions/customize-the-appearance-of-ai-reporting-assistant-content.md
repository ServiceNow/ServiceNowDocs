# Customize the appearance of AI for document designer

Configure properties that control the chart color palette and table size for content generated by the AI for document designer.

## Before you begin

Role required: sn\_grc\_doc\_design.admin

## Procedure

1.  In the filter navigator, enter `sys_properties_list.do`.

2.  In the System Properties page, search for `sn_doc_design_ai` in the Name column.

3.  Select the property you want to configure.

    |Property|Description|
    |--------|-----------|
    |sn\_doc\_design\_ai.chart\_default\_color\_scheme|Default chart color palette used in generated charts.|
    |sn\_doc\_design\_ai.table\_max\_columns|Maximum number of columns allowed in a generated table.|
    |sn\_doc\_design\_ai.table\_max\_rows|Maximum number of data rows included in a generated table, excluding the header row.|

4.  If the record opens in the Global application scope, switch to the AI for document designer scope.

5.  In the **Value** field, enter the new value for the property.

6.  Select **Update**.
