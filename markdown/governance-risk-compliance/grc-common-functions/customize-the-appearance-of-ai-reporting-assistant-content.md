# Customize the appearance of AI reporting assistant content

Configure properties that control the chart color palette and table size for content generated by the AI reporting assistant.

## Before you begin

Role required: sn\_grc\_doc\_design.admin

## About this task

**Note:**

When modifying system properties, if a message appears about the application scope, select **here** to be able to edit the record.

## Procedure

1.  In the filter navigator, enter `sys_properties_list.do`.

2.  On the System Properties page, in the **Name** field, enter the property name for the customization you want to make and select it.
