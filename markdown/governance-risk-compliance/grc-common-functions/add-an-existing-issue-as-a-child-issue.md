# Add an existing issue as a child issue

Add a standalone issue as a child of an existing parent issue directly from the parent record.

## Before you begin

A parent issue must already exist.

Role required: risk\_admin, risk\_manager, or sn\_risk.user

## Procedure

1.  On the parent issue, open the **Child Issues** related list.

2.  Select **Add**.

3.  In the Add Child Issues dialog, select the check box next to each issue you want to add.

4.  Select **Add**.


## Result

The selected issues become children of the parent, following the group's existing **Management method**.
