# Table configuration fields

Fields on the Table configuration form, used to create an issue layout.

These fields appear on the Table configuration form when creating a new issue layout from the Table configurations list.

|Field|Description|
|-----|-----------|
|**Record view configuration**|Optional. An existing record view configuration to base this layout on.|
|**Name**|A name for the layout.|
|**Table**|The table this layout applies to.|
|**Application**|The application scope for the layout. Defaults to Global.|
|**Active**|Whether the layout is available to select. Selected by default.|
|**View**|The view this layout uses.|
