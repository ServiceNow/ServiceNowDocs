# Configure business domain roles for Document designer

Configure role mappings on a business domain to control which users can select the domain when importing data into a Microsoft Word document.

## Before you begin

A business domain must be available. For more information, see [Create a business domain](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/grc-common-functions/create-a-business-domain.md).

Role required: sn\_business\_domain.admin

## Procedure

1.  In the Filter navigator, enter `sn_grc_business_domain.LIST`.

2.  In the Business domains page, select the business domain record you want to configure.

3.  In the Role mappings related list, select **New**.

4.  In the Context field, select **Document designer**.

5.  Add the required roles.

    1.  In the Roles field, select the edit icon.

    2.  Select the required roles from the available list.

    3.  Select **Done**.

6.  Select **Submit**.
