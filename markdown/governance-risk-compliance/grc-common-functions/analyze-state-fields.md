# Analyze state fields

Fields used in the activities of the Analyze state in an issue's lifecycle.

The fields available in the Analyze state depend on the playbook associated with the issue's workflow. The following activities and fields are examples from the default issue workflow playbook.

## Analyze

Categorize the issue to drive routing and reporting. Set the urgency level.

|Field|Description|
|-----|-----------|
|**Classification**|The issue's classification, such as Risk.|
|**Priority**|The issue's priority.|
|**Issue type**|The specific nature of the failure or gap.|
|**Location**|The location associated with the issue.|

## Identify the impacted entities

Identify the impacted entities, controls, and risks.

|Column|Description|
|------|-----------|
|**Name**|The entity's name.|
|**Owner**|The entity's owner.|
|**Class**|The entity's class.|
|**Description**|A description of the entity.|

## Identify the control

Identify the controls affected by the issue.

|Column|Description|
|------|-----------|
|**Name**|The control's name.|
|**Number**|The control's record number.|
|**Entity**|The entity the control belongs to.|
|**Function**|The control's function.|

## Identify the risks

Identify the risks affected by the issue.

|Column|Description|
|------|-----------|
|**Name**|The risk's name.|
|**Number**|The risk's record number.|
|**Entity**|The entity the risk belongs to.|
|**Owning group**|The group that owns the risk.|
