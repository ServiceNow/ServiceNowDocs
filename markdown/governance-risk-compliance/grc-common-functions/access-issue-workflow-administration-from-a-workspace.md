# Access issue workflow administration from a workspace

Reach issue workflow configuration from within a product workspace, such as Risk Workspace, instead of navigating to the base GRC admin console.

## Before you begin

Role required: sn\_grc\_issue\_mgmt.issue\_workflow\_reader

## About this task

Any workspace with GRC Issue Administration enabled shows the same issue workflow list you would otherwise reach from the base GRC admin console, without leaving the workspace.

## Procedure

1.  Navigate to **All** &gt; **Risk** &gt; **Risk Workspace**.

    You can open the workspace that you want.

2.  Select the Lists icon.

3.  Expand **Issue Administration** and select **Issue workflows**.


## Result

The issue workflow list opens, showing the same workflows available from the base GRC admin console.
