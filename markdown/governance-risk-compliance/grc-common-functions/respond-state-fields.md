# Respond state fields

Fields used in the activities of the Respond state in an issue's lifecycle.

The fields available in the Respond state depend on the playbook associated with the issue's workflow. The following activities and fields are examples from the default issue workflow playbook.

## Issue treatment

Determine how the issue will be addressed.

|Field|Description|
|-----|-----------|
|**Response**|How the issue is being treated, such as Remediate or Accept.|
|**Explanation**|The rationale for the selected response.|

## Remediation planning

Plan how and when the issue will be remediated.

|Field|Description|
|-----|-----------|
|**Remediation plan**|A description of how the issue will be remediated.|
|**Target remediation date**|The date by which remediation is expected to be complete.|

## Remediation tasks

Track the individual tasks required to remediate the issue.

|Column|Description|
|------|-----------|
|**Short description**|A short description of the remediation task.|
|**Assigned to**|The user assigned to the remediation task.|
|**State**|The current state of the remediation task.|
|**Due date**|The date by which the remediation task must be completed.|

See [Remediation task fields](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/grc-common-functions/remediation-task-fields.md).
