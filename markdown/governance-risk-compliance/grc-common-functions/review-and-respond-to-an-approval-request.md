# Review and respond to an approval request

Review a pending approval request and approve or reject it.

## Before you begin

An approval request must be pending and assigned to you or your group.

Role required: sn\_grc\_appr.approver

## About this task

Overdue requests are flagged so approvers can prioritize them.

## Procedure

1.  Open the pending approval request.

    Optional: open the associated issue or remediation task record to review additional context before responding.

2.  Select **Approve** or **Reject**.

3.  Enter comments explaining your decision.

4.  Select **Submit**.


## Result

If approved, the record can proceed with the requested state change or due date extension. If rejected, the record remains unchanged and the requester is notified.
