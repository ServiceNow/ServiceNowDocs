# Review and close state fields

Fields used in the activities of the Review and close state in an issue's lifecycle.

The fields available in the Review and close state depend on the playbook associated with the issue's workflow. The following activity and fields are examples from the default issue workflow playbook.

## Closure comments

Capture resolution details and any follow-up information related to the issue.

|Field|Description|
|-----|-----------|
|**Actual end date**|The date and time when the issue was resolved.|
|**Close notes**|Information about the issue resolution, lessons learned, improvements made, or follow-up actions.|
