# Remove a child issue

Remove a child issue from its group so it becomes a standalone issue.

## Before you begin

The issue must be a child in a group.

Role required: risk\_admin, risk\_manager, or sn\_risk.user

## Procedure

1.  On the parent issue, open the **Child Issues** related list.

2.  Select the check box next to the child issue that you want to remove.

3.  Select **Remove**.

4.  Confirm the removal by selecting **Remove**.

    A confirmation message asks whether you want to remove the selected record.


## Result

The issue is removed from the group and becomes standalone.
