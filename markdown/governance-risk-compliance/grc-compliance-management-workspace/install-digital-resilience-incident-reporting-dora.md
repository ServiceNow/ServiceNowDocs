# Install Digital Resilience Incident Reporting application

Install the Digital Operational Resilience Management application from the Application Manager to enable DORA framework management and compliance workflows in the Compliance Workspace.

## Before you begin

Role required: sn\_compliance.admin, sn\_compliance\_ws.corporate\_compliance\_manager, sn\_compliance\_ws.it\_compliance\_manager

Unified Content Management must be installed alongside Digital Operational Resilience Management.

## About this task

The Digital Operational Resilience Management application provides the foundational data structure and compliance workflows for managing Digital Operational Resilience Act \(DORA\) requirements. This application must be installed alongside Unified Content Management to enable comprehensive DORA compliance and ICT risk management capabilities.

## Procedure

1.  Navigate to **Admin** &gt; **Application Manager**.

2.  Search for “Digital Operational Resilience Management” in the search field.

3.  Select the **Digital Operational Resilience Management** application from the search results.

    The application details page opens, displaying the summary, pricing, compatibility, and technical details.

4.  In the **Get started** section, select **Install**.

    The Review Installation Details dialog box appears.

5.  In the Review Installation Details dialog, review the version and dependencies.

6.  Select the installation schedule.

    1.  Select **Install now** to install the application immediately.

    2.  Or select **Install later** to schedule the installation for a later time.

7.  Select **Install**.

    The installation begins. Monitor the progress bar until the installation reaches 100%.

    Optionally, you can select **Run in background** to close the progress dialog and allow the installation to complete in the background. After installation is complete, the application is available in your instance.


## Result

Digital Operational Resilience Management is now installed and ready to use. The application provides the foundational data structure for DORA compliance management in the Compliance Workspace.

## What to do next

After installing Digital Operational Resilience Management:

-   Verify that both Unified content management and Digital Operational Resilience Management are installed and active.
-   Navigate to the Compliance Workspace to access the Unified Content Management landing page.
-   Activate the DORA framework and select the citations to install for your compliance program.
