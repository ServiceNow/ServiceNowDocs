# Install Unified content management application

Install the Unified Content Management application from the Application Manager to access regulatory frameworks.

## Before you begin

Role required: sn\_compliance.admin, sn\_compliance\_ws.corporate\_compliance\_manager, sn\_compliance\_ws.it\_compliance\_manager

## About this task

The Unified Content Management application is a centralized repository of regulatory frameworks. Before you can activate frameworks and install citations in the Compliance Workspace, you must install this application from the Application Manager.

## Procedure

1.  Navigate to **All** &gt; **Application Manager**.

2.  Search for “Unified Content Management” in the search field.

3.  Select the **Unified Content Management** application from the search results.

    The application details page opens, displaying the summary, pricing, compatibility, and dependencies.

4.  In the **Get started** section, select **Install**.

    The **Review Installation Details** dialog opens.

5.  In the **Review Installation Details** dialog, review the version and dependencies.

6.  Select the installation schedule.

    1.  Select **Install now** to install the application immediately.

    2.  Or select **Install later** to schedule the installation for a later time.

7.  Select **Install**.

    The installation begins. Monitor the progress bar until the installation reaches 100%.

    Optionally, you can select **Run in background** to close the progress dialog and allow the installation to complete in the background. After installation is complete, the application is available in your instance.


## Result

Unified Content Management is now installed and ready to use. You can access the application from the Compliance Workspace to browse, preview, and activate regulatory frameworks and citations.
