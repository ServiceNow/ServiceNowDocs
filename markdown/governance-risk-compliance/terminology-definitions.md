# Terminology definitions for ROI

The Terminology definitions module lists standard row, column, group, and option label definitions used across DORA reporting sheets. Only the Description field is editable.

The Digital resilience third-party registers application installs 19 seed terminology definition records across 6 groups. Each record has a sequence position such as 10, 20, or 190.

Each record includes a row identifier, column code, group, name, and option label. These fields are read-only. You can edit only the **Description** field, which stores the internal definition for the row.

You can export a single record to a comma-separated values \(CSV\) file. The export produces one row per record.

For descriptions of all fields in this module, see [Terminology definitions fields](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/governance-risk-compliance/terminology-definitions-reference.md).

Use these fields to review the seed terminology definition records installed with the Digital resilience third-party registers.
