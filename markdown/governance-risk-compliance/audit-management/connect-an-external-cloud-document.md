# Connect an external cloud document

Link an existing document from a supported external cloud storage provider into the Documents panel.

## Before you begin

Role required: sn\_audit\_ws.auditor, sn\_audit\_ws.supervisor

The integration hub spoke for your external cloud storage provider must be installed and configured. For more information, see [Connect an external cloud document](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/connect-external-cloud-documents.md).

## Procedure

1.  Navigate to **All** &gt; **Audit** &gt; **Audit Workspace**, and open the record you want to link the document to.

2.  Select the **Documents** panel.

3.  Select **Add**, then select **Connect external cloud**.

4.  Select the cloud operation you need: **Attach from cloud** to link a cloud document into the Documents panel, or **Upload to cloud** to push the current ServiceNow version of the document to cloud storage.

5.  Select the folder and the document from the external cloud storage provider.

6.  Select **Link**.

    The document appears in the Documents panel for the record.
