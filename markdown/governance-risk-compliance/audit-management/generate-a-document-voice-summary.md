# Generate a voice summary of a document

Use the voice agent to generate an audio summary of a supported document or ask questions about its content by voice.

## Before you begin

Role required: sn\_audit\_ws.auditor, sn\_audit\_ws.supervisor

## Procedure

1.  From the Documents panel, select a supported document, such as a PDF or a Microsoft Word document, to open it.

2.  Select the Voice assist option from the ServiceNow Otto® panel options.

    The voice agent processes the document.

3.  Select the option to generate an audio summary, or ask a question about the document's content by voice.

    The voice agent plays an audio summary or responds to your question based on the document's content.
