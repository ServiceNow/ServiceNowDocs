# Create a folder in the Documents panel

Organize documents by creating folders and nested folders in the Documents panel.

## Before you begin

Role required: sn\_audit\_ws.auditor, sn\_audit\_ws.supervisor

## Procedure

1.  Navigate to **All** &gt; **Audit** &gt; **Audit Workspace**, and open an engagement, control test, or evidence record.

2.  Select the **Documents** panel.

3.  Select **Add**, then select **Folder**.

    To create a folder at the top level, select **Add** directly. To create a nested folder, open an existing folder first, then select **Add**.

4.  Enter a name for the folder, and select **Create**.

5.  Double-tap the folder to open it, and add documents or additional folders inside it.

    Use the breadcrumb at the top of the panel to navigate back to a previous folder level.
