# Summarize a document with Smart Docs

Use the ServiceNow Otto® panel to summarize a supported document or ask questions about its content.

## Before you begin

Role required: sn\_audit\_ws.auditor, sn\_audit\_ws.supervisor

## Procedure

1.  From the **Documents** panel, select a supported document, for example, a PDF or a Microsoft Word document, to open it.

2.  Select the ServiceNow Otto® panel.

    \[Omitted image "aud-dms-13-eng-evidence-doc-askotto-showvoiassist.png"\] Alt text: Otto and voice options.

    A side panel opens and processes the document.

3.  Select **Summarize** to generate a summary of the document, or ask a question about the document's content in the panel.

    The panel returns a summary or an answer from the document's content.
