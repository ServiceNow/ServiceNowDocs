# Set document permissions

Grant role-based or user-based read and write permissions on a document in the Documents panel.

## Before you begin

Role required: sn\_grc\_workspace.admin

## About this task

For more information on the two types of permissions, see [Manage document permissions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/manage-document-permissions.md).

## Procedure

1.  From the Documents panel, select the document, then select **Manage permissions**.

2.  To grant a role-based permission, in the **Roles** section, select the role, then select **Reader** or **Writer**.

3.  To grant a user-based permission, in the **Users** section, select a user, a group, or an existing condition, then select **Reader** or **Writer**.

4.  Select **Save**.

    The users, groups, and roles you configured have read or write access to the document based on the permissions you set.
