# Connect an external cloud document

Use the **Connect external cloud** action in the Documents panel to link an existing document from a supported external cloud storage provider without downloading and re-uploading the file.

The **Connect external cloud** action lets you select an existing document from Microsoft SharePoint, Microsoft OneDrive, or Google Drive. You can then link it into the Documents panel, or push the current ServiceNow version of a document out to the cloud storage provider. The action lists only the folders and documents available for the external cloud integration, or spoke, that is installed for your instance.

**Note:** The **Connect external cloud** action is a different capability from the Microsoft cloud file integration described in [Manage your documents and work papers with Audit Management as cloud files](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/manage-cloud-docs-using-onedrive-int.md). Both capabilities can link documents from Microsoft OneDrive or Microsoft SharePoint, but they use separate configurations and separate related lists or panels.

The integration hub spoke for your cloud storage provider must be installed and configured before you can use **Connect external cloud**. For the steps, see the setup documentation provided by the integration hub spoke.

For the steps to connect an external cloud document, see [Connect an external cloud document](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/connect-an-external-cloud-document.md).
