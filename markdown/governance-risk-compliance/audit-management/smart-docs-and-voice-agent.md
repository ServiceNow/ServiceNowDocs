# Smart docs and voice agent for documents

For supported document types, you can use AI to summarize a document, ask questions about its content, and generate a voice summary, without opening the full document.

When you open a supported document, such as a PDF or a Microsoft Word document, from the Documents panel, you can use the following AI-assisted options:

-   Opens a side panel where you can ask an AI assistant to summarize the document or answer questions about its content. This is useful for long documents where you don't need to read every page to find the information you need.
-   Voice agent: Generates an audio summary of the document and lets you ask questions about its content by voice.

**Note:** You cannot edit a document from the ServiceNow Otto® or voice agent panels. To change the content of a document, upload a new version. For more information, see [Document version and approval workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/document-version-approval-workflow.md).

For the steps, see [Summarize a document with Smart Docs](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/summarize-a-document-with-smart-docs.md) and [Generate a voice summary of a document](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/generate-a-document-voice-summary.md).
