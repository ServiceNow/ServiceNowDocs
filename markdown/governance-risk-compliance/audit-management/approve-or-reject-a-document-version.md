# Approve or reject a document version

Review or approve a document version from your task list.

## Before you begin

Role required: sn\_audit\_ws.auditor, sn\_audit\_ws.supervisor

## About this task

You must be assigned as the reviewer or approver on the document version.

## Procedure

1.  Navigate to your task list, and open the **Document version approval** item for the version.

2.  Select the document link to view the document, and select the version link to view the version and its attached file.

3.  If you are the assigned reviewer, select **Approve** to complete the review.

4.  If you are the assigned approver, select **Approve** to approve the version.

    After every approver in the sequence approves the version, the document owner can publish the version. See [Publish a document version](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/governance-risk-compliance/audit-management/publish-a-document-version.md).

5.  If you need to reject the version, select **Reject** to return the version to the **Draft** state.

    The version returns to **Draft** state for revision.
