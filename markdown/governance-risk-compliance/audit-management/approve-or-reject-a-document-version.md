# Approve or reject a document version

Review or approve a document version that is waiting for your action from your task list.

## Before you begin

Role required: sn\_audit\_ws.auditor, sn\_audit\_ws.supervisor

You must be assigned as the reviewer or approver on the document version.

## Procedure

1.  Navigate to your task list, and open the **Document version approval** item for the version.

2.  Select the document link to view the document, and select the version link to view the version and its attached file.

3.  Select **Approve** to complete the review, if you are the assigned reviewer.

4.  Select **Approve** to approve the version.

    1.  Select **Reject** to send the version back to the **Draft** state.

    After the reviewer completes their review, the version moves to **Awaiting approval**. After every approver in the sequence approves the version, the document owner can publish the version. For the steps, see [Publish a document version](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/publish-a-document-version.md).
