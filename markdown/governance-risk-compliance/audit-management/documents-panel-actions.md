# Documents panel actions

The following actions are available on a document in the Documents panel.

|Action|Description|
|------|-----------|
|Download|Download the current published version of the document to your local system.|
|Rename|Rename the document. The updated name appears everywhere the document is linked.|
|Edit metadata|Change document properties such as owner, type, classification, and access settings. For more information, see [Edit document metadata](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/edit-document-metadata.md).|
|Track versions|View the version history of the document and upload a new version. For more information, see [Document version and approval workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/document-version-approval-workflow.md).|
|Manage permissions|Grant role-based or user-based read and write access to the document. For more information, see [Manage document permissions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/manage-document-permissions.md).|
|Connect external cloud|Link an existing document from a supported external cloud storage provider. For more information, see [Connect an external cloud document](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/governance-risk-compliance/audit-management/connect-external-cloud-documents.md).|
|Publish|Publish a version that has been approved by every configured approver. Available only on a version in the **Awaiting approval** state after all approvals are complete.|
