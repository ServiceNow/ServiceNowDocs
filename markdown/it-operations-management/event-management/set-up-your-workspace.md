# Set up your workspace

Learn how to set up your individual Express List workspace to suit your needs.

-   **[Identify an assigned Express List view](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-operations-management/event-management/manage-views-express-list-operator.md)**  
Identify Express List views assigned to you by your Event Management admin to make sure that you focus on specific services, priorities, or alerts.
-   **[Add or modify Express List columns](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-operations-management/event-management/edit-list-columns-el.md)**  
Add columns to the Event Management Express List display to focus the list of alerts that is displayed or modify the existing columns that are displayed.
-   **[Filtering the alert display in the Express List pane](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-operations-management/event-management/filter-express-list.md)**  
Filters help you create different views of categorized alerts, creating a targeted list of alerts to prioritize and focus on, saving time and minimizing distractions.
-   **[Add custom fields to the Express List preview panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-operations-management/event-management/preview-alert.md)**  
Add custom fields from the Alert \[em\_alert\] table to the Express List Info preview panel to track alert information.
