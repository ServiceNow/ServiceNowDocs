# ServiceNow Otto for Setup \(AIOps\)

ServiceNow Otto for Setup \(AIOps\) centralizes your instance management with a modular, personalized Admin Home UI dashboard, resolving current administrative ambiguity and slow task completion caused by fragmented starting points.
