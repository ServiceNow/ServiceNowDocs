# Install the ServiceNow Otto for IT Operations Management \(ITOM\) plugin

Install ServiceNow Otto for ITOM.

## Before you begin

Install the AIOps Experience \[sn\_sow\_aiops\] application from the ServiceNow Store. See [Install Service Operations Workspace for ITOM application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-operations-management/service-operations-workspace-for-itom-apps/install-sow-itom-apps.md) for more information.

Role required: admin

## About this task

Install ServiceNow Otto for ITOM plugins to enable generative AI and agentic AI on your instance.

## Procedure

1.  Go to the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

2.  In the search bar, enter `ServiceNow Otto for ITOM` and then select **Search**.

3.  Select the ServiceNow Otto for ITOM widget and then select **Get** to make this application available for installation on your instance\(s\).

4.  Install the ServiceNow Otto for ITOM application.

    1.  Navigate to **All** &gt; **System Definition** &gt; **Plugins**.

    2.  Search for ServiceNow Otto for IT Operations Management \(ITOM\).

    3.  Select **Install**.
