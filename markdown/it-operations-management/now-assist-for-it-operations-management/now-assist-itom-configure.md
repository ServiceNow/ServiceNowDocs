# Configure ServiceNow Otto for ITOM

Enable Event Management users to view alert analyses that ServiceNow Otto for ITOM creates using generative AI.

-   **[Install the ServiceNow Otto for IT Operations Management \(ITOM\) plugin](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-operations-management/now-assist-for-it-operations-management/install-now-assist-itom.md)**  
Install ServiceNow Otto for ITOM.
-   **[Activate AI agents for IT Operations Management \(ITOM\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-operations-management/now-assist-for-it-operations-management/install-now-assist-ai-agents-itom.md)**  
Activate AI agents associated with the Triage and analyze alerts agentic workflow, to enable the agentic AI experience.
-   **[Activate AI skills in ServiceNow Otto for IT Operations Management \(ITOM\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-operations-management/now-assist-for-it-operations-management/activate-now-assist-skills-itom.md)**  
You can activate the AI skills for use in ServiceNow Otto for IT Operations Management \(ITOM\).
-   **[Configure the manage alerts autonomously agentic workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-operations-management/now-assist-for-it-operations-management/configure-manage-alerts-autonomously-workflow.md)**  
Configure an alert management rule to operate the manage alerts autonomously agentic workflow manually or automatically.
-   **[Configure observability agents for ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-operations-management/now-assist-for-it-operations-management/configure-integration-agents-for-now-assist.md)**  
Configure observability agents for third-party application performance monitoring \(APM\) or network performance monitoring \(NPM\) vendors. These agents are invoked by the analyze alert impact agentic workflow. You must configure connections to those vendors before they can be invoked.
