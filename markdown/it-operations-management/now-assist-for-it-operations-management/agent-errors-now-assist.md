# View an error analysis by ServiceNow Otto in Agent Client Collector

View an error analysis created by generative AI. Error analyses enable asking questions on a specific agent's error or error code.

## Before you begin

Role required: agent\_client\_collector\_admin

## Procedure

1.  Navigate to **All** &gt; **AI Agent Studio** &gt; **Create and manage**.

2.  Select the **Agentic workflows** tab.

3.  Select the **Agent Client Collector \(ACC\) Diagnostic** entry.

4.  Locate the **Add AI agents that can perform these steps** widget and select the **Agent Client Collector \(ACC\) Diagnostic** entry.

5.  Enable ServiceNow Otto® by sliding the **Allow AI specialists to access this AI agent** toggle switch to the right.

    ServiceNow Otto® retrieves information on errors within agents.
