# Application and Device Health usage monitoring

The UI log records who views application health and device health details, and from which alert or incident, so you can monitor how these features are used.

You can check the health of an application or device from an alert or incident or access the application health details to view usage information. The `DEX ADH UI log table` captures both the application and the device health.

|Field name|Description|
|----------|-----------|
|Source ID|Stores the context on why the application health or device health \(Alert ID, Incident ID\) was viewed.|
|User persona|Registers who \(user persona: DEX user, DEX engineer\) viewed the application health or device health.|
|App or Device ID|Tracks the app or device health or performance.|
|User|Tracks the number of users.|
