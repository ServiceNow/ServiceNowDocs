# DEX Self-service categories form

The DEX Self-service categories form contains the fields that define a device health category.

|Field|Description|
|-----|-----------|
|Title|Title of the category.|
|Parent|Parent category, if this category is a subcategory.|
|Application|Application name, which is DEX Self-service.|
|Order|Order in which this category appears to the user in the Device health check experience.|
|Active|Option that adds this category when selected. The DEX Self-service checks the performance of this category only if the check box is selected.|
