# Limitations in Proactive Engagement

Some limitations apply when you create a metric rule and select a remedial action in Proactive Engagement.

Limitations in Proactive Engagement:

-   Remedial action resolution type cannot be used if the remedial actions require any runtime parameters.
-   Actionable notifications for LLM are supported starting with the Xanadu release. In the Vancouver release, the portal with NLU receives notifications.
