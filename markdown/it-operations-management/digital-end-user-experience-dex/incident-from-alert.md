# Incidents from alerts

An agent or IT operator can create an incident from a DEX alert so that an L1 agent can address the issue.

As a response to the alerts, the IT operator can create an incident. The DEX alert-related information is available on the origin card of the incident. You can view the number of impacted devices and impacted users. To access the DEX alert information, you need the Incident management for Service Operations Workspace plugin \(`com.snc.uib.sow_incident`\) starting with version 7.1.0.
