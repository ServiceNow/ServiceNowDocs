# Resolutions for Proactive Engagement

A resolution is information that helps end users self-solve an issue, or a remedial action that runs on the end-user device.

The resolution information is provided to the end user through the methods in the following table.

|Resolution type|Description|
|---------------|-----------|
|Remedial Action|[Remedial action](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/remedial-action.md) triggers an action on the end user device.|
|Create Incident|Incident that Digital End-User Experience creates with issue details when it detects the issue based on the metric rule, so that an agent can resolve the issue.|
|Self-help instructions|Set of instructions for the user to follow and resolve the issue.|
|URL|Link to any page \(including knowledge base articles\) with details about how to resolve the issue.|
