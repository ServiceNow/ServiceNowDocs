# Monitor system performance

Monitor your organization's system performance by tracking CPU, memory, disk, and I/O metrics. Use these metrics to help prevent application bottlenecks, identify storage issues such as slow read or write speeds, and detect delays in data transfer.

## Before you begin

Confirm that the DEX plugin \(sn\_dex\) is installed.

Role required: admin

## Procedure

1.  Navigate to **Workspaces** &gt; **Service Operations Workspace**.

2.  Select the Insights icon \[Omitted image "icon-insights.png"\] Alt text: in the primary navigation pane.

3.  Select **System performance**.

    For more information on the system performance metrics, see [DEX Insights reports](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/insights-reports.md).
