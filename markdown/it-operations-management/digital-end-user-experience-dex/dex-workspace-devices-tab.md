# Devices

Access the Devices tab to obtain detailed information about each device, including user assignment status, last login timestamp, matching assignments, device status, active alerts, and incidents.

To access the Devices tab, navigate to **Workspaces** &gt; **Service Operations Workspace** and select the Devices icon \[Omitted image "icon-devices.png"\] Alt text: in the primary navigation pane.

The device view is divided into the **All devices** and **Devices by ACC status** tabs. The **All devices** tab provides the device details such as its assigned user, last logged-in user details, last logged-in user location, matching assignments, active alerts, and incidents.

The **Devices by ACC status** tab displays device status, indicating whether each device is active or inactive, the status of host data collection, and other relevant device information.

Use the **View agents table** button to see detailed agent lists and attributes.

Use the **Device overview** button in the End user device overview banner to open the DEX dashboard in a new tab. The Devices page stays open in the original tab. For more information, see [Landing page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dex-workspace-dashboard-tab.md).

**Note:** Users with the `sn_dex.service_desk_user` role can't access dashboards, so the end-user device overview banner on the Device list page doesn't appear.

For more details about each field, see [Devices list](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/devices-form.md).

**Note:** Select a device to view the device details page. Similarly, select a device on the user details page to view specific information about the device. For more details about a user's device, see [Device details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dex-workspace-user-details.md) and related subtopics.
