# DEX Application and Device Health reference

The cards, lists, and forms provide the information that you use to configure and use DEX Application and Device Health.

-   **[Installed with DEX](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/components-installed-with-dex.md)**  
Several types of components are installed with activation of the DEX application \[sn\_dex\] plugin, including user roles and tables.
-   **[Landing page cards](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dashboard-cards.md)**  
The landing page cards provide a visual summary of active and impacted devices, and alerts for monitored applications.
-   **[Digital End-User Experience remedial actions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dex-diff-ra.md)**  
ServiceNow® Digital End-User Experience \(DEX\) provides base system remedial actions to resolve issues on DEX monitored devices.
-   **[DEX Insights reports](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/insights-reports.md)**  
The Digital End-User Experience \(DEX\) Insights tab provides reports on the user device battery health, system compliance, system performance, and system time.
-   **[Custom insights report form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/custom-report-form.md)**  
The Custom insights report form contains the options that you use to create a report of metrics collected across your digital space.
-   **[Applications list](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/application-form.md)**  
The Applications list provides details about each application, including its name, its classification as an installed or web-based application, counts of alerts and incidents, and impacted devices.
-   **[Application and Device Health usage monitoring](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/adh-monitoring.md)**  
The UI log records who views application health and device health details, and from which alert or incident, so you can monitor how these features are used.
-   **[Devices list](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/devices-form.md)**  
The Devices page provides information on your organization devices, the device assigned user, last login, matching assignments, status, active alerts, and incidents.
-   **[Device details pages](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/user-device-details-pages.md)**  
The device details pages show the health of a device, including alerts, incidents, battery, and hardware, plus its applications, running processes, performance, Wi-Fi and network experience, and custom queries.
-   **[Administration cards](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/administration-cards.md)**  
Administration cards let you monitor and manage applications, including adding, turning on, or turning off cards. Use administration cards to review compliance policies, view DEX users and DEX administrators, and manage metric rules and devices that have Agent Client Collector installed.
-   **[Metrics analyzer form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/metrics-analyzer.md)**  
DEX Metrics analyzer enables you to look up metrics collected for specific devices and applications.
-   **[Event log monitoring configurations installed with DEX](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/event-log-monitoring-configs-installed-with-dex.md)**  
The Application and Device Health plugin \(com.sn\_dex\) installs 20 event log monitoring configurations that are active by default. These configurations define the monitored events, log sources, and matching criteria for Windows and macOS devices.
-   **[New DEX event form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/new-dex-event-form.md)**  
The New record form for DEX event monitoring enables you to add events to monitor.
-   **[Recommended VDI policies and configuration files for NPVDIs](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/recommended-policies-np-vdis.md)**  
VDI policy and VDI configuration file records to activate on your instance so that DEX can monitor non-persistent \(NP\) Virtual Desktop Infrastructures \(VDIs\).
-   **[Metrics monitored by DEX on macOS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/metrics-monitored-by-dex-macos.md)**  
Endpoint performance and compliance metrics that DEX collects from managed macOS devices, including collection intervals, and associated check definitions and policies.
-   **[Metrics monitored by DEX on Windows](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/metrics-monitored-by-dex-windows.md)**  
Endpoint performance and conformance metrics that DEX collects from managed Windows devices, including collection intervals, and associated check definitions and policies.
-   **[Metrics monitored by DEX for Zoom](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/metrics-monitored-by-dex-for-zoom.md)**  
The Summary and Call quality metrics tabs display call quality, call issue, and network metrics for Zoom calls.
-   **[Zoom call quality metrics on the Details page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/call-quality-metrics-monitored-by-dex-for-zoom.md)**  
The **Details** page displays granular call quality metrics for each Zoom call participant.
-   **[Digital End-User Experience properties and settings](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dex-properties-settings.md)**  
The following Digital End-User Experience properties and settings control behavior such as alert correlation, browser extension metrics collection, and Desktop Assistant notifications. You must have the admin role to update them.
