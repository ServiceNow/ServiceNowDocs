# Device details

Device details in Service Operations Workspace show the health, applications, running processes, performance metrics, network configuration, and user access details of a device.

To access user and device details, navigate to **Workspaces** &gt; **Service Operations Workspace** and select the Devices icon \(\[Omitted image "icon-devices.png"\] Alt text:\) in the primary navigation pane, then select a device from the list.

**Note:**

-   Devices are categorized as **Up** or **Down** based on their current operational status.
-   Select **Computer details** to access comprehensive information about the device. The information includes the asset tag, serial number, model ID, manufacturer, and configuration details of connected components.

To learn more, see [Device details pages](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/user-device-details-pages.md).
