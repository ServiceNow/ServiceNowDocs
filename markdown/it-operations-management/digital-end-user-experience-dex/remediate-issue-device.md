# Device issue remediation

You can create a remedial action or modify an existing one after you configure the remedial action framework. Remedial action enables you to trigger an action on the impacted device.

## Single device remedial action

You can execute a remedial action on a single device by navigating to the device health page to resolve the issue. You can view the details of all the remedial actions applied and their status.

\[Omitted image "ra-adh.png"\] Alt text: Remedial action on a single device

## Bulk remedial action

Remedial actions on multiple devices enable DEX engineers and computing teams to manage the health of the end-user experience proactively. DEX engineers can select multiple devices to execute the remedial action at the same time. Remedial actions are available for bulk remediation when a DEX administrator selects the **Available for bulk remediation** option for a remedial action. After the bulk remedial action is executed, DEX engineers can view the status of the remedial action executed on the selected devices.
