# Applications list

The Applications list provides details about each application, including its name, its classification as an installed or web-based application, counts of alerts and incidents, and impacted devices.

Fields

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Name

</td><td>

Name of the application.

</td></tr><tr><td>

Type

</td><td>

The category of the application - whether it's Web or installed.

</td></tr><tr><td>

Alerts

</td><td>

Total count of alerts in either the **Open**, **Reopen**, or **Flapping** state for an application with source as DEX.Selecting any alert number directs you to the Express list, where you can view detailed information about that alert.

</td></tr><tr><td>

Impacted devices

</td><td>

Devices that are impacted by service or performance failure, resulting in the creation of an incident.

</td></tr><tr><td>

Incidents

</td><td>

Total count of active incidents for an application.

</table>-   **[Web application Overview page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/web-application-overview-form.md)**  
The Overview page for a web application provides information on active alerts, active devices, active incidents, currently impacted devices, and the mean time to resolve incidents.
-   **[Web application Performance page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/web-app-health-form.md)**  
The Performance page for a web application displays engagement metrics and performance metrics, such as sessions and page views, response time, page load time, and failed web requests.
-   **[Web application Devices page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/web-app-users-form.md)**  
The Active devices and Impacted devices lists display device details, recent user login information, login location, and last application access time. Use this data to review security posture, manage access control, and analyze usage patterns.
-   **[Web application Trends page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/web-app-trends-form.md)**  
The Trends page displays alert trends, average page load time, average response time, failed web request metrics, total usage, and mean time to resolve incidents. Use this data to evaluate system performance and identify areas for improvement.
-   **[Installed application Overview page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/installed-application-overview-form.md)**  
The Overview page for an installed application provides information on active alerts, active incidents, currently impacted devices, and the mean time to resolve incidents. Tracking the total active incidents can help you to monitor and manage the overall health of the application.
-   **[Installed application Performance page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/installed-app-health-form.md)**  
The Performance page for an installed application presents details on the location and app version, the number of crashes and freezes, and CPU, memory, and I/O performance.
-   **[Installed application Client health page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/installed-application-client-health-page.md)**  
The installed application Client health section presents details on the devices on which the Microsoft Configuration Manager \(MCM\) policy has run.
-   **[Installed application Devices page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/installed-app-users-form.md)**  
The devices lists capture data regarding All devices, Active devices, and Impacted devices. This information helps with security and access control and provides insights into user behavior and application usage.
