# DEX Desktop Assistant reference

Information about the forms and the dashboard helps you configure and administer Desktop Assistant.

-   **[Desktop Assistant usage metrics](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dex-desktop-exp-dashboard.md)**  
The usage metrics dashboard helps you track device connection status, user login status, application version, and the number of incidents created in the Desktop Assistant application. These metrics help you monitor activity between the application and your ServiceNow instance.
-   **[Components installed with Desktop Assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/components-installed-with-desktop-assistant.md)**  
Several types of components are installed with activation of the Desktop Assistant \[sn\_dex\_desktop\] plugin, including user roles and tables.
-   **[Application Registries form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/application-registries-form.md)**  
The Application Registries form contains the OAuth client settings for an application registry, such as the client ID, client secret, redirect URL, and token lifespans.
-   **[DEX system tables for remedial actions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/dex-sys-table-ra.md)**  
DEX system tables store the configuration settings for remedial actions and track the progress of each remedial action execution.
-   **[API parameters to configure Desktop Assistant notifications](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/api-parameters-to-customize-desktop-assistant-notifications.md)**  
Parameters of the sendDANotification\(\) method in the `DesktopAppNotificationUtils` script include configure Desktop Assistant notifications.
-   **[Examples of Desktop Assistant notifications using DesktopAppNotificationUtils](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/examples-da-notifications-script-include.md)**  
Examples showing the sendDANotification\(\) method of `DesktopAppNotificationUtils` used to send a Major Incident Management \(MIM\) alert and a Proactive Engagement \(PE\) notification.
-   **[Variables to customize a theme for Desktop Assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/da-theme-variables.md)**  
You can modify specific CSS variables to customize themes for Desktop Assistant.
-   **[Resolve Desktop Assistant screen loading issue](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/resolve-loading-da-screen.md)**
