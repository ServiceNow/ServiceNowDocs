# Run ACC as a local system account user

Run Agent Client Collector \(ACC\) as a local system account to fetch the complete playbook content data for a Windows device.

## Before you begin

Role required: none

## Procedure

1.  From the Windows taskbar, navigate to **Services** &gt; **Run as administrator**.

2.  Open the Agent Client Collector service and select the **Log On** tab.

3.  Select **Local System account** and select **OK**.
