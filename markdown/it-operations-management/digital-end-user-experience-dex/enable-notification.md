# Turn notifications on or off

Turn on Desktop Assistant notifications so that employees receive timely updates about important events and activities.

## Before you begin

Role required: sn\_dex\_desktop.admin

## Procedure

1.  Navigate to **Desktop Assistant** &gt; **Configuration** &gt; **Application**.

2.  On the Desktop Assistant page, turn notifications on or off.

    -   Turn on: Select the **Notifications Enabled** check box.
    -   Turn off: Clear the **Notifications Enabled** check box.
3.  Select **Update**.


## Result

A bell icon \[Omitted image "icon-notification-bell.png"\] Alt text: appears on the Desktop Assistant header if you turn on notifications. If you turn off notifications, the bell icon disappears from the header.

When enabled, push notifications are sent to employees using Desktop Assistant. For more information, see [Desktop Assistant notifications](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/da-push-notifications.md) and [View Desktop Assistant notifications](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-operations-management/digital-end-user-experience-dex/view-notifications.md).
