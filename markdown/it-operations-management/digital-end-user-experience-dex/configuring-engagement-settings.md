# Configure engagement settings

Define how end users are engaged to self-solve issues. Virtual Agent is the only notification channel used to engage users. As a fallback, an incident can be created or routed to a live agent.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **SOW** &gt; **DEX Administration** &gt; **Metric rules** &gt; **Create metric rule**.

2.  Select the CI and alert action.

3.  In the **Resolution type** field, select a type, and then select **Continue to Engagement Settings**.

    \[Omitted image "engagement-settings.png"\] Alt text: Define the engagement settings

4.  On the Engagement settings screen, fill in the fields to define how the end user is engaged to resolve the issue.

5.  Select **Add Resolution**.
