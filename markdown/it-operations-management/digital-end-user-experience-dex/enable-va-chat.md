# Enable Virtual Agent or chat

Enable Virtual Agent so that employees can find answers to their questions without waiting on hold or calling an agent.

## Before you begin

The Virtual Agent plugin \(com.glide.cs.chatbot\) must be installed and active.

Role required: sn\_dex\_desktop.admin

## Procedure

1.  Navigate to **All** &gt; **Desktop Assistant** &gt; **Configuration** &gt; **Application**.

2.  On the Desktop Assistant page, select the **Virtual agent enabled** check box.

    For information about how to configure Virtual Agent, see [Configuring Virtual Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/conversational-interfaces/configure-virtual-agent.md).

3.  Select **Update**.

    The Virtual Agent or chat icon \[Omitted image "icon-virtual-agent.png"\] Alt text: appears on the Desktop Assistant header.

4.  To open the chat window, select the Virtual Agent or chat icon \[Omitted image "icon-virtual-agent.png"\] Alt text: from the Desktop Assistant header.

    For information about how to configure chat branding, see [Set up your Virtual Agent bot's branding](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/conversational-interfaces/ac-configure-chat-branding.md).
