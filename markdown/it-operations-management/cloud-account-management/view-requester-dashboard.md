# Viewing the account requests page

View and manage cloud account requests on requester page. The home page provides a view of requested, approved, denied, pending, and active accounts.

You can access the home page by navigating to **Workspaces** &gt; **Cloud Workspace** &gt; **Manage and Configure** &gt; **Requests** &gt; **All requests**.

\[Omitted image "cam-requests-dashboard-new.png"\] Alt text:

## Account requests tiles

The tiles on the page show the number of your requests in each state. Select a tile to view the requests in that state.

|Tile|Description|
|----|-----------|
|All requests|Account requests you have submitted.|
|Pending approvals|Account requests that are awaiting approval.|
|Approved requests|Account requests that have been approved and are awaiting provisioning.|
|Denied requests|Account requests that have been denied.|
|Failed requests|Account requests that have an error and are unable to move to the next state.|
