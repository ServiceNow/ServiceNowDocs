# ITOM Infra Services Workspace configuration

ITOM Infra Services Workspace provides real-time monitoring, proactive alerts, automation of common tasks, and centralized diagnostics to help diagnose issues and manage infrastructure.

The ITOM Infra Services Workspace is available out of the box with the Australia family release. In the Yokohama family release, it's available from the ServiceNow Store. In the Zurich family release, it's available from the ServiceNow Store, and it's installed automatically when you upgrade to Zurich Patch 11 or later. The ITOM Infra Services Workspace can be used without an ITOM license.

The ITOM Infra Services Workspace and MID Server workspace are provided by default. Additional applications are installed if you have the corresponding plugins on the instance.
