# AI in Agent Client Collector Monitoring

AI provides generative AI features in Agent Client Collector Monitoring that help administrators diagnose agent errors and investigate agent behavior faster.

ServiceNow Otto for ITOM includes two AI features for Agent Client Collector Monitoring. Both features are accessed through the ServiceNow Otto panel and require ServiceNow Otto for IT Operations Management \(ITOM\) to be installed. For a summary of all AI features across ITOM AIOps, see [AI in ITOM AIOps](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/explore-ai-in-itom-aiops.md).

**Note:** Depending on your license, you will have access to certain application features, generative AI skills, agentic workflows, and AI agents. For more information, see [ServiceNow product tiers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/ai-native-sku-overview.md).

|AI feature|Description|Use case|Resources|
|----------|-----------|--------|---------|
|ACC diagnostic workflow|An agentic workflow invoked through the ServiceNow Otto panel that examines agent behavior, diagnoses issues on a specific ACC agent, and suggests remediations for specific error codes. Generates an error report based on activity logged by the Agent Client Collector Framework.|An administrator notices errors on an ACC agent and wants to investigate the cause and get remediation suggestions without manually reviewing logs.|[Agent Client Collector \(ACC\) diagnostic workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/agent-client-collector/use-acc-diagnostic-workflow.md)|
|Error analysis skill|Uses generative AI to generate an analysis of errors within an ACC agent. Displays the analysis in the ServiceNow Otto panel and supports follow-up questions about a specific agent error or error code.|An administrator is reviewing an agent with recurring errors and wants an AI-generated summary to understand the error pattern before taking action.|[View an error analysis by Now Assist in Agent Client Collector](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/agent-client-collector/agent-errors-now-assist.md)|
