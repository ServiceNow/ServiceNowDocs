# ServiceNow Otto for Setup \(ITOM\)

The Admin Home page provides a centralized workspace for managing, monitoring, and configuring your ServiceNow instance. From a single view, administrators can access product setup, track operational health, and stay informed about instance status and AI readiness.

The Manage your products section organizes your licensed ServiceNow products into dedicated spaces for focused setup and configuration. Select any product family — such as Core Business Suite, IT Operations Management, Customer Service Management, or ServiceNow Otto — to access tailored administrative tools and overviews.

\[Omitted image "nowassist-setup-admin-home-page.png"\] Alt text: Admin Home page showing the Manage your products section with cards for Core Business Suite, IT Operations Management, Customer Service Management, and ServiceNow Otto.

The setup experience includes access to operational dashboards that display real-time metrics for monitoring your ITOM environment. Key indicators help track incident management, problem resolution, and overall system health as you implement AI-driven operations management.

\[Omitted image "nowassist-setup-shared-admin-dashboard.png"\] Alt text: Shared admin dashboard displaying operational metrics including open incidents, open request items, problems, compliance score, and customer actions.

Instance information provides visibility into your ITOM setup progress, including installed applications, available entitlements, and AI skill deployment status. This helps administrators track implementation milestones and verify that all required components are properly configured.

\[Omitted image "nowassist-setup-instance-info.png"\] Alt text: Instance information section showing upgrade status, entitled apps count, adoption blueprints, and AI skill summary.
