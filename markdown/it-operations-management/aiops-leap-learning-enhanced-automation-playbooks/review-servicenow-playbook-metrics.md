# Review ServiceNow playbook metrics

Use the **ServiceNow playbooks** tab on the LEAP value dashboard to review execution trends, playbook status, and top-performing playbooks.

## Before you begin

Role required: LEAP admin

## About this task

The **ServiceNow playbooks** tab shows execution volume, status breakdown, and top-performing playbooks for the selected time period. Use the **Time Period** list in the upper-right corner to filter all metrics by a date range. The default is **Last 6 months**.

## Procedure

1.  Open the LEAP value dashboard and select the **ServiceNow playbooks** tab.

    The **ServiceNow playbooks executions overview** section opens.

2.  Review the **Tickets resolved by playbooks - Monthly trend** chart.

    The bar chart shows the number of tickets resolved by ServiceNow® playbooks each month over the selected time period.

3.  Review the three donut charts **Playbooks by status**, **Published playbooks by automation priority**, and **Playbooks utilization overview**.

    -   **Playbooks by status** — shows the split between draft and published playbooks.
    -   **Published playbooks by automation priority** — shows published playbooks grouped by priority level, such as, Critical.
    -   **Playbooks utilization overview** — shows the ratio of executed to unexecuted playbooks.
4.  Review the tables **Top 10 Playbooks – by tickets resolved** and **Top 10 Playbooks – by time savings**.

    Each table lists playbooks by LEAP number and group description. Select a LEAP number to open the automation opportunity detail page.


## Result

You can see execution volume, status breakdown, and the top-performing ServiceNow playbooks for the selected time period.
