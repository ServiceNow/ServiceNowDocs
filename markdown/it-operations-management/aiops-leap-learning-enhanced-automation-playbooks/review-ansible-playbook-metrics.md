# Review Ansible playbook metrics

Use the **Ansible playbooks** tab on the LEAP value dashboard to review Ansible execution counts, agent-hours saved, and top automation opportunities resolved by Ansible.

## Before you begin

Role required: LEAP admin

## About this task

The **Ansible playbooks** tab shows how Ansible automation is contributing to ticket resolution and time savings. Use the **Time Period** list in the upper-right corner to filter all metrics by a date range. The default is **Last 6 months**.

## Procedure

1.  Open the LEAP value dashboard and select the **Ansible playbooks** tab.

    The **Ansible playbooks executions overview** section opens.

2.  Review the four metric cards at the top of the section.

    -   **Ansible playbooks executed** - total Ansible playbook executions triggered by LEAP in the selected time period.
    -   **Total agent-hours saved via Ansible** - cumulative agent time saved through Ansible automation.
    -   **Tickets resolved by Ansible** - total tickets resolved by Ansible playbook execution.
    -   **Cost savings via Ansible** - total cost savings from Ansible-driven resolutions.
3.  Review the **Ansible executions - monthly trend** chart.

    The bar chart shows the number of Ansible executions per month over the selected time period.

4.  Review the **Top 10 Automation Opportunities – by ticket resolved using Ansible playbooks** and **Top 10 Automation Opportunities – by time savings using Ansible playbooks** tables.

    Both tables list automation opportunities by name. Select an automation opportunity name to open its detail page.


## Result

You can see how Ansible automation is contributing to ticket resolution and time savings across your automation opportunities.
