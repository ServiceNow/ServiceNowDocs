# Review problem record metrics

Use the **Problems** tab on the LEAP value dashboard to review the volume of problem records that LEAP created and identify which automation opportunities are driving root cause investigation.

## Before you begin

Role required: LEAP admin

## About this task

The **Problems** tab shows problem record creation trends and which automation opportunities are generating the most root cause investigation. Use the **Time Period** list to filter all metrics by a date range. The default is **Last 6 months**.

## Procedure

1.  Open the LEAP value dashboard and select the **Problems** tab.

    The **Problem records overview** section opens.

2.  Review the **Problem records created – monthly trend** chart.

    The bar chart shows the number of problem records that LEAP created each month over the selected time period.

3.  Review the **Problem records created by source** donut chart.

    The chart shows the proportion of problem records created by the LEAP AI agent compared to those created manually.

4.  Review the **Top 10 opportunities that generated Problem records** table.

    The table lists automation opportunities that produced problem records, with a link to each problem record in the **Problem** column. Select the automation opportunity number to open its detail page.


## Result

You can see the volume of AI-generated versus manually created problem records and identify which automation opportunities are driving root cause investigation.
