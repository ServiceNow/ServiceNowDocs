# Review KB article metrics

Use the **KB articles** tab on the LEAP value dashboard to review the volume of knowledge base articles that LEAP created and identify which automation opportunities are generating the most knowledge content.

## Before you begin

Role required: LEAP admin

## About this task

The **KB articles** tab shows KB article creation trends and which automation opportunities are producing the most knowledge content. Use the **Time Period** list in the upper-right corner to filter all metrics by a date range. The default is **Last 6 months**.

## Procedure

1.  Open the LEAP value dashboard and select the **KB articles** tab.

    The **KB articles overview** section opens.

2.  Check the **KB articles created – monthly trend** chart.

    The `bar chart` shows the number of KB articles that LEAP created each month over the selected time period.

3.  Review the **KB articles created by source** donut chart.

    The chart shows the proportion of KB articles created by the LEAP AI agent compared with KB articles created manually.

4.  Review the **Top 10 opportunities that generated KB articles** table.

    The table lists automation opportunities that produced KB articles, with a link to each generated knowledge article in the **Knowledge** column. Select an automation opportunity number to open its detail page.


## Result

You can see the volume of AI-generated versus manually created KB articles and identify which automation opportunities are producing the most knowledge content.
