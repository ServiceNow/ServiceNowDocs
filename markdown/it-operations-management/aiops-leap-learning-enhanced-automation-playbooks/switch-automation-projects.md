# Switch between automation projects

Switch between Automation Projects to view metrics, reports, and automation opportunities scoped to a specific project.

## Before you begin

Role required:

-   LEAP viewer `sn_itom_leap.leap_viewer`

## About this task

When you have multiple Automation Projects configured, you can switch between them to view project-specific data.

**Note:** Switching projects does not affect other projects or their running analysis jobs.

## Procedure

1.  On any LEAP page that displays a project selector, open the **Switch project** menu.

    The project selector appears on all LEAP pages. It displays the name of the currently active Automation Project.\[Omitted image "switch-automation-project.png"\] Alt text: Switch automation project

2.  Select the Automation Project you want to switch to.

    \[Omitted image "select-automation-project.png"\] Alt text: Select automation project

    The page refreshes to display metrics or reports or automation opportunities scoped to the selected project.
