# Manage Automation projects

Create and manage Automation projects to run LEAP across multiple incident taxonomies independently.

## Before you begin

Role required: LEAP admin \(`sn_itom_leap.leap_admin`\)

The default Automation project must be activated through the AI Admin Workspace before you can create additional Automation projects. If you have not yet activated LEAP, complete the initial setup first.

## About this task

After activating the default Automation project, use the following procedures to create and manage additional Automation projects:

## Procedure

1.  [Create an Automation project](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/aiops-leap-learning-enhanced-automation-playbooks/create-automation-project.md).

2.  [Start the analysis job](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/aiops-leap-learning-enhanced-automation-playbooks/start-automation-project-job.md).

3.  [Switch between Automation projects](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/aiops-leap-learning-enhanced-automation-playbooks/switch-automation-projects.md).

4.  [Edit an Automation project](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/aiops-leap-learning-enhanced-automation-playbooks/edit-automation-project.md).
