# Edit an Automation Project

Edit an Automation Project configuration when the analysis job is in ready status.

## Before you begin

Role required: LEAP admin \(`sn_itom_leap.leap_admin`\)

## About this task

## Procedure

1.  Open the Automation Project from the **Manage Automation Projects** page.

2.  Select **Edit**.

    **Note:** You can only edit a project when its job status is *ready*. Projects with a running or completed analysis job can't be edited.

3.  Update the fields as needed, then select **Save**.
