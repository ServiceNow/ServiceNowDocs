# Generating service level objectives

Use the service level objective \(SLO\) creator agent to auto-generate SLOs for services and configuration items \(CIs\). The agent can help teams adopt SLOs faster and monitor service performance.

## How the SLO creator agent works

The SLO creator agent requires ServiceNow Otto for ITOM and Service Reliability Management \(SRM\). It automatically generates SLOs by analyzing operational data for services and CIs.

1.  Every 14 days, the agent processes up to 25 service or CIs that don't already have an auto-generated SLO.
2.  For each service or CI, the agent analyzes critical alerts, incidents, and outages, including data from related CIs.
3.  The agent uses existing availability commitments, when available, or business criticality to determine the SLO target.
4.  For every service or CI that it analyzes, the agent generates one SLO with up to 10 SLIs.
5.  The relevant team manger receives an email when the SLO is generated.
6.  The generated SLO is active by default and the assigned team receives an email when the error budget falls to 25% or below.

    SRM managers and responders can review, edit, or turn off generated SLOs.


You can manage the SLO creator agent, including turning the agent on or offand customizing system properties. For more information, see [Manage SLO creator agent settings](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/service-level-objective-management/now-assist-itom-manage-generated-slos.md)and [SLO creator agent system properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/service-level-objective-management/slo-creator-agent-system-properties.md). To view SLOs generated by the agent and review details about their creation, see [View generated SLOs](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-operations-management/service-level-objective-management/now-assist-itom-view-slos.md).

**Important:** This AI agent is turned on by default. For more information, see [AI agents, skills, and agentic workflows on by default](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-skills-on-by-default.md).

## Access the SLO creator agent in AI Agent Studio

Access the SLO creator agent in AI Agent Studio to manage security controls or duplicate it for further customization.

1.  Navigate to **All** &gt; **AI Agent Studio** &gt; **Create and manage**.
2.  Select the **AI agents** tab.
3.  Select **SLO Creator Agent**.

The SLO Creator Agent page lets you manage the agent, including defining security controls. To modify the agent, [duplicate it](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/clone-aia-usecase.md) and adjust the settings.

**Important:** When you modify an agentic workflow, AI agent, or tool, make sure that you update all instructions accordingly.
