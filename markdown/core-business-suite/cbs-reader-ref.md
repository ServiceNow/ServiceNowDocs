# CBS Knowledge Readers form

Field descriptions for the CBS Knowledge Readers form.

|Field|Description|
|-----|-----------|
|**Name**|Name of the user criteria.|
|**Short Description**|Brief description of the user criteria.|
|**Active**|Selected when the user criteria is active.|
|**Application**|Application scope for the user criteria.|
|**Users**|Specific users who can read the knowledge base.|
|**Groups**|Groups whose members can read the knowledge base.|
|**Roles**|Roles that grant permission to read the knowledge base.|
|**Companies**|Companies whose users can read the knowledge base.|
|**Locations**|Locations whose users can read the knowledge base.|
|**Departments**|Departments whose users can read the knowledge base.|
|**Advanced**|Selected to enable advanced scripting options.|
|**Match All**|Selected when users must match all specified criteria.|
|**Script**|Custom script to determine user eligibility. This field appears only when the **Advanced** check box is selected.|
