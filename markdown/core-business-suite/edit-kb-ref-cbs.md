# Edit Knowledge Base form

Edit any Knowledge Base settings by filling in the form fields to define workflows, ownership, and management. You can apply separate settings for different Knowledge bases across your organization.

<table><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Title**

</td><td>

Name of the Knowledge Base.

</td></tr><tr><td>

**Description**

</td><td>

Brief description of the Knowledge Base purpose.

</td></tr><tr><td>

**Publish flow**

</td><td>

Workflow for publishing knowledge articles.

</td></tr><tr><td>

**Retire flow**

</td><td>

Workflow for retiring knowledge articles.

</td></tr><tr><td>

**Owner**

</td><td>

User who owns the Knowledge Base.**Note:** You can add an owner of the Knowledge Base by adding them to the **Owner** field beyond the CBS admin.

</td></tr><tr><td>

**Managers**

</td><td>

Users who can manage the Knowledge Base.**Note:** You can add additional people who can manage the Knowledge Base by adding them to the **Manager** field, beyond the CBS admin.

</td></tr><tr><td>

**Active**

</td><td>

Selected when the Knowledge Base is active.

</td></tr></tbody>
