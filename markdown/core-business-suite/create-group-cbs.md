# Create group in Core Business Suite module

Create custom groups for specific Core Business Suite functions and assign roles to group members.

## Before you begin

Role required: sn\_cbs.admin

## About this task

Create custom groups to organize users for specific business functions within Core Business Suite.

## Procedure

1.  Navigate to **Core Business Suite** &gt; **Configure**.

2.  Select **Groups** under Core Business Suite module.

3.  Select the **Create group** button to navigate to the create group page.

4.  On the Create group page, fill in the fields and select **Save**.

    For more details on the field descriptions, see [Create group form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/core-business-suite/groups-cbs-ref.md).


## Result

You created a custom group. You can start adding people to the group.
