# ServiceNow Otto for Core Business Suite \(CBS\)

Now Assist for Core Business Suite supports Core Business Suite configuration through a conversational experience. Now Assist guides administrators through setup steps, tracks configuration progress, suggests next actions, and helps resolve errors from a single chat experience.

## ServiceNow Otto for Core Business Suite \(CBS\) overview

Now Assist for Core Business Suite provides a conversational interface using Virtual Agent to support the Core Business Suite simplified setup process. Administrators can use Now Assist to initiate setup actions, review configuration progress, and access setup‑related information.

Now Assist maintains context across setup steps and reflects the current system state. It uses AI agents, skills, and tools to guide configuration activities through a structured conversational flow.

## ServiceNow Otto for Core Business Suite \(CBS\) conversational flow

Now Assist for Core Business Suite provides a conversational experience using Virtual Agent to configure and manage Core Business Suite. Administrators can start the setup, review available configuration topics, and ask setup‑related questions using natural language.

## AI Skills

The following AI skills are available in ServiceNow Otto for Core Business Suite \(CBS\):

-   Setup Progress Summary: Provides visibility into the current state of Core Business Suite installation and configuration by summarizing completed steps and pending tasks. This helps administrators track setup progress without reviewing individual configuration areas.
-   Next Best Action: Identifies the next setup task based on the current configuration state. Recommendations update as the setup progresses and additional configuration steps become available.
-   Error Resolution: Provides contextual guidance when an installation or configuration step does not complete successfully. The skill suggests possible actions to address common setup issues and continue the setup process.

## AI capabilities

The following generative AI capabilities are available in ServiceNow Otto for Core Business Suite \(CBS\):

-   Conversational Setup Guidance: Guides administrators through Core Business Suite business unit setup steps in sequence using a conversational interface in the Now Assist panel.
-   Contextual Awareness: Maintains awareness of completed setup steps and installed business units, allowing administrators to continue configuration from the current setup state.
-   Dynamic Recommendations: Suggests next setup steps and highlights missing configurations based on the current setup state as setup progresses.
-   Multi–Business Unit Support: Supports configuring multiple business units from a single guided setup flow in the Configuration Console.

Furthermore, there is no guarantee that this application has been fully trained or tested for your use case. ## Data processing

This application requires data to be transferred from ServiceNow customers' individual instances to a centralized ServiceNow environment, which may be located in a different data center region from the one where your instance is, and potentially to a third-party cloud provider, such as Microsoft Azure. This data is handled per ServiceNow's internal policies and procedures, including our policies available through our [CORE Compliance Portal](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0564067).
