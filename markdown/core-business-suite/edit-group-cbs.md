# Edit groups in Core Business Suite module

Edit default groups to add or remove members in Core Business Suite.

## Before you begin

Role required: sn\_cbs.admin

## About this task

Modify group membership to control access to analytics and other Core Business Suite features.

## Procedure

1.  Navigate to **Core Business Suite** &gt; **Configure**.

2.  Select **Groups** under Core Business Suite module.

3.  Select the edit icon on either one of the default groups to add or remove someone in the group.

    -   Analytics editor group has role: sn\_cbs\_analytics.dashboard\_editor
    -   Analytics viewer group has role: sn\_cbs\_analytics.dashboard\_viewer
