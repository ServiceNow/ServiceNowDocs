# Import Articles form

Field descriptions for the Import Articles form used to import knowledge base articles from Word documents.

|Field|Description|
|-----|-----------|
|Knowledge Base|Knowledge base where the imported articles are stored. This field is mandatory.|
|Import a Word File|Word document file to import. Drag and drop `.doc` or `.docx` files into this area, or select to browse for files. This field is mandatory.|
|Category|Category assigned to the imported articles for organization and classification within the knowledge base.|
