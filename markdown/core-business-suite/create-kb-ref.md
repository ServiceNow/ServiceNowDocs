# Create New Knowledge Base form

Describe the fields on the Create New Knowledge Base form to configure knowledge base settings.

|Field|Description|
|-----|-----------|
|Knowledge Base|Name of the knowledge base.|
|Disable commenting|Option to prevent users from adding comments to knowledge articles.|
|Disable suggesting|Option to prevent users from suggesting knowledge articles.|
|Disable category editing|Option to prevent users from editing knowledge article categories.|
|Disable rating|Option to prevent users from rating knowledge articles.|
|Disable mark as helpful|Option to prevent users from marking knowledge articles as helpful.|
|Publish flow|Workflow for publishing knowledge articles.|
|Retire flow|Workflow for retiring knowledge articles.|
|Active|Option to make the knowledge base active.|
|Checklist|Checklist associated with the knowledge base.|
|Description|Brief description of the knowledge base purpose.|
|Set default knowledge field values|Default field values for knowledge articles in this knowledge base.|
|Release version|Version number for the knowledge base release.|
|Attachment|Placeholder to add a the knowledge base file.|
