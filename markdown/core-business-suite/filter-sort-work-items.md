# Filter and sort work items in My Work widget

Use filtering and sorting options in the My Work widget to organize and prioritize your work items in Agent Experience.

## Before you begin

Role required: sn\_cbs\_fulfiller

## About this task

The My Work widget provides multiple filtering and sorting options to help you focus on the most important work items. You can combine filters and sorting to create a customized view of your workload.

## Procedure

1.  Navigate to **All** &gt; **Core Business Suite** &gt; **Agent Experience**.

2.  In the My Work widget, select the filter icon to view filtering options.

3.  Select one or more filters to narrow your work items.

    -   **Department**: Filter work items by the department they belong to
    -   **SLA risk**: Show only items at risk of breaching their SLA within 24 hours
    -   **VIP cases**: Show only cases where the requester has VIP status
    -   **Recently updated**: Show items that were recently modified
    The widget updates to display only work items matching your selected filters.

4.  To sort work items, select the sort icon and choose a sorting option.

    -   **Record priority**: Sort by the priority level assigned to each item
    -   **Newest first**: Display the most recently created items first
    -   **Oldest first**: Display the oldest items first
    The widget reorders work items according to your selected sort option.

5.  To search for specific work items, enter keywords in the search field.

    The widget displays only items matching your search terms.

6.  To view additional work items beyond the first five displayed, use the pagination controls at the bottom of the widget.
