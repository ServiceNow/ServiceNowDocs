# Configure Manufacturing Commercial Operations

Set up Manufacturing Commercial Operations to enable manufacturers to manage the end-to-end lifecycle of your manufacturing products.

## MCO installation and configuration

Before you begin, review the Manufacturing Commercial Operations packaging and licensing requirements.

To configure MCO, complete the following foundational installation and configuration steps before configuring core features.
