# Configure product model

Create and activate product models for finished products, parts, and components in Manufacturing Commercial Operations \(MCO\).

## Before you begin

Role required: Model Manager \(model\_manager role\)

## About this task

You can define and manage both finished products and their individual parts or components as separate product model records. For example:

-   Product: Alectri Lumora VX 2025 \(Car\)
-   Component/Part: Alectri Airbag 65-77-91

Each of these entities is treated as a product model in the system.

## Procedure

1.  Navigate to **All** &gt; **Workspaces** &gt; **CSM/FSM Configurable Workspace.**

2.  Select the List icon.

3.  Navigate **MCO Setup** &gt; **Product Models**.

4.  Select **New**.

5.  Enter the product name.

    For example, enter "Alectri Lumora VX 2025" for a finished product.

6.  Select the product type of models.

    For example, select a type such as "Component" for "Alectri Airbag 65-77-91".

7.  Select **Save**.


## Result

The product model is created and ready for use in MCO processes such as warranty claims, recall campaigns, and quality investigations.
