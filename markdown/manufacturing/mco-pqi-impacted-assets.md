# Add impacted assets

Add assets affected by a product quality issue to a Product Quality Investigation record, either individually or by bulk import.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace** &gt; **List** &gt; **Product Quality Investigation** &gt; **Impacted Asset**.

2.  Select **New**.

    1.  On the Impacted asset form, fill in the following details:

        |Field|Description|
        |-----|-----------|
        |Issue|Product quality investigation associated with the impacted asset.|
        |Asset|Asset affected by the product quality issue.|
        |Status|Current status of the impacted asset record.|
        |Install base|Install base record linked to the impacted asset.|

    2.  Select **Save**.

3.  Select **Import** to bulk upload the impacted assets.

    1.  Select the template to download and use.

    2.  On the Import form, select **Add file**.

    3.  Select the required XLSX file.

        -   Asset \(Serial number\)
        -   Status
    4.  Select **Upload**.

    5.  Select **Import**.
