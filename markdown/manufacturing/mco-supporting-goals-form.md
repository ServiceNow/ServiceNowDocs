# Supporting goals form

The Supporting goals form enables you to add the supporting goal details, such as name, parent goal, owner, start date, end date, and target review date.

|Field|Description|
|-----|-----------|
|Name|Name of the effectiveness goal.|
|Parent goal|Parent effectiveness goal, used to support goal hierarchies.|
|Start date|Date on which tracking begins.|
|State|State of the effectiveness goal's lifecycle.|
|Owner|User assigned to the effectiveness goal.|
|End date|Date on which tracking for the effectiveness goal ends.|
|Target review date|Date on which the effectiveness goal's targets are reviewed.|
