# Quality issue management data model

The quality issue management \(QIM\) framework helps original equipment manufacturers \(OEMs\) centralize non-conformance data and act on root causes.

The QIM brings together quality data, workflows, and stakeholders into a single system of record. This approach centralizes visibility into issue status, tracks resolution progress, assigns accountability for corrective actions, and supports continuous improvement efforts.

The QIM involves the following tasks:

-   Issue detection and logging
-   Root cause analysis
-   Corrective and preventive actions \(CAPA\)
-   Outcome monitoring
-   Documentation
