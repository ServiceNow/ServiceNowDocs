# MCO initial setup

Configure the basic settings and organizational structure required before using Manufacturing Commercial Operations features.

Before you can use Manufacturing Commercial Operations \(MCO\) features, you must complete initial setup tasks. These tasks establish your organizational structure, user roles, and system prerequisites.
