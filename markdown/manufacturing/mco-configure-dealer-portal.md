# Configure dealer portal

Configure the dealer portal in Manufacturing Commercial Operations to enable dealers to access recalls, submit claims, and manage self-service workflows.

## Before you begin

Role required: admin

## About this task

Dealers require portal access to view recall campaigns, submit warranty claims, and access reporting dashboards. Configure the portal environment before granting user access.

## Procedure

1.  Enable the dealer portal in MCO setup.

    In the MCO module, navigate to **Setup** and activate the dealer portal feature flag.

2.  Configure the dealer portal theme and branding.

    Customize the portal appearance to match your organization's brand guidelines. Upload logos, set color schemes, and configure the header and footer content.

3.  Set up dealer user accounts and access permissions.

    Create user accounts for dealers and assign roles based on their responsibilities. Define permission levels for claim submission, recall access, and reporting views.

4.  Configure portal navigation and menu items for dealer self-service.

    Organize the portal menu to surface key dealer workflows such as recall campaign access, claim submission, and dashboard views. Hide or disable menu items not relevant to dealers.

5.  Verify dealers can access recall campaigns and submit claims.

    Sign in as a dealer user and confirm that recall campaigns are visible and the claim submission form is accessible from the portal.

6.  Test the dealer claim submission workflow.

    Submit a test claim through the portal and verify that the workflow progresses through approval states, notifications are sent, and data is captured correctly.

7.  Configure dealer portal notifications and messaging.

    Set up email notifications for claim status updates, new recall announcements, and portal messages. Customize notification templates with relevant dealer-facing language.

8.  Set up dealer reporting and dashboard access.

    Configure dashboards and reports that dealers need to monitor claim status, warranty data, and recall progress. Assign dashboard views based on dealer roles and responsibilities.

9.  Test end-to-end dealer portal functionality.

    Run a complete test cycle with dealer user accounts to verify portal navigation, claim submission, approvals, notifications, and dashboard access work as expected.


## Result

The dealer portal is configured and ready for dealer users. Dealers can now access recall campaigns, submit warranty claims, receive status notifications, and view relevant reporting dashboards.
