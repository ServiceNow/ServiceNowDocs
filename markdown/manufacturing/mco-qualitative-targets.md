# Create a qualitative target

Create a qualitative target for an effectiveness record to define and track non-numeric success criteria for a product quality investigation.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace** &gt; **List** &gt; **Product Quality Investigation** &gt; **Effectiveness Goals**.

2.  Open the effectiveness record that you want to measure.

3.  Select **Qualitative Targets**.

4.  Select **New**.

5.  On the Effectiveness Target form, fill in the details.

    For a description of the field values, see [Effectiveness target form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/manufacturing/mco-qualitative-targets-form.md).

6.  Select **Submit**.


## Result

The effectiveness qualitative target is created.
