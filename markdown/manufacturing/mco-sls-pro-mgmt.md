# Sales promotion management

The Agent workspace enables the OEMs to create the promotion campaign for a specific set of customers.

|Tasks|Description|
|-----|-----------|
|[My promotions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/manufacturing/mco-my-promotions.md)|Displays all the sales promotion claims that are assigned to the person logged in to the workspace.|
|[View all promotions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/manufacturing/mco-all-promotions.md)|Displays all the sales promotion claims.|

-   **[My promotions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/manufacturing/mco-my-promotions.md)**  
Agents workspace enables OEM to create the sales promotions campaigns. OEM agent can view all the sales promotion campaign created by them.
-   **[View all promotions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/manufacturing/mco-all-promotions.md)**  
View all the promotions you created as an OEM agent.
