# Create a correction action

Create a correction actions for the non-conformance report.

## Before you begin

Role required: Quality Issue Management Admin or product non-conformance submitter \(sn\_mfg\_qm.product\_non\_conformance\_submitter\)

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace** &gt; **List** &gt; **Product Non Conformance Case** &gt; **Correction Actions**.

2.  Select **New**.

3.  On the Correction actions form, fill in the fields.

    For a description of the field values, see [Correction actions form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/manufacturing/mco-correction-actions-form.md).

4.  Select **Save**.

5.  Select **Discuss**.

    The Start a Sidebar discussion window is displayed.

    For more information on the sidebar discussion window, see .

6.  Select **Save**.
