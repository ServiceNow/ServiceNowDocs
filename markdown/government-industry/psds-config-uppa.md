# Configuring Urban Planning &amp; Permitting Administration

Install the Urban Planning &amp; Permitting Administration application, which enables investigators and supervisors to initiate and manage land management cases, view the full context of a land management case, and get relevant recommendations.

As a user with the admin role, complete the following configuration tasks to set up Urban Planning &amp; Permitting Administration, after you install the [Public Sector Digital Services Core](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/government-industry/install-public-sector-digital-services-core.md) application.
