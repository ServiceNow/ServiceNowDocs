# GOV.UK Design System Service Portal

Use the GOV.UK Developer Toolkit, a library of reusable portal widgets that follow GOV.UK Design System guidelines, to build service portals that deliver citizen-centered digital services to UK government constituents.

The GOV.UK Developer Toolkit is a collection of pre-built, GDS-compliant portal widgets that developers and partners can use to build service portals for UK government agencies. Developers can use these standardized components, widgets, and pages \(homepage, FAQs, registration, profile, login, case detail, knowledge search, record producers\) to assemble portals that meet UK accessibility and design standards. By default, this toolkit provides a pre-built portal, the GOV.UK Design System Service Portal \(/ukgds\), that adheres to GOV.UK Design System guidelines and patterns.

\[Omitted image "psds\_gds\_portal.png"\] Alt text: GDS Portal view for UK constituents

On the GOV.UK Design System Service Portal, UK constituents can access services such as permit applications, license renewals, public records requests, and more.

UK constituents can do the following self-service tasks in the GDS Service Portal:

-   Register as a new user, create a login, and create a user profile.
-   Browse and request services or information, track cases, view received services, and report issues.
-   Search for information, browse knowledge articles, and engage with the community.
-   Get the latest information on policies and programs by searching and viewing articles.
-   Discuss issues with neighbors and share perspectives by asking the community.
-   View your recent services and see the popular services on the site.
-   Get help using Virtual Agent.
-   Request services such as street repair, trash removal, building inspections, and other public maintenance.
-   Request information and public records from local, state, and federal public agencies.

For more information on how to set up and configure the pages and widgets offered by the GOV.UK Developer Toolkit, see [Configure the GOV.UK Design System \(GDS\) Service Portal](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/government-industry/psds-config-gds-content-pack-gsp.md).
