# Release result notices to applicants

After the Grant Program Director approves a Funding Allocation Request, release result notices to applicants individually or in bulk.

## Before you begin

Role required: sn\_svc\_appl\_pgm\_mg.grant\_program\_manager

Grants Management 1.31 introduces rolling grant approvals. The Grant Program Director can release notices for individual proposals in the **Ready to release** state as soon as they are decided. Proposals don't need to wait for the entire program to complete.

## About this task

With rolling grant approvals, you can release result notices for individual proposals as soon as they are decided, without waiting for the entire program to complete. You can also release notices in bulk for all ready proposals at once.

**Note:**

Applicants whose result notices have not yet been released see their proposal status as **Decision pending** in the applicant portal. They aren't shown an outcome until you release the result notice.

## Procedure

1.  Navigate to **All** &gt; **Public Sector Workspace**.

2.  Navigate to **Lists** &gt; **Grant Proposals** and select **All**.

3.  In the **Create results letter** activity, select **Grant Program view**.

4.  Select the **Results notices** tab.

    The scored proposals appear.

5.  Select the grant program record for which you want to release the result notice and select **Release Results** to release a result notice for an individual proposal.

    To Release notices in bulk

    1.  Select the check box adjacent to the **Proposal** status filter to select all the proposals that are ready to release.

    2.  Select **Release Results**.


## Result

The result letter is sent to the applicant\(s\) immediately and the status of that grant program record changes to Closed. In the Proposal playbook, once the letters are released the playbook advances to the **Record outcome** activity while awaiting an applicant response. The resolution code is auto-populated after the applicant accepts the letter.
