# Security posture console

Improve your ability to identify, respond to, and recover from security threats with comprehensive visibility and step-by-step instructions.

\[Omitted image "sc-posture-console-1.png"\] Alt text: Security posture console page with dashboard cards, Security Tasks, and additional resources

The security posture console is divided into sections to provide information about general guidelines and security posture dashboards. Find additional details by selecting any of the cards in these sections. You can also use the bar at the top of the page to navigate between this page and the general guidelines and security posture dashboards section of Security Center.

## General guidelines

This section displays the count of general guidelines, and how many you have applied to your instance. You can see a chart showing your completed general guidelines over time.

## Security posture dashboards

This section displays the number of active integration accounts, active privileged accounts, and users that have never logged in.

-   **Active integration accounts**

    Integration accounts are user accounts that manage integrations between your instance and third-party applications.

-   **Active privileged accounts**

    Administrators assign privileged users additional roles to access features such as High Security Settings, Import, and Portal users.

-   **Never logged-in users**

    User accounts that have never logged in to your instance.


## My Security Tasks

View the most urgent Security Tasks assigned to you. Select a task to view its details, or select **See all Security Tasks** to view a complete list of Security Tasks.

Use the additional resources section on the edge of the screen to navigate to documentation and videos relevant to learning Security Center and information on managing instance security.
