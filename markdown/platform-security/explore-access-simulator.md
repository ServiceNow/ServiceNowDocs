# Exploring Access Simulator

Access Simulator helps you pre-validate how access to a specified table would change after a role or group is assigned or removed from the user.

Use Access Simulator to simulate access requirements of your users on a specified table and understand how the access controls change for a user. It helps in quickly troubleshooting and validating the effectiveness of changes.

\[Omitted video\] Description: Access Simulator

Use Access Simulator to pre-validate access for a selected user by:

-   [Add roles to users](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/add-role-to-user.md)
-   [Remove roles from users](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/remove-role-from-user.md)
-   [Add users to groups](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/add-user-to-group.md)
-   [Remove users from groups](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/remove-user-from-group.md)

To learn more about Access Simulator settings and Enable Take Actions, see [Configure the Access Simulator \(Take actions\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/configure-access-simulator.md).
