# Continuous authentication policies

View the different continuous authentication policies that are created.

The continuous authentication \(CA\) policies form includes the details of the CA policies that are created for the table or data class. You can manage policy records from the custom policies.

To access the policies page, navigate to **All** &gt; **Continuous Authentication**, select **Policies** tab. The following policy details are displayed on the page.

|Field|Description|
|-----|-----------|
|Policy Name|Policy name|
|Description|Policy description|
|Active|Policy status|
|Resource Type|Selected resource type used for the policy|
|Classification|Data classification selected for the policy|
|Tables|Tables selected for the policy|
|Created|Policy creation details|
