# Unified Secrets Gateway

Secure secrets on your instance from unauthorized access using Unified Secrets Gateway.

Unified Secrets Gateway \(USG\) is a centralized secrets organization and authorization framework based on the ServiceNow Key Management Framework. USG allows you to organize, control access to, and encrypt credentials on the instance. Use USG in combination with access policies and identity groups to help protect sensitive information. This includes API keys, authentication tokens, and database credentials from unauthorized users, scripts, or system processes. All access attempts, whether granted or denied, are logged for auditing purposes.
