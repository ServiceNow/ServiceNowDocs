# Exploring Access Simulator

Access Simulator helps you simulate how access to the specified table would change after a role or group is assigned or removed from the user.

Administrators can use the Access Simulator to simulate the access requirements of their users on a specified table and understand how the access controls change for a user. It helps in quickly understanding the present access of the users and understanding the impacts of providing or removing roles to the users.

\[Omitted video\] Description: Access Simulator

Access Simulator can be used for simulating access on a user for the following scenarios:

-   [Add a role to a user](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-security/access-control/add-role-to-user.md)
-   [Remove roles from users](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-security/access-control/remove-role-from-user.md)
-   [Add a user to a group](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-security/access-control/add-user-to-group.md)
-   [Remove users from groups](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-security/access-control/remove-user-from-group.md)

To learn more about the Access Simulator settings and how to enable take actions, see [Configure the Access Simulator \(Take actions\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-security/access-control/configure-access-simulator.md).
