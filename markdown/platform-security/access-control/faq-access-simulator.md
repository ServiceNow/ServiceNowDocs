# Frequently asked questions

Answers to common questions about getting started with Access Simulator, how it works, and turning Actions on or off.

|Questions|Explanation|
|---------|-----------|
|How do I get started with Access Simulator?|Select the **Simulate** option for the scenario that you would like to test and follow the steps.|
|How does Simulator work?|The Access Simulator simulates access to the specified table for a selected user and previews the access changes, so you can troubleshoot problems or, if the changes look right, commit them to the system.|
|How to enable or turn off Actions in Simulator?|You can enable or turn off **Actions** in Access Simulator by navigating to **Settings** or during the **Take Actions** steps in the simulation process.|
