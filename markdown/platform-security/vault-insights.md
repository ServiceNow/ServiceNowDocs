# Insights in ServiceNow Vault console

Insights uses AI to summarize the ServiceNow Vault console metrics and recommend a next step for each area of your data security.

The ServiceNow Vault console home page reports many separate metrics and charts. Insights reads those same metrics and states, in plain language, the current state of your data security and what you can do next. You don't have to interpret each chart to find the areas that need attention.

Insights appears at the top of the ServiceNow Vault console home page.

**Note:**

Insights and the charts draw on the same source data, so the two report the same values. Insights doesn't add information that the charts don't already report.

\[Omitted image "vault-insights.png"\] Alt text: Insights section at the top of the Vault console home page with summaries and next steps for data discovery, classification, and data protection.

## What each insight contains

Each area of your data security gets one insight and one next step:

-   **Insight**

    A summary of the current state for that area. For example, which patterns data discovery found across your instance, or how many findings aren't classified yet.

-   **Next step**

    A recommended action you can take to protect your data further. For example, reviewing and classifying new findings, or applying field encryption to unencrypted classified fields.


Insights are reported in this order:

1.  [Data discovery](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-security/data-discovery/data-discovery-landing.md)
2.  [Classification](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-security/data-classification/data-classification.md)
3.  Data protection, which combines [Anonymization](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-security/data-privacy-classic/dps-data-anonymization.md), [Field Encryption](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-security/field-encryption.md), and [Zero Trust Access](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-security/ca-homepage.md) into a single insight

## When an insight isn't shown

An individual insight and its next step are left out when any of these conditions apply:

-   There's no genuine next step for you to take in that area.
-   The product for that area isn't installed on your instance, so no data is available for it.
-   No graph data is returned for that product.

Retrieval runs separately for each product. If retrieval fails for one product but succeeds for others, the insight for the failed product is left out and the rest are still reported. No error message identifies the omitted product.

## Refreshing insights

Select the refresh icon in the Insights section to generate the summary again from the latest data. A loading state appears while generation is in progress.

Reloading the whole page retrieves the latest data as well. Refreshing the section is useful when you've had the home page open for some time without reloading it.

## Availability and error states

Insights requires the ServiceNow Otto for Vault application. When ServiceNow Otto for Vault isn't active on your instance, the Insights section is hidden.

Insights also requires the Generative AI Controller license, which is included with ServiceNow Otto for Vault.

When the summary can't be generated, the section reports `Unable to generate insights. Please try again later.` Select the refresh icon to try again.

Insights carries the text "Generated by AI. Check for accuracy". Review the recommended next steps before you act on them.

**Note:** Depending on your license, you will have access to certain application features, generative AI skills, agentic workflows, and AI agents. For more information, see [ServiceNow product tiers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-native-sku-overview.md).

## Role requirements

Insights is visible only to users with the `sn_vault_console.vault_console_admin` role. Elevate to this role to view Insights. Insights is hidden for users with the `sn_vault_console.vault_console_auditor` role. For more information about elevating roles, see [ServiceNow Vault roles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-security/vault-roles.md).
