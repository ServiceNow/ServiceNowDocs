# OAuth

OAuth based authentication validates the identity of the client that attempts to establish a trust on the system by using an authentication protocol.

OAuth 2.0 - Open Authorization is the industry-standard protocol for authorization that focuses on client developer simplicity while providing specific authorization flows for web applications, desktop applications, and mobile devices.

## Inbound

Create an endpoint for external clients that access your instance. This creates an OAuth client application record and generates a client ID and client secret that the client requires access to the restricted resources on the instance. For more information, see [OAuth inbound](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/authentication/oauth-inbound.md).
