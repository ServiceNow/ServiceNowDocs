# Manage identifier-first login policies

Create, edit, activate, deactivate, and delete the identifier-first login policies that drive the policy-based login experience.

## Before you begin

Role required: `user_authn_admin`

## About this task

Manage identifier-first login policies from the policy-based login experience.

## Procedure

1.  Navigate to **All** &gt; **Authentication Console**.

2.  Do any of the following:

    -   [Create an identifier-first login policy for password authentication](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/authentication/create-ifl-policy-password.md)
    -   [Create an identifier-first login policy for SSO authentication](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/authentication/create-ifl-policy-sso.md)
    -   [Edit an identifier-first login policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/authentication/edit-ifl-policy.md)
    -   [Activate or deactivate an identifier-first login policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/authentication/activate-deactivate-ifl-policy.md)
    -   [Delete an identifier-first login policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-security/authentication/delete-ifl-policy.md)
