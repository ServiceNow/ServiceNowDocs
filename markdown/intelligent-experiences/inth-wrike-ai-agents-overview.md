# Wrike Spoke AI agents

The following AI agents are available for Wrike Spoke.

-   **[Wrike approvals management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-approvals-management-ai-agent.md)**  
This AI agent deletes approvals on Wrike tasks and folders after validating the approval ID.
-   **[Wrike attachment management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-attachment-management-ai-agent.md)**  
This AI agent manages Wrike attachments. It updates attachments on tasks and folders, downloads attachments to ServiceNow, and deletes attachments.
-   **[Wrike comment management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-comment-management-ai-agent.md)**  
This AI agent manages Wrike comments. It creates comments on tasks or folders and updates or deletes existing comments.
-   **[Wrike folder and project management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-folder-and-project-management-ai-agent.md)**  
This AI agent deletes folders and projects in Wrike after confirming the target with the user.
-   **[Wrike group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-group-management-ai-agent.md)**  
This AI agent deletes groups in Wrike.
-   **[Wrike task management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-task-management-ai-agent.md)**  
This AI agent deletes tasks in Wrike.
-   **[Wrike user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-wrike-wrike-user-management-ai-agent.md)**  
This AI agent manages Wrike users. It retrieves and updates user details.
