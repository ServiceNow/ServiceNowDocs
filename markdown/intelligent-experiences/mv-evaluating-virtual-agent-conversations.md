# Evaluate conversations

Use Conversational Evaluator in AI Control Tower to review conversation quality scores, and estimate the cost savings from Virtual Agent conversations.

Conversational Evaluator provides auto-evaluation scores to track conversation quality over time. You can label individual conversations to set a quality benchmark and verify auto-evaluation accuracy. The tool also converts hours saved into a currency value to estimate the cost savings from Virtual Agent conversations.
