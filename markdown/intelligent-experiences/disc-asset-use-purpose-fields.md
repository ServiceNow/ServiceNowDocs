# Use and purpose fields

Field and value reference for the **Use and purpose** section of an AI asset record. AI stewards and AI asset owners reference these values during onboarding, reviews, and audits.

## System autonomy level

|Value|Description|
|-----|-----------|
|Not Applicable|Indication that the autonomy dimension does not apply to the asset.|
|Assistive \(AI suggests\)|Mode in which the AI system suggests outputs and the user decides whether to act on them.|
|Semi-Automated \(acts with confirmation\)|Mode in which the AI system performs actions only after the user confirms each one.|
|Condition-Based Automation|Mode in which the AI system acts automatically when defined conditions are met.|
|Event-Triggered Automation|Mode in which the AI system acts automatically in response to specific events.|
|Fully Automated Execution|Mode in which the AI system acts independently without human intervention.|

## Level of human involvement

|Value|Description|
|-----|-----------|
|Not Applicable|Indication that human involvement does not apply to the asset.|
|Full User Control|Workflow in which the user makes all decisions and the AI system provides no automated action.|
|User-Guided with AI Support|Workflow in which the user directs the activity and the AI system contributes recommendations or analysis.|
|Shared Control|Workflow in which the user and the AI system share responsibility for decisions and actions.|
|AI-Initiated with User Approval|Workflow in which the AI system proposes actions and the user approves them before execution.|
|Fully Automated Workflow|Workflow in which the AI system completes the activity end to end without user involvement.|

## Interaction type with end users

|Value|Description|
|-----|-----------|
|Not Applicable|Indication that end-user interaction does not apply to the asset.|
|No Direct Interaction|Mode in which end users do not interact with the AI system.|
|Background Support|Mode in which the AI system operates behind the scenes to support a user-facing process.|
|Notifications &amp; Prompts|Mode in which the AI system communicates with end users through notifications or prompts.|
|User-Facing Recommendations|Mode in which the AI system surfaces recommendations directly to end users.|
|Chat-Based Interaction|Mode in which end users interact with the AI system through a conversational interface.|
|Interactive Experience|Mode in which end users interact directly with an AI-embedded interface or application.|

## Intended outcome of the AI system

|Value|Description|
|-----|-----------|
|Not Applicable|Indication that the intended outcome does not apply to the asset.|
|Efficiency Boost|Outcome focused on reducing the time or effort required to complete a process.|
|Quality Enhancement|Outcome focused on improving the accuracy or consistency of a process.|
|Decision Guidance|Outcome focused on supporting human decision-making with analysis or recommendations.|
|Automation of Tasks|Outcome focused on completing tasks without human action.|
|Customer Experience Upgrade|Outcome focused on improving the experience of customers or end users.|

## Additional use and purpose fields

|Field|Description|
|-----|-----------|
|Type of output produced|Description of what the AI system generates, such as text responses, decisions, or recommendations.|
|Area where the AI system is used|Functional or organizational area in which the asset operates, such as customer service, IT support, or human resources.|
|People affected by the AI system|Groups whose work or experience is influenced by the asset, such as employees, customers, or partners.|
|Data used by the system|Categories of data the AI system reads, references, or processes, such as case records, knowledge articles, or customer profiles.|
|Additional use and purpose details|Free-text notes that capture context not covered by the other use and purpose fields.|
