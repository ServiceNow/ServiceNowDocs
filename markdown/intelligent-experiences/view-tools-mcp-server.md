# View tools on the MCP server

You can view the list of tools a connected MCP server exposes on the server's details view in the AI Agent Studio.

## Before you begin

Role required: admin

## About this task

-   The MCP server detail view shows the tools the server exposes, each with tool name and description.
-   A tool count for the server is displayed.
-   The view is read-only - no add, edit, or remove capabilities are available.
-   The view is reachable from the server record without opening an agent or an Assistant \(ServiceNow Otto panel or ServiceNow Otto for Virtual Agent\).
-   View the long tool descriptions.

## Procedure

1.  Open a Model Context Protocol Server and navigate to the Tools section of the record.

    You will see the list of all the tools that the MCP server supports.

2.  Select the refresh icon to refresh the list if the MCP server updates their tools.

3.  Use the **Search** field to search for a particular tool associated with the MCP server or to just see what's available.

    **Note:** The tools shown in the list are the ones that can be configured in the Assistant to allow, block, or run in supervised mode.
