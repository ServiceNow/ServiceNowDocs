# AIOps and Leap AI agents

The following AI agents are available for AIOps and AIOps Leap.

-   **[Alert automation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-alert-automation-ai-agent.md)**  
This agent interprets free-text user requests related to alert automation and guides users to the appropriate automation experience. It detects whether the user intends to enrich alerts, group alerts, respond to alerts, or any combination of these actions.
-   **[Alert impact verification AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-alert-impact-verification-ai-agent.md)**  
This agent is responsible for eligibility validation for a given alert, to perform impact analysis on it.
-   **[Artifact creation agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-leap-artifact-creation-ai-agent.md)**  
Assists in creating and viewing artifacts such as problem records, knowledge base articles, and playbooks for an automation opportunity. The agent checks for an automation opportunity number and invokes the artifact creation topic tool to generate the required artifacts.
-   **[Business and technology management service impact analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-business-and-technology-management-service-impact-analysis-ai-agent.md)**  
This agent calculates the business and technology management services impacted by a given alert.
-   **[Manage alerts AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-manage-alerts-ai-agent.md)**  
Responsible for generating reports for a given alert and storing a structured summary with key insights and recommended next steps in the alert record.
-   **[Service instance impact analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-service-instance-impact-analysis-ai-agent.md)**  
This agent performs alert impact analysis on service instances for a given alert.
-   **[User impact analysis AI Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aiops-user-impact-analysis-ai-agent.md)**  
This agent investigates incidents and cases related to the alerts and affected services.
-   **[Artifact creation agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/leap-artifact-creation-agent-ai-agent.md)**  
The Artifact creation agent helps users create and view artifacts for an automation opportunity, such as a problem record, a knowledge base article, or a playbook.
-   **[LEAP Ansible Agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/leap-leap-ansible-agent-ai-agent.md)**  
The LEAP Ansible agent finds the Ansible job template that best matches the problem behind an automation opportunity. It recommends the template to the user and saves it to the discovered job catalog.
-   **[LEAP Ansible Execution Agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/leap-leap-ansible-execution-agent-ai-agent.md)**  
The LEAP Ansible Execution agent runs the Ansible playbooks mapped to each resolution step of an incident. It launches jobs through Ansible Automation Platform, prompts the user to complete unmapped steps manually, and reports job status on request.
-   **[LEAP KB Creation Agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/leap-leap-kb-creation-agent-ai-agent.md)**  
The LEAP KB Creation agent creates draft knowledge base articles from the resolution steps of a LEAP automation opportunity.
-   **[LEAP Problem Creation Agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/leap-leap-problem-creation-agent-ai-agent.md)**  
The LEAP Problem Creation agent creates problem records from the data of a LEAP automation opportunity.
