# AIOps and AIOps Leap AI agents

The following AI agents are available for AIOps and AIOps Leap.

-   **[Alert automation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-alert-automation-ai-agent.md)**  
This agent interprets free-text user requests related to alert automation and guides users to the appropriate automation experience. It detects whether the user intends to enrich alerts, group alerts, respond to alerts, or any combination of these actions.
-   **[Alert impact verification AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-alert-impact-verification-ai-agent.md)**  
This agent is responsible for eligibility validation for a given alert, to perform impact analysis on it.
-   **[Artifact creation agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-leap-artifact-creation-ai-agent.md)**  
Assists in creating and viewing artifacts such as problem records, knowledge base articles, and playbooks for an automation opportunity. The agent checks for an automation opportunity number and invokes the artifact creation topic tool to generate the required artifacts.
-   **[Business and technology management service impact analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-business-and-technology-management-service-impact-analysis-ai-agent.md)**  
This agent calculates the business and technology management services impacted by a given alert.
-   **[Manage alerts AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-manage-alerts-ai-agent.md)**  
Responsible for generating reports for a given alert, applying summarization tools, and storing a structured summary with key insights and recommended next steps in the AI Agent Insight table.
-   **[Service instance impact analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-service-instance-impact-analysis-ai-agent.md)**  
This agent performs alert impact analysis on service instances for a given alert.
-   **[User impact analysis AI Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aiops-user-impact-analysis-ai-agent.md)**  
This agent investigates incidents and cases related to the alerts and affected services.
