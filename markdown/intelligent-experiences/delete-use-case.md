# Delete a use case

Delete a use case and its associated fields, tables, questions, integrations, and flows from a skill when the use case is no longer needed.

## Before you begin

Role required: DocIntel Admin \[sn\_docintel.admin\] or DocIntel Manager \[sn\_docintel.manager\] role

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Skills**.

2.  In the workflow list, select **Platform**.

3.  In the Platform skills list, find a applicable skill.

4.  Select **Edit** in the options menu \(\[Omitted image "cu-options-menu.png"\] Alt text:\) for that skill.

5.  In the row of the use case you want to delete, select **Delete** in the options menu \(\[Omitted image "cu-options-menu.png"\] Alt text:\).

6.  In the confirmation dialog, select **Delete**.


## Result

The use case is deleted, including its associated fields, tables, questions, integrations, and flows.
