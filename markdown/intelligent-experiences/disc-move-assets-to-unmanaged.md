# Move AI assets to unmanaged

Remove AI assets from active governance workflows by moving them to unmanaged status, retaining them in the inventory for tracking without incurring subscription charges.

## Before you begin

Role required: sn\_ai\_governance\_ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home** &gt; **Inventory**.

2.  Select the check box for each asset that you want to move to unmanaged.

3.  From the **Action** list, select **Move to Unmanaged**.

4.  In the confirmation dialog box that appears, review your current selections.

    1.  Review each asset that you selected and its current state.

    2.  Remove any asset that you don't want to update.

5.  Select **Move to Unmanaged** to confirm.


## Result

The status for each asset that you selected changes to unmanaged.

-   Each asset remains in the inventory but no longer participates in governance workflows, including lifecycle management, risk classification, value assessment, security, and privacy.
-   Each asset is no longer charged as part of your subscription.

## What to do next

To bring assets back into governance at any time, see [Move AI assets to managed](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/disc-move-assets-to-managed.md).
