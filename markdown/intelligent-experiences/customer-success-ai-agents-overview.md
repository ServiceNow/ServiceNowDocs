# Customer Success Management AI agents

The following agents are available for Customer Success Management.

-   **[AI insight AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-ai-insight-ai-agent.md)**  
The agent answers questions about a customer engagement or account. It reports health scores, adoption scores, value realization, risks, contract value, and other engagement data, and it forecasts scores and recommends improvements.
-   **[Draft meeting scheduler AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-draft-meeting-scheduler-ai-agent.md)**  
The agent edits a draft touchpoint meeting for a customer success agent. It updates the invitees, subject, agenda, date and time, duration, and meeting link, then sends the invitation.
-   **[Email communication manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-email-communication-manager-ai-agent.md)**  
The agent retrieves the latest released product information, creates draft emails, refines them from user input, and sends them to specific recipients.
-   **[Product adoption roadmap AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-product-adoption-roadmap-ai-agent.md)**  
The agent creates a product adoption roadmap for a customer. It analyzes the engagement and similar engagements, creates the roadmap, and arranges lanes and items to match the customer's goals.
-   **[Renewal analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-renewal-analysis-ai-agent.md)**  
The agent analyzes a renewal for a contract or engagement. It combines insight scores and value realization data into a renewal report and offers to create a renewal success play.
-   **[Success health monitor AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-success-health-monitor-ai-agent.md)**  
The agent retrieves metric trend analysis for engagements. It creates a risk signal or risk occurrence for each engagement whose health metrics are declining.
-   **[Success insights AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-success-insights-ai-agent.md)**  
The agent populates score data from a selected data source and provides trend analysis of the scores to the customer success agent.
-   **[Success risk solution AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-success-risk-solution-ai-agent.md)**  
The agent resolves unaddressed risk signals. It identifies success plays based on machine learning similarity, AI Search, or a decision table, and starts the solution flows for the selected risk.
-   **[User resource recommender AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-user-resource-recommender-ai-agent.md)**  
The agent filters and ranks users by relevance and adds the top-ranked users to the input record. It runs without user interaction by using the context that starts it.
-   **[Value realization assessor AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-value-realization-assessor-ai-agent.md)**  
The agent identifies the value realized for an engagement and returns the value data to the customer success agent.
