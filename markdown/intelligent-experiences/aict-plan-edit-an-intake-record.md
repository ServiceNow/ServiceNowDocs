# Manage intake records

Update the details of an existing intake record to reflect changes in scope, priority, or other relevant information.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home 2.0**.

2.  Expand the **Plan** menu and select **Prioritize**.

3.  Scroll to the list for the record type you must edit, Demand, Product idea, or Feedback.

4.  Select the edit icon \[Omitted image "aict-plan-edit-icon.png"\] Alt text: for the record that you want to edit.

    The record is displayed in the **Edit Record** side panel.\[Omitted image "aict-plan-edit-intake-record.png"\] Alt text: Edit the intake record in the Edit Record side panel.

5.  On the form, edit the fields.

    For field information, see:

    -   [Demand form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-plan-demand-form.md)
    -   [Feedback form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-feedback-form.md)
    -   [Product idea form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-product-idea-form.md)
6.  Select **Update**.

    The edited record is displayed in the respective list if it meets the list's display criteria.
