# Slack Spoke AI agents

The following AI agents are available for Slack Spoke.

-   **[Slack conversation management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-slack-slack-conversation-management-ai-agent.md)**  
This AI agent manages Slack channels. It creates and archives channels, renames conversations, sets channel topics, and adds or removes users.
-   **[Slack notification management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-slack-slack-notification-management-ai-agent.md)**  
This AI agent posts ServiceNow record details to Slack channels. It shares incident, problem, and change details with the specified channel.
-   **[Slack user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-slack-slack-user-management-ai-agent.md)**  
This AI agent looks up Slack users from ServiceNow.
