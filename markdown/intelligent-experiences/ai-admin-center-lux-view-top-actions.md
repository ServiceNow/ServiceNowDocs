# View and activate your top actions in AI Admin Center \(Lux UI\)

View the top actions you can take right away to adopt AI capabilities on your instance.

**Important:** Lux is the new user experience for AI Admin Center. For more information on the Lux experience, see [AI Admin Center user experience \(Lux UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-admin-center-lux-user-experience.md).

The Next Experience AI Admin Center workspace is being prepared for deprecation in the November store release and will no longer be supported. For more information on the Next Experience UI, see [AI Admin Center workspace \(Next Experience UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/now-assist-center-workspace.md).

In AI Admin Center version 6.1, the Next Experience and Lux user interfaces are both available.

## Before you begin

The ServiceNow Otto panel must be enabled to activate a proposed solution. Action items work with the ServiceNow Otto panel to guide you through the setup in a chat conversation. For more information, see [Enable the ServiceNow Otto panel \(Lux UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-admin-center-lux-enable-otto-panel.md).

Role required: sn\_na\_center.nac\_admin

## About this task

The **Top actions** section of the home page displays a series of AI-generated items that represent quick-start use cases. Each use case is tailored to your environment and proposed to help you implement AI adoption, best practices, and administrative setup on the platform.

Follow these steps to review and activate a proposed solution.

**Note:** This topic describes the AI Admin Center feature based on the Lux user interface \(UI\). If you're using the Next Experience UI for AI Admin Center, see the Next Experience UI version of this topic.

## Procedure

1.  Navigate to **All** &gt; **AI Admin Center** &gt; **Home** or **Admin** &gt; **AI Admin Center**.

    The AI Admin Center opens to the home page.

    The **Top actions** section of the home page displays a list of any action items identified for your instance. If there are no action items, the section doesn't appear.

    \[Omitted image "ai-admin-center-lux-home-top-actions.png"\] Alt text: Top actions section of the AI Admin Center home page showing proposed action items.

2.  Activate a proposed action item.

    1.  Select the action item in the **Top actions** list.

        The ServiceNow Otto panel starts a guided setup conversation. The panel describes the solution, confirms the current state, and asks you to confirm before making any change.

        Use natural language to have your AI companion implement the use case.

    2.  Confirm the proposed action to implement it.

        After you successfully activate a solution, the action disappears from the **Top actions** list and a confirmation message appears.

3.  Select **View all** to see the list of proposed AI solutions.

    The AI Solutions page opens.

    \[Omitted image "ai-admin-center-lux-ai-solutions.png"\] Alt text: AI Solutions page showing the list of proposed AI solutions.

    1.  Use the search and filter options to refine the list.

        -   Type in the search box and select the **Search** icon \(\[Omitted image "icon-now-assist-center-search.png"\] Alt text: Search icon.\) to filter by search criteria.
        -   Select a combination of the filter options to filter by solution type and impact.
    2.  Select **Configure** to activate a proposed solution.

        The related application opens depending on the solution type.

    3.  Activate the solution according to the application procedure.

        For example, follow the [Activate an AI skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/configure-a-now-assist-skill.md) steps to use the AI Admin Hub.
