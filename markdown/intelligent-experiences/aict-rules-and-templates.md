# Configuring rules and templates in AI Control Tower

Configure how AI assets are classified, evaluated, valued, and secured across your organization through rules and templates.

Rules and templates settings bring together the configuration that drives automated AI governance behavior on your instance.

## Rules and templates

-   **Automation rules**

    Define the conditions under which discovered AI assets are automatically marked as managed. Use built-in rules or create your own to reduce manual classification work and keep your inventory current. For more information, see [Managing AI assets in bulk](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/disc-ai-bulk-managing-assets.md).

-   **Evaluation**

    Configure evaluation scoring for ServiceNow and external AI systems. Select which metrics are scored on each evaluated session, and use metric templates to define how individual metric scores aggregate into quality and safety scores. For more information, see [Configure an evaluation metric template](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/mon-ai-configure-metric-templates.md).

-   **Templates**

    Manage the value templates that define the productivity gain formula for AI assets. Configure default template rules that determine which template is applied to a new AI asset, and review the AI system mappings that show which template each asset is currently using. For more information, see .

-   **Cost**

    Configure the AI cost settings used to calculate net AI returns and the cost dimension of value templates. For more information, see [Configuring Cost in AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/measure-ai-configuring-aict-value-cost.md).

-   **Security**

    Configure security rules and templates that control how AI Control Tower detects and responds to security threats across your AI assets. For more information, see [Configure post-runtime security metrics](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/gov-sec-configure-event-metrics.md).
