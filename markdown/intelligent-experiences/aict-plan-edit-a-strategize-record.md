# Edit a strategize record

Update the details of an existing goal, target, or strategic priority record to reflect changes in organizational direction, scope, or measurement criteria.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home 2.0**.

2.  Expand the **Plan** menu and **Strategize**.

3.  Scroll to the Goals and targets list.

4.  Next to the record that you want to edit, select the edit icon \(\[Omitted image "aict-plan-edit-icon.png"\] Alt text:\).

    The record is displayed in the **Edit record** side panel.

5.  Edit the fields as needed.

    For field information, see:

    -   [Goal form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-goal-form.md) for goals
    -   [Target form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-target-form.md) for targets
6.  Select **Update**.

    The updated record is displayed in the Goals and target list.
