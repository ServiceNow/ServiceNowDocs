# Use Content insights AI agent

Use the Content Insights AI agent to generate information from your inputs, attached documents, or images

Use the Content insights AI agent to:

-   [Ask questions about documents and images](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ask-questions-qna.md)
-   [Extract key information from documents](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/extract-key-information.md)
-   [Summarize documents and images](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/summarize-documents.md)

-   **[Ask questions about documents and images](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ask-questions-qna.md)**  
Use question and answer \(QnA\) to ask the Content Insights AI agent specific questions about document or image and get cited answers. QnA is the agent's default mode.
-   **[Extract key information from documents](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/extract-key-information.md)**  
Use key information extraction \(KIE\) to extract structured data from documents with a predefined template, for processing standardized documents such as invoices, contracts, or forms.
-   **[Summarize documents and images](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/summarize-documents.md)**  
Use the Content Insights AI agent to generate a concise summary of document or image from a record reference or uploaded attachment.
