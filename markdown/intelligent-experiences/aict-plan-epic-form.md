# Epic form

Learn about the fields on the Epic form. Use this form to create or edit an epic from the Execute page in AI Control Tower.

These fields are displayed on the Epic form.

|Field|Description|
|-----|-----------|
|Name|Brief description of the epic. This field is required.|
|Description|Detailed information about the epic.|
|State|Current working state of the epic. The default value is Draft.|
|Owner|User assigned to this epic.|
|Planning state|State of the epic in the planning backlog. The default value is New.|
|Percent complete|Percentage of work completed for this epic. This value is calculated automatically.|
|Primary goal|Goal associated with this epic as the primary goal.|
|Strategic priority|Strategic priority associated with this epic. This value is populated automatically based on the primary goal.|
|Enabler|Indicates whether this epic is an enabler.|
|Methodology|Agile methodology used for this epic. The default value is Scrum.|
|Department|Department associated with this epic.|
|Work notes|Notes to capture updates and discussions on this epic as work progresses.|

|Field|Description|
|-----|-----------|
|Planned start date|Planned start date for this epic.|
|Planned end date|Planned end date for this epic.|
|Approved start date|Approved start date for this epic.|
|Approved end date|Approved end date for this epic.|
|Actual start date|Actual date on which work for this epic started.|
|Actual end date|Actual date on which work for this epic was completed.|

|Field|Description|
|-----|-----------|
|Priority|Priority of this epic. The default value is 4 - Low.|
|Business capabilities|Business capabilities associated with this epic.|
|Business application|Business application that this epic is related to.|
|Other impacted business applications|Business applications that this epic has an impact on.|
|Missing estimate|Number of stories in the epic that are missing estimates. This value is calculated automatically.|
|Percent complete by count|Percentage of completed work in the epic, calculated using story count. This value is calculated automatically.|
|T-Shirt size|Relative size estimate for this epic.|
|Completed count|Number of completed stories in the epic. This value is calculated automatically.|
|Completed estimate|Sum of the estimates of all completed stories in the epic. This value is calculated automatically.|
|Total count|Total number of stories in the epic. This value is calculated automatically.|
|Total estimate|Sum of the estimates of all stories in the epic. This value is calculated automatically.|
|Percent complete by estimate|Percentage of completed work in the epic, calculated using story estimates. This value is calculated automatically.|

|Field|Description|
|-----|-----------|
|WSJF score|Weighted Shortest Job First \(WSJF\) score used to prioritize and sequence epics to produce the most business value. An epic with the highest WSJF score gets the highest priority for implementation. This value is calculated automatically from the other fields in this section.|
|Time criticality|Impact on the business when deadlines are missed, for example how projected revenue gains are reduced over time when deadlines are shifted.|
|User business value|Business value of the job based on parameters such as impact on revenue or comparable capabilities available in the market.|
|Risk reduction|Measure of how much risk this epic helps avoid. Consider whether the job adds business value in other ways, creates new business opportunities, or reduces risk for a future delivery.|
|Job size|Estimated duration for completion of this epic.|
