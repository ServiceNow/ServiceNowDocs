# Review conversation evaluation scores

Review auto-evaluation scores for Virtual Agent conversations in AI Control Tower to track conversation quality over time.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward, interaction\_admin

## About this task

Compare the average auto-evaluation score with the average human feedback score to check how closely automated ratings match human judgment.

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Insights** &gt; **ServiceNow AI** &gt; **** &gt; **Evaluation**.

2.  Select the **Evaluation** tab.

3.  In the **Select metric** list, select a metric and then select **Apply**.

    Select **User Satisfaction** to view the combined score, or select an individual metric, such as **Intent Accuracy** or **Slot Filling**.

4.  In the **Select date range** list, select the time period to review.

5.  Review the **Evaluation score trend** chart.
