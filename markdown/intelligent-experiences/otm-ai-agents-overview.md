# Operational Technology Manager AI agents

The following AI agents are available for Operational Technology Manager.

-   **[OT Excel import task AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/otm-ot-excel-import-task-ai-agent.md)**  
The OT Excel import task AI agent imports Operational Technology \(OT\) device data from a spreadsheet into the Configuration Management Database \(CMDB\). The agent validates the imported records, creates remediation tasks for invalid records, and imports the valid records.
