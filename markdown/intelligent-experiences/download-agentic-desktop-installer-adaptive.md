# Download AI Desktop Actions installer for adaptive desktop actions

Download and install the AI Desktop Actions installer on your macOS machine for running adaptive desktop actions.

## Before you begin

-   This task must be completed in the ServiceNow instance.
-   Administrator privileges are required to install the AI Desktop Actions installer on the macOS system.

Role required: sn\_aia.admin or now\_assist\_panel\_user

## Procedure

1.  Navigate to **All** &gt; **AI Desktop Actions** &gt; **Downloads**.

2.  On the AI Desktop Actions Downloads page, do any of the following actions to download the required application for macOS:

    -   Select the download icon \(\[Omitted image "rpa-hub-download-icon.png"\] Alt text:\).
    -   Select the copy link \(\[Omitted image "rpa-hub-copyurl-icon.png"\] Alt text:\). In a browser, right-click and select the **Paste and go** option.
    \[Omitted image "agentic-desktop-download-msi.png"\] Alt text: Downloads page showing available installer files.

    The system might prompt you to save or open the file.

3.  Run the application installation file \(.pkg file\).

4.  Follow the onscreen instructions to complete the installation.

    AI Desktop Actions is installed for all users by default, but you can choose to install it for your account only or specify a disk location during setup.
