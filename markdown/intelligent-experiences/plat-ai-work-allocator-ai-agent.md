# Work allocator AI Agent

This AI agent automatically fetches backlog tickets, evaluates agent workloads and performance metrics, and assigns tickets to agents in a way that optimizes distribution and operational efficiency.

## Workflow

The agent is designed for support team managers and operations leads.

1.  Assign tickets to agents optimally for the assignment group indicated by the user's input.
2.  Update the records with the ticket assignment.
3.  Display the ticket assignments to the user in a readable format.
