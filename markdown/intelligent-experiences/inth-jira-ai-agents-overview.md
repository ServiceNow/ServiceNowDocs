# Jira Spoke AI agents

The following AI agents are available for Jira Spoke.

-   **[Jira audit management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-audit-management-ai-agent.md)**  
This AI agent retrieves Jira audit logs for a date range, supporting Jira Cloud, Jira Server version 9 and earlier, and Jira Server version 10 and later.
-   **[Jira group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-group-management-ai-agent.md)**  
This AI agent manages Jira groups. It creates and removes groups, adds and removes users, and looks up groups and group members.
-   **[Jira issue management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-issue-management-ai-agent.md)**  
This AI agent manages Jira issues. It looks up issues, priorities, statuses, and transitions, transitions and assigns issues, adds comments, manages watchers and attachments, and deletes issues.
-   **[Jira project management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-project-management-ai-agent.md)**  
This AI agent manages Jira projects. It creates projects and looks up a specific project or a list of projects.
-   **[Jira sprint management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-sprint-management-ai-agent.md)**  
This AI agent manages Jira sprints. It looks up, updates, and deletes sprints.
-   **[Jira story management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-story-management-ai-agent.md)**  
This AI agent manages Jira stories. It creates and updates stories and looks up stories that match given criteria.
-   **[Jira user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-user-management-ai-agent.md)**  
This AI agent manages Jira users. It creates and removes users, looks up users and the authenticated user, and retrieves a user's group memberships.
-   **[Jira utility management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jira-jira-utility-management-ai-agent.md)**  
This AI agent provides Jira utility actions. It copies issue attachments to ServiceNow records, looks up the latest attachment and comment on an issue, looks up field details, and retrieves server information.
