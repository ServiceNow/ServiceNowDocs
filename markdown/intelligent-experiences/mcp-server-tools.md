# Model Context Protocol Server Console tools

Use the following tools that are available by default with Model Context Protocol Server Console depending on the applications installed on your instance, such as ServiceNow Otto for CSM or ServiceNow Otto for ITSM.

|Name|Category|Description|
|----|--------|-----------|
|case\_summarization|AI Skill|Get a summary of details in a case record.|
|email\_recommendation|AI Skill|Get a recommended response to an email.|
|incident\_summarization|AI Skill|Get a summary of details in an incident record.|
|lookup\_case\_records|Scripted REST API|This API enables looks up case records for the case\_summarization tool.|
|lookup\_incident\_records|Scripted REST API|This API looks up incident records for the incident\_summarization tool.|
|lookup\_kb\_records|Scripted REST API| |
