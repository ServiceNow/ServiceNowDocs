# Overview tab in AI Admin Hub

The Overview tab of the AI Admin Hub console provides information about available AI plugins and skills at a glance. Learn what skills are in use and what skills you can activate.

## AI Admin Hub overview tab

Begin your exploration of AI plugins and skills in the Overview tab of AI Admin Hub console. The widgets on this tab provide metrics on how many available plugins are installed and the activation states of skills.

The following example shows the AI Admin Hub Overview page.

\[Omitted image "now-assist-admin-console-overview.png"\] Alt text: AI Admin Hub overview page.

## AI Admin Hub workflow

Take five steps to begin using the AI Admin Hub console.

-   **1. Install plugins.**

    On the **Plugins** page of the Settings tab, you can review the available plugins and install the ones that are relevant to your business needs. Each plugin contains AI skills that you can activate. The following image shows the **Available for you** tab of **Plugins**.

    \[Omitted image "explore-now-assist-3.png"\] Alt text: Available plugins are displayed in the Settings page.

-   **2. \(Optional\) Turn on the ServiceNow Otto panel.**

    You can activate the ServiceNow Otto panel from the AI Experiences tab of AI Admin Hub. For more information about the ServiceNow Otto panel, see [ServiceNow Otto panel overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/now-assist-panel-overview.md).

    This step is optional because the skills can also display in-product in the Core UI and in Workspaces.

    \[Omitted image "turn-on-now-assist-panel-experiences-page.png"\] Alt text: ServiceNow Otto panel settings on the AI Experiences tab.

-   **3. Activate skills.**

    Skills are features that are created for a specific use case in an AI application. Use the AI Skills tab to explore the skills that are available with your installed plugins. The following diagram shows the available AI skills for ITSM in the Technology workflow.

    \[Omitted image "explore-now-assist-4.png"\] Alt text: In the Technology workflow, select the workflow area to see all of the available skills. In this example, the skills for ServiceNow Otto for IT Service Management \(ITSM\) are displayed.

    After deciding which skills best fit your business needs, you can activate them from the console. Some skills require configuration, such as determining the skill inputs and triggers. You can select the skills that you want to configure in the AI Skills tab.

    The following image shows a step in the guided setup of the skill activation process, with the Chat summarization skill as an example. Skills can be displayed in-product, including the Core UI and Workspaces, or in the ServiceNow Otto panel. You can choose either or both locations.

    \[Omitted image "explore-now-assist-5.png"\] Alt text: Skill activation, at the Define trigger step of the guided setup. The Chat summarization skill is shown as an example.

-   **4. Review your AI account settings.**

    The Settings tab of AI Admin Hub enables you to set up language support \(if you have Dynamic Translation enabled on your instance\) and review your account details. Get up-to-date information about what plugins are available to you and the status of data sharing on your instance.

    \[Omitted image "now-assist-account-overview.png"\] Alt text: Settings page on the Account tab with license details that show the ServiceNow Otto panel and AI skills included in the license.

-   **5. Monitor and analyze skill performance.**

    Use the metrics available on the Overview page to review the summaries, performance information, and issues that need your attention. The following example shows the status of current plugins and active skills.

    \[Omitted image "explore-now-assist-6.png"\] Alt text: Plugin status shows that 35 plugins are installed, and four plugins are not installed. The Skills status shows 526 total skills, divided into Active, Inactive, and so forth.


The AI Admin Hub console contains the **AI Admin Hub checklist** with additional instructions for implementing ServiceNow Otto on your instance. Consult this checklist at any time to guide your implementation.

\[Omitted image "now-assist-journey-checklist.png"\] Alt text: The five steps of the AI Admin Hub Journey checklist.
