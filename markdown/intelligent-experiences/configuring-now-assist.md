# Overview tab in AI Admin Hub

The AI Admin Hub console provides quick and effortless access to the important information that you need to set up, configure, and monitor ServiceNow Otto applications and features.

x\[Omitted video\] Description: Now Assist Admin overview

## AI Admin Hub overview tab

Begin your exploration of the ServiceNow Otto features and skills in the AI Admin Hub console. This console contains everything that you need to install, configure, and learn about the different generative AI features on the ServiceNow AI Platform.

The following example shows the AI Admin Hub Overview page.

\[Omitted image "now-assist-admin-console-overview.png"\] Alt text: AI Admin Hub overview panel.

## AI Admin Hub workflow

Take five steps to begin using the AI Admin Hub console.

-   **1. Install plugins.**

    On the **Available for you** tab of the Settings page, you can review the available plugins and install the ones that are relevant to your business needs. Each plugin contains the skills that you can activate to enable generative AI features on your instance. The following diagram shows the **Available for you** tab.

    \[Omitted image "explore-now-assist-3.png"\] Alt text: Available plugins are displayed in the Settings page.

-   **2. \(Optional\) Turn on the ServiceNow Otto panel.**

    The ServiceNow Otto panel integrates the ServiceNow Otto skills into the Next Experience UI. By turning on the ServiceNow Otto panel directly from the AI Admin Hub console, you enable agents to access skills from anywhere on the ServiceNow AI Platform.

    For more information about the ServiceNow Otto panel, see [ServiceNow Otto panel overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-panel-overview.md).

    This step is optional because the skills can also display in-product in the Core UI and in Workspaces.

    You can turn the ServiceNow Otto panel on from the ServiceNow Otto Experiences page of the Admin console.

    \[Omitted image "turn-on-now-assist-panel-experiences-page.png"\] Alt text: ServiceNow Otto panel settings on the ServiceNow Otto Experiences page

-   **3. Activate skills.**

    Skills are features that are created for a specific use case in a ServiceNow Otto application. Use the ServiceNow Otto Skills page to explore the skills that are available with your installed plugins. The following diagram shows the available features and skills in the Technology workflow.

    \[Omitted image "explore-now-assist-4.png"\] Alt text: In the Technology workflow, select the workflow area to see all of the available skills. In this example, the skills for ServiceNow Otto for IT Service Management \(ITSM\) are displayed.

    After deciding which skills best fit your business needs, you can activate them from the console. Some skills require configuration so that you can customize the skill to your needs, such as determining the skill inputs and triggers. You can select the skills that you want to configure in the AI Admin Hub Features page.

    The following example shows a step in the guided setup of the skill activation process, which is choosing where to display the skill. Skills can be displayed in-product, including the Core UI and Workspaces, or in the ServiceNow Otto panel. You can choose either or both locations. The following diagram shows the process for chat summarization activation in AI Admin Hub.

    \[Omitted image "explore-now-assist-5.png"\] Alt text: Step in the skill activation process: Choosing where to display the skill. You can specify either in-product, the ServiceNow Otto panel, or both locations.

-   **4. Review your ServiceNow Otto account settings.**

    The ServiceNow Otto Admin console Settings page enables you to set up language support, if you have Dynamic Translation enabled on your instance, and review your account details. Get up-to-date information about what plugins are available to you and the status of data sharing on your instance.

    \[Omitted image "now-assist-account-overview.png"\] Alt text: Settings page on the Account tab with license details that show the ServiceNow Otto panel and ServiceNow Otto skills included in the license and that data sharing is currently on.

-   **5. Monitor and analyze skill performance.**

    Use the metrics available on the Overview page to review the summaries, performance information, and issues that need your attention. The following example shows the current plugin status, as well as the number of active skills.

    \[Omitted image "explore-now-assist-6.png"\] Alt text: Plugin status shows that three plugins are installed, and three plugins are not installed. The Skills status shows that twelve skills are active, and one skill is inactive.


The AI Admin Hub console contains the **ServiceNow Otto journey checklist** with additional instructions for implementing ServiceNow Otto on your instance.

You can consult the following checklist from the AI Admin Hub console Overview page at any time to guide your implementation of ServiceNow Otto applications, features, and skills.

\[Omitted image "now-assist-journey-checklist.png"\] Alt text: The ServiceNow Otto Journey checklist shows the ServiceNow Otto admin journey that was described in the five step workflow of this topic.
