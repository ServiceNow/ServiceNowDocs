# Box Spoke AI agents

The following AI agents are available for Box Spoke.

-   **[Box document management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-document-management-ai-agent.md)**  
This AI agent manages Box documents. It uploads, moves, and removes files, looks up file IDs, searches content, adds metadata to files, and attaches Box files to ServiceNow records.
-   **[Box document sharing AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-document-sharing-ai-agent.md)**  
This AI agent manages sharing and collaboration in Box. It creates shared links, looks up folder collaborators, and adds or removes collaborators.
-   **[Box group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-group-management-ai-agent.md)**  
This AI agent manages Box groups. It creates, updates, and deletes groups.
-   **[Box folder management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-folder-management-ai-agent.md)**  
This AI agent manages Box folders. It creates folders, looks up folder IDs, and deletes folders.
-   **[Box legal hold management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-legal-hold-management-ai-agent.md)**  
This AI agent manages Box legal hold policies. It creates, updates, unassigns, and removes policies and looks up policies and policy assignments.
-   **[Box metadata management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-metadata-management-ai-agent.md)**  
This AI agent retrieves Box metadata instances on files and folders, by file or folder ID or by metadata scope and template key.
-   **[Box retention policy management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-retention-policy-management-ai-agent.md)**  
This AI agent manages Box retention policies. It looks up policies and policy assignments and updates retention policies.
-   **[Box user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-box-box-user-management-ai-agent.md)**  
This AI agent manages Box users. It creates, updates, enables, disables, and deletes users, looks up user IDs, and adds users to groups.
