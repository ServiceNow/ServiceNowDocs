# GitLab Spoke AI agents

The following AI agents are available for GitLab Spoke.

-   **[GitLab branch management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-branch-management-ai-agent.md)**  
This AI agent manages GitLab branches. It creates and deletes branches, deletes merged branches, protects and unprotects branches, compares branches, tags, or commits, and looks up branch details.
-   **[GitLab group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-group-management-ai-agent.md)**  
This AI agent manages GitLab group membership. It adds users to groups and removes users from groups.
-   **[GitLab issue management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-issue-management-ai-agent.md)**  
This AI agent manages GitLab issues and issue notes. It creates and updates issues, adds, updates, and deletes notes, and looks up issues and their notes.
-   **[GitLab merge request management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-merge-request-management-ai-agent.md)**  
This AI agent manages GitLab merge requests. It creates, updates, and accepts merge requests, adds, updates, and deletes merge request notes, and looks up merge requests and their notes.
-   **[GitLab package management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-package-management-ai-agent.md)**  
This AI agent manages GitLab packages and container registry repositories. It looks up packages, package files, and registry repositories, and deletes packages, package files, repositories, and repository tags.
-   **[GitLab pipeline management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-pipeline-management-ai-agent.md)**  
This AI agent retrieves GitLab pipeline information. It looks up project pipelines, a pipeline by ID, a pipeline's jobs, and its test report.
-   **[GitLab project management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-project-management-ai-agent.md)**  
This AI agent manages GitLab projects and milestones. It creates, updates, archives, and deletes projects, manages user and group access, creates, updates, and deletes milestones, and looks up projects, jobs, and milestones.
-   **[GitLab source code management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-source-code-management-ai-agent.md)**  
This AI agent works with GitLab repository source code. It adds new files to a repository and looks up commits and commit diffs for a project.
-   **[GitLab token management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-gitlab-gitlab-token-management-ai-agent.md)**  
This AI agent manages GitLab personal access tokens. It looks up tokens and revokes a token that is no longer needed.
