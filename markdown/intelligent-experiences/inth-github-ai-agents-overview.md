# GitHub Spoke AI agents

The following AI agents are available for GitHub Spoke.

-   **[GitHub branch management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-github-github-branch-management-ai-agent.md)**  
This AI agent manages GitHub branches. It lists a repository's branches and creates new branches.
-   **[GitHub code automation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-github-github-code-automation-agent-ai-agent.md)**  
This AI agent acts as a coding partner for GitHub repositories. It clarifies requirements, proposes an approach, generates or updates code in context, and commits changes to a working branch and opens a pull request.
-   **[GitHub issue management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-github-github-issue-management-ai-agent.md)**  
This AI agent manages GitHub issues. It creates issues and looks up a repository's issues.
-   **[GitHub repository management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-github-github-repository-management-ai-agent.md)**  
This AI agent manages GitHub repositories and pull requests. It creates and deletes repositories, creates and merges pull requests, manages pull request comments, and looks up repositories, milestones, pull requests, and repository events.
-   **[GitHub source code management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-github-github-source-code-management-ai-agent.md)**  
This AI agent works with GitHub repository content. It creates or updates files, looks up file content, and looks up commits, commit information, and commit comments.
