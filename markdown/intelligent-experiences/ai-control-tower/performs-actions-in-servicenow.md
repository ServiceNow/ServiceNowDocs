# Connect to AWS from ServiceNow

Connecting to AWS from ServiceNow for a hyperscaler connection.

There are two procedures for connecting AWS to ServiceNow, which include connecting for AI asset discovery and usage. To complete these procedures, you will must follow the necessary sub steps in the order for both AI asset discovery and usage.

-   [Create a hyperscaler connection for asset discovery from AWS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-a-hyperscaler-connection-for-asset-discovery-for-aws.md)
    1.  [Create a connection alias for asset discovery for AWS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-a-connection-alias-for-ai-discovery-for-aws.md)
    2.  [Create a HTTP\(s\) connection for asset discovery for AWS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-a-http-s-connection-for-ai-discovery-for-aws.md)
    3.  [Create an AWS credential for asset discovery](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-an-aws-credential-for-ai-discovery.md)
-   [Create a hyperscaler connection for usage from AWS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-a-hyperscaler-connection-for-usage-from-aws.md)
    1.  [Create a connection alias for usage for AWS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-a-connection-alias-for-usage-from-aws.md)
    2.  [Create a HTTP\(s\) connection for usage for AWS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-a-http-s-connection-for-usage-for-aws.md)
    3.  [Create an AWS credential for usage](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-an-aws-credential-for-usage.md)
