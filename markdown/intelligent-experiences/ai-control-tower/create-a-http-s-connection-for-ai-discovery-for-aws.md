# Create a HTTP\(s\) connection for asset discovery for AWS

Use AI Control Tower workspace to create a HTTP\(s\) connection for asset discovery for AWS.

## Before you begin

Role required: admin

## Procedure

1.  Open the Connection and credential alias record page.

2.  Under the Connections section, select **New** to create a HTTP\(s\) connection.

    A new HTTP\(s\) connection new record page is created.

3.  Enter the Name.

4.  Enter the Credential.

    For more information on creating AWS credential, see [Create an AWS credential for asset discovery](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-control-tower/create-an-aws-credential-for-ai-discovery.md)

5.  Enter the Connection url.

6.  Enter the Connection alias.

7.  Enter the Attributes.

8.  Select **Submit**.

    A new HTTP\(s\) connection has been created.
