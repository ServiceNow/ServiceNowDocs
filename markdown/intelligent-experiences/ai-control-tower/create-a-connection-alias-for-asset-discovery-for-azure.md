# Create a connection alias for Azure Foundry

Use the AI Control Tower workspace to create a connection alias for asset discovery for Azure Foundry.

## Before you begin

Role required: admin

## Procedure

1.  Enter the look-up list of connection alias field.

    When opened, the look-up list shows a list of existing connection aliases; you can select an appropriate alias or select New to navigate to the new record page.

    A new connection &amp; credential aliases record page appears.

2.  Enter the Name.

3.  Enter the Parent Alias: sn\_ai\_disc\_Azure\_Foundry\_for\_AICT

4.  Click **Submit**.

    The connection alias is configured
