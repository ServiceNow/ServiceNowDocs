# Create a connection alias for usage for AWS

Use the AI Control Tower workspace to create a connection alias for usage for AWS

## Before you begin

Role required: admin

## Procedure

1.  Enter the look-up list of Connection alias field.

    When opened, the look-up list shows a list of existing connection aliases; you can select an appropriate alias or select New to navigate to the new record page.

    A new connection &amp; credential aliases record page appears.

2.  Enter the Name.

3.  Enter the Parent alias: sn\_ai\_disc\_Amazon\_Cloudwatch\_for\_AICT

4.  Click **Submit**.


## Result

Connection alias is configured.
