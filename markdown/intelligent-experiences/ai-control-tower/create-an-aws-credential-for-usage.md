# Create an AWS credential for usage

Use the AI Control Tower workspace to create an AWS credential for usage.

## Before you begin

Role required: admin

## Procedure

1.  Select the look-up list of the **Credential** field.

    The AWS credentials new record page is displayed

2.  Enter the Name.

3.  Enter the Access Key ID.

4.  Enter the Secret Access Key.

5.  Enter the authentication algorithm: **Amazon CloudWatch Algorithm for AICT**.

6.  Select **Submit**.

    The AWS credential is created.
