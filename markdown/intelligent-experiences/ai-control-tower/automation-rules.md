# Automation rules

The Automation rules define how AI assets are set to managed.

## Automation rules Overview

The Automation rules page displays all default rules available in AI Control Tower. AI Stewards can modify existing rules or create based on their organizational requirements.

## Rule limits

-   Maximum rules allowed: 10
-   Maximum rules that can be active simultaneously: 5

## How rules are applied

Once activated, rules are enforced according to the schedule defined in the Run AI Asset Management Rules Scheduled job.
