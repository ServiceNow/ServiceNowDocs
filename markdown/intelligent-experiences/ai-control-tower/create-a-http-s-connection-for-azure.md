# Create a HTTP\(s\) connection for Azure Foundry

Use the AI Control Tower workspace to create a HTTP\(s\) connection for Azure Foundry.

## Before you begin

Role required: admin

## Procedure

1.  Open the Connection and credential alias record page.

2.  Under the **Connections** section, select **New** to create a HTTP\(s\) connection.

    A new HTTP\(s\) connection new record page is created.

3.  Enter the Name.

4.  Enter the Credential.

    This credential is user/customer specific. You can create **OAuth credential**or any other credential as per your specifications.

5.  Enter the Connection url.

6.  Enter the Connection Alias.

7.  Enter the Attributes such as **Subscription ID**, **Project Name**, **Resource Name**, and **Resource Group Name**, and **Workspace Name**.

8.  Click **Submit**.


## Result

A new HTTP\(s\) connection has been created.
