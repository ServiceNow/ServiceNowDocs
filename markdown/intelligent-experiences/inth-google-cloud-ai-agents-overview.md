# Google Cloud Storage Spoke AI agents

The following AI agents are available for Google Cloud Storage Spoke.

-   **[Google Cloud Storage bucket access control management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cloud-google-cloud-storage-bucket-access-control-management-ai-agent.md)**  
This AI agent manages access controls for Google Cloud Storage buckets. It lists, creates, updates, and deletes bucket access control entries.
-   **[Google Cloud Storage bucket management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cloud-google-cloud-storage-bucket-management-ai-agent.md)**  
This AI agent manages Google Cloud Storage buckets. It creates, updates, and deletes buckets, lists all buckets, and retrieves bucket details, labels, and IAM policies.
-   **[Google Cloud Storage object access control management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cloud-google-cloud-storage-object-access-control-management-ai-agent.md)**  
This AI agent manages access controls for Google Cloud Storage objects. It lists, creates, updates, and deletes object access control entries.
-   **[Google Cloud Storage object management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cloud-google-cloud-storage-object-management-ai-agent.md)**  
This AI agent manages objects in Google Cloud Storage buckets. It uploads, downloads, copies, rewrites, updates, and deletes objects, changes storage classes, and lists or retrieves object details.
