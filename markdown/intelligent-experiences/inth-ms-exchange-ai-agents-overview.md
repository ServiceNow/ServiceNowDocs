# Microsoft Exchange Online Spoke AI agents

The following AI agents are available for Microsoft Exchange Online Spoke.

-   **[Microsoft Exchange Online calendar management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-exchange-microsoft-exchange-online-calendar-management-ai-agent.md)**  
This AI agent manages Microsoft Exchange Online calendars. It creates and deletes events, finds meeting times, manages event attachments, and looks up calendars, events, occurrences, calendar views, and time zones.
-   **[Microsoft Exchange Online mail management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-exchange-microsoft-exchange-online-mail-management-ai-agent.md)**  
This AI agent manages Microsoft Exchange Online mail. It looks up mail folders and messages, deletes messages, and sets mailbox automatic replies.
-   **[Microsoft Exchange Online meeting scheduler AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-exchange-microsoft-exchange-online-meeting-scheduler-ai-agent.md)**  
This AI agent schedules meetings in Microsoft Exchange Online. It collects the attendees, subject, date, and time zone, finds times when attendees are available, and creates the calendar event.
-   **[Microsoft Exchange Online metadata retrieval management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-exchange-microsoft-exchange-online-metadata-retrieval-management-ai-agent.md)**  
This AI agent retrieves Microsoft Exchange Online reference data. It looks up room metadata and time zone metadata.
-   **[Microsoft Exchange Online room management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-exchange-microsoft-exchange-online-room-management-ai-agent.md)**  
This AI agent looks up rooms in Microsoft Exchange Online so that users can find meeting spaces.
