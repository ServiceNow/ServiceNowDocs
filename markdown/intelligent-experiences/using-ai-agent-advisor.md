# Using AI Agent Advisor

Use AI Agent Advisor to automatically discover automation opportunities in your instance and deploy AI agents to implement the automations.

AI Agent Advisor is the back-end engine that finds and proposes AI automation opportunities for your instance. It must be installed with AI Admin Center for the full experience.

## AI Agent Advisor in AI Admin Center

Use AI Agent Advisor in AI Admin Center to automatically discover automation opportunities in your instance and deploy AI agents to implement the automations.

AI Admin Center enables you to perform the following activities using AI Agent Advisor:

-   [View your automation opportunities](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-center-view-automation-opportunities.md)

    Review the automation opportunities that AI Agent Advisor has identified for your instance.

-   [Implement an automation opportunity from AI Admin Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/activate-automation-opportunity-now-assist-center.md)

    Deploy a matched AI agent or a new agent to automate a resolution for an identified automation opportunity.

-   [Edit an AI agent from an automation opportunity](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-center-edit-opportunity-agent.md)

    Edit an AI agent that was created for an automation opportunity.


For more information, see [Using AI Agent Advisor in AI Admin Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-center-using-ai-agent-advisor.md).

## AI Agent Advisor in AI Control Tower

View your top automation opportunities from AI Agent Advisor as actionable recommendations in AI Control Tower.

The integration with AI Control Tower activates automatically on installation of AI Agent Advisor and AI Admin Center. As AI Agent Advisor completes each recurring scheduled analysis of your instance records to discover automation opportunities, the highest-value recommendations display in AI Control Tower.

Select the recommendation to open the Automation details page in AI Admin Center, where you can set up and deploy an AI agent to automate the solution.

For more information, see [Recommendations and AI insights](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aict-recommendations-ai-insights.md).

## AI Agent Advisor in AI Agent Studio

Use AI Agent Studio to view and edit the prebuilt AI agents matched to each automation opportunity from AI Agent Advisor.

AI Agent Advisor pregenerates an AI agent for each automation opportunity it discovers. The AI agent has a **Pre-built AI Agent** solution type and includes a name, description, resolution steps, recommended tools, recommended skills, example records, and projected savings.

The AI Agent Advisor home page displays the AI agents pregenerated by AI Agent Advisor. As AI Agent Advisor completes each recurring scheduled analysis of your instance records to discover automation opportunities, pregenerated agents are updated to reflect the resolution plan and AI agent matches.

Select the AI agent to open it on the editing page in AI Agent Advisor, where you can refine AI agent as needed to automate the solution. The AI agent status then changes from **Recommended** to **Built** and resides in your agent inventory.

For more information, see [AI Agent Studio overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/ai-agent-studio.md).
