# Manage use case

Use cases can be modified, duplicated, deactivated, or deleted after initial setup.

After a use case is set up, you can perform the following tasks:

-   [Change the language models for a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/change-llm-use-case.md)
-   [Edit a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/edit-use-case.md)
-   [Copy a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/make-copy-use-case.md)
-   [Deactivate a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/deactivate-use-case.md)
-   [Delete a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/delete-use-case.md)

-   **[Change the language models for a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/change-llm-use-case.md)**  
Select the LLM and file language for a use case to control how documents are processed for information extraction. Change these settings when the default model doesn't suit your use case.
-   **[Copy a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/make-copy-use-case.md)**  
Copy an existing use case to use as a starting point for a similar one. The copy includes the original fields, tables, questions, integrations, and flows.
-   **[Edit a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/edit-use-case.md)**  
Update an existing use case to modify its name, fields, tables, questions, integrations, and flows. Use cases marked as read-only must be copied before you can edit them.
-   **[Deactivate a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/deactivate-use-case.md)**  
Deactivate a use case to stop it from being applied during document processing when it is no longer relevant to your document intelligence workflows.
-   **[Delete a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/delete-use-case.md)**  
Delete a use case and its associated fields, tables, questions, integrations, and flows from a skill when the use case is no longer needed.
