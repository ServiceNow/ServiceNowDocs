# Google Tasks Spoke AI agents

The following AI agents are available for Google Tasks Spoke.

-   **[Google Tasks AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-google-tasks-google-tasks-ai-agent.md)**  
This AI agent finds a Google Tasks task list ID from the task list name.
-   **[Google Tasks task management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-google-tasks-google-tasks-task-management-ai-agent.md)**  
This AI agent manages tasks in Google Tasks. It creates, updates, completes, retrieves, and deletes tasks, and finds a task list ID from its name.
-   **[Google Tasks tasklist management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-google-tasks-google-tasks-tasklist-management-ai-agent.md)**  
This AI agent manages task lists in Google Tasks. It creates, updates, and deletes task lists, retrieves a specific task list or all task lists, and finds a task list ID from its name.
