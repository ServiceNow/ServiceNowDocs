# ServiceNow Cowork reference

PLACEHOLDER: Short description of the reference information provided for ServiceNow Cowork.

-   **[Turn off local MCP servers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/turn-off-local-mcp-servers.md)**  
Turn off local MCP servers for users or user groups so that Cowork can't run MCP server actions directly on user devices.
-   **[Prevent changes to sandbox files](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/prevent-changes-sandbox.md)**  
Add a filesystem deny rule to your sandbox policy so that agent actions can't modify files in the sandbox runtime directory on user devices.
-   **[Environment and capability controls](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/environment-capability-controls.md)**  
Environment and capability controls limit what ServiceNow Cowork can access while an action runs, keeping the agent within the boundaries you set.
-   **[Test a ServiceNow Cowork policy change](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/test-cowork-policy-change.md)**  
Verify that a policy change works as intended before you apply it to all users.
