# Using ServiceNow Cowork

Use ServiceNow Cowork to get started with tasks, connect systems and extend Cowork capabilities.

-   **[Start a ServiceNow Cowork chat session](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/get-started-with-cowork.md)**  
Send your first request to ServiceNow Cowork, from a simple question to a complex multi-step task, and track its progress.
-   **[Select AI model and workspace folders](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/select-model-folders.md)**  
Select the AI model the agent uses, confirm its connection, and set the folders it works in. These settings control the quality of the agent's responses and limits file access to the selected folders.
-   **[Respond to approval requests in Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/respond-approval-requests.md)**  
Before Cowork takes a sensitive action, such as changing a record or deleting a file, it pauses and asks for your permission. Responding to these requests keeps you in control of what the agent does on your behalf.
-   **[Assign tasks to ServiceNow Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/assign-tasks-cowork.md)**  
Use ServiceNow Cowork to complete multi-step work, such as investigating incidents, creating reports, or coordinating updates across platforms. Combine skills, sub-agents, and connectors in a single request so Cowork can complete the whole piece of work from start to finish.
-   **[Track tasks in Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/track-respond-tasks.md)**  
Check and track the progress of the tasks you have delegated and respond when Cowork needs your input. Tracking tasks lets you keep working while Cowork completes them, and responding quickly keeps paused tasks from stalling.
-   **[Connectors in ServiceNow Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/connectors-in-cowork.md)**  
Connectors link ServiceNow Cowork to the platforms you work in, so Cowork can read and update your real data, not just answer questions.
-   **[Extend ServiceNow Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/extending-cowork.md)**  
Extend Cowork with skills, scheduled task, Model Context Protocol \(MCP\) servers, and sub-agents so the agent can handle more of your work. Each option adds new instructions, tools, or specialized agents, and you control what the agent can access.
-   **[Review and revoke standing approvals](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/review-revoke-approvals.md)**  
Review the actions you have allowed Cowork to take without asking, and revoke any you no longer require.
-   **[Set up TOTP authorization for sensitive actions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/setup-totp-security.md)**  
Set up TOTP authorization to add another layer of security check before performing any sensitive action, such as changing records, deleting files, or sending messages on your behalf.
-   **[Set agent limits and safeguards](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/set-agent-limits-safeguards.md)**  
Set limits on how long the agent runs and when it checks in with you, so it doesn't use more time or resources than a task needs and you stay in control of long runs.
-   **[Update ServiceNow Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/update-cowork.md)**  
ServiceNow Cowork checks for updates automatically and verifies each update before it installs. You can also check for updates yourself at any time.
