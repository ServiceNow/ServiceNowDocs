# Configure Value insights

Configure value insights in AI Control Tower to measure and track the productivity value delivered by your AI systems.

## Configuration overview

AI Control Tower uses value templates to calculate the business value delivered by your AI systems. Value templates define a formula that measures productivity based on system usage, time, and quality metrics.

By configuring value insights, you establish how your organization quantifies AI system performance and impact. This enables stakeholders to make data-driven decisions about AI investments and system optimization.

## Configuration workflow

Configure value insights by following these high-level steps:

1.  Create or select a template that defines your value calculation formula.
2.  Map the template to specific AI systems or define default template rules to apply the template automatically.
3.  Test the template against available datasets to validate calculations.
4.  Publish the template to activate value calculations across your instances.

## Roles

You must have one of the following roles to configure value insights:

-   AI steward \(sn\_ai\_governance\_ai\_steward\)
-   AI asset owner \(sn\_ai\_asset\_mgmt.ai\_asset\_owner\)
