# Document Intelligence forms

Use forms to view and update Document Intelligence information.

-   **[Check box list form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/intelligent-experiences/document-intelligence/check-box-list-form.md)**  
The Check box list form enables you to define a check box list for extraction.
-   **[Single field form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/intelligent-experiences/document-intelligence/single-field-form.md)**  
The Single field form enables you to define a single field for extraction.
-   **[Single field group form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/intelligent-experiences/document-intelligence/single-field-group-form.md)**  
The Single field group form enables you to define a related group of single fields for extraction.
-   **[Table form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/intelligent-experiences/document-intelligence/table-form.md)**  
The Table form enables you to define a table for extraction.
