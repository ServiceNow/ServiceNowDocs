# Duplicate a document extraction use case

Make a copy of a use case to save time when you want to create a new use case that shares a similar structure to another.

## Before you begin

Role required: sn\_docintel.manager

## About this task

Follow these steps to create a copy of a use case along with its fields, field groups, integrations, flows, and all related machine learning \(ML\) models.

## Procedure

1.  Navigate to **All** &gt; **Document Intelligence** &gt; **Document Data Extraction Administration** &gt; **Use Cases**.

2.  In the list, select the display name of the use case that you want to copy.

    \[Omitted image "docintel-duplicate-use-case-1.png"\] Alt text: List of data extraction use cases.

3.  On the use case screen, select the Duplicate this use case icon \(\[Omitted image "icon-docintel-duplicate.png"\] Alt text: Duplicate this use case icon\).

4.  In the Duplicate use case box, type a name for the new use case.

    \[Omitted image "docintel-duplicate-use-case-2.png"\] Alt text: Duplicate use case modal.

5.  Select **Duplicate**.


## Result

The duplicated use case is displayed in the use cases list.
