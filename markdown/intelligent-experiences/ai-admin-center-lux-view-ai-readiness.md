# View your AI readiness in AI Admin Center \(Lux UI\)

Review the results of readiness assessments run for your instance.

**Important:** Lux is the new user experience for AI Admin Center. For more information on the Lux experience, see [AI Admin Center user experience \(Lux UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-admin-center-lux-user-experience.md).

The Next Experience AI Admin Center workspace is being prepared for deprecation in the November store release and will no longer be supported. For more information on the Next Experience UI, see [AI Admin Center workspace \(Next Experience UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-center-workspace.md).

In AI Admin Center version 6.1, the Next Experience and Lux user interfaces are both available.

## Before you begin

AI readiness assessments are run on your instance to produce the results that you can view in these steps. You can re-run an AI readiness assessment at any time to update the results. For more information, see [Run the AI readiness assessment job in AI Admin Center \(Lux UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/ai-admin-center-lux-run-assessment-job.md).

Role required: sn\_na\_center.nac\_admin

## About this task

Follow these steps to review and evaluate the readiness of your instance for AI adoption.

**Note:** This topic describes the AI Admin Center feature based on the Lux user interface \(UI\). If you're using the Next Experience UI for AI Admin Center, see the Next Experience UI version of this topic.

## Procedure

1.  Navigate to **All** &gt; **AI Admin Center** &gt; **Home** or **Admin** &gt; **AI Admin Center**.

    The AI Admin Center opens to the home page.

2.  Review the **Readiness** section of the home page to see the overall AI readiness for the instance.

    The section displays data visualizations for overall instance health and data quality.

3.  Select **View all** in the **Readiness** section or select **Readiness** \(\[Omitted image "icon-aiac-lux-nav-readiness.png"\] Alt text: Readiness icon.\) in the side navigation panel to view the complete list of AI readiness checks.

    The AI readiness page opens showing tabs for **Instance health** and **Data quality**.

    Each tab shows a general assessment summary and a list of checks performed for individual product areas.

    \[Omitted image "ai-admin-center-lux-readiness-page.png"\] Alt text: AI readiness page showing the Instance health tab.

4.  Select a tab to view the check results.

    -   Select the **Instance health** tab to view the results of checks performed for the applications installed on your instance.
    -   Select the **Data quality** tab to view the results of checks performed for the data in your instance.
    \[Omitted image "ai-admin-center-lux-readiness-data-quality.png"\] Alt text: Data quality tab on the AI readiness page.

5.  Select a combination of the filter option buttons to filter by rating and product area.

6.  Select the **Expand** icon \(\[Omitted image "icon-aiac-lux-expand.png"\] Alt text: Expand icon.\) for a check to view the details.


## What to do next

Resolve the reported issues to improve AI implementation readiness.
