# Configure users and roles

Add and manage role to a user group to grant its members the corresponding permissions in AI Control Tower.

## Before you begin

Role required: admin

Confirm the following:

-   The role you want to assign must already exist in the system.
-   Identify which user group requires the role — AI Stewards, AI Product Owners, or AI Risk and Compliance Managers.

## Procedure

1.  Navigate to **Settings** &gt; **Users and roles**.

    The Users and roles page displays AI Stewards, AI Product Owners, or AI Risk and Compliance Managers user groups with their current user and role counts.

2.  To add a user, select **Add users**.

    1.  Select the user from the list to add.

    2.  Select **Add** to add the user.

3.  To manage the users in the group, select **View group details**.

    1.  Select the user from the list to add or remove.

    2.  Select **Add** user to add or **Remove from group** to remove.

        **Note:** You can't remove yourself from the group.
