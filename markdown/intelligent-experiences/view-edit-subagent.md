# View and edit a sub-agent

Review a sub-agent's system prompt to understand how it behaves, and edit it when its results don't match what you need or its scope needs to change.

## Before you begin

Role required: sn\_app\_cowork.user

## Procedure

1.  Navigate to **Settings** &gt; **Sub-Agents**.

2.  Enter a term in the **Search sub-agents** field to find a sub-agent.

3.  Select the sub-agent.

    A details panel opens with the sub-agent's name, description, system prompt, and the file that stores it.

4.  Select **Preview** for formatted text or **Source** for Markdown to change how the system prompt displays.

5.  Select **Edit Sub-Agent**.

6.  Make the updates.

7.  Select **Update**.


## Result

The sub-agent uses your updated settings the next time it runs.
