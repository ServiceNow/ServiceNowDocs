# Microsoft OneDrive Spoke AI agents

The following AI agents are available for Microsoft OneDrive Spoke.

-   **[Microsoft OneDrive drive management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-onedrive-microsoft-onedrive-drive-management-ai-agent.md)**  
This AI agent looks up Microsoft OneDrive drives.
-   **[Microsoft OneDrive file management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-onedrive-microsoft-onedrive-file-management-ai-agent.md)**  
This AI agent manages Microsoft OneDrive files.
-   **[Microsoft OneDrive folder management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-onedrive-microsoft-onedrive-folder-management-ai-agent.md)**  
This AI agent manages Microsoft OneDrive files and folders. It creates folders, moves and renames items, and deletes files or folders.
-   **[Microsoft OneDrive permission management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-onedrive-microsoft-onedrive-permission-management-ai-agent.md)**  
This AI agent manages Microsoft OneDrive permissions. It creates sharing links and looks up, updates, and deletes permissions on files and folders.
-   **[Microsoft OneDrive sharing management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-onedrive-microsoft-onedrive-sharing-management-ai-agent.md)**  
This AI agent adds and removes collaborators on Microsoft OneDrive files and folders.
