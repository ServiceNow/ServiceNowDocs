# Client Software Distribution 2.0 AI agents

The following AI agents are available for Client Software Distribution 2.0.

-   **[Catalog item creation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-catalog-item-creation-ai-agent.md)**  
This AI agent creates service catalog items for applications from Microsoft Intune, Jamf, and Microsoft Endpoint Configuration Manager. It configures the software model, identifies or creates the target groups or collections, and creates the software configuration and catalog item.
-   **[Jamf application targets addition AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-jamf-application-targets-addition-ai-agent.md)**  
This AI agent adds static groups as targets to computer or mobile device applications in Jamf. It identifies the group and application, checks whether the group is already a target, confirms the request with the user, and reports the result.
-   **[Jamf application targets removal AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-jamf-application-targets-removal-ai-agent.md)**  
This AI agent removes static groups as targets from computer or mobile device applications in Jamf. It identifies the group and application, checks that the group is a target, confirms the request with the user, and reports the result.
-   **[Jamf group creation management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-jamf-group-creation-management-ai-agent.md)**  
This AI agent creates static computer, mobile device, or user groups in Jamf. It collects the group type and name, confirms the request with the user, and reports the result or any error.
-   **[Jamf group deletion management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-jamf-group-deletion-management-ai-agent.md)**  
This AI agent deletes static computer, mobile device, or user groups in Jamf. It confirms the deletion with the user and, when applications target the group, offers to remove those targets first so that the deletion can proceed.
-   **[Jamf group membership addition AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-jamf-group-membership-addition-ai-agent.md)**  
This AI agent adds computers, mobile devices, or users to static groups in Jamf. It identifies the group and the member, confirms the request with the user, and reports the result or any error.
-   **[Jamf group membership removal AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-jamf-group-membership-removal-ai-agent.md)**  
This AI agent removes computers, mobile devices, or users from static groups in Jamf. It identifies the group and the member, confirms the request with the user, and reports the result or any error.
-   **[Microsoft Endpoint Configuration Manager application targets addition AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-endpoint-configuration-manager-application-targets-addition-ai-agent.md)**  
This AI agent adds collections as deployment targets to applications in Microsoft Endpoint Configuration Manager. It collects the collection, application, and deployment settings, confirms the request with the user, and reports the result.
-   **[Microsoft Endpoint Configuration Manager application targets removal AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-endpoint-configuration-manager-application-targets-removal-ai-agent.md)**  
This AI agent removes collections as deployment targets from applications in Microsoft Endpoint Configuration Manager. It identifies the collection and application, confirms the request with the user, and reports the result or any error.
-   **[Microsoft Endpoint Configuration Manager collection creation management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-endpoint-configuration-manager-collection-creation-management-ai-agent.md)**  
This AI agent creates device or user collections in Microsoft Endpoint Configuration Manager. It collects the required details, confirms the request with the user before acting, and reports the result or any error.
-   **[Microsoft Endpoint Configuration Manager collection deletion management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-endpoint-configuration-manager-collection-deletion-management-ai-agent.md)**  
This AI agent deletes device or user collections in Microsoft Endpoint Configuration Manager. It confirms the deletion with the user and, when applications target the collection, offers to remove those targets first so that the deletion can proceed.
-   **[Microsoft Endpoint Configuration Manager collection membership addition AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-endpoint-configuration-manager-collection-membership-addition-ai-agent.md)**  
This AI agent adds devices or users to collections in Microsoft Endpoint Configuration Manager. It collects the required details, confirms the request with the user, checks whether the member already belongs to the collection, and reports the result.
-   **[Microsoft Endpoint Configuration Manager collection membership removal AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-endpoint-configuration-manager-collection-membership-removal-ai-agent.md)**  
This AI agent removes devices or users from collections in Microsoft Endpoint Configuration Manager. It collects the required details, confirms the request with the user, checks that the member belongs to the collection, and reports the result.
-   **[Microsoft Intune application assignment creation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-intune-application-assignment-creation-ai-agent.md)**  
This AI agent creates application assignments in Microsoft Intune, which target an application to a group. It identifies the group, application, and assignment intent, confirms the request with the user, and reports the result.
-   **[Microsoft Intune application assignment deletion AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-intune-application-assignment-deletion-ai-agent.md)**  
This AI agent deletes application assignments in Microsoft Intune, which removes a group as a target of an application. It identifies the group, application, and assignment intent, confirms the request with the user, and reports the result.
-   **[Microsoft Intune group creation management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-intune-group-creation-management-ai-agent.md)**  
This AI agent creates Microsoft 365 or security groups in Microsoft Intune. It collects the group details, suggests a group description, confirms the request with the user, and reports the result or any error.
-   **[Microsoft Intune group deletion management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-intune-group-deletion-management-ai-agent.md)**  
This AI agent deletes groups in Microsoft Intune. It confirms the deletion with the user and, when applications are assigned to the group, lets the user delete those assignments, keep them, or cancel the deletion.
-   **[Microsoft Intune group membership addition AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-intune-group-membership-addition-ai-agent.md)**  
This AI agent adds devices, users, or owners to groups in Microsoft Intune. It identifies the group and the member, confirms the request with the user, and reports the result or any error.
-   **[Microsoft Intune group membership removal AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-csdv2-microsoft-intune-group-membership-removal-ai-agent.md)**  
This AI agent removes devices, users, or owners from groups in Microsoft Intune. It identifies the group and the member, confirms the request with the user, and reports the result or any error.
