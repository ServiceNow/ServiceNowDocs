# Value realization assessor AI agent

The agent identifies the value realized for an engagement and returns the value data to the customer success agent.

## Workflow

The agent helps the user see how much value an engagement has realized.

1.  Ask the user for the engagement number if it is not already available.
2.  Validate the engagement number and get the engagement record.
3.  Get the value data for the engagement and return it.
