# Calculate Virtual Agent cost savings

Estimate cost savings from Virtual Agent conversations by entering an hourly rate in the Value view of Conversational Evaluator.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward, interaction\_admin

## About this task

The **Impact** view shows the total hours saved by Virtual Agent conversations. Enter an hourly rate to see the estimated dollar value of those savings.

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Insights** &gt; **ServiceNow AI** &gt; **** &gt; **Evaluation**.

2.  Select the **Evaluation** tab.

3.  Select **Impact**.

4.  In the **Select date range** list, select the time period to calculate.

5.  In the **Estimated cost saving calculation** section, enter a value in the **Hourly rate** field.

6.  Select a currency from the **currency** list.

7.  Select **Update**.


## Result

You can see the estimated cost savings from Virtual Agent conversations.
