# Sales CRM for Telecommunications AI agents

The following AI agents are available for Sales CRM for Telecommunications.

-   **[Move order voice AI voice agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-move-order-voice-ai-voice-agent.md)**  
The AI voice agent helps a caller move their telecom service to a new address. It collects the caller's details over the phone, matches them to existing records, checks that the service is available at the new address, and creates a move order.
-   **[Order enrichment AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-order-enrichment-ai-agent.md)**  
The AI agent finds the tasks needed to enrich a top-level order line item and its child order line items. It uses historical data from similar order line items to suggest tasks, and it creates the tasks after the user confirms them.
-   **[Order fallout AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-order-fallout-ai-agent.md)**  
The AI agent analyzes the work notes and comments on an order task, identifies issues or errors, and maps them to existing fallout types. It creates fallout records so that the errors can be followed up.
-   **[Order fulfillment AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-order-fulfillment-ai-agent.md)**  
The AI agent finds the tasks needed to fulfill a domain order. It uses historical data from similar domain orders to suggest tasks, and it creates the tasks after the user confirms them.
-   **[Telco order fulfilment template creation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tmt-telco-order-fulfilment-template-creation-agent-ai-agent.md)**  
The AI agent generates a task plan template from the specification and dependency JSON provided to it.
