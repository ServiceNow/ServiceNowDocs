# Microsoft Security Response Spoke AI agents

The following AI agents are available for Microsoft Security Response Spoke.

-   **[Microsoft Security Response Center security management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-secresp-microsoft-security-response-center-security-management-ai-agent.md)**  
This AI agent retrieves security update information from the Microsoft Security Response Center. It lists available security updates and looks up a specific update by key.
