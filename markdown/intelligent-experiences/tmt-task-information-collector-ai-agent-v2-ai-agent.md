# Task information collector AI Agent V2

The agent gathers the details of a task and verifies that the task qualifies for further troubleshooting. It runs without user interaction, and returns the task details, the verification status, and the verification response to the orchestrator.

## Workflow

The agent collects and verifies the information for a task and returns it to the orchestrator.

1.  Extract the task number from the information already collected.
2.  Retrieve the task information, and report the failure to the orchestrator when the collection fails.
3.  Verify that the task information qualifies the task for further troubleshooting.
4.  Return the task details, the verification status, and the verification response to the orchestrator.
