# Zero Copy Connector for ERP AI agents

The following AI agents are available for Zero Copy Connector for ERP.

-   **[ERP action invoker AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/zcc-erp-action-invoker-ai-agent.md)**  
This AI agent gathers user inputs for a specific operation in Zero Copy Connector for ERP.
-   **[ERP data fetcher AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/zcc-erp-data-fetcher-ai-agent.md)**  
This Zero Copy Connector for ERP AI agent retrieves information about relevant models and model operations. The AI agent currently supports Read operations.
-   **[ERP output formatter AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/zcc-erp-output-formatter-ai-agent.md)**  
The Zero Copy Connector for ERP AI agent formats and refines the output from the ERP action invoker AI agent.
-   **[OData service recommender AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/zcc-odata-service-recommender-ai-agent.md)**  
The OData service recommender AI agent identifies relevant OData services and endpoints. The AI agent can create a model for the identified service if a model does not already exist.
