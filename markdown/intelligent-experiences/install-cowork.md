# Download and install ServiceNow Cowork

Install ServiceNow Cowork on a Mac with an M-series processor to use the AI desktop agent on your computer.

## Before you begin

Role required: sn\_app\_cowork.admin or sn\_app\_cowork.user

## Procedure

1.  Navigate to **All** &gt; **ServiceNow Cowork** &gt; **Downloads**.

2.  Download the Mac installer.

    **Note:** ServiceNow Cowork is only available for macOS that uses M-series processors, such as M1, M2, M3, and M4.

3.  Go to your **Downloads** folder and select ServiceNow Cowork installer package.

4.  Open the ServiceNow Cowork installer package.

5.  On the Introduction screen, select **Continue**.

6.  On the Installation Type screen, select **Install** to perform a standard installation in your home folder.

7.  Select **Change Install Location** to select a destination.

8.  On the Destination Select screen, select how you want to install the software.

    -   Install for all users of this computer: Installs Cowork for every user account on the computer.
    -   Install for me only: Installs Cowork in your home folder. Only you can use the software.
    -   Install on a specific disk: Installs Cowork on a disk that you choose.
9.  Select **Continue**.

10. After the installation completes, select **Close**.


## What to do next

After you install Cowork, it keeps itself up to date. It checks for updates at startup, during onboarding, every 30 minutes, and when you check for updates from **Settings**.

A required update shows the **Update and Restart** screen, and you install the update before you continue. An update found in the background appears as a notification that you can dismiss. Cowork verifies the signature of each update before it installs.
