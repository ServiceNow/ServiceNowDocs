# Edit a project or epic in AI Control Tower

Update the details of a project or epic from the Execute page in AI Control Tower to reflect changes in scope, state, priority, or other information.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home 2.0**.

2.  Navigate to **Plan** &gt; **Execute**.

3.  In the **Project** or **Epic** list, select the edit icon \(\[Omitted image "aict-plan-edit-icon.png"\] Alt text:\) next to the record you want to update.

4.  Update the fields as needed.

    For field descriptions, see:

    -   [Epic form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aict-plan-epic-form.md) for epics.
    -   [Project form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aict-plan-project-form.md) for projects.
    The forms display the Default view of the project and epic.

5.  Select **Save**.

    The updated record is displayed in the respective list.
