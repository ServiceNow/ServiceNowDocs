# Select channels for an agentic workflow

In the guided setup for an agentic workflow, configure where users can engage with the agentic workflow.

## Before you begin

Role required: sn\_aia.admin

## About this task

In this section of the agentic workflow guided setup, you configure where the agentic workflow can be invoked.

## Procedure

1.  Choose whether to engage via Otto panel by toggling **Otto panel**.

2.  To add UI actions, select **Create new** under **UI actions invoking this workflow**.

    A modal opens where you can configure the UI action.

3.  Configure the UI action in the modal.

    1.  Toggle **Active** to determine if the UI action is active.

    2.  Enter a label for the UI action in the **UI action label** field.

    3.  Select the table from the **Table** dropdown where the UI action will appear.

    4.  Add conditions to filter under **Add conditions to filter**.

        You can build a filter by adding conditions that contain a field, operator, and value\(s\).

4.  Select **Save**.

    \[Omitted image "aw-setup-channels.png"\] Alt text: Agentic workflow setup channels and display configuration with Virtual Agent assistants, UI actions, and processing messages.


## Result

You have completed the channels section of the guided setup for creating an agentic workflow.

## What to do next

You can save the agentic workflow by selecting **Save**, and you can [test your agentic workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/test-ai-asset-new.md) by selecting **Run test**.
