# Microsoft SharePoint Online Spoke AI agents

The following AI agents are available for Microsoft SharePoint Online Spoke.

-   **[Microsoft SharePoint Online change management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-change-management-ai-agent.md)**  
This AI agent retrieves Microsoft SharePoint Online change-tracking tokens. It gets the next token and the delta link token for a drive so that flows can track changes.
-   **[Microsoft SharePoint Online file management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-file-management-ai-agent.md)**  
This AI agent manages Microsoft SharePoint Online files.
-   **[Microsoft SharePoint Online folder management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-folder-management-ai-agent.md)**  
This AI agent manages Microsoft SharePoint Online folders. It creates, renames, looks up, and deletes folders, lists the files and subfolders in a folder, and shares or unshares folders with users or groups.
-   **[Microsoft SharePoint Online group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-group-management-ai-agent.md)**  
This AI agent manages Microsoft SharePoint Online groups and site roles. It creates and deletes groups, adds and removes users, updates group owners, looks up groups and Microsoft 365 members, and adds or removes site roles.
-   **[Microsoft SharePoint Online list item management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-list-item-management-ai-agent.md)**  
This AI agent manages Microsoft SharePoint Online list items. It creates, updates, and deletes list items and looks up a specific item or the items in a list.
-   **[Microsoft SharePoint Online list management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-list-management-ai-agent.md)**  
This AI agent manages Microsoft SharePoint Online lists. It creates, updates, and deletes lists, looks up lists and list IDs, manages list subscriptions, and looks up drives.
-   **[Microsoft SharePoint Online search management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-search-management-ai-agent.md)**  
This AI agent runs searches in Microsoft SharePoint Online and returns the query results.
-   **[Microsoft SharePoint Online site management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-site-management-ai-agent.md)**  
This AI agent manages Microsoft SharePoint Online sites. It creates, updates, and deletes modern sites and subsites, creates root site subscriptions, and looks up sites, site collections, subsites, group information, role assignments, and permissions.
-   **[Microsoft SharePoint Online user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-sharepoint-microsoft-sharepoint-online-user-management-ai-agent.md)**  
This AI agent retrieves Microsoft SharePoint Online user information. It looks up users by email or login name and the Microsoft SharePoint Online groups a user belongs to.
