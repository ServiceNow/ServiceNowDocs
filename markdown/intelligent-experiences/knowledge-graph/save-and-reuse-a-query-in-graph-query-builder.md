# Save and reuse a query in Graph Query Builder

Save and share a successfully run query to load and rerun it later in Graph Query Builder

## Before you begin

You must run a query successfully at least once before you can save it.

Role required: kg\_admin

## Procedure

1.  Navigate to **All** &gt; **Knowledge graph** &gt; **Graph Query Builder**.

2.  Build and run a query successfully from the Ask Natural Language Query or Build with Query Builder section.

    Once you run the query, **Save query** option is enabled.

3.  Select **Save query**.

    Save query window is displayed.

4.  Choose whether to save as a new query or to add to an exiting query.

5.  Add a query name and assign permissions.

    For permission, the options are:

    -   Me: only you can see and load the saved query.
    -   Everyone: all users with access to Query Builder can see and load the saved query.
6.  Select **Save**.

7.  Select **Use saved queries** option to load saved queries.

8.  Choose a query from either **My queries** or **Others** section on saved queries window.

9.  Select **Load query** to view and load the query.

10. Edit the query, if required and select **Run**.

    -   You can rename a saved query, but you can't edit its underlying logic directly.
    -   To change the logic, build the updated query in the builder and save it as a replacement.
    -   Queries saved by other users might be visible to everyone but cannot be edited or deleted by you.
    -   You can only delete the queries that you have saved.
