# Access Graph Query Builder

Open Graph Query Builder directly from drop-down menu options on the home page of ServiceNow UI or from the Query Builder section within Knowledge Graph Designer.

## Before you begin

Role required: kg\_admin

## Procedure

1.  Navigate to **All** &gt; **Knowledge Graph** &gt; **Graph Query Builder**.

2.  You can also navigate to **All** &gt; **Knowledge Graph** &gt; **Knowledge Graph Designer** &gt; **Query Builder** and select **Open Query Builder** from home page.

    \[Omitted image "graph\_builder\_sn\_ui\_access.png"\] Alt text: Graph Query Builder main menu

    \[Omitted image "query\_builder\_kg\_ui.png"\] Alt text: Graph Query Builder module

    Graph Query Builder opens in a new browser tab, separate from Knowledge Graph Designer window.
