# Access guided setup

Open guided setup from the AI Control Tower Home page to configure AI Control Tower in a logical sequence and track your progress toward a complete setup.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward and sn\_ia\_config.ia\_user

## About this task

The **Get started with AI Control Tower** widget on the **Home** page is visible only to users with the AI steward role. It tracks your overall setup progress and shows the setup area you're currently working on.

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home**.

2.  On the **Get started with AI Control Tower** widget, select **Set up now** to open guided setup, or select **Continue** to pick up where you left off.

    Guided setup opens to a summary page showing your progress across all four setup areas.

3.  Complete the setup items for each area.

    For a complete listing of setup items and the topic to reference for each one, see [Guided setup areas](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/aict-guided-setup-modules.md).
