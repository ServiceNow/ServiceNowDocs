# Action performed on duplicates

Resolve duplicate AI assets in the AI asset inventory by taking the appropriate actions on review duplicate page.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home****Inventory****Action****Review duplicates**.

2.  Select **Mark assets as duplicates**.

3.  Select **None of these are duplicates**.

4.  Select **Convert to main asset**.

5.  Select **This is not a duplicate**.
