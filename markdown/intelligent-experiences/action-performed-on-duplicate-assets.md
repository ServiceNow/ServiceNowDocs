# Actions performed on duplicates

Review the actions and their immediate results when performed on duplicate AI assets in the Review duplicates page.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home** &gt; **Inventory** &gt; **Action** &gt; **Review duplicates**.

2.  Select **Mark assets as duplicates**.

    The main asset is promoted to managed if it was previously unmanaged; managed assets are unchanged. Duplicate assets retain their existing managed status.

3.  Select **None of these are duplicates**.

    No managed status change on any asset in the group.

4.  Select **Convert to main asset**.

    The newly designated main asset is set to the primary reference for the group, and the previous main asset moves to the duplicates list.

5.  Select **This is not a duplicate**.

    No managed status change on any asset in the group.
