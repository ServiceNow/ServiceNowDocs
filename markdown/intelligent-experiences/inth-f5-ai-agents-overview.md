# F5 BIG-IP Spoke AI agents

The following AI agents are available for F5 BIG-IP Spoke.

-   **[F5 BIG-IP pool management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-f5-f5-big-ip-pool-management-ai-agent.md)**  
This AI agent manages F5 BIG-IP pools. It creates, checks, and deletes pools and adds, removes, enables, disables, and lists pool members.
-   **[F5 BIG-IP server management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-f5-f5-big-ip-server-management-ai-agent.md)**  
This AI agent manages F5 BIG-IP virtual servers. It creates, updates, and deletes virtual servers and adds profiles to them.
