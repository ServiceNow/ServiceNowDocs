# AI Gateway settings

Turn MCP server connections on or off, automatically deactivate vulnerable tools and activate new tools, and activate the Data Sensitivity Check.

Role required: sn\_ai\_governance.ai\_steward or admin

In AI Control Tower, navigate to **Settings** &gt; **AI Gateway**. The page opens on the **Overview** tab.

|Tab|What you can do|
|---|---------------|
|[Overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-gw-overview-tab.md)|Turn all MCP server connections on or off, and turn connections on or off for one server.|
|[Tools](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-gw-tools-tab.md)|Choose whether vulnerable tools are deactivated automatically, and whether new tools are activated automatically.|
|[Policies](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-gw-policies-tab.md)|Activate the Data Sensitivity Check, define the sensitive data you want it to detect, and choose the servers it applies to.|

Settings on the **AI Gateway** tab of an MCP server record apply to that server only. For details, see [Connecting agents through AI Gateway](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-gw-connecting-agents.md) and [Governing MCP server tools and data](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-gw-governing-tools-data.md).
