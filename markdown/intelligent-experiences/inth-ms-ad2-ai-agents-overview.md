# Microsoft Active Directory v2 Spoke AI agents

The following AI agents are available for Microsoft Active Directory v2 Spoke.

-   **[Microsoft Active Directory computer management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-ad2-microsoft-active-directory-computer-management-ai-agent.md)**  
This AI agent manages Microsoft Active Directory computer accounts. It creates, updates, enables, disables, and deletes computers, looks up computers, and checks whether a computer exists or is disabled.
-   **[Microsoft Active Directory group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-ad2-microsoft-active-directory-group-management-ai-agent.md)**  
This AI agent manages Microsoft Active Directory groups. It creates and deletes groups, looks up groups, checks whether a group exists, and checks whether a user is a member.
-   **[Microsoft Active Directory object management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-ad2-microsoft-active-directory-object-management-ai-agent.md)**  
This AI agent manages Microsoft Active Directory objects. It creates and deletes objects, updates object expiration and organizational unit, and looks up objects by filter.
-   **[Microsoft Active Directory user authentication AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-ad2-microsoft-active-directory-user-authentication-ai-agent.md)**  
This AI agent manages Microsoft Active Directory account access. It unlocks accounts, checks lock status, generates random passwords, resets or changes passwords, and retrieves password expiration details.
-   **[Microsoft Active Directory user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-ms-ad2-microsoft-active-directory-user-management-ai-agent.md)**  
This AI agent manages Microsoft Active Directory users. It looks up users, checks whether a user exists or is disabled, enables or disables users, and deletes users.
