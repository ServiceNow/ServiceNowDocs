# Track tasks in Cowork

Check and track the progress of the tasks you have delegated and respond when Cowork needs your input. Tracking tasks lets you keep working while Cowork completes them, and responding quickly keeps paused tasks from stalling.

## Before you begin

Role required: sn\_app\_cowork.user

## Procedure

1.  Select **Kanban** in the ServiceNow Cowork application.

2.  Review the status of each task.

    |Column|Description|
    |------|-----------|
    |**Queued**|The task is waiting to start.|
    |**Running**|Cowork is working on the task.|
    |**Awaiting Input**|The task needs a response from you before it continues.|
    |**Completed**|The task is done.|
    |**Failed / Stopped**|The task ended before it completed.|

3.  If a task is in **Awaiting Input**, select it.

4.  Respond to the request in the chat.


## Result

Cowork continues the task after you respond, and the task moves to **Completed** when it's done.
