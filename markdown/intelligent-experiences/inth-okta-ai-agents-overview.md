# Okta Spoke AI agents

The following AI agents are available for Okta Spoke.

-   **[Okta application access management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-application-access-management-ai-agent.md)**  
This AI agent manages access to Okta applications. It looks up the users and groups assigned to an application and revokes a user's application access.
-   **[Okta application management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-application-management-ai-agent.md)**  
This AI agent retrieves Okta application information. It looks up App Launcher applications and application details by application ID.
-   **[Okta group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-group-management-ai-agent.md)**  
This AI agent manages Okta groups. It creates and updates groups, adds and removes users, checks group membership, and looks up groups and group details.
-   **[Okta group membership management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-group-membership-management-ai-agent.md)**  
This AI agent retrieves Okta group membership. It looks up the members of a group and the groups a user belongs to.
-   **[Okta logs management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-logs-management-ai-agent.md)**  
This AI agent retrieves Okta system logs so that users can review sign-in and administrative activity.
-   **[Okta password management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-password-management-ai-agent.md)**  
This AI agent manages Okta passwords and account access. It sets, changes, expires, and resets passwords, resets authentication factors, and unlocks user accounts.
-   **[Okta user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-okta-okta-user-management-ai-agent.md)**  
This AI agent manages the Okta user lifecycle. It creates, activates, deactivates, suspends, unsuspends, and deletes users, restarts activation, clears sessions, checks lock status, and looks up users, profiles, and account details.
