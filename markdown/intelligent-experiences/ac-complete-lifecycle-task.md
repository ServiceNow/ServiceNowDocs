# Complete a lifecycle task

Advance a managed AI asset through its lifecycle by completing the reviews, assessments, or approvals that an asset lifecycle playbook requires.

## Before you begin

Role required: sn\_ai\_asset\_mgmt.ai\_asset\_owner or sn\_ai\_governance.ai\_steward

## About this task

Lifecycle tasks are generated by an AI asset lifecycle playbook. Lifecycle tasks include impact assessments, architecture reviews, security clearances, value template approvals, and other reviews that must be completed before a managed AI asset can advance to its next lifecycle stage.

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home** &gt; **Activity Center** &gt; **Work** &gt; **Assigned to you**.

2.  On the **Lifecycle tasks** tab, select the lifecycle task that you want to complete.

3.  In the Task side panel, review the task details and complete the work that the task requires.

    For example, an impact assessment task requires you to evaluate the asset against the assessment criteria and record your findings in the form. An architecture review task requires you to review the asset's architecture and confirm that it meets your organization's standards.

4.  In the side panel, select **Save**.


## Result

The task is updated with your status change. The asset's lifecycle progresses according to the playbook's logic. If your task was the last outstanding task for the current activity, the asset advances to the next activity in the lifecycle stage.
