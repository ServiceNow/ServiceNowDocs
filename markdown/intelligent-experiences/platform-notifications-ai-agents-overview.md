# Notifications AI agents

The following AI agents are available for Notifications.

-   **[Email generator AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-not-email-generator-agent-ai-agent.md)**  
This AI agent composes and sends emails \(including new messages or replies\) based on the provided context.
-   **[Intent executor AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-not-intent-executor-agent-ai-agent.md)**  
This AI agent executes admin-defined actions, such as workflows or creating reply responses based on matched intent.
-   **[Intent identification AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-not-intent-identification-agent-ai-agent.md)**  
This AI agent analyzes and identifies the input email body intent. A list of admin-configured intents are compared with the input email body for a potential match.
-   **[Notification AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-not-notification-agent-ai-agent.md)**  
This AI agent creates or edits notification records through natural‑language interaction.
-   **[Notification content AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-not-notification-content-agent-ai-agent.md)**  
This AI agent prepares email notification templates and layouts. It begins by analyzing user input to understand the notification's content requirements and design expectations. Before generating any content, the agent searches for similar existing templates and presents the results to the user.
