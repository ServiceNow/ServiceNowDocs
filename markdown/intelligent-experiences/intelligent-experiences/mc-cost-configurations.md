# Cost configurations

Configure the hourly rates and vendor costs that AI Control Tower \(AICT\) uses to calculate what your AI systems cost to run.

Cost configurations establish the input for the Cost Framework in the AI Control Tower. Set up these inputs to make sure that cost data is accessible for the AI systems in your organization. After you configure, review the details and submit the configuration to activate it.
