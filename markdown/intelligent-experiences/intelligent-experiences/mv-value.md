# Value

Value translates AI usage into measurable productivity metrics.

Value uses templates and value jobs to assess the impact of AI usage on productivity and calculate the productivity gains from your AI systems.

Value templates define how Measure converts AI usage into productivity gains. Each template includes the usage indicator, time saved per occurrence, and quality score used in the calculation. You can reuse a value template across multiple AI systems.

Value jobs are scheduled tasks that collect usage and user metrics. By default, value jobs run daily. You can also schedule value jobs to run monthly or quarterly based on your reporting requirements.
