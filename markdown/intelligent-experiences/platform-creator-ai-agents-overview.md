# ServiceNow Otto for Creator AI agents

The following AI agents are available for ServiceNow Otto for Creator.

-   **[Catalog AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-conv-catalog-agent-ai-agent.md)**  
This ServiceNow Otto for Creator agent gathers, validates, and tracks all required inputs for a given Service Catalog item.
-   **[Module creator AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-uig-module-creator-agent-ai-agent.md)**  
This ServiceNow Otto for Creator agent Converts natural language requests into structured JSON definitions for ServiceNow application navigator modules.
-   **[Playbook activity context AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wfs-ply-playbook-activity-context-agent-ai-agent.md)**  
This ServiceNow Otto for Creator agent helps users complete ServiceNow forms by fetching form fields, automatically matching pre-filled field values, and prompting for any missing required information. The agent saves the summary of what it has done.
-   **[Playbook data gathering and processing AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wfs-ply-playbook-data-gathering-and-processing-agent-ai-agent.md)**  
This ServiceNow Otto for Creator agent is a assistant that consolidates data gathering, processing, and slot-filling capabilities. It handles end-to-end playbook execution using a broad toolkit of retrieval, reasoning, and action-oriented functions. The agent also helps with tasks related to processing of files attached to instance records.
-   **[Playbook processing AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wfs-ply-playbook-processing-agent-ai-agent.md)**  
This ServiceNow Otto for Creator agent is a general-purpose processing engine. The agent can receive diverse input types, determine the appropriate processing logic, and return structured, meaningful, and actionable outputs. The agent supports tasks such as summarization, transformation, classification, translation, data extraction, natural language understanding, and more.
-   **[Theme builder AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-thme-theme-builder-agents-ai-agent.md)**  
This ServiceNow Otto for Creator agent assists in creating and managing themes for user interfaces. It is intended for use by UI/UX designers, developers, and anyone responsible for maintaining the visual consistency of their organization's digital properties.
-   **[UI builder AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-uig-ui-builder-agent-ai-agent.md)**  
This agent helps users edit pages and answer questions within the ServiceNow UI Builder editor.
