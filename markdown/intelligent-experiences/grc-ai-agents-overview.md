# Governance, Risk, and Compliance AI agents

The following AI agents are available for Governance, Risk, and Compliance.

-   **[Control objective change AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/grc-control-objective-change-agent-ai-agent.md)**  
This AI agent acts as a Compliance Manager that validates if the description and supplemental guidance of a given control objective need updates based on the associated citations. The AI agent recommends new values if changes are required, and updates the control objective record after getting confirmation from the user.
-   **[Issue action plan AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/grc-issue-action-plan-ai-agent.md)**  
This AI agent identifies the optimal steps for resolving an issue by referencing the past similar issue details. It presents a step-by-step summarized action plan to the user.
-   **[Remediation tasks AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/grc-remediation-tasks-ai-agent.md)**  
This AI agent identifies the remediation tasks for resolving an issue by referencing the action plan field on the issue record.
-   **[Report a GRC issue AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/grc-report-a-grc-issue-ai-agent.md)**  
This AI agent enriches the given issue description with additional information by looking at historical data and using GRC context. It analyzes, extracts key information \(such as issue type, date of occurrence, and so on\), and creates a GRC issue.
