# Review and revoke standing approvals

Review the actions you have allowed Cowork to take without asking, and revoke any you no longer require.

## Before you begin

Role required: sn\_app\_cowork.user

## About this task

A standing approval exists only after you select **Allow always** on an approval card when Cowork asks permission for an action.

## Procedure

1.  Navigate to **Settings** &gt; **Approvals**.

2.  Review the list of standing approvals.

3.  Select **Revoke** for each approval to remove the approval.

    If you revoke the permission, Cowork requests permission again before running the action.
