# View AI assets usage and performance in AI Admin Center

Use AI Admin Center to view dashboards showing the usage and performance of your AI assets.

## Before you begin

Role required: sn\_na\_center.nac\_admin

## Procedure

1.  Navigate to **All** &gt; **AI Admin Center** or **Workspaces** &gt; **AI Admin Center**.

2.  Select **Monitor** \(\[Omitted image "icon-now-assist-center-nav-monitor.png"\] Alt text: Monitor icon.\) in the side navigation bar.

    The Analytics page opensshowing tabs for the different dashboards.

    Dashboards and data visualizations are derived from various AI features and are grouped by asset type.

    \[Omitted image "now-assist-center-monitor-2.png"\] Alt text: Monitor page in AI Admin Center.

3.  Select the tab for the dashboard you want to view.

    Some tabs contain another set of tabs for viewing the various usage, performance, and governance properties of the asset type.

4.  Select the tab for the data visualizations you want to view.

    The Overview tab displays a summary of AI asset activation, adoption, and usage across your organization. Use the dashboard to monitor the state of your AI assets and track user engagement across departments. For more information, see [AI Admin Center Overview dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-center-overview-dashboard.md).

    The Performance Explorer tab displays execution-level details for assistants and AI agents. Use the dashboard to investigate individual executions, analyze performance For more information, see [AI Admin Center Performance Explorer dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-center-performance-explorer-dashboard.md).

    The Business Value dashboard displays a consolidated view of the business value generated by AI assets across your organization. Use the dashboard to monitor total executions, time saved, and cost saved across skills, AI agents, and agentic workflows. For more information, see [AI Admin Center Business Value dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-center-business-value-dashboard.md).

    The Skills tab provides dashboards showing usage and performance metrics for generative AI skills. The dashboards are featured in the Performance section of the AI Admin Hub. For more information, see [Analyzing AI performance](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-analytics.md).
