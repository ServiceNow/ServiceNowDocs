# Docusign eSignature Spoke AI agents

The following AI agents are available for Docusign eSignature Spoke.

-   **[Docusign eSignature account management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-account-management-ai-agent.md)**  
This AI agent retrieves Docusign eSignature account information. It looks up accounts by alias, role IDs, and the signature providers available to an account.
-   **[Docusign eSignature bulk envelopes management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-bulk-envelopes-management-ai-agent.md)**  
This AI agent manages Docusign eSignature bulk sending. It creates, updates, looks up, and deletes bulk send lists, creates bulk send and test requests, and looks up and updates bulk send batches.
-   **[Docusign eSignature document management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-document-management-ai-agent.md)**  
This AI agent manages documents in Docusign eSignature envelopes. It adds and replaces documents, looks up documents and document IDs, and attaches individual or combined documents to ServiceNow records.
-   **[Docusign eSignature document signature AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-document-signature-ai-agent.md)**  
This AI agent generates Docusign eSignature embedded signing URLs so that recipients can sign documents directly within an application.
-   **[Docusign eSignature envelope management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-envelope-management-ai-agent.md)**  
This AI agent manages Docusign eSignature envelopes. It creates envelopes from templates, manages recipients and field values, sends envelopes and ad-hoc signature requests, waits for signatures, cancels envelopes, and attaches certificates to ServiceNow records.
-   **[Docusign eSignature group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-group-management-ai-agent.md)**  
This AI agent manages Docusign eSignature groups. It looks up group IDs and adds users to or removes users from groups.
-   **[Docusign eSignature templates management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-templates-management-ai-agent.md)**  
This AI agent retrieves Docusign eSignature template information. It looks up template names for an account and a template's fields and recipients.
-   **[Docusign eSignature user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-docusign-docusign-esignature-user-management-ai-agent.md)**  
This AI agent manages Docusign eSignature users. It creates, updates, and deletes users and looks up user details.
