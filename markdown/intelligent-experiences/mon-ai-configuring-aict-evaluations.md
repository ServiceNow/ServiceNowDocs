# Configuring monitoring and evaluations in AI Control Tower

Set up monitoring in AI Control Tower by activating evaluations, adding metrics, and configuring metric templates.

## Configuration overview

Setting up monitoring involves enabling scoring for each type of AI system you want to evaluate, managing which metrics to include, and configuring metric templates that define how quality and safety scores are calculated.After the initial setup, you can configure how long trace data is retained, and adjust which AI systems are included in scoring as your portfolio changes.
