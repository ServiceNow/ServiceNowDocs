# Oracle HCM Cloud Spoke AI agents

The following AI agents are available for Oracle HCM Cloud Spoke.

-   **[Oracle HCM Cloud compensation management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-oraclehcm-oracle-hcm-cloud-compensation-management-ai-agent.md)**  
This AI agent retrieves compensation data from Oracle HCM Cloud. It looks up an employee's total rewards and individual compensation details.
-   **[Oracle HCM Cloud feedback management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-oraclehcm-oracle-hcm-cloud-feedback-management-ai-agent.md)**  
This AI agent looks up feedback records in Oracle HCM Cloud so that users can review feedback without leaving ServiceNow.
-   **[Oracle HCM Cloud goals management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-oraclehcm-oracle-hcm-cloud-goals-management-ai-agent.md)**  
This AI agent looks up goals in Oracle HCM Cloud so that HR professionals and managers can review and track objectives.
-   **[Oracle HCM Cloud human capital management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-oraclehcm-oracle-hcm-cloud-human-capital-management-ai-agent.md)**  
This AI agent retrieves human capital data from Oracle HCM Cloud. It looks up holiday calendars, employee documents, and the attachments linked to those documents.
-   **[Oracle HCM Cloud jobs management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-oraclehcm-oracle-hcm-cloud-jobs-management-ai-agent.md)**  
This AI agent looks up recruiting candidates in Oracle HCM Cloud so that HR professionals and recruiters can review candidate details quickly.
-   **[Oracle HCM Cloud payroll management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-oraclehcm-oracle-hcm-cloud-payroll-management-ai-agent.md)**  
This AI agent retrieves payroll information from Oracle HCM Cloud. It looks up payroll data and employee payslips for HR professionals and payroll administrators.
