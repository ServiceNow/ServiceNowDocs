# External Content Connector AI agents

The following AI agents are available for External Content Connectors.

-   **[AI Search XCC AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/xcc-ai-search-xcc-agent-ai-agent.md)**  
This agent assists with AI Search External Content Connector \(XCC\) setup for private data sources \(SharePoint, Confluence, Google Drive, Box, OneDrive\) and public providers \(Zoom, Apple Support, Okta\).
