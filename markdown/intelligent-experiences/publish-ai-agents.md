# Publish AI agents

Marking AI agents as publishable from an AI asset record page.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## About this task

An AI agent needs to meet all the prerequisites criteria to be eligible to get publish-ability status.

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Inventory**.

2.  Open an AI agent.

3.  Select **Actions**.

4.  Select **Mark as publishable**.


## Result

The Agent is returned by discover-ability APIs; External registries section reflects updated status.
