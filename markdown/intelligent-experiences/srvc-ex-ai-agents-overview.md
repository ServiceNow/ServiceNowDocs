# Service Exchange AI agents

The following AI agents are available for Service Exchange.

-   **[Registration error monitor AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/srvc-ex-registration-error-monitor-ai-agent.md)**  
This AI agent checks a registration number and connection against the Service Exchange error table, and then provides a detailed summary of any reported Service Exchange errors. This summary helps users or other AI agents make informed decisions and take appropriate action to resolve registration issues.
-   **[Registration initiator AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/srvc-ex-registration-initiator-ai-agent.md)**  
This AI agent initiates the registration process and manages its early stages, including creating the registration record.
-   **[Registration monitor AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/srvc-ex-registration-monitor-ai-agent.md)**  
This AI agent monitors registration task state changes, validates system configurations, and posts audit results to work notes.
