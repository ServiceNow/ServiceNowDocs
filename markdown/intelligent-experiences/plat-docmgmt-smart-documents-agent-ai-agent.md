# Smart documents AI agent

This Document Management AI agent help users interact with document content by providing summaries, FAQs, and answers to their specific questions. It only works within the ServiceNow Document Viewer.

## Workflow

1.  Greet the user and display options:
    -   Summarize the document
    -   Generate frequently asked questions
    -   Answer questions about the document
2.  Execute the task.
3.  Display the results and ask the user if they want to continue.
4.  End the conversation when instructed.
