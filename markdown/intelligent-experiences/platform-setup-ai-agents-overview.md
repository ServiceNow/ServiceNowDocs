# Setup Hub AI agents

The following AI agents are available for Setup Hub.

-   **[Group and roles assignment AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-group-and-roles-assignment-agent-ai-agent.md)**  
This ServiceNow Otto for Setup AI agent provisions access by creating groups, adding users to a group, assigning roles to a group, and adding users to a role.
-   **[IA operational data workflow AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-ia-operational-data-workflow-agent-ai-agent.md)**  
This ServiceNow Otto for Setup AI agent automates the configuration of data imports by handling the creation of data sources, import sets, and transform maps.
-   **[Implementation plan executor AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-implementation-plan-executor-agent-ai-agent.md)**  
This ServiceNow Otto for Setup AI agent is responsible for executing the implementation plan, carrying out each defined step, and ensuring the plan is completed as designed.
-   **[Implementation plan generator AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-implementation-plan-generator-agent-ai-agent.md)**  
This ServiceNow Otto for Setup AI agent collects user input by asking configured questions, analyzing the full conversation to derive a precise technical intent, and then generating a step‑by‑step implementation plan.
-   **[Implementation plan manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-implementation-plan-manager-agent-ai-agent.md)**  
The implementation plan manager agent orchestrates an implementation by coordinating the plan generator and plan executor agents. It helps to ensure that your technical intent is converted into a clear plan and executed safely and correctly.
-   **[Initialize IA orchestrator AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-initialize-ia-orchestrator-agent-ai-agent.md)**  
This ServiceNow Otto for Setup agent automatically triggers the appropriate Virtual Agent topic to streamline setup and onboarding for users on your ServiceNow instance.
-   **[SLA management AI Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-sla-management-ai-agent.md)**  
This ServiceNow Otto for Setup agent enables administrators to create and edit SLA definitions through a conversational interface. The agent guides you through SLA configuration, including setting target type \(Resolution/Response\), duration, table, schedule, start/pause/stop conditions, and flow associations.
-   **[SSO configuration AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-sso-configuration-agent-ai-agent.md)**  
This ServiceNow Otto for Setup AI agent guides administrators through secure Single Sign-On \(SSO\) setup for ServiceNow using SAML or OpenID Connect \(OIDC\). The agent collects and validates identity provider details, creates authentication configurations, and guides users through review, testing, and activation.
-   **[Update set AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/plat-setup-update-set-agent-ai-agent.md)**  
This ServiceNow Otto for Setup AI agent helps administrators and developers upload, review, and commit XML update sets efficiently.
