# Email on existing parent lead AI agent

This AI agent handles emails that have a parent record and creates or updates tasks for them.

## Workflow

The agent handles emails received on an existing parent task record.

1.  Call the email action and information AI agent to analyze the email body and extract action items.
2.  To update an existing record:
    1.  Retrieve all fields that can be updated from the parent task table.
    2.  Use the record management AI agent to update the parent task.
3.  To create a new record:
    1.  Get a list of all task tables and choose the appropriate one based on the email and parent task context.
    2.  Use the email action and information AI agent to fetch all fields for the chosen table and generate the inputs.
    3.  Use the record management AI agent to create a new child task.
    4.  Use the email action and information AI agent to attach emails to the new task.
4.  Exit the workflow when all items are processed.
