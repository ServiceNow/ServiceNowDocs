# Unified Security Exposure Management AI agents

The following AI agents are available for Unified Security Exposure Management.

-   **[VR data retrieval agent AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/usem-data-retrieval-agent-ai-agent.md)**  
This Unified Security Exposure Management agent answers questions about vulnerability response data by constructing and executing table queries.
-   **[Remediation compliance analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/usem-remediation-compliance-analysis-ai-agent.md)**  
This Unified Security Exposure Management agent provides insights around remediation target compliance. It provides SLA or compliance statistics about remediation targets. The agent can break down these numbers by attributes such as severity, assignment group, or configuration class item class.
-   **[Vulnerability exposure analysis AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/usem-vulnerability-exposure-analysis-ai-agent.md)**  
This Unified Security Exposure Management agent assesses vulnerability on business services or configuration items.
