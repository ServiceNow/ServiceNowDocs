# Use Information Extraction skill

The Information Extraction skill generates predictions from activated use cases. In agent review mode, you review and correct predictions before the extracted values populate your records.

After you activate a use case in agent review mode, review and correct the predictions that the Information Extraction skill generates before the extracted values populate your records.
