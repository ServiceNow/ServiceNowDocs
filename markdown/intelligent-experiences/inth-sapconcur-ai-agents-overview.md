# SAP Concur Spoke AI agents

The following AI agents are available for SAP Concur Spoke.

-   **[SAP Concur expense entry management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapconcur-sap-concur-expense-entry-management-ai-agent.md)**  
This AI agent retrieves the details of a specific expense entry from SAP Concur.
-   **[SAP Concur expense report management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapconcur-sap-concur-expense-report-management-ai-agent.md)**  
This AI agent manages expense reports in SAP Concur. It looks up reports modified after a given date, retrieves report comments, submits reports for approval, and runs workflow actions on reports.
-   **[SAP Concur itinerary management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapconcur-sap-concur-itinerary-management-ai-agent.md)**  
This AI agent looks up SAP Concur travel itineraries by trip ID so that users can review travel details from ServiceNow.
-   **[SAP Concur payment request management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapconcur-sap-concur-payment-request-management-ai-agent.md)**  
This AI agent retrieves the details of existing payment requests from SAP Concur.
-   **[SAP Concur purchase order management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapconcur-sap-concur-purchase-order-management-ai-agent.md)**  
This AI agent retrieves purchase order details from SAP Concur.
-   **[SAP Concur receipt management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapconcur-sap-concur-receipt-management-ai-agent.md)**  
This AI agent handles expense receipts in SAP Concur. It uploads receipt images to expense reports and retrieves the URL of an expense entry's receipt image.
