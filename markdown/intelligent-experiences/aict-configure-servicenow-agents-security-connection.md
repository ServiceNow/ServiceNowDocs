# Add a ServiceNow Agents connection

Connect ServiceNow Agents to AI Control Tower so AI agent containment using kill switch protocol can reach and deactivate agents running as ServiceNow Agents.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **AI Control Tower** &gt; **Settings** &gt; **Integrations** &gt; **Security**.

2.  On the **Available connectors** sub-tab, select **ServiceNow Agents**.

3.  Select the **Active** check box.

4.  Select **Submit**.


## Result

The connector appears on the **Established connections** sub-tab. AI Control Tower can now use this connection to apply AI agent containment using kill switch protocol to AI agents running on ServiceNow.
