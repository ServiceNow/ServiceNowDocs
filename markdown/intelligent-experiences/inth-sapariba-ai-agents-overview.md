# SAP Ariba Spoke AI agents

The following AI agents are available for SAP Ariba Spoke.

-   **[SAP Ariba approvals procurement management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapariba-sap-ariba-approvals-procurement-management-ai-agent.md)**  
This AI agent looks up the status of procurement approvals in SAP Ariba.
-   **[SAP Ariba approvals sourcing management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapariba-sap-ariba-approvals-sourcing-management-ai-agent.md)**  
This AI agent creates approval statuses in SAP Ariba to move sourcing approval workflows forward.
-   **[SAP Ariba invoice management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapariba-sap-ariba-invoice-management-ai-agent.md)**  
The agent retrieves invoice information from SAP Ariba. It looks up pending message IDs and invoice details using the cXML protocol.
-   **[SAP Ariba procurement export management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapariba-sap-ariba-procurement-export-management-ai-agent.md)**  
This AI agent looks up procurement receipts in SAP Ariba so that users can access receipt data from ServiceNow.
-   **[SAP Ariba sourcing event management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-sapariba-sap-ariba-sourcing-event-management-ai-agent.md)**  
This AI agent manages SAP Ariba sourcing events. It looks up supplier bids and awarded bids, downloads bid response attachments, updates event states, and creates supplier awards.
