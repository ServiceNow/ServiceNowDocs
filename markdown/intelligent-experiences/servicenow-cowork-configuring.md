# Configuring ServiceNow Cowork

Activate ServiceNow Cowork plugin to download, install and setup Cowork.

-   **[Activate the ServiceNow Cowork plugin](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/activate-servicenow-cowork-plugin.md)**  
You can activate the ServiceNow Cowork plugin \(sn\_app\_cowork\) for ServiceNow Cowork if you have the admin role. The application includes demo data and installs related ServiceNow® Store applications and plugins if they aren't already installed.
-   **[Download and install ServiceNow Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/install-cowork.md)**  
Install ServiceNow Cowork on a Mac with an M-series processor to use the AI desktop agent on your computer.
-   **[Set up ServiceNow Cowork](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/set-up-cowork.md)**  
Connect Cowork to your ServiceNow instance and prepare your workspace and secure sandbox.
-   **[Create a ServiceNow Cowork agent policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/create-cowork-agent-policy.md)**  
Create a policy to define what ServiceNow Cowork can do, which actions need human approval, and which actions are blocked.
-   **[Configure a ServiceNow Cowork agent policy](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/configure-cowork-agent-policy.md)**  
Add tool gates, approval patterns, network rules, sandbox rules, capability overrides, connector scopes, and file type rules to a policy to control what Cowork can do for the users the policy applies to.
-   **[Trace evaluation for Cowork in AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/cowork-trace-evaluation.md)**  
AI Control Tower scores the traces that Cowork sends for quality and safety. Review the scores to understand usage patterns and identify where responses fall short.
