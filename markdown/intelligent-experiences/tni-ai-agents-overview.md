# Telecommunications Network Inventory AI agents

The following AI agents are available for Telecommunications Network Inventory.

-   **[Rack placement AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/tni-rack-placement-ai-agent.md)**  
This AI agent finds a data center rack allocation that fits the capacity requirements of a change request. It validates the request, applies the placement policies for the data center, and records the outcome on the change request.
