# Cost Framework in AI Control Tower

Get started with Cost Framework to track, calculate, and analyze the financial costs of your AI systems, helping you measure return on investment and justify AI spending.

## Cost Framework overview

The Cost Framework is a comprehensive system for measuring and tracking the financial impact of AI systems. It enables you to:

-   Calculate productivity savings \(hours and money saved\)
-   Track all costs associated with running AI systems
-   Compute net returns \(benefits minus costs\)
-   Make data-driven decisions about AI investments

For more information about configuring Cost in AI Control Tower, see [Configuring Cost in AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/measure-ai-configuring-aict-value-cost.md).
