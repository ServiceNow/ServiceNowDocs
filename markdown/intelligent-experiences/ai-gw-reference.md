# AI Gateway reference

Reference topics provide details about the roles and system properties that apply to AI Gateway.

Related reference information for AI Gateway is in these topics:

-   [System properties for AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aict-reference-system-properties.md): the system properties that choose how MCP server tools are scanned.
-   [Managing your AI Gateway](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/managing-your-ai-gateway.md): the tool threat categories that the security scan reports.
-   [AI Control Tower playbooks](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aict-playbooks-reference.md): the AI Asset Onboarding playbook that takes MCP servers through approval.
-   [Components installed with AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aict-installed-with.md): the AWH for AI Control Tower plugin \(sn\_awh\_config\) that provides AI Gateway, and the AI Steward role.
-   [Domain separation and AI Control Tower](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/aict-domain-separation.md): domain separation in AI Control Tower. AI Gateway isn't available on instances that use domain separation.
