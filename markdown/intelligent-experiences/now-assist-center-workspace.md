# AI Admin Center workspace

Use the AI Admin Center workspace to set up, monitor, and manage your AI solutions.

## Overview of the AI Admin Center workspace

The AI Admin Center workspace provides features that enable you to set up of your AI solutions in a unified experience without switching between separate AI applications.

With the AI Admin Center workspace, you can:

-   Access your integrated AI applications and features using the side navigation bar.
-   Use the home page features to set up AI solutions on your instance, find and activate automation opportunities, and track AI performance.
-   Use the conversational interface in the ServiceNow Otto panel as your AI assistant to perform common setup, building, and question answering tasks.

## Access the AI Admin Center workspace

To access the AI Admin Center workspace, navigate to **All** &gt; **AI Admin Center** or **Workspaces** &gt; **AI Admin Center**.

The first time you access AI Admin Center, a welcome message displays prompting you to get started by installing essential ServiceNow Otto plugins. If you already have these plugins installed, the message simply introduces the benefits of AI Admin Center. Select **Let’s get started** to continue to the home page.
