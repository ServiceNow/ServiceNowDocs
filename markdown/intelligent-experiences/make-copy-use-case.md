# Copy a use case

Copy an existing use case to use as a starting point for a similar one. The copy includes the original fields, tables, questions, integrations, and flows.

## Before you begin

Role required: sn\_docintel.manager or sn\_docintel.admin

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Skills**.

2.  In the workflow list, select **Platform**.

3.  In the Platform skills list, locate the skill that contains the use case you want to copy.

4.  In the options menu \(\[Omitted image "cu-options-menu.png"\] Alt text:\), select **Edit**.

5.  In the options menu \(\[Omitted image "cu-options-menu.png"\] Alt text:\) for the use case you want to copy, select **Make a copy**.

6.  In the confirmation dialog, select **Make a copy**.

7.  Select **Continue**.

8.  In the **Name** field, enter a name for the use case.

9.  Select **Make a copy**.


## Result

The copied use case appears in the use cases list.

## What to do next

Edit the new use case to make any necessary changes, then test it to confirm it works as expected. For steps to edit a use case, see [Edit a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/edit-use-case.md).
