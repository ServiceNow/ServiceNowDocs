# ServiceNow AI dashboard

The ServiceNow AI dashboard is a central hub for monitoring and evaluating the performance, adoption, and financial impact of AI systems deployed across your ServiceNow environment.

## ServiceNow AI overview

The ServiceNow AI dashboard consolidates operational and financial metrics from all AI agents, offering real-time insights into AI value delivery, cost management, and usage patterns. It helps organizations evaluate AI effectiveness, support investment decisions, and identify optimization opportunities.

By consolidating AI performance data into a single interface, the dashboard eliminates the need to gather metrics from individual system sources or manual reports. It presents productivity gains, financial returns, operational costs, and usage insights in an accessible visual format suitable for both technical practitioners and business leaders.

The dashboard serves multiple audiences and use cases. Operational teams use the dashboard to monitor whether deployed AI agents are performing as expected and delivering measurable value to end users. Finance and business leaders use the dashboard to assess return on AI investment and make informed decisions about resource allocation. Product and platform teams use the dashboard to understand adoption patterns and identify which AI capabilities drive the highest user engagement.

The dashboard displays metrics across configurable time ranges, enabling trend analysis and historical comparison. Period-over-period comparisons help identify whether AI value delivery, costs, and usage are improving, stagnating, or declining, supporting data-driven conversations about AI strategy and optimization priorities.

The ServiceNow AI dashboard in the Value module consists of three sub dashboards:

-   **Value dashboard**

    The ServiceNow AI Value dashboard aggregates data from all AI systems in your organization monitoring AI value delivery, track usage trends, and assess return on investment.

    For more information about what the ServiceNow AI Value dashboard contains, see [ServiceNow AI Value dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/measure-snow-ai-value.md).

-   **Engagement**

    The ServiceNow AI Engagement dashboard provides visibility into user adoption, utilization patterns, and performance metrics across all AI systems in your ServiceNow instance. Monitor AI action volume, user engagement trends, departmental usage, and task efficiency gains to identify adoption opportunities and system effectiveness.

    For more information about what the ServiceNow AI Engagement dashboard contains, see [ServiceNow AI Engagement](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/measure-snow-ai-engagement.md).

-   **Creator skills**

    The ServiceNow AI Creator Skills dashboard provides insight into how your organization uses AI-powered creator skills—automated code generation, documentation, and testing capabilities—to boost developer productivity.

    For more information about what the ServiceNow AI Creator skills dashboard contains, see [ServiceNow AI Creator skills](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/measure-snow-ai-creator-skills.md).

-   **Evaluation**

    The ServiceNow AI Evaluation dashboard offers insights into the performance of AI-generated responses.

    For more information about what the ServiceNow AI Evaluation dashboard contains, see [ServiceNow AI Evaluation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/measure-snow-ai-evaluation.md).
