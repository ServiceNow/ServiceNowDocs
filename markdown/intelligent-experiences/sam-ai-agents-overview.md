# Software Asset Management AI agents

The following AI agents are available for Software Asset Management.

-   **[Microsoft license assignment AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/sam-microsoft-license-assignment-ai-agent.md)**  
This Software Asset Management agent assigns a Microsoft license to a user for a given request item, handling integration profile selection, reservation order creation, and Entra ID group assignment.
-   **[Software entitlement allocation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/sam-software-entitlement-allocation-ai-agent.md)**  
This Software Asset Management agent allocates software licenses for a request item, handling device selection when required.
-   **[Software reclamation rule creation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/sam-software-reclamation-rule-creation-ai-agent.md)**  
This Software Asset Management agent analyzes software utilization and spend, then creates a reclamation rule based on user-approved criteria.
-   **[Software removal candidate evaluation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/sam-software-removal-candidate-evaluation-ai-agent.md)**  
This Software Asset Management agent identifies unused or underused software licenses and initiates reclamation after user confirmation.
