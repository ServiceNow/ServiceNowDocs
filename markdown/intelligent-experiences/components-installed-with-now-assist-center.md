# Components installed with AI Admin Center

Several components are installed with the AI Admin Center application.

## Roles installed

The following roles are installed with AI Admin Center.

-   AI Admin Center admin \[sn\_na\_center.nac\_admin\]
-   AI Admin Center user \[sn\_na\_center.nac\_user\]

For information on the roles installed with AI Admin Center, see [AI Admin Center roles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-center-roles.md).
