# Zoom Spoke AI agents

The following AI agents are available for Zoom Spoke.

-   **[Zoom chat management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-zoom-zoom-chat-management-ai-agent.md)**  
This AI agent manages Zoom Team Chat from within ServiceNow. It creates and updates channels, sends chat messages, adds and removes channel members, and looks up channels, channel members, and a user's messages and channels.
-   **[Zoom cloud recording management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-zoom-zoom-cloud-recording-management-ai-agent.md)**  
This AI agent retrieves Zoom cloud recordings. It looks up recordings, a meeting's recordings, and a meeting's recording settings.
-   **[Zoom meeting management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-zoom-zoom-meeting-management-ai-agent.md)**  
This AI agent manages Zoom meetings. It creates, updates, ends, and deletes meetings, adds registrants, and looks up meeting details, live meetings, ended meeting instances, and past participants.
-   **[Zoom user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-zoom-zoom-user-management-ai-agent.md)**  
This AI agent manages Zoom users. It creates, deletes, and disassociates users, updates user settings, and looks up users and user details.
