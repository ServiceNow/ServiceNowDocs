# Move AI assets to managed

Bring discovered or imported AI assets into your governance program by moving them to managed status, making them eligible for lifecycle review, evaluation scoring, risk classification, and value measurement.

## Before you begin

Role required: sn\_ai\_governance\_ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home** &gt; **Inventory**.

2.  Select the check box for each asset that you want to move to managed.

3.  From the **Action** list, select **Move to Managed**.

4.  In the confirmation dialog box that appears, review your current selections.

    1.  Review each asset that you selected and its current state.

    2.  Remove any asset that you don't want to update.

5.  Select additional actions to perform while moving the asset to managed.

    -   **Initiate lifecycle review**

        Starts the onboarding workflow for the asset immediately after it moves to managed.

    -   **Turn on evaluation**

        Enables evaluation scoring for the asset so quality and safety scores begin generating.

6.  Select **Move to Managed** to confirm.


## Result

The status changes to **New** for each asset that you selected. The asset now participates in governance workflows, including lifecycle management, risk classification, value assessment, security, and privacy.
