# Google Calendar Spoke AI agents

The following AI agents are available for Google Calendar Spoke.

-   **[Google Calendar access control list management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cal-google-calendar-access-control-list-management-ai-agent.md)**  
This AI agent manages Google Calendar access control lists. It looks up, updates, and deletes access control rules for a calendar.
-   **[Google Calendar event management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cal-google-calendar-event-management-ai-agent.md)**  
This AI agent manages Google Calendar events. It creates, updates, moves, and deletes events, looks up events by calendar or event ID, and finds busy slots.
-   **[Google Calendar list management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cal-google-calendar-list-management-ai-agent.md)**  
This AI agent manages a user's Google Calendar list. It looks up calendars in the list and removes calendars from it.
-   **[Google Calendar metadata management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-google-cal-google-calendar-metadata-management-ai-agent.md)**  
This AI agent looks up Google Calendar time zone metadata.
