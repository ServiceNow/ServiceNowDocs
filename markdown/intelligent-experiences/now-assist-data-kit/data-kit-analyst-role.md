# AI Data Kit roles \(sn\_data\_kit.analyst\)

Users with this role can access the AI Data Kit Home page and edit and save ground truth data. Assign this role to analysts and AI practitioners who work with datasets and ground truth in AI Data Kit.

## Contains Roles

List of roles contained within the role.

None.

## Groups

List of groups this role is assigned to by default.

None.

## Special considerations

The AI Data Kit Home page requires the `sn_data_kit.analyst` role. Users who have the platform `admin` role but not `sn_data_kit.analyst` or `sn_data_kit.admin` will receive a security constraint error when navigating to AI Data Kit. Assign `sn_data_kit.analyst` to all users who need access to the application, including administrators.
