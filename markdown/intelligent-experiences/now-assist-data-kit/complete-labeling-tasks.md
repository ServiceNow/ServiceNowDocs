# Complete labeling tasks

Enter the ground truth for each record in the labeling tasks that are assigned to you.

## Before you begin

You must be a labeler on the labeling project.

If the data collection came from an instance table, read access to that table is also required.

Role required: sn\_data\_kit.analyst or sn\_data\_kit.admin

## Procedure

1.  On your home page, open a labeling task that's assigned to you.

2.  In the banner at the top of the task, select the link to open the data labeling project.

    The labeling page opens, with your tasks listed on the left.

3.  In the Tasks list, select a task.

    The task shows the record's fields and a field for the ground truth. Follow the project's labeling instructions when you write the ground truth.

4.  Enter the ground truth for the record.

5.  Choose how to save your work.

    |Goal|Action|
    |----|------|
    |**Finish the task**|Select **Submit**. The task's state changes to Published.|
    |**Come back to the task later**|Select **Save as draft**. The task stays open.|

6.  To move to another task, select **Next** or **Previous**, or select a task in the Tasks list.


## Result

When labeling is finished, the project owner marks the project complete. The ground truth values are then added to a new dataset and data collection.
