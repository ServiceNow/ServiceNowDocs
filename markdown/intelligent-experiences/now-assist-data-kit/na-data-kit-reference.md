# AI Data Kit reference

Reference topics for AI Data Kit.

-   **[AI Data Kit roles \(sn\_data\_kit.analyst\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-data-kit/data-kit-analyst-role.md)**  
This user can edit and save ground truth in AI Data Kit. This role has read only access within AI Data Kit.
-   **[AI Data Kit roles \(sn\_data\_kit.admin\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/now-assist-data-kit/data-kit-admin-role.md)**  
This user can create, update, and publish datasets in AI Data Kit. This role is mandatory to use AI Data Kit.
