# Create an intake record

Use the Prioritize tab to add a demand, product idea, or feedback record. Selecting **New** in any list opens a full form. The form fields differ by record type.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Home 2.0**.

2.  Expand the **Plan** menu and select **Prioritize**.

3.  Scroll to the list for the record type you need to create, Demand, Product idea, or Feedback.

4.  Select **New**.\[Omitted image "aict-plan-create-intake-record.png"\] Alt text: Use the New button to create an intake record.

5.  On the form, fill in the fields.

    For field information, see:

    -   [Demand form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-plan-demand-form.md)
    -   [Feedback form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-feedback-form.md)
    -   [Product idea form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/intelligent-experiences/aict-product-idea-form.md)
    **Note:**

    -   For demand and product idea: The **Investment Type** field must be set to **Artificial Intelligence** or the **Product** field must be set to **AI System**.
    -   For feedback: The **Product** field must be set to **AI System**.
6.  Select the **Actions** drop-down list and select **Save**.

    The new record is displayed in the respective list if it meets the list's display criteria.
