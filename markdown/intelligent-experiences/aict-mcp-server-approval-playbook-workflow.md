# MCP server approval playbook workflow

After you register and manage an MCP server, the AI steward moves it through the onboarding lifecycle before agents can use it.

Role required: sn\_ai\_governance.ai\_steward

This process has two outcomes that unlock different capabilities:

-   Managed: activates AI Gateway functionality.
-   Approved: makes the MCP server available for use in AI Agent Studio. Achieved by completing all phases of the Onboard playbook.
