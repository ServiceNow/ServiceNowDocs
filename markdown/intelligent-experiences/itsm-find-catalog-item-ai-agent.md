# Find catalog item AI agent

This AI agent identifies relevant catalog items for a given incident and adds all detected catalog item links to the incident's additional comments.

## Workflow

The agent uses an input query to find relevant catalog items and adds all the related catalog item links to the incident record worknotes.

1.  Find either the incident number or the incident sys\_id.
2.  Call the Find Catalog item and add the URLs in the additional comments tool and pass the incident number or sys\_id as parameters.
3.  Record the URLs in the record and end the workflow.
