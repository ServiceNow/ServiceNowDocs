# Controlling MCP server traffic

Turn MCP server connections off while you investigate a server, turn them back on when you're done, and review each server's activity.

## Overview of controlling traffic

When an MCP server needs investigation, turn off its connections through AI Gateway, or turn off AI Gateway for all servers. Agents keep their configuration, so traffic resumes when you turn the connections back on, which can take a few minutes.

-   [Turn AI Gateway connections on or off](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-gw-turn-connections.md): stop or restart traffic for all servers or for one server.
-   [Monitoring an MCP server](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/mon-ai-mcp-server-monitor.md): review requests, success rate, and latency for each of a server's tools over the last 30 days, on the record's **Monitor** tab. The tab shows data only for managed servers.
