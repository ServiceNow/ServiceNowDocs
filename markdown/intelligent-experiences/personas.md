# Content Understanding personas

Personas define the roles that interact with Content Understanding and the actions each role performs.

<table id="table_fkv_km4_ckc"><thead><tr><th>

Persona

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Admin

</td><td>

Activates capabilities, configures use cases \(fields, tables, questions, extraction mode\), and manages related integrations and flows. Requires the DocIntel Admin \[sn\_docintel.admin\] or DocIntel Manager \[sn\_docintel.manager\] role.

</td></tr><tr><td>

Fulfiller or human agent

</td><td>

Works a record, such as a case or task, and uses Document Q&amp;A or attachment summarization to get context from an attachment without opening the file.Reviews a document task when its use case is not set for full automation, and validates or corrects the predicted values before the task is completed. For more information, see [Automation modes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/automation-modes.md).

</td></tr><tr><td>

Requester or end user

</td><td>

Submits the record or request associated with a document and may also need quick answers about an attachment's content.Uses Document Q&amp;A conversationally in Virtual Agent, or views attachment summaries alongside a record.

</td></tr></tbody>
