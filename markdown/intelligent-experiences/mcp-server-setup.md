# MCP server setup

Explore the complete MCP server setup process in configuring and introducing MCP servers via AI Gateway.

Role required: sn\_ai\_governance.ai\_steward

The MCP server setup process consists of several key workflows:

1.  MCP server intake: The MCP server can be added in three different ways:
    -   Automatic discovery: Add an MCP server from AI Agent Studio.
    -   MCP Catalog: Add an MCP server from MCP Catalog.
    -   Manual registration: Add an MCP server manually from AI Control Tower.
2.  AI Steward playbook approval
3.  Client registration and setup
