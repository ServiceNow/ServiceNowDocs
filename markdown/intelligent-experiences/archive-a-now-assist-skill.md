# Archive an AI skill

The 'Archive' option enables you to archive copies and custom AI skills.

## Before you begin

Role required: sn\_generative\_ai.nsa\_admin

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **AI Skills**.

    If you’re already in the AI Admin Hub console, select the **AI Skills** tab.

2.  In the navigation pane, select a workflow you would like a archive a skill from.

3.  Select a skill you would like to archive.

    \[Omitted image "na-skill-archive.png"\] Alt text: Archive a skill

    You can archive custom skills and copies of skills, only.

4.  Confirm your selection in the modal.

    \[Omitted image "na-skill-archive-modal.png"\] Alt text: Modal for skill archival

5.  In the navigation pane, select **Archive**.

6.  Find the skills you have archived.

7.  Restore an archived skill you would like to activate.

    \[Omitted image "na-skill-archive-restore.png"\] Alt text: Restore an archived skill

8.  Select **Restore** to find the skill in your instance.

9.  Select **Activate**.

    You may find specific skills within **Archive** for which **Activate** option is unavailable. These are deprecated skills.

10. Find **Archived skills** option in the navigation pane to view and restore archived skills.

11. Find **Deprecated skills** option in the navigation pane to view skills deprecated by business unit or skills no longer supported by ServiceNow®.

    \[Omitted image "na-skill-deprecate.png"\] Alt text: Deprecated skills

    Deprecated skills consists:

    -   Skills that have been deprecated by a business unit and unavailable for use
    -   Skills that are available for use but targeted to be removed soon
    -   Skills for which a new version has been released, rendering the old version deprecated
