# Update ServiceNow Cowork

ServiceNow Cowork checks for updates automatically and verifies each update before it installs. You can also check for updates yourself at any time.

## Before you begin

Role required: sn\_app\_cowork.user

## About this task

Cowork checks for updates at startup,When it finds a required update, it shows the **Update and Restart** screen. When it finds an update in the background, it shows a notification that you can dismiss.

## Procedure

1.  In ServiceNow Cowork application, open **Settings**.

2.  Select **About**.

3.  Select **Update**.

    The **Update** button appears only when an update is available. If Cowork is current, **About** shows **Up to date** with the version number, for example **Up to date \(v1.0.0\)**.
