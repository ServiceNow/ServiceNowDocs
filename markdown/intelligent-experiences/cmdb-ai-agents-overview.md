# CMDB AI agents

The following AI agents are available for CMDB.

-   **[CI form contextual help AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-ci-form-contextual-help-ai-agent.md)**  
CI form contextual help AI agent helps users by answering questions about CI attributes and classes. It guides them through CI forms, dashboards, home pages, and other views on the workspace.
-   **[CMDB CI creator AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-ci-creator-ai-agent.md)**  
Handles the creation of a configuration item \(CI\). A CI is a representation of some type of infrastructure, application, software, hardware. Those configuration items belong to classes. Examples of CI classes include Windows Server, Data Center, Internet Cable, Apache Application, and Virtual Machine.
-   **[CMDB data certification and attestation manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-data-certification-and-attestation-manager-ai-agent.md)**  
Performs actions related to the data certification and data attestation policies of configuration item \(CI\) classes
-   **[CMDB data ownership manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-data-ownership-manager-ai-agent.md)**  
Performs actions related to the data ownership of configuration item \(CI\) classes
-   **[CMDB health metrics manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-health-metrics-manager-ai-agent.md)**  
Performs actions related to the CMDB health metrics
-   **[CMDB life cycle manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-life-cycle-manager-ai-agent.md)**  
Performs actions related to the lifecycle management of configuration item \(CI\) classes
-   **[CMDB principal class manager AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-principal-class-manager-ai-agent.md)**  
Performs actions related to principal configuration item \(CI\) classes
-   **[CMDB search AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-cmdb-search-ai-agent.md)**  
This AI agent searches for data in CMDB.
-   **[Configuration item summarization AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/cmdb-configuration-item-summarization-ai-agent.md)**  
This AI agent uses a sys\_id to summarize a configuration item \(CI\) using an existing skill.
