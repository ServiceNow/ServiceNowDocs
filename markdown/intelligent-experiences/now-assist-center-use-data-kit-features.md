# Use AI Data Kit features in AI Admin Center\(Next Experience UI\)

Use AI Data Kit on the data page in the AI Admin Center workspace.

**Important:** Lux is the new user experience for AI Admin Center. For more information on the Lux experience, see [AI Admin Center user experience \(Lux UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/ai-admin-center-lux-user-experience.md).

The Next Experience AI Admin Center workspace is being prepared for deprecation in the November store release and will no longer be supported. For more information on the Next Experience UI, see [AI Admin Center workspace \(Next Experience UI\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/now-assist-center-workspace.md).

In AI Admin Center version 6.1, the Next Experience and Lux user interfaces are both available.

## Before you begin

The following applications must be installed before performing this task:

-   AI Admin Center.

    For more information, see [Confirm installation of AI Admin Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/now-assist-center-install.md).

-   AI Data Kit.

    For more information, see [Install and configure essential AI plugins using AI Admin Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/install-configure-essential-now-assist-plugins.md).


Role required: sn\_na\_center.nac\_admin

## About this task

Follow these steps to use AI Data Kit capabilities from AI Admin Center.

AI Data Kit enables you to add custom datasets to a data catalog and create collections for use in ServiceNow SDK. The curated data works with ServiceNow SDK to enable the AI skill development and evaluation.

In AI Admin Center, the integration of AI Data Kit includes multi-tabbing support for working with datasets without leaving the application context.

**Note:** This topic describes the AI Admin Center feature based on the Next Experience user interface \(UI\). There is no Lux UI version of this topic.

## Procedure

1.  Navigate to **All** &gt; **AI Admin Center** &gt; **AI Admin Center \(Legacy\)**.

2.  Select **Data** \(\[Omitted image "icon-now-assist-center-nav-data.png"\] Alt text: Data icon. \) in the side navigation bar.

    The Data tab opens showing the AI Data Kit home page.

3.  Perform any of the tasks you would perform in the AI Data Kit application.

    Each action you take will open in a new tab in the AI Admin Center workspace.

    For more information on AI Data Kit, see [AI Data Kit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/now-assist-data-kit/now-assist-data-kit-landing.md).
