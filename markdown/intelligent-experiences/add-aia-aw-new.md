# Add AI agents to an agentic workflow

Add AI agents to an agentic workflow so they can work together to accomplish complex tasks.

## Before you begin

Role required: sn\_aia.admin

## About this task

AI agents are the core components of an agentic workflow. Each AI agent performs specialized tasks, and the agentic workflow coordinates them to solve complex problems collaboratively. You can create AI agents, add existing AI agents to your workflow, or allow the system to recommend AI agents based on your workflow's description and instructions.

## Procedure

1.  In the **Agents** section, select **Add Agents**.

2.  Choose how you want to add AI agents:

    -   Select **Create new agent** to create an AI agent. The AI agent guided setup opens in a new tab of AI Agent Studio. You can configure the new AI agent and return to the agentic workflow once you have saved it.

    -   Select **Add existing agent** to add an AI agent that already exists. A modal opens where you can search for an AI agent by name or browse the list of available AI agents. Select the AI agent you want to add to the agentic workflow.

    -   Select **Recommend agents** to let the system suggest AI agents. Based on your agentic workflow's description and instructions, the system automatically populates relevant and useful AI agents that would benefit your workflow.

    Once an AI agent is selected, it appears in the Agents section and can be removed by selecting the remove icon.


## Result

You have added AI agents to your agentic workflow. The workflow now has the specialized agents it needs to accomplish complex tasks collaboratively.
