# Order Management AI agents

The following AI agents are available for Order Management.

-   **[Invoice dispute AI voice agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/om-inv-invoice-dispute-ai-voice-agent.md)**  
This AI voice agent helps customers resolve discrepancies between invoiced quantities and received quantities by creating dispute cases.
-   **[Invoice dispute intake assistant AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/om-inv-invoice-dispute-intake-assistant-ai-agent.md)**  
This AI agent helps requesters identify the correct invoice, confirm dispute details, and submit invoice disputes related to quantity issues. It guides users step by step through invoice identification, validation, and dispute submission to ensure a smooth and accurate experience. The agent also analyzes the sentiment of the user throughout the conversation.
-   **[Invoice dispute support assistant AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/om-inv-invoice-dispute-support-assistant-ai-agent.md)**  
This agent helps users efficiently identify, review, and answer questions related to invoice disputes. It validates information, maintains data integrity, and answers questions regarding the invoice case.
-   **[Manage order operations AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/om-ord-manage-order-operations-ai-agent.md)**  
This AI agent helps customers request faster delivery of an order.
-   **[Order capture AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/om-order-capture-ai-agent.md)**  
This AI agent helps order-management agents investigate, understand, and update customer orders in any form, whether direct \(“apply 10% discount to all lines”\), corrective \(“this address is wrong, fix it”\), bulk \(“set quantity to 50 for every item”\), diagnostic \(“why is this order delayed?”\), or follow-up \(“undo the last change”\).
-   **[Order exception AI voice agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/om-ord-order-exception-voice-ai-voice-agent.md)**  
This AI voice agent helps customers request faster delivery of an order.
