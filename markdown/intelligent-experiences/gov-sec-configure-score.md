# Configure the AI asset security score

Customize the AI asset security score to align with your enterprise's security practices. You can omit large language model \(LLM\) guardrail categories from the score or change the weights of categories.

## Before you begin

Role required: AI steward \[sn\_ai\_governance\_ai\_steward\]

## About this task

Users should actively manage and review their agent assets and not rely solely on this AI asset security score.

## Procedure

1.  In AI Control Tower, navigate to **Settings** &gt; **Rules and templates** &gt; **Security**.

2.  Select **Security Score**.

3.  In Score Weight, select **Configure**.

4.  Adjust the weights next to each agent and model category.

5.  If you want to remove a security category from the score, clear the **Active** box.

6.  Save the settings.
