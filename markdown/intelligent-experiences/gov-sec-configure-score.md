# Configure the AI asset security score

Customize the AI asset security score in Super Intelligence Control Tower to align with your enterprise's security practices. You can omit large language model \(LLM\) guardrail categories from the score or change the weights of categories.

## Before you begin

Role required: sn\_ai\_governance.ai\_steward

## About this task

Users should actively manage and review their agent assets and not rely solely on this AI asset security score.

## Procedure

1.  In Control Tower, navigate to **Settings** &gt; **Rules and templates** &gt; **Security**.

2.  Select the **Overview** sub-tab.

3.  Adjust the weights next to each agent and model category.

4.  If you need to remove a security category from the score, clear the **Active** check box.

5.  Save the settings.
