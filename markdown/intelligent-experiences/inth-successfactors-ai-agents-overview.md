# SuccessFactors Spoke AI agents

The following AI agents are available for SuccessFactors Spoke.

-   **[SuccessFactors employee management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-successfactors-successfactors-employee-management-ai-agent.md)**  
This AI agent retrieves employee benefit and time off data from SAP SuccessFactors. It looks up benefit enrollments, time off records, and time off balances.
-   **[SuccessFactors HR foundational data AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-successfactors-successfactors-hr-foundational-data-ai-agent.md)**  
This AI agent retrieves holiday calendars from SAP SuccessFactors.
-   **[SuccessFactors jobs management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-successfactors-successfactors-jobs-management-ai-agent.md)**  
This AI agent looks up recruiting candidates in SAP SuccessFactors by candidate ID.
-   **[SuccessFactors payroll management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-successfactors-successfactors-payroll-management-ai-agent.md)**  
This AI agent looks up employee payrolls in SAP SuccessFactors from ServiceNow.
-   **[SuccessFactors todos AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-successfactors-successfactors-todos-ai-agent.md)**  
The agent manages SAP SuccessFactors todos from ServiceNow. It creates new todos and retrieves a specific todo by its ID.
-   **[SuccessFactors user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-successfactors-successfactors-user-management-ai-agent.md)**  
This AI agent retrieves user information from SAP SuccessFactors. It looks up a user by user ID and retrieves a user's personal details.
