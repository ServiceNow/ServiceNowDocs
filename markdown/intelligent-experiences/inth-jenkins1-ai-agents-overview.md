# Jenkins Spoke AI agents

The following AI agents are available for Jenkins Spoke.

-   **[Jenkins build management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jenkins1-jenkins-build-management-ai-agent.md)**  
This AI agent manages Jenkins builds. It runs builds, retrieves build numbers, build information, build history, and all builds for a job, and deletes builds.
-   **[Jenkins configuration management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jenkins1-jenkins-configuration-management-ai-agent.md)**  
This AI agent manages Jenkins configuration. It tests the connection, retrieves the version and a CSRF token, creates credentials, and creates or deletes nodes.
-   **[Jenkins job management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jenkins1-jenkins-job-management-ai-agent.md)**  
This AI agent manages Jenkins jobs and folders. It copies, reloads, and deletes jobs, creates and deletes folders, and retrieves job configurations, build timestamps, console output, and the jobs in a folder.
-   **[Jenkins user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jenkins1-jenkins-user-management-ai-agent.md)**  
This AI agent creates and deletes Jenkins users.
-   **[Jenkins view management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-jenkins1-jenkins-view-management-ai-agent.md)**  
This AI agent manages Jenkins views. It creates and deletes views, adds and removes jobs, and lists the jobs in a view.
