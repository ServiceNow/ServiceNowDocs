# Model version viewer AI agent

This AI agent shows admins the active and deprecated LLM models that are being used in the instance, at both the instance level and the skill level.

## Workflow

1.  Analyze the user's request to determine one of the four actions:
    -   View active or deprecated model versions.
    -   View deprecation or retirement dates for a particular LLM model.
    -   View instance-level configuration for model versions of a particular provider.
    -   View skill-level configuration for model versions.
2.  Display results to the user.
