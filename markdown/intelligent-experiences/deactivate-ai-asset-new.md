# Deactivate an agentic AI asset

Deactivate an AI agent or agentic workflow to stop it from running.

## Before you begin

Role required: sn\_aia.admin

## About this task

Deactivate an agentic AI asset when you want to stop it from running. Once deactivated, the agentic AI asset will no longer execute or be available for use.

You can reactivate the agentic AI asset at any time.

Instead of deactivating an entire agentic AI asset, you can create a new version of the instructions and use that instead. You can change versions at any time should you want to. For more information, see [Version control for AI agents and agentic workflows](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/version-control.md).

## Procedure

1.  Navigate to the **All** &gt; **AI Agent Studio** &gt; **Agentic solutions**.

2.  Select the **AI agents** or **Agentic workflows** tab.

3.  Select the agentic AI asset you want to deactivate.

4.  In the node view, select the first node of the AI specialist.

    The first node contains the main configuration settings for the AI specialist. The other nodes represent the individual agents that comprise the underlying architecture and aren't required to view the AI specialist's performance.

5.  Select the **Deactivate** button.

6.  In the confirmation modal, select **Deactivate** again to confirm.


## Result

Your agentic AI asset is deactivated and will no longer run or be available for use.
