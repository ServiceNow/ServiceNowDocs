# Microsoft Entra ID Spoke AI agents

The following AI agents are available for Microsoft Entra ID Spoke.

-   **[Microsoft Entra ID group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-entraid-microsoft-entra-id-group-management-ai-agent.md)**  
This AI agent manages Microsoft Entra ID groups. It creates security groups, deletes groups, looks up groups, and adds or removes members and owners.
-   **[Microsoft Entra ID license management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-entraid-microsoft-entra-id-license-management-ai-agent.md)**  
This AI agent manages Microsoft Entra ID licenses. It looks up subscribed SKUs and assigns or removes user licenses.
-   **[Microsoft Entra ID user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/inth-ms-entraid-microsoft-entra-id-user-management-ai-agent.md)**  
This AI agent manages Microsoft Entra ID users. It creates, enables, disables, and deletes users, looks up users, checks whether a user is enabled, in a group, or owns a group, and fetches user delta tokens.
