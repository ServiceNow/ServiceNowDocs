# Kubernetes Spoke AI agents

The following AI agents are available for Kubernetes Spoke.

-   **[Kubernetes endpoint management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-endpoint-management-ai-agent.md)**  
This AI agent creates and deletes Kubernetes endpoints.
-   **[Kubernetes namespace management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-namespace-management-ai-agent.md)**  
This AI agent creates and deletes Kubernetes namespaces.
-   **[Kubernetes node management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-node-management-ai-agent.md)**  
This AI agent manages Kubernetes nodes. It creates, inspects, and deletes nodes.
-   **[Kubernetes pod management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-pod-management-ai-agent.md)**  
This AI agent manages Kubernetes pods. It creates, inspects, and deletes pods.
-   **[Kubernetes secret management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-secret-management-ai-agent.md)**  
This AI agent creates and deletes Docker Hub secrets in Kubernetes.
-   **[Kubernetes service management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-service-management-ai-agent.md)**  
This AI agent creates and deletes Kubernetes services.
-   **[Kubernetes volume management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-kubernetes-kubernetes-volume-management-ai-agent.md)**  
This AI agent manages Kubernetes persistent storage. It creates and deletes persistent volumes and persistent volume claims and inspects claims.
