# Value configurations

Configure the value templates, value jobs, and calculation settings that Control Tower uses to measure the business value of your AI systems.

Value configurations control how Control Tower calculates value for the AI systems in your organization. Configure the templates that define which metrics are calculated, and the value jobs that run those calculations.
