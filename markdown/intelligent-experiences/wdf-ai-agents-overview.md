# Workflow Data Fabric AI agents

The following AI agents are available for Workflow Data Fabric.

-   **[Automation finder AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-ac-automation-finder-ai-agent.md)**  
This Workflow Data Fabric agent fetches automation records from tables on your instance. The agent discovers relevant automations for a specified asset, estimates cost and time savings, saves the discovered automations, and presents a value insights summary to the user.
-   **[Automation table discovery AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-ac-automation-table-discovery-ai-agent.md)**  
This Workflow Data Fabric agent collects asset, time, and scope inputs from the user and returns a structured JSON payload identifying the target execution tables for automation discovery.
-   **[Workflow data fabric flow generation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-workflow-data-fabric-flow-generation-ai-agent.md)**  
This Workflow Data Fabric agent transforms a user's natural-language integration intent into a generated Workflow Studio flow.
-   **[Workflow data fabric product knowledge AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-workflow-data-fabric-product-knowledge-ai-agent.md)**  
This Workflow Data Fabric agent retrieves and summarizes knowledge articles. The agent passes the user's query verbatim to the search tool, extracts factual content from matching articles, and produces a consolidated summary with references to source documents.
-   **[Workflow data fabric product recommendation AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-workflow-data-fabric-product-recommendation-ai-agent.md)**  
This Workflow Data Fabric agent evaluates integration requirements, data movement needs, communication flows, and automation objectives expressed in the user's prompt and determines the most suitable workflow data fabric product.
-   **[Workflow data fabric spoke asset discovery AI Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-workflow-data-fabric-spoke-asset-discovery-ai-agent.md)**  
This Workflow Data Fabric agent finds specific flows, subflows, and actions inside a named spoke that fulfill a user's stated automation goal. This agent is triggered only when a user has identified a spoke and wants to explore what reusable assets it contains for their use case.
-   **[Workflow data fabric spoke install advisor AI Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/wdf-workflow-data-fabric-spoke-install-advisor-ai-agent.md)**  
This Workflow Data Fabric agent helps you search for available IntegrationHub spokes that aren't installed on the instance. This agent takes the your search query, retrieves matching non-installed spokes from the instance catalog, and returns a prioritized list of candidates with installation links.
