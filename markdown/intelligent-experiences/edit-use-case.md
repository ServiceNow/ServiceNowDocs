# Edit a use case

Update an existing use case to modify its name, fields, tables, questions, integrations, and flows. Use cases marked as read-only must be copied before you can edit them.

## Before you begin

Role required: DocIntel Admin \[sn\_docintel.admin\] or DocIntel Manager \[sn\_docintel.manager\] role

## About this task

Use cases marked as read-only can't be edited. To edit a read-only use case, first make a copy of it. For more information, see [Copy a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/make-copy-use-case.md).

## Procedure

1.  Navigate to **All** &gt; **Now Assist Admin** &gt; **Skills**.

2.  In the workflow list, select **Platform**.

3.  In the Platform skills list, find a applicable skill.

4.  Select **Edit** in the options menu \(\[Omitted image "cu-options-menu.png"\] Alt text:\) for that skill.

5.  In the row of the use case you want to edit, select **Edit** in the options menu \(\[Omitted image "cu-options-menu.png"\] Alt text: Options menu icon \).

6.  Make changes as needed.

    For more information on use case setup, see [Set up a use case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/set-up-use-case.md).
