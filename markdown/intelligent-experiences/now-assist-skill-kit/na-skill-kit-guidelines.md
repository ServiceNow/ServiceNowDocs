# General guidelines for AI Skill Kit

Building a custom skill in AI Skill Kit follows five phases, from scoping the skill to deploying and monitoring it.

## AI Skill Kit skill-building phases

Think about the process of building a custom skill as having the following phases:

1.  [Scoping the skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-skill-kit/scoping-the-skill.md)
2.  [Collecting data and creating a dataset](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-skill-kit/creating-a-dataset.md)
3.  [Developing the prompt](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-skill-kit/developing-the-prompt.md)
4.  [Conducting a performance evaluation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-skill-kit/evaluating-the-prompt.md)
5.  [Deploying and monitoring the skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-skill-kit/deploying-and-monitoring.md)

\[Omitted image "MMASSET0020509-general-guidelines-now-assist-skill-kit-landing.png"\] Alt text: Five phases of building a custom skill, from scoping through deployment and monitoring.

Adopt a data-driven mindset while you build a skill. A data-driven mindset means emphasizing evidence-based decisions and minimizing speculation about how a large language model \(LLM\) can interpret the specific wording of a prompt.

Using AI Skill Kit requires intermediate prompt engineering skills. If you're not a developer, build that knowledge before you work with the tool.

Tooltips throughout the product explain individual fields and options.

To keep duties separate, a developer or generative AI practitioner creates the skill and then publishes it. After the skill is published, a AI Admin Hub activates the skill so that it appears at the configured touch points and is available to use.
