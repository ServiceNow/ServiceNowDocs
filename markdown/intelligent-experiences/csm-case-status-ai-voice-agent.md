# Case status AI voice agent

This AI agent helps users quickly retrieve and understand the status of their cases through a conversational voice interface.

## Workflow

The agent helps users complete tasks related to case status voice agent.

1.  Welcome and greeting.
2.  Request case number.
3.  Confirm case details.
4.  Retrieve case information.
5.  Generate case summary.
6.  Handle follow-up questions.
7.  Confirm completion and end the call.
