# Map an AI asset to a value template

Map an AI asset to a value template so that AI Control Tower calculates that AI system's value by using the mapped template.

## Before you begin

Role required:

-   AI steward \[sn\_ai\_g overnance\_ai\_steward\]
-   AI asset owner \[sn\_ai\_asset\_mgmt.ai\_asset\_owner\]

## About this task

You can map a value template to an AI asset from the **Templates** view on the AI asset record page, or from the **AI system mapping** sub-tab in template settings.

## Procedure

1.  Navigate to **All** &gt; **AI Control Tower** &gt; **Inventory**.

2.  Select the AI system asset and then select the **Templates** tab.

3.  Select **Add mapping** in the Value templates list.

4.  Select a template to map to the AI system.


## Result

The AI system uses the mapped value template, and its value appears in the value insights.
