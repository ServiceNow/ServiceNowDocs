# Duplicate an agentic AI asset

Duplicate an agentic AI asset to create an identical copy that you can fine-tune with distinct instructions and tools.

## Before you begin

Role required: sn\_aia.admin

## About this task

Duplicate agentic AI assets to create an identical copy of an existing agent or agentic workflow. Duplicating allows you to reuse asset configurations without affecting the original asset. The duplicated asset cannot have the same name as an existing agentic AI asset.

**Note:** For AI agents, the duplicate shares its tools with the original agent. Changing a tool on the duplicate also changes it on the original. To keep the original unchanged, add a new tool to the duplicate instead of editing the shared tool.

## Procedure

1.  Navigate to the **All** &gt; **AI Agent Studio** &gt; **Agentic solutions**.

2.  Select the **AI agents** or **Agentic workflows** tab.

3.  Scroll horizontally to view the duplicate icon on the far right of the agentic AI asset row.

4.  Select the duplicate icon for the agentic AI asset you want to duplicate.

5.  In the confirmation modal, select **Duplicate**.


## Result

You have duplicated the agentic AI asset. The duplicated asset appears in the list and you can now fine-tune it with distinct instructions and tools by following the agentic AI asset configuration guided setup.
