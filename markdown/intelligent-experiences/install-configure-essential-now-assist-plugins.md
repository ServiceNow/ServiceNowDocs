# Install and configure essential AI plugins using AI Admin Center

Install the plugins required to enable AI solutions on your instance before activating use cases.

## Before you begin

Role required: sn\_na\_center.nac\_admin

## Procedure

1.  Navigate to **All** &gt; **AI Admin Center** or **Workspaces** &gt; **AI Admin Center**.

    The first time you access AI Admin Center, a welcome message displays prompting you to get started by installing essential plugins. If you already have these plugins installed, the message simply introduces the benefits of AI Admin Center.

    \[Omitted image "ai-admin-center-home-welcome-message.png"\] Alt text: Welcome message showing the benefits of AI Admin Center.

2.  Select **Let’s get started** to continue to the home page.

    The home page opens.

    If you don’t have the essential plugins installed yet, the first section of the home page displays a **Let’s get you set up** card.

    \[Omitted image "now-assist-center-essential-plugins-card.png"\] Alt text: Actionable use case card to set up essential plugins.

3.  Select **Install plugins**.

    The Application Manager opens.

    AI Admin Center identifies which plugins are needed based on your license entitlements.

4.  Follow the prompts to install the required plugins.

5.  After installation completes, return to the AI Admin Center home page.


## Result

The required plugins are installed on your instance.

Actionable use case cards tailored to your instance and entitlements now appear in the first section of the home page.
