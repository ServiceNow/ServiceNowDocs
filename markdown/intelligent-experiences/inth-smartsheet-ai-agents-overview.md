# Smartsheet Spoke AI agents

The following AI agents are available for Smartsheet Spoke.

-   **[Smartsheet attachment management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-attachment-management-ai-agent.md)**  
This AI agent manages Smartsheet attachments. It attaches files or URLs to sheets and looks up a specific attachment or a sheet's attachments.
-   **[Smartsheet cell history AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-cell-history-ai-agent.md)**  
This AI agent retrieves the history of a Smartsheet cell so that users can see how its value changed over time.
-   **[Smartsheet column management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-column-management-ai-agent.md)**  
This AI agent retrieves Smartsheet column information. It looks up a column by ID or lists a sheet's columns.
-   **[Smartsheet comment management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-comment-management-ai-agent.md)**  
This AI agent manages Smartsheet comments. It creates comments, with or without attachments, updates comments, and looks up comments by ID.
-   **[Smartsheet cross sheet reference management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-cross-sheet-reference-management-ai-agent.md)**  
This AI agent manages Smartsheet cross-sheet references. It creates references and looks up a specific reference or a sheet's references.
-   **[Smartsheet folder management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-folder-management-ai-agent.md)**  
This AI agent manages Smartsheet folders. It creates and updates folders and looks up folders.
-   **[Smartsheet group management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-group-management-ai-agent.md)**  
This AI agent manages Smartsheet groups. It looks up the groups in an organization and updates group details.
-   **[Smartsheet row management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-row-management-ai-agent.md)**  
This AI agent adds new rows to Smartsheet sheets.
-   **[Smartsheet sharing management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-sharing-management-ai-agent.md)**  
This AI agent manages Smartsheet sheet sharing. It looks up a sheet's shares and shares a sheet with users or groups.
-   **[Smartsheet sheet management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-sheet-management-ai-agent.md)**  
This AI agent looks up Smartsheet sheets by ID.
-   **[Smartsheet user management AI agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/intelligent-experiences/inth-smartsheet-smartsheet-user-management-ai-agent.md)**  
This AI agent manages Smartsheet users. It creates, updates, and removes users and looks up users by ID or the admin user.
