# Configure ServiceNow Otto for Purchase Order Management \(POM\)

If you have the admin role, you can configure the ServiceNow Otto for Purchase Order Management \(POM\) application so that an operational buyer or a supplier can use the generative AI skills in Purchase Order Management.

## Before you begin

**Note:** Depending on your license, you have access to certain application features, generative AI skills, agentic workflows, and AI agents.

Role required: admin

## Procedure

1.  Install the ServiceNow Otto for POM plugin \(sn\_poem\_gen\_ai\).

    -   For information about the plugin dependencies and plugin activation order, see [Supporting information for ServiceNow Otto for Purchase Order Management \(POM\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/source-to-pay-operations/supporting-information-na-pom.md).
    -   For information about the installation process, see [Install plugins for ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/intelligent-experiences/install-now-assist-feature-plugins.md).
2.  Review the define PO exception mitigation strategy agentic workflow in AI Agentic Studio.
