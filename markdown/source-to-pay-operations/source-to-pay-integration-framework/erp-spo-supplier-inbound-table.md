# Supplier Stage inbound staging table

The Supplier Stage inbound \[sn\_fcms\_intg\_imp\_supplier\] staging table temporarily stores important data about suppliers before this data is sent to the primary table.

The following table lists the fields for the Supplier Stage inbound \[sn\_fcms\_intg\_imp\_supplier\] staging table.

|Field|Data type|Description|
|-----|---------|-----------|
|Company|String|Name of the company that the supplier is linked to.|
|Zip/Postal code|String|The zip code of the supplier location.|
|ERP source|String|ERP source from which data is imported.|
