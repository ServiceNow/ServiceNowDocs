# AI Data Explorer using multiple tables

The AI Data Explorer interprets natural-language prompts to correlate data across multiple related Accounts Payable Operations, Sourcing and Procurement Operations, and Supplier Lifecycle Operations tables. Fulfillers get unified answers without manually exporting and joining data.

## Key benefits

Multi-table analysis with AI Data Explorer provides the following benefits:

-   Correlates data across related entities, such as supplier, invoice, and purchase order, in a single query.
-   Merges columns from multiple related tables into a unified data set and generates reports, visualizations.
-   Reduces the manual effort.
-   Supports faster, more complete decision-making from a single prompt-based interaction.

## How it works

A fulfiller enters a natural-language prompt describing the information they need. AI Data Explorer interprets the prompt, queries the relevant APO, SPO and SLO tables, and returns a consolidated answer.

-   Queries can span multiple related tables, including invoice, supplier, approval, purchase order, and receipt data.
-   Answers combine data from more than one table into a single result set.
