# Query multiple tables in AI Data Explorer

Use natural-language prompts to retrieve and correlate data from multiple related tables in a single answer.

## Before you begin

Role required: fulfiller

## About this task

Use this procedure when you need to combine data from multiple related tables, such as invoices, suppliers, purchase orders, and approvals.

**Warning:**

Generative AI may produce inaccurate or incomplete information. Always validate AI-generated content and implement human review of results.

## Procedure

1.  Navigate to **AI Data Explorer**.

2.  In the prompt field, enter your question in natural language.

    Example: List requisitions where the requested delivery date is earlier than the expected delivery date on any of their PO lines.\[Omitted image "use-ai-data-explorer.png"\] Alt text: AI Data Explorer using Natural language query\[Omitted image "use-ai-data-explorer.png"\] Alt text: Query visualization

    The interface displays the generated query and results from the relevant tables.

3.  Select **Edit source** to view the generated query.

    \[Omitted image "condition-filter-ai-explore.png"\] Alt text: Query in AI Data Explorer


## Result

AI Data Explorer interprets your prompt and returns a consolidated answer that combines data from the relevant related tables.
