# GL rule \[sn\_fin\_gl\_rule\] table

The GL Rule \[sn\_fin\_gl\_rule\] table stores general ledger classification rules.

## GL rule \[sn\_fin\_gl\_rule\] table

This table contains the following fields.

|Field|Data type|Description|
|-----|---------|-----------|
|Name|String|Name of the GL rule.|
|Class name|String|Table class name of the GL rule record.|
|Table|Table name|Table to which the GL rule applies.|
|Execution order|Integer|Order in which the GL rule is executed relative to other rules.|
|Inactive|Boolean|Inactive status of the GL rule.|
|Conditions|Conditions|Conditions on the selected table that determine when the rule applies.|
|Default|Boolean|Indicates whether this is the default GL rule.|
