# Primary data tables for Sourcing and Procurement Operations

The primary data tables for Sourcing and Procurement Operations store important information about products, attributes, pricing, approvals, payment terms, shipping methods, delivery locations, and job codes.

-   **[Fixed Asset \[sn\_fin\_fixed\_asset\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-fixed-asset-table.md)**  
The Fixed Asset \[sn\_fin\_fixed\_asset\] table stores information related to: Fixed assets purchased from suppliers.
-   **[Finance Exchange Rates \[sn\_fin\_fx\_rate\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-fx-rate-table.md)**  
The Finance Exchange Rates \[sn\_fin\_fx\_rate\] table stores currency exchange rates used for Finance Common.
-   **[Ledger Account table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-gl-account-table.md)**  
The Ledger Account \[sn\_fin\_gl\_account\] table stores information related to: General ledger accounts.
-   **[GL rule \[sn\_fin\_gl\_rule\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-gl-rule-table.md)**  
The GL Rule \[sn\_fin\_gl\_rule\] table stores general ledger classification rules.
-   **[Threshold rule \[sn\_fin\_gl\_threshold\_rule\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-gl-threshold-rule-table.md)**  
The Threshold Rule \[sn\_fin\_gl\_threshold\_rule\] table stores variance threshold information for general ledger rules.
-   **[Industry \[sn\_fin\_industry\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-industry-table.md)**  
The Industry \[sn\_fin\_industry\] table stores industry classification information.
-   **[Ledger \[sn\_fin\_ledger\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-ledger-table.md)**  
The Ledger \[sn\_fin\_ledger\] table stores financial reporting ledger data.
-   **[Legal Entity \[sn\_fin\_legal\_entity\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-legal-entity-table.md)**  
The Legal Entity \[sn\_fin\_legal\_entity\] table stores information about legal entities used in financial and organizational structures.
-   **[Office Location table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-office-location-table.md)**  
The Office Location \[sn\_fin\_office\_location\] table stores data about organization office locations, including address, country, legal entity, and ERP source.
-   **[Organization \[sn\_fin\_organization\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/fin-organization-table.md)**  
The Organization \[sn\_fin\_organization\] table stores information about organizational entities such as companies and legal entities.
-   **[Approval Group \[sn\_shop\_approval\_group\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-approval-group-table.md)**  
The Approval Group \[sn\_shop\_approval\_group\] table stores information related to: Approval groups.
-   **[Approval Rule \[sn\_shop\_approval\_rule\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-approval-rule-table.md)**  
The Approval Rule \[sn\_shop\_approval\_rule\] table stores the rules that determine how and when approval requests are sent for purchasing objects.
-   **[Approval Rule Composition table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-approval-rule-composition-table.md)**  
The Approval Rule Composition \[sn\_shop\_approval\_rule\_composition\] table stores rule ordering within approval groups.
-   **[Attribute \[sn\_shop\_attribute\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-attribute-table.md)**  
The Attribute \[sn\_shop\_attribute\] table stores product attribute values.
-   **[Attribute Set \[sn\_shop\_attribute\_set\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-attribute-set-table.md)**  
The Attribute Set \[sn\_shop\_attribute\_set\] table groups attribute types.
-   **[Attribute Type \[sn\_shop\_attribute\_type\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-attribute-type-table.md)**  
The Attribute Type \[sn\_shop\_attribute\_type\] table stores product attribute definitions.
-   **[Delivery Location \[sn\_shop\_delivery\_location\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-delivery-location-table.md)**  
The Delivery Location \[sn\_shop\_delivery\_location\] table stores delivery address information.
-   **[Job Code \[sn\_shop\_job\_code\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-job-code-table.md)**  
The Job Code \[sn\_shop\_job\_code\] table stores job codes for users.
-   **[Payment Terms \[sn\_shop\_payment\_term\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-payment-terms-table.md)**  
The Payment Terms \[sn\_shop\_payment\_term\] table stores payment term information.
-   **[Price Break \[sn\_shop\_price\_break\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-price-break-table.md)**  
The Price Break \[sn\_shop\_price\_break\] table stores quantity-based pricing information.
-   **[Pricing \[sn\_shop\_m2m\_product\_contract\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-pricing-table.md)**  
The Pricing \[sn\_shop\_m2m\_product\_contract\] table stores contract-specific product pricing information.
-   **[Product group \[sn\_shop\_product\_group\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-product-group-table.md)**  
The Product group \[sn\_shop\_product\_group\] table stores product model grouping information.
-   **[Product Visuals \[sn\_shop\_supplier\_product\_artifact\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-product-visuals-table.md)**  
The Product Visuals \[sn\_shop\_supplier\_product\_artifact\] table stores product images and media.
-   **[Shipping methods \[sn\_shop\_shipping\_method\] table](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/spo-shipping-methods-table.md)**  
The Shipping methods \[sn\_shop\_shipping\_method\] table stores shipping method and carrier information.
