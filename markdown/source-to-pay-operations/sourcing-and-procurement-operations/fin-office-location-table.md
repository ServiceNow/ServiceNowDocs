# Office Location table

The Office Location \[sn\_fin\_office\_location\] table stores data about organization office locations, including address, country, legal entity, and ERP source.

This table contains the following fields.

|Field|Data type|Description|
|-----|---------|-----------|
|Name|String|Display name used when referencing this office location.|
|Location|Reference|Address of this office location.|
|Country|Reference|Country in which this office location exists.|
|Legal entity|Reference|Legal entity responsible for this office location.|
|Default|Boolean|Determines whether this is the organization's default location.|
|ERP Source|Reference|ERP source system associated with the office location.|
