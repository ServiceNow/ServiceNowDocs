# Enable AI agents for the Help fulfill procurement requests agentic workflow in Virtual Agent

Enable AI agents in Virtual Agent to streamline procurement requests, providing quicker support and a more efficient experience for requesters through intelligent assistance.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **AI Agent Studio** &gt; **Overview**.

2.  Under Agentic workflows, select **Help fulfill procurement requests**.

    \[Omitted image "agentic-spo-wf.png"\] Alt text: Help fulfill procurement requests agentic workflow.

3.  Under Connect AI agents, select any of the AI agents that you want to make available in Virtual Agent.

    The agents that you can select:

    -   Track request agent
    -   Product recommendation and procurement agent
    -   Guided checkout agent
    -   Off catalog agent
    -   Procurement inquiry analysis AI agent
    For example, let's assume that you select the Product recommendation and procurement agent.

    \[Omitted image "agentic-connect-ai.png"\] Alt text: AI agents that you can select to enable.

4.  On the Describe and instruct page, select **Continue**.

    The Describe and instruct page is read-only.

5.  On the Add tools and information page, select **Continue**.

    The Add tools and information page is read-only.

6.  On the Describe and instruct page, select **Continue**.

    The Describe and instruct page is read-only.

7.  On the Define trigger page, select **Continue**.

    The Describe trigger page is read-only.

8.  On the Define availability page, in the Select display section, switch the Display toggle to the open position so that the AI agent is enabled in the Virtual Agent.

    \[Omitted image "agentic-prod-agent.png"\] Alt text: Enable the selected AI agent in Virtual Agent.

9.  To activate the agentic workflow, select **Save and test**.

    The selected AI agent is enabled in Virtual Agent.
