# Job Code \[sn\_shop\_job\_code\] table

The Job Code \[sn\_shop\_job\_code\] table stores job codes for users.

This table contains the following fields.

|Field|Data type|Description|
|-----|---------|-----------|
|Code|String|Job code for a user.|
