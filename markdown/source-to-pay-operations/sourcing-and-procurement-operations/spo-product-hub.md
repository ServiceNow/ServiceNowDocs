# Sourcing and Procurement Operations Product Hub

The Sourcing and Procurement Operations Product Hub is the central surface for installing SPO, tracking installation status, and reaching learning resources.

Selecting the SPO tile on Admin Home opens the SPO Product Hub. The hub landing page displays the product name and a brief description, and brings installation, status tracking, and product learning content into a single page.

\[Omitted image "spo-product-hub-configure.png"\] Alt text: Sourcing and Procurement Operations Product Hub with the Installed tab selected and the Helpful resources section.

## Apps and plugins tabs

The **Apps and plugins** section of the hub organizes SPO resources into three tabs:

-   **Not installed** — resources not yet installed on the instance. This tab is selected by default the first time an admin visits the hub.
-   **Installed** — resources that have completed installation.
-   **Updates available** — installed resources with a newer version available.

A resource card moves from the **Not installed** tab to the **Installed** tab after installation completes, and to the **Updates available** tab when a newer version becomes available.

## Helpful resources section

A **Helpful resources** section on the hub remains visible regardless of the current installation state, so admins can access learning content at any point. It provides:

-   A product overview video
-   A link to configure with SPO using ServiceNow Otto
-   Configuration guidance
-   A release notes link
-   A product documentation link
-   A community link

## Configuration redirection

The Product Hub includes a control to configure the installed product, which opens the SPO Configuration Console.

For the procedure to install SPO from the Product Hub, see [Install Sourcing and Procurement Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/sourcing-and-procurement-operations/install-spo-ai.md).
