# Address deletion permissions

Only the user who saved a delivery address can delete it. If you shop on behalf of another user, you have the same ability to delete addresses saved under that account.

## Who can delete a delivery address

|User|Can delete a saved address|Role required|
|----|--------------------------|-------------|
|The user who saved the address|Yes|`sn_shop.shopper`|
|A user shopping on behalf of the address owner \(Shop as\)|Yes|`sn_shop.shopper`|
