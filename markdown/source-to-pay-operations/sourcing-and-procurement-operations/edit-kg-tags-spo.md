# Edit Knowledge Graph tags

Customize the instructions that the AI L1 SPO Service Desk Specialist uses to retrieve information by editing FSC Common Knowledge Graph tags.

## Before you begin

Role required: kg\_admin

## About this task

FSC Common Knowledge Graph Tags is a collection of tables that help the AI L1 SPO Service Desk Specialist interpret the context and content of different tables. Edit these tags to add or update tables, table synonyms, column descriptions, and other instructions that improve the accuracy of AI responses.

## Procedure

1.  Navigate to **All** &gt; **Knowledge Graph Designer** &gt; **Enterprise Graph Tags**.

2.  Select **FSC Common KG Tags** to open it in the Knowledge Graph canvas.

    The canvas displays all tables that are part of the tag.

3.  Open the tag for editing.

    -   To edit the tag, select **Edit tag**.
    -   To edit a node, select the node. The Tag configuration section appears in the right pane.
4.  Update the tag details as needed, including table synonyms, column names, and instructions.

    Instructions you add help the AI L1 SPO Service Desk Specialist interpret the context of the table when processing procurement inquiries.

5.  Select **Update Tag** to save your changes.
