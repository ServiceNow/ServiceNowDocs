# Integrate Accounts Payable Operations with other applications

Accounts Payable Operations integrates with ERP systems, Document Intelligence, IT Asset Management, and other business applications to enable bidirectional data exchange and automated invoice processing.

## Accounts Payable Operations integrations

Accounts Payable Operations supports the following integrations:

-   **Integration framework**

    Invoice integration enables bidirectional data exchange with ERP systems for ingestion, posting, and synchronization. For more information, see [Accounts Payable Operations integration framework](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/accounts-payable-operations/using-integration-to-create-invoice.md).

-   **IT Asset Management purchase order invoice processing**

    IT Asset Management invoice exceptions for purchase orders are automatically handled through quantity validation, discrepancy notifications, and revalidation. For more information, see [IT Asset Management purchase order invoice processing](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/accounts-payable-operations/apo-integration-with-itam.md).


## Third-party application integrations

Accounts Payable Operations integrates with the following third-party ERP applications.

-   **ERP Integration Framework**

    The Source-to-Pay Operations ERP Integration Framework connects ServiceNow® with third-party ERP systems, enabling data exchange for purchase orders, receipts, invoices, fixed assets, and tax information across multiple ERP instances.

    For more information, see [ERP Integration Framework](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/erp-integration-framework.md).

-   **Accounts Payable Operations integration with SAP**

    Post and synchronize invoices between Accounts Payable Operations and SAP ECC and SAP S/4HANA through bidirectional data exchange.

    For more information, see [Source-to-Pay integration with SAP](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-sap-integration.md).

-   **Accounts Payable Operations integration with Oracle EBS**

    Post, synchronize, and reconcile invoices in Oracle EBS from your ServiceNow® instance.

    For more information, see [Source-to-Pay integration with Oracle EBS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-oracle-ebs-integration.md).

-   **Accounts Payable Operations integration with SAP Ariba**

    Post, synchronize, and reconcile invoices in SAP Ariba from your ServiceNow® instance.

    For more information, see [Source-to-Pay integration with SAP Ariba](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-integration-sap-ariba.md).

-   **Accounts Payable Operations integration with Coupa**

    Post, synchronize, and reconcile invoices in Coupa from your ServiceNow® instance.

    For more information, see [Source-to-Pay integration with Coupa](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-coupa-integration.md).
