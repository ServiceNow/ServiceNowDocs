# Reopen a closed invoice case

Reopen a closed or cancelled invoice inquiry case to continue working on it instead of creating a new one. Reopening preserves the full case history, so you can correct details, send a follow-up email, or resume the conversation on the existing case.

## Before you begin

Role required: APO CM agent

## Procedure

1.  Navigate to **All** &gt; **Accounts Payable Operations** &gt; **Accounts Payable Workspace**.

2.  Select the list icon \(\[Omitted image "icon-list.png"\] Alt text: List icon\).

3.  Navigate to **Lists** &gt; **Invoices** &gt; **All Invoices**.

4.  Open an invoice in **Closed** or **Cancelled invoice inquiry** state.

5.  Select **Reopen**.


## Result

The case state reverts to **Work in Progress**. All previous case activities, field changes, and communication history remain visible and accessible, so you can continue working on the existing case.
