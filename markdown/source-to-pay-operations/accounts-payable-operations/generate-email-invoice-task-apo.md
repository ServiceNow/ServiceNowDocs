# Generate email response for invoice task

Generate email response for invoice task.

## Before you begin

Role required: ap\_agent or ap\_specialist

## About this task

The Email response for invoice task skill uses invoice task details to compose an email response. These details include short description, description, work notes, activity stream, additional comments, related records, and relevant knowledge base articles. You can also use this skill to elaborate, shorten, or change the tone of your email draft.

## Procedure

1.  Navigate to **Workspaces** &gt; **Source-to-Pay Workspace**.

2.  Select the list icon \(\[Omitted image "cases-list-icon.png"\] Alt text: List icon\).

    A list of options within the workspace is displayed.

3.  Select **Invoices &gt;****All invoices.**

4.  Select an invoice case.

    The case detail view appears.

5.  Select **Tasks**.

6.  In the **Email** tab, select anywhere within the email body text box.

7.  Generate an email draft by selecting the ServiceNow Otto icon \[Omitted image "servicenow-otto-icon.png"\] Alt text: AI icon.

8.  Select **Insert**.

9.  Select **Refine** to elaborate, shorten, or change the tone of an email body.

10. Apply templates by selecting the template icon\[Omitted image "template-icon.png"\] Alt text: Template.\[Omitted image "email-inv-task-apo.png"\] Alt text: Email generation for invoice task

    The email response is generated for the invoice task.
