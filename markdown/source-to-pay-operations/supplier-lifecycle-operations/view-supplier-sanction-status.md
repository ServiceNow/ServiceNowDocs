# View supplier sanction status

Supplier managers can view the sanction status and last sanction check date for suppliers from the Manage Suppliers list.

## Before you begin

Role required: sn\_slm.manager, sn\_slm.owner, or sn\_slm.admin

## About this task

The Manage Suppliers list displays the sanction status and last sanction check date for each supplier. These fields are available regardless of whether the Relish plugin is installed.

## Procedure

1.  Navigate to **All** &gt; **Supplier Lifecycle Operations** &gt; **Manage Suppliers**.

2.  Review the **Sanction status** and **Last sanction check** columns.

    The Sanction status field displays one of the following values:

    -   **Clear**: Sanction screening passed or passed with cautions
    -   **Blacklisted**: Sanction screening failed
    -   **Skipped**: Sanction screening was bypassed or could not be completed
    The Last sanction check field displays the date and time when the most recent sanction screening was performed for the supplier.

    **Note:** The Sanction status and Last sanction check fields in the supplier list are updated only when Relish is integrated. If Relish is not integrated, users can edit the field manually if they want.
