# View supplier tax information

Supplier managers can view all tax information records for a supplier from the supplier record.

## Before you begin

Role required: sn\_slm.manager, sn\_slm.owner, or sn\_slm.admin

## About this task

The **Tax Information** related link on the supplier record displays all tax records for the supplier. Each supplier can have only one tax record per country.

## Procedure

1.  Navigate to **All** &gt; **Supplier Lifecycle Operations** &gt; **Manage Suppliers**.

2.  Open the supplier record for which you want to view tax information.

3.  In the Related Links section, select **Tax Information**.

    A list of all tax records for the supplier appears, showing the tax ID, tax type, and country for each record.
