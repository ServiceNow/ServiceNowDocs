# Edit Knowledge Graph Tags

Customize instructions used by the AI L1 SLO Service Desk Specialist to retrieve information by editing the FSC Common Knowledge Graph tags.

## Before you begin

Role required:kg\_admin

## About this task

FSC Common KG Tags is a collection of tables that help AI L1 SLO Service Desk Specialist evaluate the context and content of different tables. You can edit these tags to add or update tables, table synonyms, column descriptions, and other instructions to improve the accuracy of AI responses.

## Procedure

1.  Navigate to **All** &gt; **Knowledge Graph Designer** &gt; **Enterprise Graph Tags**.

2.  Select **FSC Common KG Tags** to open it in the Knowledge Graph canvas.

    The canvas displays all tables that are part of the tag.

3.  Select a tag for editing.

    -   To edit the tag, select **Edit tag**.
    -   To edit a node, select the node. The Tag configuration section appears in the right pane.
4.  Update the tag details as needed, including table synonyms, column names, and instructions.

    Instructions you add help the AI L1 SLO Service Desk Specialist interpret the context of the table when processing supplier inquiries.

5.  Select **Update Tag** to save your changes.
