# Integrate Supplier Lifecycle Operations with other applications

Extend the capabilities of Supplier Lifecycle Operations by integrating with other applications.

## Supplier Lifecycle Operations integrations

Supplier Lifecycle Operations \(SLO\) supports the following integrations:

-   **Supplier Lifecycle Operations integration framework**

    The Supplier Lifecycle Operations integration framework connects ServiceNow with third-party ERP systems, enabling the exchange of supplier data across multiple ERP instances.

    For more information, see [Supplier Lifecycle Operations integration framework](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/slo-int-framework.md).

-   **Craft.co Integration for Supplier Lifecycle Operations**

    This integration between Craft and Supplier Case Management surfaces supplier risk intelligence directly within Supplier Lifecycle Operations.

    For more information, see [Craft.co Integration for Supplier Lifecycle Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/craft-integration.md).

-   **News Integration for Supplier Lifecycle Operations**

    This integration retrieves supplier news and activities using the Microsoft Bing News Search API and displays this information in the Supplier News and Activity section on the About tab of the Source-to-Pay Workspace.

    For more information, see [News Integration for Supplier Lifecycle Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/supp-news-integration.md).

-   **Relish Integration for Supplier Lifecycle Operations**

    This integration between Relish Data Assure and Supplier Case Management brings supplier data assurance checks into Supplier Lifecycle Operations.

    For more information, see [Relish Integration for Supplier Lifecycle Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/relish-slo-connector.md).

-   **FedEx Dataworks Integration for Supplier Lifecycle Operations**

    FedEx Dataworks brings logistics intelligence into Supplier Lifecycle Operations, surfacing shipping patterns and delivery data to support supplier onboarding and risk decisions.

    For more information, see [FedEx Dataworks Integration for Supplier Lifecycle Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/fedex-dataworks-overview.md).


## Third-party application integrations

Supplier Lifecycle Operations integrates integrates with the following third-party ERP applications.

-   **ERP Integration Framework**

    The Source-to-Pay Operations ERP Integration Framework connects ServiceNow® with third-party ERP systems, enabling data exchange for purchase orders, receipts, invoices, fixed assets, and tax information across multiple ERP instances.

    For more information, see [ERP Integration Framework](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/erp-integration-framework.md).

-   **Supplier Lifecycle Operations integration with SAP**

    Exchange supplier and primary data between Supplier Lifecycle Operations and SAP ECC and SAP S/4HANA from your ServiceNow® instance.

    For more information, see [Source-to-Pay integration with SAP](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-sap-integration.md).

-   **Supplier Lifecycle Operations integration with Oracle EBS**

    Handle sales orders, procurement, finance, and other operations in Oracle EBS from your ServiceNow® instance.

    For more information, see [Source-to-Pay integration with Oracle EBS](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-oracle-ebs-integration.md).

-   **Supplier Lifecycle Operations integration with SAP Ariba**

    Handle sales orders, procurement, finance, and other operations in SAP Ariba from your ServiceNow® instance.

    For more information, see [Source-to-Pay integration with SAP Ariba](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-integration-sap-ariba.md).

-   **Supplier Lifecycle Operations integration with Coupa**

    Manage business spend and automate approvals, contracts, inventory, purchase orders, requisitions, suppliers, and user management in Coupa from your instance.

    For more information, see [Source-to-Pay integration with Coupa](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-coupa-integration.md).

-   **Supplier Lifecycle Operations integration with Oracle Financial Cloud**

    Sync supplier data from ServiceNow® to Oracle Financial Cloud.

    For more information, see [Source-to-Pay integration with Oracle Financial Cloud](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/source-to-pay-integration-framework/source-to-pay-oracle-fin-cloud-integration.md).


-   **[Supplier Lifecycle Operations integration framework](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/slo-int-framework.md)**  
The Supplier Lifecycle Operations \(SLO\) integration framework enables you to exchange supplier data with any third-party ERP system.
-   **[Craft.co Integration for Supplier Lifecycle Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/craft-integration.md)**  
The Craft.co Integration for Supplier Lifecycle Operations plugin \(com.snc.sn\_supplier\_craft\) provides an integration between Craft and Supplier Case Management plugin.

The News Integration for Supplier Lifecycle Operations plugin \(com.snc.sn\_supplier\_news\) retrieves supplier news and activities using the Microsoft Bing News Search API and displays this information in the Supplier News and Activity section on the **About** tab of the Source-to-Pay Workspace.
-   **[Relish Integration for Supplier Lifecycle Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/source-to-pay-operations/supplier-lifecycle-operations/relish-slo-connector.md)**
