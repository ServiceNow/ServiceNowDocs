# Purchase order confirmation form

Use the purchase order confirmation form to view the confirmation details and related confirmation lines.

|Field|Description|
|-----|-----------|
|Number|Auto-generated unique identifier for this PO confirmation record.|
|Purchase order|Purchase order associated with this confirmation.|
|Created|Date and time on which this PO confirmation was created.|
|Status|Indicates the current stage of the confirmation record. Possible values are Draft, Draft Retracted, or Submitted.|
|ERP number|Purchase order ID in the external ERP system.|
|Created by|Supplier contact who created this purchase order confirmation record.|
