# Manage sales records on Sales CRM Mobile

View and manage your accounts, leads, opportunities, and contact details from Sales hub on Sales CRM Mobile application.

## Before you begin

Role required: **sales\_mobile\_user**

## About this task

## Procedure

1.  Open Sales CRM Mobile and select **Sales hub**.

    The **Sales** section displays a tile for Opportunity, Account, Lead, and Contacts.

2.  Select the **Opportunity** tile.

    The **My Opportunities** tab displays the list of current opportunities assigned to you and their status. The **All** tab displays all the opportunities in the system that are visible to you.

    1.  Select an opportunity to view its record.

        The record displays the **Overview**, **Details**, **Related**, and **Activities** tabs.

    2.  Select the **Related** tab to view the tasks, meetings, and other details related to that opportunity.

    3.  Select the **Activities** tab to add more information to the opportunity.

    4.  Select **Add Comment** to add a work note to the record.

    5.  Select **Document** to attach a document to the record.

    6.  Select **Image** to attach an image to the record.

    7.  Select **Camera** to take a photo and attach it to the record.

3.  Select the **Account** tile.

    The **Account** tab displays all the accounts assigned to you. Select any account to view its complete details.

4.  Select the **Lead** tile.

    The **My Leads** tab displays the list of leads assigned to you and their status. The **All** tab displays all the leads in the system that are visible to you.

    1.  Select a lead to view its record.

        The record displays the **Overview**, **Details**, **Related**, and **Activities** tabs.

    2.  Select the **Related** tab to view the tasks, meetings, and other details related to that lead.

    3.  Select the **Activities** tab add more information to the lead.

    4.  Select **Add Comment** to add a work note to the record.

    5.  Select **Document** to attach a document to the record.

    6.  Select **Image** to attach an image to the record.

    7.  Select **Camera** to take a photo and attach it to the record.

5.  Select the **Contact** tile.

    View all the contacts that you have and select any contact to view more details about them.

6.  Under the Pipeline health section, view all the statistics of the opportunities and the assets.


## What to do next

Access ServiceNow Otto AI interface to know more about your current records and view their summary.
