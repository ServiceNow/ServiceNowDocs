# Activating the RMA Agentic workflows

Activate the agentic workflows and triggers to manage cases and provide resolutions.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **AI Agent studio** &gt; **Create and Manage**.

2.  Select **RMA AI Agent workflow**.

    The workflow is active by default.

3.  In the RMA AI Agentic workflow, select **Define trigger**.

4.  Select the agentic workflow trigger in the list.

5.  On the Edit trigger form, set **Active** to true.
