# Pricing Management reference

Reference topics provide additional information about the Pricing Management group of applications.

-   **[Components installed with Pricing Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/components-installed-with-pricing-management.md)**  
Several types of components are installed with activation of the Pricing Management plugin, including tables, user roles, and scheduled jobs.
-   **[Components installed with Context Rule Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/components-installed-context-rule-management.md)**  
Several types of components are installed with activation of the Context Rule Management \(sn\_csm\_ctxrul\_mgt\) plugin, including tables and user roles.
-   **[Pricing Management properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/pricing-management-properties.md)**  
System properties available with Pricing Management that enable you to control the precision applied to non-currency pricing values, tune how multiline pricing requests are processed, and set the level of detail captured for pricing engine troubleshooting.
-   **[Pricing payload field mapping](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/r_pricing_payload_field_mapping.md)**  
Pricing payload fields that ServiceNow Quote Experience sends to the pricing service, with the ServiceNow Quote Experience field each one maps to. Use this reference to check header, line item, and entity metadata values in the payload.
-   **[Pricing response field mapping](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/r_pricing_response_field_mapping.md)**  
Pricing response fields that the pricing service returns to ServiceNow Quote Experience, with the ServiceNow Quote Experience field each one maps to. Use this reference to check header totals, line item prices, and settings in the response.
