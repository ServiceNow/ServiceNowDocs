# Create a deal registration task

Create a task linked to a deal registration to organize work and assign actions to team members.

## Before you begin

The deal must be in an active state \(**Submitted**, **Under Review**, **Pending Approval**, or **Approved**\). You must have permission to create tasks on the deal based on your role and the deal's visibility rules.

Tasks can be assigned to any internal ServiceNow user to delegate deal-related work.

Role required: admin.

## Procedure

1.  Open the deal registration record you want to create a task for.

2.  Navigate to the **Deal Registration Tasks** related list on the deal form.

3.  Select **New** or **Create** to open the task creation form.

    A new deal registration task form opens in a dialog or new form view depending on your system configuration.

4.  In the **Deal Registration** field, confirm that the deal is pre-filled correctly.

5.  In the **Short Description** field, enter a brief, specific summary of the work required.

6.  In the **Assigned To** field, select the user responsible for completing the task.

    You can assign the task to any internal ServiceNow user, including deal agents, relationship managers, account managers, operations staff, finance team members, or anyone otherwise involved in deal work.

    The Fulfiller role is automatically granted by the system, enabling the selected user to work on the task even without deal access.

7.  Set the **State** field to reflect the current task status.

8.  Set a **Due Date** to specify when the task must be completed.

9.  Add initial guidance or context in the **Work Notes** section.

10. Select **Submit** or **Save** to create the task.

    The task is now linked to the deal and assigned to the selected user. The assigned user receives a notification about their new task assignment.


## Result

The deal registration task is created and added to the deal's **Deal Registration Tasks** related list. The task appears in the assigned user's work items in their workspace and the user receives notification of the assignment.

## What to do next

Monitor the task status from the deal record or from the standalone task list view. Update the task status as work progresses.
