# Account details form

Use the Account Details form to create or review account information for customers and partners.

<table id="table_qrh_qrq_4nb"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Name

</td><td>

Name of the enterprise or customer.

</td></tr><tr><td>

Number

</td><td>

Unique system-assigned account number, starting with a prefix ACCT.

</td></tr><tr><td>

Primary Contact

</td><td>

Name of the primary contact person for the account.

</td></tr><tr><td>

Parent Account

</td><td>

Name of the parent account, if any, for this account. -   For example, if the account is a national branch of a multinational corporation, the parent account is the multinational corporation account.
-   If there isn't a parent account, leave this field empty.

</td></tr><tr><td>

Registration Code

</td><td>

Registration code, if any, assigned to the account.

</td></tr><tr><td>

Customer

</td><td>

Option that designates if this account is for a customer.

</td></tr><tr><td>

Partner

</td><td>

Option that designates if this account is for a business partner.

</td></tr><tr><td>

Website

</td><td>

URL of the website for this account, if any.

</td></tr><tr><td>

Phone

</td><td>

Primary phone number for the account.

</td></tr><tr><td>

Street

</td><td>

Street address for the account.

</td></tr><tr><td>

City

</td><td>

Name of the city for the account.

</td></tr><tr><td>

State / Province

</td><td>

</td></tr><tr><td>

Zip / Postal code

</td></tr><tr><td>

Country

</td><td>

</td></tr><tr><td>

Notes

</td><td>

Free-form note text for the account.

</td></tr><tr><td>

Industry

</td><td>

Legal entity name

Registered business name.

</td></tr><tr><td>

Business structure

Assumed name

Date of Incorporation

Trademark

Tax ID

Email

Sales Owner
