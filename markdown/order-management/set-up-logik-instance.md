# Request a CPQ tenant

Submit a support ticket on Now Support to request a CPQ instance for use with your ServiceNow instance.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to [Now Support](https://support.servicenow.com/now?id=ns_get_help).

2.  Select **Create a case**.

3.  In the ServiceNow Otto panel, select the link to open the case form.

4.  Select **Service request**.

5.  Enter `Request a new CPQ instance` and select **Next**.

6.  Select your instance and select **Next**.

    **Note:** Contact the primary customer administrator \(PCA\) if your instance is not listed.

7.  Select **Continue**.

8.  Enter the **Client ID** and **Client secret** and the public certificate details.

9.  Select **Continue**.

10. Review the summary and select **Confirm and Submit**.


## What to do next

Connect the CPQ instance to your ServiceNow instance. See [Connect your instance with CPQ instance](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/connect-sn-instance-logik.md).
