# Configuring Advanced Approval Management AI

Install and set up the Advanced Approval Management AI application, which enables advanced approval users to manage quote approvals by using an MCP-compatible client such as Claude.

## Configuration overview

1.  [Install Advanced Approval Management AI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/order-management/install-advanced-approval-management-ai.md).
2.  Assign the approval roles to the users who use the MCP tools. For the role each tool needs, see [Components installed with Advanced Approval Management AI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/order-management/components-installed-with-advanced-approval-mgmt-AI.md).
3.  [Connect Sales CRM server to an AI assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/order-management/connect-CRM-server-to-AI-assistant.md).
