# Activate ServiceNow Otto AI Interface

After installing the ServiceNow Otto plugin, activate the chat launcher required to enable ServiceNow Otto AI conversational interface on Sales CRM Mobile application.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **Conversational Interfaces** &gt; **Assistant Designer**.

    The Assistant Designer page appears.

2.  Select **Edit** on ServiceNow Otto for Virtual Agent \(default\) assistant.

    The ServiceNow Otto for Virtual Agent \(default\) assistant is displayed.

3.  Navigate to **Settings** &gt; **Display experience** &gt; **Mobile apps**.

    The Mobile apps section appears.

4.  In the Chat launcher function section, select **Add agent chat** from the **Add Chat launcher function** list.

    The Add chat experience dialog box appears.

5.  In the Add chat experience dialog box, select **Premium chat**.

    **Note:** **Premium chat** enables you to have the best experience with ServiceNow Otto AI interface.

6.  Select **Add**.

    The Agent Chat function is added.

7.  Select **Save**.

8.  On the Assistant Designer page, select the **More Actions** icon for ServiceNow Otto for Virtual Agent \(default\).

9.  Select **Activate**.


## Result

The ServiceNow Otto AI interface on Sales CRM Mobile is available for users.
