# Enable offline mode on Sales CRM Mobile

Enable offline mode on Sales CRM Mobile to access your sales records when you don't have an internet connection.

## Before you begin

Role required: **sales\_mobile\_user**

## About this task

Download the Sales CRM Mobile data to the application cache while you have an internet connection so that the app has data available when you lose connectivity. For more information, see [Offline mode](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/mobile/mobile-offline-mode.md).

## Procedure

1.  On the Sales CRM Mobile, navigate to **Settings** &gt; **Offline**.

2.  Select **Download Cache**.

    The application downloads the cached data.

3.  Turn on the **Offline mode** toggle.

    You can now use the Sales CRM Mobile application in the offline mode with the cached data of the current records.

    **Note:** ServiceNow Otto AI interface and editing records are not available in offline mode.
