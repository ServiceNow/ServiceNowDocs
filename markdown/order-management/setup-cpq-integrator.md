# Setting up ServiceNow CPQ

Set up ServiceNow CPQ Configurator and Quote Experience to define products, quotes, pricing rules, complex product bundles, and enable other capabilities.

The Configurator streamlines the quoting process by automating configuration logic, reducing manual quote creation errors, and ensuring consistent application of business rules across all quotes.

The Quote Experience is the quoting solution that uses the Configurator. It provides a configurable workspace where sales teams create and manage quotes, add products, apply pricing, route quotes for approval, and track each quote through its lifecycle. Because the Configurator supplies the product and rule logic, the quotes that teams build in the Quote Experience stay consistent with the catalog you set up.

You can set up the Configurator and Quote Experience using one of the following approaches.

-   Use the guided setup to configure the Configurator and Quote Experience step by step. The guided setup walks you through each required setting in a structured sequence, providing context and validation at each stage. For more information, see [Set up ServiceNow CPQ Configurator and ServiceNow Quote Experience using guided setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/guided-setup.md).
-   Configure each setting individually without guided assistance. This approach provides full flexibility and control over configuration order and settings. For more information, see [Set up ServiceNow CPQ Configurator without guided setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/order-management/configuring-servicenow-cpq.md).
