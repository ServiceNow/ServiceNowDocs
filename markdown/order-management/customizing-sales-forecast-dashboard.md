# Customizing Sales Forecast dashboard

Customize the columns that are displayed on your Sales Forecast dashboard and set your preferred column order to match your workflow.

## Before you begin

Role required: sn\_sales\_forecast.forecast\_viewer

## Procedure

1.  Navigate to **Workspaces** &gt; **CSM/FSM Configurable Workspace**.

2.  Select the List icon \[Omitted image "list-outline-24.svg"\] Alt text:.

3.  Select the **Sales Forecast** view.

4.  Select the Customize your list icon \[Omitted image "gear\_icon.png"\] Alt text: on the dashboard toolbar.

    The Customize your list dialog box opens. The dialog box has two sections. Top-level section includes column names, such as Quota, Won, Gap, Commit, Strong Upside, Upside, and Pipeline. The bottom section contains sub-columns that apply within every forecast category, such as Final Forecast, Hierarchy Forecast, Base Forecast, and Last Submitted Forecast.

    \[Omitted image "customize-your-list.png"\] Alt text: Customize your list dialog box

5.  In the top section, under Available columns, select the option for each column that you want to display and clear the check box for any column that you want to hide.

6.  Under Selected columns, drag and drop the columns to set the order in which they appear on the dashboard.

7.  In the bottom section, select the sub-column options that you want to display within every forecast category.

    A sub-column that you select is added under every adjustable forecast category on the dashboard. Clearing a sub-column removes it from all the adjustable categories. Final Forecast and Hierarchy Forecast are selected by default. Final Forecast cannot be cleared.

8.  Drag and drop the selected sub-columns to set the order in which they appear within each category.

9.  To reset all selections and display the default dashboard view, select **Restore to Defaults**.

10. Select **Apply** to save your changes.

    The dashboard displays your selected columns in the order that you set and saves it for your forecast model.
