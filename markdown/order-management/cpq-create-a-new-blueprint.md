# Create a blueprint

Create a blueprint to define the structure, behavior, and configuration experience for your product model.

## Before you begin

Role required: Admin

## Procedure

1.  In the CPQ Admin navigation pane, click **Blueprints**.\[Omitted image "cpq-blueprints.png"\] Alt text: Blueprints in menu

2.  On the Blueprints page, click **New**.\[Omitted image "cpq-blueprints-new-button.png"\] Alt text: New blueprint
