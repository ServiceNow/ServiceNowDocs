# Transaction header-level system fields for subscriptions

Transaction header-level system fields are system-provided header fields in Quote Experience, some of which support subscription processing for amendments and renewals.

## Header-level system fields

Transaction header-level system fields are available through the Quote Experience administration interface. Navigate to **All** &gt; **CPQ Administration** &gt; **Transaction** &gt; **Associated Fields** and select **Transaction**.

The following table summarizes the transaction-level header system fields that are relevant for subscriptions in Quote Experience.

|Variable name|Description|
|-------------|-----------|
|`txn.startDate`|Start date for the transaction.|
|`txn.endDate`|End date for the transaction.|
|`txn.term`|Term in months from contract.|
|`txn.transactionType`|Type of transaction: New, amendment, or renewal.|
|`txn.transactionAction`|Choice field with options for add or change. Determines transaction type.|
|`txn.isAutoGeneratedForRenewal`|Indication of whether the transaction was automatically generated from a renewal, based on the expiry of the original contract.|
|`txn.isAutoRenewContract`|Indication of whether the resulting contract from the transaction should trigger automatic renewal workflows.|
|`txn.pricing.adjustment.renewalBasis`|Starting renewal price from which to apply adjustments. Valid values are Contracted Price or List Price.|
|`txn.pricing.adjustment.renewalType`|Type of adjustment for the renewal with options of Markup % and Markdown %. If the renewal adjustment basis is List Price, this field is read-only and empty.|
|`txn.pricing.adjustment.renewalValue`|Amount of adjustment to apply to the renewal depending on whether the Renewal Adjustment Type is Markup or Markdown.|
|`txn.source.quote`|Reference to the quote from which this was consolidated.|
|`txn.source.contract`|Reference to the contract used in the amendment or renewal workflow for this transaction.|

For more information about transaction-level header system fields, see [Transaction-level system fields](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/order-management/quote-tm-header-level-system-fields.md).
