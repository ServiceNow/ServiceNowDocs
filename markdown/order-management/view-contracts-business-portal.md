# View contracts on the Business Portal

Customers can view contracts associated with their accounts on the Business Portal, including contract details and contract line items.

## Before you begin

Role required: sn\_customerservice.customer

## Procedure

1.  Log in to the Business Portal.

2.  Select **My hub** &gt; **Manage contracts**.

    A list of contracts available for all your accounts is displayed.

3.  To view contract details, select a contract from the list.

    The contract details page opens and displays the following information:

    -   List of contract line items
    -   Contract number
    -   Contract administrator
    -   Total contract value
    -   Start and end dates
    -   Account information
    -   Location
4.  Select any contract line item to view the details.

    The contract line items table displays the following information for each line item:

    -   Child contract lines of that line item
    -   Line item number
    -   Contract number
    -   Start and end dates
    -   Term \(in months\)
    -   Pricing and quantity details
    -   Product offer
5.  To view related information, select any of the available tabs.

    -   Select the **Child contract lines** tab to view child contract line details.
    -   Select the **Products covered** tab to view products and installed base items covered.
    -   Select the **Renewal history** tab to view renewal information.
    -   Select the **Consolidation history** tab to view consolidation information.
    -   Select the **Characteristics** tab to view contract line characteristics.
    -   Select the **Usage** tab to view usage information.
    -   Select the **Pricing** tab to view pricing details.
