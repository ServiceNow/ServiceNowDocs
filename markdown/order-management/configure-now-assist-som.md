# Configure ServiceNow Otto for Sales Automation

If you have the admin role, you can configure the ServiceNow Otto for Sales Automation application so that agents can use the generative AI capabilities in the CSM Configurable Workspace.

## Before you begin

Use the AI Admin Hub console to configure ServiceNow Otto for Sales Automation. This console contains everything that you need to install the plugins and configure the generative AI skills. For additional information, see [Overview tab in AI Admin Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/intelligent-experiences/configuring-now-assist.md).

Role required: admin

## Procedure

1.  Log in to the ServiceNow instance.

2.  Install the ServiceNow Otto for Sales Automation plugin \(sn\_som\_gen\_ai\).

    For information about the installation process, see [Install plugins for ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/intelligent-experiences/install-now-assist-feature-plugins.md).
