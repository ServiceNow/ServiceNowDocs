# Order case management using Business Portal

Business Portal enables customers to create and view order cases for orders or order line items. They can request changes to unfulfilled orders from the ServiceNow Otto Virtual Agent panel using chat and voice channels.

-   **[Request updates for one or more orders](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/create-order-case-for-multiple-orders.md)**  
Request changes to the expected order fulfillment date and shipping location for one or more orders or to draw attention to an issue by creating an order case from the Business Portal.
-   **[Request updates for items in a single order](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/create-order-case-specific-order-lines.md)**  
Request changes for the expected order fulfillment date, shipping location, or quantity for specific items in an order by creating an order case from the Business Portal.
-   **[View order case details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/view-order-case.md)**  
View the list of order cases and their state from the Business Portal.
-   **[Request order changes using ServiceNow Otto Virtual Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/request-order-changes-now-assist.md)**  
Request an expedited delivery, a quantity change, or a shipping location change for your order in natural language using the ServiceNow Otto Virtual Agent on the Business Portal.
-   **[Request order changes via calls](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/now-assist-order-mgmt-voice-aiagent.md)**  
Use the AI voice agents to expedite delivery, change quantity, or change the shipping location for an order by using voice calls. The voice agent captures your request and creates an order case for an order case agent to resolve.
-   **[View customer context for an order exception chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/order-management/view-interactions-on-order-case.md)**  
View the customer's account and contact details on the interaction record and the AI-generated chat summary in the Active Chat panel when the order exception AI agent hands off a chat to a live agent in the CSM/FSM Configurable Workspace.
