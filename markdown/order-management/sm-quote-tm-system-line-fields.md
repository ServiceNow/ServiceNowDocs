# Transaction line-level system fields for subscriptions

Transaction line-level system fields are system-provided line fields in Quote Experience, some of which support subscription processing for amendments and renewals.

## Line-level system fields

Transaction line-level system fields are available through the Quote Experience administration interface. Navigate to **All** &gt; **CPQ Administration** &gt; **Transaction** &gt; **Associated Fields** and select **Transaction Line**.

The following table summarizes the transaction line-level system fields that are relevant for subscriptions in Quote Experience.

|Variable name|Description|
|-------------|-----------|
|`txn.line.startDate`|Start date of the line.|
|`txn.line.endDate`|End date of the line.|
|`txn.line.term`|Difference in months between the start date and end date for recurring products. Automatically calculated using the contract start date and contract end date.|
|`txn.line.lineType`|Description of the changes made to the transaction line. Valid values include New, Renew, Upsell, Amend, Cancel, or No Change.|
|`txn.line.lineAction`|Action applied to the Sold Product. Valid values include Add, Change, Disconnect, or No Change.|
|`txn.line.quantity`|Quantity of the line.|
|`txn.line.isAutoGeneratedForRenewal`|Indication of whether this line was automatically generated from a renewal workflow.|
|`txn.line.isAutoRenewContract`|Indication of whether the contract line is eligible for automatic renewal, based on its expiration date.|
|`txn.line.pricing.adjustment.renewalBasis`|Starting renewal price to which adjustments are applied. Overrides the header-level setting if specified.|
|`txn.line.pricing.adjustment.renewalType`|Indication of whether the adjustment value is a percentage or absolute amount when calculating a renewal price.|
|`txn.line.pricing.adjustment.renewalValue`|Percentage amount to adjust the renewal as indicated by renewal adjustment type when calculating a renewal price.|
|`txn.line.pricing.delta.priceTreatment`|Pricing treatment applied to a transaction line based on line type, line action, and whether the product offering characteristics have changed.|
|`txn.line.source.soldProduct`|Reference to the underlying Sold Product record from which this line was created.|
|`txn.line.source.splitFromSoldProduct`|Reference to the underlying Sold Product record when a line is split due to an amendment. The Sold Product record is from the Sold Product field of the original line. Used for delta pricing calculations.|
|`txn.line.source.entitlement`|Reference to the entitlement from which this line was renewed.|
|`txn.line.source.contract`|Reference to the existing contract from which this line was derived.|
|`txn.line.source.contract.line`|Reference to the contract line from which this line was renewed.|
|`txn.line.source.consolidation.lines`|List of contract lines from which this line was consolidated.|

For more information about transaction line-level system fields, see [Transaction line-level system fields](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/order-management/quote-tm-line-level-system-fields.md).
