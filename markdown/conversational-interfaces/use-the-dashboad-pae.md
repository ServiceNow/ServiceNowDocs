# \(Legacy\) Set the date range of the data

Set the date range using the date picker on the Overview tab to view the data visualizations for the specified date range. The date range set on this tab applies to all the other tabs on the dashboard.

## Before you begin

Role required: Chat Analytics Viewer \(chat\_analytics\_viewer\)

## About this task

Set the date range for the visualizations using the date picker. You can either select from the standard date ranges available or use the custom range option to select start and end dates.

## Procedure

1.  Navigate to **All** &gt; **Conversational Interfaces** &gt; **Analytics**.

2.  Use the date picker on the Overview tab to set the date range.

    1.  Select the date picker. \[Omitted image "dashboard-calendar-icon.png"\] Alt text: Date picker.

    2.  Select the start date of the date range.

    3.  Select the end date of the date range.

        The dashboard highlights the selected date range.

        \[Omitted image "dashboard-calendar-start-drag-pae.png"\] Alt text: Calendar showing highlighted start-to-end dates.

    4.  Select **Apply**.

    The data displayed on the dashboard adjusts according to the new date range.
