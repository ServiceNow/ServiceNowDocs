# Install Conversational Integration with Google Chat

Activate the necessary plugins and ServiceNow Otto for Virtual Agent for Google Chat

Activate the Glide Virtual Agent \[com.glide.cs.chatbot\] plugin and the Conversational Integration with Google Chat \[sn\_va\_google-chat\] plugin.
-   **[Activate ServiceNow Otto for Virtual Agent for Google Chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/conversational-interfaces/activate-na-va-google-chat.md)**  
Add ServiceNow Otto for Virtual Agent to your Google Chat bot.
