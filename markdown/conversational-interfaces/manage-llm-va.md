# Manage LLM virtual agents on the Assistants screen

Create, edit, and turn on/off LLM virtual agents from the Assistants screen.

## Before you begin

Role required: virtual\_agent\_admin

## Procedure

1.  Navigate to **All** &gt; **Conversational Interfaces** &gt; **Assistant Designer**.

2.  The Assistants screen displays existing LLM virtual agents.

3.  To create a new virtual agent, select **Create new** to display the ServiceNow Otto for Virtual Agent Overview screen.

    Follow the screens to create a new virtual agent. For more information, see [Configuring assistants overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/configure-now-assist-va.md).

4.  To edit an existing virtual agent, select the virtual agent's name or select the three vertical dots \[Omitted image "three-dots-icon.png"\] Alt text: More actions icon. at the end of any field and select **Edit**.

    If Virtual Agent is completely configured, ServiceNow Otto for Virtual Agent Review screen displays. For more information, see [Configuring assistants overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/configure-now-assist-va.md). If Virtual Agent is not completely configured, the last unfinished step in the Virtual Agent guided setup displays. For more information, see [Installing Conversational Interfaces components](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/ci-home-install-components.md).

5.  To turn an existing virtual agent on or off, select the three vertical dots \[Omitted image "three-dots-icon.png"\] Alt text: More actions icon. at the end of any field and select **Activate** or **Deactivate**.\[Omitted image "three-dots-edit.png"\] Alt text: Assistants screen in Now Assist.
