# Using Virtual Agent

Virtual Agent is a self-service messaging platform that enables requesters to resolve common issues independently through a conversational chat interface, and transfers conversations to a live agent when human attention is required.

## Overview of using Virtual Agent

Virtual Agent is a self-service messaging platform that helps requesters resolve issues without contacting a live agent. Prebuilt conversation topics guide requesters through routine IT, HR, customer service, and workplace tasks, and requesters can also reach Virtual Agent through the same channels they already use, such as web portals, the Now Mobile app, and messaging apps such as Slack and Microsoft Teams.

Generative AI skills from ServiceNow® Otto for Virtual Agent let requesters ask questions and get things done using plain language instead of navigating a fixed menu of topics, and reduce how often a conversation needs to be escalated. When a conversation does need more than Virtual Agent can provide on its own, it can be transferred to a live agent without losing the context the requester already provided.
