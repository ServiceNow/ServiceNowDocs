# Chat experiences

ServiceNow Otto for Virtual Agent offers three different chat experiences that vary in capability, AI integration, and deployment model. Consider the experience that matches your organization's licensing, infrastructure, and user engagement requirements.

Each chat experience builds on the previous tier, adding AI-powered features and configuration options. All three experiences are configured in [Assistant Designer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/conversational-interfaces/virtual-agent/assistant-designer.md) as you select a display experience, such as a portal, channel, or mobile app.

|Feature|Standard|Enhanced|Premium|
|-------|--------|--------|-------|
|Conversational topic flows|Supported|Supported|Supported|
|Generative AI responses|Not supported|Supported|Supported|
|Knowledge search integration|Basic|AI-powered|AI-powered|
|Dynamic search window|Not supported|Supported|Supported|
|Integrated third-party messaging|Not supported|Not supported|Supported|
|Chat history panel|Not supported|Supported|Supported|
|Post-chat survey|Supported|Supported|Supported|

For more information about each chat experience, see:

-   [Standard chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/conversational-interfaces/virtual-agent/nava-standard-chat.md)
-   [Enhanced chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/conversational-interfaces/virtual-agent/nava-enhanced-chat.md)
-   [Premium chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/conversational-interfaces/virtual-agent/nava-integrated-chat.md)
