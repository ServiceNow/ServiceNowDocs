# Assistant Designer capabilities

Add in-depth functions to Virtual Agent conversations with Assistant Designer capabilities. These controls provide special filters and abilities to your Virtual Agent topics.

The ServiceNow platform offers various products \(such as Dynamic Translation\) that can be used in Assistant Designer along with other areas of the ServiceNow AI Platform. For Virtual Agent, these capabilities function as no-code topic blocks, performing complex functions in a conversation.

Unlike the User Inputs, Bot Responses, and Utilities, capabilities are features that are part of the ServiceNow AI Platform, which have been mapped to nodes in Assistant Designer. The nodes are available for use in the Conversation Builder when you enable Generative AI Controller.

## Enable capabilities

To enable capabilities in Assistant Designer, see [Generative AI Controller](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/generative-ai-controller.md).
