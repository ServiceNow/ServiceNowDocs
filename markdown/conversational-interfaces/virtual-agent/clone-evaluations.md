# Clone an existing evaluation

To reuse the configuration of a completed evaluation, you can clone it instead of setting up a new evaluation from scratch.

## Before you begin

Role required: virtual\_agent\_admin or admin

## Procedure

1.  From the **Testing** tab in Assistant Designer, open the summary of a completed evaluation.

2.  Select **Clone**.

    \[Omitted image "evaluations-ad-10.png"\] Alt text: Clone option on the Testing tab.

3.  Review the pre-populated configuration.

    Update the name, description, or any other settings as needed.

    **Note:** Cloned evaluations carry the table mappings and any data set filter from the source evaluation.

4.  Select **Start evaluation** to run the cloned evaluation.
