# Configure a Zoom webhook for Zoom extension for Omnichannel Callback

Configure a Zoom webhook in ServiceNow to notify the Zoom extension for Omnichannel Callback app when a callback meeting transcript is completed in Zoom.

## Before you begin

The verification token from the Notify Zoom connector configuration in Zoom must be available.

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **Zoom Spoke** &gt; **Zoom Webhook Registries**.

2.  Select **Zoom Callback Transcript completed** from the list.

3.  In the **Token** field, paste the verification token that validates event notifications.

4.  Select **Update**.
