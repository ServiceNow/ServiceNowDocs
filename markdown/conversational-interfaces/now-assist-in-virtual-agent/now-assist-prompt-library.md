# Prompt library

The prompt library provides a centralized place to browse, save, and reuse prompt templates from within chats. Instead of typing frequently-used prompts from scratch, you can select from promoted templates or save your own custom prompts for quick access.

With the prompt library, you can do the following:

-   Save time - Select a prompt template and customize it instead of creating it from scratch.
-   Maintain consistency - Use standardized templates across your conversations.
-   Discover new prompts - Browse recommendations tailored to your workflow.
-   Build your own library - Save frequently-used messages as custom prompts for quick reuse.

An administrator must enable the prompt library before you can use it, see [Edit a chat assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/conversational-interfaces/now-assist-in-virtual-agent/edit-assistant.md) for information on enabling it. When the prompt library is disabled, the greeting screen shows the All Topics menu instead.

Access the prompt library by selecting **View prompt library** from the greeting screen or from the + icon on the omnibar.

The prompt library organizes templates across these tabs:

-   Recommended - Promoted topics for the assistant.
-   Favorites - Prompts and topics you've marked as favorites.
-   Recently Used - Prompts and topics you used recently.
-   Custom Prompts - Prompts you created \(these prompts are private and only visible to you\).
-   Prompts - All public prompts. Use the drop-down lists to filter the prompts.
-   Topics - All promoted topics for your assistant.

## Using prompts and topics

Select a prompt or topic card to add it to your chat input. When you select a prompt, the prompt library closes and the prompt text appears in the input field. After the text appears in the input field, you can fill in any placeholder information or make edits before submitting. When you select a topic, you will be directly taken to the chat and enter the topic execution flow. To save a prompt or topic for quick access in your favorites, select the heart icon on the card. Select the heart icon again to remove it from your favorites.

To create a new custom private prompt, send a prompt to a conversation and select the bookmark icon. In the dialog box, enter a title and description, edit the prompt, then select **Save prompt**. To delete a custom prompt, navigate to the Custom Prompts tab, select the more actions icon in the prompt card, then select **Delete prompt**.
