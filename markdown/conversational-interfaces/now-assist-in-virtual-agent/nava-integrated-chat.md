# Premium chat

ServiceNow® Otto for Virtual Agent premium chat is a contextual chat experience that adapts to where you are and what you're doing across the platform.

## Accessing ServiceNow Otto for Virtual Agent premium chat

You can enter the conversational search experience in either of two ways:

-   The search omnibar
-   The ServiceNow Otto chat widget button

\[Omitted image "nava-portal-screen.png"\] Alt text: Premium chat entry points, including the search omnibar and the ServiceNow Otto icon.

You can either enter a query or prompt or select one of the recommended auto-suggestions that appear following the chat input box. Recommended auto-suggestions may include:

-   Suggested queries
-   Related workflows and actions
-   Direct links to relevant content such as knowledge base articles

**Note:** For more information about how ServiceNow Otto for Virtual Agent and ServiceNow Otto for AI Search combine to include recommended prompts, see [Auto-complete suggestion types included with ServiceNow Otto for AI Search](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/platform-administration/auto-complete-suggestion-types-na-ais.md).

## Search omnibar and chat widget entry points

Both the search omnibar and chat widget responses assist you, but the conversational experiences differ slightly. For example, the catalog item form-opening behavior depends on which conversational experience you launched the catalog item from.

-   **Search omnibar**

    After you enter a prompt through the portal's search omnibar in premium chat, you're redirected to the portal's conversational experience. The chat displays Genius Results as a synthesized response generated by ServiceNow Otto. This response includes inline citations at the end of each sentence. Depending on context, you can select citations, action buttons, or **Sources and more** to open a side panel showing the sources used.

    Selecting **Sources and more** opens a side panel that displays the sources used in the chat response. If you start a conversation from the search omnibar and you open a catalog item from the **Sources and more** panel, the catalog form opens in the interactive view.

-   **Chat widget**

    After you select the chat widget button on the portal, the floating chat window opens and replaces the chat button. A greeting message appears, and a chat is created only after you enter an initial utterance. If you have an active chat ongoing, the current active chat appears instead of a greeting message. You can select a predefined action, topic, or suggested search query. You can also start a new conversation or select **View all**, if applicable. The **View all** option appears only if more than one suggested search query or promoted topic is available.

    Selecting **Sources and more** opens a side panel that displays the sources used in the chat response. If you open a catalog item from the chat widget's **Sources and more** panel, the catalog form opens in a new tab.

After you enter an utterance and a search result is found, a synthesized response may appear. A synthesized response includes a brief summary of the requested information and search results along with Genius Results. For more information about how these search results are found, see [Actions Genius Results](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/platform-administration/now-assist-catalog-ordering-gr.md) and [Knowledge base articles Genius Results](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/platform-administration/now-assist-qna-genius-results.md).

If multiple results are found, you can follow inline citations to either begin an action or learn more. The option for **Sources and more** appears in the feedback panel for internal and external sources. Virtual Agent can return available catalog items that match your request only when the ServiceNow Otto Multi-Turn Catalog Ordering skill is enabled.

**Note:** For full catalog functionality, enable the generative AI experience for catalog item request submissions. For more information, see [Configure ServiceNow Otto in Conversational Catalog Request](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/configure-gen-ai-catalog-item.md).

Whenever only a single search result for topics is found, the synthesized response and options are bypassed by default and you're taken directly into that action's flow. You can also bypass the synthesized response and options by automatically launching catalog items. For more information about automatically launching single search result actions, search for the **sn\_nowassist\_va.synthesized\_autostart\_items** system property in [ServiceNow Otto for Virtual Agent system properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/nava-sys-props.md).

You can create a query from within a ServiceNow Otto conversation using mid-topic discovery. For more information, see [Mid-topic switching during ServiceNow Otto for Virtual Agent conversations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/intent-switching-na-va.md).

If AI Guardian is enabled and your request contains profane content, the Virtual Agent responds with a message prompting you to re-enter an appropriate request without profanity or offensive content.

Responses generated in ServiceNow Otto for Virtual Agent can come from a combination of catalog items, Virtual Agent topics, subflows and actions, knowledge articles, attachments, external content sources, and people citations. Inline citations appear at the end of the relevant synthesized response sentence. The following options may appear as synthesized response inline citations depending on what search results are returned:

-   Catalog
-   Topics, subflows, or actions
-   Q&amp;A Knowledge Base articles
-   External content connections
-   People
-   Extended entities and additional records

**Note:** Sources used also appear in the **Sources and more** panel.

## Viewing and downloading generated files

After ServiceNow Otto generates a file, it appears in a thumbnail card. You can select the download icon to download the generated file or select the file name to open it in the interactive view. Downloaded files use plain Microsoft Office templates with no ServiceNow branding applied.

ServiceNow Otto displays generated files in the interactive view for these formats:

-   Microsoft Word \(.doc, .docx\)
-   Microsoft PowerPoint \(.ppt, .pptx\)
-   Microsoft Excel \(.xls, .xlsx\)
-   PDF

For unsupported file types, either a fallback file reader opens the file or an error message appears. You can navigate between file previews and other interactive view content—knowledge articles, catalog items, and more—without losing your conversation context.

## Chatting with a live agent in Virtual Agent

You can chat with a live agent if you need more support. Use any of the following methods to begin a live agent chat:

-   Select the **Support** &gt; **Request a live chat** option found in More options \(\[Omitted image "ellipsis-vertical-outline-24.svg"\] Alt text:\).
-   Enter a request such as `Chat with live agent` into the chat.
-   Select the **Request a live chat** fallback option.

After an agent accepts your chat, the agent's name and avatar appear at the top of the chat in a banner. Only one live agent chat at a time is permitted. To exit the live chat, select **End live chat**. The chat history then moves to the Closed chats section.

## Fallback options

**Note:** For more information about where and how to enable fallback options, see [Manage an assistant chat experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/manage-assistant-chat-experience.md).

A fallback state can occur whenever search results are unavailable. Scenarios where search results are unavailable include cases when the Virtual Agent can't interpret the query, complaint small talk is detected, or an error occurs. When search results are unavailable, one or more fallback options may appear. These fallback options include:

-   **Request a live chat**: Triggers live agent mode and routes you to a human support representative.
-   **Search the web**: Triggers web search mode and uses the internet to search for the results.

    **Note:** When you enter web search mode through the **Search the web** fallback option, only the last query in the conversation is used.

-   **Create a generic ticket**: Creates a record.
-   **Custom fallback option**: Presents a fallback Virtual Agent topic.

Select a fallback option to launch that mode or action.
