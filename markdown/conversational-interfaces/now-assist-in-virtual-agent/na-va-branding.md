# Set up your ServiceNow Otto for Virtual Agent branding

Create different ServiceNow Otto for Virtual Agent branding configurations for the various organizations that use your instance. These configurations only apply to chat widget branding on portals.

## Before you begin

For more information about ServiceNow Otto for Virtual Agent, see [ServiceNow Otto for Virtual Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/now-assist-in-va-landing.md) and [Configuring assistants overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/now-assist-in-virtual-agent/configure-now-assist-va.md).

Role required: virtual\_agent\_admin or admin

## About this task

Create different chat widget branding configurations.

## Procedure

1.  Navigate to **All** &gt; **Conversational Interfaces** &gt; **Settings**.

2.  In the Display Options section, select **View All** next to **Branding**.

3.  Select **New** to create a branding configuration or select **ServiceNow Otto for Virtual Agent** to update it.

4.  To edit the settings, see [Set up your Virtual Agent bot's branding](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/conversational-interfaces/ac-configure-chat-branding.md).
