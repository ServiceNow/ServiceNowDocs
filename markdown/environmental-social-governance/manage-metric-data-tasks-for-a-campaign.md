# Manage metric data tasks for a campaign

Approve, reject, or review metric data tasks for a campaign individually, or together as a bulk action if bulk submission is enabled for the campaign.

## Before you begin

Role required: sn\_grc\_metric.manager, or the user assigned to approve the task or a member of its assignment group.

## About this task

If bulk actions are enabled for the campaign, all tasks in a campaign cycle must be approved or rejected together; individual approval isn't available for that cycle. For more information about enabling bulk actions, see [Enable campaigns](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/environmental-social-governance/enable-campaigns.md).

## Procedure

1.  Navigate to **All** &gt; **Operational Sustainability Workspace**.

2.  Select the **Metric tasks** icon.

3.  Select the **Approvals** tab.

4.  Select the check box for each task you want to act on.

    **Note:** If bulk actions are enabled, you must select every task in the campaign cycle before approving or rejecting. If any task in the cycle is left unselected, an error states that tasks within a campaign can't be approved \(or rejected\) individually and that all tasks must be approved \(or rejected\) together.

5.  Select **Approve** or **Reject**.


## Result

Selected tasks move to **Closed** if approved, or back to **In Progress** if rejected. If the task's data is estimated, it moves to **Estimated** instead of **Closed**.
