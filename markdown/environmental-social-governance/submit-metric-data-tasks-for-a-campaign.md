# Submit metric data tasks for a campaign

Submit metric data tasks for a campaign individually, or together as a bulk action if bulk submission is enabled for the campaign.

## Before you begin

Role required: sn\_grc\_metric.manager, or the user assigned to the task or a member of its assignment group.

## About this task

Use the filter on the **Metric data entry** tab to select a campaign or campaign cycle before selecting tasks. If bulk submission is enabled for the campaign, all tasks in a campaign cycle must be submitted together; individual submission isn't available for that cycle. For more information about enabling bulk submission, see [Enable campaigns](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/environmental-social-governance/enable-campaigns.md).

## Procedure

1.  Navigate to **All** &gt; **Operational Sustainability Workspace**.

2.  Select the **Metric tasks** icon.

3.  On the **Metric data entry** tab, select the check box for each task you want to submit, or select **Select all** to select every task in the list.

    **Note:** If bulk submission is enabled, you must select every task in the campaign cycle before submitting. If any task in the cycle is left unselected, an error states that tasks within a campaign can't be submitted individually and that all tasks must be submitted together.

4.  Select **Submit**.


## Result

All selected tasks move to **Awaiting Approval**. When a task belongs to a campaign cycle and bulk actions are enabled, its individual approval list is hidden; approval is handled through this bulk view instead.
