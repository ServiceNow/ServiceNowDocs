# Bulk-enrich assets from the Data Catalog

Select specific assets directly from the Data Catalog page and submit them for bulk enrichment by AI agents.

## Before you begin

Role required: df\_data\_steward

## Procedure

1.  Navigate to **All** &gt; **Workflow Data Fabric** &gt; **Workflow Data Fabric Home**.

2.  In the left sidebar, select the Data Catalog icon.

3.  Open the three-dot menu and select **Bulk Enrich Assets**.

4.  Select data assets to bulk enrich.

    1.  In the asset-selection view, search, filter, or browse to narrow down the assets to enrich.

    2.  Use the **Add all** button to select all data assets, or select **Add** next to each asset to select them individually.

    \[Omitted image "dc-bulk-enrich-ai-select-assets.png"\] Alt text: Asset selection view for bulk enrichment

5.  Confirm the selection.


## Result

Workflow Data Fabric creates the job and shows a selection-completion screen with a job ID, plus links to monitor progress and open the review workspace. See [Monitor an enrichment job](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/integrate-applications/monitor-enrichment-job-dc.md).
