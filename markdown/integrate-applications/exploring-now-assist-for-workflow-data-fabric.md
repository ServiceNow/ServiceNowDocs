# Exploring ServiceNow Otto for Workflow Data Fabric \(WDF\)

With the ServiceNow Otto for Workflow Data Fabric \(WDF\) application, you can obtain information about setting up integrations.

## ServiceNow Otto for WDF overview

Use ServiceNow Otto for WDF to discover data fabric tables, connectors, and collectors, and request guidance on how to set up integrations.

ServiceNow Otto for WDF includes the oneExtend LLM skill that enables you to find information about collectors, connectors, data fabric tables, data products, and more.
