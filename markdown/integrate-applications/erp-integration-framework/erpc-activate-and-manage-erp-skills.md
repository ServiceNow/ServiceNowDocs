# View and deactivate ERP skills

View the ERP data discovery and ERP data query skills in Otto admin, and deactivate a skill if necessary.

## Before you begin

Role required: admin

The ServiceNow Otto for Zero Copy Connector plugin is installed. For more information, see [Install the ServiceNow Otto for Zero Copy Connector plugin](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-install-the-erp-ai-plugin.md).

## About this task

The ServiceNow Otto for Zero Copy Connector plugin includes the following skills:

-   [ERP data discovery](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-query-sap-data-with-erp-data-discovery.md)
-   [ERP data query](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-identify-sap-objects-with-erp-data-query.md)

**Important:** Some generative AI skills, AI agents, and agentic workflows are turned on by default. For more information, see [AI agents, skills, and agentic workflows on by default](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/now-assist-skills-on-by-default.md).

For more information about managing skills, see [Overview tab in AI Admin Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/configuring-now-assist.md).

## Procedure

1.  Navigate to **All** &gt; **Otto admin** &gt; **Skills** and select **Other**.

    The ERP data discovery and ERP data query skills appear in the list.

2.  To deactivate a skill, select the options icon next to the **Last modified** column and select **Deactivate skill**.
