# Authentication methods for Oracle REST connections

REST connections to Oracle ERP systems in Zero Copy Connector for ERP support basic authentication.

Basic authentication is supported. HTTP must be used. User name and password are set with each request. For more information, see [Connect to SAP with RFC or BAPI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/erp-integration-framework/set-up-erp-integration-connection.md).

For background on REST connectivity to Oracle ERP systems, see [REST API support for Oracle E-Business Suite](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/erp-integration-framework/erp-canvas-oracle-rest-support.md).
