# Connecting to SAP

Connect Zero Copy Connector for ERP \(Enterprise Resource Planning\) to an SAP system using a variety of methods.

Zero Copy Connector for ERP supports the following SAP systems:

-   SAP ECC
-   SAP S/4HANA
-   SAP S/4HANA Cloud
