# Connect to SAP

Connect Zero Copy Connector for ERP \(Enterprise Resource Planning\) to an SAP system using a variety of methods.

The following SAP systems are supported:

-   SAP ECC
-   SAP S/4HANA
-   SAP S/4HANA Cloud
