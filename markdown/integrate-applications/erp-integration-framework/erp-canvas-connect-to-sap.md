# Connecting Zero Copy Connector for ERP to SAP ECC and SAP S/4HANA

Connect Zero Copy Connector for ERP to an SAP ECC, SAP S/4HANA, or SAP S/4HANA Cloud system so that you can build models that use its data.

Zero Copy Connector for ERP Zero Copy Connector for ERP supports the following SAP systems:

-   SAP ECC
-   SAP S/4HANA
-   SAP S/4HANA Cloud
