# Install the ServiceNow Otto for Zero Copy Connector plugin

Install the ServiceNow Otto for Zero Copy Connector plugin \(sn\_erp\_ai\) to add ServiceNow Otto skills, agentic workflows, and AI agents to Zero Copy Connector for ERP.

## Before you begin

Role required: admin

Confirm that your instance meets the license and application requirements. For more information, see [Requirements for using AI in Zero Copy Connector for ERP](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-prereqs-for-ai.md).

## Procedure

1.  Install the ServiceNow Otto for Zero Copy Connector plugin \(sn\_erp\_ai\) by following the instructions in [Install AI plugins in AI Admin Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/install-now-assist-feature-plugins.md).

2.  To use the Explore ERP models agentic workflow or the OData Service Recommender AI agent, also complete the steps in [Prepare ServiceNow Otto for agentic workflows and AI agents](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-prepare-otto-for-erp-agentic-workflows.md).


## Result

The ERP data discovery and ERP data query skills are added to your instance.

## What to do next

Review the skills and set who can use them. For more information, see [View and deactivate ERP skills](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-activate-and-manage-erp-skills.md) and [Set access controls for ERP skills](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/erp-integration-framework/erpc-set-access-for-erp-skills.md).
