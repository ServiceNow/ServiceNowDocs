# Building applications and flows with ERP data from Zero Copy Connector for ERP

After you create Zero Copy Connector for ERP models, use the ERP data they extract, such as SAP data, to build applications in ServiceNow Studio, flows in Workflow Studio, and playbooks.

After you create models in Zero Copy Connector for ERP \(Enterprise Resource Planning\), use the extracted and transformed data as a foundation to build. For example, use ServiceNow Studio to build an application, or build flows within Workflow Studio.
