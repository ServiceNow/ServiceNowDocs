# Set up Boomi access in Partner Passport Portal

Install the Boomi store application and request a Boomi account before you purchase your first Boomi plan.

## Before you begin

Review the [Prerequisites for setting up Boomi](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/integrate-applications/prerequisites-partner-passport-portal.md).

Role required: sn\_wdf\_token.wdf\_admin

## About this task

Selecting **Get started** on the Boomi card opens a setup with three steps: **Install store app**, **Request access**, and **Purchase**. You mark each step as complete before you move to the next.

Installing the store application doesn't give you access to the Boomi platform. Boomi creates your account from the request that you submit.

## Procedure

1.  Navigate to **All** &gt; **Workflow Data Fabric Usage** &gt; **Partner Passport**.

2.  On the Boomi card, select **Get started**.

3.  In the **Install store app** step, select **Go to ServiceNow Store**.

    \[Omitted image "partner-portal-install-store-app.png"\] Alt text: Install store app step in the Boomi setup wizard, showing the Go to ServiceNow Store link and Mark as complete button

4.  On the Boomi Enterprise Platform listing, select **Get**, and accept the Boomi terms and conditions.

5.  Return to the setup, and select **Mark as complete**.

6.  In the **Request access** step, select **Go to Service Catalog**, and open the **Request Boomi Platform Account** item.

    \[Omitted image "partner-portal-request-access.png"\] Alt text: Request access step in the Boomi setup wizard, showing the Go to Service Catalog link and Mark as complete button

7.  Complete the form with your account details, and submit it.

8.  Return to the setup, and select **Mark as complete**.


## Result

You get a confirmation email from Boomi after you submit the request form. Boomi sends a welcome email with account access details. You can purchase a plan before the welcome email arrives.

## What to do next

Purchase a plan. For more information, see [Purchase a Boomi plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/integrate-applications/purchase-boomi-plan.md).
