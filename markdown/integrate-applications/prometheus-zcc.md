# Prometheus

The Prometheus connector provides read-only access to data and metadata in Prometheus.

A connection admin can create a connection to Prometheus and give data stewards access to that connection in Zero Copy Connector Hub. A data steward can select the established connection to create a data fabric table and map data from Prometheus. This allows users to retrieve Prometheus data through the table list view or GlideRecord scripts. For details on creating data fabric tables and mapping data, see [Managing data fabric tables](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/managing-data-fabric-tables-zcc.md).
