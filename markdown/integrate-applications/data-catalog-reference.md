# Data catalog reference

Reference topics provide information about roles and key terms.

-   **[Data catalog key terms](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/data-catalog-key-terms.md)**  
Key terms used in Data catalog.
-   **[Data catalog roles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/data-catalog-roles.md)**  
Assign roles to specify what different users can see and do.
-   **[Data assets enrichment statuses and AI confidence scores](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/enrichment-job-statuses-dc.md)**  
Enrichment statuses track the state of AI-generated suggestions at the field, asset, and enrichment run levels. Each suggestion also carries a confidence score that reflects how certain ServiceNow Otto is about that suggestion.
-   **[Data assets enrichment system properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/ai-enrichment-system-properties-dc.md)**  
System properties that control how the AI enrichment process batches assets, runs parallel enrichment lanes, and manages lane timeouts.
-   **[Data quality properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/data-quality-properties.md)**  
System property that controls how long data quality records are retained in the data quality audit and unmatched resource queue tables.
