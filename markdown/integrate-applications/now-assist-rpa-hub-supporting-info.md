# Supporting information for Now Assist for RPA Hub

Get a quick overview of the important information that is related to the Now Assist for RPA Hub application.

## Supported versions

Now Assist for RPA Hub is supported from Yokohama release 12.0.2.

## Supported user interfaces

To build automations using Now Assist, install the Now Assist for RPA Hub and then activate the RPA bot generation skill. For more information, see [Install Now Assist for RPA Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/configure-now-assist-rpa-hub.md).

The Now Assist for RPA Hub application includes the skills that are listed in the following table.

|Interface|Skill supported|
|---------|---------------|
|RPA Desktop Design Studio - [Create an automation with Now Assist](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/create-automation-now-assist.md)|RPA bot generation|
|RPA Desktop Design Studio - [Create an activity with Now Assist](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/create-activity-now-assist.md)|
|RPA Desktop Design Studio - [Build an automation with Now Assist](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/build-automation-now-assist.md)|
