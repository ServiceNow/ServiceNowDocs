# Workflow Data Fabric installers

Workflow Data Fabric installers streamline deployment by installing all required applications in a unified process, reducing setup time and supporting consistent configuration.

Workflow Data Fabric installers automate the deployment of multiple dependent applications through a single installation process. This approach eliminates the need to install each application individually, reducing the time required to set up Workflow Data Fabric and minimizing configuration errors. The installers are cumulative: Advanced includes everything in Foundation and AI Native, plus its own additional capabilities.

## Summary

|Installer|Scope|
|---------|-----|
|WDF AI Native Installer|Standalone|
|WDF Foundation Installer|AI Native + Foundation-specific|
|WDF Advanced Installer|AI Native + Foundation + Advanced-specific|

## WDF AI Native installer

-   ServiceNow Otto for Spokes
-   AI Data Explorer
-   Implementation Agents
-   Assists

## WDF Foundation installer

Installs everything in the AI Native installer, plus:

Capabilities specific to Foundation:

-   Integration Hub + Top 15 Spokes
-   API Access Volume
-   Data Access Requests
-   Robotic Process Automation \(RPA\) Hub
-   Automation Center
-   Data Catalog
-   External Content Connectors
-   Primary Zero Copy Connectors

## WDF Advanced installer

Installs everything in the Foundation and AI Native installers, plus:

Capabilities specific to Advanced:

-   Zero Copy Connectors
-   Zero Copy Connectors for ERP
-   Stream Connect for Apache Kafka
-   Password Reset
