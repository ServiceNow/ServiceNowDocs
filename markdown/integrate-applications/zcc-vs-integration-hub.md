# Differences between Zero Copy Connectors and Integration Hub

Choose whether to use Zero Copy Connectors or Integration Hub to integrate with external systems.

|Application|When to use|
|-----------|-----------|
|Zero Copy Connectors|When you want to retrieve real-time data from external sources without storing it on your instance, use Zero Copy Connectors.|
|Integration Hub|When you want advanced import and transformation options or customizable integrations, use Integration Hub.|
