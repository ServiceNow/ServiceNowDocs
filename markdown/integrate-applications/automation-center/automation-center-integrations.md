# Automation Center integrations

Automation Center integrations enable you to discover, analyze, and automate work from other ServiceNow applications. Rather than manually identifying automation opportunities, integrations help you to tap into existing analysis and user workflow data to find and build automations efficiently.

The product integrations help you in the following ways:

-   Process Mining integration: Discover inefficient or error-prone process steps and convert them directly into automation requests.
-   Task Mining integration: Record how users perform repetitive tasks and generate automations from those recordings.
-   Together, they provide a complete discovery-to-automation workflow that bridges analysis and implementation.

-   **[Integration with Process Mining](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-autreq-po.md)**  
Create an automation request from the Process Mining Workspace, which is outside of the Automation Center. If you have installed Process Mining and Automation Center, then you can create an automation request from the Process Mining Workspace.
-   **[Integration with Task Mining](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/integrating-with-task-mining.md)**  
Task Mining integration helps you use Task Mining to identify, design, and build automation agents that handle repetitive user workflows. Task Mining captures screen activity from user sessions and analyzes what users do, enabling you to automate those exact workflows.
