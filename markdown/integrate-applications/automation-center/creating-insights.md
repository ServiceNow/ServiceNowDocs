# Creating insights

Insights help you get automated analysis of your automation execution data. Instead of manually reviewing logs and metrics, insight rules automatically generate alerts and recommendations when patterns, anomalies, or issues are detected.

In this section, you will:

-   [Create an insight rule](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-insight-rule.md)
-   [Create an insight trigger](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-insight-trigger.md)
-   [Write a script for an automation message variable](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-message-variable-auto-center.md)
-   [View automation insights](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/view-insights.md)

-   **[Create an insight rule](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-insight-rule.md)**  
Create an insight rule to generate custom insights for an automation business process.
-   **[Create an insight trigger](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-insight-trigger.md)**  
Create an active insight trigger so that you can run the related insight rule.
-   **[Write a script for an automation message variable](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/create-message-variable-auto-center.md)**  
Write JavaScript code input for variables that are added in the message of an insight rule.
-   **[View automation insights](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/view-insights.md)**  
View automation insights to view the generated insights from the insight rules in Automation Center Executions dashboard.
