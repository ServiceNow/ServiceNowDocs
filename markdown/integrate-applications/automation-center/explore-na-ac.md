# Exploring ServiceNow Otto for Automation Center

Explore the benefits of ServiceNow Otto for Automation Center.

## ServiceNow Otto for Automation Center

ServiceNow Otto for Automation Center helps you use AI to ease your tasks in Automation Center.

## Saving Estimator skill

ServiceNow Otto for Automation Center includes the Saving Estimator skill, which must be activated to explore and discover automations from your ServiceNow® instance. For information about activating the skill, see [Activate skills for ServiceNow Otto for Automation Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/activate-skill.md). For information about how to explore automations, see [Explore automations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/auto-explorer.md).

## User task step summarization skill

ServiceNow Otto for Automation Center includes the User task step summarization skill. The User task step summarization skill uses the user interaction steps from Task Mining and produces a targeted summary of the intended business outcome, and a set of detailed steps derived from the original interactions. For more information about activating the skill, see [Activate skills for ServiceNow Otto for Automation Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/integrate-applications/automation-center/activate-skill.md). For information about creating an automation request from Task Mining workspace, see [Integration with Automation Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/now-intelligence/integration-with-automation-center.md).
