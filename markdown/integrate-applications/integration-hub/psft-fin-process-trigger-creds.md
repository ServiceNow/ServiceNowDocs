# Provide Oracle PeopleSoft credentials for the Process Trigger action

Store the credentials of a Oracle PeopleSoft user with the required permissions so that the Process Trigger action in the Oracle Peoplesoft Financial spoke can authenticate to your Oracle Peoplesoft Financial instance.

## Before you begin

-   [Configure a connection for the Oracle Peoplesoft Financial spoke](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/integrate-applications/integration-hub/psft-fin-conctn-config.md).
-   Role required: admin.

## Procedure

1.  Navigate to **Oracle Peoplesoft Credentials** &gt; **Oracle Peoplesoft Credentials**.

2.  Click **New**.

3.  On the form, enter the username and password of user with the required permissions.

4.  Click **Submit**.
