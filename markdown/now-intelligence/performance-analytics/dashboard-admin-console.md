# Admin Console for Core UI Dashboards

The Performance Analytics Admin Console contains several features for responsive dashboard management.

## Explore and Manage

**Note:** This topic refers to Core UI dashboards. If you are looking for information about the newer Platform Analytics dashboards, see [Dashboards in Platform Analytics](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/now-intelligence/analytics-center-dashboards.md).

Navigate to **Performance Analytics** &gt; **Admin Console**.

The Explore and Manage dashboard contains tools to find, modify, and create dashboards and indicator-related records. Click the links to manage Dashboard Groups and Dashboards.

## Advanced Configuration

Navigate to **Performance Analytics** &gt; **Admin Console**.

The **Advanced Configuration** tile on the Admin Console shows a link to [Dashboard Properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/now-intelligence/performance-analytics/dashboard-properties.md).

## Tree view

The Admin Console tree view enables you to identify and view the relationships between Performance Analytics and Reporting entities in a hierarchy. With the tree view, you don't have to sift through multiple pages to determine how they relate to one another. For more information, see [\(Legacy\) Dependency Assessment](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/now-intelligence/performance-analytics/impact-analysis.md).

For more information on Admin Console functionality, see [\(Legacy\) Performance Analytics Admin Console](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/now-intelligence/performance-analytics/pa-admin-console.md).
