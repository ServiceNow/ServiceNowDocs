# Configure the ServiceNow Otto context menu in Now Assist Experiences

The ServiceNow Otto context menu enables users to apply a variety of AI skills in the context of dashboards.

## Before you begin

Role required: now\_assist\_admin

## About this task

The skills you configure here are the ones that you can select when you add the reusable ServiceNow Otto context menu dashboard element.

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Experiences**.

2.  In the product area pane, select **ServiceNow Otto context menu**.

3.  In the **Configurations** tab, select **Create new**.

4.  In the Configure ServiceNow Otto context menu window, select

    -   Workflow: `Data and Analytics`
    -   Product: `Analytics`
5.  Provide a unique name for context menu and select **Start configuration**.

6.  Select the **Par Dashboard \(par\_dashboard\)** table.
