# Bookmark a Platform Analytics dashboard

Bookmark a dashboard so that you can find it easily in the Dashboard Library.

## Before you begin

Role required: Any, if the user has access to the dashboard

## Procedure

1.  Navigate to **All** &gt; **Platform Analytics** &gt; **Library** &gt; **Dashboards**.

2.  Select the empty bookmark icon \[Omitted image "bookmark-icon-empty.png"\] Alt text: next to the dashboard that you want to bookmark.

    The icon fills \[Omitted image "bookmark-icon-full.png"\] Alt text: to indicate the dashboard is bookmarked.


## Result

When the Dashboard Library is filtered by Bookmarks, the selected dashboards appear in the Bookmarked list.

## What to do next

To remove a bookmark, choose the filled bookmark icon \[Omitted image "bookmark-icon-full.png"\] Alt text:.
