# Bookmark a Platform Analytics dashboard

Bookmark a dashboard so that you can find it easily in the Analytics Center.

## Before you begin

Role required: Any, if the user has access to the dashboard

## Procedure

1.  Navigate to **All** &gt; **Platform Analytics** &gt; **Dashboards**.

2.  Select the dashboard that you want to bookmark.

3.  From the More actions menu \(\[Omitted image "icon-vert-3dot-p.png"\] Alt text: More actions menu icon\), select **Add to bookmarks**.


## Result

In the **Dashboards** overview, the selected dashboard appears in the Bookmarked list.

## What to do next

To remove a bookmark, choose the bookmarked dashboard and select **Remove bookmark** from the More actions menu \(\[Omitted image "icon-vert-3dot-p.png"\] Alt text: More actions menu icon\).
