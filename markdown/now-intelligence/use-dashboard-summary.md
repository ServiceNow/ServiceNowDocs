# Using Dashboard Summary

Enable users of Platform Analytics experience inline dashboards and workspaces to generate summaries of a dashboard's content using AI.

**Note:** The following dashboard elements aren't supported in the Dashboard Summary:

-   Process Mining - Map
-   Usage Insights Funnel
-   iFrame

The Dashboard Summary does not support technical dashboards.
