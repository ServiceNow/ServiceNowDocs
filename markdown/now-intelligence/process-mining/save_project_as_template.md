# Save a project as a template

Save a project you have tested and refined as a template, so anyone can reuse its configuration for new projects.

## Before you begin

Role required: sn\_process\_mining\_analyst, sn\_process\_mining\_power\_user, or sn\_process\_mining\_admin

## About this task

The template type this project is saved as depends on your role:

-   If you're a power user or above, the project is saved as a Standard template.
-   If you're an analyst, the project is saved as a Custom template.

## Procedure

1.  Navigate to **Workspaces** &gt; **Process Mining Workspace**.

2.  Open the Process Mining project you want to save as a template.

3.  From the card's dropdown menu, select **Save as Template**.

    \[Omitted image "add-template.png"\] Alt text: Save as template option

    The Set objectives tab is displayed.

4.  Follow the steps in the [Create a project or template using Project Builder](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/process-mining/define-workflow-model.md) section to complete the process.


## Result

The template is created using the project.

You can view and manage it from **Manage project templates** \(available from the gear icon on the projects page\).
