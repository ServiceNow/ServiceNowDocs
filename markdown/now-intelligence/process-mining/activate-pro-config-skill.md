# Generate process configuration using AI skill

Use AI to generate a suggestion for the process configuration fields for a table, instead of selecting each field manually.

## Before you begin

Role required: admin

**Note:** This skill is activated by default. If it is turned off, you can activate it with the following procedure.

## About this task

AI analyzes your table's fields and how frequently they change, then suggests which fields to use for your control flow \(state\), team, and agent definitions, along with suggested breakdown, work notes, and root-cause-analysis fields.

**Note:** AI recommendation for clustering and intent and activity analysis is not supported.

**Activate the skill**

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Skills**.

2.  Select **Platform** &gt; **Other**.

3.  Select **Generate process configuration** from the list of AI skills for Platform.

4.  Select **Activate skill** for the Generate process configuration skill.

    The skill is activated for your instance.
