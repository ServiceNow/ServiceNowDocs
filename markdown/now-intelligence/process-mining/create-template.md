# Create a Process Mining template

Create a Process Mining template to reuse a Process Mining project configuration and reapply it across your organization without the need of creating it everytime.

## Before you begin

Role required: sn\_process\_mining\_analyst, sn\_process\_mining\_power\_user, or sn\_process\_mining\_admin

## About this task

Creating a template has the following conditions:

-   Only power users or higher can create or delete Standard templates. Analysts can view them.
-   Analysts and above can create Custom templates.
-   An analyst never sees the type selector when creating a template. The type is always set to Custom automatically.

## Procedure

1.  Navigate to **Workspaces** &gt; **Process Mining Workspace**.

2.  From the Process Mining projects page, select the gear icon, then select **Manage project templates**.

    \[Omitted image "man-temp.png"\] Alt text: Manage project templates button

    You can also manage templates from the Project Setup page. For more information, see [Create a project or template using Project Builder](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/process-mining/define-workflow-model.md).

3.  Select the **Templates** tab on the Manage project templates page.

    \[Omitted image "create-template.png"\] Alt text: Templates tab

    **Note:** You can select any template, and select the **Delete** button to delete it. To edit a template, you can open the template and edit.

4.  Select **New**.

    The Set objectives tab is displayed.

    \[Omitted image "set-obj-temp.png"\] Alt text: Set objectives tab

5.  Follow the steps in the [Create a project or template using Project Builder](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/process-mining/define-workflow-model.md) section to complete the process.


## Result

The template is created.

You can view and manage it from **Manage project templates** \(available from the gear icon on the projects page\).
