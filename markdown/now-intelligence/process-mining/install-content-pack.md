# Install Process Mining content pack

Install the content pack to copy the process configurations set for the content pack to your process configuration.

## Before you begin

Role required: sn\_process\_mining\_power\_user or sn\_process\_mining\_admin

## Procedure

1.  Navigate to **Workspaces** &gt; **Process Mining Workspace**.

2.  On the left of the page, select the Process configurations icon \(\[Omitted image "icon-process-config.png"\] Alt text: Process configuration builder\).

3.  Select the **Content pack templates** tab.

4.  Select **Browse content packs** if you want to install a content pack template.

    **Important:**

    Starting with the Brazil release, the ITSM, Customer Service Management, HR Service Delivery, SPM, Security Incident Response, and Field Service Management content packs load automatically and don't require the steps in this topic. For more information, see [Automatic delivery of content packs](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/process-mining/process-mining-content-pack-delivery.md). The steps in this topic still apply to the Financial Services Operations and Telecommunications content packs.

    \[Omitted image "conten-pack-install.png"\] Alt text: Install content pack templates

5.  Select **Go to ServiceNow Store**.

    \[Omitted image "content-pack-install-2.png"\] Alt text: Install content pack template

6.  Find the content pack you need, install it, and copy the preferences from the template.

    You can see the table name listed under **Content pack templates** tab. The table that is displayed here is the one on which the content pack is based.
