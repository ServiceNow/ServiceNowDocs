# Bookmark a visualization in the Visualization Designer

Bookmark a visualization so that you can find it easily in the Data Visualizations library.

## Before you begin

Role required: None. Anyone who can access a data visualization can bookmark it for themselves.

## Procedure

1.  Navigate to **All** &gt; **Platform Analytics** &gt; **Library** &gt; **Data Visualizations**.

2.  Select the empty bookmark icon \[Omitted image "bookmark-icon-empty.png"\] Alt text: next to the visualization that you want to bookmark.

    The icon fills \[Omitted image "bookmark-icon-full.png"\] Alt text: to indicate the visualization is bookmarked.

3.  From the More actions menu \(\[Omitted image "icon-vert-3dot-p.png"\] Alt text: More actions icon\), select **Add to bookmarks**.


## Result

When the Data visualizations Library is filtered by Bookmarks, the selected visualizations appear in the Bookmarked list.

## What to do next

To remove a bookmark, select the filled bookmark icon \[Omitted image "bookmark-icon-full.png"\] Alt text:.
