# Install AI Data Explorer

Verify that AI Data Explorer is installed, and install it if it is not.

## Before you begin

Role required: now\_assist\_explorer\_admin or higher

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Settings**.

    If you don't have the AI Admin Hub, you don't have any ServiceNow Otto applications installed. You need at least one such application. Visit the ServiceNow® Store.

2.  Go to the **Plugins** page.

3.  Open the **Installed** tab and search for AI Data Explorer.

    If the application is installed, you are done. If it is not installed, continue with this procedure.

4.  Decide whether you want the AI Data Explorer skills to be activated automatically on installation.

    By default, AI Data Explorer skills are automatically activated. If you turn off automatic activation before installation, you will activate each skill manually.\[Omitted image "otto-default-activation-switch.png"\] Alt text: Settings &gt; Plugins page showing the Default activation of out-of-the-box skills switch.

5.  Under **All available plugins**, locate the AI Data Explorer application and select **Get plugin**.


## Result

You are navigated to a location where you can get the plugin. Follow all steps on that location, including those regarding licensing.
