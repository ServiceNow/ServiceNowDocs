# Edit a data visualization in the Visualization Designer

After you create a data visualization, you can return to it and edit the data visualization's appearance and other aspects.

## Before you begin

Role required: You can edit any data visualization you own unless it is a shared visualization, in the library. If the data visualization is in the library and you own it, you need the itil, report\_user, or viz\_creator role to edit it. You can edit any data visualization with the viz\_admin role or higher.

If you don't have edit rights to a visualization that has been shared with you, you can still edit the visualization to explore the data. You cannot, however, save those changes to the visualization.

If the visualization is in the library and you don't own it, you need the viz\_admin or admin role to save edits to it. Alternatively, the owner can share it with you with edit rights. When you save your edit, you can save the visualization in the library, which affects all dashboards that show the visualization. Alternatively, you can save a local copy. You cannot save changes to data visualizations in the library if you don't have edit rights or you don't have the viz\_admin or admin role.

## Procedure

1.  Navigate to **All** &gt; **Platform Analytics** &gt; **Library** &gt; **Data Visualizations**, or open an in-line dashboard and select **Edit**.

2.  Select the visualization that you want to edit.

3.  In the Visualization Designer, select the Configuration icon \(\[Omitted image "icon-ac-config.png"\] Alt text: Configuration icon\) to edit header, data, and presentation options.

    For details about editing the configuration of a data visualization, look up the visualization type under [Creating data visualizations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/creating-data-visualizations.md).

4.  Select the information icon \(\[Omitted image "icon-info-ac.png"\] Alt text: Info icon\) to edit name, description, certification, and requester information.
