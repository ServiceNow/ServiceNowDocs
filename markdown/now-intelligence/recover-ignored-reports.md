# Reassess ignored visualizations

When you address the ACL Assessment for Data Visualizations, you can ignore any data visualization or Core UI report. View these visualizations to consider their statuses again.

## Before you begin

Roles required: admin and security\_admin.

## Procedure

1.  Navigate to **All** &gt; **Platform Analytics Administration** &gt; **ACL Assessment for Data Visualizations** &gt; **Ignored Data Visualizations and Users**.

    In the Ignored Users and Reports list \[report\_view\_acl\_assessment\_ignored\_users\_list\], you see three columns by default: Visualization, Ignored Users, and Ignore Report.

2.  In the Ignore Report column, set the value of the visualizations to reassess to `false`.


## Result

The ACL Assessment for Data Visualizations assesses the `false` visualizations the next time you run the assessment.
