# Reassess ignored users

When you address the ACL Assessment for Data Visualizations, you can ignore any individual user. View these users to consider their statuses again.

## Before you begin

Roles required: admin and security\_admin.

## Procedure

1.  Navigate to **All** &gt; **Platform Analytics Administration** &gt; **ACL Assessment for Data Visualizations** &gt; **Ignored Data Visualizations and Users**.

    In the Ignored Users and Reports list \[report\_view\_acl\_assessment\_ignored\_users\_list\], you see three columns by default: Visualization, Ignored Users, and Ignore Report.

2.  Select a row with an Ignored User whom you no longer want to ignore.

3.  From the **Actions on select rows** list, select **Delete**.


## Result

The ACL Assessment for Data Visualizations application includes the users you deleted from this report the next time you run the assessment.
