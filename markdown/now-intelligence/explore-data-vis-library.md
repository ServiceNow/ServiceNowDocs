# Exploring the data visualization library

Find any data visualization which you can access in the Platform Analytics data visualizations library. With the appropriate role, you can also create a visualization there.

## Overview of the Data Visualizations library

Open the data visualizations library by navigating to **All** &gt; **Platform Analytics** &gt; **Library** &gt; **Data visualizations**.

\[Omitted image "analytics-center-data-vis-tab.png"\] Alt text: Data Visualizations library

## List actions

A set of buttons enables you to take the following actions on the Data Visualization list:

-   **Refresh list \[Omitted image "analytics-center-dv-refresh.png"\] Alt text: The Refresh List button.**

    There can be a lag in the list of visualizations after you create or delete a visualization. Select **Refresh List** to update the list.

-   **Copy URL for data visualizations \[Omitted image "analytics-center-vd-copy-url.png"\] Alt text: Copy URL button.**

    Copies the data visualizations library URL to the clipboard.

-   **New**

    Create a data visualization, as described by visualization type in the subtopics of this section. For information on who can create data visualizations,see [Platform Analytics roles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/now-intelligence/platform-analytics-roles.md).


## List filters

A search box lets you filter the list of data visualizations by name or description. The filter panel shows you which filters are being applied. By default, the filter Active = true is always applied. For example, filtering on the word Data shows the following filters in the panel:

-   Active = true
-   Name contains Data
-   Description contains Data

Alternatively, you can select one of these predefined filters:

-   **All** shows all the visualizations that you have access to.
-   **Bookmarked** shows only your bookmarked visualizations. Bookmark any data visualization that you have access to so that you can find it here easily. To bookmark a visualization, see [Bookmark a visualization in the Visualization Designer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/now-intelligence/bookmark-dv-ac.md).
-   **Certified** shows only the visualizations that an administrator has certified. To certify a data visualization, see [Certify a data visualization in the Visualization Designer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/now-intelligence/certify-dv-ac.md).
-   **Shared with me** shows the visualizations that have been shared with you as a user, or member of a group or role. To share a data visualization, see [Share a data visualization in the Visualization Designer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/now-intelligence/share-dv-ac.md).
-   **Created by me** shows only the visualizations that you’ve created.
