# Install the ACL Assessment for Data Visualizations

The ACL Assessment for Data Visualizations enables you to identify users that don't have access to reports and to enable access where appropriate.

## Before you begin

Your Brazil instance must be on Brazil Patch 2 or later.

Roles required: admin and security\_admin.

## About this task

The ACL Assessment for Data Visualizations is a store app. For more information about installing store apps, see [Install an application or plugin](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/installing-applications-in-application-manager.md).

## Procedure

1.  Navigate to **All** &gt; **System Applications** &gt; **All Available Applications** &gt; **All**.

2.  Enter `ACL assessment` in the search bar.

    You can search for the application by its name or ID. If you cannot find an application, you may have to request it from the ServiceNow Store.

3.  Select a version from the list and select **Install**.

    In the Review Installation Details dialog box, any dependencies installed with your application are listed.

4.  If you're prompted, follow the links to the ServiceNow Store to get any additional entitlements for dependencies.

5.  Select a version from the list and select **Install**.

    In the Review Installation Details dialog box, any dependencies installed with your application are listed.
