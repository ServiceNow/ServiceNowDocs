# Using knowledge blocks in the Knowledge Center

Use knowledge blocks to simplify knowledge authoring for writers and knowledge consumption for readers.

In the Knowledge Center, you create knowledge blocks, add them to knowledge articles, and edit them in the context of an article. For what knowledge blocks are, how user criteria control who can read block content, and what you must activate before you use them, see [Knowledge blocks in Knowledge Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/servicenow-platform/kc-knowledge-blocks.md).
