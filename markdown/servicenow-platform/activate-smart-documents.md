# Activate the smart documents skill

Activate the smart documents skill to get document insights through conversational interactions by using Now Assist in the Document Management application.

## Before you begin

Role required: sn\_nowassist\_admin.nsa\_admin

**Note:** From Zurich Patch 11 and Australia Patch 4 onwards, Smart documents skill is enabled by default for all tables. For more information see, [Configure the smart documents skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/configure-skill-smart-documents.md).

## Procedure

1.  Navigate to **All** &gt; **Now Assist Admin** &gt; **Skills**.

2.  In the workflow list, select **Platform**.

3.  In the Now Assist skills for Platform, locate the **Smart Documents** skill.

4.  Select **Activate skill**.

5.  In the Define availability section, select the tables for which to activate smart documents.

6.  Select **Save and continue** to go to the next step in the guided setup.

    The guided setup walks you through the configuration of general details, input, prompt, availability, display, review, and activation of the customized skill.

7.  In the Define access section, select the roles that have access to this skill.

8.  Select **Save and continue**.

9.  In the Select display section, select where to display Smart Documents.

10. Select **Save and continue**.

11. Review your selections and select **Activate**.

    The guided setup is complete and the skill is activated.


## What to do next

To configure system properties for the Smart Documents skill, see [System property for Smart Documents skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/system-property-smart-documents.md).
