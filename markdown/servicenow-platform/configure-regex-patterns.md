# Add or remove data patterns for sensitive content detection

Add or remove data patterns to customize what the Smart Docs Agent suggests during redaction.

## Before you begin

Role required: platform\_document\_management\_admin

## Procedure

1.  Navigate to **All** &gt; **System Security** &gt; **Data Privacy** &gt; **Privacy Policy Advanced Configuration**.

2.  Select **Document Redaction-sn\_doc\_gen\_ai**.

3.  Select and open **Select Data Patterns**.

4.  Select and add or remove patterns as needed.

5.  Select **Save**.

    To create custom data patterns beyond the provided defaults, see [Configure Data Discovery patterns](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-security/configure-data-discovery-patterns.md).
