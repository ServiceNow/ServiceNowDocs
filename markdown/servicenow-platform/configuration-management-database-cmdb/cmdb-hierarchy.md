# CMDB hierarchy

Sets of CIs that share attributes are typically stored in the same class table. All CMDB tables are connected by relationships and child classes inherit attributes from parent classes to form a web of tables referred to as the CMDB hierarchy.

The base system contains hundreds of table definitions that you can use to store actual CIs in your organization. You can also add tables to the existing hierarchy, by connecting a custom table to a table that is already in the CMDB hierarchy.
