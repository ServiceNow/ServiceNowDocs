# Activate the CMDB Duplicate CIs Agent

Activate the CMDB Duplicate CIs Agent from the Feature Preview Program to start automated duplicate CI remediation.

## Before you begin

The CMDB Duplicate CIs Agent must be activated from the Feature Preview Program. For more information, see [Feature Preview Program](https://www.servicenow.com/docs/r/platform-administration/feature-preview-program.html).

Role required: admin

## About this task

The agent is inactive by default. After activation, the agent is available from the Duplicate CIs card on the Data Foundations advisor dashboard. You can deactivate the feature at any time.

**Note:** If ServiceNow Otto for CMDB isn't installed, the **Duplicate CIs agent** card doesn't appear on the Feature Preview Program page.

## Procedure

1.  Navigate to **All** &gt; **Feature Preview Program**.

2.  On the Feature Preview Program page, locate the **Duplicate CIs agent** card.

3.  On the card, select **Activate**.

    The button changes to **Deactivate** and an **Active** badge appears on the card.


## What to do next

To deactivate the feature, select **Deactivate** on the card. The button returns to **Activate**.
