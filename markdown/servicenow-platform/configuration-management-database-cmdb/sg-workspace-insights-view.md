# Insights view in CMDB Workspace

View insightful dashboards that show aggregated counts, state, and health for key features such as CMDB Health, Service Instances, and CMDB 360.

## Access

Navigate to **Workspaces** &gt; **CMDB Workspace**, and then in the navigation panel, select the Insights icon. Only dashboards that you have access to, appear in the Insights navigation panel and specific widgets on dashboards might require additional access privileges.

Role required: Any role containing sn\_cmdb\_user \(sn\_cmdb\_user, sn\_cmdb\_editor, sn\_cmdb\_admin\)
