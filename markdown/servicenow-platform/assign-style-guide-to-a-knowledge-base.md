# Assign a style guide to a knowledge base

Assign a style guide to a knowledge base in Knowledge Center so that authors can choose it when they generate articles in that knowledge base. Only active style guides can be assigned.

## Before you begin

Role required: knowledge admin

## Procedure

1.  Navigate to **Lists** &gt; **Administration** &gt; **Knowledge base**.

2.  Select and open the knowledge base where you want the style guide to be available.

3.  Select the **Style Guides** tab.

    The style guides already assigned to the knowledge base appear.

4.  Select **New**.

5.  On the form, fill in the fields.

    |Field|Description|
    |-----|-----------|
    |Knowledge base|Knowledge base that the style guide is assigned to. This field is automatically populated.|
    |Order|Position of the style guide in the style guide list that authors see. Lower values appear first. The default value is 100.|
    |Style guide|Style guide to assign to the knowledge base. Only active style guides are available.|

6.  Select **Save**.

    The style guide appears in the list of style guides for the knowledge base.
