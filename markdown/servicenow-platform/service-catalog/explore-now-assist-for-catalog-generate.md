# Exploring AI Authoring for Catalog Builder

Learn how the AI Authoring for Catalog Builder application helps you to create catalog items by simply describing them. AI generates catalog items with more detailed descriptions and question labels.

## AI Authoring for Catalog Builder overview

In Catalog Builder, you can describe the catalog item you want, and AI generates the catalog item for you.

The application uses the Catalog item generation skill to create catalog items. For more information about the skill, see [Catalog item generation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/service-catalog/now-assist-catalog-item-generation.md).

**Note:** You must be assigned the catalog\_builder\_editor role to create catalog items using AI.
