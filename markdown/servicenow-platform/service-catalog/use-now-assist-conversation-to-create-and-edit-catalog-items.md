# Using AI conversation to create and edit catalog items

AI provides a conversational interface that enables you to create catalog items, making these items available in the Service Catalog for users to request.

To use AI for creating catalog items, you must have the catalog\_builder\_editor role and confirm that the ServiceNow Otto for Creator is installed in your environment.

To streamline the catalog creation process, you can use plain language input through AI within Catalog Builder. This approach allows you to generate values for various steps simply by describing what you need in natural language.

By responding directly to your prompts, AI can generate a catalog item and its details where possible.

## Catalog item preview

After receiving a response from AI regarding catalog item creation, you can view a preview of the catalog item.

## AI tag

The fields with values generated by AI show the AI sparkle \(\[Omitted image "icon-ai-sparkle.png"\] Alt text: AI sparkle icon.\) icon. If you make any changes in these fields, the icon is removed.

You can edit published catalog items conversationally using AI. If you’ve already started editing a published catalog item, you can still use AI to edit the draft of that published catalog item. You can edit variables and UI policies in this mode.
