# Migrating from Core UI to Angular portal

Administrators on upgraded instances must install the `com.glideapp.servicecatalog.ui16_portal` plugin to migrate from the Core UI catalog experience to the Angular portal.

On new instances, the `com.glideapp.servicecatalog.ui16_portal` plugin is active by default. On upgraded instances, administrators must install the plugin manually to move requesters from the Core UI catalog experience to the Angular portal.

When ordering an item, requesters start viewing the Angular portal instead of Core UI.

In Angular portal, catalog items behave as they do in Service Portal, including client scripts and UI policies.

**Note:**

For the plugin installation procedure, see [Install an application or plugin](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/installing-applications-in-application-manager.md).
