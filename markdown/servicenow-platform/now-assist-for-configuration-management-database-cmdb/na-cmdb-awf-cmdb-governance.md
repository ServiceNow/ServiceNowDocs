# Get advice on CMDB governance from Now Assist

Work through the process of improving CMDB data accuracy, completeness, and health. The objective is to ensure that users can trust the data that they use for their work.

## Before you begin

Role required: sn\_cmdb\_admin

## About this task

To learn more about using the Now Assist panel, see [Working in the Now Assist panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/intelligent-experiences/now-assist-panel-overview.md).

## Procedure

1.  Use either of the following methods to start the process.

    -   While working in the CMDB Workspace, select **Provide advice on CMDB governance** in the Quick Links section.
    -   While working in the CMDB Workspace, select the Now Assist icon \[Omitted image "ai-sparkle-cmdb.png"\] and then enter `Provide advice on CMDB governance`. For more information, see [Working in the Now Assist panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/intelligent-experiences/now-assist-panel-overview.md).
2.  Enter the class of CI to create and then continue by answering the Now Assist questions.
