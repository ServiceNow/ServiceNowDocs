# Remediate software data and attribute gaps using AI agents

Use the CMDB ingestion optimizer agent from the Software Asset Management advisor dashboard to review and apply ingestion source recommendations for flagged software products or CI classes.

## Before you begin

Role required: sam\_admin or sn\_cmdb\_admin, plus now\_assist\_panel\_user, to start an agent conversation with **Ask Otto**. A user with only the CMDB success advisor scope-user role can still select **Ask Otto** on the same card; see the following steps.

## About this task

The CMDB ingestion optimizer agentic workflow evaluates the software products and CI classes affected by a data or attribute gap on the Software Asset Management advisor dashboard.

For more information about the ingestion sources this workflow recommends, see [Software data gap remediation using the ingestion optimizer agentic workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/servicenow-platform/now-assist-for-configuration-management-database-cmdb/na-cmdb-awf-ingestion-optimizer-c.md) and [Improving CMDB data quality for SAM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-asset-management/cmdb-sa-sam-remediation.md).

## Procedure

1.  Open CMDB success advisor and select **View insights** for Software Asset Management.

    The Software Asset Management advisor dashboard opens.

2.  In the **CMDB data quality insights generated by AI** section at the top of the dashboard, locate the **Software installs missing version** card or the **CIs missing CPU attributes** card.

3.  Select **Ask Otto** \[Omitted image "ask-otto-blue.png"\] on the card.

    If you hold sam\_admin or sn\_cmdb\_admin and the now\_assist\_panel\_user role, and the CMDB ingestion optimizer agent is available, **Ask Otto** opens a new ServiceNow Otto panel conversation with the agent. Otherwise, **Ask Otto** opens the affected installs list directly.


## Result

Continue in the ServiceNow Otto panel conversation to review the recommended Discovery patterns, Service Graph Connectors, and specialized ingestion tools. Configuring a recommended source improves the CMDB data quality score in CMDB success advisor over time.
