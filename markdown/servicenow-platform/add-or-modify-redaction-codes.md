# Add or modify redaction codes for sensitive data redaction

Add new redaction codes for sensitive data redaction based on your organization's compliance framework, or modify existing codes to match your document handling policies

## Before you begin

Role required: platform\_document\_management\_admin

## Procedure

1.  Navigate to **All** &gt; **Document Management** &gt; **Administration** &gt; **Redaction Codes**.

2.  Add a redaction code

    1.  Select **New**.

    2.  In the **Redaction Code** field, enter a code as the redaction code.

    3.  In the **Description** field, enter the names or description of the data type this code applies to.

    4.  Select **Active** and **Save**.

3.  Modify an existing code

    1.  Open the record.

    2.  Update the **Description** or **Redaction Code** as required.

    3.  Select **Update**.

4.  Deactivate a code

    1.  Open the record.

    2.  Clear the Active check box.

    3.  Select **Update**.
