# Generate knowledge articles using style guide

Learn how to apply a style guide when you generate a knowledge article in the Knowledge Center. The style guide applies only to the article you generate, and it sets the tone, voice, and terminology that the generated content follows.

## Before you begin

Role required: knowledge

## Procedure

1.  Navigate to **All** &gt; **Knowledge** &gt; **Knowledge Center**.

2.  In **Knowledge Actions**, select **Create an article**.

3.  Select the knowledge base that the style guide is assigned to.

4.  Select a template and select **Next**.

    The article editor opens.

5.  In the AI context menu, enter a prompt for ServiceNow Otto.

    For example, `Create a knowledge article about password resets on iPhones`.

6.  From the **Style guide** list, select a style guide.

    The list shows the active style guides assigned to the knowledge base, sorted by their order value.

    To generate the article without a style guide, select **None**.

7.  Select **Submit**.


## Result

AI sends the style guide instructions with your prompt to the Large Language Model \(LLM\). The generated article follows the language, tone, voice, and terminology rules defined in the style guide.
