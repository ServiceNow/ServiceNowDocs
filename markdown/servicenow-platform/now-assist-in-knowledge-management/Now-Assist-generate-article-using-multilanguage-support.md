# Generate a Knowledge article using multi-language support

ServiceNow Otto in Knowledge Management provides multi-language support for Knowledge article generation. As an agent, generate articles from incidents, cases, and other task types in languages other than English using a language selector configured by the admin.

## Before you begin

Languages available in the language selector are determined by:

-   The language package installed for the Knowledge Base
-   The language preference selected by the admin in the knowledge settings

Role required: author or agent

## Procedure

1.  Navigate to **All** &gt; **Knowledge** &gt; **Articles** &gt; **All**.

2.  Open a case or an incident assigned to you that is documented in a language other than English.

3.  Select **Create Knowledge**.

    \[Omitted image "NA-multi-language-1.png"\] Alt text: Create a Knowledge article from a non-English incident, case, or other task type.

4.  In the Use AI to draft this article? modal, select **Yes, draft with Otto**.

    \[Omitted image "NowAssist\_CoreUI.png"\] Alt text: Draft the article using AI.

5.  In the Select Options modal, select the **Knowledge base** and the **Article language** to use for the article.

    \[Omitted image "NA-multi-language-2.png"\] Alt text: Select the Knowledge Base and the article language.

6.  Select **Continue**.

    \[Omitted image "NA-multi-language-3.png"\] Alt text: Knowledge article generated in the selected language.

    The Knowledge article is generated in the selected language.
