# RaptorDB Professional

RaptorDB Professional is a ServiceNow database tier that adds analytical processing to the transactional performance of RaptorDB Standard. A single engine runs both workload types on the same data, so you can report on and analyze operational records without exporting them to an external system.

RaptorDB Professional underpins ServiceNow core services, applications, and data.

**Note:** The roll-out of RaptorDB Professional is not tied to your organization's upgrade to Brazil. Contact your account team for more information.

## Benefits

RaptorDB Professional adds capabilities that RaptorDB Standard does not provide: column-store indexing and parallel query processing for analytical queries on large tables, and support for shared, replicated, and self-hosted instance topologies. It is also the database tier required for Live Connect and Live Archive.

## Features

RaptorDB Professional includes the following features.

|Feature|Details|
|-------|-------|
|PostgreSQL foundation|Built on PostgreSQL with ServiceNow optimizations for ServiceNow AI Platform workloads.|
|Hybrid transactional-analytical processing \(HTAP\)|Runs transactional and analytical workloads simultaneously on a single engine, without maintaining a separate analytics system.|
|Optimized for ServiceNow workloads|Query performance optimized for ServiceNow AI Platform applications and workloads.|
|Improved response time|Query performance designed for ServiceNow AI Platform workloads.|
|Ultra-scale performance and scalability|Supports generative AI, machine-scale data use cases, user growth, applications, workloads, and analytics.|
|Enhanced analytics with built-in column store|Accelerates analytical queries through integrated columnar storage and parallel query processing. For more information, see [Create a table index](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/t_CreateCustomIndex.md).|
|Advanced instance topology support|Supports complex deployment configurations across ServiceNow AI Platform instances, including shared and replicated topologies.|
|Support for self-hosted environments|Available for organizations running ServiceNow AI Platform in self-hosted deployments.|
|Live Connect|Available starting from Australia|
|Live Archive|Available starting from Australia.|
