# MID Server profiles

A MID Server profile is a named collection of configuration settings that you can apply to one or more MID Server instances from your ServiceNow instance.

A profile stores wrapper configuration parameters and instance configuration settings that are synced to all associated MID Server instances without requiring direct access to the host server. Because a single profile can be associated with multiple MID Server instances, you can maintain consistent configuration across your MID Server fleet from one location.

MID Server profiles were introduced in the San Diego release for containerized MID Server deployments. Starting with the Zurich release, MID Server profiles are available for all MID Server deployment types.
