# Configure Voice Assist for Docs skill

Configure the Voice Assist for Docs skill to get document insights through audio summaries and voice interactions.

## Before you begin

Role required: sn\_nowassist\_admin.nsa\_admin

## Procedure

1.  Navigate to **All** &gt; **Now Assist Admin** &gt; **Skills**.

2.  In the workflow list, select **Platform**.

3.  In the search field, enter `Voice Assist for Docs`.

4.  Select **Activate skill**.

5.  In the Select Tables section, select the tables for which you want to activate the Voice Assist for Docs skill.

6.  Select **Save and continue**.

    A guided setup leads you through the configuration of general details, input, prompt, availability, display, review, and activation of the skill. Completing the entire guided setup activates the skill.

7.  In the Define access section, determine the roles that have access to this skill.

    The sn\_voice\_doc.user role is selected by default and should not be edited.

8.  Select **Save and continue**.

9.  In the Select display section, choose where to display Voice Assist for Docs.

10. Select **Save and continue**.

11. Review your selections and select **Activate**.

    The skill is activated.


## What to do next

To configure system properties for the Voice Assist for Docs skill, see [Configure Document Voice Interaction](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/servicenow-platform/configure-system-properties-voice-assist-for-docs.md).
