# Complete care team tasks in Care Team Mobile

View, update, and complete your assigned care team tasks, including any attached smart assessments, on the mobile device that you already use in the field.

## Before you begin

Field Service Management Mobile \[sn\_fsm\_mobile\] version 29.2.3 must be installed.

Role required: sn\_cto.care\_team\_agent

## About this task

A "My work" tab surfaces within the Care Team Mobile navigation which allows care team members to view, update, and complete their care team tasks directly from the FSM Mobile app.

You can also fulfill care team tasks in the workspace. For more information, see [Fulfill care team case and tasks](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/ctwm-fulfill-care-team-cases-tasks.md).

## Procedure

1.  In Care Team Mobile, select **My work**.

2.  Select the care team task that you want to work on.

3.  Update the task status and add notes as needed.

4.  If the task includes a smart assessment, complete the assessment.

    For more information on smart assessments, see [Smart assessments in Care Team Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/ctwm-smart-assessments.md).

5.  Mark the task as complete.


## Result

The task status, notes, and completed smart assessment are saved to the care team task record, and the care team case progress is updated.
