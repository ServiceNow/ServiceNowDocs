# ServiceNow agentic workflows in Care Team Operations

Care Team Operations uses one agentic workflow, available over chat or by phone, to create and manage support requests conversationally.

The following agentic workflow is available for Care Team Operations. Its full overview, including supported Care Team Operations plugins, is documented next to the case content it creates.

-   **Request care team assistance**

    Collects support request details conversationally over chat or by phone, then creates one or more care team cases for the appropriate service department. See [Care Team Operations AI Chat Assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-care-team-chat-assistant.md).


Agentic workflows and AI agents included with the base system ship inactive. Before care team members can use this workflow, an administrator must activate it and the agents it depends on. See [Configure agentic workflows for Care Team Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-otto-workflows-config.md).
