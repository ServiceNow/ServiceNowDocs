# Configure agentic workflows for Care Team Operations

Activate and configure the Request care team assistance agentic workflow and the AI agents it depends on, for both the chat and voice channels.

Role required: admin

Complete [Install ServiceNow Otto for Care Team Operations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-install.md) first. The sections below list the configuration steps for each channel of the Request care team assistance agentic workflow.

## Chat channel \(Care Team Operations AI Chat Assistant\)

The main task for this channel is [Activate the Care Team Operations AI Chat Assistant and agents](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-activate-cto-assistant.md), which activates the assistant, its AI agents, and the Request care team assistance workflow in one procedure. The other tasks in this list cover individual settings for the workflow.

1.  [Activate ServiceNow Otto for Virtual Agent for case intake](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-activte-agent.md)
2.  [Enable the Request care team assistance agentic workflow to create care team cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-enable-request-cto-assistance.md)
3.  [Activate the Care Team Operations AI Chat Assistant and agents](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-activate-cto-assistant.md)

For background on the assistant, see [Care Team Operations AI Chat Assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-care-team-chat-assistant.md).

## Voice channel \(AI voice agent\)

1.  [Activate the Care Team Operations Case Creation AI voice agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-activate-voice-agent.md)
2.  [Configure Care Team Operations Case Creation AI voice agent triggers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/healthcare-life-sciences/healthcare-operations-core/hco-now-assist-cto-voice-triggers.md)
