# Input Care team task details into the Care team activities playbook

Complete the **Care team task** playbook stage in the Care team activities playbook.

## Before you begin

Role required: sn\_cto.loc\_support\_agent and sn\_hco\_orc.plan\_author

## Procedure

1.  In the **Care team activities playbook**, navigate to the **Care team task** stage.

2.  Enter a **Task name**.

3.  Provide **Instructions** for the agent who will complete the task.

4.  Assign an **Owner** for the task.

5.  Describe the **Expected outcome** for the task.

6.  If needed, select an existing smart assessment or create a new one, and optionally define conditional execution rules so the assessment only appears when specified conditions are met.

    For more information, see [Smart assessments in Care Team Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/healthcare-life-sciences/ctwm-smart-assessments.md).

7.  If required, select **+Add** to add an additional task.

8.  Select **Continue**.
