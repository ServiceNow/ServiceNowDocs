# Edit a care team case in Care Team Mobile

Update the details of a care team case from your mobile device so that the case stays accurate as the work progresses.

## Before you begin

Role required: sn\_hco.care\_team\_member

## Procedure

1.  In Care Team Mobile, navigate to **Track requests** &gt; **Care team**.

2.  Select the care team case that you want to edit.

3.  Select **Edit**.

    The edit form opens with the case's current values filled in.

4.  Update any of the following fields as needed.

    -   **Short description**
    -   **Assigned to**
    -   **Description**
    -   **Priority**
    -   **Location**
    -   **Assignment group**
    -   **SLA due**
    **Note:** If you change the assignee, select an active member of the assignment group on the form. If you change both the assignment group and the assignee, the assignee is checked against the new group.

5.  Select **Submit**.


## Result

Your changes are saved to the case. If the assignee isn't an active member of the assignment group, the change is rejected with an error and the case isn't updated.
