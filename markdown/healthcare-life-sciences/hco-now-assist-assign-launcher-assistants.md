# Assign the chat launcher to a Care Team Mobile assistant

After creating the chat launcher button, assign it to your ServiceNow Otto chat and voice assistants in Assistant Designer.

## Before you begin

Role required: admin

-   Complete [Create a chat launcher button in Care Team Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/healthcare-life-sciences/hco-now-assist-create-launcher-button.md).

## Procedure

1.  Navigate to **Conversational Interfaces** &gt; **Assistant Designer**.

2.  Open your chat assistant.

3.  Go to **Settings** &gt; **Display Experiences** and select **Mobile Apps**.

4.  In the **Chat Launcher function** field, select the function you created in [Create a chat launcher button in Care Team Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/healthcare-life-sciences/hco-now-assist-create-launcher-button.md).

5.  Open the voice assistant you want to configure.

6.  Go to **Settings** &gt; **Communication Channels** &gt; **Mobile Channels**.

7.  Under the **Prominent action button**, select the button you created in [Create a chat launcher button in Care Team Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/healthcare-life-sciences/hco-now-assist-create-launcher-button.md).


## Result

The chat and voice assistants are now available from the prominent action button in the mobile app. For additional configuration, see [Integrate voice assistant with mobile app launcher](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/intelligent-experiences/integrate-voice-assistant-with-mobile-app-voice-launcher.md).
