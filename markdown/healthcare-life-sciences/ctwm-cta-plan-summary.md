# Review and publish a Care team activities task plan

Review then publish the task plan template created using the Care team activities playbook.

## Before you begin

Role required: sn\_cto.loc\_support\_agent and sn\_hco\_orc.plan\_author

## About this task

The Care team activities playbook reuses the same Plan Summary stage as the Operational rounding playbook, unmodified.

## Procedure

1.  In the **Care team activities playbook**, navigate to the **Plan Summary** stage.

2.  Review all playbook stages as needed:

    -   Select a panel to display all field inputs for that stage.
    -   Change information within a playbook stage by selecting **Edit**.
    -   Select **Save** to save your updates or select **Cancel** to cancel any changes made.
3.  Select **Publish** to publish your task plan template.


## Result

Your task plan template is now published. Care team cases and tasks will now begin to generate according to the schedule you configured.
