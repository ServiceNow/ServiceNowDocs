# Healthcare organizations and locations in Care Team Work Management

Care Team Work Management uses the same healthcare organization and healthcare location model as Healthcare Operations Core.

Healthcare organizations and healthcare locations aren't specific to Care Team Work Management. They're shared, foundational tables that Healthcare Operations Core owns and that every Healthcare Operations application, including Care Team Work Management, builds on.

For information about the healthcare organization and healthcare location data model and how to set them up, see [Organization and location relationships in Healthcare Operations Core](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/healthcare-life-sciences/healthcare-operations-core/hco-organization-location-relationships.md) in Healthcare Operations Core.
