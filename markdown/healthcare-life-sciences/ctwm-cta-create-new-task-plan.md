# Create a Care team activities task plan

Create a new task plan using the Care team activities playbook.

## Before you begin

Role required: sn\_cto.loc\_support\_agent and sn\_hco\_orc.plan\_author

## About this task

## Procedure

1.  Navigate to **CSM/FSM Configurable Workspace** &gt; **Task Plan Templates** &gt; **All Task Plans** &gt; **New**.

2.  In **Create new task plan**, select **Care Team Activities**.

3.  Select **Create plan**.

4.  Complete the playbook stages that follow.


## What to do next

[Input plan details into the Care team activities playbook](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/healthcare-life-sciences/ctwm-cta-plan-details.md)
