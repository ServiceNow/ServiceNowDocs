# Create a care team case request in Care Team Mobile

Create a care team case request from your mobile device so that the work is defined, prioritized, and routed to the right care team.

## Before you begin

Role required: sn\_cto.care\_team\_agent

## Procedure

1.  In Care Team Mobile, navigate to **Track requests** &gt; **Care team**.

2.  Select **Create a request**.

    The catalog list opens, showing only the Care Team Services catalog.

3.  Select the **Care Team Services** catalog, and then select **Care Team Work**.

4.  Fill in the fields on the form.

    |Field|Description|
    |-----|-----------|
    |**Requesting service organization**|Service organization making the request.|
    |**Assignment group**|Group to assign the case to.|
    |**Assigned to**|Care team agent to assign the case to.|
    |**Description**|Description of the work needed.|
    |**Priority**|Priority of the case.|
    |**Window start**|Start of the time window for the work.|
    |**Window end**|End of the time window for the work.|
    |**Apply request details**|Option to apply the request details to the tasks and work orders created for the case.|

5.  Select **Submit**.


## Result

A care team case is created, and care team tasks are generated for the case from the care team task plan template. A confirmation message appears after the case is created which will list the care team case record number.
