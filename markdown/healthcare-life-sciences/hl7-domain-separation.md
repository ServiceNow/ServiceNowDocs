# HL7 v2.x Integration and domain separation

HL7 v2.x Integration does not support domain separation.

HL7 v2.x Integration does not support domain separation. The application receives and stores inbound HL7 v2.x messages in the global domain. Message log records created by the integration are visible to all domains on instances where domain separation is enabled.
