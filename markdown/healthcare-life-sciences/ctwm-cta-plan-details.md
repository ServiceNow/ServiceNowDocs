# Input plan details into the Care team activities playbook

Complete the **Plan details** form shown when you create a task plan using the Care team activities playbook.

## Before you begin

Role required: sn\_cto.loc\_support\_agent and sn\_hco\_orc.plan\_author

## About this task

This form appears automatically when you create a new task plan using the Care team activities playbook, before the first playbook stage.

## Procedure

1.  Provide a **Short description**.

    For example, **Daily unit safety check**.

2.  Set the **Priority**.

3.  Enter a detailed **Description**.

4.  Select **Save &amp; continue**.
