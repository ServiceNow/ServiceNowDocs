# Edit a care team task in Care Team Mobile

Update the details of a care team task from your mobile device so that you can keep work current without returning to a desktop.

## Before you begin

Role required: sn\_hco.care\_team\_member

## Procedure

1.  In Care Team Mobile, navigate to **Track requests** &gt; **Care team**.

2.  Select the care team case that contains the task.

3.  Select the **Tasks** tab, and then select the care team task.

    The task details open, including its assignment, description, priority, location, time window, SLA, and related work order and case details.

4.  Select **Edit**.

    The edit form opens with the task's current values filled in.

5.  Update any of the following fields as needed.

    -   **Short description**
    -   **Assigned to**
    -   **Description**
    -   **Priority**
    -   **Location**
    -   **Assignment group**
    -   **SLA due**
    Work order details, case details, the time window, and **Opened by** are shown on the task but can't be edited.

    **Note:** If you change the assignee, select an active member of the assignment group on the form. If you change both the assignment group and the assignee, the assignee is checked against the new group. Clearing the **Assigned to** field unassigns the task.

6.  Select **Submit**.


## Result

Your changes are saved to the task. If the assignee isn't an active member of the assignment group, the change is rejected with an error and the task isn't updated.
