# Schedule the Early Warning for Security Exposure Management integrations

You can schedule the integration import times on the records in the Vulnerability Integrations \[sn\_vul\_int\_fw\_integration\] table and launch them on-demand.

## Before you begin

Role required: sn\_vul\_int\_fw.configure\_integrations

## Procedure

1.  Navigate to **All** and enter sn\_vul\_int\_fw\_integration.LIST in the Filter Navigator.

2.  In the **Vulnerability Integrations** list, select **Early Warning Integration for Security Exposure Management**.

3.  Set how often, when you want to run the integration, and any conditions you want on **Schedule** tab.

4.  Select **Update** to save your changes.

5.  Select **Execute Now** to run the integration on-demand.
