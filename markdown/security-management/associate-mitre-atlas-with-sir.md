# Associate MITRE ATLAS information with security incidents

Associate MITRE ATLAS tactics and techniques with a security incident for better security incident and threat analysis.

## Before you begin

Role required: sn\_si.analyst

## Procedure

1.  Navigate to **All** &gt; **Security Incidents** &gt; **Show All Incidents**.

2.  Select the security incident to enrich with MITRE ATLAS information.

3.  Select the **Associate MITRE Technique** related link.

    The Associate MITRE Technique pane appears.\[Omitted image "mitre-atlas-assoc-technique.png"\] Alt text: Screenshot showing the Associate MITRE Technique pane with Source, Tactic, and Techniques fields

4.  Select **Source**.

    **Note:** If the MITRE ATLAS collection is activated, it appears in the source list alongside MITRE-ATT&amp;CK sources.

5.  Select the **Tactic** and **Techniques**.

6.  Review the information based on relevance and remove sources, tactics, or techniques as needed.

7.  Select **Save**.


## Result

The MITRE ATLAS information is associated with the security incident. You can now view the associated information in the MITRE-ATT&amp;CK Card.
