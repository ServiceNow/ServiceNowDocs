# Using Fix Intelligence for Security Exposure Management

Review the remediation actions available in your instance. Prioritize work by the risk each fix removes, and move between a fix and the findings and assets it resolves.

## Overview of using Fix records

After Fix Intelligence for SEM is installed and configured, use the following capabilities to work with the fixes it ingests.

-   [Understanding Fix records](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/understanding-fix-records.md)

    Learn what a Fix record represents and how to interpret its key fields.

-   [View fixes in USEM Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/view-fixes-in-workspace.md)

    View the fixes Fix Intelligence for SEM has ingested, along with the findings and assets each one resolves, in Unified Security Exposure Management Workspace.

-   [Group findings by fix](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/group-findings-by-fix.md)

    Group the findings that share a fix into a single remediation task.

-   [Fix links on findings and vulnerabilities](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/fix-links-on-findings.md)

    See which fix resolves a finding directly from the finding or vulnerable item.


-   **[View fixes in USEM Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/view-fixes-in-workspace.md)**  
Review the fixes that Fix Intelligence for SEM has identified, and see the findings and assets each one resolves. A Fix record represents a single remediation action that resolves one or more findings.
-   **[Group findings by fix](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/group-findings-by-fix.md)**  
Use a remediation task rule to group the findings that share a fix, so your team can remediate them together as a single unit of work.
-   **[Fix links on findings and vulnerabilities](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/security-management/fix-links-on-findings.md)**  
Fix Intelligence for SEM adds a read-only Fix reference to vulnerable items and vulnerabilities, so you can see which fix resolves a given finding directly from the finding.
