# Review the MITRE ATLAS system properties

Review the MITRE ATLAS system property values to configure how ATLAS information is handled in security incidents.

## Before you begin

Role required: sn\_ti.admin, sn\_si.admin

## Procedure

1.  Navigate to **All** &gt; **Threat Intelligence** &gt; **MITRE ATLAS Repository** &gt; **Properties**.

2.  On the form, fill in the fields.
