# Set up requirements for Early Warning for Security Exposure Management

Complete the following setup steps in your Armis Intelligence Center console environment before you configure Early Warning for Security Exposure Management in your ServiceNow AI Platform® instance.

## Before you begin

Role required: Armis Intelligence Center console account and credentials

## Procedure

1.  Navigate to the Armis Intelligence Center console - [https://ic.armis.com/manage/login](https://ic.armis.com/manage/login).

2.  Enter your email address.

3.  Select **Send login link**.

4.  Check your email inbox for a login link from Armis.

5.  Select the login link in your email to authenticate and log in to the Armis Intelligence Center console.

6.  Navigate to the API Credentials section.

7.  In the Value column, select the eye icon to reveal the API key.

8.  Copy the API key to a secure location.

    These credentials are required when you configure Early Warning for Security Exposure Management in your ServiceNow AI Platform® instance.

    **Note:** The API URL is static for your environment and does not change between sessions. This value is organization-specific.
