# MITRE ATLAS information in the MITRE Card

The MITRE Card displays MITRE ATLAS technique information that has been aggregated from threat lookups, observables, or SIEM integrations associated with a security incident.

The system aggregates information from threat lookups, observables, or SIEM integrations and adds it to the security incident. The MITRE Card then displays this aggregated information.

The **MITRE Card** provides two views:

-   Navigator view: Shows all techniques that have been manually added or rolled up from the observable or threat lookup tables.
-   List view: Shows data in list or table format.

The MITRE Card displays MITRE ATLAS technique links in a separate tab alongside MITRE-ATT&amp;CK technique links. Each technique link opens its corresponding record from either the ATLAS or ATT&amp;CK framework.
