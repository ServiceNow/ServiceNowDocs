# Exploring Now Assist for Threat Intelligence Security Center

Threat analysts and security operations teams can use ServiceNow generative AI skills to summarize case management content and generate threat intelligence case reports with Now Assist for Threat Intelligence Security Center.

## Now Assist for Threat Intelligence Security Center overview

With generative AI skills, your threat analysts and security operations teams can summarize threat cases and generate case reports quickly in a concise, easy-to-read format.

## Benefits

Now Assist for Threat Intelligence Security Center provides the following benefits:

-   **Improved case context** — Summarize threat case details so analysts can quickly understand the scope and status of the cases.
-   **Accelerated reporting** — Generate threat intelligence reports directly from case data, reducing manual documentation time and ensuring consistent report structure.

## User roles

The following user roles interact with Now Assist for Threat Intelligence Security Center:

-   **Threat analyst** — Generates and reviews case summaries and threat intelligence case reports.
-   **Administrator** — Configures and activates Now Assist for Threat Intelligence Security Center skills in the Now Assist Admin console.
