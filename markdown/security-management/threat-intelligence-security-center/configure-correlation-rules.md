# Configure correlation rules

Enable or disable the Correlation rules or customize them according to your business requirements.

## Before you begin

Role required: sn\_sec\_tisc.admin

## About this task

The correlation rules that generate potential relationships are disabled by default. Enable the required rules.

## Procedure

1.  Select **All**.

2.  In the navigation filter, enter `sn_sec_tisc_correlation_rules.list` and press Enter.

    The Correlation rules list opens.

3.  To enable a rule, set **Active** to `true`.

4.  Open a rule to modify it.

5.  Select **Update**.
