# Roll up of MITRE Techniques from Artifacts to Case

When intelligence records are added to a case, all associated MITRE Techniques are automatically rolled up to the case level.

## Before you begin

Role required: admin

## About this task

Only the associations that come from tactic and technique pairs that MITRE currently maps are rolled up to the case. A pair that MITRE has stopped mapping is excluded from the roll-up and from the technique counts on the case. For more information, see [Review revoked MITRE tactic and technique associations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/security-management/threat-intelligence-security-center/tisc-review-revoked-mitre-associations.md).

## Procedure

1.  Navigate to **Workspaces** &gt; **Threat Intelligence Security Center**.

2.  Click the **Threat Analyst Workbench** icon.

3.  Go to **Case Management** &gt; **All Cases**.

    All the cases are displayed.

4.  Select any case.

5.  Go to **Artifacts** tab.

    The associated artifacts are displayed as the related lists for that specific case.
