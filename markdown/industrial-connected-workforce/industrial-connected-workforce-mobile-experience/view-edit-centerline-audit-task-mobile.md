# View and edit a centerline audit task

View and edit the details of a centerline audit task before you start it to ensure the correct material and assignment information is set.

## Before you begin

The centerline audit task must be in the **Ready** state to edit its details. After the task has been started, the **Active material** field becomes read-only.

Role required: sn\_icw\_ctl.user

## Procedure

1.  Navigate to the **Tasks** tab.

2.  Select the tab that contains the centerline audit task.

    -   **My Tasks**
    -   **Area Tasks**
    -   **Upcoming**
    -   **Done**
3.  Select the centerline audit task tile to open it.

4.  On the **Details** tab, review the task information.

    The **Details** tab shows the **Short description**, **Description**, **Assigned to**, **Due date**, and **Active material** fields, along with the task type label, priority pill, and state pill.

5.  Select **Edit** to change any task details.

    The edit form exposes the following fields:

    |Field|Description|
    |-----|-----------|
    |**Short description**|Brief description of the centerline audit task.|
    |**Description**|Full description of the centerline audit task.|
    |**Assigned to**|User responsible for executing the task.|
    |**Due date**|Date and time by which the task must be completed.|
    |**Active material**|Material against which the centerline standard is audited. If the material was predefined in the standard configuration, it is automatically populated. This field is editable only before the task is started.|

6.  Make your changes and select **Save**.


## Result

The task details are updated. When the **Active material** field is filled in, the **Edit** and **Start** actions appear on the task.

## What to do next

To start executing the centerline audit, select **Start**.
