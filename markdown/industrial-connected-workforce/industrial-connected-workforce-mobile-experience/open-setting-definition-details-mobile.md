# Open setting definition details during a centerline audit

View the full specification for a setting definition during centerline audit execution without leaving the audit.

## Before you begin

Role required: sn\_icw\_ctl.user

You must have an active centerline audit task open and be on the execution screen. For more information, see [Execute a centerline audit task](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/industrial-connected-workforce-mobile-experience/execute-centerline-audit-task-mobile.md).

## Procedure

1.  On the parameter card for the setting you want to inspect, tap the three-dot menu \(**...**\).

    An action sheet opens.

2.  Select **Open details**.

    The setting definition detail screen opens.

3.  Select the **Articles** tab to view related knowledge articles.


## Result

The setting definition detail screen is a read-only view showing the following information about the setting:

-   State badge \(for example, **Updated**\)
-   Category
-   Record type label: **Setting definition**
-   Name
-   Equipment
-   Location
-   Short description
-   Full description
-   Unit of measurement
-   Setting frequency

## What to do next

Select the **Back** button to return to the execution screen and continue entering parameter values.
