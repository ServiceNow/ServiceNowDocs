# Execute a work set task

Execute the sub-activities of a work set task from a single list in the Industrial Connected Workforce Mobile Experience, without navigating to a related list.

## Before you begin

Role required: sn\_icw\_std.work\_set\_user

## About this task

When you open a work set task, the **Tasks** tab opens first. It lists all the sub-activities of the work set task in execution order, including the following task types:

-   Industrial Guided Tasks
-   Actions
-   Centerline tasks
-   Deviations
-   Root cause analysis \(RCAs\)

## Procedure

1.  Navigate to the **Tasks** tab.

2.  Select the tab that contains the work set task.

    -   **My Tasks**
    -   **Area Tasks**
    -   **Upcoming**
    -   **Done**
3.  Select the work set task tile to open it.

    The work set task opens on the **Tasks** tab. To view the details of the work set task itself, select the **Details** tab.

4.  Review the sub-activities in the list.

    Each card shows the following information for a sub-activity:

    -   Short description
    -   Task type
    -   State
    -   Assigned to
    -   Equipment, or the functional location if no equipment is set
    -   Planned start
    -   Line status and LOTO\(TO\) level, when they have values
    When a sub-activity is no longer active, its card shows only the state, short description, task type, and equipment or functional location.

5.  Select a sub-activity card to open the sub-activity and execute it.

    For more information about executing each type of sub-activity, see [Execute an Industrial Guided Task with the Industrial Connected Workforce Mobile Experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/industrial-connected-workforce-mobile-experience/execute-igt-icw-mobile.md) and [Execute a centerline audit task](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/industrial-connected-workforce-mobile-experience/execute-centerline-audit-task-mobile.md).
