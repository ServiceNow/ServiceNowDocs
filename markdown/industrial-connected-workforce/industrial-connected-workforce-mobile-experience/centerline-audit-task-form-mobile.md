# Centerline audit task form

Use this reference to identify the fields on the centerline audit task form in the Industrial Connected Workforce Mobile Experience.

|Field|Description|
|-----|-----------|
|**Short description**|Brief description of the centerline audit task.|
|**Description**|Full description of the centerline audit task.|
|**Assigned to**|User responsible for executing the task.|
|**Due date**|Date and time by which the task must be completed.|
|**Active material**|Material against which the centerline standard is audited. If the material was predefined in the standard configuration, this field is automatically set to the value defined in the standard configuration. The field is editable before the task is started.|
|**State**|Current state of the task. Displayed as a pill on the task details screen. Possible values are: **Ready**, **Work in progress**, **Submitted**, and **Closed complete**.|
|**Priority**|Priority of the task. Displayed as a pill on the task details screen.|
|**Functional location**|Industrial facility work area for the task. Inherited from the operator's worker profile and the centerline standard.|
|**Equipment**|Equipment associated with the centerline audit. Inherited from the centerline standard.|

## Task tabs

The centerline audit task screen includes the following tabs:

-   **__Details__**

    Shows the task fields described in the preceding table.

-   **__Activity__**

    Shows comments, work notes, and attachments associated with the task.

-   **__Recommendations__**

    Shows recommended actions associated with the task.

-   **__Related__**

    Shows tasks and deviations related to this centerline audit task, including any deviations automatically created for non-compliant parameters.
