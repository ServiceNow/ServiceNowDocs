# Centerline tasks in the Digital Factory Workspace

Centerline tasks appear in a dedicated list view in the Digital Factory Workspace, where authorized users can view, filter, and manage task records generated from centerline standards.

## Centerline task list

Centerline tasks are displayed in a dedicated list category in the Digital Factory Workspace. The list shows tasks generated from centerline standards and follows the same filtering and ordering behavior as for other types of tasks, such as Industrial Guided Tasks.

From the list view, users with the appropriate role can filter tasks, edit task data fields, and assign a task to themselves using the **Assign to me** action.

**Note:**

Access to the centerline task list is restricted to users with the appropriate role. Users with the sn\_icw\_cl.user role can create, read, and update active centerline tasks.

## Centerline task record

The centerline task record page displays all task details and follows the same layout and behavior as other types of tasks, such as Industrial Guided Task records. From the record page, authorized users can view task details, edit task data fields based on their role, and view related tasks.

**Note:**

Centerline tasks are executed on mobile. Editing from the Digital Factory Workspace is limited to specific task-related fields.
