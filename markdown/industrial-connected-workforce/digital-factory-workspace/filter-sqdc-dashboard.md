# Filter an SQDC Analytics dashboard by period

Use the period selector at the top of the Overview or Delivery dashboard to refresh KPIs and visualizations for a specific shift, day, or production week.

## Before you begin

You have an SQDC Analytics dashboard open on a functional location record.

Role required: sn\_icw\_report.user

## About this task

The period selector controls the date range for every indicator, chart, and visualization on the dashboard. When you change the period, all KPI cards refresh to reflect the selected range. The same period selector behavior applies to both the Overview and Delivery dashboards.

## Procedure

1.  Locate the period selector at the top of the Overview or Delivery dashboard.

    The default selection is **Current production shift**.

2.  Select the period selector and choose a period from the list.

    The available periods include the following:

    -   Current production shift: Data from the active shift.
    -   Last shift: Data from the previous shift.
    -   Production day: Data aggregated for the current production day.
    -   Production week: Data aggregated for the current production week.
    All KPI cards and visualizations refresh to reflect the selected period. Time-series charts adjust the trend axis to match the period range.

3.  Review the refreshed data on the dashboard.

    Use the filtered view to compare performance across shifts, identify peak loss periods, or align findings with cadence meeting cycles.
