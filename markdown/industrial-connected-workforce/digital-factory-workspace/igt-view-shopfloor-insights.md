# View shopfloor insights for a manufacturing standard

Access the embedded shopfloor insights dashboard on an IGT standard record to analyze execution performance and identify improvement opportunities.

## Before you begin

-   A worker profile is configured with a functional location assigned.

Role required: sn\_icw\_igt.user

## About this task

The Insights Overview tab provides embedded analytics for each published IGT standard. The dashboard displays key performance indicators, trend charts, and follow-up task summaries based on execution data. Use this information to compare execution across shifts, track improvement progress, and identify areas requiring attention.

## Procedure

1.  Navigate to **Workspaces** &gt; **Digital Factory Workspace** &gt; **Select the Standards hub menu \[Omitted image "icw-standards-hub-icon.png"\] Alt text:**.

2.  Locate and open the IGT standard you want to analyze.

    Use the search or filter options to find the standard. Select the standard tile to open the standard record.

3.  Select the **Overview** tab.

    The embedded dashboard displays execution analytics for the standard. The dashboard includes:

    -   Single-score indicators for key metrics such as completion rate and average score
    -   Trend charts showing execution patterns over time
    The shopfloor insights dashboard loads with data based on the default filters and displays all tasks related to the standard.

4.  Review the dashboard indicators and visualizations.

    Analyze the following areas:

    -   Completion metrics: Review the IGT completion rate and completion in time rate to understand task performance.
    -   Execution trends: Examine the IGT execution by state chart to identify bottlenecks or patterns.
    -   Follow-up tasks: Check the actions and deviations created to identify recurring issues.
    -   Average score: If scoring is enabled, review the average score trend to track quality performance.
5.  Adjust the filters to refine the data displayed.

    Use the filter options to narrow the scope of the insights:

    -   Functional location: Select a specific location or include child locations in the hierarchy.
    -   Equipment: Filter by specific equipment.
    -   Date filter: Adjust the time period for analysis.
    For more information, see [Filter shopfloor insights data](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/igt-filter-shopfloor-insights.md).

6.  Drill down into follow-up tasks for more details.

    Select a visualization to open the related list of tasks. This enables you to view individual action or deviation records and investigate specific issues.
