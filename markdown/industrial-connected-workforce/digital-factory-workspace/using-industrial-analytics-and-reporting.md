# Using Industrial Analytics and Reporting

View and filter the SQDC Analytics dashboards and shopfloor insights to monitor operational performance in the Digital Factory Workspace.

## Tasks overview

Use the following tasks to open, navigate, and filter the dashboards that Industrial Analytics and Reporting provides:

-   SQDC Analytics: Open a dashboard from the landing page, view the Overview and Delivery dashboards on a functional location record, and filter a dashboard by period.
-   Shopfloor insights: View execution analytics for a manufacturing standard and filter the data by functional location, equipment, and time period. For more information, see:
    -   [View shopfloor insights for a manufacturing standard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/igt-view-shopfloor-insights.md)
    -   [Filter shopfloor insights data](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/igt-filter-shopfloor-insights.md)

-   **[Open your SQDC Analytics dashboard from the landing page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/navigate-sqdc-dashboard.md)**  
Use the My work area action on the Industrial Connected Workforce \(ICW\) landing page to open the SQDC Analytics Overview dashboard for your assigned functional location.
-   **[View the SQDC Analytics Overview dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/view-sqdc-overview-dashboard.md)**  
Open the Overview dashboard on a functional location record to review Overall Equipment Effectiveness \(OEE\), safety incidents, standard task completion, Planned vs. Actual production, and loss analysis.
-   **[View the SQDC Analytics Delivery dashboard](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/view-sqdc-delivery-dashboard.md)**  
Open the Delivery dashboard on a functional location record to track IGT and CIL completion, action SLAs, deviations, downtime, breakdowns, waste, and root cause analysis aging.
-   **[Filter an SQDC Analytics dashboard by period](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/filter-sqdc-dashboard.md)**  
Use the period selector at the top of the Overview or Delivery dashboard to refresh KPIs and visualizations for a specific shift, day, or production week.
