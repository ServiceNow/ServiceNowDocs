# Open your SQDC Analytics dashboard from the landing page

Use the My work area action on the Industrial Connected Workforce \(ICW\) landing page to open the SQDC Analytics Overview dashboard for your assigned functional location.

## Before you begin

A worker profile is configured for your user with an assigned functional location.

Role required: sn\_icw\_report.user

## About this task

The My work area action retrieves the functional location assigned to your worker profile and opens the SQDC Analytics Overview dashboard for that location. You don't have to navigate the equipment hierarchy each time you check line performance.

## Procedure

1.  Navigate to **Workspaces** &gt; **Digital Factory Workspace**.

2.  On the landing page, select **My work area**.

    The system retrieves the functional location assigned to your worker profile and opens the Overview dashboard for that location.

    **Note:** If you're not assigned a worker profile, or if no functional location is assigned to your worker profile, an error message is displayed. Contact your administrator to assign a functional location.

    The Overview dashboard appears with KPI cards and visualizations preloaded for your functional location.

3.  To switch to the Delivery dashboard, select the **Delivery** tab from the left sidebar.
