# Centerline standard form

Field descriptions for the centerline standard form.

<table id="table-centerline-standard-form"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Number

</td><td>

System-generated unique number for the standard.

</td></tr><tr><td>

State

</td><td>

Current state of the standard. A new standard is set to Draft. Options are:-   Draft
-   Review
-   Published
-   Retired
-   Revised

</td></tr><tr><td>

Category

</td><td>

Category that the standard belongs to.

</td></tr><tr><td>

Allow ad-hoc request

</td><td>

When selected, you can initiate tasks directly from the Standards hub.

</td></tr><tr><td>

Short description

</td><td>

Short description or title for the standard.

</td></tr><tr><td>

Query

</td><td>

Conditions that filter the setting definitions available for the standard. Select **Set conditions** to build the query.

</td></tr><tr><td>

Setting definition

</td><td>

Setting definitions that operators confirm when they execute the standard. Only setting definitions that match the query are available to select.

</td></tr><tr><td>

Owner group

</td><td>

Group of users who own the standard.

</td></tr><tr><td>

Author

</td><td>

Name of the user who creates the standard. This field is automatically set when the standard is created and can be edited.

</td></tr><tr><td>

Document scope

</td><td>

Specifies whether the standard applies to a single site or across all sites. Options are:-   Local
-   Global

</td></tr><tr><td>

CMDB assignment type

</td><td>

Type of configuration item that the standard is assigned to. Options are:-   Equipment models
-   Specific equipment
-   Functional location

</td></tr><tr><td>

Location

</td><td>

Factory that the standard is used for.

</td></tr><tr><td>

Functional locations

</td><td>

Work areas where the standard is executed.

</td></tr><tr><td>

Material classifications

</td><td>

Groups of materials based on their properties and applications that the standard applies to.

</td></tr><tr><td>

Equipment models

</td><td>

Group of equipment items that the standard applies to. This field is required if the CMDB assignment type is set to **Equipment models**.

</td></tr><tr><td>

Equipment

</td><td>

Piece of equipment or machinery that the standard applies to. This field appears if the CMDB assignment type is set to **Specific equipment**.

</td></tr><tr><td>

Material models

</td><td>

Categories of finished goods based on the materials they are made from that the standard applies to.

</td></tr><tr><td>

LOTO level

</td><td>

Lockout/Tagout safety procedure level required to perform the task. Options are:-   None
-   LOTO Level 0
-   LOTO Level 1
-   LOTO Level 2
-   LOTO Level 3

</td></tr><tr><td>

Line status

</td><td>

Status that the production line must be in to perform the task. Options are:-   None
-   Running
-   Stopped

</td></tr><tr><td>

Required skills

</td><td>

Skills required for task eligibility. Only operators with these skills can perform the task.

</td></tr><tr><td>

Knowledge article

</td><td>

Knowledge article that provides more information about the standard for the operator who executes the task.

</td></tr><tr><td>

Attachments

</td><td>

Files that support the standard. The maximum file size is 1024 MB.

</td></tr></tbody>
