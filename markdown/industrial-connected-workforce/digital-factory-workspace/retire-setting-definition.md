# Retire a setting definition

Retire a published setting definition when it is no longer valid for use in centerline tasks.

## Before you begin

The setting definition must be in the **Published** state. Setting definitions in the **Draft** state cannot be retired.

Role required: sn\_icw\_ctl.config or sn\_icw\_ctl.admin

## Procedure

1.  Navigate to the equipment record and select the **Settings** tab.

2.  Select the setting definition to retire.

3.  Select **Retire**.

    A confirmation dialog appears.

4.  Select **Yes** to confirm.


## Result

The setting definition state changes to **Retired**.
