# Create a setting plan

Create a setting plan to group setting specifications for a piece of operational equipment and define the standard values used during centerline task execution.

## Before you begin

Role required: Industrial Centerlines config \[sn\_icw\_ctl.config\] or Industrial Centerlines admin \[sn\_icw\_ctl.admin\]

## Procedure

1.  Navigate to the equipment record

2.  Select the **Settings Plans** tab.

3.  Open the equipment record.

4.  Select **New**.

5.  In the **Equipment** field, confirm that the equipment information is pre-filled.

    When you navigate to the form from an equipment record, the **Equipment** field is pre-filled with the information for that piece of equipment.

6.  Complete the required fields on the form.

7.  Select **Save**.


## Result

The setting plan record is created. You can update the record or add setting specifications to the plan.
