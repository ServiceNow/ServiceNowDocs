# Duplicate a setting specification

Duplicate an existing setting specification to create an independent copy with all field values carried over, so you can reuse its configuration without re-entering all values.

## Before you begin

Role required: Industrial Centerlines config \[sn\_icw\_ctl.config\] or Industrial Centerlines admin \[sn\_icw\_ctl.admin\]

## About this task

Use this procedure when you need to create multiple setting specifications with similar values. Duplicating an existing specification is faster than creating each one individually. After duplicating, update the values in each copy as needed.

## Procedure

1.  Navigate to the setting plan record.

2.  Select the **Settings Specifications** related list.

3.  Select the setting specification that you want to duplicate.

4.  Select **Duplicate specification**.


## Result

A copy of the setting specification is created with all field values carried over from the original.

## What to do next

**Note:**

Unlike setting definitions, duplicated setting specifications are not prefixed with a label. Update the values in the duplicate after creating it to distinguish it from the original.
