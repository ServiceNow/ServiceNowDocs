# Centerline task form

Field descriptions for the centerline task form, including priority options, assignment, location, and scheduling fields.

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Number

</td><td>

System-generated unique number for the task.

</td></tr><tr><td>

Priority

</td><td>

Options are:-   1 - Direct
-   2 - This shift
-   3 - Today
-   4 - Within 7 days
-   5 - Within 30 days
-   6 - Unplanned

Short description

</td><td>

Description

</td><td>

Additional information about the task.

</td></tr><tr><td>

Assignment group

</td><td>

Group of users that the task can be assigned to.

</td></tr><tr><td>

Assigned to

</td><td>

User that the task is assigned to.

</td></tr><tr><td>

Active material

</td><td>

Material that the task applies to.

</td></tr><tr><td>

Functional location

</td><td>

Industrial facility work area where the task is to be completed.

</td></tr><tr><td>

Equipment

</td><td>

Machine to which the task relates.

</td></tr><tr><td>

Due date

</td><td>

Date by which the task is to be executed.

</td></tr><tr><td>

Planned start

</td><td>

Planned start of the task execution.

</td></tr><tr><td>

Planned end

</td><td>
