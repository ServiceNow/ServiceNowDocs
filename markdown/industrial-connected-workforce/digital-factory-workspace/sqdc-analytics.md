# SQDC Analytics

SQDC Analytics provides inline dashboards that track safety, quality, delivery, and cost performance for a functional location, directly within the Digital Factory Workspace.

## SQDC Analytics overview

SQDC \(Safety, Quality, Delivery, Cost\) is a management framework used to track and improve operational performance across the four critical factors in a manufacturing environment. SQDC Analytics embeds this framework in the Digital Factory Workspace as two inline dashboards on the functional location record page:

-   Overview dashboard
-   Delivery dashboard

As a field worker you can use the dashboards to monitor, analyze, and act on key performance indicators without leaving their current operational workflows. This approach enables you to switch between applications during shift handovers, daily reviews, and cadence meetings.

## Dashboards available

SQDC Analytics provides two dashboards for each functional location.

|Dashboard|Description|
|---------|-----------|
|Overview|Displays high-level performance for the functional location, including OEE, safety incidents, standard task completion, planned vs. actual production, and loss analysis.|
|Delivery|Displays operational performance for delivery activities, including Industrial Guided Task \(IGT\) completion, CIL completion, action SLAs, deviation trends, downtime, breakdowns, waste, and root cause analysis aging.|

## SQDC Analytics personas

SQDC Analytics supports the following operational roles.

|Persona|Typical use|
|-------|-----------|
|Line manager|Reviews operational performance for a line during daily cadence meetings and adjusts resource allocation.|
|Production manager|Tracks OEE, safety incidents, and production attainment against targets across shifts.|
|Operations supervisor|Monitors task completion, deviations, and action SLAs to maintain pre-production quality checks according to schedule.|
|Plant manager and quality lead|Drives continuous improvement based on loss analysis, breakdown aging, and root cause analysis aging.|

## Data aggregation and filtering

Each dashboard aggregates data according to the period selected at the top of the page. The default period is the current production shift. Available period selections include the current shift, the previous shift, the current production day, and the production week.

When you change the period, all indicators, charts, and visualizations on the dashboard refresh to reflect the new range. The selected period also drives the time-series trend in stacked column and combo charts.

## SQDC Analytics benefits

|Benefit|Feature|Users|
|-------|-------|-----|
|Monitor SQDC metrics in real-time without leaving the operational workspace.|Inline dashboard on functional location record|Line manager, production manager|
