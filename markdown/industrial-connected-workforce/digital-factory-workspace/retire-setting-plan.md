# Retire a setting plan

Retire a published setting plan when it is no longer valid for centerline tasks.

## Before you begin

Role required: Industrial Centerlines config \[sn\_icw\_ctl.config\] or Industrial Centerlines admin \[sn\_icw\_ctl.admin\]

The setting plan must be in the **Published** state. Setting plans in other states cannot be retired.

## Procedure

1.  Navigate to the equipment record.

2.  Select the **Settings Plans** tab.

3.  Select the setting plan to retire.

4.  Select **Retire**.

    A confirmation dialog appears.

5.  Select **Yes** to confirm.


## Result

The setting plan state changes to **Retired**.
