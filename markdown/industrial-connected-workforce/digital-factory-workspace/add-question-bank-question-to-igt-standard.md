# Add a question bank question to an IGT standard

Add a question from the question bank to a section in an IGT standard to reuse an existing question without recreating it.

## Before you begin

Role required: sn\_icw\_igt.standard\_author or sn\_icw\_igt.manager

The question that you want to add must be published in a question bank with the Industrial Guided Task purpose. The section to which you want to add the question must already exist in the standard.

## Procedure

1.  Open the IGT standard and navigate to the **Task authoring** tab.

2.  In the content tree, select the **Add questions from question bank** icon next to the section where you want to add the question from the question banks that apply to the standard..

3.  In the **Search for questions across all banks** field, enter a keyword to narrow the list.

4.  Select the checkbox for each question that you want to add.

5.  Select **View selected questions** to review your selection.

6.  Select **Add questions to template**.

    A message confirms that one or more questions from the question bank are added and asks you to refresh the page.

7.  Refresh the page.


## Result

The questions are added at the end of the selected section in the IGT standard. Each added question is an independent copy, so later changes to the question in the question bank don't affect the standard.

## What to do next

If some or all of the questions can't be added, an error message appears. Refresh the page and try again, and contact your administrator if the problem persists.
