# Configuring Industrial Centerlines

Industrial centerline configuration involves the setting definitions, setting plans, and setting specifications that centerline standards use.

## Configuration overview

-   [Create a setting definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/create-setting-definition.md)

    Define the equipment settings that operators confirm.

-   [Create a setting plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/create-setting-plan.md)

    Group setting definitions for equipment.

-   [Create a setting specification](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/create-setting-specification.md)

    Set the target values and ranges for each setting.


-   **[Industrial Centerlines standards and equipment settings](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/icw-centerlining-managing-equipments.md)**  
Manage Industrial Centerlines standards to define which equipment settings to verify and when. Define setting definitions, setting plans, and setting specifications to establish standard base conditions for operational equipment.
-   **[Create a setting definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/create-setting-definition.md)**  
Define configurable parameters on operational equipment, including type, value format, and classification properties, to support centerline task configuration.
-   **[Duplicate a setting definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/duplicate-setting-definition.md)**  
Create an independent copy of an existing setting definition to reuse its configuration without re-entering all values.
-   **[Retire a setting definition](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/retire-setting-definition.md)**  
Retire a published setting definition when it is no longer valid for use in centerline tasks.
-   **[Create a setting plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/create-setting-plan.md)**  
Create a setting plan to group setting specifications for a piece of operational equipment and define the standard values used during centerline task execution.
-   **[Duplicate a setting plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/duplicate-setting-plan.md)**  
Duplicate a setting plan to create a copy with all field values carried over, so you can reuse its configuration without re-entering all values.
-   **[Retire a setting plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/retire-setting-plan.md)**  
Retire a published setting plan when it is no longer valid for centerline tasks.
-   **[Create a setting specification](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/create-setting-specification.md)**  
Create a setting specification to define the target values and limits for a setting definition within a setting plan.
-   **[Duplicate a setting specification](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/industrial-connected-workforce/digital-factory-workspace/duplicate-setting-specification.md)**  
Duplicate an existing setting specification to create an independent copy with all field values carried over, so you can reuse its configuration without re-entering all values.
