# Impact Delivery Instance roles

IDI offers roles to fit your business needs. When you log in to IDI, you’ll see a personalized view of your objectives, metrics, and recommendations tied directly to your role.

<table id="table_o2s_fql_ntb"><thead><tr><th>

Role

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Impact User

</td><td>

-   Can access the Impact Delivery Instance.
-   Can create and update conversations.

</td></tr><tr><td>

Impact Permissions Authorizer

</td><td>

Allows users to grant permissions for IDI features that require consent.

</td></tr><tr><td>

Impact Executive

</td><td>

-   Has read access to view IDI status and value reporting.
-   Can create and update conversations.
-   Manages production adoption roadmap.

</td></tr><tr><td>

Impact Platform Owner

</td><td>

-   Has full access to all IDI features.
-   Can request Accelerators and advisory sessions
-   Can manage production adoption roadmaps.

</td></tr><tr><td>

Impact Admin

</td><td>

-   Manages user accounts and premium access to add-on packages.
-   Administers the ServiceNow platform.
-   Has full access to all IDI features.
