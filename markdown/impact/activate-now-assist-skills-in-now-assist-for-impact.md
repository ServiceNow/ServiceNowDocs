# Activate Now Assist Skills for Impact

Activate the Now Assist skill before you can use the generative AI capabilities for Impact.

## Before you begin

**Important:** The outcome summarization AI skill is turned on by default and is automatically available to assigned role users for the application. The skill is activated and does not affect roles that are needed to use the skill. The default behavior works as follows:

-   **New customers**

    When you install a ServiceNow AI product, designated skills are turned on automatically.

-   **Existing customers who are upgrading \(starting with Zurich Patch 4\)**

    Any previously unconfigured skill is turned on automatically.

    There is no change to AI skills that are currently enabled and customized.

    Previously configured skills that were turned on, then off, remain inactive.


Role required: Impact Platform owner, Impact Admin, Impact Portfolio Owner

## Procedure

1.  Navigate to **All** &gt; **Now Assist Admin** &gt; **Now Assist Skills**.

2.  On the **Now Assist Skills** tab, under the **Technology** workflow group, select **Impact**.

    **Note:** Now Assist skills must be installed before you can configure Impact Now Assist skills.

3.  To View details for a specific Now Assist Impact Skill, select **View details**.

    **Note:** For additional information on Now Assist Skills, see [AI Admin Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/platform-now-assist-landing.md) and [Activate an AI skill](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/configure-a-now-assist-skill.md).

4.  In the **All** section, select **Activate skill** to activate the desired skill.

5.  Review the details of the skills on each tab, configure the skills, and select **Save and continue**.

6.  Review your choices and select **Activate** to complete the configuration.

    A confirmation modal is displayed.

7.  Select **Activate** to complete the configuration or **Cancel** to revert.

    Your skill is configured.
