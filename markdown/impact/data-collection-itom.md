# Impact Value Management Data Collection Content Pack for IT Operations Management

Install and configure the Data Collection Content Pack for IT Operations Management.

Perform the steps in the following order:

1.  [Install the Data Collection Pack for IT Operations Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-install.md)
2.  [Configure Data Collection for IT Operations Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-config.md)
3.  [Activate Data Collection for IT Operations Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-activate.md)
4.  [Review IT Operations Management artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-install-artifacts.md)

You can also modify the configuration at any point, and maintain customizations when you are ready to upgrade. For more information, see [Upgrading the Data Collection Content Pack](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-all-upgrade.md) and [Modifying the Data Collection configuration](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-all-modify.md).

-   **[Install the Data Collection Pack for IT Operations Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-install.md)**  
To enable the Data Collection Pack, you must install dependent plugins and activate Data Collection jobs.
-   **[Configure Data Collection for IT Operations Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-config.md)**  
Configure Data Collection for IT Operations Management.
-   **[Activate Data Collection for IT Operations Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-activate.md)**  
Activate the Data Collection Pack for IT Operations Management after you enable and configure it.
-   **[Review IT Operations Management artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-itom-install-artifacts.md)**  
The Data Collection app contains a pre-build data metric structure for the ServiceNow Performance Analytics application and includes artifact types.
