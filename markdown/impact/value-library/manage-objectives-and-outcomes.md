# Manage objectives and outcomes

You can review objectives and outcomes tracking configuration, and access trend data, business context, relevant capabilities, and quarterly performance reviews.

## Before you begin

Role required: Impact App Admin, Impact Platform Owner, Impact Portfolio Owner.

## Procedure

1.  Navigate to **Impact** &gt; **Value Management** &gt; **Objectives and Outcomes**.

2.  On the **Manage objectives and outcomes** page, select the outcome you want to review.

    The page displays the child outcomes under the selected parent outcome.

3.  Select an outcome to open its details panel for editing.

    The outcome details panel on the right displays the following:

    |Field|Description|
    |-----|-----------|
    |**Tracking**|The parent objective the outcome belongs to.|
    |**Objective and Outcome**|The parent objective the outcome belongs to.|
    |**Outcome name**|The name of the outcome.|
    |**Reference quarter**|The quarter used as the baseline for measuring progress.|
    |**Reference value**|The baseline metric value at the reference quarter.|
    |**Goal %**|The target improvement expressed as a percentage.|
    |**Goal units**|The target improvement expressed in absolute units.|
    |**Outcome description**|A description of the outcome and its business context.|

4.  To view the outcome details page, select **View details** on the outcome panel.

    The outcome detail page opens with the following sections.

    -   **Monthly trend view**

        A trend chart displaying **Metric**, **Benchmark**, **Goal**, and **Trend** lines over time. A metric direction indicator shows whether the metric is moving in the intended direction. Use the trend period filter to set the view to **Monthly**.

    -   **About this outcome**

        Describes the business context of the outcome, including the outcome description, product, objective, driver, success metric, indicator, and value direction.

    -   **Capabilities**

        Lists the capabilities associated with the outcome, showing the capability name, product, and adoption status for each.

    -   **Operational performance reviews**

        Provides a quarterly performance summary including the reference value, current quarter data, quarter-over-quarter comparison, observations, and partner feedback.

5.  To summarize the Outcome section, select **Summarize this outcome**.

    ServiceNow Otto for Impact generates and displays summary information for the outcome.

    For more information on outcomes summarization, see [Summarize outcomes with ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/impact/value-library/gen-ai-based-outcome-summarizatio.md).

6.  To edit any details in the selected outcome, select **Edit**.
