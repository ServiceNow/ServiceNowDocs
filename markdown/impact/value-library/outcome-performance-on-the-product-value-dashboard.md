# View outcome performance on the product value dashboard

Use the product value dashboard to view tracked outcomes for a selected product. Each outcome appears as an individual card that displays the outcome name, a trend indicator, the current performance value, and a trend chart showing performance over time.

## Before you begin

Role required: admin

**Note:** Viewing outcome performance on the product value dashboard is currently available only for IT Service Management.

## Procedure

1.  Navigate to **All** &gt; **Impact** &gt; **Value Management** &gt; **Product Value**.

2.  To switch between your eligible products use the **Product** selector filter.

3.  To filter performance by month, quarter, or year use the **Trend period** filter.

    **Note:** The comparison baseline is the immediately preceding period. For example, a monthly view compares the current month to the previous month.

4.  To switch between operational metrics and monetized value use the **Realized value** filter.

    This filter updates each outcome card to show the estimated business value realized for that outcome over time.

5.  Narrow the outcomes displayed by objective or value driver using the **Quick filter**.

    If the selected product has no outcomes in a tracking state, a message appears in place of the outcome cards. To resolve this, turn on tracking for one or more outcomes.
