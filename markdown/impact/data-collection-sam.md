# Impact Value Management Data Collection Content Pack for IT Asset Management

Install and configure the Data Collection Content Pack for SAM.

Perform the steps in the following order:

1.  [Install the Data Collection Pack for IT Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-install.md)
2.  [Configure Data Collection for IT Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-config.md)
3.  [Activate Data Collection for IT Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-activate.md)
4.  [Review IT Asset Management artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-install-artifacts.md)

You can also modify the configuration at any point, and maintain customizations when you are ready to upgrade. For more information, see [Modifying the Data Collection configuration](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-all-modify.md) and [Upgrading the Data Collection Content Pack](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-all-upgrade.md).

-   **[Install the Data Collection Pack for IT Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-install.md)**  
To enable the Data Collection Pack, you must install dependent plugins and activate Data Collection jobs.
-   **[Configure Data Collection for IT Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-config.md)**  
Configure data collection for IT Asset Management so that Software Asset Management indicators report measured values rather than default values.
-   **[Activate Data Collection for IT Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-activate.md)**  
Activate the Data Collection Pack for IT Asset Management after you enable and configure it.
-   **[Review IT Asset Management artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-sam-install-artifacts.md)**  
The Data Collection app contains a pre-build data metric structure for the ServiceNow Performance/Platform Analytics application.
