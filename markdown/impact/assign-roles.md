# Assign roles

Assign users to the role groups that control access to Impact, Platform Health, and the Now Assist panel.

## Before you begin

**Important:** Navigation to reach these steps differs depending on whether you're using the [Impact Setup Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/use-impact-setup-hub.md) or the legacy [Guided Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/guided-setup-impact-in-app.md). See whichever one applies to you for the exact path.

See [Roles installed with Impact](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/impact-roles.md) for the roles installed with Impact.

Role required: impact app admin, admin

## Procedure

1.  On the **Assign Impact roles** page, select the checkbox next to each role you want to assign, then select **Assign users**.

2.  On the **Assign Platform Health roles** page, select the checkbox next to each role you want to assign, then select **Assign users**.

    Feature allocation and availability in Platform Health is based on role and group assignment. See [Track Platform Health trends](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/scan-engine-diagnostic-dashboards.md) for additional information.

    [Create a development team](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/create-development-team.md).

3.  On the **Assign Code Fix and Now Assist roles** page, select the checkbox next to each role you want to assign, then select **Assign users**.


## What to do next

If a role assignment changed, affected users must log out and log back in to your instance for the permissions to apply.

[Activate Scan Engine and review settings](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/configure-initial-scan-engine-settings.md)

-   **[Assign users to Platform Health groups](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/assign-users-scan-engine-groups.md)**  
In addition to assigning Impact users to groups, Platform Health users must also be part of a group for the Scan Engine feature.
-   **[Create a development team](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/create-development-team.md)**  
Each record represents a team and a development team lead. Scan Engine findings are reported for this team in the Analytics Dashboard.
