# Impact Value Management Data Collection Content Pack for Customer Service Management

Install and configure the Data Collection Content Pack for Customer Service Management.

**Important:** You should test system configuration changes in a sub-production environment before you deploy them into production.

Perform the steps in the following order:

1.  [Install the Data Collection Pack for Customer Service Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-install.md)
2.  [Configure Data Collection for Customer Service Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-config.md)
3.  [Activate Data Collection for Customer Service Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-activate.md)
4.  [Review Customer Service Management artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-install-artifacts.md)

You can also modify the configuration at any point, and maintain customizations when you are ready to upgrade. For more information, see [Modifying the Data Collection configuration](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-all-modify.md) and [Upgrading the Data Collection Content Pack](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-all-upgrade.md).

-   **[Install the Data Collection Pack for Customer Service Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-install.md)**  
To enable the Data Collection Pack, you must install dependent plugins and activate Data Collection jobs.
-   **[Configure Data Collection for Customer Service Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-config.md)**  
Configure Data Collection for Customer Service Management.
-   **[Activate Data Collection for Customer Service Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-activate.md)**  
Activate the Data Collection Pack for Customer Service Management after you enable and configure it.
-   **[Review Customer Service Management artifacts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-csm-install-artifacts.md)**  
The Data Collection app contains a pre-build data metric structure for the ServiceNow Performance/Platform Analytics application.
