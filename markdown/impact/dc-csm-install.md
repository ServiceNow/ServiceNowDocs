# Install the Data Collection Pack for Customer Service Management

To enable the Data Collection Pack, you must install dependent plugins and activate Data Collection jobs.

## Before you begin

The Customer Service Management Success Metric Definitions in this application rely on another application.Verify that the required plugins are installed if they are not already installed. For more information, see [Install Impact Value Management Data Collection Content Pack Apps dependent plugins](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-install-plugins.md).

Role required: Impact user

## Procedure

1.  Navigate to the Impact workspace on your instance.

2.  Navigate to **All** &gt; **Impact** &gt; **Configuration** &gt; **Value PA Data Collection Jobs**.

3.  Select **Value PA Data Collection jobs**.

4.  Search for and select the following:

    -   **Impact VM - Customer Service Management - Monthly Data Collection**
    -   **Impact VM - Customer Service Management - Historical Data Collection**
5.  If you're having trouble finding the data collection jobs, check whether the required data collection-dependent plugins are installed correctly.

    See [Install Impact Value Management Data Collection Content Pack Apps dependent plugins](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/dc-install-plugins.md).
