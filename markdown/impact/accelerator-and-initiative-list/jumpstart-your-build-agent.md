# Jumpstart Your Build Agent

This accelerator provides an overview and demonstration of the possibilities and capabilities of Build Agent and exploring how it generates complete applications.

## Accelerator Overview

Jumpstart Your Build Agent provides Impact customers with an overview and demonstration of Build Agent using a temporary instance. It helps explore its ability to generate complete applications—including 50+ metadata types across 14 domains, such as tables, flows, catalog items, roles, and more.

During this session, participants learn how to effectively prompt Build Agent, interpret its output, and leave with a clear plan to begin using it in their own environment. The engagement reduces uncertainty around adopting a new AI-powered development tool and accelerate time to first meaningful use. This offering also includes key resources and leading practice guides to help customers get started.

## Package Availability

**Note:** This Accelerator is available for Impact Guided, Guided+ \(SV or PG\), Advanced, and Total packages.

## What You Get

-   **Session Preparation**

    The Technical Accelerator Consultant:

    -   Provisions a temporary instance \(if applicable\)
    -   Activates and configures related plugins
-   **Customer Coaching Session \#1 \(up to 1.5 hours\)**

    Includes the following:

    -   Overview of Build Agent:
        -   Leading practices
        -   Vibe coding
    -   Demonstration of:
        -   Creating applications
        -   Working from Stories
        -   Assessing and updating existing code
-   **Customer Coaching Session \#2 \(Optional up on Customer request – up to 1 hour\)**

    Opportunity for Q&amp;A related to Build Agent.


## Outputs

-   30-day access to the temporary instance and Technical Accelerator Consultant with whom you met for any further questions or in-depth explorations
-   Copy of the Coaching Session Deck
