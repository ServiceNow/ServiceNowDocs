# Jumpstart Your Migration to ServiceNow Otto for Virtual Agent

This accelerator provides an overview and demonstration of migrating NLU-based Virtual Agent to ServiceNow Otto for Virtual Agent.

## Accelerator Overview

Jumpstart Your Migration to ServiceNow Otto for Virtual Agent provides Impact *ServiceNow Otto* customers with guided coaching to support the migration of an existing NLU-based Virtual Agent to *ServiceNow Otto* for Virtual Agent. This offering also includes key resources and leading practice guides to help customers get started.

Working in a copy of the customer's instance, this engagement begins by explaining the key architectural and functional differences between NLU-based and LLM-based Virtual Agent. It covers how intent recognition, topic design, and conversation handling differ between the two approaches so customers have a clear foundation before any migration work begins. From there, the engagement maps existing topic coverage to *ServiceNow Otto* for Virtual Agent equivalents and produces a structured migration plan that customers can confidently execute.

## Package Availability

**Note:** This Accelerator is available for Impact Guided, Guided+ \(SV or PG\), Advanced, and Total packages.

## Prerequisites

Customer must have an existing NLU Virtual Agent with live topics.

## What You Get

-   **Session Preparation**

    The Technical Accelerator Consultant:

    -   Provisions a temporary instance \(if applicable\)
    -   Activates and configures related plugins
-   **Customer Coaching Session \#1 \(up to 1.5 hours\)**

    Includes the following:

    -   Overview of NLU vs. ServiceNow Otto for Virtual Agent architecture differences
    -   Walkthrough of the NLU topic Migration Tool
    -   Demonstration of ServiceNow Otto for Virtual Agent topic structure and LLM-based conversational flow design
    -   Leading practice and redesign strategies
-   **Customer Coaching Session \#2 \(Optional up on Customer request – up to 1 hour\)**

    Opportunity for Q&amp;A related to migrating to ServiceNow Otto for Virtual Agent.


## Outputs

-   30-day access to the temporary instance and Technical Accelerator Consultant with whom you met for any further questions or in-depth explorations
-   Copy of the Coaching Session Deck
