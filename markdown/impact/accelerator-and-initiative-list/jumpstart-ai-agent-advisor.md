# Jumpstart Your AI Agent Advisor

This accelerator provides an overview and demonstration of ServiceNow's AI Agent Advisor \(AAA.

## Accelerator Overview

This accelerator discovers automation opportunities in your instance and match them to prebuilt or custom AI tooling. It shows customer admins how to put AAA to work on their existing task data. It informs about the base system AI tools they can use and flags gaps where custom tooling might be a better fit. Customers also receive key resources and leading practices to help get them started.

## Package Availability

**Note:** This Accelerator is available for Impact Guided, Guided+ \(SV or PG\), Advanced, and Total packages.

## Prerequisites

-   Customer has over 500 Task records \(Incident and Case as of May 2026\)
-   Customer is licensed for ServiceNow Otto / AI Agents

## What You Get

-   **Session Preparation**

    The Technical Accelerator Consultant:

    -   Provisions a temporary instance
    -   Activates and configures AI Agent Advisor for Incident &amp; Case \(as applicable\)
    -   Reviews AAA findings
-   **Customer Coaching Session \#1 \(up to 1 hour\)**

    Includes the following:

    -   AI Agent Advisor product introduction
    -   AI Agent Advisor workflow: Mine &gt; Match &gt; Make
    -   Guided walkthrough
    -   Review results from the customer's instance
    -   Additional information and key resources
-   **Customer Coaching Session \#2 \(Optional up on Customer request – up to 1 hour\)**

    Opportunity for Q&amp;A related to AI Agent Advisor.


## Outputs

-   30-day access to the temporary instance and Technical Accelerator Consultant with whom you met for any further questions or in-depth explorations
-   Copy of the Coaching Session Deck
