# Jumpstart Your Zero Copy Connectors

This accelerator provides guided coaching and demonstrations on designing, configuring, and governing Zero Copy Connectors for external data access via Workflow Data Fabric.

## Accelerator Overview

Jumpstart Your Zero Copy Connectors \(ZCC\) provides Impact customers with an overview and applied demonstration to help them design, configure, and manage Zero Copy Connectors. Customers learn how to securely access external data sources—including Databricks, Snowflake, and remote ServiceNow instances without duplicating data or building custom integrations.

Through this coaching, customers learn how Zero Copy Connectors integrate with Workflow Data Fabric \(WDF\) to enable real-time, governed data access that powers workflows, AI agents, and analytics. This accelerator also includes key resources and leading practices to help customers successfully implement and adopt Zero Copy Connectors.

## Package Availability

**Note:** This Accelerator is available for Impact Guided, Guided+ \(SV or PG\), Advanced, and Total packages.

## Prerequisites

-   Workflow Data Fabric must be licensed and activated on the customer's ServiceNow instance, or the customer is planning to obtain the license in the short term
-   Customers must have identified a specific external data source they want to connect to via ZCC \(ERP not in scope for this accelerator\)
-   Customer understands that ZCC is read-only for SQL sources \(Snowflake, Databricks, remote ServiceNow instances\); no bidirectional integration or ETL

## What You Get

-   **Session Preparation**

    The Technical Accelerator Consultant:

    -   Provisions a temporary instance \(if applicable\)
    -   Activates and configures related plugins
    -   Prepares the ServiceNow demo instance to demonstrate ServiceNow Remote connection
-   **Customer Coaching Session \#1 \(up to 1.5 hours\)**

    Includes the following:

    -   Where ZCC fits within the broader Workflow Data Fabric \(WDF\) architecture
    -   Primary and Community Connectors
    -   ZCC for federated read-only access to a live SQL source \(Databricks, remote ServiceNow instance\); Snowflake as optional
    -   Configuration of Primary Connectors
    -   Demonstration of:
        -   A live-federated connection to Databricks
        -   Remote connection to a ServiceNow instance
-   **Customer Coaching Session \#2 \(Optional upon Customer request – up to 1 hour\)**

    Opportunity for Q&amp;A related to Zero Copy Connectors.


## Outputs

-   30-day access to the temporary instance and Technical Accelerator Consultant with whom you met for any further questions or in-depth explorations
-   Copy of the Coaching Session Deck
