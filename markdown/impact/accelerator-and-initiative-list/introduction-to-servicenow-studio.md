# Introduction to ServiceNow Studio

This accelerator provides an overview of ServiceNow Studio, the primary environment for scoped app development on the Now Platform.

## Accelerator Overview

Introduction to ServiceNow Studio provides Impact customers with guided coaching and practical demonstrations of the Studio interface and the way it fits within the broader ServiceNow Studios ecosystem. This accelerates onboarding and time-to-value for platform development. This offering also shares key resources and leading practices for getting started with ServiceNow Studio.

## Package Availability

**Note:** This Accelerator is available for Impact Guided, Guided+ \(SV or PG\), Advanced, and Total packages.

## Prerequisites

-   App Engine \(or the applicable development entitlement\) must be licensed and activated on the customer's instance or the customer is planning to acquire it in the short term
-   Customer should be new to ServiceNow Studio as this accelerator establishes first-time orientation
-   Customer understands this is a high-level, non-technical introduction to the Studio environment. It covers what the IDE is and how to navigate it, not a guided build of a specific application

## What You Get

-   **Session Preparation**

    The Technical Accelerator Consultant provisions a ServiceNow demonstration instance

-   **Customer Coaching Session \#1 \(up to 1 hour\)**

    Includes the following:

    -   Overview of ServiceNow Studio:
        -   Its purpose and how to navigate the interface
        -   How it fits within the broader ServiceNow Studios ecosystem—App Engine Studio, Creator Studio, Workflow Studio, Studio IDE \(legacy\), and VS Code IDE
        -   Key features and capabilities
    -   Demonstration, including:
        -   Navigating the ServiceNow Studio interface and its core capabilities
        -   Applying leading practices to a basic scoped-app task on the Now Platform
-   **Customer Coaching Session \#2 \(Optional up on Customer request – up to 1 hour\)**

    Opportunity for Q&amp;A related to ServiceNow Studio.


## Outputs

-   30-day access to the temporary instance and Technical Accelerator Consultant with whom you met for any further questions or in-depth explorations
-   Copy of the Coaching Session Deck
