# Maturity assessment questionnaires

A maturity assessment questionnaire collects responses that an Impact maturity assessment accelerator scores, using questions grouped into domains.

## How maturity assessments work

Several Impact accelerators assess the maturity of a process or capability by asking a set of questions grouped into domains. A maturity assessment can involve multiple participants. The main user completes the questionnaire and can also invite others in their organization to complete it independently. Responses across all completed questionnaires are aggregated to produce a maturity score for each domain and an overall maturity score for the accelerator.

Using these results, you can identify maturity gaps across domains and select a target maturity level for each one you want to improve. Based on those selections, the accelerator generates an action plan with a customized list of recommendations to close the gaps.

**Note:** For the accelerators that use a maturity assessment questionnaire, see [Strategy Accelerators](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/accelerator-and-initiative-list/strategy-accelerators.md).

## Question types

A maturity assessment questionnaire uses single-select questions only. For each question, you choose the one statement that best reflects current practice from a set of options describing increasing levels of maturity. Your answer should reflect how work happens today, not documentation, goals, or planned improvements.

## Question and domain weighting

Every question and every domain carries the same weight when responses are scored. No question or domain counts for more than another.

## Existing assessments

Accelerators that were built on the earlier assessment model continue to work as before, including the Impact [Staffing and Roles Review-On Demand](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/accelerator-and-initiative-list/staffing-and-roles-review-on-demand.md) and the [Adopt AI Governance](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/accelerator-and-initiative-list/adopt-ai-governance.md) assessment.

## Maturity assessment workflow UI features

For every maturity assessment on-demand accelerator, the following UI features are available:

-   Multi-Participant Assessment Configuration:

    Add participants to an on-demand maturity assessment and assign each one a role and one or more domains. Generate surveys for your participants and track their delivery from a single configuration view.

-   External Participant Surveys:

    Send participants external survey questionnaires. Each participant sees only the questions for the domains assigned to them. It also supports target specification during assessments.

-   Aggregated Participant Results:

    View responses from all participants combined in the Review Results step of your Playbook. As the assessment owner, you see all aggregated data, while participants can't see each other's responses. You can also use the multiple visualization formats \(KPI cards, bar charts, heat maps, tables\) to review aggregated survey results. Users can monitor assessment progress over the 14-day survey collection period.

-   Participant Completion Tracking:

    Monitor each participant's completion status and response date so you know whose input is still outstanding.

-   Action Plan:
    -   View and download the action plan page displaying prioritized items organized by domain.
    -   Modify suggested owners and add notes to action items.
