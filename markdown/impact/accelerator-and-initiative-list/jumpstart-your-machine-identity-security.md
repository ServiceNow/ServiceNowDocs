# Jumpstart Your Machine Identity Security

This accelerator provides an overview and demonstration of the possibilities and capabilities of the Machine Identity Console and Machine Access Controls.

## Accelerator Overview

Jumpstart Your Machine Identity Security guides Impact customers through ServiceNow's Machine Identity Security capabilities, showing how to govern and secure non-human identities across their instance. Through an applied demonstration of the Machine Identity Console \(MIC\) and Machine Identity Access Controls \(MIAC\), participants see how to audit service accounts, assess authentication risks, and apply least-privilege controls to integrations and automated processes. They receive a prioritized remediation plan and a practical approach to managing machine identities as an ongoing security practice.

## Prerequisites

-   Customer must be on Zurich release or above — MIAC is a Zurich-and-above capability.
-   Security Center must be accessible to the attending Security or IT Administrator.
-   Customer should have existing integration users/service accounts in their instance.

## Package Availability

**Note:** This Accelerator is available for Impact Guided, Guided+ \(SV or PG\), Advanced, and Total packages.

## What You Get

-   **Session Preparation**

    The Technical Accelerator Consultant:

    -   Provisions an instance copy
    -   Activates Security Center and machine identity plugins
-   **Customer Coaching Session \#1 \(up to 1.5 hours\)**

    Includes the following:

    -   Overview of Machine Identity Security:
        -   Machine Identity Console \(MIC\) and Security Score
        -   Machine Identity Access Controls \(MIAC\)
        -   Inbound Integration Experience
        -   Representational State Transfer \(REST\) API Access policies and Open Authorization \(OAuth\) migration
    -   Demonstration of MIC
-   **Customer Coaching Session \#2 \(optional upon customer request - up to 1 hour\)**

    Opportunity for Q&amp;A related to Machine Identity Security

-   **Outputs**
    -   30-day access to the temporary instance and Technical Accelerator Consultant with whom you met for any further questions or in-depth explorations
    -   Copy of the Coaching Session Deck
