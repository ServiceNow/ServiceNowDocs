# Data synchronization reference

Reference information for data synchronization features in Impact.

This section contains reference information for data synchronization, including field mappings, storage estimation, and data sync processes.

-   **[Use manual registration to configure the Impact Store Application](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/use_manual_registration_configure_impact_store_application.md)**  
Manual registration is generally used by advanced users or to obtain configuration support from your Impact Squad. Regulated and GCC customers are also required to use manual registration.
-   **[Secure data transfer using Service Bridge](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/service-bridge-overview.md)**  
Data transfer between the Impact Delivery Instance and Impact Store Application is facilitated via Service Bridge.
-   **[Impact storage estimation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/impact-store-app-storage-estimation.md)**  
The Impact store app stores data within your ServiceNow instance and contributes to your instance's overall storage footprint. Storage usage varies depending on whether your instance is connected to the Impact Delivery Instance and on the level of collaboration activity.
