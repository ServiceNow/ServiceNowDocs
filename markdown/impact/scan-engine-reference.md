# Scan Engine reference

Reference information for Scan Engine features in Impact.

This section contains reference information for Scan Engine, including API field references.

-   **[Scan Engine definitions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/scan-engine-definitions.md)**  
The Scan Engine uses a large set of definitions to correct coding and workflow findings in real-time and perform scans across your entire instance to detect existing findings.
-   **[Platform Health score calculation model](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/instance-health-score-calculation.md)**  
Your Platform Health score is the foundation for understanding instance risk. The score reflects platform risk through a four-step, category-weighted calculation that combines findings into a single 0–100 health metric.
-   **[Supported record types for Real-time prevention monitoring with AI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/real-time-prevention-monitoring-supported-record-types.md)**  
The Scan Engine checks your code against active scan definitions and displays findings inline along with AI-suggested fixes you can apply.
-   **[Scan Engine API field reference](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/finding-resolved-finding-fields.md)**  
Field reference for scan status, findings, and resolved findings API responses.
-   **[Scan Engine API endpoints](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/api-endpoints.md)**  
Reference information for Scan Engine Headless API endpoints, authentication requirements, and response formats.
-   **[Scan Engine API error codes](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/impact/api-error-codes-grouped.md)**  
Error codes returned by the Scan Engine API, organized by HTTP status code. Each section includes proposed solutions and handling strategies.
