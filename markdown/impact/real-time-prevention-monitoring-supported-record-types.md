# Supported record types for Real-time prevention monitoring with AI

The Scan Engine checks your code against active scan definitions and displays findings inline along with AI-suggested fixes you can apply.

Following are the supported script-related tables that generate AI-suggested fixes.

|System table|Description|
|------------|-----------|
|sysauto\_script|Scheduled scripts|
|sysevent\_script\_action|Script actions|
|sys\_script|Business rules|
|sys\_script\_client|Client scripts|
|catalog\_script\_client|Catalog client scripts|
|sys\_script\_email|Email scripts|
|sys\_script\_include|Script includes|
|sys\_transform\_script|Transform scripts|
|sys\_ui\_list\_script\_client|List control scripts|
|sys\_ui\_script|UI scripts|
