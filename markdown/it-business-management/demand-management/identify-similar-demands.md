# Identify similar records using AI

Use the identify similar records skill to find demand records with similar names, descriptions, or business case content.

## Before you begin

**Important:** This generative AI skill is turned on by default. The skill will be automatically available to appropriate role users for the application. For more information, see [AI agents, skills, and agentic workflows on by default](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-skills-on-by-default.md).

If you have custom roles that require access to this skill, update the ACLs \(access control lists\) for those roles that require access.

Role required: it\_demand\_user

## About this task

-   If similar records exist, the related list displays them.
-   If no similar records are found, a message appears and the related list remains empty.

## Procedure

1.  Navigate to **All** &gt; **Demand** &gt; **Demands** &gt; **All**.

2.  Select a demand from the **Demands** list.

3.  Select the **Identify similar demands** button to detect similar demand records.

    The similar demands identified by AI are displayed in the top banner and the Similar Demands related list.

    \[Omitted image "similar-demand-new-color.png"\] Alt text: List of similar records identified by AI.


## What to do next

To view full details of a similar demand record, select the demand number link from the Similar Demands related list.
