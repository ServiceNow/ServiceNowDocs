# Legacy- Generated actuals

Account code, or budget key, expenses are records that show general ledger amounts for a budget key. The amounts are aggregated for each fiscal period.

The expenses in the Account Code Expenses \[itfm\_plan\_actuals\] table are used by the financial planning workbench for calculations of actual expenses. Normally you do not need to create or modify data in this table.

Finance analysts can access account code expenses from the **Financial Planning** &gt; **Financial Planning** &gt; **Generated Actuals**. The expenses are populated when you click **Generate Actuals** button on the [financial workbench](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/portfolio-management/financial-planning-workbench.md).
