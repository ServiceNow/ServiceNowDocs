# Legacy- Forecast period

Forecast periods are similar to budget periods that aim to control the promotion of forecast plans.

Forecast periods can be created for a closed budget period. Forecast plans can be promoted only if the forecast fiscal month period is open.

**Note:**

Only one forecast period can be open at any point in time.
