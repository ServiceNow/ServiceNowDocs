# MCP for Strategic Portfolio Management

MCP for Strategic Portfolio Management \(SPM\) connects any MCP-compatible AI assistant to your ServiceNow instance, giving strategy and PMO leaders, portfolio managers, and project managers direct access to live SPM data through natural language prompts. Instead of navigating multiple workspace views, users can ask for at-risk goals, portfolio plan insights, project insights, and project risks — and get results instantly, from whichever AI client they already work in.
