# Target Breakdown form

Use the Target Breakdown form to track and measure the progress of the target breakdown and its goal.

<table id="table_demand_benefit_plan_form"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Breakdown period

</td><td>

Period of the target breakdown.

</td></tr><tr><td>

Parent breakdown

</td><td>

Year of the target breakdown.

</td></tr><tr><td>

Target

</td><td>

Parent target of the target breakdown.

</td></tr><tr><td>

Status

</td><td>

Status of the target breakdown. The status can be **Red**, **Yellow**, **Green**, or **No status**.

</td></tr><tr><td>

Breakdown

</td><td>

Breakdown interval specified in the parent target.

</td></tr><tr><td>

Planned target

</td><td>

Target value for the target breakdown.For targets of type **Maintain above**, **Maintain below**, or **Maintain constant**, the planned target is set to the final target value of the target. You can edit it for a specific breakdown.

</td></tr><tr><td>

Actual

</td><td>

Actual value for the target breakdown.

</td></tr><tr><td>

Remark

</td><td>

Remark entered for business justification when updating the actuals.
