# Create RIDAC item for a goal

Create RIDAC items \(Risks, Issues, Decisions, Actions, Changes\) for a goal to track and manage governance across the goal lifecycle.

## About this task

RIDAC is a governance framework that tracks five key item types for goals:

-   **Risks:** Potential events or conditions that could negatively impact the goal or its outcomes.
-   **Issues:** Current problems or blockers that require immediate attention and resolution.
-   **Decisions:** Critical choices or approvals needed to move the goal forward.
-   **Actions:** Specific tasks or steps required to address risks, issues, or implement decisions.
-   **Changes:** Modifications to scope, schedule, resources, or other goal attributes.

Creating RIDAC items for your goals provides a unified view of governance activities, ensuring visibility across the portfolio and enabling better decision-making.

## Before you begin

Role required: sn\_apw\_advanced.spw\_goal\_user and sn\_align\_core.apw\_user

## Procedure

1.  Navigate to **All** &gt; **Strategic Planning** &gt; **Strategic Planning Workspace** &gt; **Portfolio Planning**.

2.  From the list of portfolio plans, select one and then select **Goals**.

3.  In the Goals view, select the **Goals and targets** tab.

4.  From the goals list, select a goal and open its full details page for which you want to create a RIDAC item.

5.  Create a RIDAC item for the goal.

## Result

The RIDAC item has been created successfully. The item now appears on the RIDAC page of the goal, contributing to a unified view of all governance activities for the goal. You can view, update, or track related items from the RIDAC interface.
