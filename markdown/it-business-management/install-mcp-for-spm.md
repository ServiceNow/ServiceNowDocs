# Install MCP for Strategic Portfolio Management

You can install the MCP for Strategic Portfolio Management application \(com.sn.spm.mcp\) if you have the admin role.

## Before you begin

-   Ensure that the application and all of its associated ServiceNow Store applications have valid ServiceNow entitlements. For more information, see [Get entitlement for a ServiceNow product or application](https://store.servicenow.com/$appstore.do#!/store/help?article=KB0030186).
-   Review the [MCP for Strategic Portfolio Management](https://store.servicenow.com/sn_appstore_store.do#!/store/application/3a97d7dd37300310eecc3c1384924b8d/1.0.2) application listing in the ServiceNow Store for information on dependencies, licensing or subscription requirements, and release compatibility.

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **System Applications** &gt; **All Available Applications** &gt; **All**.

2.  Find the MCP for Strategic Portfolio Management application \(com.sn.spm.mcp\) using the filter criteria and search bar.

    You can search for the application by its name or ID. If you cannot find the application, you might have to request it from the ServiceNow Store.

    A list of the versions available to you are displayed.

3.  Select a version from the list and select **Install**.

    In the Review Installation Details dialog box, any dependencies installed with your application are listed.

4.  If you're prompted, follow the links to the ServiceNow Store to get any additional entitlements for dependencies.

5.  Select **Install**.

6.  Go to the [MCP for Strategic Portfolio Management](https://store.servicenow.com/store/app/aca7e28993e9cfd41caaf76e1dba1098) application listing in the ServiceNow Store and install the application.
