# Connect the SPM MCP server to an AI assistant

Connect the SPM MCP server to an AI assistant so that the assistant can query goals, portfolio plans, and project insights directly from your ServiceNow instance.

## Before you begin

-   The MCP for Strategic Portfolio Management application is installed. For details, see [Install MCP for Strategic Portfolio Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/install-mcp-for-spm.md).
-   Confirm that the SPM MCP server is enabled on your instance by navigating to **All** &gt; **MCP Server Console**. If you don't see the server or want to create another MCP server, see [Create a Model Context Protocol server](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/create-mcp-server.md).

    \[Omitted image "mcp-for-spm-active-status.png"\] Alt text: MCP for SPM active status.

-   Confirm that the MCP for SPM tools are enabled on your instance by navigating to **All** &gt; **MCP Server Console**.

    \[Omitted image "mcp-for-spm-tools-status.png"\] Alt text: MCP for SPM tools active status.


Role required: admin or sn\_mcp\_server.admin

## Procedure

1.  Connect the SPM MCP server to your AI assistant.

    For instructions, see [Connecting to an MCP server from an MCP client](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/connect-mcp-server-client.md).
