# Export a demand Doc as a PDF

Export demand Docs as PDF files to use them offline or share with stakeholders outside Next Experience for Demand Management.

## Before you begin

Role required: it\_demand\_user, it\_demand\_manager, or demand\_approver

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Docs** from the navigation menu.

5.  From the Doc header, select the More actions icon \[Omitted image "cwm-icon-more-actions-dots.png"\] Alt text: and select **Export as PDF**.


## Result

The PDF file is downloaded to your local system.
