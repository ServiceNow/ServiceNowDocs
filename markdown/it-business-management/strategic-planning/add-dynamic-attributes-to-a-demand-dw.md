# Add dynamic attributes to a demand

Provide values for the dynamic attributes available on a demand through its Additional Information tab. This approach captures governance-process-specific information without affecting demands using other experiences.

## Before you begin

The demand must have a dynamic category with one or more dynamic attributes defined through its selected demand experience. For more information, see [Demand experiences](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/strategic-planning/demand-experiences-dw.md).

Role required: it\_demand\_user or it\_demand\_manager

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select the **Details** tab.

5.  Select the **Additional Information** tab.

    \[Omitted image "demand-additional-info-tab.png"\] Alt text: Additional Information tab with dynamic attribute fields on a demand record.

6.  Enter values in the dynamic attribute fields.

7.  Select **Save**.


## Result

The values that you entered are saved to the demand's dynamic attributes.
