# Edit a draft demand in Employee Slate

Update the details of a draft demand in Employee Slate before submitting it for a demand manager's review.

## Before you begin

Project Workspace and Employee Slate Core apps are installed.

Role required: snc\_internal

## Procedure

1.  Open a demand from **My Demands** or **Requests**.

    2.  Select a demand from the list.


</td></tr></tbody>
</table>2.  In the Demand Details section, select the Edit icon.

3.  Update the fields.

    For information on the field values, see [Demand form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/demand-form-dw.md).

4.  Select **Save**.


## Result

After you submit the demand, the fields are set to read-only, though you can still add comments and attachments.
