# Financials tab

The Financials tab of the demand dashboard summarizes planned cost, financial benefit, and return on investment \(ROI\) across demands.

\[Omitted image "demand-dashboard-financials.png"\] Alt text: Financials tab in the demand dashboard

The widgets in the Financials tab consider demands in the Submitted, Screening, Qualified, or Approved states to display the data. You can further drill down on each widget to see the list of records associated with them.

The Date range widget scopes the data shown across all widgets on the Financials tab. The default range is the current year.
