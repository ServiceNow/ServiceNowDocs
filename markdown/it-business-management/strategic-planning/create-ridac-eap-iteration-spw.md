# Create RIDAC for an EAP iteration

Create a Risk, Issue, Decision, Action, or Change item and associate it with an Enterprise Agile Planning \(EAP\) iteration.

## Before you begin

Role required: sn\_apw\_advanced.eap\_user

## About this task

You can create a RIDAC item directly from an EAP iteration to document and track risks, issues, decisions, actions, and changes that affect your agile planning and execution. RIDAC items help you manage planning uncertainties and dependencies across your iterations.

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace** &gt; **Enterprise Agile Planning**.

    The Enterprise Agile Planning view opens.

2.  From the Agile structure section of the left navigation panel, choose an ART or an Agile team and select **Planning Board**.

    The planning board for the selected ART or Agile team opens, displaying the planning items and iterations.

3.  Select an iteration from the planning board to open its details page.

    The iteration Details page opens.

4.  On the iteration Details page, select the tab for the RIDAC type you want to create:

    -   **Risks** — to create a risk item.
    -   **Issues** — to create an issue item.
    -   **Decision** — to create a decision item.
    -   **Actions** — to create an action item.
    -   **Request Changes** — to create a change item.
    The selected RIDAC tab opens.

5.  Select **New**.

    The RIDAC creation form opens with the EAP iteration information automatically populated.

6.  On the form, fill in the required fields for the RIDAC item.

    For a description of the field values, see the form.

    -   For a Risk, see [RIDAC Risk form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-risk-form-spw.md).
    -   For an Issue, see [RIDAC Issue form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-issue-form-spw.md).
    -   For a Decision, see [RIDAC Decision form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-decision-form-spw.md).
    -   For an Action, see [RIDAC Action form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-action-form-spw.md).
    -   For a Change Request, see [RIDAC Change Request form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-change-request-form-spw.md).
7.  Select **Save** to save the record.


## Result

A RIDAC item has been created and is now associated with the EAP iteration.

## What to do next

After creating a RIDAC item, you can:

-   Edit the RIDAC item to add more details, assign ownership, or set status and priority.
-   View the RIDAC item in the RIDAC home page by filtering by the appropriate tab \(All RIDAC, Project RIDAC, Portfolio RIDAC, or Program RIDAC\).
-   If integration is enabled and an execution task is linked to the iteration, view the RIDAC item on the execution task as well.
