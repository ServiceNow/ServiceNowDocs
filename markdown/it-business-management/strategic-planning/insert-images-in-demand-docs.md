# Add images in demand Docs or download them

Add images to demand Docs by uploading a file or embedding a URL. You can also download images from a Doc page to use outside Docs.

## Before you begin

Role required: it\_demand\_user, it\_demand\_manager, or demand\_approver

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Docs** from the navigation menu.

5.  Select the page or subpage where you want to insert the image.

6.  Add an image to the Doc page either by pasting it directly, uploading it from your system, or by embedding a link.
