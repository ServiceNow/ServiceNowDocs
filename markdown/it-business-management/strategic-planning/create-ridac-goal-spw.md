# Create RIDAC for a goal

Create a Risk, Issue, Decision, Action, or Change item and associate it with a portfolio plan goal or a goal that is part of a board \(Strategy and Goals\).

## Before you begin

Role required: sn\_apw\_advanced.spw\_goal\_user

## About this task

You can create a RIDAC item directly from a goal to document and track risks, issues, decisions, actions, and changes that affect your strategic goals. Goals can be portfolio plan goals or goals that are part of a board \(Strategy and Goals\). RIDAC items help you manage planning uncertainties and dependencies across your goals.

## Procedure

1.  Navigate to the goal in one of the following ways:

    1.  **For a portfolio plan goal:** Navigate to **Workspaces** &gt; **Strategic Planning Workspace** &gt; **Portfolio Planning**, select a portfolio plan, then select **Goals**.

    2.  **For a goal on a board \(Strategy and Goals\):** Navigate to **Workspaces** &gt; **Strategic Planning Workspace** &gt; **Strategy and Goals**, select a board, then locate and select the goal.

    The goal details open.

2.  On the goal Details page, select the tab for the RIDAC type you want to create:

    -   **Risks** — to create a risk item.
    -   **Issues** — to create an issue item.
    -   **Decision** — to create a decision item.
    -   **Actions** — to create an action item.
    -   **Request Changes** — to create a change item.
    The selected RIDAC tab opens.

3.  Select **New**.

    The RIDAC creation form opens with the goal information automatically populated.

4.  On the form, fill in the required fields for the RIDAC item.

    For a description of the field values, see the form.

    -   For a Risk, see [RIDAC Risk form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-risk-form-spw.md).
    -   For an Issue, see [RIDAC Issue form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-issue-form-spw.md).
    -   For a Decision, see [RIDAC Decision form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-decision-form-spw.md).
    -   For an Action, see [RIDAC Action form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-action-form-spw.md).
    -   For a Change Request, see [RIDAC Change Request form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/ridac-change-request-form-spw.md).
5.  Select **Save** to save the record.


## Result

A RIDAC item has been created and is now associated with the goal.

## What to do next

After creating a RIDAC item, you can:

-   Edit the RIDAC item to add more details, assign ownership, or set status and priority.
-   View the RIDAC item in the RIDAC home page by filtering by the appropriate tab \(All RIDAC, Project RIDAC, Portfolio RIDAC, or Program RIDAC\).
-   If integration is enabled and an execution task is linked to the goal, view the RIDAC item on the execution task as well.
