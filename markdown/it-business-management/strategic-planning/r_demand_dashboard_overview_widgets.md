# Overview tab

The Overview tab of the demand dashboard summarizes demand volume, activity, and risk across all demands.

\[Omitted image "demand-dashboard-overview.png"\] Alt text: Overview tab of the demand dashboard.

Select any widget to see the records associated with it.

<table id="table_jpf_yym_bkc"><thead><tr><th>

Widget

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Demand Distribution

</td><td>

Displays the total count of demands, grouped by a field you select. By default, demands are grouped by Investment Type.To regroup the data, select one of the following options:

-   Investment Type
-   Department
-   Investment Class
-   Primary goal
-   Business Unit

</td></tr><tr><td>

Demand Analysis

</td><td>

Shows demand counts as a stacked bar chart, grouped and optionally stacked by fields you select. By default, the grouping is by State and stacking is by Demand manager.Both controls offer the same set of options, along with the respective default values:

-   State
-   Category
-   Investment Class
-   Investment Type
-   Priority
-   T-Shirt size
-   Department
-   Primary goal
-   Strategic program
-   Product
-   Portfolio

The Stack by control also offers the None value, which removes stacking from the chart.

</td></tr><tr><td>

Inactive Demands

</td><td>

Count of demands not updated in the last 30 days.

</td></tr><tr><td>

Overdue Demand Tasks

</td><td>

Count of demand tasks with a past due date as of the current date.

</td></tr><tr><td>

Demands Pending Conversion

</td><td>

Count of demands in the Approved state that are pending for conversion to work items.

</td></tr><tr><td>

Demands created - Last 30 days

</td><td>

Lists demands created in the last 30 days, with key fields such as number, name, state, demand manager, and score. The View all option displays the full list.

</td></tr><tr><td>

Risk vs. Score

</td><td>

Plots demand risk against demand score as a bubble chart. Select a bubble to see the underlying values and a link to the record list.

</td></tr></tbody>
</table>
