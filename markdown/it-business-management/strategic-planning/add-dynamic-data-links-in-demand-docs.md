# Add dynamic data to demand Docs

Add references to application records or fields in demand Docs to keep documentation current without manual updates. You can add references from any table on your ServiceNow instance you have access to.

## Before you begin

Role required: it\_demand\_user, it\_demand\_manager, or demand\_approver

## About this task

Hovering over a reference in the Doc displays its data. Selecting the reference link opens its related record form.

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Docs** from the navigation menu.

5.  Select the page or subpage where you want to add the dynamic data link.

6.  Place the cursor where you want to add the dynamic data link and type the slash command \( `/`\).

7.  Select the **Mention a record** option.

8.  Select the record in a table or field in a record that you want to reference.

    1.  In the Search field, enter the table or record name and select it.

    2.  Continue navigating through the hierarchy of fields or related records to access the field or record you want to reference and select it.


## Result

The record or record field is added to the doc.
