# View assessment results for a demand

View the assessment results for a demand to evaluate its feasibility, priority, and alignment with organizational objectives.

## Before you begin

Role required: it\_demand\_manager

## About this task

Assessment results provide demand managers with the insights needed to make informed decisions to approve, defer, or reject a demand.

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Details** from the navigation menu.

5.  Select the **Assessment Results** tab.

    **Note:** If the **Assessment Results** tab isn't visible, select **More** &gt; **Assessment Results**.

6.  Open an assessment result record to view the details.
