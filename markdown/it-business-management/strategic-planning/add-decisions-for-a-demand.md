# Add decisions to a demand

Add a decision to a demand to record the solution or plan for a risk or issue.

## Before you begin

Role required: it\_demand\_manager

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Details** from the navigation menu.

5.  Select the **Decisions** tab.

    **Note:** If the **Decisions** tab isn't visible, select **More** &gt; **Decisions**.

6.  Select **New**.

7.  On the Decision form, fill in the fields.

    For a description of the field values, see [Decision form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/strategic-planning/decision-form-dw.md).

8.  Select **Save**.
