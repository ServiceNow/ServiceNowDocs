# Add an assessment instance and its questions

Add assessment instances and associated questions for a demand to evaluate its feasibility and gather structured feedback from stakeholders.

## Before you begin

Role required: it\_demand\_manager

## Procedure

1.  Navigate to **Workspaces** &gt; **Strategic Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Details** from the navigation menu.

5.  Select the **Assessment Instances** tab.

    **Note:** If the **Assessment Instances** tab isn't visible, select **More** &gt; **Assessment Instances**.

6.  Select **New**.

7.  On the Assessment Instance form, fill in the fields.

    For a description of the field values, see [Assessment instance form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/strategic-planning/assessment-instance-form-dw.md).

8.  Select **Save**.

    The assessment instance is added.

9.  Select the **Assessment Instance Questions** tab.

10. Select **New**.

11. On the Assessment Instance Question form, fill in the fields.

    For a description of the field values, see [Assessment instance question form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/strategic-planning/create-assessment-instance-question-form-dw.md) form.

12. Select **Save**.


## Result

The assessment instance and the associated instance questions are added.

**Note:** When the assessment instance moves to the **Ready to take** state, or the **Assigned to** user changes, the assigned user receives an "Assessment notification for Demand" email with a link to take the assessment, and a link to their assessment queue under **Self Service** &gt; **My Assessment &amp; Surveys**.
