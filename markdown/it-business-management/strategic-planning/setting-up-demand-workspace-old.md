# Configure financials for demands

Financial planning settings for demands include the financials view, planning attributes, and scheduled jobs.

## Configuration overview

Define the following items for financials Next Experience for Demand Management.

-   Define the multicurrency settings for the financials fields. See [Multicurrency in Next Experience for Demand Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/multicurrency-in-demand-workspace.md).
-   Enable the budget allocation for demands. See [Enable financial budget allocation for demands](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/enable-financial-budget-allocation-for-demands.md).
-   Define the budget allocation attribute to allocate budget by cost type or expense type. See [Configure budget attribute at instance level](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/configure-budget-attribute-at-instance-level-dw.md).
-   Enable monetary benefit plans for demands. See [Enable monetary benefit plans for demands](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/strategic-planning/enable-monetary-benefit-plans-for-demands.md).
