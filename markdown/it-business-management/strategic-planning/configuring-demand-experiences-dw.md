# Configuring demand experiences

Configure demand experiences so that each type of demand has its own custom fields, form view, and visible modules.

A demand experience combines a dynamic category, a form view, and module visibility settings. For an overview of these components, see [Demand experiences](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/strategic-planning/demand-experiences-dw.md).

To configure a demand experience, complete the following tasks:

-   Create a dynamic category \(optional\)

    A default dynamic category is available in the base system, so a custom dynamic category isn't required to create a demand experience. Create one only when demands of a type require custom fields that the default category doesn't provide. See [Create a dynamic category](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/strategic-planning/create-a-dynamic-category-dw.md).

-   Create a demand experience

    Create the demand experience and define its form view, dynamic category, and visible modules. See [Create a demand experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-business-management/strategic-planning/create-a-demand-experience-dw.md).
