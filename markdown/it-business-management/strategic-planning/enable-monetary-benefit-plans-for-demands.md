# Enable monetary benefit plans for demands

Enable the benefit plans property to create and manage benefit plans for demands.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** and type in `sys_properties.list` in the filter box.

2.  Filter the Name column to locate and open the **sn\_invst\_pln.enable\_benefit\_plan\_in\_new\_financials** property.

3.  Enter `true` in the Value field.

4.  Select the **Update** button.
