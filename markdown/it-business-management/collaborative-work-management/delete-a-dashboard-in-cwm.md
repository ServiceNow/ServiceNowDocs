# Delete a dashboard in Collaborative Work Management

Delete a dashboard in a CWM Board when your team no longer needs it.

## Before you begin

Confirm that a dashboard is created. For more information, see [Create a dashboard for a CWM Board in Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/collaborative-work-management/creating-dashboards-in-cwm.md).

Role required: sn\_cwm.cwm\_user

## About this task

Space owner or the dashboard owner can delete a dashboard.

You can't delete the predefined dashboards: Team progress and Team sprint tracker.

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  From a Space, select the Board where your dashboard is.

3.  Select the **Dashboard** tab.

4.  Select the dashboard from the Shared dashboards list.

5.  Select the Dashboard options \[Omitted image "cwm-dashboard-options-icon.png"\] Alt text:menu.

    \[Omitted image "cwm-delete-dashboard.png"\] Alt text: Dashboard options menu with Delete highlighted.

6.  Select **Delete**.

7.  Select **Delete** to confirm deletion.


## Result

The dashboard is deleted. A confirmation message appears. The dashboard selector returns to the Team progress dashboard.
