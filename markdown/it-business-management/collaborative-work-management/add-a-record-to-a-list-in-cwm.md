# Add a record to a list in CWM

Use CWM Lists to add a record to the source table of a predefined or custom list, without leaving the CWM workspace.

## Before you begin

Role required: sn\_cwm.cwm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  Select **Lists** under **Quick access**.

3.  Select a list from **My lists** or **Default lists**.

4.  Select **New**.

    \[Omitted image "cwm-add-record-in-list.png"\] Alt text: The New option in the header.

    The record form for the list's source table opens in a new browser tab.

5.  Complete the record form.

6.  Select **Submit**.


## Result

The record is created and appears in the respective list in CWM.
