# View project tasks assigned to you in CWM My Work

Track project tasks alongside your other CWM work from a single view in My Work. Project tasks show up when you're assigned to them directly or through a group.

## Before you begin

Role required: sn\_cwm.cwm\_user

## About this task

My Work shows a project task from Project Workspace when any of the following are true:

-   You're listed in the **Assigned to** field on the project task.
-   You're listed as a resource assignee on the project task.
-   You belong to a group that is listed as a resource assignment group on the project task.
-   You belong to a group that is listed in the **Assignment group** field on the project task.

Each team member sees only their own share of a group assignment. For general information about My Work, see [My Work in CWM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/my-work-in-cwm.md).

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  Open **My Work**.

3.  To view only project tasks, from the task type filter, select **Project task**.

    The task type filter shows only the task types currently assigned to you. Project tasks appear when at least one is assigned through any of the routes listed in the context.

    \[Omitted image "cwm-pws-my-work.png"\] Alt text: My Work Overview filtered to show only project tasks.

4.  Select the **List** tab to review the full list of project tasks with columns for state, priority, and dates.

5.  To open a project task in Project Workspace, select the value in the **Source** column.
