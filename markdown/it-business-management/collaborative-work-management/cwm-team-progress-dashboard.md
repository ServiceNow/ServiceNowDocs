# Team progress dashboard in Collaborative Work Management

The Team progress dashboard supports waterfall use cases and includes widgets that visualize task completion and workload for the whole Board.

This dashboard appears by default the first time you open the Dashboard tab on a Board. After that first visit, the tab opens to the last dashboard you viewed.
