# Create a dashboard for a CWM Board in Collaborative Work Management

Create a dashboard for a CWM Board to visualize work data using predefined or custom widgets. Track progress and spot issues without reviewing individual tasks or stories.

## Before you begin

A board is created. For more information, see [Create a Board in CWM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/create-boards-in-cwm.md).

Role required: sn\_cwm.cwm\_user

## About this task

-   All dashboards are shared with everyone who has access to the Board.
-   Space owners and editors can create dashboards.
-   Space viewers can only view existing dashboards.

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  From a Space, select a Board to add the dashboard to.

3.  Select the **Dashboard** tab.

4.  Select **New dashboard**.

    \[Omitted image "cwm-new-dashboard.png"\] Alt text: The New dashboard option is available on the dashboard header.

5.  Enter a name for the dashboard.

6.  Select **Create**.


## Result

The dashboard opens in an empty state with the **Add widgets** option.

\[Omitted image "cwm-dashboard-empty-state.png"\] Alt text: The empty state of a dashboard.

## What to do next

Add predefined or custom widgets to your dashboard. For more information, see [Add widgets to a dashboard in Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/add-a-widget-to-cwm-dashboard.md).
