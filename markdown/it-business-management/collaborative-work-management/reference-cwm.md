# Collaborative Work Management reference

Reference topics provide details on the roles, tables, and properties installed with Collaborative Work Management \(CWM\).

-   **[Components installed with Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/components-installed-with-cwm.md)**  
Several types of components are installed with activation of the Collaborative Work Management application, including tables and user roles.
-   **[Properties installed with Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/properties-installed-with-cwm.md)**  
System properties that you can configure to include other ServiceNow AI Platform records in CWM Docs and modify the way non-CWM users request access to the workspace.
-   **[Skill inputs for ServiceNow Otto for Collaborative Work Management \(CWM\) \(CWM\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/skill-inputs-now-assist-for-cwm.md)**  
Learn about the inputs of each skill of ServiceNow Otto for CWM. By configuring inputs for a skill, you can determine how and when a skill is used within the CWM workspace.
-   **[Grouping of tasks in status reports of CWM My Work](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/grouping-of-tasks-in-status-reports-of-cwm-my-work.md)**  
Learn how various tasks assigned to you are grouped based on their State and Priority in My Work reports of Collaborative Work Management \(CWM\).
-   **[Project task access in CWM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/cwm-access-via-project-permissions.md)**  
Learn how project users and CWM users can access project tasks and CWM tasks within the Collaborative Work Management workspace.
