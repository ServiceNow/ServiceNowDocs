# Edit a record from a list in CWM

Edit a record in a default or custom list without leaving the list view in CWM.

## Before you begin

Role required: sn\_cwm.cwm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  Select **Lists** under **Quick access**.

3.  Select a list from **My lists** or **Default lists**.

4.  Select the check box next to the record.

5.  Select **Edit**.

    \[Omitted image "cwm-edit-record-in-list.png"\] Alt text: Check box beside a record row and the Edit option in the header.

6.  Update the record fields in the side panel.

    \[Omitted image "cwm-edit-record-list-panel.png"\] Alt text: The Edit item side panel to update the records.

7.  Select **Submit**.


## Result

The record is updated in the list.
