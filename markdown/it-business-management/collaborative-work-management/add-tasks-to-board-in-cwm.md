# Add tasks to a CWM Board

Add tasks to a CWM Board and assign them to team members to plan and track work in a Collaborative Work Management workspace.

## Before you begin

A Board is created before you add tasks. For details, see [Create a Board in CWM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/create-boards-in-cwm.md).

Role required: sn\_cwm.cwm\_user

## About this task

Each task on a Board is a unit of work that your team plans, assigns, and tracks to completion.

This procedure provides step by step guidance on how to add a single task to a CWM Board.

To bring in many tasks at once from an existing file such as Excel, Word, or PDF, import them individually using ServiceNow Otto instead of adding them individually. See [Import existing tasks into a CWM Board](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/import-tasks-cwm-board.md).

To generate a batch of tasks from an open prompt or an uploaded document, use AI to generate tasks. See [Create CWM tasks or stories from files or open prompts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/generate-tasks-cwm-boards.md).

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  From a Space, select a Board that you want to add tasks to.

3.  From the Board footer, select **+ Add item**.

    \[Omitted image "cwm-add-tasks-to-board.png"\] Alt text: Board footer showing the Add item button at the bottom of the task list.

4.  Fill in details such as the Type, Short description, Assigned to, dates, and others.

    The default work item types available in CWM are Task and Defect. If you want to create other work items such as Milestones or Events, you can create your own task type. See [Create and manage custom work item types in CWM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/create-custom-work-item-types-in-cwm.md).


## What to do next

-   Add more tasks to the Board and assign them to yourself or members of your team.
-   Edit task details from the side panel by selecting the short description.
-   Edit task details directly in the grid using inline editing.
-   Rearrange your tasks on the Board by using the drag-and-drop feature.
-   Share tasks by their URL using the **Copy task link** option from the row context menu of the task. This way, when a user clicks the shared URL, the task opens in the side panel in the context of the Board that it belongs to.

    \[Omitted image "cwm-copy-task-link.png"\] Alt text: Row context menu showing the Copy task link option.


To plan and manage tasks, you can also:

-   Create additional columns for a task to add other details. See [Add custom columns for tasks in a CWM Board](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/add-custom-columns-for-tasks-in-board.md)
-   Choose the columns to be displayed for the tasks on the Board. See [Personalize List, Gantt and Kanban display for CWM Boards](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/personalize-cwm-board-views.md).
-   Break a task down into smaller units of assignable work by using AI to generate child tasks. See [Generate child tasks for CWM tasks](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/generate-subtasks-for-cwm-tasks.md).

-   **[Create CWM tasks or stories from files or open prompts](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/generate-tasks-cwm-boards.md)**  
Generate tasks or stories for a Board by describing the work in a natural language prompt or by uploading a document. AI analyzes the input to propose a list of actionable tasks or stories for you to review and select, saving time and manual effort.
-   **[Generate tasks from Docs in Collaborative Work Management \(CWM\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/collaborative-work-management/generate-tasks-cwm-docs-now-assist.md)**  
Use the generative AI capabilities of ServiceNow Otto to create tasks from the content of your Docs and help you add them to the required Board in CWM workspace.
