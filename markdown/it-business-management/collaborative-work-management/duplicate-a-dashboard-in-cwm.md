# Duplicate a dashboard in Collaborative Work Management

Duplicate a dashboard in a CWM Board to reuse an existing set of widgets in a new dashboard. This avoids rebuilding the same layout from scratch.

## Before you begin

Confirm that a dashboard is created. For more information, see [Create a dashboard for a CWM Board in Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/collaborative-work-management/creating-dashboards-in-cwm.md).

Role required: sn\_cwm.cwm\_user

## About this task

Space owners and editors can duplicate dashboards.

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  From a Space, select the Board where your dashboard is.

3.  Select the **Dashboard** tab.

4.  From the Shared dashboards list, select the dashboard to duplicate.

5.  Select the Dashboard options \[Omitted image "cwm-dashboard-options-icon.png"\] Alt text:menu.

    \[Omitted image "cwm-duplicate-dashboard.png"\] Alt text: Dashboard options menu showing the Duplicate option.

6.  Select **Duplicate**.

    The name of the new dashboard is populated as `Copy (*original dashboard name*)`.

7.  Enter a new name for the dashboard.

8.  Select **Duplicate**.


## Result

The duplicate dashboard is created and includes all widgets from the original dashboard.

## What to do next

Add predefined or custom widgets to your duplicated dashboard or remove existing ones. For more information see [Add widgets to a dashboard in Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/collaborative-work-management/add-a-widget-to-cwm-dashboard.md) and [Remove widgets from a dashboard in Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/collaborative-work-management/remove-a-widget-from-a-dashboard.md).
