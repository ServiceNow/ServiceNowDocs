# Rename a dashboard in Collaborative Work Management

Rename a dashboard in a CWM Board so your team can easily identify it among shared dashboards for any specific requirement.

## Before you begin

Confirm that a dashboard is created. For more information, see [Create a dashboard for a CWM Board in Collaborative Work Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-business-management/collaborative-work-management/creating-dashboards-in-cwm.md).

Role required: sn\_cwm.cwm\_user

## About this task

Predefined dashboards — Team progress and Team sprint tracker — can't be renamed. Space owners and editors can rename dashboards.

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  From a Space, select the Board where your dashboard is.

3.  Select the **Dashboard** tab.

4.  From the Shared dashboards list, select the dashboard to rename.

5.  Select the Dashboard options \[Omitted image "cwm-dashboard-options-icon.png"\] Alt text:menu.

    \[Omitted image "cwm-rename-dashboard.png"\] Alt text: Rename dashboards under Dashboard options.

6.  Select **Rename**.

7.  Enter a new name for the dashboard.

8.  Select **Save**.
