# Export a list in CWM

Export the records in a default or custom list in Collaborative Work Management to Excel, CSV, JSON, or PDF, either as a direct download or delivered by email.

## Before you begin

Role required: sn\_cwm.cwm\_user

## Procedure

1.  Navigate to **Workspaces** &gt; **Collaborative Work Management**.

2.  Select **Lists** under **Quick access**.

3.  Select the **My lists** or **Default lists** tab.

4.  Open the list that you want to export.

5.  Select **Export**.

6.  In the **Export** dialog, select a **File Type**.

    You can export to Excel, CSV, JSON, or PDF.

    \[Omitted image "cwm-export-lists-option.png"\] Alt text: Export dialog showing file type options: Excel, CSV, JSON, and PDF.

7.  If you're exporting a PDF, select an orientation such as **Landscape**.

8.  If you're exporting an accessible PDF, select the **Accessible PDF** check box.

9.  Under **Delivery Type**, select **Download** or **Email**.

10. If you select **Email**, enter an email address in the **Email** field.

11. Select **Export**.


## Result

Depending on the delivery type you selected, the file downloads directly on your system or is sent to the email address you entered.
