# Qualify a demand

Qualify a demand manually in Next Experience for Demand Management, without waiting for an assessment to complete. Qualifying a demand moves it to the Qualified state, where the demand manager can move it forward for approval.

## Before you begin

Demands must be in the Submitted or Screening state.

Role required: it\_demand\_manager

## About this task

Qualifying a demand this way is a manual override — it doesn't require a completed assessment, classic or smart. If smart assessments is enabled for the demand, every open assessment for it is left as is; it isn't automatically canceled by qualifying the demand manually. For more information about how assessments can also qualify a demand automatically, see [Assess demands with smart assessments](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/portfolio-planning/smart-assessments-overview-ppw.md).

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Details** from the navigation menu.

5.  Select **Qualify**.
