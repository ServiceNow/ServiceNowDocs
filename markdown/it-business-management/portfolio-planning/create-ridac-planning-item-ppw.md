# Create RIDAC for a planning item

Create a Risk, Issue, Decision, Action, or Change item and associate it with a planning item in the Portfolio Planning Workspace.

## Before you begin

Role required: sn\_align\_core.apw\_user

## About this task

You can create a RIDAC item directly from a planning item to document and track risks, issues, decisions, actions, and changes that affect your strategic plans. RIDAC items help you manage planning uncertainties and dependencies across your portfolio.

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace** &gt; **Portfolio Planning**.

    The Portfolio Planning view opens, displaying the list of portfolio plans.

2.  From the list of portfolio plans, select one and then select **Planning**.

    The Planning view opens, showing the planning items within the selected portfolio.

3.  From the **Prioritization**, **Roadmap**, or **Hierarchy** tab, select a planning item to which you want to create a RIDAC item.

    If you selected the planning item from the **Roadmap** tab, select **Full details** in the side panel to open the Details page of the planning item.

    The Details tab of the planning item opens.

4.  On the planning item Details page, select the tab for the RIDAC type you want to create:

    -   **Risks** — to create a risk item.
    -   **Issues** — to create an issue item.
    -   **Decision** — to create a decision item.
    -   **Actions** — to create an action item.
    -   **Request Changes** — to create a change item.
    The selected RIDAC tab opens.

5.  Select **New**.

    The RIDAC creation form opens with the planning item information automatically populated.

6.  On the form, fill in the required fields for the RIDAC item.

    For a description of the field values, see the form.

    -   For a Risk, see [RIDAC Risk form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/portfolio-planning/ridac-risk-form-ppw.md).
    -   For an Issue, see [RIDAC Issue form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/portfolio-planning/ridac-issue-form-ppw.md).
    -   For a Decision, see [RIDAC Decision form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/portfolio-planning/ridac-decision-form-ppw.md).
    -   For an Action, see [RIDAC Action form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/portfolio-planning/ridac-action-form-ppw.md).
    -   For a Change Request, see [RIDAC Change Request form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/portfolio-planning/ridac-change-request-form-ppw.md).
7.  Select **Save** to save the record.


## Result

A RIDAC item has been created and is now associated with the planning item.

## What to do next

After creating a RIDAC item, you can:

-   Edit the RIDAC item to add more details, assign ownership, or set status and priority.
-   View the RIDAC item in the RIDAC home page by filtering by the appropriate tab \(All RIDAC, Project RIDAC, Portfolio RIDAC, or Program RIDAC\).
-   If integration is enabled and an execution task is linked to the planning item, view the RIDAC item on the execution task as well.
