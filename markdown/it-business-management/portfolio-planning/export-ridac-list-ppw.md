# Export RIDAC list

Export a filtered list of RIDAC records to Excel, PDF, CSV, or JSON format. You can download the file directly or send it via email to share RIDAC information with stakeholders.

## Before you begin

Role required: User with read or edit access to RIDAC records

**Tip:** You can export any filtered view of RIDAC records, including filtered by risk type, planning scope, state, or other criteria. Filter the RIDAC list first to export only the records you need.

## About this task

Exporting RIDAC records allows you to share risk, issue, decision, action, and change information with team members, stakeholders, or external partners. You can choose to download the file directly or send it via email to one or more recipients.

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace** &gt; **RIDAC**.

2.  Select the RIDAC records you want to export or email.

    For example, to export all risks, select **Risks** under **All RIDAC**. Filter the RIDAC list by planning scope \(All RIDAC, Project RIDAC, Portfolio RIDAC, Program RIDAC\) or by RIDAC type \(Risks, Issues, Decisions, Actions, Request Changes\).

3.  Select **Export**.

4.  On the Export dialog, configure the export options:

    1.  **File type** — Select the format for the exported file: **Excel**, **PDF**, **CSV**, or **JSON**.

    2.  **Delivery type** — Select how you want to receive the file.

        -   **Download** — Select to download the file directly to your computer.
        -   **Email** — Select to send the file via email. Enter one or more email addresses in the **Email** field to specify where the file should be sent.
5.  Select **Export** to complete the export.


## Result

The RIDAC records are exported to the selected file format. If you selected **Download**, the file is downloaded to your default downloads folder. If you selected **Email**, the file is sent to the specified email address\(es\).

The exported file contains all visible columns from the RIDAC list view, including Number, Short description, Planning Item, Planning Item type, State, Priority, Impact, and Due date.
