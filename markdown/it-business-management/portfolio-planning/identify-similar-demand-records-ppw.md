# Identify similar records using AI

Use the identify similar records skill to find demand records with similar names, descriptions, or business case content.

## Before you begin

**Important:** This generative AI skill is turned on by default. The skill will be automatically available to appropriate role users for the application. For more information, see [AI agents, skills, and agentic workflows on by default](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/intelligent-experiences/now-assist-skills-on-by-default.md).

If you have custom roles that require access to this skill, update the ACLs \(access control lists\) for those roles that require access.

Role required: it\_demand\_user

## About this task

-   If similar records exist, the related list displays them.
-   If no similar records are found, a message appears and the related list remains empty.

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Details** from the navigation menu.

5.  Select **Identify similar demands**.

    The similar demands identified by AI are displayed in the top banner and the **Similar Demands** tab.

    \[Omitted image "identify-similar-records-dw.png"\] Alt text: List of similar records identified by AI.


## What to do next

To view full details of a similar demand record, select the demand number link from the **Similar Demands** tab.

**Note:** If the **Similar Demands** tab isn't visible, select **More** &gt; **Similar Demands**.
