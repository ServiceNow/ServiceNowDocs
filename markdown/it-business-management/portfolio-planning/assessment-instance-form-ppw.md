# Assessment instance form

The assessment instance form enables you to create and edit an assessment instance for a demand.

|Field|Description|
|-----|-----------|
|Number|System-generated ID number.|
|State|Current state of the assessment instance. The default value is Ready to take.|
|Metric type|Type of metric used to define the evaluation criteria for the assessment.|
|Assessment group|Group responsible for completing the assessments.|
|Due date|Expected completion date and time for the assessment.|
|Assigned to|Resource responsible for completing the assessment.|
|Expiration date|Date after which the assessment instance is no longer valid.|
|Signature|Signature associated with the assessment instance on completion.|
|Preview|Indicates whether a preview of the assessment is available before submission.|
|Signature result|Outcome or status of the signature collected for the assessment instance.|
