# Configure the demand details fields in Employee Slate

Configure the fields that appear in the demand details ticket page in Employee Slate.

## Before you begin

Role required: admin

## About this task

The demand details ticket page is predefined. Administrators can modify it according to their use cases. By default, the following fields appear on the demand details ticket page in Employee Slate.

-   Business case
-   Risk of performing
-   Risk of not performing
-   Assumptions

## Procedure

1.  Navigate to **All** &gt; **Standard Ticket** &gt; **Standard Ticket Configuration**.

2.  Select the `dmn_demand` record.

3.  Select the Unlock Info fields icon beside **Info fields**.

    \[Omitted image "demand-ticket-config.png"\] Alt text: The Info fields section in the ticket configuration form.

4.  Add or remove fields by selecting the **Add item** or **Remove item** arrows.

5.  Reorder the fields by selecting the **Move up** or **Move down** arrows.

6.  Select the Lock Info fields icon.

7.  Select **Update**.
