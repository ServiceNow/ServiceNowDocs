# Assessment instance question form

The assessment instance question form enables you to create and edit assessment questions associated with an assessment instance.

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

</td><td>

Table from which the assessment instance question originates.

</td></tr><tr><td>

Category

</td><td>

Category of the assessment instance question.

</td></tr><tr><td>

Source

</td><td>

Source record associated with the assessment instance question.

</td></tr><tr><td>

Domain

</td><td>

Domain associated with the assessment instance question. The domain is set to global by default.

</td></tr><tr><td>

Metric

</td><td>

Assessment metric defining the evaluated criteria.

</td></tr><tr><td>

Instance

</td><td>

Assessment instance associated with the question belongs.

</td></tr><tr><td>

Value

</td><td>

Numeric value assigned to the assessment question response.

</td></tr><tr><td>

String value

</td><td>

Text-based response or value provided for the assessment question.

</td></tr><tr><td>

Reference id

</td><td>

System-generated ID of the referenced record associated with the assessment question.

</td></tr><tr><td>

Additional information

</td><td>

Information about the assessment question.
