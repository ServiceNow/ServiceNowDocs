# Configuring demand experiences

Configure demand experiences so that each type of demand has its own dynamic attributes, form view, and visible modules.

A demand experience combines a dynamic category, a form view, and module visibility settings. For an overview of these components, see [Demand experiences](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/portfolio-planning/demand-experiences-ppw.md).

To configure a demand experience, complete the following tasks:

-   Create a dynamic category \(optional\)

    A dynamic category isn't required to create a demand experience. The base system includes a Default demand experience, which enables all demand modules and has no dynamic category. Create a dynamic category only when demands of a type require dynamic attributes. See [Create a dynamic category](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/portfolio-planning/create-a-dynamic-category-ppw.md).

-   Create a demand experience

    Create the demand experience and define its form view, dynamic attributes, and visible modules. See [Create a demand experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/portfolio-planning/create-a-demand-experience-ppw.md).
