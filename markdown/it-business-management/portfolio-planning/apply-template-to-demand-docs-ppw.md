# Use templates with demand Doc pages

Apply a template to demand Doc pages to standardize content structure across demands or save a configured page as a reusable template for your team.

## Before you begin

Role required: it\_demand\_user, it\_demand\_manager, or demand\_approver

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Open a demand from the **List** page.

4.  Select **Docs** from the navigation menu.

5.  In the **Pages** tab, select the Product Requirements page actions icon \[Omitted image "eap-doc-page-actions-icon.png"\] Alt text:.

6.  Determine whether you want to apply a template to the doc or save the doc as a template.
