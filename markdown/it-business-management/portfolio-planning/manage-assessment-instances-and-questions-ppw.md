# Add an assessment instance and its questions

Add assessment instances and associated questions for a demand to evaluate its feasibility and gather structured feedback from stakeholders.

## Before you begin

Role required: it\_demand\_manager

## Procedure

1.  Open a demand from the home page of Next Experience for Demand Management.

    For more information, see .

2.  Select **Details** from the L-2 \(level 2\) navigation menu.

3.  Select the **Assessment Instances** tab.\[Omitted image "assessment-instances-demand.png"\] Alt text: Use the Assessment Instances tab to add or edit assessment instances for a demand.

    **Note:** If the **Assessment Instances** tab isn't visible, select **More** &gt; **Assessment Instances**.

4.  Select **New**.

5.  On the Assessment Instance form, fill in the fields.

    For a description of the field values, see [Assessment instance form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/portfolio-planning/assessment-instance-form-ppw.md).

6.  Select **Save**.

    The assessment instance is added.

7.  Select the **Assessment Instance Questions** tab.

8.  Select **New**.

9.  On the Assessment Instance Question form, fill in the fields.

    For a description of the field values, see [Assessment instance question form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/portfolio-planning/create-assessment-question-form-ppw.md) form.

10. Select **Save**.


## Result

The assessment instance and the associated instance questions are added.

**Note:** When the assessment instance moves to the **Ready to take** state, or the **Assigned to** user changes, the assigned user receives an "Assessment notification for Demand" email with a link to take the assessment, and a link to their assessment queue under **Self Service** &gt; **My Assessment &amp; Surveys**.
