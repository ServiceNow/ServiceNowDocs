# View the Demands Dashboard

Use the Demands Dashboard to monitor performance, track progress, and make informed decisions about demands.

## Before you begin

Role required: it\_demand\_manager, it\_demand\_user, or ppm\_read

## About this task

Dashboards consolidate data from multiple sources into a single, easily digestible format. Each widget within a dashboard displays key data and metrics and may include visualizations.

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  Select a tab to view its data and metrics.

4.  Select a widget to view more details in list view.

    If you have edit access, you can update the details of an individual record directly from the list view.
