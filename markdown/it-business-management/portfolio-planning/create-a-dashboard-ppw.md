# Create or manage a dashboard

In the Platform Analytics experience, you can create, duplicate, share, and export dashboards with data visualizations, filters, and other elements.

## Before you begin

Role required: it\_demand\_manager, it\_demand\_user

## About this task

The inline editor provides elements for adding widgets, filters, and visualizations to a dashboard.

## Procedure

1.  Navigate to **Workspaces** &gt; **Portfolio Planning Workspace**.

2.  Select the Demands icon \[Omitted image "demands-icon.png"\].

3.  From the dashboard header, select the More actions icon\[Omitted image "more-actions.png"\] Alt text: More actions icon in the portfolio plan header..

4.  Create, duplicate, share, or export the dashboard.

    3.  Enter a brief description for the dashboard in the **Description** field.

**Duplicate a dashboard**

</td><td>

1.  Select **Duplicate**.
2.  On the Duplicating dashboard window, enter the details:
    -   Enter a name for the dashboard in the **New name** field. By default, the name is **Demands dashboard - Copy** , where "Demands dashboard" is the name of the original dashboard.
    -   Enter a brief description of the goal in the **Description** field.
3.  Select **Duplicate**.
 The dashboard may take time to duplicate. Select **Continue in background** to keep using the application in the meantime.

</td></tr><tr><td id="d167245e201">

**Share a dashboard**

</td><td>

1.  Select **Share**.
2.  On the Share Dashboard window, enter the details:
    -   Enter a user name or group name in the **Grant access to** field. Use a user name for individual access or a group name for group access.

To grant access to all users with a specific role, select that role.

    -   Select **Allow recipients to add, edit, or delete sharing permissions associated with this dashboard** to enable users to grant access to new users and modify or remove existing permissions.
    -   Select **Add as viewer** or **Add as editor**.

The selected users, groups, and roles appear under **Manage Access**.

To manage sharing permissions, select a user, group, or role and enable the **Can share** option.

3.  Select **Confirm**.
 To update sharing rights, open the Share Dashboard dialog. Under the **Can view** or **Can share** list, select a user, group, or role and adjust permissions.

</td></tr><tr><td id="d167245e272">

**Export a dashboard**

</td><td>

1.  Select **Export**.
2.  On the Export Dashboard window, enter the details:
    -   Select the file type as **PowerPoint** or **PDF**.
    -   Select or clear the toggles for **Export all tabs** and **Export with applied filters**.
    -   Select the delivery type as download or email.
    -   Optional: For email, enter the recipients and subject.
3.  Select **Export**.
 -   For downloads, the file is downloaded to your local system.
-   For email deliveries, the file is sent to the recipients.
