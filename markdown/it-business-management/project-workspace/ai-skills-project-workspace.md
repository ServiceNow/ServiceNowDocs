# AI skills in Project Workspace

Use AI skills to transform Project Workspace into a continuous value engine. Embed intelligence across every stage to optimize resources and investments.

## Refine records

Improve record quality by enabling AI assistance in the rich and long fields of multiple forms. These include Product idea, Demands, Epic, Projects, Capability, Features, Stories, Project tasks, Risks, Strategic priorities, Goals, Targets, Initiatives, Feedback, Milestones, and Story forms. Enable text refinement with the **Elaborate** and **Shorten** options. This supports portfolio, project, product, and demand managers and agile team members in creating and editing record content more effectively.

## Project doc generation and insights, Planning Item doc generation and insights, or EAP doc generation and insights

Provides product managers with a concise and informative summary of the selected or complete text by using AI in Docs. Product managers can summarize, elaborate, or shorten the selected or complete content on Docs to quickly understand the key information. Use the Project doc generation and insights \(Project Workspace\), Planning item doc generation and insights \(Strategic Planning\), or EAP doc generation and insights \(Enterprise Agile Planning\) skill.

## Project insights generation

Monitor the progress and changes in each project through the Project insights generation skill. With minimal effort, your project managers can schedule a cadence for generating project insights and receive it via email. They can track key elements such as the project, project task, milestone, resource assignment, ridac, and financial. They can also prioritize key elements to focus on. They can also decide the cadence of receiving project insight emails.

## Project status generation

Generate an AI‑assisted project status report using project status generation skill.

With project status generation skill, AI predicts overall and dimension‑level project health \(such as schedule, cost, resources, and scope\), generates an executive summary using weekly project data, and provides a rationale for each prediction. Project Managers can generate a status report where AI pre-populates key fields:

-   Overall project health
-   Health by dimensions \(schedule/cost/resources/scope\)
-   Executive summary
-   Rationale/analysis for each predicted health value

This skill streamlines the process of status report creation in Project Workspace.
