# Manage project tasks in Employee Slate

Add work notes, attachments, or edit the project tasks details using the Project Tasks widget on your Employee Slate.

## Before you begin

Role required: sn\_csm\_ppm.project\_task\_writer

## Procedure

1.  Navigate to Employee late using the following URL.

    ```
    https://<instance-name>.service-now.com/aiux/employeeslate/home
    ```

    **Note:** The URL may change based on your configuration in Branding and Theme.

2.  Select **Canvas** from the side menu.

3.  If you don't see the Project Tasks widget, add the widget as follows.

    1.  Select the **Edit** icon.
    2.  Select **Add item**.
    3.  Select the check box against Tasks widget and select **Add item**.
    Widget is added to your canvas and it lists all the task which are assigned to you.

4.  Select a task name from the widget to review or update a task.

    To view all of your assigned customer project tasks, select the open full list icon in the widget header.

    The task detail page opens for the selected task.

5.  Edit the required fields from Task details, Activity, Attachments, Checklist, or Dependencies section and select **Save**.
