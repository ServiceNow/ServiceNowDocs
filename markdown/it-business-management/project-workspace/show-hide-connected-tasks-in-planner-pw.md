# Show or hide connected CWM tasks on the planning page

Enable or disable the display of connected Collaborative Work Management \(CWM\) tasks and stories on the Project planning page.

## Before you begin

Collaborative Work Management \(CWM\) must be active in your instance. The **Show connected tasks** toggle appears on the Settings side panel only when CWM is enabled.

Role required: it\_project\_manager or it\_project\_user

## About this task

The **Show connected tasks** setting is turned on by default. When on, CWM tasks and stories linked to your project tasks appear inline as child rows under each project task on the planning page. When off, only the regular project tasks are displayed.

The setting is saved as a personal preference for you. Turning it off for one project turns it off across every project you open.

## Procedure

1.  Open a project in Project Workspace and go to the planning page.

2.  Select the Settings icon \(\[Omitted image "icon-settings.png"\] Alt text: Settings icon.\).

    The Settings side panel opens.

3.  Select the **General** tab.

4.  Turn the **Show connected tasks** toggle on or off.

    Turning the toggle off hides all connected CWM tasks and stories from the planning page. Regular project tasks and their non-CWM children remain visible.


## Result

The planning page immediately reflects the setting. Your preference persists across sessions and applies to every project you open.
