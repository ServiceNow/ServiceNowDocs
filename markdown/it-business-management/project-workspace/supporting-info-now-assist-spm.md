# Supporting information for ServiceNow Otto for Strategic Portfolio Management

Get a quick overview of the important information that is related to the ServiceNow Otto for Strategic Portfolio Management application.

## Supported versions

The ServiceNow Otto for SPM application is supported starting with the Xanadu patch 3 release.

## Supported user interfaces

The ServiceNow Otto for SPM application is supported for the Strategic Planning Workspace, Project Workspace, Demand Management, and Enterprise Agile Planning.

## Licensing requirements

The ServiceNow Otto for SPM application requires an SPM Pro plus license.

## Application information

Activate the latest ServiceNow Otto for SPM \(sn\_spm\_gen\_ai\) store app to use the Now Assist skills.

This store app has the following dependencies:

-   Now Assist for Platform \(sn\_genai\_platform\)
-   Strategic Planning
-   Project Workspace
-   Enterprise Agile Planning
-   Demand workbench

For more information, see [Configure AI Admin Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-business-management/project-workspace/configuring-na-spm.md).
