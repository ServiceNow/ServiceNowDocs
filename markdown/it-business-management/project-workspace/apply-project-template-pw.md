# Apply a template to a project

Apply a saved project template to a project in Project Workspace to reuse a planned set of tasks and sub-projects.

## Before you begin

Role required: it\_project\_manager

A project template must exist. For more information, see [Save a project as a template](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/project-workspace/save-project-template-pw.md).

## Procedure

1.  Open a project from the home page of Project Workspace.

    For information, see [Access the Project Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/project-workspace/access-new-project-workspace.md).

2.  Select **Planning**.

3.  From the More actions \(\[Omitted image "more-actions-homepage-icon.png"\] Alt text: more action icons.\) menu, select **Apply template**.

4.  In the Apply Template dialog, select a template from the **Project template** field.

5.  Select **OK**.


## Result

The tasks and sub-projects from the template are added to the project plan.
