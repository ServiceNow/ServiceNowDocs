# Save a project as a template

Save the plan of an existing project as a template to reuse the tasks and sub-projects in other projects in Project Workspace.

## Before you begin

Role required: it\_project\_manager

## About this task

A project template stores the plan of a project, such as its project tasks and sub-projects. After you save a template, you can apply it to other projects or select it when you create a project from a template.

## Procedure

1.  Open a project from the home page of Project Workspace.

    For information, see [Access the Project Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/project-workspace/access-new-project-workspace.md).

2.  Select **Details**.

3.  Add the project tasks and sub-projects to include in the template.

    You can add them from the **Project Tasks** and **Sub Projects** tabs on the Details page.

4.  From the More actions \(\[Omitted image "more-actions-homepage-icon.png"\] Alt text: more action icons.\) menu, select **Save as New Template**.

5.  Enter a name in the **Template name** field.

6.  Enter a description of the template in the **Description** field.

7.  Select **OK**.


## Result

The template is saved and is available to select when you apply a template to a project or create a project from a template.
