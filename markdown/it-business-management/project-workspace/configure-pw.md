# Configuring Project Workspace

Set up and configure the Project Workspace application to initiate and plan your projects, financials, and resources.

-   **[Configuring resources with Project Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/it-business-management/project-workspace/configure-resource-mgmt-prj-wksp.md)**
