# Work with project tasks in Employee Slate

The Project Tasks widget shows employees a quick view of the customer project tasks assigned to them on the Employee Slate.

The Project Tasks widget is a canvas widget on the Employee Slate for the Project Workspace. It gives employees visibility into their project tasks without leaving their dashboard.

The widget displays count of the tasks assigned to the logged-in user. Each task in the list shows its short description, current status, and the project it belongs to.

From the widget, employees can take two actions:

-   Select a task to open its task details.
-   Select the expand icon to open the full list of assigned customer project tasks.

If an employee has no assigned customer project tasks, the widget displays an empty state message instead of a list. If the task data fails to load, the widget displays an error message.

Users need sn\_csm\_ppm.viewer role to view the widget and sn\_csm\_ppm.project\_task\_writer to edit the task records.
