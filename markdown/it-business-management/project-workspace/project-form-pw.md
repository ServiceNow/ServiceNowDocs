# Project form in Project Workspace

Learn about the fields on the forms that you use to create a project in Project Workspace, either as a new project or from a project template.

## Project form

Select **New project** on the Project Workspace homepage to open this form.

<table id="table_new_project_form_pw"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Project class

</td><td>

Type of project that you want to create. Options include: project, customer project, and TeamSpace1 project.

</td></tr><tr><td>

Project name

</td><td>

Name of the project.

</td></tr><tr><td>

Project type

</td><td>

Project type that determines the custom fields, form layout, and modules applied to this project. For more information, see [Project type form](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-business-management/project-workspace/project-type-form-pw.md).

</td></tr><tr><td>

Approved start date

</td><td>

Date and time that the project is approved to start.

</td></tr><tr><td>

Approved end date

</td><td>

Date and time that the project is approved to end.

</td></tr><tr><td>

Planned duration

</td><td>

Planned length of the project in days, hours, minutes, and seconds.

</td></tr><tr><td>

Description

</td><td>

Brief description of the project.

</td></tr></tbody>
</table>## Project from template form

Select the drop-down arrow next to **New project** and then select **New project from template** to open this form.

<table id="table_gfs_gjy_hsb"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Project class

</td><td>

Select the type of project that you want to create. For example, a regular project, customer project, or TeamSpace project.

</td></tr><tr><td>

Project template

</td><td>

Template to apply for your project. If the template you need is not available in the list, you can create it later and apply to your project.

</td></tr><tr><td>

Project name

</td><td>

Preferred name of the project.

</td></tr><tr><td>

Planned start date

</td><td>

The date that you plan to start the tasks for this project.
