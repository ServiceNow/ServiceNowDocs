# ServiceNow Otto for Employee Center Pro release notes

Version history for ServiceNow Otto for Employee Center on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.2.4 - August 2026**

    Updated to support the latest version of the dependent apps.

-   **Version 1.1.9 - December 2025**

    Added support for Now Assist Suite to enhance the installation/upgrade experience.

-   **Version 1.0.4 - October 2025**

    The Now Assist for Employee Center Pro application bundles the required Now Assist capabilities for delivering an enterprise wide AI experience for employees. Employees can search across the enterprise, access tasks across systems, and more through an omni-channel conversational AI experience.
