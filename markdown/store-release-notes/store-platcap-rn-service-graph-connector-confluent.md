# Service Graph Connector for Confluent release notes

Version history for the ServiceNow® Service Graph Connector for Confluent application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.2 - October 2026**

    Importing Confluent Cloud's configuration into the ServiceNow CMDB provides visibility of the Kafka estate within the ServiceNow platform and enables workflows and business context to be applied to clusters, topics, and other elements of the Kafka ecosystem.
