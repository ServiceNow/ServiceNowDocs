# Service Graph Connector for NetBrain release notes

Version history for the ServiceNow® Service Graph Connector for NetBrain application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.2 - October 2026**

    NetBrain is a network automation and visibility platform designed to help IT teams manage, troubleshoot, and document complex enterprise networks. The integration pulls switch and router details from Netbrain and populates ServiceNow CMDB. The integration is compliant with Service Graph Connectors.
