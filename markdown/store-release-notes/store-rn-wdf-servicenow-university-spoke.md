# ServiceNow University Spoke release notes

Version history for the ServiceNow® University Spoke application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.1.1 - September 2026**
    -   This integration enables the Now learning content from ServiceNow instance.
        -   This spoke imports Course Items and Learning paths from the Now learning instance to the ServiceNow instance.
        -   This spoke imports and updates user course progress and completion history in the ServiceNow instance.
    -   When used with workforce optimization:
        -   As a manager, you can assign course items to employees from the Manager Workspace.
        -   As an IT employee, you can enroll in the course items from the Service Operations Workspace.
