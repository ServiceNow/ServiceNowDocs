# Service Lifecycle Request release notes

Version history for the ServiceNow® Service Lifecycle Request application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.1 - October 2026**

    Account Changes is a new base case type in Telecom Service Management that establishes the foundation for all customer-initiated changes to service ownership. Transfer of Responsibility is the first of child case types extending Account Changes with its own table and journey. This hierarchy allows each account change type to carry its own fields, eligibility logic, and workflows while inheriting shared infrastructure — routing, SLAs, audit, consent frameworks, and reporting — from the parent. New account change types are added as child tables extending Account Changes rather than standalone implementations.
