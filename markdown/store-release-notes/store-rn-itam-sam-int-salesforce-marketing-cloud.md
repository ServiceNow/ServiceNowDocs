# Software Asset Management integration with Salesforce Marketing Cloud release notes

Version history for the ServiceNow® Software Asset Management integration with Salesforce Marketing Cloud application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.2.11 - September 2026**
    -   The Software Asset Management Salesforce Marketing Cloud connector provides actions that a process analyst can use when designing flows. The actions allow them to automate SAM tasks for Salesforce Marketing Cloud.
    -   The Software Asset Management integration with Salesforce Marketing Cloud is built by Bristlecone, Inc.
