# Service Graph Connector for BlueCat release notes

Version history for the ServiceNow® Service Graph Connector for BlueCat application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.0 - October 2026**

    The Service Graph Connector for BlueCat imports IP and network data from BlueCat Networks quickly, seamlessly, and securely. BlueCat is a highly scalable and automation-friendly DDI solution that provides a single source of truth for network teams to reduce errors and speed up operations. The Service Graph Connector for BlueCat enables you to pull such IP data to enrich ServiceNow's CMDB, enabling use cases such as incident management, change management, and service mapping, with smarter network planning, fastertroubleshooting, and enhanced support.

    The Service Graph Connector for BlueCat imports data consistent with the other connectors and the rest of the ServiceNow ITOM suite, ensuring your CMDB isclean, consistent, and fully aligned with all the network information across your environment. Its plug-and-play configuration is compatible with SGC Central, making it easy and straightforward to set up. The connector supports the use of tags from BlueCat and handles the life cycle of networks and IPs, giving you complete discretion on your policies.
