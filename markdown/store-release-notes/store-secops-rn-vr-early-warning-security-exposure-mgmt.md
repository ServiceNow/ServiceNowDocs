# Early Warning for Security Exposure Management release notes

Version history for the ServiceNow® Early Warning for Security Exposure Management application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.4 - July 2026**
    -   To use this application, verify you are on Vulnerability Response \(VR\) version 30.0 or later, which automatically includes the required Unified Security Exposure Management \(USEM\) capabilities. You also need an active Armis Centrix for Early Warning subscription and a configured Armis API key.
    -   Strengthen vulnerability management with early warning on the threats that matter. Powered by Armis Threat Intelligence \(ATI\), this integration enriches CVEs with Early Warning data, flagging the Common Vulnerabilities and Exposures \(CVEs\) that threat actors are actively targeting or exploiting. These insights are derived from deception honeypots, threat-actor infiltration, and operational vulnerability research. Each signal carries the supporting evidence and a source-confidence rating, enabling teams to assess the reliability of intelligence, prioritize effectively, and improve visibility across Security Exposure Management. Focus remediation efforts on real, imminent threats before they become widespread.
