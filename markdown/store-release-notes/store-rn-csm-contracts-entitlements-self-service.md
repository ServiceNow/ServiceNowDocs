# Contracts and Entitlements Self Service release notes

Version history for the ServiceNow® Contracts and Entitlements Self Service application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.1 - September 2026**

    Contracts and Entitlements self-service empowers customers to independently review their contracts, contract lines, and entitlement details directly within the portal — eliminating the need for agent assistance. Customers gain real-time visibility into their active contracts and associated entitlements
