# AI Service Graph Connector for GitHub Copilot release notes

Version history for the ServiceNow® AI Service Graph Connector for GitHub Copilot application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.11 - November 2026**

    The AI Service Graph Connector for GitHub Copilot extends AI Control Tower Discovery to GitHub's Copilot agent ecosystem. Using OAuth and CBA authentication, the connector automatically discovers organizations, repositories, and supported GitHub Copilot assets that are accessible to the authenticated GitHub account.
