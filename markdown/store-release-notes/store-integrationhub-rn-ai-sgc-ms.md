# AI Service Graph Connector for Microsoft release notes

Version history for the ServiceNow® AI Service Graph Connector for Microsoft application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 3.1.19 - September 2026**
    -   New:
        -   Certificate based authentication support for setting up Microsoft connector. Support discovery across multiple Copilot environments through a single connection.
        -   Microsoft Agent365 Discovery Connector:
            -   Discover AI assets from Microsoft Agent365 registry which includes agents from Microsoft environments such as Copilot, Azure Foundry, Agent Builder etc. and non-Microsoft environment for the external AI connectors set up in Agent365 registry
            -   Catalog agents, models, tools and prompts across these environments into
            -   Support for automated deduplication of existing assets in
-   **Version 3.1.7 - August 2026 \(Australia\)**
    -   New:
        -   Unified single-page connection for Azure ML and AI services. Admins can now configure both machine learning and AI connections for Microsoft Azure Foundry and Copilot using a single interface, with records created for both services and automated test connections.
        -   Resource group discovery and storage for Azure Foundry assets. The system now discovers and stores the resource group information for each asset or agent in Microsoft Azure Foundry.
        -   Certificate-based authentication for Azure Foundry and Copilot. Certificate-based authentication is now available as an option alongside existing client credentials, supporting JWT client-assertion signing and centralized alias management for both Azure and Copilot connections.
        -   Knowledge Base integration in configuration review. The configuration review step now displays an attached Knowledge Base article with up-to-date configuration details, which can be updated independently for Azure Foundry and Microsoft Copilot.
    -   Changed:
        -   Standardized Create and Test Connection experience. The Create and Test Connection features now use a standard template with helper content describing each field, providing a consistent and informative setup process for users.
        -   Combined configuration for Azure Foundry and Copilot. Both Azure and Copilot services are now managed through a single configuration page, with unified validation, provisioning, and deprovisioning processes. Service-specific data sources and scheduled imports are tagged and managed independently within the shared connection.
