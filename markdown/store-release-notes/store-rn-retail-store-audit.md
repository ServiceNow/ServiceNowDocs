# Retail Store Audit release notes

Version history for the ServiceNow® Retail Store Audit application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.2.0 - July 2026**

    The Retail Store Audit Operations application enables structured, repeatable store audit programs across retail locations. It automates the creation and assignment of audit cases and tasks to field teams, and gives store leadership real-time visibility into progress and fulfillment across every store in scope.
