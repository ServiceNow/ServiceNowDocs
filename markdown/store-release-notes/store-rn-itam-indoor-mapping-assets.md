# Indoor Mapping for Assets release notes

Version history for the ServiceNow® Indoor Mapping for Assets application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.1.0 - September 2026**

    ServiceNow Indoor Mapping for assets provides native creation of indoor maps, including navigation. Asset managers can visualize and locate assets on indoor maps within a selected campus, building, and floor.
