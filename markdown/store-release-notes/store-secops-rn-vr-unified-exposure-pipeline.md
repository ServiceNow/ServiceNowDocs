# Unified Exposure Pipeline release notes

Version history for the ServiceNow® Unified Exposure Pipeline application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.10 - November 2026**
    -   Note:
        -   This app is intended for Unified Security Exposure Management \(USEM\), a significant architectural upgrade to the Vulnerability Response applications.
        -   If you are currently using Vulnerability Response and upgrading to USEM for the first time, you must use the Migration assistant for Unified Security Exposure Management to ensure a safe and successful upgrade. For full details, please refer to the Unified Exposure Pipeline centralises scanner integration through a unified ingestion and normalisation pipeline that normalises and enriches assets and exposure findings from across scanners.
    -   Note: Unified Exposure Pipeline cannot be leveraged alongside the standard scanner integration apps. All standard scanner integrations must be disabled, and the data must be cleared before the unified exposure pipeline can be used.
