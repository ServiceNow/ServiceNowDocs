# TNI - Advanced release notes

Version history for the ServiceNow® TNI - Advanced application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 2.0.2 - July 2026**

    Brings ServiceNow Agentic AI to Telecommunications Network Inventory through the shared Network Inventory / Data Center Network GenAI content. Includes the autonomous infrastructure-allocation agent that turns free-text change requests into validated, policy-aware allocations with full traceability in the Network Inventory workspace.
