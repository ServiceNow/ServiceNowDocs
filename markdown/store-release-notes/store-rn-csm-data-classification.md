# CSM Data Classification release notes

Version history for the CSM Data Classification application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.3.2 - September 2026**

    Changed: CSM Data Classification \(com.snc.csm\_data\_privacy\) plugin is renamed to CRM Data Classification.

-   **Version 1.2.0 - August 2026**
    -   New: CRM Data Classification plugin is now available in Fluent. All core data classification records and workflows have been migrated from legacy XML to Fluent, supporting full plugin functionality and validation in the new format. Admins can now manage CRM Data Classification using the Fluent SDK structure, with all plugin records, templates, and field-level validations preserved.
    -   Changed: The CSM Data Classification plugin has been renamed to CRM Data Classification. The plugin ID, configuration files, guided setup, and automations now reflect the new name across the system.
-   **Version 1.1.0 - June 2026**

    No release notes.

-   **Version 1.0.0 - August 2025**

    The Data Classification Store Application is being developed to simplify the process for ServiceNow administrators to protect sensitive data within the platform. It aims to provide out-of-the-box \(OOB\) templates for SN workflows and different compliances, which will help in quickly applying protection policies without the need for manual planning and inventory creation.
