# DevOps Feature Flag Integrations release notes

Version history for the ServiceNow® DevOps Feature Flag Integrations application on the ServiceNow Store.

-   **Version 7.1.1 - September 2026**

    Changed: No code updates were made in this release. The release number has been updated to maintain consistency with changes in related DevOps applications.

-   **Version 7.0.0 - June 2026**

    The Split Feature Flag tool is now integrated with ServiceNow DevOps to support change acceleration for feature flag updates.
