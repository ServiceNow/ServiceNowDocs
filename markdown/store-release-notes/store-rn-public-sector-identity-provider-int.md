# Identity Provider Integration release notes

Version history for the ServiceNow® Identity Provider Integration application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.1 - October 2026**

    A foundational data model providing the table, fields, and access control rules needed to integrate ServiceNow with OpenID Connect \(OIDC\) identity providers, enabling trusted authentication and identity verification.
