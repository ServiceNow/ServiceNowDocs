# Field Service Resource Scheduling release notes

Version history for the ServiceNow® Field Service Resource Scheduling application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 30.1.5 - September 2026**

    Resource Scheduling extends Field Service Management's scheduling engine to cover equipment. Instead of dispatchers manually managing equipment assignments separately from crew assignments, they assign tools and parts to work order tasks alongside the technicians who need them, matched by skill and availability with the same precision used for crew formation. Technicians arrive equipped with both the required skills and necessary parts to complete the task on the first visit.
