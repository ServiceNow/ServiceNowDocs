# Advanced Approval Management AI release notes

Version history for the ServiceNow® Advanced Approval Management AI application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.2.2 - September 2026**
    -   New:
        -   Delta between quote versions
        -   support adding adhoc approvals
        -   Approval step and condition details
-   **Version 1.1.1 - August 2026**
    -   New:
        -   Enable sales agents and approvers to add ad-hoc approvers from Claude Desktop.
        -   Enable sales agents to recall approval requests from Claude Desktop.
-   **Version 1.0.0 - July 2026**

    MCP tools for Advanced Approval Management enable agents to submit quotes for approval and approvers to take action on approval requests directly from their MCP client, such as the Claude desktop application, eliminating the need to log in to the ServiceNow instance. By integrating with the Sales CRM MCP server, this application ensures that agents can manage approvals efficiently without switching between multiple systems.
