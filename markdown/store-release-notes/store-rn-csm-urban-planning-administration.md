# CSM Urban Planning Administration release notes

Version history for the ServiceNow® CSM Urban Planning Administration application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.2 - October 2026**

    Urban Planning &amp; Permitting Administration is the unified platform for government land management, designed to modernize property administration, streamline permitting workflows, and enable evidence-based urban planning decisions.

    Purpose-built foundation of property-centric data models, planning workflows, and enterprise-grade architecture transforms fragmented land records and spreadsheet-driven permitting processes into a single source of truth for urban planning operations. Urban Planning provides a standard architecture for managing complex property portfolios, zoning regulations, and permitting workflows with a government-optimized data model supporting cross-jurisdictional land administration.
