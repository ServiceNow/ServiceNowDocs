# Access Analysis AI Agents release notes

Version history for the ServiceNow® Access Analysis AI Agents application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.4 - September 2026**

    ServiceNow Access Analysis AI Agents introduces the Access Analysis Agent, a ServiceNow Otto AI agent that allows administrators, developers, and security teams to ask natural-language questions about access and get instant, explainable answers.Users can ask questions like "Can Abel Tuter read this record?" or "Why can't the itil role write to the incident table?", and then the agent can then evaluate the access using Access Analyzer's underlying engine. It responds in conversational language while citing the specific ACLs and conditions involved.
