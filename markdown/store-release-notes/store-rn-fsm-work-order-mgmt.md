# FSM: Work Order Management release notes

Version history for the ServiceNow® FSM: Work Order Management application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 2.1.6 - September 2026**

    Service teams often manage work requests, scheduling, parts, and cost tracking across disconnected tools which slows dispatch and makes job costing unreliable. Work Order Management gives dispatchers and technicians one native record for the full requirement: creating and managing work orders and tasks, tracking parts, labor, and costs, and applying templates for repeat work. Work moves from request to close without handoffs between separate systems.
