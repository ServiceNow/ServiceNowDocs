# AI Agents for Meetings release notes

Version history for the ServiceNow® AI Agents for Meetings application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.10 - September 2026**

    Touchpoint Conversations Brief, Builder skill, Transcript skill for Post meeting and Premeeting preperation skill with recorring meetings and TOuchpoint details.

-   **Version 1.0.6 - August 2026**
    -   AI Agents for Meetings is a ServiceNow application that brings agentic AI into the meeting lifecycle. Rather than requiring teams to manually gather context, draft agendas, and coordinate logistics, the application handles that work automatically — reading relevant records, proposing a complete meeting, and presenting it for review and confirmation.
    -   Delivered as a standalone plugin \(sn\_meeting\_ai\_ag\), AI Agents for Meetings is designed to work across teams and use cases beyond any single workflow. As the application grows, it will extend across the full meeting lifecycle — pre-meeting preparation, participant briefing, conversation guidance, and follow-through — making intelligent meeting support available wherever teams need it.
