# Field Service Work Configurations release notes

Version history for the ServiceNow® Field Service Work Configurations application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 31.0.2 - September 2026**

    Work Configuration lets admins set up different field sets and state flows for work orders, so each business unit or department can run field service work the way its operations require. Each configuration can also turn specific business properties on or off, so behavior that applies to one department doesn't apply into another.
