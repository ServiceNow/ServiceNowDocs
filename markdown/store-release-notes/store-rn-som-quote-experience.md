# Quote Experience release notes

Version history for the ServiceNow® Quote Experience application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 2.2.4 - September 2026 \(Australia\)**

    The Quote Experience application provides a modern quoting experience embedded in your CRM that enables sellers to create, update, and manage quotes end-to-end using scalable microservices and built-in sales capabilities.
