# Invoice Self-Service release notes

Version history for the ServiceNow® Invoice Self-Service application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.5.0 - September 2026 \(Australia\)**

    Maintenance release. Contains internal code updates with no impact to existing functionality or user-facing behavior.

-   **Version 1.4.0 - September 2026 \(Zurich\)**

    Maintenance release. Contains internal code updates with no impact to existing functionality or user-facing behavior.

-   **Version 1.3.1 - August 2026 \(Australia\)**

    Changes: Maintenance release. Contains internal code updates with no impact to existing functionality or user-facing behavior.

-   **Version 1.3.0 - August 2026 \(Zurich\)**

    Changed: Maintenance release. Contains internal code updates with no impact to existing functionality or user-facing behavior.

-   **Version 1.0.0 - March 2026**

    Enable seamless invoice self‑service on the ServiceNow Business Portal, enabling customers to view, track, and manage invoices efficiently while supporting streamlined financial operations.
