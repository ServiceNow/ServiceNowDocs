# Field Service Task Bundling release notes

Version history for the ServiceNow® Field Service Task Bundling application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 30.0.9 - September 2026**
    -   FSM Task Bundling extends ServiceNow Field Service Management with intelligent, automated task grouping that helps dispatchers organize and assign work more efficiently. Instead of managing every work order task individually, dispatchers can group related tasks into bundles — treating each bundle as a single schedulable unit for dynamic scheduling and route optimization.
    -   With FSM Task Bundling, administrators define policies and rules that automatically consolidate eligible tasks based on custom business criteria — such as assignment group, territory, task type, duration, or any field-level condition. Bundles are generated on demand or on a schedule, keeping dispatch queues organized and field teams focused.
