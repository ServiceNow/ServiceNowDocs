# Sales Territory Management release notes

Version history for the ServiceNow® Sales Territory Management application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 2.7.1 - September 2026 \(Australia, Brazil\)**
    -   New:
        -   Accounts are now automatically assigned to a sales territory at creation time when an active sales territory model is configured, removing the need for manual assignment.
        -   When an Account's Sales Owner is synced to the Account Team Member table, the member is now created as Active with a start date recorded.
    -   Changed:
        -   Sales Territory Management is now supported with Fluent.
        -   The Run Assignment algorithm has been characterized for maximum supported territory hierarchy depth.
    -   Fixed:
        -   A minor issue for Territory assignment on manual Opportunity Allocation splits.
        -   Eliminated repeated errors and processing overhead during territory access evaluation on Opportunity and Quote records thereby improving preformance.
-   **Version 2.6.3 - September 2026 \(Zurich\)**
    -   New:
        -   Accounts are now automatically assigned to a sales territory at creation time when an active sales territory model is configured, removing the need for manual assignment.
        -   When an Account's Sales Owner is synced to the Account Team Member table, the member is now created as Active with a start date recorded.
    -   Changed:
        -   Sales Territory Management is now supported with Fluent.
        -   The Run Assignment algorithm has been characterized for maximum supported territory hierarchy depth.
    -   Fixed:
        -   A minor issue for Territory assignment on manual Opportunity Allocation splits.
        -   Eliminated repeated errors and processing overhead during territory access evaluation on Opportunity and Quote records thereby improving preformance.
-   **Version 2.5.0 - August 2026 \(Australia\)**

    New: Sales territory management application now supports the Fluent framework. Users can access the sales territory application with updated functionality and interface powered by the ServiceNow Fluent SDK.

-   **Version 2.4.1 - August 2026 \(Zurich\)**

    New: Sales territory management application now supports the Fluent framework. Users can access the sales territory application with updated functionality and interface powered by the ServiceNow Fluent SDK.

-   **Version 2.3.6 - June 2026 \(Australia\)**

    This release addresses minor defect fixes.

-   **Version 2.2.5 - June 2026 \(Zurich\)**

    This release addresses minor defect fixes.

-   **Version 2.3.0 - April 2026 \(Australia\)**

    This release includes: Minor enhancements to support Sales Territory on Opportunity Allocations.

-   **Version 2.2.1 - April 2026 \(Zurich\)**

    This release includes: Minor enhancements to support Sales Territory on Opportunity Allocations.

-   **Version 2.1.0 - March 2026**

    New: Introduced 'Sales Territory Member' role, granting users permission to view sales territories on CRM entities such as Lead, Opportunity, Account, or Consumer.

-   **Version 1.0.0 - December 2025**

    Sales Territory Management enables customers to systematically organize their sales efforts by segmenting them into distinct territories. These territories can be defined geographically, by product line, or by industry. The primary objective is to ensure that the right sales representatives address the appropriate accounts, leads, and opportunities, thereby optimizing sales activities. The focus is on dividing the market into manageable segments to ensure comprehensive and efficient coverage.
