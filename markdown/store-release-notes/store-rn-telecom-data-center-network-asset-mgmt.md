# Data Center Network Asset Management release notes

Version history for the ServiceNow® Data Center Network Asset Management application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 6.2.2 - July 2026**
    -   The Data Center Network Asset Management \(DCNAM\) application delivers a fully integrated suite for managing the complete lifecycle of physical and virtual assets in data center environments.
    -   DCNAM acts as a unified solution bundle that combines Hardware Asset Management, Enterprise Asset Management, Planned Maintenance Management, and Telecom Network Inventory \(TNI\) capabilities into a single deployment. Operations teams gain a single-pane-of-glass view across hardware, network, and maintenance processes — eliminating siloed tools and accelerating time-to-value.
    -   Built on the ServiceNow platform, DCNAM enables:- End-to-end hardware asset lifecycle tracking from procurement to retirement- Enterprise-grade asset management with data-center-specific extensions \(sn\_eam\_dcnam\)- Telecom network inventory integration for TNI-based environments- Planned and preventative maintenance scheduling tied directly to asset records- Unified visibility across physical infrastructure, network devices, and virtual assets
    -   DCNAM is the recommended starting point for telecommunications and data center customers deploying ServiceNow's Industry - Telco solution suite.
