# Appointment Booking release notes

Version history for the ServiceNow® Appointment Booking application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 30.0.3 - September 2026**

    Appointment Booking lets customers see real appointment windows and book service directly from the service portal, while technicians and dispatchers can book on a customer's behalf when required. Administrators control what's actually available to book — appointment slots, notification rules, and availability windows — so what customers see reflects what the business can actually deliver.
