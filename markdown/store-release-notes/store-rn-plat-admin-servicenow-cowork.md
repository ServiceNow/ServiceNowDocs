# ServiceNow Cowork release notes

Version history for the ServiceNow® ServiceNow Cowork application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.7 - October 2026**

    ServiceNow Cowork is an AI coworker that runs on your machine and gets done work for you. It plans, executes, and retries multi-step tasks across email, calendar, Teams, files, code repositories, and ServiceNow. Because it carries context from one system to the next, work moves forward without manual handoffs.

    Employees are already adopting powerful AI agents often without IT visibility. Cowork gives organizations a governed way to say yes. Every action runs in an isolated sandbox on the user's device, and every client registers with ServiceNow AI Control Tower at install. Admins set one policy for models, connectors, sandbox configuration, and permitted actions. Users choose what works for them within those boundaries, and any action that carries high risk actions pause for human approval.

    Cowork works across model families and is model-flexible, so organizations aren't locked in to a single model family. It also keeps a standing memory that each user shapes over time.
