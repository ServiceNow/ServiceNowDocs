# Customer Household Data Model release notes

Version history for the ServiceNow® Customer Household Data Model application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 2.5.0 - September 2026**
    -   New:
        -   Admins can now assign multiple roles to users during onboarding. This streamlines user setup by allowing role selection in a single workflow.
        -   Users can reset their passwords via email link. The password reset process now supports secure email-based recovery.
    -   Changed:
        -   The user profile interface now displays assigned roles more clearly. Role information is shown in a dedicated section for easier review.
        -   Onboarding workflow has been updated to include role selection. The process now prompts admins to choose roles before completing user creation.
    -   Fixed:
        -   Duplicate user records have been resolved. The system now prevents creation of users with identical email addresses.
        -   Role assignment errors during onboarding have been corrected. Users now consistently receive the roles selected by admins.
        -   Password reset emails now send reliably. Users requesting password resets receive email links without delay.
-   **Version 2.3.0 - September 2026**
    -   Changed: Java compile version updated to Java 21
    -   Fixed: Performance improvement on Manage Hosuehold Member on Consumer Portal
-   **Version 2.2.4 - September 2026**

    Fixed: Security enhancements

-   **Version 2.2.1 - May 2026**

    Defect fixes

-   **Version 2.1.0 - April 2026**

    Fixed: Defect fixes.

-   **Version 2.0.6 - March 2026**
    -   Customer Household Data Model provides a structured foundation for representing households as logical groupings of individual consumers. It enables organizations to create households, define household members, and establish relationships between members providing a comprehensive representation of household structure.
    -   By providing a consolidated view of household dynamics, the application empowers service teams to deliver more personalized, coordinated, and efficient support. It enhances visibility into shared services, improves case handling across related customers, and drives better customer outcomes through contextual awareness.
