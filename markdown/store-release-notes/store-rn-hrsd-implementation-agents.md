# HR Service Delivery Implementation Agents release notes

Version history for the ServiceNow® HR Service Delivery Implementation Agents application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.2.0 - September 2026**

    HR Service Delivery Implementation Agents shortens the path from install to a working HR Service Delivery deployment.Configuration consoles walk implementers through HR Core, document template, and Agent Workspace setup in a structured tree, while AI agents built on Now Assist handle the configuration work itself — creating HR users and companies, chat and email configuration, HR topics and topic categories, record producers, and HR templates from natural-language input.Component checks validate that prerequisite HR groups, roles, departments, and locations are in place before configuration proceeds, so implementers catch gaps early rather than after activation.
