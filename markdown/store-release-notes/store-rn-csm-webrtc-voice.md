# WebRTC Voice release notes

Version history for the ServiceNow® WebRTC Voice application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.7 - September 2026**

    Add a phone widget to portal and engagement messenger pages so users can make voice calls directly from the portal or engagement messenger interface without switching to their own telephone. The widget maintains call state across page navigation and multiple browser tabs. Portal context automatically passes to the agent.
