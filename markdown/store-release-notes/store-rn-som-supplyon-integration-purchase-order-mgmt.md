# SupplyOn Integration for Purchase Order Management release notes

Version history for the ServiceNow® SupplyOn Integration for Purchase Order Management application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.4 - October 2026**

    This plugin adds new integration capability to receive purchase order confirmations from suppliers via SupplyOn to improve supply chain visibility and exception handling.
