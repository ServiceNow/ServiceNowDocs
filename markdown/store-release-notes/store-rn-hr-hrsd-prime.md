# HRSD - Prime release notes

Version history for the ServiceNow® HRSD - Prime application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 2.2.5 - September 2026**

    Licensing app for Prime SKU

-   **Version 2.2.2 - August 2026**

    New: Otto skills and a refreshed user interface for Otto.

-   **Version 2.1.0 - July 2026**

    Changed: Plugin and content bundling has been updated for licensing.

-   **Version 2.0.2 - June 2026**

    Changed: App and plugin dependencies have been updated.

-   **Version 1.0.3 - April 2026**

    The HRSD Prime plug-in acts as a digital identifier, specifically designed to represent and validate the customer's licensing tier.
