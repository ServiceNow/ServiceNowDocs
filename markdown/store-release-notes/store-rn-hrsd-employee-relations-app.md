# HRSD Employee Relations Application release notes

Version history for the ServiceNow® HRSD Employee Relations application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.2.0 - September 2026**

    The Employee Relations Case Management Container packages the Employee Relations application together with its required dependencies so it can be installed as one unit.It gives HR Admins a single, guided path to standing up Employee Relations case handling — confidential case intake, investigation management, and allegation tracking — without resolving plugin dependencies by hand.
