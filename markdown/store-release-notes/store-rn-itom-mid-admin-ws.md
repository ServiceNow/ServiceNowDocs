# MID Admin Workspace release notes

Version history for the ServiceNow® MID Admin Workspace application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 2.0.3 - August 2026**
    -   The MID Admin Workspace gives platform owners and IT operations teams a centralized place to manage and monitor MID Servers at scale. It provides real-time visibility, server actions, and troubleshooting assistance in one interface. By adopting this solution, organizations reduce MID Server downtime which keeps mission critical operations like Discovery, Integration Hub, Service Mapping, and Orchestration up and running.
    -   Requires ITOM Infra Services Workspace
