# Enterprise Asset Management Advanced release notes

Version history for the ServiceNow® Enterprise Asset Management Advanced application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 2.0.0 - September 2026**
    -   New:
        -   Added support for ServiceNow Otto for Enterprise Asset Management.
        -   Added support for AI-powered asset request and repair experiences.
        -   Added support for AI-powered asset data loading experiences.
-   **Version 1.0.0 - April 2026**

    A single app to deploy Enterprise Asset Management and its AI-powered flows in ServiceNow Otto for Enterprise Asset Management \(EAM\).
