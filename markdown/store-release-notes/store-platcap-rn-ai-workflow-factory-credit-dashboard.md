# AI Workflow Factory Credit Dashboard release notes

Version history for the ServiceNow® AI Workflow Factory Credit Dashboard application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.13 - October 2026**

    A ServiceNow-instance dashboard for customer admins to see how their AI Workflow Factory Prime SKU credits are being consumed. It aggregates raw usage from each capability's DEF ID \(records, users, lanes, instances\), applies the MDM-hosted rate card to convert usage into funds, and shows both per-capability burn and total funds remaining against the customer's purchased pool.
