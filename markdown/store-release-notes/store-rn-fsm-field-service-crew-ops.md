# Field Service Crew Operations release notes

Version history for the ServiceNow® Field Service Crew Operations application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 30.3.5 - September 2026**

    Field Service Crew Operations extends ServiceNow Field Service Management to support work that requires more than one technician on-site. From Dispatcher Workspace, dispatchers can create standing, ad hoc, or quick crews, set the required crew size and skills — including equipment skills — and assign a crew leader. Work order tasks are then assigned to the crew as a group rather than to individuals one at a time. If a task needs more support after assignment, dispatchers can add resources or resource requirements without starting over. Crew members, including the crew manager, manage their assigned tasks from the Now Mobile Agent app, and supervisors can adjust individual time worked on a crew task when it differs from the rest of the crew. Crews can also be assigned to territories for territory-based planning.
