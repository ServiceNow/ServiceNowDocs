# CSM MCP Server release notes

Version history for the ServiceNow® CSM MCP Server application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.4 - July 2026**
    -   Use the CSM MCP \(Model Context Protocol\) Server to expose Customer Service Management capabilities as standardized tools that AI systems can consume.
    -   The MCP server contains no business logic or implementation. All underlying logic is delegated to existing ServiceNow APIs, script includes, flow actions, subflows, and Now Assist skills across apps.
