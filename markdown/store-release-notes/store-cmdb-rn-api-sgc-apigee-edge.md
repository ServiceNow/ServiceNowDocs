# API Service Graph Connector for Apigee Edge release notes

Version history for the ServiceNow® API Service Graph Connector for Apigee Edge application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.1 - August 2026**
    -   Use the ServiceNow CMDB as your normalized source of truth for APIs deployed on Apigee Edge. Having your API inventory in the CMDB enables other workflows to be used in managing your API estate, including Security Operations, IT Service Management, IT Operations Management, Integrated Risk, and more. The ServiceNow API Insights workspace also provides a way for teams to interact with the API data, allowing stakeholders to analyze the data without requiring direct access to Apigee Edge.
    -   Configuring this API Service Graph Connector retrieves the following objects from an Apigee organization:
        -   Apigee organization
        -   API proxies
        -   Proxy and target endpoints
        -   Target servers
        -   Deployments
        -   API Products
        -   Apps \(company and developer\)
        -   Developers
        -   Companies
