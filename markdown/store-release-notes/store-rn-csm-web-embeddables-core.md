# Web Embeddables core release notes

Version history for the ServiceNow® Web Embeddables core application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 6.3.0 - August 2026**
    -   Web Embeddables Core provides the ability to configure the ServiceNow web components for seamless self-service experiences and embed these web components on non-ServiceNow websites. Key features include:
        -   Low-Code Configuration: Configure Case List, Case View, Case Create, and Catalog Item components with low-code/no code administration.
        -   Security Configuration: Create security configurations to ensure seamless integration of the web components.
        -   Code Generation: Leverage generated code to embed on non-ServiceNow websites.
