# Workflow Studio release notes

Version history for the ServiceNow® Workflow Studio application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.19 - November 2026 \(Australia, Brazil\)**
    -   Flow Designer is a ServiceNow platform feature that enables process owners to automate work. Build multi-step flows from reusable components without having to code.
    -   Flow Designer is the default ServiceNow platform process automation builder used to create flows. Flow Designer replaces the legacy Workflow graphical editor.
