# Employee Journeys for EmployeeWorks and Employee Slate release notes

Version history for the ServiceNow® Employee Journeys for EmployeeWorks and Employee Slate application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.1.1 - November 2026**
    -   Fixed Defects:
        -   Filters alignment should be in single line in mobile landscape view or in other widths of desktop view.
        -   Journey details page related UX defects.
        -   Not able to switch between list items of group filter using keyboard arrow keys.
        -   AIUX EJM - Uptake mobile design guidelines from UEX.
        -   Common issue on loading journey detail page.
-   **Version 1.1.0 - October 2026**

    Employee Journeys for EmployeeWorks and Employee Slate brings Employee Journey experiences directly into the EmployeeWorks portal, providing employees and managers with a unified destination to discover, track, and complete journey activities. Employees can view active journeys from the Employee Slate homepage, access detailed journey information, track progress, and complete journey-related tasks without navigating to Employee Center Pro. Managers gain visibility into team journeys, enabling them to monitor progress and support employees throughout key lifecycle moments. This application delivers the foundational Employee Journeys experience in EmployeeWorks, helping organizations increase journey participation, improve task completion rates, and streamline employee lifecycle experiences through a modern, AI-native employee portal.
