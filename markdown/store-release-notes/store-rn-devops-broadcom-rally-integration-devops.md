# Broadcom Rally Integration with DevOps release notes

Version history for the ServiceNow® Broadcom Rally Integration with DevOps application on the ServiceNow Store.

-   **Version 7.1.1 - September 2026**
    -   Changed:
        -   Rally Authentication with OAuth 2.0
            -   Authenticate a Rally tool connection using OAuth 2.0 credentials to strengthen your tool security.
-   **Version 7.0.0 - June 2026**

    Connects Rally software to ServiceNow DevOps to incorporate Rally project data into DevOps Insights and Change Acceleration features.
