# Field Service Task Dependency release notes

Version history for the ServiceNow® Field Service Task Dependency application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 30.1.3 - September 2026**

    Task Dependency lets you define the order tasks are performed in a work order. When a job has multiple steps, technicians need to do them in sequence, not just complete them — you can't test a repair before you make it. Define dependencies between tasks so a task waits until its prerequisite is done, and build that sequence into work order templates so it applies automatically to every work order generated from them.
