# ITOM MCP Server Console release notes

Version history for the ServiceNow® ITOM MCP Server Console Server application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.1.3 - September 2026**
    -   The ITOM MCP Server brings the full intelligence of ServiceNow IT Operations Management directly into the AI tools your teams already use — including Claude, ChatGPT, and other MCP-compatible clients. Rather than building fragile workarounds against raw Table APIs, operations teams get a single, enterprise-grade channel for AI-powered access to the platform's native capabilities: alert data, AI models, CMDB relationships, automation logic, service reliability data, and learning-enhanced automation insights — all surfaced through natural language, all governed by ServiceNow's role-based access controls, audit trails, and data residency policies.
    -   Designed for enterprises where security reviews are non-negotiable, the ITOM MCP Server is the only AI integration path that satisfies CISO requirements out of the box. Every skill invocation is authenticated, scoped to the user's platform roles, and fully auditable — so AI-assisted operations scale without introducing compliance risk. With LEAP integration, operators now access automation opportunities and configuration intelligence alongside traditional operational context, enabling smarter decision-making at every stage of the IT operations lifecycle.
