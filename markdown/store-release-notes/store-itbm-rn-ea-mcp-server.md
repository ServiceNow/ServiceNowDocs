# Enterprise Architecture \(EA\) MCP Server release notes

Version history for the ServiceNow® Enterprise Architecture \(EA\) MCP Server application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 2.0.2 - October 2026**

    The Enterprise Architecture \(EA\) Model Context Protocol \(MCP\) server connects an MCP-compatible AI assistant, such as Claude, to your ServiceNow instance. With MCP for Enterprise Architecture, enterprise architects and application portfolio managers can use natural language queries to get the following information directly in their AI client, without opening the ServiceNow instance:

    -   Business application insights
    -   Application rationalization scores
    -   Business capability mappings
    -   Relationships between entities, such as business applications, business capabilities, services, databases, and servers, including multi-level impact analysis
    -   Architectural artifacts linked to entities, such as documents and diagrams
    -   Modeling diagram summaries and comparisons
    -   Knowledge graph queries
    The tools installed with the application are read-only and don't create, update, or delete records in your instance.
