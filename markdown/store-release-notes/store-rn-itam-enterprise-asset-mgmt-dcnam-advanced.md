# Enterprise Asset Management for DCNAM Advanced release notes

Version history for the ServiceNow® Enterprise Asset Management for DCNAM Advanced application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 2.0.0 - September 2026**
    -   New:
        -   Added support for ServiceNow Otto for Enterprise Asset Management.
        -   Added support for AI-powered enterprise asset request experiences.
        -   Added support for AI-powered troubleshooting and repair assistance experiences.
-   **Version 1.0.0 - April 2026**

    A single app to deploy Enterprise Asset Management for DCNAM and its AI-powered flows in ServiceNow Otto for Enterprise Asset Management \(EAM\).
