# Service Graph Connector for Omnissa Workspace ONE UEM release notes

Version history for the ServiceNow® Service Graph Connector for Omnissa Workspace ONE UEM application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 1.0.0 - October 2026**

    The Service Graph Connector for Omnissa Workspace ONE UEM uses Omnissa Intelligence APIs to populate your ServiceNow CMDB with high-fidelity device data. It's easy to configure and starts collecting data quickly. Like all Service Graph Connectors, it uses the Identification and Reconciliation Engine \(IRE\) to prevent duplicate records and ensure each value comes from its most trusted source.

    The connector supports:

    -   Mobile device management
    -   Windows and macOS end-user computing
    -   Hardware and software asset management
    The connector is easy to configure and can be managed at scale using SGC Central.
