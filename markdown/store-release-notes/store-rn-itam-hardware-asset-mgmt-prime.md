# Hardware Asset Management - Prime release notes

Version history for the ServiceNow® Hardware Asset Management - Prime application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 1.0.12 - September 2026**
    -   Every digital business relies on IT assets, foundational for protecting revenue and business resilience. Businesses need to track asset ownership, location, usage, configuration, costs, and value. ITAM enables adaptability as operations evolve.
    -   As workplaces change, managing assets across tools and locations creates operational, cost, and risk challenges. Scattered data and siloed teams hinder efficiency.
    -   ServiceNow Hardware Asset Management Prime enhances asset visibility and automates IT lifecycles on an AI native platform.
    -   Asset managers can streamline sourcing and repair using AI agents in agentic workflows.
    -   Key features include:
        -   Automating IT lifecycles on one platform
        -   End-to-end asset visibility
        -   Cost and risk reduction
        -   Centralized asset data for accurate reporting
        -   Automated request-to-dispose workflows
        -   Actionable AI insights for asset planning
        -   Informed decision-making for utilization and investments
        -   Compliance with security policies and regulations
        -   Hardware Asset Management integration with Contract Management Professional
    -   Features like Hardware normalization standardize asset data using manufacturer details and populate metadata \(e.g., end-of-life dates\) via the ServiceNow Content Library. Asset Lifecycle Automation uses Flow Designer for customizable workflows, while Asset Tasks automate updates across deployments and retirements.
    -   The Hardware Asset Dashboard provides a command center for lifecycle management, normalization tracking, and compliance. Mobile Asset Inventory Audit validates physical stock against records using mobile scanning, improving accuracy through scheduled audits.
    -   Contract management professional integration allows managing hardware contract lifecycle across renewals, expirations, and obligations within hardware asset workspace. Use the agentic workflow to extract key metadata and obligations from signed contract documents and track contractual commitments proactively to reduce unexpected costs.
