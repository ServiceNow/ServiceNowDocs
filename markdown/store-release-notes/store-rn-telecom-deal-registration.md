# Deal Registration release notes

Version history for the ServiceNow® Deal Registration application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

-   **Version 7.0.3 - September 2026**
    1.  Fixed:
        1.  Fixed the issue where PRM External Manager and other users could not see/add comments via the activity section in  deal reg details page.
        2.  Add business rule to validate exclusivity expiry date and prevent backdating.
        3.  Fixed the issues with agents and relationship managers not being able to create entries in opportunity related party table.
    2.  New:
        1.  Added helper function for deleting a deal registration line item by number helper functionality.
        2.  Added account and consumer reference qualifiers by channel partner \(filter based on service organization criteria applied on channel partner\).
    3.  PC Suggestion:
        1.  Fixes
            1.  Fixed an issue where PRM External Managers and other users could not view or add comments in the activity section on the deal registration details page.
            2.  Added a business rule to validate the exclusivity expiry date and prevent users from selecting a past date.
            3.  Fixed an issue where agents and relationship managers were unable to create entries in the Opportunity Related Party table.
        2.  New Features
            1.  Added helper functionality to delete a deal registration line item by number.
            2.  Added account and consumer reference qualifiers by channel partner, filtered based on service organization criteria applied to the channel partner.
-   **Version 6.0.2 - September 2026**

    Fixed:

    1.  Fixed the issue where PRM External Manager and other users could not see/add comments via the activity section in  deal reg details page.
    2.  Add business rule to validate exclusivity expiry date and prevent backdating.
    3.  Fixed the issues with agents and relationship managers not being able to create entries in opportunity related party table.
    New:

    1.  Added helper function for deleting a deal registration line item by number helper functionality.
    2.  Added account and consumer reference qualifiers by channel partner \(filter based on service organization criteria applied on channel partner\).
    PC Suggestions:

    Fixed:

    1.  Fixed the issue where PRM External Managers and other users could not view or add comments via the activity section in the deal registration details page. This enables better collaboration and communication within deal registration workflows.
    2.  Add business rule to validate exclusivity expiry date and prevent backdating, ensuring data integrity and compliance.
    3.  Fixed the issue where agents and relationship managers could not create entries in the opportunity related party table. This restores full functionality for managing relationship hierarchies.
    New:

    1.  Added helper function for deleting deal registration line items by number. This streamlines deal registration management and improves operational efficiency.
    2.  Added account and consumer reference qualifiers by channel partner, filtered based on service organization criteria. This enables channel partners to access only relevant references aligned with their service organization, improving data relevance and security.
-   **Version 5.0.1 - August 2026**
    -   New:
        -   Introducing the creation of Deal Tasks for Deal Registration record
        -   Advance approval framework integrated with Deal Registration
        -   Enabled audit on Deal Registration fields
        -   Added two fields on Deal Registration - Segment &amp; Exclusivity Expiry Date
-   **Version 4.0.0 - August 2026 \(Zurich\)**
    -   New:

-   **Version 2.2.2 - July 2026 \(Zurich\)**

    Fixes: Fixed sentence casing- Making account/consumer/account name/first name mandatory on workspace for B2C &amp; B2B agents
