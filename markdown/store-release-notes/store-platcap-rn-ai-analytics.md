# AI Analytics release notes

Version history for the ServiceNow® AI Analytics application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 5.2.4 - August 2026**
    -   AI Analytics is a unified analytics experience that provides visibility into the performance and adoption of AI-powered capabilities implemented and activated across your ServiceNow instance. The application consolidates two purpose-built dashboards:
        -   Assistant Analytics – Monitor assistant performance, user adoption &amp; engagement, sentiment \(inferred CSAT, effort score, etc,\), and self-solve \(deflection related\) performance across assistants and channels \(ServiceNow Otto for Virtual Agent &amp;  ServiceNow Otto panel\). This dashboard is accessible from the Analytics tab in Assistant Designer.
        -   AI Analytics dashboard – Track usage and adoption, performance of generative AI skills, AI Guardian, ServiceNow Otto context menu, and AI search. Accessible from the Performance tab in AI Admin Hub.
