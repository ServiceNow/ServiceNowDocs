# Retail MCP Server Console release notes

Version history for the ServiceNow® Retail MCP Server Console Server application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 2.0.0 - October 2026 \(Brazil\)**
    -   Retail MCP Server is for retail organizations running ServiceNow retail — store teams and the HQ teams that support them. Work that until now meant opening the right form and filling it in can be done by asking an AI assistant instead.
    -   The app is the layer that makes that possible: it exposes ServiceNow retail capabilities as tools any AI assistant can call, so a user describes the situation in plain language — "the third register is frozen" — and the assistant identifies the store, matches the device, raises the correct record, and reports back. Records arrive complete and correctly categorized, so less time goes into chasing detail before work can start, and requests that were never worth a form get captured.
    -   Every tool delegates to existing ServiceNow retail logic rather than reimplementing it, and runs as the calling user — so your access controls, roles, and record-level visibility apply unchanged, with no separate integration layer to secure or maintain. It serves every retail persona from one server, and new retail capabilities register on it as they ship.
