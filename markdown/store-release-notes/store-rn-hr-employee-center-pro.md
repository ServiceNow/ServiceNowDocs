# Employee Center Pro release notes

Version history for the Employee Center Pro application on the ServiceNow Store.

**Important:** For details on system requirements and family compatibility, view the application listing on the [ServiceNow Store](https://store.servicenow.com/sn_appstore_store.do#!/store/home) website.

## Version history

-   **Version 42.0.4 - July 2026 \(Australia\)**

    Updated to support the latest version of the dependent apps.

-   **Version 38.2.4 - July 2026 \(Zurich\)**

    Updated to support the latest version of the dependent apps.

-   **Version 42.0.2 - June 2026 \(Australia\)**

    Updated to support the latest version of the dependent apps.

-   **Version 38.2.1 - June 2026 \(Zurich\)**

    Updated to support the latest version of the dependent apps.

-   **Version 38.1.0 - May 2026**

    Migrated the Org Chart server-side changes from EC Pro to EC Core and removed the corresponding files from EC Pro. There is no impact to the upgrades.

-   **Version 38.0.2 - March 2026**

    Updated to support the latest version of the dependent apps.

-   **Version 37.0.3 - December 2025**

    Updated to support the latest version of the dependent apps.

-   **Version 36.0.1 - August 2025**
    -   Recent changes:
        -   Improved Mega Menu performance Faster load times and smoother navigation.
        -   Improved resilience during high traffic events Optimized for stability and performance during peak usage.
        -   Identified and removed existing, outdated content and sync new content to associated categories.
        -   Enhanced Requests experience for better configurability and user experience.
    -   What you need:
        -   Get skeleton loaders for existing widgets, banner notifications for load delays, and asynchronous load-time processing to improve overall portal performance.
        -   Get the Employee Center Browser Extension to stay connected with your Employee Center portal activities even when you're working on external applications.
        -   Note: Browser Extension feature requires the Employee Center for Browser Extension plugin.
-   **Version 35.0.4 - June 2025**
    -   Resolved the following bugs:
        -   Malfunction in tablet responsiveness on the appointment booking pages when the dynamic window is pinned.
        -   Adjustment to the background gradient size from 100% 30% to 100% 20%.
-   **Version 35.0.3 - May 2025**
    -   Employee Communications: Company Events improvements:
        -   The new capabilities include an integration with Workplace Service Delivery, a calendar widget view, RSVP/Waitlisting tools, events notifications and more.
    -   Integrated Experience and Service Feedback functionality improvements:
        -   Utilize an experience rating question available OOTB that enables employees to rate their user experiences.
        -   Configure the experience feedback more flexibly, including whether the comment functionality is required.
    -   Notifications improvements:
        -   Leverage portal notifications for news content​ that provides quick and easy updates for both news authors and employees consuming news content.
-   **Version 34.0.3 - March 2025**

    In the App Launcher widget, the performance indicator now displays the individual execution time instead of cumulative total.

-   **Version 34.0.2 - February 2025**
    -   Improved the following capabilities:
        -   Live company events hosting and communications framework: Live company events can now be hosted directly in the Employee Center Pro portal, with prebuilt configurations to streamline the pre-event communications and handle traffic surges. Content authors can easily create and share event content using the drag-and-drop Rich Content Editor, combined with mass-publishing capabilities similar to news articles.
        -   Portal shortcuts for content authoring: Content authors can now easily edit or create news articles and banners using shortcuts in the Content Experiences or News widgets. The system auto-generates publishing plans, streamlining content delivery to the selected widget and reducing the effort needed for configuration.
        -   Unified appointment booking experience for IT and HR: Employees can schedule in-person or virtual appointments with IT or HR to get help through a quick link in the Mega Menu or Quick links widget.
        -   Improved apps discovery: Employees can now search for web applications configured in App Launcher using the AI-powered global search bar.
        -   Note: Also see Employee Center release notes for additional functionalities released.
-   **Version 33.0.2 - November 2024**
    -   Improved employee communication capabilities: Rich Content Editor updates: Introduced additional formatting elements for more visually engaging content in microsites and news experience. These include bulleted lists, numbered lists, table and grid layouts, and accordions.
    -   Improved Experience &amp; Service Feedback capabilities:
        -   Post-Feedback Loop: Admins can set a rating threshold that automatically triggers a feedback response loop. This generates a task based on the rating and associated survey questions.
        -   Automated notifications: When feedback tasks are completed, non-anonymous feedback providers will automatically receive email notifications.
        -   Feedback Task Analytics dashboard: The dashboard enables tracking of post-feedback loop tasks to provide insight into task progress.
    -   Homepage theme improvements: Improved home page theme: Theme aligns with the latest sets components, a new color scheme, a logo update, and CSS variable adjustments for an improved browsing experience.
    -   Note: Also see Employee Center release notes for additional functionalities released.
-   **Version 32.1.2 - October 2024**

    The October release of EC Pro has improved compatibility with Xanadu and enables backporting capabilities. Once released, the August version will be withdrawn from stores.

-   **Version 32.0.4 - August 2024**
    -   Improved employee communication capabilities.
        -   Enabled authors to save existing news articles as a reusable template, allowing easy replication of structured content and streamlined news publishing.
        -   Added engagement reporting for all content published through content library, not just campaign content.
        -   Introduced content operations dashboard to provide centralized oversight across the content lifecycle, highlighting requests and active content publishing.
        -   Introduced content publishing calendar for strategic planning and scheduling of communications activities.
        -   Introduced content ownership matrix for clearer visibility into ownership across content items, audiences, topics, and pages within the content platform.
    -   Improved the microsite authoring experience with visual add/edit shortcuts directly on the portal, empowering content managers to seamlessly add new rich content microsites and edit existing content.
    -   Improved experience and service feedback capabilities.
        -   Added the ability to use surveys for capturing experience feedback
        -   Added configurable page intercepts for triggering the drawer to slide out or modal to show up such as time spent on page
        -   Made experience and service feedback available within Now mobile and VA interfaces
    -   Improved kiosk-based experience for deskless workers. See Employee Center Pro kiosk for additional details.
-   **Version 31.0.4 - May 2024**
    -   Introduced employee experience for deskless workers via Employee Center Pro Kiosk. See Employee Center Pro Kiosk and HRSD Integration with Kronos plugin for additional highlights.
    -   Improved Experience and Service Feedback capability to provide more flexibility in configuration and reduce feedback fatigue: Ability to deliver surveys for service feedback on portal.
    -   Ability to deliver actionable surveys in emails for service workflows.
    -   Configurable page intercepts for triggering feedback nudge such as on page load, with time delay, at scroll point on portal pages.
    -   Admin and user controls to mitigate feedback fatigue.
    -   Integration of feedback responses with UEX analytics to correlate usage analytics with feedback and plan of action.
-   **Version 32.0.3 - February 2024**
    -   Capture user feedback directly in Employee Center Pro during or after service request fulfilment.
    -   In-page feedback widget that supports out of the box feedback question types and simple admin configuration.
    -   Support for feedback in email notifications in Microsoft Outlook \(Requires Outlook Actionable Messages plugin\).
    -   Cross-channel feedback tracking across portal and email.
    -   Capture user feedback on any employee experience touchpoint.
    -   Experience feedback drawer widget with flexible configuration to appear on all or select portal pages.
    -   Support for anonymous user responses for experience and service feedback.
    -   Analyze user responses in Experience and Service Feedback dashboard.
-   **Version 29.0.4 - November 2023**
    -   New out of the box Home Page templates for Employee Center Pro with additional widgets for targeted communications.
    -   Revamped Information Architecture with new top-level menu items 'Help Center', 'Your Career', 'Your Team' &amp; 'News Center'.
    -   Introduced Approvals Hub integration with Workday for Now Mobile. See 'Approvals Hub integration with Workday'.
    -   Changes related to Employee News and Content Experience widget. See 'Content Publishing' for additional highlights.
-   **Version 28.2.1 - August 2023**

    Introduced an integrated news experience to keep employees informed of important company news. Introduced pre-built integration of Approval Hub with Workday. See Content Publishing, HR Service Delivery Integration with Workday, and Now Mobile release notes for additional highlights.

-   **Version 28.0.1 - February 2023**
    -   Changed
        -   Updated the Rich Content Editor for creating consistent and more organized Topic Microsites.
        -   Updated the Content Governance workflows by allowing content authors or requestors to include additional content reviewers for approving the content.
        -   See Employee Center, Content Publishing, Content Governance, Manager Hub, and Now Mobile release notes for additional highlights.
-   **Version 27.0.2 - November 2022**
    -   New dynamic topic microsites with a drag-and-drop content authoring experience.
    -   Updated Content Governance request and fulfillment workflow.
    -   Ability to search secured SharePoint content from Employee Center.
    -   See Employee Center, Content Publishing, Content Governance, Manager Hub, and SharePoint Online Search Connector release notes for additional highlights.
-   **Version 26.0.2 - August 2022**
    -   New
        -   Optimize the performance of the Employee Center portal with synchronous load configuration, individual widget performance details, and empty state message display.
        -   Updated employee org chart, with added configuration options, to drive employee engagement.
        -   Allow managers to view and search knowledge articles as one of their employees though Manager Hub, a new experience for managers.
        -   See Employee Center, Content Publishing, Content Governance and Manager Hub release notes for additional highlights.
-   **Version 25.0.3 - May 2022**

    New:

    -   New cross-channel favorites feature pre-integrated with requests, knowledge &amp; applications.
    -   Updated App Launcher with Okta integration and user personalization options.
    -   Built-in image editor \(crop, resize etc.\) for styled content &amp; employee profile page.
    -   Distributed ownership of communication content on portal pages &amp; topic pages.
    See [Employee Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/store/markdown/store-release-notes/store-rn-hr-employee-center.md), [Content Experiences](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/store/markdown/store-release-notes/store-rn-hr-content-experiences.md), [Content Publishing](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/store/markdown/store-release-notes/store-rn-hr-content-publishing.md), and [Employee Profile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/store/markdown/store-release-notes/store-rn-hr-employee-profile.md) release notes for additional highlights.

-   **Version 24.0.4 - February 2022**
    -   New
        -   Added demo data to the Employee Center Pro home pages for existing and new content experience widgets.
        -   SSO-powered App launcher enables employees to access their applications from Employee Center.
        -   Introduced a modern, configurable employee profile page.
        -   Added a new configuration option for Link Content allowing the content author to select where the link loads \(within the current browser page or in a new tab\).
        -   View the employee details and associated information from the Now Mobile app.
    -   Changed
        -   Updated the content recommendations ML model to use employee profile for similarity.
        -   Updated the demo data for the Employee Center Pro home page.
-   **Version 23.0.2 - November 2021**
    -   Changed
        -   Updated mega menu with quick links displayed
        -   Improved 'my active items' widget that supports web responsiveness and allows admins to define user restrictions on visibility of cards
-   **Version 22.0.7 - September 2021**
    -   Employee Center Pro provides a single unified portal for multi-department service delivery, enabling organizations to easily scale their service solutions across IT, HR, Workplace, Legal, and Procurement so employees can easily find information, get help, and request the services they need. Employee Center Pro expands the portal experience beyond service delivery with employee communication and engagement tools including content publishing and campaigns, content experiences, and employee communities.
