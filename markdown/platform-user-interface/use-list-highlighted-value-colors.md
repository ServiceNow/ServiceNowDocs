# View color labels for highlighted values

Display color information alongside highlighted values in lists.

## Before you begin

Role required: admin

## About this task

When you enable the **Highlighted value label in lists** preference, color names will display alongside highlighted values.

## Procedure

1.  Select the profile icon \(\[Omitted image "list-profile-icon.png"\] Alt text: profile icon\).

2.  Select **Preferences** &gt; **Accessibility**.

3.  Select **Highlighted value label in lists**.

    \[Omitted image "list-highlighted-value-label.png"\] Alt text: Highlighted value label in lists preference

    Lists display color names alongside highlighted values.
