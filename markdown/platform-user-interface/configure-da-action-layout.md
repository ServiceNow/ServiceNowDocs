# Configure a form action layout on a workspace page

Add a UX Form Actions Layout to a workspace page in UI Builder.

## Before you begin

Role required: admin

## Procedure

1.  Open your workspace experience in UI Builder.

    For instructions, see Open a Configurable Workspace experience in UI Builder.

2.  Select or create a page that contains the Form component.

    For example, select a record page.

    For instructions on creating a workspace page in UI Builder, see [Create a Configurable Workspace page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-user-interface/create-configurable-workspace-page-uib.md).

3.  From the Data and scripts tree, select the **Form Controller**.

4.  Select the **Configure** tab and expand the **Advanced** section.

5.  In the Action layout property, select a UX Form Actions Layout record.

6.  Select **Save**.


## Result

The actions specified in the UX Form Actions Layout record appear on the workspace page.
