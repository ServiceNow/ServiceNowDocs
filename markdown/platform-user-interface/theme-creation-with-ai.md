# Theme creation with AI

Use AI to generate themes from images directly in Theme Builder or from the ServiceNow Otto® panel. This feature is available for instances running Zurich Patch 7 or later.

## Configuring Theme Builder AI theme creation

The requirements for AI theme creation depend on where you start the workflow.

To start using AI theme creation from within Theme Builder, you must install ServiceNow Otto for Creator. See [Install ServiceNow Otto for Creator](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/build-workflows/install-now-assist-for-creator.md). After you have installed ServiceNow Otto for Creator, see [Create a theme with AI in Theme Builder](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/tb-create-a-theme-ai.md).

To start using Theme Builder AI theme creation workflow from the ServiceNow Otto® panel, you must install ServiceNow Otto for Creator and turn on the Theme Creation Workflow in AI Agent Studio. For more information, see [Turn on theme creation workflow for use in the ServiceNow Otto® panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/turn-on-theme-creation-workflow.md). After you have enabled the Theme Creation Workflow, see [Create a theme using ServiceNow Otto®](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/create-theme-now-assist.md).

-   **[Turn on theme creation workflow for use in the ServiceNow Otto panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/turn-on-theme-creation-workflow.md)**  
Turn on the theme creation workflow to generate themes using the ServiceNow Otto® panel.
-   **[Create a theme using ServiceNow Otto](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/create-theme-now-assist.md)**  
Use ServiceNow Otto® to generate themes from your brand image or brand guidelines. This AI-powered workflow extracts color palettes automatically, creating visually consistent themes without requiring brand color codes.
-   **[Create a theme with AI in Theme Builder](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/tb-create-a-theme-ai.md)**  
Use an AI-powered theme creation from within Theme Builder to generate themes from brand images, preview, and refine results all within the updated Create a theme wizard.
