# Configure theme mapping for embeddables

Apply a custom UI Builder theme that matches your ServiceNow® NOW experience.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **Service Portal** &gt; **Themes**.

2.  In the **CSS variables** section, in the **Matching NOW experience theme** field, select the UI Builder theme.

    For more information, see [Create a portal theme](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-user-interface/service-portal/c_CustomCSS.md).

3.  Select **Save** to apply your changes.


## Result

Your embeddables now use the selected UI Builder theme. If no theme is selected, embeddables use the default UI Builder theme.
