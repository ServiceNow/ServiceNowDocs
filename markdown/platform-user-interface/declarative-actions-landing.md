# Customizing Configurable Workspace with declarative actions

Add custom actions to forms, fields, lists, and related list pages in a Configurable Workspace.

With declarative actions, you can add custom functionality that extends pages without taking ownership of a UI Builder.

    Create a declarative action and add the button to a workspace.

-   **[Configure declarative action buttons](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-user-interface/configuring-da-buttons.md)**

    Configure declarative action buttons to perform actions.

-   **[Manage action visibility](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-user-interface/da-hide-global-actions.md)**

    Configure global actions to exclude specified tables, views, pages, workspaces, or experiences.
