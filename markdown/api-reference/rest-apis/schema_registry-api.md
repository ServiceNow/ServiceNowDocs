# Schema Registry API

Use the Schema Registry API to retrieve Avro schemas generated by Stream Connect, along with their subject and version history.

This API is a ServiceNow implementation of the [Schema Registry API for Confluent Platform](https://docs.confluent.io/platform/current/schema-registry/develop/api.html). [Avro schemas](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/schema-management.md) are generated by [Stream Connect](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/integrate-applications/stream-connect-apache-kafka.md) for tables published to Kafka. This API is read-only; schemas and their evolution history are generated and maintained internally by Stream Connect.

This API requires the ServiceNow IntegrationHub Stream Connect Schema plugin \(`com.glide.hub.stream_connect.schema`\). This plugin provides the following tables:

-   Table Message Schema \[sys\_table\_message\_schema\]: Stores each generated Avro schema.
-   Table Message Schema Evolution \[sys\_table\_message\_schema\_evolution\]: Tracks the subject and version for each schema. Schema subjects correspond to a table's Stream Connect topic name.

The calling user must have the message\_schema\_viewer role.
