# Example scripts

Browse useful script examples for common platform tasks.

The API reference includes additional script examples for specific APIs. For more information, see the topics in the [API reference](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/api-reference.md).

-   **[Business rule use cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/scripts/useful-business-rules.md)**  
Use cases for business rules include aborting a database action and restricting record access.
-   **[Client-side script use cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/scripts/useful-client-side-scripts.md)**  
Use cases for client-side scripts include displaying field messages, changing form colors, adding fields, and creating UI routing actions.
-   **[Field script use cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/scripts/r_UsefulFieldScripts.md)**  
Common use cases for field customization scripts.
-   **[Scheduling script use cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/scripts/c_UsefulSchedulingScripts.md)**  
A business rule script specifies the actions that the business rule takes. Scripts commonly include predefined global variables to reference items in your system, such as the current record. Global variables are available to all business rules.
-   **[Server-side script use cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/scripts/useful-server-side-scripts.md)**  
Use cases for server-side scripts include logging output, getting user objects, and modifying date/time values.
-   **[Validation script use cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/api-reference/scripts/c_ValidateDateAndTime.md)**  
To validate the input of all date/time fields, you can use the following in a validation script \(**System Definition** &gt; **Validation Scripts**\).
