# Customize an indicator in the Technology Account 360 view

Modify the values of the indicators in the Technology Account 360 view.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **System Definition** &gt; **Script Includes**.

2.  Open the **Account360EditableConstants** record.

3.  Modify the values for each metric.

4.  Select **Save**.
