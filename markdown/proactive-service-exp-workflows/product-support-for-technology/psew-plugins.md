# Plugins installed with Proactive Service Experience Workflows

The Proactive Service Experience Workflows plugin activates several related plugins if they aren’t already active.

|Plugin|Description|
|------|-----------|
|com.glide.hub.integrations|Enables execution of IntegrationHub actions and flows.|
|Flow Designer - Installer \[com.glide.hub\]|Plugins required to support the Flow Designer application.|
|Process Automation Designer Core - Model \[com.glide.pad.core.model\]|Contains the data model for Process Automation Designer and the Process Automation Runtime engine. This plugin also contains the out of the box content for building a Process Definition.|
|Process Automation Designer Core - Runtime \[com.glide.pad.core.runtime\]|Contains the Process Automation Runtime engine and platform artifacts.|
|Process Automation Designer Core \[com.glide.pad.core\]|Installer and content for the Process Automation Designer Base Product.|
|Playbook Experience Core \[com.glide.playbook\_experience.config\]|Provides fulfillers a way to visualize and interact with business process workflows in a task-oriented view.|
|Service Catalog Page for UXF Workspace \[com.glideapp.servicecatalog.uxfworkspace\]|Provides UXF Workspace page for Catalog.|
|@servicenow/now-diagram \[com.servicenow\_now\_diagram\]|GoJS library diagram for Seismic.|
|@servicenow/now-mobile-app-bridge \[com.servicenow\_now\_mobile\_app\_bridge\]|Enables Now Experience Framework web pages to interface with mobile apps.|
|Subscriptions and Activity Feed Framework \[com.snc.activity\_subscriptions\]|Provides a generic set of artifacts to handle subscriptions for any defined subscribable object. Any entity can be defined as a subscribable object and a set of subscribers can subscribe to the objects. When an event related to the subscribable object occurs, activities are tracked and subscribers are notified.|
|ServiceNow Document Viewer \[com.snc.documentviewer\]|Enables users to view enterprise-class documents inline in the platform attachment instead of downloading and opening them with a locally installed viewer.|
|Guided Decisions - Guidance Global Entities \[com.snc.guided\_decisions\_guidance\_global\]|Loaded as a dependent of Guided Decisions Guidance to access global entities.|
|Recommended Actions - Base Extensions \[com.snc.next\_best\_action\]|Incorporates extension points for Recommended Actions.|
|CSM Account Hierarchy \[com.snc.sn\_csm\_account\_hierarchy\]|Helps customer service agents navigate the account hierarchy and open specific accounts to view details. This plugin is not visible to customers because it depends on the Customer Service plugin.|
|CSM Configurable Workspace Lookup and Verify \[com.snc.sn\_csm\_lookup\_verify\]|CSM Configurable Workspace is a user interface that provides agents with the tools they need to answer customer questions and resolve customer issues. The Workspace UI is built to improve agent productivity and facilitate resolutions.|
|Task Communications Management \[com.snc.task\_communication\_management\]|Helps you streamline the communication process by creating designated plans for effective messaging during an event.|
|Base Agent Workspace \[com.snc.uib.base\_agent\_workspace\]|A common agent workspace experience for reusable pages.|
|sn-pd-picker \[com.sn\_pd\_picker\]|Picker component for Playground Designer and Flow Designer.|
|sn-pill-field \[com.sn\_pill\_field\]|Pill Field component to display static entry or pill.|
