## Release notes

This release version includes the following fixes.

## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2062770|Fixed error in product search that occurred when a date field on the transaction was empty.|
|PRB2063249|Added the missing build identifier property to cart line items.|
|PRB2063421|Fixed issue where the product hierarchy in transaction lines was returned out of order when sending the configured BOM to Transaction Manager.|
|PRB2063574|Resolved issue where the Create Order event in Transaction Manager created customer orders in a continuous loop.|
