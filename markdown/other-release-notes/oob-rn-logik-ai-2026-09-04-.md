## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2015994|Fixed issue where disconnecting a line with an effective date earlier than the start date did not work.|
|PRB2068672|Removed unnecessary validation messages when splicing out set indices in an On Request enrichment.|
