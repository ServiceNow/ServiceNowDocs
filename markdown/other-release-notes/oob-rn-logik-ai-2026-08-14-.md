## Release notes

This release version includes the following new enhancement and fixes.

## Singapore Region Availability

Logik.ai is now available in a Google Cloud region in Singapore, providing a local deployment option for customers in the Asia-Pacific region. The region runs across multiple availability zones with high-availability database failover and zonally redundant storage.
