## Release notes

This release version includes the following new enhancement and fixes.

## Create Order Integration with Partial Line Selection

Logik.ai now supports creating an order from a subset of transaction lines rather than the full transaction. When an order is created, a confirmation message displays with a link directly to the created order.

## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2037358|Fixed issue where pricing enrichment combined with the pricing matrix caused values ending in zero to display in scientific notation.|
|PRB2039445|Fixed issue where pricing was not appearing in the configurator.|
