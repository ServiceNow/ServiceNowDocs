# ServiceNow CPQ 2026/10/16 release notes

ServiceNow CPQ October 16, 2026 release notes include new enhancements and bug fixes.

## Schedule

|Sector|Upgrade|
|------|-------|
|Demo|Thursday, Oct 15, 2026, 8 pm CT|
|Test|Thursday, Oct 15, 2026, 8 pm CT|
|Prod|Friday, Oct 23, 2026, 8 pm CT|

Example: an environment with URL, https://\[YourLogikURL\].prod.logik.io, receives this build Oct 23, 2026.

## Release notes

This release version includes the following new enhancements and fixes.

## Localization in the configurator

Configurator translations follow the language set in ServiceNow, so admins no longer need to change browser settings to show translated text.

## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2091263|Fixed issue preventing search and selection of picklist values in large multi-select dynamic picklists.|
|PRB2095280|Improved typing responsiveness in free-text fields on large Quote Experience transactions.|
|PRB2095508|Fixed issue where error indicators did not display on tier levels in Quote Experience.|
|PRB2098076|Fixed error when rolling up partner data with multiple zero-quantity lines.|
|PRB2099169|Fixed issue where Smart Predict training failed during data ingestion for large CSV fields.|
|PRB2099359|Fixed issue where integrations rejected for timeout checks were not reported to admins in blueprint upload errors.|
