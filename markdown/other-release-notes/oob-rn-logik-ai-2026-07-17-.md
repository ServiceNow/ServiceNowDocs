## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2020136|Resolved issue where export jobs could hang instead of completing|
|PRB2023800|Fixed issue where picklist pricing did not update dynamically.|
|PRB2035329|Fixed issue in the Visual Editor where adding a second custom font could remove other theme properties from a saved layout.|
