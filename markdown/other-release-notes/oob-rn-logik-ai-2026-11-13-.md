# ServiceNow CPQ 2026/11/13 release notes

ServiceNow CPQ November 13, 2026 release notes include bug fixes.

## Schedule

This build upgrades ServiceNow CPQ environments according to the following schedule:

|Sector|Upgrade|
|------|-------|
|Demo|Thursday, Nov 12, 2026, 8 pm CT|
|Test|Thursday, Nov 12, 2026, 8 pm CT|
|Prod|Friday, Nov 20, 2026, 8 pm CT|

Example: an environment with URL, https://\[YourLogikURL\].prod.logik.io, receives this build Nov 20, 2026.

## Release notes

This release version includes the following fixes.

## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2129831|Fixed issue where field-level mandatory validation did not apply across blueprints when configuring through Quote Experience.|
|PRB2130028|Fixed issue where managed table upserts did not update rows when a number natural key contained leading zeros.|
