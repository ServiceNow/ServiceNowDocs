# ServiceNow CPQ 2026/11/06 release notes

ServiceNow CPQ November 6, 2026 release notes include bug fixes.

## Schedule

This build upgrades ServiceNow CPQ environments according to the following schedule:

|Sector|Upgrade|
|------|-------|
|Demo|Thursday, Nov 05, 2026, 8 pm CT|
|Test|Thursday, Nov 05, 2026, 8 pm CT|
|Prod|Friday, Nov 13, 2026, 8 pm CT|

Example: an environment with URL, https://\[YourLogikURL\].prod.logik.io, receives this build Nov 13, 2026.

## Release notes

This release version includes the following fixes.

## Bug fixes

|Fix|Short description|
|---|-----------------|
|PRB2103027|Addressed issue with partial values displayed in number fields in the Quote Experience configuration BOM.|
|PRB2117126|Fixed issue where the opportunity ID was not set during renewal for users with Read Only view access to the transaction.|
