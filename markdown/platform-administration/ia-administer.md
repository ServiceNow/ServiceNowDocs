# Administer ServiceNow Otto for Setup

Explore this section to learn more about setting up an application and ServiceNow Otto admin with ServiceNow Otto for Setup.

-   Set up an application: [Set up an application with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-setup-apps.md)
-   Set up ServiceNow Otto: [Set up ServiceNow Otto with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-setup-now-assist.md)

To learn more about managing update set batch file, see [Manage update set for ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-update-set.md).

-   **[Set up an application with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-setup-apps.md)**  
Implement the following steps to set up a specific application or plugin with ServiceNow Otto for Setup on your instance.
-   **[Set up ServiceNow Otto with ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-setup-now-assist.md)**  
Implement the following steps to set up ServiceNow Otto with ServiceNow Otto for Setup on your instance.
-   **[Manage update set for ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-update-set.md)**  
Upload a batch update set to promote validated configuration changes from a non-production instance to production in a single, controlled deployment, ensuring consistency and reducing manual errors.
-   **[Mandatory and optional app selection modal](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-mandatory-optional-select-modal.md)**  
The app selection modal enables platform admins to view, select, and install product bundles with clear separation of mandatory and optional apps. The modal validates licensing, prevents modification of required apps, and integrates with App Manager APIs to verify transparent and guided installations.
-   **[Individual plugin installation from Product Hub](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-plugin-install.md)**  
Individual plugin installation enables you to discover, review, and install standalone plugins directly from Product Hub without requiring a bundled apps package. This capability supports flexible deployment scenarios, early adoption, and validation of plugins before committing to full product bundles.
-   **[Jumbo apps and entitlement validation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/ia-jumbo-apps-valid.md)**  
Jumbo apps are large application bundles that support mandatory and optional app selection during installation. Entitlement validation confirms that admins have appropriate licensing for mandatory apps before installation proceeds, while optional apps display licensing status inline to inform installation decisions.
