# Track how your EVAM view configurations are used

Track where Entity View Action Mapper \(EVAM\) view configurations are being used in the AI Search application. EVAM helps you understand search result layouts, identify shared settings, and make adjustments for better search results.

## Before you begin

Role required: admin or ais\_admin

## About this task

Tracking where a view configuration is used helps you:

-   Understand the overall structure of the view configuration and open each component directly from the ServiceNow AI Platform record page.
-   Check whether the view configuration is shared across search applications.

## Procedure

1.  Navigate to **All** &gt; **AI Search Admin** &gt; **AI Search Admin Home**.

2.  On the **Applications** tab, select the application card that you want track the usage of.

3.  In the left pane, select **Result-card Interface**.

4.  From the Select a bundle to edit list, select an EVAM configuration bundle.

    A list of view configurations linked to the selected bundle appears.

5.  Hover over the view configuration and select **More Actions \(\[Omitted image "more-actions-icon.png"\] Alt text: More Actions.\)** &gt; **View usage**.

6.  In the View usage dialog box, review the values.

7.  Select **Close**.
