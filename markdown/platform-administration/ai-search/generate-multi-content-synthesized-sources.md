# Generate multi-content synthesized responses

Multi-content source synthesis lets AI Search gather and combine information from any indexed source in your system to provide comprehensive AI-generated responses to your questions.

By default, Now Assist Genius Results and Virtual Assistant pull answers from four source types:

-   External Content integrations
-   Knowledge Base articles
-   Service Catalog items
-   Skills

Multi-content source synthesis expands this capability to include any indexed source in your ServiceNow instance, such as:

-   Custom tables
-   Documents module
-   Incidents
-   Microsites
-   News content

When your administrator activates multi-content source synthesis, Genius Results and Virtual Assistant pull answers from all these sources, giving you faster, more complete responses in a single result.

Administrators can activate and configure multi-source content synthesized sources. See [Configure multi-content synthesized sources](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/platform-administration/ai-search/configure-multi-content-synthesis-sources.md) for more information.
