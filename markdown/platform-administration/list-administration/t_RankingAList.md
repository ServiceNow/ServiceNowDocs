# Rank a list

Rank the records in a related list to set a custom order that list filters can't produce. A ranking definition must exist for the table and context.

## Before you begin

Role required: none

## About this task

You can set the preferential order of records.

## Procedure

1.  Select the **Rank** button in the related list to reorder the records.

    \[Omitted image "ClickRankToSortIncidents.png"\] Alt text: Click Rank to sort incidents

    The Rank dialog box appears, where you can sort the records in any order.

    \[Omitted image "RankDialogBox.png"\] Alt text: Rank dialog box

2.  Drag the move icon \[Omitted image "MoveIcon.png"\] Alt text: to change the position of a record.

    **Note:** Administrators can define which columns appear in the Rank dialog box in the **Attributes** field of the Ranking Definition form.


-   **[Apply a new sort order to a list](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/platform-administration/list-administration/t_ApplyANewSortOrderToAList.md)**  
Display a related list in its ranked order, or return it to its original sort order.
