# Apply a new sort order to a list

Display a related list in its ranked order, or return it to its original sort order.

## Before you begin

Role required: none

## Procedure

1.  Open the context menu from the list title and select **Sort by rank**.

    \[Omitted image "SortByRank.png"\] Alt text: Sort by rank

2.  To remove the ranking and return to the original order of the list, select the label in any column that contains data.
