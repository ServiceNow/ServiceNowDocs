# Use list controls in hierarchical lists

Switch the related list shown in a hierarchical list and show or hide its column headers. By default, one related list is displayed at a time and column headers are hidden.

## Before you begin

Role required: none

## Procedure

1.  In the list view, select the arrow icon to expand the record.

2.  To select a different related list, select the link in the related list context menu.

3.  Select a list from the menu.

    \[Omitted image "RelatedLists.png"\] Alt text: Select a different related list.

    If the related list is empty, the hierarchical list indicates that there are no records to display.

    The platform saves this preference and displays the last selected related list for each table when you open another hierarchical list within that table.

4.  To display column headers in the related list, select the show/hide headers icon in the upper right corner of the hierarchical list.

    \[Omitted image "EnableAColumnHeader.png"\] Alt text: Enable a column header

    The platform saves this preference and opens all hierarchical lists with column headers enabled until the headers are hidden.
