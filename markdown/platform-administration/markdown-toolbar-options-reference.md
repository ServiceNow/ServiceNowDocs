# Markdown toolbar options and syntax

The Markdown field type supports standard Markdown syntax and toolbar options for formatting content.

## Default toolbar options

The following options are available by default on the Markdown toolbar.

|Toolbar option|Markdown syntax|Description|
|--------------|---------------|-----------|
|Heading|`# H1`, `## H2`, `### H3`, `#### H4`, `##### H5`, `###### H6`|Organize content into section titles \(sizes H1-H6\)|
|Bold|`**bold text**`|Emphasize important text|
|Italic|`*italicized text*`|Italicize text|
|Strikethrough|`~~Strikethrough text~~`|Strikethrough text|
|Code|``code``|Format inline technical terms or commands|
|Highlight|`==Highlighted words==`|Draw attention to key information|
|Subscript|`H~2~O`|Position text below the line|
|Superscript|`X^2^`|Position text above the line|
|Bullet List|`- First item`|Unordered list for non-sequential items|
|Numbered List|`1. First item`|Ordered list for sequential or priority items|
|Task List|`- [ ] point 1`|Checklist for tracking action items|
|Link|`[title](https://www.example.com)`|Create clickable references to URLs or resources|
|Table|`| Header | Header |`|Display structured data in rows and columns|
|Code Block|````code````|Format multi-line code or technical content|
|Quote|`> quote`|Highlight important statements or references|
|Horizontal Rule|`---`|Insert visual divider between sections|
|Download|N/A|Save the current Markdown as a .md file|
|Full Screen|N/A|Change the editor into full screen mode|

## Additional supported Markdown syntax

The following Markdown elements are supported in addition to the toolbar options.

|Markdown element|Markdown syntax|Description|
|----------------|---------------|-----------|
|Image|`![Image](/url)`|Embed images|
|Fenced code block|````json`|Display formatted code snippets with syntax preservation|
|Footnote|`[^1]: This is the footnote.`|Add reference notes at the bottom of the page|
|Heading ID|`### My Great Heading {#custom-id}`|Create custom anchor links for direct navigation within documents|
|Definition List|`term : definition`|Present terms with their corresponding definitions|
|Emojis|`:joy:`|Insert emoji characters|
