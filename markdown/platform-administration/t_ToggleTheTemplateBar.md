# Toggle the template bar

The template bar appears at the bottom of forms. It provides shortcuts to apply, edit, and create templates.

## Before you begin

Role required: none

## About this task

You can toggle the template bar, which hides or shows it for all forms. The template bar is shown by default.

\[Omitted image "UI16TemplateBar.png"\] Alt text: Template bar

## Procedure

1.  Navigate to a form.

2.  Click the more options icon \(\[Omitted image "IconUI16MoreOptions.png"\] Alt text: More options icon\) in the form header.

3.  Select **Toggle Template Bar**.
