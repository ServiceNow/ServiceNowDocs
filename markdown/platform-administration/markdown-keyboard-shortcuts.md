# Markdown field keyboard shortcuts

Keyboard shortcuts are available for common Markdown formatting actions.

The following keyboard shortcuts are available in Markdown fields.

|Action|Mac|Windows and Linux|
|------|---|-----------------|
|Bold|⌘B|Ctrl+B|
|Italic|⌘I|Ctrl+I|
|Inline code|⌘E|Ctrl+E|
|Code block|⌘⌥C|Ctrl+Alt+C|
|Blockquote|⌘⇧.|Ctrl+Shift+.|
|Link|⌘K|Ctrl+K|
|Focus toolbar|⌥F8|Alt+F8 or Alt+F10|
|Return to editor or exit full screen|Escape|Escape|
|Resize \(focus the handle first\)|↑ or ↓|↑ or ↓|
