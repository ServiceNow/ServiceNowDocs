# Configuration Console for Software Asset Management

Use the Configuration Console to configure Software Asset Management after installation. Complete platform-level settings, configure key items with AI assistance, and package configurations for deployment to other instances.

**Note:** To access the Configuration Console for Software Asset Management, you must have the sam\_admin and sn\_ia\_config.ia\_user roles.

The Configuration Console for Software Asset Management groups configuration items under the following three categories:

-   Software foundations
-   Governance
-   Data management

From the console, you can:

-   Track configuration progress on the Configuration Summary page.
-   Complete platform-level settings such as content jobs, properties, and scheduled jobs.
-   Use AI assistance to configure items such as Content service setup, Groups, and Users.
-   Package configuration changes into an update set and download it to deploy to another instance.

**Note:** AI-assisted configuration provides suggestions based on your instance data and may not be accurate. Review and validate all AI-generated configurations before applying them to verify they meet your organization's requirements.
