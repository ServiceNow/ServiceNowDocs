# Using CMDB success advisor for SAM

As a CMDB administrator, you can use the Software Asset Management \(SAM\) dashboard in CMDB success advisor to keep software asset data accurate and aligned with data quality guidelines.

The ServiceNow® CMDB success advisor is a scoped application that drives business outcomes for targeted business products. To learn more, see [CMDB success advisor](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/servicenow-platform/cmdb-sa.md).

1.  [CMDB success advisor for SAM setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-asset-management/software-asset-management/cmdb-sa-sam-config-settings.md).

    Set up the CMDB success advisor for Software Asset Management \(SAM\).

2.  [Monitor CMDB data quality for SAM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-asset-management/software-asset-management/cmdb-sa-sam-dashboard.md).

    Identify and address data quality issues specific to SAM in the CMDB.

3.  [Improve CMDB data quality for SAM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/it-asset-management/software-asset-management/cmdb-sa-sam-remediation.md).

    Use the Remediation actions panel available for a data card in the advisor dashboard for SAM to improve the overall quality of your CMDB.
