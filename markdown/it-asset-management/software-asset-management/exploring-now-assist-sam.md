# AI in Software Asset Management

ServiceNow Otto for Software Asset Management \(SAM\) uses AI to automate software asset management operations, improve compliance, and optimize license management.

The ServiceNow AI Platform now brings you a new AI experience with three licensing tiers available:

-   Foundation: AI basics to deliver insights
-   Advanced: AI to boost productivity across relevant use cases
-   Prime: Act autonomously with all AI assets, and create your own

For more information, see [ServiceNow product tiers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/ai-native-sku-overview.md).

## AI capabilities in ServiceNow Otto for Software Asset Management \(SAM\)

ServiceNow Otto for SAM enhances the capabilities of the Software Asset Management application. It automates complex tasks, provides intelligent insights, and enables organizations to manage software assets, maintain compliance, and reduce costs.

With ServiceNow Otto for SAM AI agent collection, organizations gain the following benefits:

-   Reduce software request processing time by automating software request fulfillment.
-   Identify and create reclamation rules for software products that lack reclamation rules but are viable candidates.
-   Identify and reclaim unused licenses to reduce waste and accelerate license reclamation.

With ServiceNow Otto for SAM generative AI skills, organizations gain the following benefits:

-   Generate detailed publisher and product summaries to enhance software estate visibility and streamline compliance evaluation.
-   Generate recommended actions to manage software license compliance and optimize licensing spend.
-   Generate user resolution rules to support accurate mapping of incoming subscription data to SAM users.
-   Create entitlements by extracting information from software contracts, reducing manual effort.
-   Resolve entitlement import errors by normalizing the unresolved Publisher and Product field value.
