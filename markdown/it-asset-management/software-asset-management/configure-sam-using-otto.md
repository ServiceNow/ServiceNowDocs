# Configure Software Asset Management using AI

Use the AI conversational experience to configure Content service setup, groups, and users in the Configuration Console as a guided alternative to manual configuration.

The AI assistant guides you to configure the following three items in the Configuration Console for Software Asset Management:

-   Content service setup
-   Groups
-   Users

Items that AI can configure display an Otto automation available badge on the item page. Complete the remaining items manually. For the full list of configuration items and reference links, see [Configuration Console overview](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/software-asset-management/config-console-overview.md).

AI-guided configuration suits standard setups where you want suggested values based on your instance data. Manual configuration remains available for items that require custom values or that the AI assistant does not support.

When you select **Configure with AI** in the console header, the AI assistant opens as a side panel and suggests values for each configuration option based on your instance data. You can accept the suggestions, choose alternatives, or skip steps. After completing the AI-guided configuration, select **Mark as configured** on the item page. The item's status updates on the Configuration Console, and you can proceed to the next item.

-   **[Configure Content Service setup using AI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/software-asset-management/configure-content-service-otto.md)**  
Use the AI conversational experience to opt in to the Software Asset Management Content Service. The AI conversational experience walks you through the opt-in decision, the software asset data types that you share with ServiceNow, and the confirmation of your choices.
-   **[Configure groups and users using AI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/software-asset-management/configure-sam-team-using-ai.md)**  
Use the AI conversational experience in the Configuration Console to configure groups and users for Software Asset Management. This approach allows you to complete multiple setup tasks through a single interface without navigating to individual modules.
