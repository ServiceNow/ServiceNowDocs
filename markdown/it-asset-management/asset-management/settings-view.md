# Settings view in the AI Cost Management application

The Settings view enables you to set up integrations,spend limits and alerts, and enter subscription costs to use with the AI Cost Management application.

The Settings view is divided into the following sections, where you can perform relevant tasks:

-   **Integrations**: Create and manage integrations with AI provider accounts. For detailed instructions, see [Integrating with AI providers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-asset-management/asset-management/integrating-ai-saas-providers.md).

    Access this section of the Settings view by navigating to **Settings** &gt; **Integrations** in the navigation panel of the AI Cost Management application.

    \[Omitted image "aicm\_integrations.png"\] Alt text: Integrations page showing a table with connected AI software accounts, integration types, sync status, and view logs links.

-   **Spend limits**: Set up spend limits and thresholds on those limits. Alerts based on these thresholds notify you when an entity like a department or user exceeds your specified thresholds. For detailed instructions, see [Set up an AI spend limit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-asset-management/asset-management/set-up-spend-limits.md).

    Access this section of the Settings view by navigating to **Settings** &gt; **Spend limits** in the navigation panel of the AI Cost Management application.

    \[Omitted image "aicm\_spend-limits.png"\] Alt text: Spend limits page showing organization-wide limit and account-specific limits with alert thresholds and notification settings.

-   **Subscription costs** \(Copilot only\): Configure the per-seat monthly charge for each Microsoft Copilot account. See [Configure Subscription Cost for Microsoft Copilot](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-asset-management/asset-management/configure-subscription-cost-for-microsoft-copilot.md).

    Access this section of the Settings view by navigating to **Settings** &gt; **Subscription costs** in the navigation panel of the AI Cost Management application.

    \[Omitted image "aicm\_subscription.png"\] Alt text: Subscription costs page displaying subscriptions for two Microsoft Copilot accounts
