# Manage transfer order

Manage the asset movement from one stockroom to the other using transfer order.

-   **[Transfer orders for Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/it-asset-management/asset-management/transfer-orders-for-am.md)**  
Transfer orders move assets between company stockrooms.
-   **[Create a transfer order for Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/it-asset-management/asset-management/t_CreateATransferOrder.md)**  
Create a transfer order in order to transfer assets from one location to the other.
-   **[Transfer order line asset tracking](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/it-asset-management/asset-management/r_TransferOrderLineAssetTracking.md)**  
As transfer order line actions are triggered, the stock information and states of any affected assets are updated. Consumables and non-consumables are tracked differently.
-   **[Perform bulk updates for transfer order lines](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/yokohama/markdown/yokohama/it-asset-management/asset-management/create-bulk-transfer.md)**  
Update tasks for multiple transfer order lines at one go to streamline the transfer order process.
