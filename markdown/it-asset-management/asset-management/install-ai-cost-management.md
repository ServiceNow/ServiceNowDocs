# Install AI Cost Management

You can install the AI Cost Management application \(sn\_itam\_aicm\) if you have the admin role..

## Before you begin

-   Ensure that the application and all of its associated ServiceNow Store applications have valid ServiceNow entitlements. For more information, see [Get entitlement for a ServiceNow product or application](https://store.servicenow.com/$appstore.do#!/store/help?article=KB0030186).
-   Review the [application listing](https://store.servicenow.com/store/app/afe169b9c3b74b106a2eb043e40131ea) in the ServiceNow Store for information on dependencies, licensing or subscription requirements, and release compatibility.
-   Verify that the Software Asset Management Professional plugins is already activated on your ServiceNow instance.

Role required: admin

## About this task

Roles are installed with AI Cost Management.

For more information, see [Components installed with AI Cost Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-asset-management/asset-management/installed-with-ai-cost-management.md).

## Procedure

1.  Navigate to **All** &gt; **System Applications** &gt; **All Available Applications** &gt; **All**.

2.  Find the AI Cost Management application \(sn\_itam\_aicm\) using the filter criteria and search bar.

    You can search for the application by its name or ID. If you can't find the application, you might have to request it from the ServiceNow Store.

    A list of the available versions are displayed.

3.  Select a version from the list and select **Install**.

    In the Review Installation Details dialog box, any dependencies installed with your application are listed.

4.  If you're prompted, follow the links to the ServiceNow Store to get any additional entitlements for dependencies.

5.  If demo data is available and you want to install it, select the **Load demo data** check box.

    Demo data are the sample records that describe application features for common use cases. Load the demo data when you first install the application on a development or test instance.

6.  Select **Install**.


## Result

You can access AI Cost Management by navigating to **All** &gt; **AI Cost Management** &gt; **Home**.
