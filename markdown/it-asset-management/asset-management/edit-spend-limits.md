# Edit spend limits

Edit spend limits and alert thresholds for accounts, cost centers, departments. Edit alert thresholds for users.

## Before you begin

Role required: ai\_cost\_admin

## Procedure

1.  Navigate to **All** &gt; **AI Cost Management** &gt; **Home**.

2.  From the navigation panel of the AI Cost Management application, navigate to **Settings** &gt; **Spend limits**.

3.  Select the tab for the entity type you want to edit.

4.  Select the **Edit** icon to open the Edit panel to make changes.

    Note the following:

    -   The spend limit for an organization is derived from the total of all account spend limits. You can't edit this amount.
    -   User spend limits are imported directly from Anthropic. You can only set alert thresholds for users.
5.  Select **Update**.
