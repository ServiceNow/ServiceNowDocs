# Add a Microsoft Copilot integration

Add an integration to track and monitor spend and usage for Copilot.

Integration with Copilot involves two steps:

-   Configure the integration. See [Configure Microsoft Copilot integration](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-asset-management/asset-management/configure-microsoft-copilot-integration.md)
-   Configure your subscription costs. See [Configure Subscription Cost for Microsoft Copilot](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/it-asset-management/asset-management/configure-subscription-cost-for-microsoft-copilot.md)
