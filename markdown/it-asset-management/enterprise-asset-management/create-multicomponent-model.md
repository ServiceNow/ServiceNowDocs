# Create a multi-component model

Create a multi-component model to define more than one model component based on the same product model.

## Before you begin

For details on multi-component models, see [Multi-component models and assets in Enterprise Asset Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/enterprise-asset-management/complex-models.md).

Role required: sn\_eam.enterprise\_admin or sn\_eam.enterprise\_asset\_manager

## Procedure

1.  Create a model by navigating to **Enterprise Asset Workspace** &gt; **Enterprise model management**

    You can create a pre-assembled or user-assembled model. For instructions on how to create a model, see [Create enterprise models](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/enterprise-asset-management/create-model-eam.md).

2.  After you create a model, add model components to it.

    You can add model components only when the model has a status of Build. In addition, each model component must have a status of In Production. For instructions on how to create model components, see [Create enterprise model components](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/enterprise-asset-management/create-model-components-eam.md).

3.  After you add all model components to the model, change the status of the model to **In Production**.

4.  Select **Publish to Enterprise Asset Catalog** to publish your model to the catalog.
