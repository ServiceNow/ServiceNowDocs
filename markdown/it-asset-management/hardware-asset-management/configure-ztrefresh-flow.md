# Configure Zero Touch Refresh flow

Set up the Service Exchange connection and replacement models that the Zero Touch Refresh flow requires before asset managers can initiate hardware refresh requests through an external provider.

|Configuration task|Configuration scope|
|------------------|-------------------|
|[Service Exchange configuration for Zero Touch Refresh](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/service-bridge-config-ztr.md)|Service Exchange connection between your ServiceNow instance and the provider ServiceNow instance, including triggering remote task assignment and activating remote task definitions.|
|[Replacement model configuration for a refresh model](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/create-replacement-model.md)|Replacement models for each refresh hardware asset model so that employees can select correct replacement asset when a refresh request is initiated.|

-   **[Configure replacement models for a refresh model](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/create-replacement-model.md)**  
Configure replacement models for a hardware asset model that is refreshed. When configured, employees can select replacement models for their hardware assets on the Zero Touch Refresh form.
