# Integrations and advanced configuration

Configure HAM integrations and advanced settings to connect external carriers, enable Zero Touch workflows, track cost and performance, define success goals, and manage charity organizations for asset disposal.

|Configuration task|Configuration scope|
|------------------|-------------------|
|[Configure Hardware Model Normalization](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/Work-with-hardware-normalization.md)|Hardware Model Normalization and normalization settings for hardware and consumable models.|
|[Configure HAM success goals](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/suc-goal-act-hw.md)|Measurable targets, automated actions, and goal categories for your asset management priorities.|
|[Configure total cost of ownership](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ham-tco.md)|Labor task rates and task types for calculating the full cost of deploying, maintaining, and retiring assets.|
|[Configure asset performance KPI settings](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-kpi-settings-ham.md)|Operational tracking schedules and settings for measuring uptime and utilization for hardware assets.|
|[Configure integration framework to track shipments](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-int-frame-shipment.md)|Carrier API connections through integration profiles and script includes for automatic shipment status updates on transfer orders and stock requests.|
|[Configure the Zero Touch request flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ztr-flow.md)|Service Exchange connection, service catalog items, and integration profile or routing and fulfilling employee hardware requests through an external provider.|
|[Configure Zero Touch Refresh flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ztrefresh-flow.md)|Service Exchange connection between your ServiceNow instance and a provider ServiceNow instance for transmitting and fulfilling Zero Touch asset refresh requests.|
|[Configure the Lenovo Warranty API connection](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/connect-to-lenovo-api.md)|Connection and credential for accessing the Lenovo Warranty API.|
|[Configure charity organization for asset donation](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/add-charity-org.md)|Charity organizations available for donating assets.|
|[Configure the Manage contract repository agentic workflow for HAM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-contract-repo-agentic-workflow-ham.md)|Generative AI skills for the Manage contract repository agentic workflow.|

-   **[Configure Hardware Model Normalization](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/Work-with-hardware-normalization.md)**  
Hardware Model Normalization standardizes manufacturer, model, and model number data across asset records using the Hardware Asset Management Content Service. Normalized data improves the accuracy of asset reporting, lifecycle planning, and cost analysis. Configure hardware normalization before asset managers begin creating or managing hardware models.
-   **[Configure HAM success goals](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/suc-goal-act-hw.md)**  
Track the success of the Hardware Asset Management application in your instance by creating success goals. You can also create a success goal category for a success goal and track the success of your goals by creating success activities.
-   **[Configure the Total Cost of Ownership of assets](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ham-tco.md)**  
Configure the Total Cost of Ownership \(TCO\) of assets by creating rate cards for each task in a Hardware Asset Management workflow.
-   **[Configure settings to monitor asset key performance indicators \(KPIs\) in the Hardware Asset Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-kpi-settings-ham.md)**  
Set up the necessary configurations in the Asset operations view to enable the tracking of KPIs for your hardware assets. These settings enable you to monitor and manage the performance your assets.
-   **[Integration framework configuration for shipment tracking](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-int-frame-shipment.md)**  
Configure the integration framework for Hardware Asset Management \(HAM\) to connect to external shipping carriers so that inbound shipments are tracked in real time and asset records are updated automatically when hardware asset arrives.
-   **[Configure Zero Touch request flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ztr-flow.md)**  
The Zero Touch request flow requires a Service Exchange connection, service catalog items, and an integration profile so that employees can submit hardware requests through an external provider.
-   **[Configure Zero Touch Refresh flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ztrefresh-flow.md)**  
Set up the Service Exchange connection and replacement models that the Zero Touch Refresh flow requires before asset managers can initiate hardware refresh requests through an external provider.
-   **[Connect to the Lenovo Warranty API](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/connect-to-lenovo-api.md)**  
Create a connection and credential to connect to the Lenovo Warranty API and download the warranty information for hardware assets.
-   **[Add a charity organization for donating assets](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/add-charity-org.md)**  
Add a charity organization to the Charity Organization \[sn\_itam\_common\_charity\_org\] table to make it available for asset donations.
-   **[Configure the Manage contract repository agentic workflow for HAM](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-contract-repo-agentic-workflow-ham.md)**  
Install the ServiceNow Otto for Contract Management Pro plugin \(sn\_cm\_gen\_ai\) and activate the generative AI skills to use the Manage contract repository agentic workflow.
