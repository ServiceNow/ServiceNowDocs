# Use Zero Touch request flow

Fulfill hardware asset requests of your employees through an external provider by using the Zero Touch request flow.

After [Configure Zero Touch request flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/configure-ztr-flow.md) is complete, employees can submit hardware asset requests through the service catalog, and the provider receives and fulfills those requests automatically through the Zero Touch request flow.

## Zero Touch request flow tasks for your employees

1.  [Request a hardware asset through the Zero Touch request flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/request-hardware-assets-ztr-catalog.md).
2.  [Acknowledge receipt of an asset received through the Zero Touch request flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/acknowledge-ztr-asset-on-mobile.md).

## Zero Touch request flow task for providers

[Fulfill incoming hardware asset requests assigned to you through the Zero Touch request flow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/it-asset-management/hardware-asset-management/fulfill-provider-task-ztr.md).
