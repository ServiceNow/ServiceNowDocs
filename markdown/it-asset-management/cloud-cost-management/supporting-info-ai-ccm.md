# Supporting information for ServiceNow Otto for Cloud Cost Management \(CCM\)

Get a quick overview of the important information related to the ServiceNow Otto for Cloud Cost Management application.

## Supported versions

The ServiceNow Otto for CCM application is supported starting with the Australia Patch 5 release.

## Supported user interfaces

You can access the generative AI skill included in the ServiceNow Otto for CCM application through the ServiceNow Otto panel in the Cloud Cost Management Workspace.

## Application information

Activate the ServiceNow Otto for Cloud Cost Management \(CCM\) \(com.sn\_now\_assist\_ccm\) store application to use the generative AI skill.

This store application has the following dependencies:

-   Cloud Cost Management \(sn\_clin\)
-   Cloud Spend Core \(sn\_cld\_spend\_core\)
-   Cloud Integrations Core \(sn\_cld\_intg\_core \)
-   ServiceNow Otto for Platform \(com.sn\_genai\_platform\)
-   AI Agents for IT Asset Management \(com.sn\_itam\_aia\)

Activate the applications in the following order:

-   Cloud Cost Management \(sn\_clin\)
-   Cloud Spend Core \(sn\_cld\_spend\_core\)
-   Cloud Integrations Core \(sn\_cld\_intg\_core \)
-   ServiceNow Otto for Platform \(com.sn\_genai\_platform\)
-   ServiceNow Otto for Cloud Cost Management \(com.sn\_now\_assist\_ccm\)
