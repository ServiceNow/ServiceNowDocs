# Saved views

The Saved views page displays all spend analytics views saved for your organization. Use this page to manage your customized views.

The Saved views page shows configuration details for each spend view, including the spend type, cost type, time range, group-by selection, permissions, and the date it was created. Access the Saved views page by navigating to **Workspaces** &gt; **Cloud Cost Management Workspace** &gt; **Spend** &gt; **Saved views**.

\[Omitted image "saved-views-ccm.png"\] Alt text: Saved views page on Cloud Cost Management Workspace

Perform the following actions on the Saved views page.

|Button|Action|
|------|------|
|New|Creates a new spend analytics view with the configured spend type, cost type, time range, group-by options, and permissions.|
|Edit|Updates the selected view according to your input. Select a view from the list to edit it.|
|Set as default|Sets the selected view as your default view on the Spend analytics page. The default view loads automatically when you open the Spend analytics page. Select a view from the list to set as default.|
|Delete|Deletes the selected view. Default views can't be deleted.|
