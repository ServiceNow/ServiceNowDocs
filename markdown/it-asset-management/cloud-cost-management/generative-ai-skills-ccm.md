# Using generative AI skills for ServiceNow Otto for Cloud Cost Management \(CCM\)

Streamline cloud spend management tasks in the Cloud Cost Management Workspace by using the generative AI skills available in the ServiceNow Otto for Cloud Cost Management application.

|Generative AI skill name|Description|Version information|
|------------------------|-----------|-------------------|
|[Cloud cost summarizer](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/it-asset-management/cloud-cost-management/spend-summary-otto-ccm.md)|Generates a comprehensive summary of spend trends for all the cloud service providers, top cost drivers, budget comparisons, and optimization recommendations.|Introduced in ServiceNow Otto for Cloud Cost Management \(CCM\) version 11.0.|
