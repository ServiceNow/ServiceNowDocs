# HRSD MCP Server

The HRSD MCP Server allows HR agents and employees to securely access Case and Knowledge Management features through AI applications like Claude.

## MCP Server Overview

The Model Context Protocol \(MCP\) enables large language models \(LLM\) to communicate with external systems like a ServiceNow instance. AI applications such as Claude or Copilot use MCP servers to access external resources and perform actions. Tools define which functionality and data a server exposes to clients and the actions that can be performed on an instance. For more information on the ServiceNow AI Platform MCP Server Console Console, see [MCP Server Console](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/mcp-platform-manager-landing.md).

**Note:** Depending on your license, you will have access to certain application features, generative AI skills, agentic workflows, and AI agents. For more information, see [ServiceNow product tiers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/ai-native-sku-overview.md).

## HRSD MCP Server capabilities

HR agents can:

-   List and triage your assigned case queue \(open, overdue, unresolved\)
-   Add work notes or employee-visible comments to cases
-   Advance, resolve, or close cases with resolution notes
-   Look up operational and agent-facing knowledge \(SLAs, approvals\)
-   Work within platform-enforced state-transition rules

Employees can:

-   Open an HR case for an eligible service via natural language
-   Check case status or list/search open, recent, or overdue cases
-   Add comments to a case
-   Progress or close a case with resolution notes
-   Get direct, cited answers to HR policy questions
-   Check eligibility and required documents for HR services
-   Browse and search for eligible HR services
