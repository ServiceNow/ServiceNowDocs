# View a special handling note in HR Service Delivery Agent Workspace

View special handling notes that alert you to important information about HR cases requiring careful attention.

## Before you begin

Role required: sn\_hr\_core.case\_writer

## Procedure

1.  Navigate to **All** &gt; **HR Case Management** &gt; **HR Agent Workspace**.

2.  Locate and display an HR case.

    If the HR case is configured to show a special handling note, it appears as a pop-up.\[Omitted image "agent-ws-hr-spec-hand-pop-up.png"\] Alt text: Special handling note pop-up dialog displaying alert message with Dismiss button

3.  Read the note and select **Dismiss**.
