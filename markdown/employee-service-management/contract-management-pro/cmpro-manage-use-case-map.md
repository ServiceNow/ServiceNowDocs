# Manage use case mappings for ServiceNow Otto for Contract Management Pro

Manage use case mappings for ServiceNow Otto for Contract Management Pro by updating the mapped tables for use cases, deactivating the mappings when not in use, or deleting them when no longer required.

## Before you begin

Role required: sn\_cm\_gen\_ai.ai\_contract\_config, sn\_cm\_contract\_config

## Procedure

1.  Navigate to **All** &gt; **Admin Center** &gt; **AI Admin Hub** to access the **AI Skills** tab of the AI Admin Hub console.

2.  Navigate to **Employee** &gt; **CM Pro**.

3.  On the tile of your activated skill, select **Edit Configuration** to modify it.

    \[Omitted image "cmpro-na-active-skills.png"\] Alt text: Active skills in Contract management pro.

4.  In the skill guided setup, select **Use case mappings**.

5.  Select the actions icon \[Omitted image "cmpro-na-three-dot-icon.png"\] Alt text: Actions icon. on the use case mapping that you want to update, delete, or deactivate.

    \[Omitted image "cmpro-na-edit-usecase-map.png"\] Alt text: Actions available on use case mappings.

    -   **Edit**

        Update the mapped tables or conditions for the mapping.

        For more information on mapping a use case, [Map a use case for contract metadata extraction](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/employee-service-management/contract-management-pro/cmpro-na-usecase-mappings-me.md), [Map a use case for contract obligation extraction](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/employee-service-management/contract-management-pro/cmpro-na-map-usecase-obext.md), and [Map a use case for contract analysis](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/employee-service-management/contract-management-pro/cmpro-na-usecase-mappings-ca.md).

    -   **Deactivate**

        Deactivate a use case mapping to temporarily make it unavailable for the skill.

        The **Reactivate** option appears when a use case mapping is deactivated. Use this option to activate a use case mapping.

    -   **Delete**

        Delete a use case mapping when it is no longer required for the skill.


## Result

AI uses the updated use case mapping for contract analysis or metadata extraction.
