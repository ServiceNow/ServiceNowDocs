# Manage AI skills

Manage AI skills in Contract Management Pro including use cases, use case mappings, clause mappings, expected responses, and skill activation.

Manage AI skills to maintain and optimize the performance of metadata extraction, contract analysis, and obligation extraction capabilities in Contract Management Pro.

## Management tasks

Perform the following management tasks for AI skills:

-   **Manage use cases**

    Create, modify, and delete use cases that define how AI skills extract metadata, analyze contracts, and identify obligations. Use cases specify which fields to extract, what criteria to analyze, and which obligations to track.

-   **Manage use case mappings**

    Map use cases to contract types to ensure the appropriate AI skills are applied to each contract. Update mappings when contract types change or new use cases are created.

-   **Manage clause mappings**

    Map field groups to specific clauses for contract analysis. Define which clauses should be analyzed for each field group and update mappings as contract templates evolve.

-   **Manage expected responses**

    Define and update expected responses for contract analysis to specify what the AI should identify when reviewing contracts. Expected responses help the AI understand your organization's contract standards and requirements.

-   **Deactivate AI skills**

    Deactivate AI skills when they are no longer needed or when troubleshooting issues. Deactivation prevents the skills from running without deleting the configuration.


## Best practices

Follow these best practices when managing AI skills:

-   Review and update use cases regularly to ensure they align with current contract management processes
-   Test changes to use cases and mappings with sample contracts before applying them to production
-   Document the purpose and configuration of each use case for future reference
-   Monitor AI skill performance and adjust configurations based on accuracy and user feedback
-   Deactivate unused skills to improve system performance and reduce confusion
