# View contract repository record

Use the tabs on a contract repository record to view contract details, documents, requests, obligations, and renewal history.

The following tabs are available on a contract repository \(CNTR\) record:

-   **Details**

    View and edit the contract details, including contract dates, parties, type, and other metadata fields.

-   **Child Contracts**

    View contracts that are linked as children of the current contract in a parent-child hierarchy.

-   **Contract documents**

    View all signed documents related to the contract, including documents generated or updated through amendment processes. Amendment contract documents have **Amend&lt;version&gt;** appended to the name.

-   **Contract requests**

    View all contract and amendment requests associated with the contract repository record.

-   **Obligations**

    View and manage obligations extracted from the contract. For more information, see [Obligation Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/contract-management-pro/cncore-obligation-management.md).

-   **Amendment field changes**

    View a detailed log of all field changes made through amendments, including the old and new values for each change.

-   **Record History**

    View the history of changes made to the contract repository record.

-   **Contract history**

    View the renewal chain for the contract, showing how it is connected to contracts that preceded it through renewal. Each entry shows the contract number, start date, end date, status, previous contract, and previous contract dates. For more information, see [View renewal details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/contract-management-pro/cncore-renewal-history.md).
