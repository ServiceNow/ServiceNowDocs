# Contract Management Pro MCP Server tools reference

Reference for the tools available in the Contract Management Pro MCP Server.

|Tool name|Description|
|---------|-----------|
|sn\_cm\_mcp\_server.get\_contract\_negotiation\_playbook|Fetch approved contract analysis playbook containing clause level organizational positions that is used as guidance for contract analysis and redlining.|

You can enable or disable the tool using one of the following methods.

-   Using the Enable toggle on the MCP server details page.
-   Opening the tool record and selecting the Activate check box.

For more information on the tools, see [Creating tools for a Model Context Protocol server](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/creating-tools-mcp-server.md)
