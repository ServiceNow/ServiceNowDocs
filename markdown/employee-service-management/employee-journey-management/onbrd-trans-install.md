# Install Lifecyle events for enterprise

Install Lifecyle events for enterprise and related applications.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **All Applications** and select Lifecyle events for enterprise.

2.  Select **Install**.
