# AI-Native HR Service Delivery Implementation

The HR Service Delivery Implementation agent shortens the path from install to a working HR Service Delivery deployment using an AI-first, centralized, and intuitive admin experience.

## What is the HR Service Delivery Implementation agent

The HR Service Delivery Implementation agent cuts through deployment friction and shortens the path from install to a working HR Service Delivery deployment. Instead of juggling multiple lists and console tabs, admins get a guided, intelligent configuration experience built right into the Admin Center. AI agents handle the heavy lifting: creating HR users and companies, setting up chat and email, building HR topics, configuring templates. Structured component checks catch prerequisite gaps early, so teams activate faster and with fewer surprises.

1.  Verify that the ServiceNow Otto for Setup application is installed your ServiceNow instance. See .
2.  Verify that you're licensed for HR Service Delivery Foundation or above. For more information, see [ServiceNow product tiers](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/intelligent-experiences/ai-native-sku-overview.md).

See [Install HR Service Delivery apps in the AI-Native workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/zurich/markdown/zurich/employee-service-management/hr-service-delivery/install-native-ai-hrsd.md).
