# HR Application Configuration

Configure system-level settings, behavioral controls, and conditional logic that govern the runtime operation and user interactions.

|Component|Description|
|---------|-----------|
|HR Criteria|Establishes conditional criteria to define groups of users based on specific conditions to enable predefined group actions.|
|HR Properties|Configures runtime properties that adjust the behavior of the HR application, including UI field display settings \(payroll activity fields, talent management activity fields\) and security/authentication settings. For a list of HR properties and descriptions, see [HR properties](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/hr-service-delivery/t_HRProperties.md).|
|HR Relationships|Define interpersonal relationships between users \(such as Aunt, Brother, Child, Cousin, or Daughter\), with optional dependent flags to indicate if a relationship involves dependent family members.|
|HR Surveys|Create surveys to capture feedback from employees at key moments, such as an HR Request Satisfaction Survey. For more information, see [HR surveys](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/hr-service-delivery/c_HRSurveysIst.md).|
