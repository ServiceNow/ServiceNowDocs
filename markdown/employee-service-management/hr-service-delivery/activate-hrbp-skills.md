# Activate HRBP skills

Activate the HR Case Enrichment skill to let the enrichment process set urgency, resolution tracks, and recommendations for HR cases that are assigned to an HRBP. If you want AI-generated case summaries, also activate the HR Case Summarization skill.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **AI Admin Hub** &gt; **Skills**.

2.  Expand the **Employee** menu, and select **HRSD**.

3.  Locate the **HR Case Enrichment** skill.

4.  Select **Activate**.

5.  If you want AI-generated case summaries, activate the **HR Case Summarization** skill.

    The HRBP skills are active and ready for use. Proceed to the next configuration step.
