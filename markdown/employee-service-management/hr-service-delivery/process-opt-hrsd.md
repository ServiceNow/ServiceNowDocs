# Process Mining content pack for HR Service Delivery

The HR Service Delivery Process Mining Content Pack enables companies to analyze and improve service delivery processes.

The HR Service DeliveryProcess Mining Content Pack \(com.sn\_hr\_process\_optimization\) application is not available as a standalone application, it is available through the unified Process Mining Content Pack application. For more information, see [Process Mining](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/now-intelligence/process-mining.md).

-   For new users, the Process Mining Content Pack application will be auto-installed, which delivers a more intuitive, cohesive experience.
-   For the existing users, the support for Process Mining Content Pack for HR Service Delivery is ended. While it remains active in your instance, including when you upgrade to a new release family, HR Service Delivery does not support it.

    The unified Process Mining Content Pack application will be available automatically. No manual action is required; Existing functionality is expected to remain available through the unified Process Mining Content Pack application.
