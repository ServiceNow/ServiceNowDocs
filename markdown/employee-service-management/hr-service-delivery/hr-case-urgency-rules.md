# HR case urgency rules

During the enrichment process, urgency rules set a minimum urgency level for HR cases that match specific conditions. Review the base system rules and the level each one sets.

|Rule name|Rule type|Urgency level|
|---------|---------|-------------|
|Misconduct|Condition-based|Critical|
|Manager-initiated PIP|Condition-based|High|
|Discrimination|Condition-based|Critical|
|Payroll discrepancies|Condition-based|Medium|
