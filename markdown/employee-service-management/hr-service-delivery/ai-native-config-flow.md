# Configure HR Service Delivery in AI-Native workflow

Configure your HR Service Delivery workflows using an AI-first, centralized, and intuitive admin experience.

## Before you begin

Role required: admin

Install the HR Service Delivery applications: [Install HR Service Delivery apps in the AI-Native workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/hr-service-delivery/install-native-ai-hrsd.md)

Complete the ServiceNow Otto for Setup Platform configuration flow: [Configure the Platform module in ServiceNow Otto for Setup](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/platform-administration/ia-config-platform-il.md)

## Procedure

1.  If you selected **Configure** in the **Now you're ready to configure** window, you're redirected to the **Configure Human Resources Service Delivery** page.

    Otherwise, open the Configuration Console from the Admin tab or via the Admin Center:

    -   Admin tab:

        From the **Admin** tab, select **Human Resources Service Delivery**.\[Omitted image "admin-tab-hrsd.png"\] Alt text: The Admin tab has the Human Resources Service Delivery option

    -   Admin Center:
        1.  Navigate to **Admin Center** &gt; **Admin Home**.
        2.  From the **Manage your products** section, select the **Human Resources Service Delivery** tile.
        3.  From the Product Hub page for HR Service Delivery, select **Configure**.
2.  From the HR Service Delivery Configuration Console, perform any of the following tasks.

    \[Omitted image "hrsd-config-console.png"\] Alt text: Configure Human Resources Service Delivery Configuration Console showing configuration summary and setup status.

    |Choice|Description|
    |------|-----------|
    |**Configuration Summary in the left navigation pane**|Provides a summary of configuration activity and progress across modules.|
    |**Configure with AI**|Opens ServiceNow Otto to configure the selected item.|
    |**Configurations under Platform and Case and Knowledge Management in the left navigation pane**|For each module, view the default configuration \(if available\) and modify it as necessary.|
    |**Package and download**|Packages configuration changes into an update set and downloads it to use in another instance.|
