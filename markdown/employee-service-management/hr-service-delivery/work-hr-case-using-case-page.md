# Work an HR case on the case page

As an HR business partner, review the AI insights, details, and history for an HR case on one page. You can approve, reject, defer, resume, or cancel the case from the same page.

## Before you begin

Role required: HR business partner \[sn\_hrbp\_hub.user\]

## About this task

When you update a case in your conversation with the HRBP productivity assistant, the case page reflects the change without refreshing the page.

## Procedure

1.  Open the EmployeeWorks Web App.

2.  In the side navigation, under Assistants, select **HRBP Productivity Assistant**.

    If the assistant isn't listed, select **Browse assistants** and then select the **HRBP Productivity Assistant** card.

3.  In the message field, ask to see your cases.

    For example, type `Show me my open cases`.

    The assistant lists your cases.

4.  Select the case number associated with the case you want to work.

    You can also select **Investigate** on a case card in the Your requests section of the HRBP homepage.

    The case page opens.

5.  Review the AI Insights panel.

    The panel shows the recommendation, the confidence score, and a summary of the case. To see the full summary, select **Read more**.

    -   For Employee Relations cases, the panel displays the summary only.
    -   If AI analysis is still in progress, the panel displays a status indicating analysis is pending.
    -   For request types that don't support AI insights, the panel indicates the request type isn't supported. You can still review and act on the case.
    **Important:** Always review AI-generated content for accuracy.

6.  Review the fields on the **Case details** tab.

    The tab lists the people linked to the case, the AI urgency, and the HR service. To open a person's profile, select the person's name.

7.  Select the **Activity** tab to review the case history.

8.  Select the **Attachments** tab to view or add attachments.

    You can add attachments only if you have write access to the case.

9.  Act on the case.
