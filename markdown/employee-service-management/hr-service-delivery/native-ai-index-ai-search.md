# Index AI search

Index the HR Service Delivery AI Search to enable the Implementation agent to retrieve data from existing HR services.

## Before you begin

Role required: admin

[Install HR Service Delivery apps in the AI-Native workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/hr-service-delivery/install-native-ai-hrsd.md)

## Procedure

1.  Navigate to **All** &gt; **AI Search** &gt; **AI Search Index** &gt; **Indexed Sources**.

2.  Set the application scope to `HR Service Delivery Implementation Agents`.

3.  Select **HR Service**.

4.  Select **Index All Tables**.

    The indexing process runs. In the future, a scheduled job runs to index new HR services.
