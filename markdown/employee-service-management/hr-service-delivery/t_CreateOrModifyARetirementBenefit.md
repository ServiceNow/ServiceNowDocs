# Enroll an employee in the company retirement plan

Enroll an employee in the company retirement plan using the retirement benefits module.

## Before you begin

Role required: sn\_hr\_core.profile\_writer

## Procedure

1.  Navigate to **HR Profile** &gt; **Retirement benefits**.

2.  Select **New**.

3.  Complete the form.

    The fields you see depend on how the form is configured and what fields are selected to display.

    |Field|Description|
    |-----|-----------|
    |Plan|Select the **Lookup using list** icon and select the retirement plan.|
    |Employee|Select the **Lookup using list** icon and select the employee.|
    |Plan ID|Select the **Lookup using list** icon and select the bank account.|

4.  Select **Submit**.
