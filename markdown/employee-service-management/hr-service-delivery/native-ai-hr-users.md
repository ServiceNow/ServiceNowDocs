# HR Users

Manages access control, group assignments, and escalation workflows to enable HR service delivery and support across different user types and organizational tiers.

|Component|Description|
|---------|-----------|
|HR Group|Set up groups and manage group membership. Groups can have managers and parent groups.|
|HR Roles|Define permissions for different user types accessing HR application features.|
|HR Client Role Rules|Set up client role rules to grant non-HR team users access to HR Services. Use employment type conditions and employment start date logic to determine role eligibility, for example, contractors active within a specified timeframe.|
|HR Tier Escalation Rules|Define where HR cases get delivered and the rules for escalation between HR tiers. Allows routing of cases based on complexity or tier requirements.|
