# Use the capabilities from the ServiceNow Otto panel

Use the contextual AI capabilities, such as a request summary by using the conversational interface in the ServiceNow Otto panel.

## Before you begin

Make sure that Next Experience is enabled in the instance. For more information, see [Next Experience UI](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-user-interface/next-experience-landing-page.md).

Role required: sn\_lg\_gen\_ai.request\_fulfiller

## About this task

You can use the ServiceNow Otto panel to request a summary.

For more information about the panel, see [ServiceNow Otto panel](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-panel-overview.md). For information about activating the panel, see [Activate the ServiceNow Otto panel standard chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/intelligent-experiences/activate-now-assist-panel.md).

## Procedure

1.  Log in to an instance where the ServiceNow Otto for LSD application is installed.

2.  Navigate to **Workspaces** &gt; **Legal Counsel Center**.

3.  Request the generative AI capabilities in LSD for summarization by selecting the ServiceNow Otto icon \[Omitted image "cmpro-otto-icon.png"\] Alt text: Now assist icon..

4.  After you request the generative AI capabilities, select **Summarize a record**.

5.  Enter the record number that you want to summarize.

    The summary is displayed.
