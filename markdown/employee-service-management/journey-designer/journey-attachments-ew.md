# Add and view attachments on a journey in EmployeeWorks Web App

Upload, view, and download attachments on a journey or lifecycle event case from the Journey Details page in EmployeeWorks Web App.

## Before you begin

Role required: sn\_jny.manager

You must have permission to access the associated journey or lifecycle event.

## About this task

The Journey Details page includes an Attachments tab. Attachments are shown for both journey records and standalone lifecycle event cases.

## Procedure

1.  Open a journey or standalone lifecycle event case, and select the **Attachments** tab.

2.  To add a file, select the upload control and choose a file.

    The file is added as an attachment to the journey or lifecycle event case record.

3.  To open or download an attachment you're authorized to access, select it from the list.


## Result

The attachment list refreshes after attachments are added or removed. Loading and error states are handled if an upload or download doesn't complete successfully.
