# Journey Details page header in EmployeeWorks Web App

The Journey Details page header in EmployeeWorks Web App provides information about a journey, including its status, progress, remaining task count, and associated participants. The information displayed depends on whether you access the journey as an employee or a manager.

## Employee View

The employee header displays the following information:

-   **Journey status:** Displays the status based on the employee's assigned tasks:
    -   **Overdue**: One or more active tasks assigned to the employee are overdue.
    -   **On Track**: No active tasks assigned to the employee are overdue while the journey remains in progress.
-   **Remaining tasks:** Displays the number of tasks remaining for the employee.
-   **Progress:** Displays the completion percentage of the employee's assigned tasks as a progress bar.
-   **Journey Owner**: Displays the employee's manager or **Journey Owner** details.
-   **Mentor**: Displays the assigned mentor, when available.

## Manager view

The manager header displays the following information:

-   **Journey status:** Displays the manager-specific status based on tasks assigned to the manager.
-   **Remaining tasks:** Displays the number of tasks remaining for the manager.
-   **Manager progress:** Displays the completion percentage of tasks assigned to the manager as a progress bar.
-   **Overall journey status:** Displays the overall status of the journey.
    -   **Overdue**: One or more active tasks assigned to any journey participant.
    -   **On Track**: No active tasks assigned to any journey participant are overdue while the journey remains in progress.
    -   **Completed**: The journey is completed.
-   **Overall progress**: Displays the overall completion percentage of the journey.
-   **Team Member**: Displays the employee associated with the journey.
-   **Mentor**: Displays assigned journey mentors, when available.

## Progress indicators

Progress indicators display task completion percentages for the journey or lifecycle event.

-   **Employee view:** Displays progress based on tasks assigned to the employee.
-   **Manager view:** Displays the manager's task progress and the overall journey progress.

## View precedence

If you're both the subject person \(employee\) and the opened-for \(journey owner\) user of the same journey, the employee view takes precedence.
