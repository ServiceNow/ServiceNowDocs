# View upcoming tasks on the Journey Details page in EmployeeWorks Web App

View the upcoming tasks from the **Up Next** section on the Journey Details page in EmployeeWorks Web App to view upcoming tasks associated with the journey.

## Before you begin

Role required: You must have permission to access the associated journey or lifecycle event.

## About this task

The Up Next tab displays tasks that require your attention, helping you identify overdue and upcoming activities.

Each task card displays:

-   Task name and associated stage or activity set name.
-   Due Soon or Overdue status, when applicable.

Completed tasks are removed from the Up Next list, and the next eligible tasks are displayed.

## Procedure

1.  Navigate to the Journey details page and view the **Up Next** tab.

2.  Select a task card to open the corresponding task details page.


## What to do next

Complete the task from the Task details page.
