# View upcoming tasks on the Journey Details page in Employee Works

View and filter your next actionable tasks for a journey or lifecycle event case from the Up Next tab on the Journey Details page in Employee Works.

## Before you begin

Role required: sn\_jny.manager

## Procedure

1.  Navigate to a journey or standalone lifecycle event case and select the **Up Next** tab.

    Each task card shows the stage or activity set name and task name \(for example, Task Name - Stage Name\), a Required/Optional indicator, and a Due Soon or Overdue status when applicable.

2.  Select one or more filters — **Required**, **Overdue**, or **Due soon** to narrow the task list, or select **All tasks** to clear the other filters.

    Selecting any of the other three filters clears **All tasks**, and selecting **All tasks** clears the other filters. The task list updates immediately when a filter changes.

3.  Select a task card to open the corresponding task record page.


## Result

Tasks are ordered with overdue tasks first \(longest overdue first\), then tasks due today, then upcoming tasks by nearest due date. Completed tasks are removed automatically and replaced with the next eligible task. When you have no upcoming tasks, an empty state is shown.
