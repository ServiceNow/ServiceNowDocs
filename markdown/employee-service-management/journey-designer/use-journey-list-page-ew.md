# View journeys and lifecycle events from Journeys List page

The Journey List page in EmployeeWorks Web App provides a unified list view of all active journeys and lifecycle events that employees and managers have access to.

## Before you begin

Role required: You must have permission to access the associated journey or lifecycle event.

## Procedure

1.  Navigate to EmployeeWorks Web App and open the Journey List page by clicking on the **Open Journeys** icon from the Journeys widget.

    -   Each journey card shows the journey type, title, employee specific journey progress, and task completion status for employees. For managers, an overall journey status and overall progress is shown.
    -   You can identify journeys that require immediate attention by the overdue status indicator.
    -   By default, results are sorted by journey created date \(earliest first\).
2.  Select the **Journey Type** filter option and choose one or more journey types from the drop-down, to filter by a journey type.


## What to do next

Select a specific journey card to view and complete the journey from the Journey Details page.
