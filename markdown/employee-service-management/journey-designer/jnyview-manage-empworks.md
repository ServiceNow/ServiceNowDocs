# Journey view for managers in EmployeeWorks Web App

As a manager, you can view all your journeys and your team's journeys in EmployeeWorks Web App.

Managers can use EmployeeWorks Web App to monitor their journeys and their employees' journeys and track activities associated with their teams.

## Journeys Widget

The Journeys widget on the EmployeeWorks Web App homepage allows you to view your journeys and the journeys associated with your employees that you're authorized to view. For more information, see [Use the Journeys widget on the EmployeeWorks Web App home page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/use-journey-home-widget-ew.md).

\[Omitted image "jnywidget.png"\] Alt text: Journeys widget on the homepage with top three active journeys for the manager and the team managed

## Journeys list page

The Journeys List page allows you to review a unified list of journeys and lifecycle events \(yours and your team's under **Your** and **Teams** tabs respectively\). You can monitor journey status, progress, and upcoming activities, and identify journeys that need attention due to overdue activities. You can also filter journeys by journey type.

You select a journey card to open its **Journey Details** page. For more information, see [View journeys and lifecycle events from Journeys List page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/use-journey-list-page-ew.md).

\[Omitted image "jnylist-manager-ew.png"\] Alt text: Journey list page with the list of journeys and life cycle event for the manager and the team managed

## Journeys details page

The journey details page allows you

-   To monitor overall journey progress
-   View manager-specific task completion progress
-   View upcoming tasks
-   Identify overdue or due soon tasks across stages
-   Add comments and attachments

For more information, see [View journey stages and details in EmployeeWorks Web App](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/view-journey-details-ew.md).
