# Journey Accelerator task types in Employee Works

Supported Journey Accelerator \(JA\) task types are surfaced correctly in Employee Works To-Dos. You can open a JA task of a supported type from To-Dos, which opens the corresponding task record page, and complete it within Employee Works.

## Supported task types

The following JA task type is confirmed converted to a Lit-based component and supported in Employee Works:

-   Complete a general to-do
-   Schedule a meeting
-   Submit a catalog request

## Access and behavior

-   Employees, managers, and other assignees can open and complete tasks from the Journey Details page or Inbox To-Dos.
-   Managers can open tasks assigned to other assignees that they have access to, from the Journey Details page.
-   Existing role, visibility, and access control rules are respected.
