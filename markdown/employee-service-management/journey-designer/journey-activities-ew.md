# View journey activity and add comments in Employee Works

View the chronological activity history for a journey or lifecycle event case, and add comments, from the Activities tab on the Journey Details page in Employee Works.

## Before you begin

Role required: sn\_jny.manager

## About this task

The Journey Details page includes an Activities tab, shown for both journey records and standalone lifecycle event cases.

## Procedure

1.  Open a journey or standalone lifecycle event case, and select the **Activities** tab.

    Activities display in chronological order and include both system-generated and user-generated entries, such as the activity description, timestamp, and the actor where applicable.

2.  To add a comment, use the comment entry field on the tab.


## Result

The activity timeline updates after relevant journey or lifecycle event actions. When no activities are available, an empty state is shown.
