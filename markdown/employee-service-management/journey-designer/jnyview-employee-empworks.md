# Journey view for employees in EmployeeWorks Web App

As an employee, you can view your journeys and complete associated tasks from EmployeeWorks Web App.

## Journeys Widget

The Journeys widget on the EmployeeWorks Web App homepage allows you to view your top three active journeys. For more information, see [Use the Journeys widget on the EmployeeWorks Web App home page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/use-journey-home-widget-ew.md).

\[Omitted image "jnywidget-emp-ew.png"\] Alt text: Journeys widget on the homepage with top three active journeys and their status

## Journeys list page

The Journeys List page allows you to review the list of all journeys and lifecycle events that you are authorized to access in one consolidated list. You can view key journey information, such as the type, stage, status, progress, and remaining tasks. In this page you can identify the journeys that are on track or overdue.

You can select a journey card to open its **Journey Details** page. For more information, see [View journeys and lifecycle events from Journeys List page](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/use-journey-list-page-ew.md).

\[Omitted image "jny-list-emp.png"\] Alt text: Journeys list page with the list of journeys and lifecycle events

## Journeys details page

The journeys details page allows you

-   View employee specific task completion progress
-   View upcoming tasks
-   Identify overdue or due soon tasks across stages
-   Add comments and attachments

For more information, see [View journey stages and details in EmployeeWorks Web App](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/view-journey-details-ew.md).
