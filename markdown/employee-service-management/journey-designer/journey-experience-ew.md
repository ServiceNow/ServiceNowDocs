# Journeys in EmployeeWorks Web App

Employee Journeys in EmployeeWorks Web App brings journeys and lifecycle events together in one unified experience powered by ServiceNow's AI-native employee experience platform.

EmployeeWorks Web App provides a unified experience for employees. Employees and managers can view, navigate, and complete their journeys and lifecycle events directly from EmployeeWorks Web App. To use this capability install **Employee Journeys for EmployeeWorks and Employee Slate** plugin. For more information, see [Install Employee Journeys for EmployeeWorks and Employee Slate](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/ejm-install-employeework.md) and [Fix Restricted Caller Access \(RCA\) approval requests](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/journey-designer/jny-manual-rca-fix.md).

## Key capabilities

As an employee, you can:

-   View and access top active journeys from the **Journey widget** in the EmployeeWorks homepage.
-   Access all journeys and lifecycle events from a unified list from the **Journey List** page.
-   View journey specific details such as progress, status, task completion by stage from the **Journey Details** page.
-   View and complete the assigned tasks from the **Tasks and Request** section or from **Journey Details** page.

As a manager, you can:

-   View and access top active employee journeys you have access to from the **Journey widget** in the EmployeeWorks home page.
-   View which of your team's journeys need attention from the **Journey List** page.
-   View journey-specific details such as overall journey progress for the team journeys from the **Journey Details page**.
-   View and complete the assigned tasks from the **Tasks and Request** section or from **Journey Details** page.

## Lifecycle events and journeys

EmployeeWorks Web App provides a unified end-user experience for journeys and lifecycle event cases. Both appear through the same Journey experiences, including the Journeys widget, Journey List page, and Journey Details page.
