# Journeys in EmployeeWorks Web App

Employee Journey Management \(EJM\) brings journeys and lifecycle events into EmployeeWorks Web App Base, ServiceNow's conversational employee experience platform, so employees and managers can view, navigate, and complete journeys without leaving EmployeeWorks Web App Base.

## Journeys in Employee Works

As EmployeeWorks Web App Base becomes the primary employee experience layer, Journeys for EmployeeWorks Web App Base capability lets employees and managers view, navigate, and complete their journeys and lifecycle events entirely within EmployeeWorks Web App Base.

## Conversation-first experience

The homepage features a prominent AI-powered chat and search bar. Employees can interact with the chat in natural language. When employees submit the initial query, it expands into a full-page conversation view powered by ServiceNow Otto or Now Assist, capable of answering questions, submitting requests, and surfacing relevant content.

## Key capabilities

As an employee \(new hires\), use journeys forEmployeeWorks Web App Base to:

-   View what requires your attention for a given day or week.
-   See what an agent has already done on your behalf for tasks that require attention.
-   Review agent recommendations and completing the remaining portion of a task conversationally.
-   View notifications, reminders, and nudges related to your journey.
-   View specific journey details, such as stages and tasks, in response to a conversational question \(for example, "what does my 90-day onboarding look like?"\).

As a manager, use Journeys for EmployeeWorks Web App Baseto:

-   View which of your team's journeys need attention.
-   View why a journey needs attention and what the agent recommends to bring it back on track.
-   Review AI recommendations and modifying or adding tasks to a journey conversationally.
-   View specific journey details for their team's journeys.

## Lifecycle events and journeys

EmployeeWorks Web App Base presents lifecycle event cases alongside journey records using the same widgets and card layout, so that employees and managers see a unified list regardless of which fulfillment type an HR service uses.
