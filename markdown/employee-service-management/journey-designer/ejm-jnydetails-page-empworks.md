# Journey details in EmployeeWorks Web App

The Journey Details page provides a consolidated view of the journey, including its current status, progress, stages, and tasks. The information displayed depends on whether you access the journey as an employee or a manager.

You must have access to the associated journey or lifecycle event. The information and activities available on the Journey Details page depend on your role and access permissions.

The Journey details page can be accessed from the Journeys Widget in the EmployeeWorks Web App home page, Journey List page, or an associated task details page.

The Journey Details page contains the following sections:

-   **Header:** Displays the journey overview information, status, and progress.
-   **Up Next:** Displays tasks associated with the journey that require attention.
-   **Overview:** Displays the journey stages and the tasks associated with each stage.
-   **Activities:** Displays journey-related updates and allows users to add comments or updates.
-   **Attachments:** Displays attachments associated with the journey and allows users to add files.
