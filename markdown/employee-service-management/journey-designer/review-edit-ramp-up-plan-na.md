# Review and edit onboarding ramp-up plans using ServiceNow Otto

Review and edit AI-generated onboarding ramp-up plans using Now Assist in Virtual Agent. After approval, the plan is added to the new employee's onboarding journey.Managers working for organizations using the Generate onboarding ramp-up plan agentic workflow can use ServiceNow Otto to review and edit personalized onboarding plans generated by a team of AI agents. Once the manager approves a plan that they reviewed, the corresponding plan is added to the new employee's onboarding journey.

## Before you begin

The ServiceNow Otto for HR Service Delivery \(HRSD\) \(sn\_hr\_gen\_ai\) plugin must be activated.

The Generate onboarding ramp-up plan agentic workflow must be activated and implemented into your organization's case or journey creation process.

The configuration tasks in the following topics must be completed:

-   [Set Onboarding ramp up trigger to use Employee Center portal](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/journey-designer/set-trigger-emp-center.md).
-   [Activate Onboarding ramp-up trigger](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/journey-designer/activate-trigger-rampup.md)
-   [Activate the associated AI skills](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/journey-designer/turn-on-nowassist-skills.md)
-   
-   [Add Employee Center to Now Assist in Virtual Agent](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/employee-service-management/journey-designer/enable-na-va-ec.md)

To trigger this agentic workflow, the **Trigger onboarding rampup agent** scheduled job runs nightly to search for Journey records associated with a new employee's onboarding journey. This scheduled job targets Journey records for new employees who are starting their onboarding journey within five days. Specifically, this scheduled job selects the **Initiate onboarding ai** check box in the Journey record to initiate the agentic workflow when the following conditions are true:

-   The **State** field in the Journey record is set to **Ready**.
-   The **Journey accelerator plan type** field in the corresponding Journey Configuration record is set to **Agentic AI Onboarding Plan Type**.
-   The **Type** field in the corresponding Journey Configuration record is set to **Blank** or **Onboarding**.
-   The **Employment start date** in the employee's HR profile is within the specified number of days from the current date. The **sn\_jny.agent\_conversation\_head\_start\_days** property controls this timeframe. The default is five days.
-   The date in the **Employment start date** field in the HR profile record of the onboarding employee is equal to or greater than the system date by up to the number of days specified in the **sn\_jny.agent\_conversation\_head\_start\_days** property. The default number of days specified in the **sn\_jny.agent\_conversation\_head\_start\_days** property is five.

Role required: manager

## About this task

A manager receives a notification from ServiceNow Otto after they access the Employee Center. The manager is prompted to review the ramp-up plan for a new employee who is onboarding in five days.

## Procedure

1.  Navigate to **All** &gt; **Self-Service** &gt; **Employee Center**.

    A notification from ServiceNow Otto appears.

2.  Select the ServiceNow Otto icon.

    ServiceNow Otto outputs a message that includes the following information:

    -   Name of the new employee
    -   Their start date
    -   The stages and tasks it generated to help the employee ramp up for their role
    -   A link to a draft of the onboarding plan
3.  Select the link provided by ServiceNow Otto to view the onboarding plan.

    The Journey details page appears with the stages created by the AI agent.

4.  Converse with ServiceNow Otto to convey the changes you want made to the ramp-up plan.

## What to do next

You must publish the stages in the ramp-up plan that were added to the employee's onboarding journey. After you publish the stages that were added, the employee can view and complete the courses and tasks nested in the added stages.
