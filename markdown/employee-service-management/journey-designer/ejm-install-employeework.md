# Install Employee Journeys for EmployeeWorks and Employee Slate

Install the Employee Journeys for EmployeeWorks and Employee Slate version 1 application to enable employees and managers to view, navigate, and complete journeys in EmployeeWorks.

## Before you begin

**Note:** You must upgrade to Australia before you can install Employee Journeys for EmployeeWorks and Employee Slate application.

Dependent plugins and apps for Employee Journeys for EmployeeWorks and Employee Slate:

-   Case and Knowledge Management for EmployeeWorks and Employee Slate 1.5.0 \[app-hr-aiux\]
-   Journey designer 7.7.0 \[app-journey-designer\]
-   AI Experience Framework Components 1.5.0 \[ai-experience-components\]

Role required: admin.

## About this task

Employee Journeys for EmployeeWorks and Employee Slate must be installed as a store application.

## Procedure

1.  Go to the ServiceNow Store and find the Employee Journeys for EmployeeWorks and Employee Slate application using the filter criteria and search bar.

    In the list next to the **Install** button, the versions that are available to you are displayed.

2.  Select a version from the list and select **Install**.

    In the Review Installation Details dialog box, any dependencies installed with your application are listed.

3.  If you're prompted, follow the links to the ServiceNow Store to get any additional entitlements for dependencies.

4.  If demo data is available and you want to install it, select the **Load demo data** check box.

    Demo data comprises sample records that describe application features for common use cases. Load demo data when you first install the application on a development or test instance.

    **Note:** Any demo data related to dependent applications must be updated when Journey designer is updated.

5.  Select **Install**.
