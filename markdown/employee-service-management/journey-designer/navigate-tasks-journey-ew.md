# Navigate from a task to its journey in Employee Works

Open the journey or lifecycle event details behind a task directly from that task in Employee Works.

## Before you begin

Role required: sn\_jny.manager

You must have permission to view the associated journey or lifecycle event.

## About this task

Tasks linked to a journey or a standalone lifecycle event case in Employee Works open in the Journey Details experience, rather than in Employee Center.

## Procedure

1.  Open a task associated with a journey or a standalone lifecycle event case.

2.  Select the journey or parent-record link.

    If the task is linked to a journey, the corresponding Journey Details page opens in Employee Works. If the task is linked to a standalone lifecycle event case, the corresponding record opens using the Journey Details experience. The page loads with the view appropriate to your relationship to the record \(for example, journey owner, manager, or subject person\).

3.  Select **Back** to return to the page you navigated from.

    **Note:** If you don't have permission to view the associated journey or lifecycle event, Employee Works shows the applicable No Access state instead, without exposing any journey or lifecycle event information you're not authorized to view.
