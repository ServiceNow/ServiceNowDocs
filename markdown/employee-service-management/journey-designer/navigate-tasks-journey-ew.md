# Navigate from a task to its journey in EmployeeWorks Web App

Open the journey details page directly from the **Task details** page in EmployeeWorks Web App.

## Before you begin

Role required: sn\_jny.manager

You must have permission to view the associated journey or lifecycle event.

## Procedure

1.  Open a task associated with a journey or a standalone lifecycle event case from the **Tasks and Requests** section on the home page or the **Journey Details** page.

2.  Select the journey or parent-record link.

    If the task is linked to a journey, the corresponding Journey Details page opens in EmployeeWorks Web App. If the task is linked to a standalone lifecycle event case, the corresponding record opens using the Journey Details experience. The page loads with the view appropriate to your relationship to the record \(for example, journey owner, manager, or subject person\).

3.  Select **Back** to return to the page you navigated from.

    **Note:** If you don't have permission to view the associated journey, EmployeeWorks Web App shows the applicable **No Access** state instead, without exposing any journey information you're not authorized to view.
