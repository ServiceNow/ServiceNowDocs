# ServiceNow EmployeeWorks Web App Mobile Experience

Manage your tasks and requests on the go using the ServiceNowEmployeeWorks Web App experience in your Now Mobile®.

EmployeeWorks in Now Mobile® brings your tasks, requests, search, and knowledge into one place. Check open work between meetings, follow up on requests, and find answers quickly without the need of a desktop.

Using ServiceNow EmployeeWorks Web App on Now Mobile®, you can:

-   Submit and track your requests.
-   View and complete your tasks.
-   Search for services.
-   Find knowledge articles.

\[Omitted image "mobile-exp-nowmobile.png"\] Alt text: Now Mobile homepage with EmployeeWorks

For more information, refer to [Using EmployeeWorks EmployeeWorks Web App in Now Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/use-employeeworks-in-now-mobile.md).

As an admin, configure the Mobile experience depending on the ServiceNow EmployeeWorks Web App version that you're using, set up your mobile experience as follows:

|ServiceNow EmployeeWorks Web App version|Mobile Experience Setup|
|----------------------------------------|-----------------------|
|Brazil Patch 00 &amp; 01, Australia Patch 7 &amp; previous, Zurich Patch 13 &amp; previous|Set up your mobile experience manually. For more information, refer to [Set up Mobile experience manually for ServiceNow EmployeeWorks Web App](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/set-up-mobile-experience-manually-for-servicenow-employeeworks.md).|
|Brazil Patch 02, Australia Patch 8 and later|The Mobile experience is available with the application. As an admin, you must enable the Mobile experience and configure further to use it in Now Mobile®. To configure, refer to [Configure mobile experience for ServiceNowEmployeeWorks Web App](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/configure-mobile-experience-of-employeeworks.md).|
