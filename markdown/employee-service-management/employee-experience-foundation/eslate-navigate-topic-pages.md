# Use topic pages in Employee Slate

Use topic pages to discover content, access subtopics, and find relevant knowledge articles and catalog items through the browse experience.

## Before you begin

The browse experience must be configured with a taxonomy.

Role required: Employee

## About this task

Topic pages provide organized access to content within specific categories. You can navigate through the topic hierarchy, access quick links, and discover relevant knowledge articles and catalog items.

**Note:** The explore button appears in the Employee Slate interface when a taxonomy is configured.

## Procedure

1.  Access the browse experience by clicking the **Explore** button.

    A flyout panel opens displaying all root topics.

    \[Omitted image "es-explore-menu.png"\] Alt text: Explore flyout panel listing root topics such as Legal, Technology services, and Human Resources, with quick action buttons.

2.  Select a topic from the flyout panel or click **See more in Explore**.

    -   Select a specific root topic to navigate directly to its topic page
    -   Select **See more in Explore** to view the complete topic catalog
    You navigate to either a specific topic page or the topic catalog page.

    \[Omitted image "es-topic-page-employee.png"\] Alt text: Explore landing page with Browse by Department cards for Travel and Expense, Legal, Technology services, and other topics.

    **Note:** On the topic catalog page, each root topic shows together with its subtopics in a single card. When a root topic has more subtopics than fit the card, a **+N** control shows the remaining count. Select it to see the remaining subtopics in a list.

3.  On a topic page, review the available content sections.

    Each topic page contains a header with the topic name and description, followed by content widgets.

    **Note:** When a topic has no content configured, the page shows an empty state.

    1.  Check the subtopics widget for child topics.

        Select any subtopic to navigate to its dedicated topic page.

    2.  Review quick links for frequently accessed resources.

        External links are identified by specific icons.

    3.  Explore the Support resource widget for related content.

        This widget combines knowledge articles and catalog items associated with the topic.

    4.  Browse the featured content section.

        Select any featured item to open its detail page.

    5.  Browse the featured application section.

        Select the application.

    6.  Select a prompt in the Topic Assist widget, when present, to start a conversation with the assistant.

        The Topic Assist widget shows up to five preconfigured prompts for the topic and appears only when the experience chat type is Moveworks.

4.  Use the sorting and filtering options in the Support resource widget.

    -   Select **A-Z** to sort content alphabetically
    -   Filter by **Articles** to show only knowledge articles
    -   Filter by **Request** to show only catalog items
    -   Select **All** to display all content types
    The default sorting is by popularity to surface the most relevant content first.

5.  Select and navigate to the specific knowledge article detail page or catalog item page.


## Result

You can efficiently discover and access relevant content through the organized topic structure, making use of the hierarchical navigation and content filtering capabilities.
