## Using guided setup to implement EmployeeWorks Web App

Guided setup provides a sequence of tasks that help you configure EmployeeWorks Web App on your ServiceNow instance. To open guided setup for EmployeeWorks Web App, navigate to **Product Hub** from an existing ServiceNow instance or a provisioned Moveworks instance.

EmployeeWorks Web App supports two deployment paths: one with Moveworks and one with Now Assist. The deployment path determines which configuration tasks apply.
