# Access Explore menu items

Activate the AIX menu item to make Explore section menu items visible on topic pages in EmployeeWorks Web App.

## Before you begin

Role required: aix\_exp\_admin

## Procedure

1.  Navigate to **All** &gt; **AI Experience Framework \(AIUX\)** &gt; **Menus**.

2.  Select **Employee Menu** from the AIX Menus list.

3.  In the Employee Menu record, go to the related list and select **Explore**.

4.  Select the **Active** check box to mark the record active.

5.  Change the value in the **Order** field to modify the priority order of this menu item.


## Result

You can view all menu items on a topic page in the Explore section.

**Note:** In a responsive view, the page view can differ in the following ways:

-   If real estate is limited, selecting **Explore** automatically opens the Explore page, without the left navigation fly-out available on desktop.
-   If real estate is limited, the Explore page shows only the department headers or the top-tier topic pages along with the department header, depending on the screen size.
