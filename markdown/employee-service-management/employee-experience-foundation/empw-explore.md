# Explore EmployeeWorks Web App

Learn about ServiceNow EmployeeWorks Web App, the users it serves, and its benefits.

## EmployeeWorks Web App overview

ServiceNow EmployeeWorks Web App is an AI-native employee engagement layer. It combines intelligent assistance, task management, employee communications, and organizational navigation to support daily work from one interface.

## EmployeeWorks Web App users

|User|Description|
|----|-----------|
|Administrator|Installs plugins, configures branding and data sources, builds custom widgets, and monitors adoption through analytics.|
|Employee|Submits requests, tracks tasks and approvals, searches knowledge, and manages their profile and calendar from one interface.|
|Content manager|Authors and targets announcements with AI assistance, publishes across channels, and measures engagement.|

## EmployeeWorks Web App workflow

Administrators set up the portal and connect the conversational assistant. Employees interact with the AI assistant to complete daily tasks, find information, and manage work items.
