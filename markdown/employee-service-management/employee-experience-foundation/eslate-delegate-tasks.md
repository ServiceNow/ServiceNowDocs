# Delegate tasks and approvals

Delegate a task or approval to one or more employees for a specific time period.

## Before you begin

Role required: Employee

## About this task

Delegation uses the same back-end functionality as the delegation support in Employee Center. You can add multiple delegates to a task or approval. Any delegate can act on the item, and the item then closes for the assignee and every delegate.

## Procedure

1.  Open a task or approval from **Tasks and requests**.

2.  In the delegates section of the task detail, add a delegate.

3.  Select an employee and set the delegation end date.

    The delegate appears in the delegates section. The item also appears in the tasks and requests view of the delegate. A note shows who delegated it.

    **Note:** The delegation end date is required.

4.  When there are more than five delegates, select the additional-count indicator to view the complete list.

    A dialog box lists every delegate for the item.

5.  To change a delegation end date, select the edit option next to a delegate and update the date.

6.  To remove a delegate, select the delete option next to the delegate.


## Result

The task or approval remains visible to the original assignee. The assignee can also act on it or manage the delegates.

When the assignee or any delegate completes the item, the system removes it from the view of every delegate.
