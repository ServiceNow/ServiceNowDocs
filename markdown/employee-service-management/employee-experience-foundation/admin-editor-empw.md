# Admin editor in EmployeeWorks Web App

Starting from EmployeeWorks Web App 1.1.14, Admin editor replaces instance options for customizing portal pages. When you customize a header or widget, you're prompted to add translated versions to support multiple languages.

Admin editor is an in-portal editing mode that lets administrators customize the **Explore** page header and topic page widgets directly, without navigating to separate instance option records.

Starting from EmployeeWorks Web App 1.1.14, Admin editor replaces the widget instance options approach. Changes you make in Admin editor take effect immediately on the portal page.

## Translation support

When you customize a header or widget on a portal page, EmployeeWorks Web App prompts you to add translated versions of the text. This confirms that customized labels and headings are available to employees in their preferred language.

## What you can customize

Using Admin editor, you can customize the following areas.

-   **Explore page**

    Page heading text, welcome label, hero title, and subtitle displayed on the **Explore** page.

-   **Topic page**

    Visibility of the topic description on individual topic pages.

-   **Widget head**

    Title and label text displayed in the header area of individual widgets on topic pages.
