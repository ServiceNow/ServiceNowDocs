# Customize the Explore header

Customize the heading, welcome label, title, and subtitle displayed on the **Explore** page using Admin editor in EmployeeWorks Web App.

## Before you begin

Role required: admin

## About this task

The Explore Hero widget controls the text displayed at the top of the **Explore** page. Use Admin editor to open the widget configuration panel and update the fields directly on the page. When you enter custom text, you're prompted to add translated versions.

## Procedure

1.  Navigate to **EmployeeWorks Web App** &gt; **Explore** as an admin.

2.  Select **Admin editor** to enter edit mode.

    The page displays edit icons on each widget.

3.  Select the edit icon on the Explore Hero widget to open its configuration panel.

    The explore-hero panel opens on the right side of the page.

4.  In the explore-hero panel, fill in the fields.

    |Field|Description|
    |-----|-----------|
    |**Page heading text**|Text displayed as the page heading. This field is automatically set to `Explore`.|
    |**Show page heading**|Selected by default. When cleared, the page heading is hidden.|
    |**Welcome label text**|Text displayed as the welcome label before the title. This field is automatically set to `Welcome`.|
    |**Title text**|Main title text displayed in the hero section. This field is automatically set to `Where Would You Like to Start?`.|
    |**Subtitle text**|Subtitle text displayed following the title.|

5.  Select **Reset** next to Reset widget to revert the widget to its default configuration.

6.  Select **Save** to apply your changes.


## Result

The **Explore** page displays the updated heading, welcome label, title, and subtitle for all employees.

**Note:** When you enter custom text in any field, add the corresponding translated versions when prompted to confirm the text appears correctly for employees in all supported languages.
