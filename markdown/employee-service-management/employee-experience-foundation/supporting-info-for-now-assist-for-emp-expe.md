# Supporting information for ServiceNow Otto for Employee Experience

Get a quick overview of the key information related to the ServiceNow Otto for Employee Experience.

## Supported versions

ServiceNow Otto for Employee Experience is supported starting from Xanadu Patch 3 and later versions.

## Supported user interfaces

The ServiceNow Otto for Employee Experience application supports the following user interfaces:

-   ServiceNow Otto® chat bot in any service portal
-   ServiceNow Otto for Virtual Agent interfaces

## Application information

Activate the ServiceNow Otto for Employee Experience store app \(sn\_ex\_gen\_ai\).

This store app has the following dependencies:

-   ServiceNow Otto® for platform \(sn\_genai\_platform\)
-   Employee Center \(sn\_ex\_sp\)

For more information, see [Configure ServiceNow Otto for Employee Experience](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/employee-service-management/employee-experience-foundation/configure-nowassist-emp-exp.md).
