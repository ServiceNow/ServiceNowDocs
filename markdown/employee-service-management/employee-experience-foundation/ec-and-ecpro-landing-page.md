# EmployeeWorks

ServiceNow EmployeeWorks Web App is the AI-first portal that brings employee search, requests, tasks, knowledge, and communications into one destination. Employees describe what they need in plain language and complete the work in the same panel.

## Give every employee the AI-first interface

ServiceNow EmployeeWorks Web App provides employees a plain language conversational interface for their employee portal.

The AI assistant reads the intent, runs the action, and returns the answer in the same panel. Search, requests, tasks, knowledge, and communications sit in one destination, so employees stop moving between tools to finish one piece of work.

EmployeeWorks Web App Extended adds the communications layer on top. Communicators target announcements by location, department, or role. They draft conversationally with Moveworks, publish to the portal and mobile, then track impressions and click-through rates.

EmployeeWorks Web App Extended is an add-on application. It requires either EmployeeWorks Web App or Employee Slate \(built for Now Assist\).

The home page leads with an AI-powered chat and search bar. When an employee starts typing, the bar expands into a full-page conversation. The assistant stays available on the Home, the inbox, the Canvas, and the Org Chart, and keeps the active conversation across pages. A split view opens catalog forms, knowledge articles, tasks, and canvas pages next to the chat, so employees review and act without leaving the conversation. Full-page search ranks results from the catalog, knowledge, people, and connected tools in one list.

The home page layout adapts to each employee's role, department, and usage, and EmployeeWorks Web App serves everyday employees, content managers, and administrators from the same experience. For more information, see [ServiceNow EmployeeWorks Web App](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/employee-slate-landing-page.md).

## Act across connected systems with Moveworks

When your organization runs EmployeeWorks Web App with Moveworks, the AI assistant plans the work and carries it out. It builds an ordered set of steps, runs each one against the right system of record, evaluates the result, and adjusts the plan when something changes. For any change to sensitive data, the assistant summarizes the intended change and waits for confirmation.

Enterprise Search covers content in SharePoint, OneDrive, Google Drive, Slack, and Outlook, with up to 100 million documents per system. World Knowledge pairs AI reasoning with web search for questions that sit outside your knowledge base. Specialized assistants appear in the left panel with ready prompts and connected tools for a type of work. For more information, see [Moveworks capabilities](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/empworks-moveworks-capabilities.md).

## Run the AI experience on Now Assist

Employee Slate \(built for Now Assist\) is the option when EmployeeWorks Web App isn't available to you.

It combines the AI assistant with the conversation-first home page. It also provides the conversational catalog, the AI widget builder, and conversational authoring for announcements. Employees find a catalog item by describing a need, ask policy questions and get answers with citations, and view the organization chart and employee profiles from the same conversation. Intelligent recommendations run across knowledge, catalog, and tasks.

Automated form completion, predictive text, and smart replies cut data entry. Proactive notifications group updates in the bell tray, and employees continue the same conversation on a mobile browser. For more information, see [Employee Slate \(built for Now Assist\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/employee-slate-nowassist.md).

## Engage employees with Employee Center Pro

Employee Center Pro is the subscription application that extends the standard Employee Center portal beyond service delivery. It adds content creation, multi-stage and multi-channel content delivery, campaigns, employee communities, enterprise search, and portal analytics. Communicators author and schedule content, then measure engagement and refine the next message. Employee Center Pro requires additional licensing.

You can bring an AI assistant to this portal before you set up EmployeeWorks Web App. Moveworks for Employee Center, built on Moveworks and formerly known as Moveworks for Employee Center, embeds a conversational assistant in Employee Center and Employee Center Pro. Employees ask questions in their own words, get answers from your knowledge base and catalogs, and complete actions such as checking a ticket status or updating a request. For more information, see [Moveworks for Employee Center](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/moveworks-for-employeecenter.md).
