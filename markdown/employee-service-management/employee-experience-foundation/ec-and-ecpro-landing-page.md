# EmployeeWorks

ServiceNow EmployeeWorks Web App is the AI-first portal that brings employee search, requests, tasks, knowledge, and communications in one place. Employees describe what they need in plain language and complete the work in the same panel.

## Give every employee the conversational interface

ServiceNow EmployeeWorks Web App provides employees a plain language, conversational interface for their employee portal.

The AI assistant renders the intent, runs the action, and returns the answer in the same panel. Search, requests, tasks, knowledge, and communications sit in one destination, so employees stop moving between tools to finish one piece of work.

EmployeeWorks Web App Extended adds the communications layer on top. Communicators target announcements by location, department, or role. They draft conversationally with Moveworks, publish to the portal and mobile, then track impressions as portal analytics.

EmployeeWorks Web App Extended is an add-on application. It requires either EmployeeWorks Web App or the Employee Slate \(built for Now Assist\) application.

The home page leads with an AI-assistant chat and search bar. When an employee starts typing, the bar expands into a full-page conversation. The assistant stays available on the Home, the inbox, the Canvas, and the Org Chart, and keeps the active conversation across pages.

A split view opens catalog forms, Knowledge Base articles, tasks, and Canvas pages next to the chat, so employees can review and act without leaving the conversation. Full-page search ranks results from the Service Catalog, Knowledge, people, and connected tools in one list.

The home page layout adapts to each employee's role, department, and usage. EmployeeWorks Web App is equipped to serve employees, content managers, and administrators from the same experience.

For more information, see [ServiceNow EmployeeWorks Web App](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/employee-slate-landing-page.md).

## Act across connected systems with Moveworks

When your organization runs the EmployeeWorks Web App with Moveworks, the AI-assistant plans the work and carries it out. It builds an ordered set of steps, runs each one against the right system of record, evaluates the result, and adjusts the plan when something changes. For any change to sensitive data, the assistant summarizes the intended change and waits for confirmation.

Enterprise Search covers content in Microsoft SharePoint, Microsoft OneDrive, Google Drive, Slack, and Microsoft Outlook, with up to 100 million documents per system. World Knowledge pairs AI reasoning with web search for questions that sit outside your knowledge base. Specialized assistants appear in the left panel with ready prompts and connected tools for a type of work.

For more information, see [Moveworks capabilities](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/empworks-moveworks-capabilities.md).
