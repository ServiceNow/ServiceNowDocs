# Use EmployeeWorks Web App

Complete daily work tasks using EmployeeWorks Web App capabilities, including the conversational assistant, tasks and requests, canvas, notifications, and employee communications.

## Overview of EmployeeWorks Web App capabilities

Access all your essential work tools from one interface. Use the conversational assistant to ask questions and take actions, or navigate directly to the capability you need.

1.  [Manage tasks and approvals](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/eslate-work-with-inbox.md)

    View and manage tasks, approvals, and requests from across systems.

2.  [Create a catalog request from chat](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/eslate-submit-catalog-request.md)

    Submit service catalog requests through the conversational catalog without leaving the chat.

3.  [Use topic pages](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/eslate-navigate-topic-pages.md)

    Browse topic pages to find knowledge, policies, and services organized by subject.

4.  [Manage employee profiles](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/emp-slate-view-edit-profile.md)

    View and update your employee profile, including contact information and preferences.

5.  [Manage your calendar with the Calendar Management assistant](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/eslate-use-calendar-assistant.md)

    View your schedule and manage meetings using the calendar assistant.


-   [Create announcements](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown)

    Draft and publish announcements for employees using conversational AI assistance.

-   [Configure email notifications from the admin console](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/eslate-manage-notifications-console.md)

    View and manage notifications from the notifications console.

-   [Create a widget with the AI-powered Widget Builder](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/eslate-create-widget.md)

    Build custom canvas widgets using the AI widget builder.


## Conversational assistant

The conversational assistant is available from every page in EmployeeWorks Web App. Use natural language to ask questions, submit requests, and take actions without navigating away from your current context. For example prompts, see [EmployeeWorks Web App prompt library](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/employee-service-management/employee-experience-foundation/employee-slate-prompt-library.md).
