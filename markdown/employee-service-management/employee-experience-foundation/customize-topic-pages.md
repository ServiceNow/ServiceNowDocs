# Customize topic pages

Customize the display of topic descriptions on topic pages using Admin editor in EmployeeWorks Web App.

## Before you begin

Role required: admin

## About this task

The topic header widget controls what appears at the top of each topic page. Use Admin editor to open the widget configuration panel on any topic page and update the settings directly. When you enter custom text, you're prompted to add translated versions.

## Procedure

1.  Navigate to **EmployeeWorks Web App** &gt; **Explore** as an admin, then select a topic page.

2.  Select **Admin editor** to enter edit mode.

    The page displays edit icons on each widget.

3.  Select the edit icon on the topic header widget to open its configuration panel.

    The topic-header panel opens on the right side of the page.

4.  In the topic-header panel, fill in the fields.

    |Field|Description|
    |-----|-----------|
    |**Show description**|Selected by default. When cleared, the topic description is hidden on the topic page.|

5.  Select **Reset** next to Reset widget to revert the widget to its default configuration.

6.  Select **Save** to apply your changes.


## Result

The topic page shows or hides the topic description based on your configuration.

**Note:** Changes apply to the topic page you configured. Repeat these steps for each topic page you want to customize.
