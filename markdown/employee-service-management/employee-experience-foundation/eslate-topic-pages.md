# Browse and topic pages

Topic pages organize content for specific categories. Each page includes subtopics, applications, quick links, knowledge articles, and catalog items.

Each topic page contains multiple widgets that organize and present content related to specific categories or subjects.

## Topic page overview

Based on admin configuration, you can access the following components on topic pages.

\[Omitted image "es-ask-otto-emp.png"\] Alt text: Browse experience with topic pages, support resource cards, and the Ask Otto panel showing four suggested conversation prompts.

Access topic pages through the side navigation or by selecting **Explore** to browse the full taxonomy.

-   **Header section**

    Topic name and description.

-   **Subtopics widget**

    Direct child topics for navigating deeper into the hierarchy.

-   **Quick links widget**

    Frequently accessed links. External links are identified by icons.

-   **Support resource widget**

    Knowledge articles and catalog items with filtering options. Displays an empty state when no content is configured.

-   **Topic Assist widget \(Ask Otto\)**

    Preconfigured chat prompts that enable employees to start a conversation with the assistant. Appears only when the experience chat type is Moveworks.

-   **Topic page templates**

    Default layout that administrators can override for an individual topic and extend to child topics.


Topic pages adapt to screen size and display subtopics responsively.
