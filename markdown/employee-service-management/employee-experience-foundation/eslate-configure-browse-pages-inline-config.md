# Edit widgets inline

Use inline admin edits to customize the Explore page and topic pages directly, without configuring widget instance options separately.

## Before you begin

Role required: admin.

## About this task

Select **Admin editor** to enter edit mode, then select the edit icon on a widget to open its configuration panel.

## Procedure

1.  Go to the page \(such as **Explore**\) or a topic page as an admin.

2.  Select **EmployeeWorks Web App****Admin editor** in the bottom-right corner to enter edit mode.

3.  Select the edit icon on a widget to open its configuration panel.

    Each widget on the page has its own edit icon.

    \[Omitted image "image.es-topic-page-inline-config"\] Alt text: Topic page showing edit controls on the banner, support resources, and topic assist widgets

4.  On the **Explore Hero** panel, update the fields as needed.

5.  On a topic page, use a widget edit icon to show or hide its description, or to limit the number of quick links shown.

6.  Select **Reset widget** to revert a widget to its default configuration.

7.  Close the panel to apply your changes.


## Result

Employees see the customized headings, descriptions, and widget options on the Explore page and topic pages you configured.

**Note:** If you enter new custom text in a field, add the corresponding translation using the existing string tables.
