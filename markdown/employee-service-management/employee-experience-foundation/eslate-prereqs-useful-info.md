# Before you start with EmployeeWorks Web App

Verify the prerequisites, plugins, roles, licenses, and assets that EmployeeWorks Web App requires.

EmployeeWorks Web App has distinct prerequisites for the administrator who configures the deployment and for the employee who uses it. Review the lists that apply to your role before you begin.

## Administrator prerequisites

Before you install and configure EmployeeWorks Web App, verify the following prerequisites:

-   The ServiceNow instance runs a platform version with the EmployeeWorks Web App release.
-   Verify that you have the administrator role or an equivalent role.
-   Determine the deployment path with EmployeeWorks Web App or Employee Slate \(built for Now Assist\). Verify that you have all the entitlements.
-   Verify that the EmployeeWorks Web App plugin for your deployment is available.
-   Install the EmployeeWorks Web App Extended plugin if your deployment requires the advanced experience.
-   Verify that you have tools and licenses to build widgets with the AI-powered Widget Builder.
-   Keep the branding assets such as logo file, favicon, primary color hex code, accent color hex code, and a URL suffix ready.
-   Verify that you configure the AI-driven capabilities — AI summaries, prioritization, conversational filters, and chat-driven actions — Moveworks or Now Assist.

## Employee prerequisites

Before you use EmployeeWorks Web App, verify the following prerequisites:

-   You can log in to EmployeeWorks Web App with your ServiceNow identity.
-   You use a supported desktop browser or a mobile browser.
-   Use the admin configured AI-driven capabilities — AI summaries, prioritization, conversational filters, and chat-driven actions — Moveworks or Now Assist that are active on the instance.

## Content and communications prerequisites

If your team publishes content or announcements in EmployeeWorks Web App, verify the following prerequisites:

-   Verify that you have the content manager or content administrator role required to create and publish announcements.
-   Associate knowledge articles and catalog items that are published and accessible.
-   Populate the holiday calendar table for the work locations that your Upcoming Holiday widget targets.
