# Review applied consequences

Check the action that was applied because of a violation and whether the action repeats.

## Before you begin

Role required: sn\_st\_mgmt.test\_viewer

## About this task

An applied consequence is an action that was applied because of a threshold rule violation. It is created from a measure consequence that an administrator defined for the threshold rule. See [Define measure consequences for the threshold rules](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/define-threshold-consequences-spm.md).

## Procedure

1.  Navigate to **All** &gt; **Service Test Management** &gt; **Test Runs** &gt; **All**.

2.  Open the test run.

3.  In the Test Measures related list, select the test measure that you want to see the violations.

4.  In the Threshold Rule Violations related list, select the violation that you want to open.

5.  In the Applied Consequences related list, select the applied consequence that you want to open.

6.  Review the applied action and the repeat action option.

7.  Check the measure consequence that the applied consequence came from.


## Result

Diagnostic tasks and resolution tasks help your teams investigate and fix the underlying problem. They're described in the Customer Service Problem Management documentation. See [Related Customer Service Problem Management information](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/stm-related-cspm-information.md).
