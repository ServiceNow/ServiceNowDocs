# Retiring and archiving specifications

When a published specification or product offering is no longer being used, you can retire it. A retired version stays in the operational tables, but you can't use it in a product offering or create specification versions from it. To remove a retired version from the operational tables, archive it. Archiving doesn't permanently delete the version.
