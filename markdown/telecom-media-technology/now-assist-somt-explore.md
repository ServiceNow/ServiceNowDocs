# Exploring ServiceNow Otto for Sales Customer Relationship Management for Telecommunications

With the ServiceNow Otto for Sales CRM for Telecommunications application, you can use standalone AI agents to create a customer move order capture journey and create enrichment tasks. You can also identify the tasks required for domain orders by using historical data from similar orders.
