# Related Customer Service Problem Management information

Find the Service Test Management features that are described in the Customer Service Problem Management documentation.

Customer Service Problem Management \(CSPM\) provides the following features that work with Service Test Management.

-   The Service Test Management Open API \(TMF 653\), which external systems use to send test runs, test measures, threshold rule violations, and applied consequences.
-   Creating tests from a case.
-   Working with diagnostic tasks and resolution tasks.

For more information, see [Customer Service Problem Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/cspm-landing-page.md).

For how these records reach the application, see [Recording test results and violations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/how-test-results-are-recorded.md). For the plugin dependency between the two products, see [Plugins installed with Service Test Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/stm-requirements.md).
