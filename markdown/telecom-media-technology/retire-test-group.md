# Retire a test group

Retire a published test group that your teams no longer use in the Service Test Management application.

## Before you begin

The test group must be in the Published state.

Role required: sn\_st\_mgmt.test\_def\_manager

## Procedure

1.  Navigate to **All** &gt; **Service Test Management** &gt; **Test Groups** &gt; **All**.

2.  Select the published test group that you want to retire.

3.  Select **Retire**, and then confirm.


## Result

The state of the test group changes from Published to Retired. After a test group is retired, you can't change it.
