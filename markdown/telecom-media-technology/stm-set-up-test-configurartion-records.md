# Setting up test configuration records

Define the test definitions, test measures, threshold rules, consequences, and test groups that your teams run against telecom services.

Configure test definitions first, and then group them so that the right tests run for a specification or a product model. For the roles that each task needs, see [Roles installed with Service Test Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/stm-roles.md).

Before you start, review the plugin requirements in [Plugins installed with Service Test Management](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/stm-requirements.md). Some tasks are available only when the Product Model or Product Inventory plugin is active.

|Task|Description|
|----|-----------|
|[Setting up test definitions](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/settingup-test-specifications.md)|Define test definition to specify the parameters, metrics, and threshold rules for a service test.|
|[Setting up a test group](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/setting-test-group.md)|Use test groups to define manual or automated testing strategies, apply shared characteristics across test definitions, and limit scope using conditions tied to product inventory records.|
