# Access the Image to task plan template AI agent

Access the ServiceNow Otto for Sales CRM for Telecommunications Image to task plan template AI agent in AI Agent Studio.

## Before you begin

Role required: sn\_task\_plan.admin and sn\_prd\_pm.product\_catalog\_admin

## About this task

Open the AI agent to review its configuration, make sure that it's active, or clone it so that you can customize it. For details on customizing the agent, see [Duplicate an agentic workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/clone-aia-usecase.md).

## Procedure

1.  Navigate to **All** &gt; **AI Agent Studio** &gt; **Create and manage**.

2.  Select **Image to task plan template AI agent**.

    This AI agent is used in the Design Telecom Order Fulfilment Template agentic workflow.

    The guided setup opens, with the **Define key requirements**, **Define security controls**, **Add triggers**, and **Select channels and status** pages.

3.  On the **Select channels and status** page, make sure that **Active** is turned on.

    The AI agent runs only when it's active.
