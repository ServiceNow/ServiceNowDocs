# Test group run characteristics

Find out which characteristics appear on a test group run and which value is shown when a test group and a test definition define the same characteristic.

## Characteristics shown on a test group run

After the system selects a test definition, it applies the characteristic mapping to decide which characteristics appear on the test group run.

-   **Characteristic only on the test definition**

    The system adds the characteristic as it is, next to the characteristics of the test group.

-   **Characteristic on both the test group and the test definition**

    The system shows the value from the test group. The value from the test definition isn't shown.


## Characteristic choices

The characteristic and characteristic option lists on a test group run characteristic show only the characteristics defined for the test group of that run. The lists for a test characteristic show the characteristics of the test definition or of the test group of the associated run.
