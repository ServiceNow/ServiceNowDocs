# Use Service Test Management

Review test runs, the measures captured for them, and the violations and consequences that the measures raise.

Test results are normally sent by an external system rather than entered by hand. These topics describe how to read the records that arrive from the external system. For how the records are created, see [Recording test results and violations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/how-test-results-are-recorded.md).

Diagnostic tasks and resolution tasks are described in the Customer Service Problem Management documentation. See [Related Customer Service Problem Management information](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/telecom-media-technology/stm-related-cspm-information.md).
