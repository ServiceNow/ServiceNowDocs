# View a Customer Dispute Management case record

View the details of an Customer Dispute Management \(CDM\) case record in the CSM/FSM Configurable Workspace so that you can review the customer dispute information.

## Before you begin

Role required: sn\_telco\_adr\_mgmt.viewer

## Procedure

1.  Navigate to **All** &gt; **Workspaces** &gt; **CSM/FSM Configurable Workspace**.

2.  Select the list icon \(\[Omitted image "Lists.png"\] Alt text: List Icon.\).

3.  Navigate to **Customer Dispute Management** &gt; **All**.

4.  Select the CDM case record that you want to see the details.
