# Configure agentic workflows for Telecommunications Customer 360

Duplicate and activate the Telecommunications Customer 360 agentic workflows, and complete any additional setup a specific workflow requires.

Agentic workflows included with the base system are read-only. Before you use one, duplicate it and activate it, along with any AI agents and triggers it depends on. See [Duplicate an agentic workflow](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/clone-aia-usecase.md) and [Activate an agentic workflow template](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/intelligent-experiences/activate-aia-use-case.md).
