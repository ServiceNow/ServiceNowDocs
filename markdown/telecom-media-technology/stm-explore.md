# Exploring Service Test Management

Service Test Management \(STM\) enables service providers to define, execute, and monitor service tests in real time, and to review test results and resolve threshold violations.

Service Test Management enables Technology, Media, and Telecommunications \(TMT\) service providers to define, execute, and monitor service tests in real time. Service providers can use this application where proactive and reactive service testing is critical. You can create detailed test specifications, define test measures, set threshold limits, and configure actions for threshold violations. STM records the results of tests run against telecom services. Agents can then perform instantaneous testing and diagnostics.

When a measured value exceeds a defined limit, the system records a violation and can automatically apply a consequence. Agents can then review the test results and use diagnostic and resolution tasks to investigate issues and address the underlying problems efficiently.
