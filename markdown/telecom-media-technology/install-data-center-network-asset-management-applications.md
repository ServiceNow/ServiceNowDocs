# Install Data Center and Network Asset Management applications

Install all eligible Data Center and Network Asset Management applications from a single ServiceNow Store product. Use this procedure to install the apps your organization is entitled to in one step.

## Before you begin

Role required: admin

## About this task

A ServiceNow Store product groups multiple Store applications into one installable bundle. With a Store product, customers can:

-   Install multiple apps in a single select.
-   See which apps they're entitled to, based on their licenses.
-   Choose which apps to include at install time.

Data Center and Network Asset Management capabilities are delivered through many individual applications.

## Procedure

1.  Navigate to **All** &gt; **Application Manager**.

2.  Log in to your ServiceNow instance.

3.  Search for the Data Center and Network Asset Management.

4.  Select **Install**.

5.  Review the list of eligible apps and select the apps to install.

6.  Select **Confirm**.


## Result

You have successfully installed the Data Center and Network Asset Management store product and its eligible component applications to your ServiceNow instance.
