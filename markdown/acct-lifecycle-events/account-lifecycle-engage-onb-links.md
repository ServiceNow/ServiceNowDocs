# Engagement onboarding links

Link an engagement to more than one onboarding case to see all of the onboarding work for that engagement in one place.

An engagement can cover more than one onboarding workstream, such as a phased rollout for an existing customer account. An engagement onboarding link connects one engagement to one onboarding case. You can link an engagement to more than one onboarding case, and an onboarding case to more than one engagement.

The engagement and the onboarding case in a link must belong to the same account. When you select the second record, the list shows only active records on that account that aren't already linked to the record you started from.

The **Engagement Onboarding Links** related list shows the links on an engagement and on an onboarding case. On an onboarding case, the related list appears in the Account Onboarding Workspace view.

**Note:** Deleting a link removes only the link. The engagement and the onboarding case remain. Deleting an engagement or an onboarding case also deletes its links.

To link an engagement to an onboarding case, see [Link an engagement to an onboarding case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/acct-lifecycle-events/account-lifecycle-link-engage-onb-case.md). To create an engagement, see [Create an engagement](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/acct-lifecycle-events/account-lifecycle-create-engage.md). For onboarding cases that you create for an account in phases, see [Manage account onboarding cases](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/acct-lifecycle-events/account-lifecycle-manage-acct-onboard.md).
