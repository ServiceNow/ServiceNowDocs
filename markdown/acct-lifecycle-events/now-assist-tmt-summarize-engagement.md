# Summarize an engagement using ServiceNow Otto for Telecommunications, Media, and Technology \(TMT\)

Generate a summary from the fields you select on the engagement record. Get up to speed on success initiatives, outcomes, risks, and internal plays associated with an engagement.

## Before you begin

Role required: admin

## About this task

The engagement summary skill provides a concise summary of all activities and key points of information associated with an engagement. With this skill, you can generate an initial summary of the engagement, or summarize all the work associated with it.

The skill is available in CRM Workspace and in Core UI:

-   In CRM Workspace, use the Engagement summary by ServiceNow Otto component, which appears above the Account details card.
-   In Core UI, select **Summarize** on the engagement record.

**Note:** The skill requires a minimum 50 words in the record to generate a summary.

## Procedure

1.  Navigate to **Workspaces** &gt; **CRM Workspace** &gt; **Lists** &gt; **All Engagements**.

2.  Open an engagement.

3.  In the Engagement summary by ServiceNow Otto component, select **Summarize**.

    The component expands to display the summary. For longer summaries, select **View more** and scroll to see the rest of the content.

4.  After you're finished, manage the results: view more/less detail, provide helpful/not-helpful feedback, copy the summary, or view summary info using the icons on the summary card.
