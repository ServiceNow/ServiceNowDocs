# Track and monitor store plans

HQ and regional managers lack real-time insight into how published store plans are progressing. This capability bridges that gap by providing visibility from overall plan status down to individual store tasks.

Tracking begins once a plan is published and its cases and tasks have been generated. The **Track Plan** tab on a published plan brings the execution state of that plan into one place, so a manager can see overall progress and then move down to the record that is holding things up.

The tab provides two views:

-   The plan progress summary reports completion for a selected schedule occurrence, for the plan types provided with the base system.
-   The hierarchical list view presents the plan's generated records as a navigation tree with state tabs, and works with any plan type.

For details on when cases and tasks are generated, see [Stages of store plan tracking and monitoring](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/retail-industry/rahi-retail-stages-tracking-monitoring.md).

-   **[Plan progress summary](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/retail-industry/rahi-retail-plan-progress-summary.md)**  
The plan progress summary gives headquarters and regional managers a single view of how a published plan is progressing for a selected schedule occurrence, without opening individual cases.
-   **[Hierarchical list view](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/retail-industry/rahi-retail-hierarchical-list-view.md)**  
The hierarchical list view on the Track Plan tab presents a plan's generated cases and tasks as a navigation tree, so managers can move from the plan down to an individual store task without losing context.
-   **[Track a store plan on the workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/retail-industry/track-hq-case.md)**  
Enable plan creators to track published plan execution end-to-end, overall completion status, parent \(HQ\) cases, HQ tasks, store cases, and store tasks.
-   **[Track a store case from an HQ case](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/australia/retail-industry/track-store-case-hq-case.md)**  
Track a store case from an HQ case to view the status.
