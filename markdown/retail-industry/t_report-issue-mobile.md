# Report an issue on RSM Mobile

Create a case on RSM Mobile to quickly report an in-store issue and assign tasks to team members from your phone or tablet.

## Before you begin

Role required: `sn_rtl_instore_ops.associate`, `sn_rtl_instore_ops.manager`, or `sn_rtl_instore_ops.plan_author`

## About this task

**Note:** The store field is pre-filled based on your user profile. The case state progresses from New \(created\) to Open \(when assigned\) to Closed \(when resolved\).

## Procedure

1.  Open RSM Mobile and select **Report an Issue** from the main menu.

2.  Complete the following required fields:

    |Field|Description|
    |-----|-----------|
    |**Store**|Pre-filled with your assigned store. Managers can change this to report for another store in their area.|
    |**Short Description**|A brief summary of the issue \(required\).|
    |**Priority**|The urgency level \(required\).|
    |**Description**|Optional. Additional context about the issue.|
    |**Attachment**|Optional. Take a photo or attach a file from your device.|

3.  Tap **Submit**.

    **Note:** The system creates a case and displays a confirmation with the case number. The case is visible in your case list immediately.

4.  To assign a task from the new case, open the case details and tap **Add Task**. See [Add a task to a case on RSM Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/t_add-task-mobile.md).
