# Create a store plan from the CRM Workspace

The HQ manager creates a new plan for case and task generation.

## Before you begin

Role required: sn\_rtl\_hq\_ops.agent, sn\_rtl\_hq\_ops.agent\_manager, sn\_rtl\_hq\_ops.location\_manager

## Procedure

1.  Navigate to **All Lists** &gt; **Store plan** &gt; **All**.

2.  Select **New** &gt; **HQ communication** and select **Create plan**.

    A new playbook gets loaded.

3.  Enter the name in the **Name**.

4.  Enter the short description in the **Short Description**.

5.  Select **Save** to save the details and **Continue** to go the next step.


-   **[Add HQ case details to the HQ communication plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-add-hq-case-details.md)**  
Log the HQ case details to the new HQ communications store plan.
-   **[Add HQ task details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-add-hq-task-details.md)**  
Log the HQ task details to the new HQ communications store plan.
-   **[Add store case details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-add-store-case-details.md)**  
Log the store case details to the new HQ communications plan.
-   **[Add store task details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-add-store-task-details.md)**  
Log the store task details to the new HQ communications plan.
-   **[Add affected Retail stores](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-add-affected-retail-stores.md)**  
Determine the affected Retail stores from the list of retail stores.
-   **[Schedule the store plan](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail_schedule-the-cases-or-tasks.md)**  
Schedule the store plan based on the requirement- immediate, one time, or recurring. Once the store plan gets scheduled, it automates the case and task generation which reduces manual work.
-   **[Review store plan details](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/review-store-plan-details.md)**  
Review the details logged for the store plan and make any updates in any of the sections, if required.
