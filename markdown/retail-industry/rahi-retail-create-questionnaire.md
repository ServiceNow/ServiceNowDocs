# Create questionnaire for a store plan

Create questionnaire for a store plan on CSM/FSM Worskpace.

## Before you begin

Role required: sn\_rtl\_instore\_ops.manager

## Procedure

1.  Navigate to **Store plan** &gt; **All**.

2.  Select **New** &gt; **HQ communication** &gt; **Create plan**.

3.  Add HQ details, HQ task details, store case details, and store task details.

4.  On the Store task page, select a questionnaire template in the **Questionnaire template** or select **Create new questionnaire**.

5.  Enter the name of the template in **Template name**.

6.  Enter the description in the **Description**.

7.  Select **Create**.

8.  Enter the assessment template details in **General** &gt; **Details**.

9.  Enter preferred type of questions in **Questions** &gt; **Add question**.

    | | |
    |---|---|
    |**Add assessment reference**| |
    |**Add instructions**| |

10. Enter preferred type of section details in **Questions** &gt; **Add section**.

    | | |
    |---|---|
    |**Question**| |
    |**Required toggle option**| |
    |**Type &gt; Create choices to select from**|Drop-down, radio button, checkbox|
    |**Type &gt; Allow a freeform answer**|Text, number,code|
    |**Other**|Reference, attachment|

11. Set preferred settings in **Settings**.

    | | |
    |---|---|
    |**Duration of the assessment**|Number of days|
    |**Assessment reader role**|Assessment reader role is mandatory|

12. Select **Continue** to create the store task.

    Store task page displays the store task name, questionnaire template name, and priority of the task.
