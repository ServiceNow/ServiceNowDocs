# Manage store plans to generate cases and tasks

Manage store plans to plan and schedule generation of cases and tasks to simplify manual efforts.

To create a store plan, see [Create a store plan from the CRM Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/create-plan-workspace.md). The topics under it cover adding the case and task details, adding the affected stores, scheduling the plan, and reviewing the plan details.

-   **[Create a store plan from the CRM Workspace](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/create-plan-workspace.md)**  
The HQ manager creates a new plan for case and task generation.
