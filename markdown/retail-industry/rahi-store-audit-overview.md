# Retail Store Audit Operations

Retail Store Audit Operations lets Plan Authors publish structured audit plans that automatically generate Store Audit Cases and Audit Tasks for field Auditors to complete across selected store locations.

Retail Store Audit Operations enables structured, repeatable store audit programs. Plan Authors author audit plans against pre-configured templates, select the store locations to audit, and publish the plan. Auditors then visit the stores, complete the generated work, and record their findings—all tracked on a single platform instead of spreadsheets or disconnected task lists.

## Plan authoring and case generation

A Plan Author uses the **Store audit** playbook to configure audit template items, select store locations, and set a schedule, then publishes the plan. For an immediate schedule, the Store Audit Cases and Audit Tasks are created automatically as part of publishing—one Store Audit Case per selected store, with an Audit Task per case. For a one-time or recurring schedule, they are generated later at the scheduled time instead.

Platform assignment rules automatically set the assignment group on the new records. A Store Audit Manager can assign an individual Auditor if the automated routing needs correcting.

## Auditor fulfillment

HQ Auditors complete their assigned Store Audit Cases in CSM/FSM Workspace; Location Auditors can also use Retail Mobile. Fulfillment centers on completing the questionnaire on each Audit Task, recording observations in work notes and comments, and progressing the case through New, Open, and Closed.

**Note:** The Store Audit Case and Audit Task list views don't have **New** or **Add** buttons—records are only created by the playbook or generation flow. Generated records remain visible from the **Retail cases** list.
