# Components installed with Smart Assessments for CSM

Smart Assessment support in CRM Workspace provides a unified experience for creating, configuring, and viewing assessment templates and instances.

The following enhancements are available in CRM Workspace:

-   Smart Assessment functionality is available in CRM Workspace.
-   Users can create Smart Assessment templates by using a modal dialog within the CRM Workspace experience.
-   The Template Overview page is available in CRM Workspace for defining and managing Smart Assessment questions.
-   Interoperability configurations enable the Template Overview experience from the Smart Assessment workspace to be reused in CRM Workspace.
-   The integration supports the complete Smart Assessment template creation workflow within CRM Workspace.
-   A dedicated Smart Assessment Instance record page variant is available in CRM Workspace.
-   The Smart Assessment Instance record page enables users to view Smart Assessment instance details within the CRM Workspace experience.
