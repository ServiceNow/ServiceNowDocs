# Find a project task in the Retail Portal

Open the projects for your store in the Retail Portal and drill into the project task you want to work on.

## Before you begin

Role required: a retail contributor or fulfiller responsibility, and either sn\_bus\_loc.location\_project\_stakeholder or sn\_bus\_loc.location\_manager\_project\_stakeholder for your store

## About this task

**Note:** The **Projects** category appears only when the App SPM Retail plugin is active. You see only the project tasks that the project manager made visible to your store. For more information, see [Project tasks in Retail](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-spm-project-tasks-overview.md).

## Procedure

1.  In the Retail Portal, navigate to **More information** &gt; **Retail organizations**, and then select your store.

2.  On the Retail Org Details page, select the **Projects** category.

    The projects for your store are listed with their number, project name, state, and project manager.

3.  Select a project.

    The project page shows the project number and state, followed by the project name, project manager, planned end date, and description. The **Project tasks** list shows the tasks for the project with their number, short description, planned end date, priority, state, and assignee. You can search the list and filter it by state, priority, or assignee.

4.  Select the project task you want to work on.

    The task page shows the task number and state. Below that, it shows the task title, assignee, priority, planned end date, assignment group, and the project that the task belongs to. Select the project name to open the project. The **Project task** tab lists any child tasks of this task.


## Result

The project task page is open. To assign or close the task, see [Assign or close a project task in the Retail Portal](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-spm-act-on-tasks-portal.md).
