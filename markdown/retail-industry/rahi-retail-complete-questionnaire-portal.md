# Complete a questionnaire for a Store Task on the Retail Portal

Complete task-based questionnaires for HQ-to-store communication directly on the Retail Portal.

## Before you begin

Role required: sn\_rtl\_instore\_ops.manager or sn\_rtl\_instore\_ops.associate

## About this task

**Note:** Only the user assigned to the Store Task can fill in and submit its questionnaire. Other users can view the answers but can't edit or submit them.

## Procedure

1.  From the Retail Portal, navigate to **Cases &amp; tasks**, and open the Store Task with the linked questionnaire.

2.  Select the **Questionnaires** tab.

    The tab shows a card with the questionnaire name, description, current status, and last-updated timestamp.

3.  Select **Take questionnaire** from the card or the **Overflow** menu.

    If you already saved progress on this questionnaire, the button reads **Resume** instead. Either option opens the questionnaire inline.

4.  Answer the questions.

    You can answer any question type supported by the embedded Smart Assessment questionnaire. You can save your progress and return later; your answers are preserved.

5.  If finished, select **Submit**.

    **Note:**

    -   Submission is blocked if any required question is unanswered. The portal highlights the missing required fields.
    -   Once submitted, the questionnaire card updates to **Completed** with a timestamp, and the questionnaire becomes read-only.
    -   If the Store Task is reassigned before the questionnaire is submitted, the original questionnaire instance is abandoned and a new instance is created for the new assignee. Partial answers aren't carried over.
