# Assign or close a project task in Retail Mobile

Comment on a project task, assign it, or close it from the task screen in Retail Mobile.

## Before you begin

Role required: a retail contributor or fulfiller responsibility, and either sn\_bus\_loc.location\_project\_stakeholder or sn\_bus\_loc.location\_manager\_project\_stakeholder for your store

Open a project task as described in [Find a project task in Retail Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-spm-view-projects-mobile.md).

## About this task

**Note:** The task actions are offered only while the task is open.

## Procedure

1.  To add a comment or an attachment, use the activity stream.

2.  To assign the task, select **Assign task** or **Assign to me**.

    These actions are available while the task is open, you can change the assignee and assignment group, and the task isn't already assigned to you. Select **Assign task** to choose an assignment group or an assignee. **Assign task** is also available from the overflow menu, where it appears even when the task is already assigned to you.

3.  To complete the task, select **Close task**.

    This action is available while the task is open and assigned to you. If you don't have write access to the task, the action reports that the update wasn't permitted instead of failing silently.


## Result

Your update is saved to the project task. The project manager at headquarters sees the current state of the work without asking the store for a status update.
