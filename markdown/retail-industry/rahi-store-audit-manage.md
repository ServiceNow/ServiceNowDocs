# Manage Store Audit

Manage store audit operations by audit assignments, creating and publishing audit plans, and completing store audits.

For more information on managing store audits, see

-   [Override audit assignment](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-override-assignment.md)
-   [Create an audit plan and generate cases and tasks](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-create-and-generate.md)
-   [Complete a store audit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-fulfill-audit.md)

.

-   **[Override audit assignment](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-override-assignment.md)**  
As a Store Audit Manager, manually reassign a Store Audit Case or Audit Task to a different Auditor when the automated assignment rules have routed a record incorrectly.
-   **[Create an audit plan and generate cases and tasks](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-create-and-generate.md)**  
Use the **Store audit** playbook in CSM/FSM Workspace to author and publish an audit plan, then click **Generate Cases/Tasks** to create Store Audit Cases and Audit Tasks for all selected store locations.
-   **[Complete a store audit](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-fulfill-audit.md)**  
As an Auditor, open your assigned Store Audit Case in CSM/FSM Workspace, visit the physical store, record observations in work notes and comments, close each Audit Task using **Close Complete**, then close the Store Audit Case.
-   **[Complete a store audit from Retail Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-fulfill-audit-mobile.md)**  
As a Location Auditor, take your assigned Store Audit Case and Audit Tasks in Retail Mobile, complete the questionnaire, and close the case.
-   **[Complete an Audit Task from Retail Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/retail-industry/rahi-store-audit-t-complete-audit-task-mobile.md)**  
As a Location Auditor, open an Audit Task in Retail Mobile, complete its questionnaire, and close the task.
