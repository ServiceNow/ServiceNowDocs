# Track Store Audit Progress Using Moveworks Chat

After Store Audit plans are published and audit cases are created in RSM, auditors can ask Moveworks about plan progress, task completion status, and Pass/Fail results without accessing the RSM portal.

## Before you begin

-   A Store Audit plan has been created and published \(see [Create and Publish Store Audit Plans](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-store-audit-t-create-and-generate.md)\)
-   Audit cases have been auto-generated in RSM for your store
-   You are an auditor assigned to execute the audit tasks
-   Access to Moveworks \(web, Teams, Slack, or embedded Retail portal\)
-   Role required: none.

## About this task

After a Store Audit plan is published, RSM auto-generates one Audit Case per selected store with all associated tasks. Auditors execute tasks on mobile \(see [Execute Store Audit on Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-store-audit-t-fulfill-audit-mobile.md)\). To check overall plan progress, task completion status, or Pass/Fail results without navigating the portal, use Moveworks chat.

## Procedure

1.  Ask Moveworks about your Store Audit plan.

    -   "What's the status of my Store Audit plan for June?"
    -   "How many tasks do I have left in my audit?"
    -   "Show me my audit progress"
    -   "What store audit cases am I assigned to?"
2.  Review the audit plan and case status that Moveworks retrieves from RSM.

    Moveworks displays the following information:

    -   **Plan Name**: for example, "June Monthly Compliance Audit"
    -   **Total Tasks**: Number of tasks in the plan
    -   **Completed**: Tasks marked Pass/Fail
    -   **Remaining**: Tasks not yet executed
    -   **Pass Count / Fail Count**: Results breakdown
    -   **Overall Progress**: Percentage complete
3.  Ask Moveworks for details on specific tasks if needed.

    -   "What does Task 3 require?"
    -   "Which tasks failed in my audit?"
    -   "Show me tasks that are pending"
    -   "What's the deadline for completing this audit?"
4.  To execute tasks, use the mobile app instead of Moveworks.

    While Moveworks provides status tracking, actual task execution \(marking Pass/Fail, taking photos, adding notes\) happens in the mobile app. See [Execute Store Audit on Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-store-audit-t-fulfill-audit-mobile.md) for the task execution workflow.

5.  Use Moveworks to check audit progress between mobile sessions.

    You can check Moveworks anytime \(web, Teams, Slack\) to see updated progress after completing tasks on mobile. No portal login is required.


## Result

You now have quick visibility into Store Audit plan progress without a portal login. You can see the overall plan completion percentage, view the Pass/Fail breakdown, identify remaining tasks, check task details and deadlines, and monitor progress from any device \(web, Teams, Slack\).

## What to do next

To execute audit tasks and mark them Pass/Fail, use the mobile app as described in [Execute Store Audit on Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-store-audit-t-fulfill-audit-mobile.md). For managers tracking audit results across stores, see [Track Store Audit Results \(Manager\)](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-store-audit-manage.md).
