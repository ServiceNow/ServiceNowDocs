# Find a project task in Retail Mobile

Reach the project tasks for your store from your store details or from **My Work**, and open the one you want to work on.

## Before you begin

Role required: a retail contributor or fulfiller responsibility, and either sn\_bus\_loc.location\_project\_stakeholder or sn\_bus\_loc.location\_manager\_project\_stakeholder for your store. **My Work** is available to fulfillers only.

## About this task

**Note:** The **Projects** entry and the **Tasks** filter appear only when the App SPM Retail plugin is active. You see only the project tasks that the project manager made visible to your store. For more information, see [Project tasks in Retail](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-spm-project-tasks-overview.md).

## Procedure

1.  Open the project task using one of the following options.

    -   To work through your store, open your store details, select **Projects**, select a project, and then select a project task. Each project shows its state, number, name, and project manager.
    -   To work from your own queue, open **My Work**. The list shows your cases and your project tasks together. Select the **Tasks** filter to show only the project tasks assigned to you or to an assignment group that you belong to.
    Project task cards show the state, priority, task number, short description, assignee, and due date.

    **Note:** The **Projects** entry appears only when you have project tasks assigned for your store. **My Work** is available to fulfillers, so a contributor reaches project tasks through their store details instead.

2.  Review the task details.

    The task screen shows the project number, due date, and description. Select **Show more** to expand a long description, and select the project number to open the project. Any child tasks of this task are listed below the activity stream.


## Result

The project task is open. To assign or close it, see [Assign or close a project task in Retail Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-spm-act-on-tasks-mobile.md).
