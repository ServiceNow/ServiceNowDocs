# Field Service for Audit data model

The Field Service for Audit data model shows how the audit task table extends the work-management task type provided by Field Service Management.

## Data model

The `wm_audit_task` table extends `wm_task` from Field Service Management, inheriting all standard assignment, scheduling, and lifecycle fields. Field Service for Audit adds two audit-specific fields: Result and Task Plan Template Item.
