# Add a task to a case on Retail Mobile

Create a task within an existing case to delegate work to team members on Retail Mobile.

## Before you begin

Role required: `sn_rtl_instore_ops.associate`, `sn_rtl_instore_ops.manager`, or `sn_rtl_instore_ops.manager_contributor`

## About this task

You can add a task from the bottom of the case screen or from the case's overflow menu. Either option opens a form with the required fields. The new task is linked to the case automatically. No questionnaire changes were made on mobile for this feature.

## Procedure

1.  On Retail Mobile, open the case for which you want to add a task.

2.  Tap **Add task** at the bottom of the case screen, or select it from the overflow menu.

3.  Enter the task details:

    |Field|Description|
    |-----|-----------|
    |**Short Description**|A brief summary of the work \(required\).|
    |**Assigned To**|Optional. The store associate or store manager who completes the task. The picker isn't restricted by role, so area and region managers can also be selected, but they can't assign tasks themselves.|
    |**Priority**|Required. The urgency level for the task.|
    |**Due Date**|When the task should be completed.|
    |**Description**|Optional. Task details or instructions.|
    |**Assignment group**|Optional. The group to assign the task to.|
    |**Add attachment**|Optional. Take a photo or attach a file from your device.|

4.  Tap **Submit**.

    The task appears on the case's **Tasks** tab. An unassigned task is in the Pending Assignment state. When a task is assigned, the assignee gets a push notification.

5.  Optional: To assign, edit, or close the task, tap it on the case's **Tasks** tab.

    For details, see [Work on a quick in-store task on Retail Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/t_work-adhoc-task-mobile.md).
