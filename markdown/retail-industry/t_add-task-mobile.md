# Add a task to a case on RSM Mobile

Create a task within an existing case to delegate work to team members on RSM Mobile.

## Before you begin

Role required: `sn_rtl_instore_ops.manager` or `sn_rtl_instore_ops.associate`

## About this task

**Note:** Tasks can be added from the **Tasks** tab on the case detail screen, or from the action menu. Task state progresses from Pending Dispatch → Accepted → Closed Complete. A linked questionnaire, if present, must be submitted before the task can close.

## Procedure

1.  On RSM Mobile, open the case for which you want to add a task.

2.  Tap the **Tasks** tab.

3.  Tap **Add Task** \(or from the action menu, select **Add Task**\).

4.  Enter the task details:

    |Field|Description|
    |-----|-----------|
    |**Short Description**|A brief summary of the work \(required\).|
    |**Assigned To**|The team member who will complete the task \(required\). Area/Region Managers cannot be assigned to tasks.|
    |**Priority**|Urgency level for the task.|
    |**Due Date**|When the task should be completed.|
    |**Description**|Optional. Task details or instructions.|

5.  Tap **Submit**.

    **Note:** The task is created in Pending Dispatch state and the assignee is notified. They can accept the task or update the status from their mobile app.

6.  To manage the task \(edit, close, or view details\), open it from the case **Tasks** tab. See [Work on an In-store operations task in Retail Mobile](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/brazil/markdown/retail-industry/rahi-retail-in-store-task-mobile.md).
